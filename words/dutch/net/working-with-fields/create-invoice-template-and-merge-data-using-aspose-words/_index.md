# Maak factuursjabloon en voeg gegevens samen met Aspose.Words

Als je snel een **factuursjabloon** moet maken, laat deze gids je precies zien hoe. Na de eerste twee zinnen ken je de volledige workflow om een leeg Word‑bestand om te zetten in een volledig ingevulde factuur, met behulp van de low‑code mail‑merge API van Aspose.Words.

Facturen genereren is een veelvoorkomende eis voor facturatiesystemen, ERP‑integraties en geautomatiseerde rapportage. In deze tutorial leer je **hoe je mail‑merge uitvoert**, **een Word‑sjabloon vult**, **gegevens in Word samenvoegt**, en uiteindelijk **het samengevoegde document opslaat** — alles met een handvol C#‑regels.

## Wat je zult bereiken

* Een herbruikbaar Word‑sjabloon (`InvoiceTemplate.docx`) dat samenvoegvelden bevat voor klant, datum, regelitems en totaal.  
* Een C#‑programma dat het sjabloon laadt, een sterk getypeerd gegevensobject injecteert en het resultaat schrijft naar `Invoice_001.docx`.  
* Inzicht in randgevallen zoals lege collecties, aangepaste gegevenstypen en bestands‑padafhandeling.

### Vereisten

| Vereiste | Waarom het belangrijk is |
|----------|--------------------------|
| .NET 6 of later | Aspose.Words for .NET ondersteunt .NET 6+ en biedt de low‑code API die in deze gids wordt gebruikt. |
| Aspose.Words for .NET NuGet‑pakket (`Aspose.Words`) | Levert `Document`, `MailMerger` en gerelateerde types. |
| Basis C#‑kennis | Nodig om anonieme objecten en LINQ te begrijpen. |
| Visual Studio 2022 (of een andere IDE) | Maakt bewerken en debuggen eenvoudig. |

> **Pro tip:** Installeer het NuGet‑pakket via de Package Manager Console:  
> `Install-Package Aspose.Words`

## Hoe een factuursjabloon maken met low‑code mail merge

De eerste stap is een Word‑bestand te maken dat samenvoegvelden bevat die overeenkomen met de eigenschappen van het gegevensobject dat later wordt doorgegeven. Sla het bestand op als `InvoiceTemplate.docx` in een map die je beheert (bijv. `C:\Invoices\Template`).

| Samenvoegveld | Voorbeeld placeholder in Word |
|---------------|-------------------------------|
| CustomerName | «CustomerName» |
| InvoiceDate | «InvoiceDate» |
| Items (repeating) | «Items.Description», «Items.Qty», «Items.Price» |
| Total | «Total» |

> **Waarom dit belangrijk is:** De low‑code API mapt automatisch de eigenschapsnamen van de gegevensbron naar de samenvoegvelden. Het identiek houden van namen elimineert handmatige veld‑naar‑eigenschap‑mapping en vermindert runtime‑fouten.

## Stap 1: Laad het factuursjabloon

```csharp
using Aspose.Words;
using Aspose.Words.LowCode;   // Low‑code mail‑merge API

// Load the Word file that contains the merge fields.
Document template = new Document(@"C:\Invoices\Template\InvoiceTemplate.docx");
```

*De `Document`‑klasse vertegenwoordigt het volledige Word‑bestand. Het één keer laden stelt je in staat hetzelfde sjabloon voor veel facturen te hergebruiken.*

## Stap 2: Bereid de gegevensbron voor

Maak een anoniem object dat de samenvoegvelden weerspiegelt. De low‑code API kan werken met elk .NET‑object, inclusief arrays en geneste collecties.

```csharp
var invoiceData = new
{
    CustomerName = "Acme Corp",
    InvoiceDate = DateTime.Today,
    Items = new[]
    {
        new { Description = "Widget A", Qty = 10, Price = 9.99M },
        new { Description = "Widget B", Qty = 5,  Price = 19.95M }
    },
    Total = 199.85M
};
```

**Waarom dit werkt:**  
* De eigenschapsnamen (`CustomerName`, `InvoiceDate`, `Items`, `Total`) komen overeen met de samenvoegvelden in het sjabloon.  
* `Items` is een array van objecten, waardoor de mail‑merger de tabelrij automatisch voor elk element herhaalt.  
* Het gebruik van `decimal` (`M`‑suffix) voor geldwaarden voorkomt afrondingsproblemen van floating‑point.

### Lege collecties verwerken

Als een factuur geen regelitems heeft, geef dan een lege array door:

```csharp
Items = new object[0]
```

De low‑code engine zal simpelweg de herhalende sectie weglaten, waarbij de tabelkop behouden blijft.

## Stap 3: Initialiseert de low‑code mail merger

```csharp
MailMerger merger = new MailMerger(template);
```

`MailMerger` is het toegangspunt voor **hoe je mail‑merge uitvoert** met Aspose.Words. Het leest het sjabloon, bindt de gegevens en bereidt het einddocument voor in één enkele aanroep.

## Stap 4: Voer de merge uit – vul Word‑sjabloon in één regel

```csharp
Document mergedDocument = merger.Execute(invoiceData);
```

* Deze regel **vult het Word‑sjabloon** en produceert een nieuwe `Document`‑instantie (`mergedDocument`).  
* Alle samenvoegvelden worden vervangen, herhalende secties worden uitgebreid, en het resulterende document bevindt zich volledig in het geheugen.

### Randgeval: Aangepaste opmaak

Als je een specifiek datumformaat nodig hebt, voeg dan een aangepaste formatter toe vóór de merge:

```csharp
merger.Options.DateFormat = "MMMM dd, yyyy"; // e.g., "October 07, 2026"
```

## Stap 5: Sla het samengevoegde document op

```csharp
mergedDocument.Save(@"C:\Invoices\Output\Invoice_001.docx");
```

De aanroep **save merged document** schrijft de volledig ingevulde factuur naar de schijf. Het bestand kan nu worden geopend in Microsoft Word, verzonden als e‑mailbijlage, of geconverteerd naar PDF.

### Het resultaat verifiëren

Open `Invoice_001.docx`. Je zou moeten zien:

* **CustomerName** vervangen door *Acme Corp*  
* **InvoiceDate** toont de datum van vandaag in het gekozen formaat  
* Een tabelrij voor *Widget A* (10 × 9.99) en *Widget B* (5 × 19.95)  
* **Total** toont *199.85*

Als een veld onveranderd blijft (bijv. nog steeds «CustomerName» toont), controleer dan of de eigenschapsnamen exact overeenkomen met de samenvoegveld‑namen in het sjabloon.

## Volledig uitvoerbaar voorbeeld

Hieronder staat het volledige programma dat je kunt kopiëren en plakken in een nieuw console‑project.

```csharp
using System;
using Aspose.Words;
using Aspose.Words.LowCode;   // Low‑code mail‑merge API

namespace InvoiceGenerator
{
    class Program
    {
        static void Main()
        {
            // 1️⃣ Load the template
            Document template = new Document(@"C:\Invoices\Template\InvoiceTemplate.docx");

            // 2️⃣ Build the data source
            var invoiceData = new
            {
                CustomerName = "Acme Corp",
                InvoiceDate = DateTime.Today,
                Items = new[]
                {
                    new { Description = "Widget A", Qty = 10, Price = 9.99M },
                    new { Description = "Widget B", Qty = 5,  Price = 19.95M }
                },
                Total = 199.85M
            };

            // 3️⃣ Initialise the mail merger
            MailMerger merger = new MailMerger(template);

            // Optional: customise date format
            merger.Options.DateFormat = "MMMM dd, yyyy";

            // 4️⃣ Perform the merge (populate word template)
            Document mergedDocument = merger.Execute(invoiceData);

            // 5️⃣ Save the resulting file (save merged document)
            mergedDocument.Save(@"C:\Invoices\Output\Invoice_001.docx");

            Console.WriteLine("Invoice generated successfully.");
        }
    }
}
```

Voer het programma uit (`dotnet run`). De console geeft *Invoice generated successfully.* weer en het bestand verschijnt in `C:\Invoices\Output`.
