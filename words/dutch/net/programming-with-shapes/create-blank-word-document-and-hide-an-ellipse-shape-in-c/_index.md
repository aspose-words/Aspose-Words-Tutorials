# Maak een leeg Word‑document en verberg een ellipsvorm in C#

Als je een **leeg Word‑document** wilt maken en vervolgens een grafisch element wilt verbergen, laat deze gids je precies zien hoe je dat doet met C#. Je ziet een volledig, uitvoerbaar voorbeeld dat een ellips invoegt, positioneert, als verborgen markeert en het bestand opslaat — alles in een paar regels code.

De tutorial behandelt alles van projectopzet tot de laatste verificatiestap. Aan het einde kun je een Word‑bestand genereren waarin de ellips nooit op het scherm of op papier verschijnt, wat handig is voor het opslaan van metadata, bladwijzers of andere onzichtbare markeringen.

## Vereisten

Voordat je begint, zorg dat je het volgende hebt:

* .NET 6.0 SDK of later geïnstalleerd  
* Een C#‑ontwikkelomgeving (Visual Studio 2022, Rider of VS Code)  
* Het **Aspose.Words for .NET** NuGet‑pakket (`Install-Package Aspose.Words`)  

Deze tools leveren de `Document`‑ en `DocumentBuilder`‑klassen die in het code‑voorbeeld worden gebruikt.

## Stap 1: Maak een leeg Word‑document

De eerste handeling maakt een leeg `Document`‑object en een `DocumentBuilder` waarmee je inhoud kunt toevoegen.

```csharp
using Aspose.Words;
using Aspose.Words.Drawing;

// Step 1: Initialize an empty document and a builder
Document doc = new Document();
DocumentBuilder builder = new DocumentBuilder(doc);
```

`Document` vertegenwoordigt het volledige `.docx`‑pakket, terwijl `DocumentBuilder` een fluent API biedt voor het invoegen van tekst, vormen en andere objecten. Beginnen met een leeg document geeft je volledige controle over elk element dat je toevoegt.

## Stap 2: Hoe een ellips invoegen

Een ellips is een vectorvorm die als markering kan dienen. De `InsertShape`‑methode vereist het vormtype en de breedte/hoogte in punten.

```csharp
// Step 2: Insert an ellipse shape of the desired size (100 pt × 50 pt)
Shape ellipse = builder.InsertShape(ShapeType.Ellipse, 100, 50);
```

De ellips wordt geplaatst op de huidige pagina op de cursorlocatie. Je kunt de afmetingen aanpassen door de numerieke argumenten te wijzigen.

## Stap 3: Hoe de vorm positioneren

Na het invoegen kun je de vorm overal op de pagina verplaatsen door de eigenschappen `Left` en `Top` in te stellen, die punten ten opzichte van de paginamarge gebruiken.

```csharp
// Step 3: Position the shape on the page
ellipse.Left = 150; // distance from the left margin
ellipse.Top  = 100; // distance from the top margin
```

Deze coördinaten plaatsen de ellips ongeveer in het boven‑midden van een standaard A4‑pagina. Pas de waarden aan om aan je lay‑outvereisten te voldoen.

## Stap 4: Hoe de vorm verbergen

Een verborgen object wordt niet weergegeven wanneer het document wordt geopend of afgedrukt. Het instellen van de `Hidden`‑vlag markeert de vorm als een **verborgen object**.

```csharp
// Step 4: Hide the shape so it never appears
ellipse.Hidden = true;
```

Word respecteert de verborgen‑vlag zowel voor weergave op het scherm als voor afdrukoutput. De vorm blijft onderdeel van de documentstructuur, zodat je later via code kunt zoeken of deze kunt wijzigen.

## Stap 5: Sla het document op

Schrijf tenslotte het document naar de schijf. Kies een map waarin je schrijfrechten hebt.

```csharp
// Step 5: Save the document to a .docx file
doc.Save(@"C:\Temp\HiddenEllipse.docx");
```

Het bestand `HiddenEllipse.docx` bevat nu een lege pagina met een verborgen ellipsvorm.

## Verifiëren van de verborgen ellips

Open het gegenereerde bestand in Microsoft Word en schakel de optie **Verborgen tekst weergeven** in (Bestand → Opties → Weergave). Je ziet een vage omtrek van de ellips. Als je de optie uitschakelt, verdwijnt de vorm volledig, wat bevestigt dat `ellipse.Hidden = true` werkt zoals verwacht.

## Veelvoorkomende variaties en randgevallen

| Situatie | Aanbevolen aanpassing |
|-----------|------------------------|
| **Andere vorm** | Vervang `ShapeType.Ellipse` door `ShapeType.Rectangle`, `ShapeType.Arrow`, enz. |
| **Meerdere verborgen objecten** | Herhaal stappen 2‑4 voor elke vorm; elke vorm kan zijn eigen `Hidden`‑vlag hebben. |
| **Andere paginagrootte** | Stel `doc.FirstSection.PageSetup.PageWidth` en `PageHeight` in vóór het invoegen van de vorm. |
| **Conditionele zichtbaarheid** | Gebruik `Shape.Visible` in combinatie met `Hidden` om tijdens runtime te schakelen via code. |

**Pro tip:** Sla identificatiedata op in de eigenschap `AlternativeText` van de vorm. Zelfs wanneer verborgen, kun je de vorm later ophalen met `doc.GetChildNodes(NodeType.Shape, true)` en filteren op die tekst.

## Volledige broncode

Hieronder staat het complete programma dat je kunt kopiëren, plakken en uitvoeren.

```csharp
using System;
using Aspose.Words;
using Aspose.Words.Drawing;

namespace HiddenShapeDemo
{
    class Program
    {
        static void Main()
        {
            // Create a new blank document and a builder
            Document doc = new Document();
            DocumentBuilder builder = new DocumentBuilder(doc);

            // Insert an ellipse shape (100 pt × 50 pt)
            Shape ellipse = builder.InsertShape(ShapeType.Ellipse, 100, 50);

            // Position the shape on the page
            ellipse.Left = 150;
            ellipse.Top  = 100;

            // Hide the shape so it is invisible in the UI and on print
            ellipse.Hidden = true;

            // Optional: add a description for later retrieval
            ellipse.AlternativeText = "Hidden marker for internal processing";

            // Save the document
            string outputPath = @"C:\Temp\HiddenEllipse.docx";
            doc.Save(outputPath);

            Console.WriteLine($"Document saved to {outputPath}");
        }
    }
}
```

**Verwachte output:** De console toont het opslagpad, en het bestand `HiddenEllipse.docx` opent als een lege pagina zonder zichtbare grafische elementen, tenzij verborgen objecten worden weergegeven.

## Conclusie

Je weet nu hoe je **een leeg Word‑document** programmatically kunt **maken**, **een ellips kunt invoegen**, **de vorm kunt positioneren** en **de vorm kunt verbergen** zodat deze zich gedraagt als een **verborgen object**. Deze techniek is ideaal voor het embedden van onzichtbare markeringen, aangepaste metadata of tijdelijke aanduidingen die downstream‑processen kunnen lezen zonder de visuele lay‑out van het document te beïnvloeden.

* Integreer deze code in een grotere automatiseringspipeline die rapporten of contracten genereert.

Voel je vrij om te experimenteren met de coördinaten, afmetingen en de verborgen‑vlag om ze aan te passen aan jouw specifieke scenario. Veel programmeerplezier!
