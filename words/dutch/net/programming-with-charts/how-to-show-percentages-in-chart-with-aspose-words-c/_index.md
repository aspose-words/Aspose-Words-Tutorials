# Hoe percentages weergeven in een diagram met Aspose.Words C#

Heb je je ooit afgevraagd **hoe je percentages in een diagram kunt weergeven** zonder te worstelen met complexe Office‑interop? Je bent niet de enige—veel ontwikkelaars lopen tegen die muur aan wanneer ze snel een programmeerbare manier nodig hebben om een taart‑ of donut‑diagram te labelen. Het goede nieuws? Met Aspose.Words voor .NET kun je die gegevenslabels inschakelen in slechts een handvol regels code.

In deze tutorial behandelen we ook **gegevenslabels toevoegen aan taartdiagram** en **hoe diagram‑gegevenslabels in te schakelen**, zodat je visualisaties meteen inzichtelijker worden. Aan het einde heb je een kant‑klaar Word‑document (`.docx`) dat een gepolijste taartgrafiek toont met percentages netjes buiten elke partitie geplaatst.

## Vereisten

Voordat we beginnen, zorg dat je het volgende hebt:

- **Aspose.Words voor .NET** (nieuwste versie, bijv. 24.9) geïnstalleerd via NuGet.  
- Een **ChartTemplate.docx**‑bestand dat al een taart‑ of donut‑diagram bevat.  
  *(Als je er geen hebt, maak dan een eenvoudig Word‑document, voeg een taart‑diagram toe en sla het op als `ChartTemplate.docx`.)*  
- .NET 6.0 of later en een IDE naar keuze (Visual Studio, Rider, VS Code).

Er zijn geen extra afhankelijkheden nodig—Aspose.Words regelt alles intern.

## Hoe percentages weergeven in een diagram – Stap‑voor‑stap

Hieronder splitsen we het proces op in zes duidelijke stappen. Elke stap bevat de exacte C#‑code die je kunt kopiëren‑en‑plakken, plus een korte uitleg **waarom** we dit doen.

### Stap 1: Laad het bron‑document

```csharp
using Aspose.Words;
using Aspose.Words.Drawing.Charts;

// Load the .docx that already holds a chart.
Document sourceDoc = new Document("YOUR_DIRECTORY/ChartTemplate.docx");
```

*Waarom?*  
`Document` is het startpunt voor elke Word‑manipulatie. Door het sjabloon te laden krijgen we toegang tot elk knooppunt—vormen, tabellen, tekst en uiteraard het diagram dat we gaan aanpassen.

### Stap 2: Pak de eerste diagram‑vorm

```csharp
// The chart lives inside a Shape node; retrieve it.
Chart chart = (Chart)sourceDoc.GetChild(NodeType.Shape, 0, true);
```

*Waarom?*  
Aspose slaat diagrammen op als `Shape`‑objecten. `GetChild` doorloopt de documentboom en retourneert de eerste vorm die hij vindt, wat in ons geval het taart‑diagram is dat we willen bewerken.

### Stap 3: Bevestig het diagramtype

```csharp
if (chart.ChartType == ChartType.Pie || chart.ChartType == ChartType.Doughnut)
{
    // Inside this block we’ll enable the data labels.
}
else
{
    throw new InvalidOperationException("The chart is not a Pie or Doughnut type.");
}
```

*Waarom?*  
Percentage‑labels hebben alleen zin voor ronde diagrammen. Deze controle voorkomt dat we per ongeluk instellingen toepassen op bijvoorbeeld een staafdiagram, waar `ShowPercentage` wordt genegeerd.

### Stap 4: Schakel gegevenslabels in en toon percentages

```csharp
// Turn on data labels for the chart.
chart.HasDataLabel = true;

// Show the percentage value for each slice.
chart.DataLabel.ShowPercentage = true;
```

*Waarom?*  
`HasDataLabel` vertelt Aspose een label voor elk datapunt te renderen. Het instellen van `ShowPercentage` zorgt ervoor dat de labelinhoud het berekende aandeel van het geheel is—exact wat de **gegevenslabels toevoegen aan taartdiagram**‑vereiste vraagt.

### Stap 5: Plaats labels buiten de partities

```csharp
// Place the labels outside the pie slices for better readability.
chart.DataLabel.Position = ChartDataLabelPosition.OutSideEnd;
```

*Waarom?*  
Labels binnen de partitie kunnen krap worden, vooral bij kleine partities. `OutSideEnd` bootst de standaard “buiten”‑stijl na die je in de Word‑UI ziet, waardoor het diagram overzichtelijk blijft.

### Stap 6: Sla het bijgewerkte document op

```csharp
sourceDoc.Save("YOUR_DIRECTORY/FormattedPieChart.docx");
```

*Waarom?*  
Opslaan schrijft alle wijzigingen weg naar een nieuw bestand. Open `FormattedPieChart.docx` in Word en je ziet de percentages naast elke partitie.

#### Verwacht resultaat

Wanneer je `FormattedPieChart.docx` opent, zou het taart‑diagram er ongeveer zo uit moeten zien (denkbeeldige screenshot):

```
[ Pie chart with three slices ]
- Slice A – 45%
- Slice B – 30%
- Slice C – 25%
```

Alle percentages worden automatisch berekend uit de onderliggende gegevensreeks, en de labels staan net buiten elke partitie.

## Veelvoorkomende variaties & randgevallen

| Situatie | Wat aan te passen |
|-----------|-------------------|
| **Meerdere diagrammen** in hetzelfde document | Loop door `sourceDoc.GetChildNodes(NodeType.Shape, true)` en cast elk naar `Chart` voordat je dezelfde logica toepast. |
| **Staaf‑ of lijndiagram** waarbij je toch labels wilt | Gebruik `chart.DataLabel.ShowValue = true;` (of `ShowSeriesName`) in plaats van `ShowPercentage`. |
| **Aangepast getalformaat** (bijv. “45 %”) | Stel `chart.DataLabel.NumberFormat = "0%";` in vóór het opslaan. |
| **Grote datasets** die label‑overlapping veroorzaken | Overweeg `chart.DataLabel.ShowLeaderLines = true;` om verbindingslijnen te tekenen. |

> **Pro tip:** Als je veel documenten in één batch genereert, maak dan één `Aspose.Words.License`‑object aan bij het starten van de applicatie om de prestatie‑penalty van herhaaldelijk licentie‑laden te vermijden.

## Volledig werkend voorbeeld

Hier is het volledige programma, klaar om uitgevoerd te worden:

```csharp
using System;
using Aspose.Words;
using Aspose.Words.Drawing.Charts;

class Program
{
    static void Main()
    {
        // 1️⃣ Load the template document.
        Document sourceDoc = new Document("YOUR_DIRECTORY/ChartTemplate.docx");

        // 2️⃣ Retrieve the first chart shape.
        Chart chart = (Chart)sourceDoc.GetChild(NodeType.Shape, 0, true);

        // 3️⃣ Ensure we’re dealing with a Pie or Doughnut chart.
        if (chart.ChartType != ChartType.Pie && chart.ChartType != ChartType.Doughnut)
        {
            Console.WriteLine("The selected shape is not a Pie/Doughnut chart.");
            return;
        }

        // 4️⃣ Enable data labels and show percentages.
        chart.HasDataLabel = true;
        chart.DataLabel.ShowPercentage = true;

        // 5️⃣ Position the labels outside the slices.
        chart.DataLabel.Position = ChartDataLabelPosition.OutSideEnd;

        // 6️⃣ Save the modified document.
        sourceDoc.Save("YOUR_DIRECTORY/FormattedPieChart.docx");

        Console.WriteLine("Chart updated successfully – percentages now visible!");
    }
}
```

Kopieer de code, vervang `YOUR_DIRECTORY` door het daadwerkelijke pad op jouw machine, en voer het uit. Je krijgt binnen enkele seconden een Word‑bestand met een volledig gelabelde taartgrafiek.

## Wat volgt hierna?

- **Stijl de labels** – wijzig lettertype, kleur of voeg een achtergrond toe met `chart.DataLabel.Font`.  
- **Diagrammen vanuit nul maken** – verken `Chart chart = (Chart)sourceDoc.FirstSection.Body.AppendChild(new Shape(sourceDoc, ShapeType.Chart));` om diagrammen programmatisch te genereren.  
- **Meerdere diagrammen** combineren in één document voor dashboards, en vervolgens exporteren naar PDF met `sourceDoc.Save("Dashboard.pdf", SaveFormat.Pdf);`.
