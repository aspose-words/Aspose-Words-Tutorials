# Hoe maak je een donutgrafiek in een Word‑document met Java

Als je een **donutgrafiek maken** in een Word‑bestand moet **maken**, laat deze tutorial je een complete, kant‑klaar oplossing zien. Je ziet hoe je een **cirkeldiagram invoegen**, het omzet in een donut, de **cirkeldiagram roteren** voor betere balans, en de **cirkeldiagram formatteren** zodat het bij je branding past. Aan het einde heb je een professioneel Word‑document dat kan worden gebruikt in rapporten, dashboards of geautomatiseerde e‑mailbijlagen.

Het programmatic maken van een grafiek elimineert handmatige kopie‑plak stappen en garandeert consistente opmaak over tientallen gegenereerde documenten. Het voorbeeld maakt gebruik van de Aspose.Words for Java‑bibliotheek, die werkt met Java 8+ en geen Microsoft Office‑installatie vereist. Er zijn verder geen andere vereisten nodig, behalve een standaard JDK en je favoriete IDE.

## Vereisten

- Java Development Kit (JDK) 8 of nieuwer  
- Maven of Gradle voor afhankelijkheidsbeheer (de tutorial gebruikt Maven)  
- Aspose.Words for Java bibliotheek (gratis proeflicentie is voldoende voor testen)  

Voeg de Aspose.Words‑afhankelijkheid toe aan je `pom.xml`:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-words</artifactId>
    <version>24.9</version> <!-- Use the latest stable version -->
</dependency>
```

> **Pro tip:** Registreer je licentie met `License license = new License(); license.setLicense("Aspose.Words.lic");` voordat je een document maakt om evaluatiewatermerken te verwijderen.

## Maak een donutgrafiek in een Word‑document

De kernworkflow bestaat uit vijf logische stappen. Elke stap is ingekapseld in een eigen methode om de code schoon en herbruikbaar te houden.

```java
import com.aspose.words.*;
import com.aspose.words.drawing.*;

public class DoughnutChartDemo {

    public static void main(String[] args) throws Exception {
        // Step 1: create blank Word document
        Document doc = createBlankWordDocument();

        // Step 2: insert a pie chart (base for the doughnut)
        Chart chart = insertPieChart(doc, 400, 300);

        // Step 3: convert the pie chart into a doughnut and rotate it
        customizeChartAppearance(chart);

        // Step 4: apply additional formatting to the chart
        formatPieChart(chart);

        // Step 5: save the final document
        doc.save("output/DoughnutChartFormatted.docx");
        System.out.println("Document saved successfully.");
    }

    /** Step 1 – create blank Word document */
    private static Document createBlankWordDocument() {
        // Aspose.Words creates an empty document by default
        return new Document();
    }

    /** Step 2 – insert pie chart with given dimensions */
    private static Chart insertPieChart(Document doc, int width, int height) throws Exception {
        DocumentBuilder builder = new DocumentBuilder(doc);
        // ChartType.PIE creates a standard pie chart that we will later turn into a doughnut
        Chart chart = builder.insertChart(ChartType.PIE, width, height);
        // Populate the chart with sample data
        chart.getSeries().clear(); // Remove default series
        ChartSeries series = chart.getSeries().add("Sales", new String[]{"Q1", "Q2", "Q3", "Q4"},
                new double[]{15000, 23000, 18000, 27000});
        return chart;
    }

    /** Step 3 – rotate pie chart and make it a doughnut */
    private static void customizeChartAppearance(Chart chart) {
        // Explode the first slice for emphasis
        chart.getSeries().get(0).setExplode(20);
        // Convert the pie into a doughnut by setting a hole size (percentage of radius)
        chart.setHoleSize(30); // 30% hole creates a classic doughnut look
        // Rotate the chart so the largest slice starts at 45°
        chart.setRotationAngle(45);
    }

    /** Step 4 – additional formatting of the pie chart */
    private static void formatPieChart(Chart chart) {
        // Example: change the first slice color to a brand color
        chart.getSeries().get(0).getPoints().get(0).getFormat().setFillForegroundColor(Color.fromArgb(0xFF, 0x4A, 0x90));
        // Add a legend and position it at the bottom
        chart.setHasLegend(true);
        chart.getLegend().setPosition(LegendPosition.BOTTOM);
        // Set a title for the chart
        chart.setTitle("Quarterly Sales Distribution");
    }
}
```

### Wat de code doet

| Stap | Actie | Reden |
|------|--------|--------|
| **Maak leeg Word‑document** | `new Document()` | Begint met een leeg bestand zodat je elk element kunt beheersen. |
| **Voeg cirkeldiagram in** | `builder.insertChart(ChartType.PIE, …)` | Een cirkeldiagram is de basisvorm; Aspose levert alleen een donut door de gatgrootte aan te passen. |
| **Roteer cirkeldiagram** | `chart.setRotationAngle(45)` | Roteren plaatst het grootste segment op een beter leesbare positie. |
| **Formatteer cirkeldiagram** | `setExplode`, `setHoleSize`, kleur, legenda | Verbetert de visuele hiërarchie en voldoet aan de huisstijlrichtlijnen. |
| **Sla document op** | `doc.save("…/DoughnutChartFormatted.docx")` | Schrijft het uiteindelijke .docx‑bestand naar schijf, klaar voor distributie. |

## Voeg cirkeldiagram in vóór conversie naar donut

Aspose.Words biedt geen directe “insert doughnut chart”‑methode. In plaats daarvan **voeg je een cirkeldiagram in** en wijzig je vervolgens de eigenschappen. Deze twee‑stappenbenadering geeft je volledige controle over dataseries, segment‑explosie en gatgrootte. Als je elders een puur cirkeldiagram nodig hebt, laat dan simpelweg de `setHoleSize`‑aanroep weg.

## Roteer cirkeldiagram voor visueel evenwicht

De standaardoriëntatie start het eerste segment op de 12‑uur positie. In veel bedrijfsrapporten moet het belangrijkste segment op een meer natuurlijke hoek beginnen, bijvoorbeeld 45 graden. De `setRotationAngle(double angle)`‑methode accepteert graden en roteert de volledige grafiek zonder de gegevenswaarden te beïnvloeden.

## Formatteer cirkeldiagram en pas het uiterlijk aan

Naast het converteren naar een donut wil je vaak de **cirkeldiagram formatteren** elementen:

- **Explode** de eerste slice (`setExplode`) om aandacht te trekken.  
- **Kleur** elke slice met `getPoints().get(i).getFormat().setFillForegroundColor`.  
- **Legenda** positionering (`setHasLegend`, `setPosition`) helpt lezers de categorieën te interpreteren.  
- **Titel** (`setTitle`) geeft in één oogopslag context.

Al deze instellingen zijn optioneel; je kunt ze aanpassen om overeen te komen met je merkpalet of bedrijfs‑templates.

## Maak leeg Word‑document en sla het resultaat op

De `createBlankWordDocument`‑methode omvat de stap **maak leeg Word‑document**. Het geïsoleerd houden van deze logica maakt het eenvoudig om de methode opnieuw te gebruiken bij het genereren van meerdere rapporten in een batch‑proces. Na alle aanpassingen schrijft `doc.save` het bestand weg in het standaard Office Open XML‑formaat (`.docx`), dat kan worden geopend in Microsoft Word, LibreOffice of Google Docs zonder verlies van kwaliteit.

### Verwachte output

Wanneer je de `main`‑methode uitvoert, print de console:

```
Document saved successfully.
```

En het bestand `output/DoughnutChartFormatted.docx` bevat een enkele pagina met een donutgrafiek getiteld *Quarterly Sales Distribution*. De grafiek toont vier segmenten, waarbij het eerste segment geëxplodeerd is, gekleurd in de merkkleur, en geroteerd 45 graden.

## Veelvoorkomende variaties en randgevallen

| Situatie | Aanpassing |
|-----------|------------|
| **Meer dan één dataserie** | Voeg extra `ChartSeries`‑objecten toe aan `chart.getSeries()`. |
| **Andere grafiekgrootte** | Wijzig de `width`‑ en `height`‑argumenten in `insertPieChart`. |
| **Geen gat (puur cirkeldiagram)** | Laat `chart.setHoleSize(…)` weg of stel deze in op `0`. |
| **Grote documenten** | Gebruik `DocumentBuilder` om de grafiek in een specifieke sectie of bladwijzer in te voegen. |
| **Licentie niet ingesteld** | De bibliotheek draait in evaluatiemodus, waardoor een watermerk op de eerste pagina wordt toegevoegd. Registreer een licentie om dit te verwijderen. |

## Conclusie

Je weet nu hoe je een **donutgrafiek** in een Word‑document kunt **maken** met Java, van **maak leeg Word‑document** tot **voeg cirkeldiagram in**, **roteer cirkeldiagram**, en **formatteer cirkeldiagram** voor een gepolijst eindproduct. Het volledige, uitvoerbare voorbeeld kan in elk Java‑project worden geplaatst dat al gebruikmaakt van Aspose.Words.

Vervolgens kun je verkennen:

- Het automatiseren van de generatie van meerdere documenten in een lus voor batch‑rapportage  

Voel je vrij om te experimenteren met kleuren, segment‑explosies en legendes om aan te sluiten bij de visuele taal van je organisatie. Veel plezier met grafieken!
