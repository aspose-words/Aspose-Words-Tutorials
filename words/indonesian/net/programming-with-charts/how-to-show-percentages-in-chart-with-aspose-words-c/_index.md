# Cara Menampilkan Persentase dalam Diagram dengan Aspose.Words C#

Pernah bertanya-tanya **bagaimana cara menampilkan persentase dalam diagram** tanpa berurusan dengan interop Office yang rumit? Anda tidak sendirian—banyak pengembang mengalami hal yang sama ketika mereka membutuhkan cara cepat dan programatik untuk memberi label pada diagram pai atau donat. Kabar baiknya? Dengan Aspose.Words untuk .NET Anda dapat mengaktifkan label data tersebut hanya dengan beberapa baris kode.

Dalam tutorial ini kami juga akan membahas **add data labels to pie chart** dan **how to enable chart data labels** sehingga visualisasi Anda langsung menjadi lebih informatif. Pada akhir tutorial Anda akan memiliki dokumen Word siap‑pakai (`.docx`) yang menampilkan diagram pai yang rapi dengan persentase yang ditempatkan dengan rapi di luar setiap irisan.

## Prasyarat

- **Aspose.Words for .NET** (versi terbaru, misalnya 24.9) diinstal melalui NuGet.
- File **ChartTemplate.docx** yang sudah berisi diagram pai atau donat.  
  *(Jika Anda belum memilikinya, buat dokumen Word sederhana, sisipkan diagram pai, dan simpan sebagai `ChartTemplate.docx`.)*
- .NET 6.0 atau yang lebih baru dan IDE apa pun yang Anda sukai (Visual Studio, Rider, VS Code).

Tidak ada dependensi tambahan yang diperlukan—Aspose.Words menangani semuanya secara internal.

## Cara Menampilkan Persentase dalam Diagram – Langkah‑per‑Langkah

Di bawah ini kami membagi proses menjadi enam langkah jelas. Setiap langkah menyertakan kode C# yang tepat yang dapat Anda salin‑tempel, plus penjelasan singkat tentang **mengapa** kami melakukannya.

### Langkah 1: Muat Dokumen Sumber

```csharp
using Aspose.Words;
using Aspose.Words.Drawing.Charts;

// Load the .docx that already holds a chart.
Document sourceDoc = new Document("YOUR_DIRECTORY/ChartTemplate.docx");
```

*Mengapa?*  
`Document` adalah titik masuk untuk setiap manipulasi Word. Dengan memuat templat, kami memperoleh akses ke setiap node—bentuk, tabel, teks, dan tentu saja diagram yang akan kami modifikasi.

### Langkah 2: Ambil Bentuk Diagram Pertama

```csharp
// The chart lives inside a Shape node; retrieve it.
Chart chart = (Chart)sourceDoc.GetChild(NodeType.Shape, 0, true);
```

*Mengapa?*  
Aspose menyimpan diagram sebagai objek `Shape`. `GetChild` menelusuri pohon dokumen dan mengembalikan bentuk pertama yang ditemukan, yang dalam kasus kami adalah diagram pai yang ingin diedit.

### Langkah 3: Konfirmasi Tipe Diagram

```csharp
if (chart.ChartType == ChartType.Pie || chart.ChartType == ChartType.Doughnut)
{
    // Inside this block we’ll enable the data labels.
}
else
{
    throw new InvalidOperationException("The chart is not a Pie or Doughnut type.");
}
```

*Mengapa?*  
Label persentase hanya masuk akal untuk diagram melingkar. Pemeriksaan ini mencegah kami secara tidak sengaja menerapkan pengaturan pada, misalnya, diagram batang di mana `ShowPercentage` akan diabaikan.

### Langkah 4: Aktifkan Label Data dan Tampilkan Persentase

```csharp
// Turn on data labels for the chart.
chart.HasDataLabel = true;

// Show the percentage value for each slice.
chart.DataLabel.ShowPercentage = true;
```

*Mengapa?*  
`HasDataLabel` memberi tahu Aspose untuk menampilkan label untuk setiap titik data. Menetapkan `ShowPercentage` memastikan konten label adalah bagian yang dihitung dari keseluruhan—tepat seperti yang diminta oleh persyaratan **add data labels to pie chart**.

### Langkah 5: Posisi Label di Luar Irisan

```csharp
// Place the labels outside the pie slices for better readability.
chart.DataLabel.Position = ChartDataLabelPosition.OutSideEnd;
```

*Mengapa?*  
Label di dalam irisan dapat menjadi sempit, terutama ketika irisan kecil. `OutSideEnd` meniru gaya “luar” default yang Anda lihat di UI Word, menjaga diagram tetap bersih.

### Langkah 6: Simpan Dokumen yang Diperbarui

```csharp
sourceDoc.Save("YOUR_DIRECTORY/FormattedPieChart.docx");
```

*Mengapa?*  
Menyimpan menuliskan semua perubahan ke file baru. Buka `FormattedPieChart.docx` di Word dan Anda akan melihat persentase ditampilkan di samping setiap irisan.

#### Hasil yang Diharapkan

Saat Anda membuka `FormattedPieChart.docx`, diagram pai seharusnya terlihat mirip dengan ini (tangkapan layar imajiner):

```
[ Pie chart with three slices ]
- Slice A – 45%
- Slice B – 30%
- Slice C – 25%
```

Semua persentase dihitung secara otomatis dari seri data yang mendasarinya, dan label berada tepat di luar setiap irisan.

## Variasi Umum & Kasus Tepi

| Situasi | Apa yang Harus Disesuaikan |
|-----------|----------------|
| **Multiple charts** in the same document | Loop through `sourceDoc.GetChildNodes(NodeType.Shape, true)` and cast each to `Chart` before applying the same logic. |
| **Bar or line chart** where you still want labels | Use `chart.DataLabel.ShowValue = true;` (or `ShowSeriesName`) instead of `ShowPercentage`. |
| **Custom number format** (e.g., “45 %”) | Set `chart.DataLabel.NumberFormat = "0%";` before saving. |
| **Large data sets** causing label overlap | Consider `chart.DataLabel.ShowLeaderLines = true;` to draw connector lines. |

> **Pro tip:** Jika Anda menghasilkan banyak dokumen secara batch, buat satu objek `Aspose.Words.License` pada saat aplikasi dimulai untuk menghindari penurunan kinerja akibat memuat lisensi berulang kali.

## Contoh Lengkap yang Berfungsi

Berikut seluruh program yang digabungkan, siap dijalankan:

```csharp
using System;
using Aspose.Words;
using Aspose.Words.Drawing.Charts;

class Program
{
    static void Main()
    {
        // 1️⃣ Load the template document.
        Document sourceDoc = new Document("YOUR_DIRECTORY/ChartTemplate.docx");

        // 2️⃣ Retrieve the first chart shape.
        Chart chart = (Chart)sourceDoc.GetChild(NodeType.Shape, 0, true);

        // 3️⃣ Ensure we’re dealing with a Pie or Doughnut chart.
        if (chart.ChartType != ChartType.Pie && chart.ChartType != ChartType.Doughnut)
        {
            Console.WriteLine("The selected shape is not a Pie/Doughnut chart.");
            return;
        }

        // 4️⃣ Enable data labels and show percentages.
        chart.HasDataLabel = true;
        chart.DataLabel.ShowPercentage = true;

        // 5️⃣ Position the labels outside the slices.
        chart.DataLabel.Position = ChartDataLabelPosition.OutSideEnd;

        // 6️⃣ Save the modified document.
        sourceDoc.Save("YOUR_DIRECTORY/FormattedPieChart.docx");

        Console.WriteLine("Chart updated successfully – percentages now visible!");
    }
}
```

Salin kode, ganti `YOUR_DIRECTORY` dengan jalur sebenarnya di mesin Anda, dan jalankan. Anda akan memiliki file Word dengan diagram pai yang sepenuhnya berlabel dalam hitungan detik.

## Apa Selanjutnya?

- **Style the labels** – ubah font, warna, atau tambahkan latar belakang menggunakan `chart.DataLabel.Font`.  
- **Create charts from scratch** – jelajahi `Chart chart = (Chart)sourceDoc.FirstSection.Body.AppendChild(new Shape(sourceDoc, ShapeType.Chart));` untuk menghasilkan diagram secara programatik.  
- **Combine multiple charts** in a single document for dashboards, then export to PDF with `sourceDoc.Save("Dashboard.pdf", SaveFormat.Pdf);`.
