# Membuat dokumen Word kosong dan menyembunyikan bentuk elips di C#

Jika Anda perlu **membuat dokumen Word kosong** dan kemudian menyembunyikan elemen grafis, panduan ini menunjukkan secara tepat cara melakukannya dengan C#. Anda akan melihat contoh lengkap yang dapat dijalankan yang menyisipkan sebuah elips, menempatkannya, menandainya sebagai tersembunyi, dan menyimpan file—semua dalam beberapa baris kode.

Tutorial ini mencakup semua hal mulai dari penyiapan proyek hingga langkah verifikasi akhir. Pada akhirnya, Anda dapat menghasilkan file Word di mana elips tidak pernah muncul di layar atau saat dicetak, yang berguna untuk menyimpan metadata, bookmark, atau penanda tak terlihat apa pun.

## Prasyarat

Sebelum Anda memulai, pastikan Anda memiliki:

* .NET 6.0 SDK atau yang lebih baru terpasang  
* Lingkungan pengembangan C# (Visual Studio 2022, Rider, atau VS Code)  
* Paket NuGet **Aspose.Words for .NET** (`Install-Package Aspose.Words`)  

Alat‑alat ini menyediakan kelas `Document` dan `DocumentBuilder` yang digunakan dalam contoh kode.

## Langkah 1: Membuat dokumen Word kosong

Operasi pertama membuat objek `Document` kosong dan `DocumentBuilder` yang memungkinkan Anda menambahkan konten.

```csharp
using Aspose.Words;
using Aspose.Words.Drawing;

// Step 1: Initialize an empty document and a builder
Document doc = new Document();
DocumentBuilder builder = new DocumentBuilder(doc);
```

`Document` mewakili seluruh paket `.docx`, sementara `DocumentBuilder` menawarkan API yang fluently untuk menyisipkan teks, bentuk, dan objek lainnya. Memulai dengan dokumen kosong memberi Anda kontrol penuh atas setiap elemen yang Anda tambahkan.

## Langkah 2: Cara menyisipkan elips

Elips adalah bentuk vektor yang dapat digunakan sebagai penanda. Metode `InsertShape` memerlukan tipe bentuk serta lebar/tinggi dalam poin.

```csharp
// Step 2: Insert an ellipse shape of the desired size (100 pt × 50 pt)
Shape ellipse = builder.InsertShape(ShapeType.Ellipse, 100, 50);
```

Elips berada pada halaman saat ini di lokasi kursor. Anda dapat mengubah dimensinya dengan menyesuaikan argumen numerik.

## Langkah 3: Cara memposisikan bentuk

Setelah penyisipan, Anda dapat memindahkan bentuk ke mana saja di halaman dengan mengatur properti `Left` dan `Top`, yang menggunakan poin relatif terhadap margin halaman.

```csharp
// Step 3: Position the shape on the page
ellipse.Left = 150; // distance from the left margin
ellipse.Top  = 100; // distance from the top margin
```

Koordinat ini menempatkan elips kira‑kira di bagian tengah‑atas halaman A4 standar. Sesuaikan nilai‑nilai tersebut agar cocok dengan kebutuhan tata letak Anda.

## Langkah 4: Cara menyembunyikan bentuk

Objek tersembunyi tidak ditampilkan ketika dokumen dibuka atau dicetak. Menetapkan flag `Hidden` menandai bentuk sebagai **hidden object word**.

```csharp
// Step 4: Hide the shape so it never appears
ellipse.Hidden = true;
```

Word menghormati flag tersembunyi baik untuk rendering di layar maupun output cetak. Bentuk tetap menjadi bagian dari struktur dokumen, memungkinkan Anda untuk menanyakan atau memodifikasinya nanti melalui kode.

## Langkah 5: Menyimpan dokumen

Akhirnya, tulis dokumen ke disk. Pilih folder yang Anda miliki hak menulis.

```csharp
// Step 5: Save the document to a .docx file
doc.Save(@"C:\Temp\HiddenEllipse.docx");
```

File `HiddenEllipse.docx` kini berisi halaman kosong dengan bentuk elips tersembunyi.

## Memverifikasi elips tersembunyi

Buka file yang dihasilkan di Microsoft Word dan aktifkan opsi **Show hidden text** (File → Options → Display). Anda akan melihat garis tipis elips. Jika Anda mematikan opsi tersebut, bentuk menghilang sepenuhnya, mengonfirmasi bahwa `ellipse.Hidden = true` berfungsi seperti yang diharapkan.

## Variasi umum dan kasus tepi

| Situasi | Penyesuaian yang disarankan |
|-----------|------------------------|
| **Bentuk berbeda** | Ganti `ShapeType.Ellipse` dengan `ShapeType.Rectangle`, `ShapeType.Arrow`, dll. |
| **Beberapa objek tersembunyi** | Ulangi langkah 2‑4 untuk setiap bentuk; masing‑masing dapat memiliki flag `Hidden` sendiri. |
| **Ukuran halaman berbeda** | Setel `doc.FirstSection.PageSetup.PageWidth` dan `PageHeight` sebelum menyisipkan bentuk. |
| **Visibilitas bersyarat** | Gunakan `Shape.Visible` bersama dengan `Hidden` untuk mengubah tampilan pada runtime melalui kode. |

**Pro tip:** Simpan data identifikasi di properti `AlternativeText` bentuk. Bahkan ketika tersembunyi, Anda dapat mengambil bentuk tersebut nanti dengan `doc.GetChildNodes(NodeType.Shape, true)` dan menyaringnya berdasarkan teks itu.

## Kode sumber lengkap

Berikut adalah program lengkap yang dapat Anda salin, tempel, dan jalankan.

```csharp
using System;
using Aspose.Words;
using Aspose.Words.Drawing;

namespace HiddenShapeDemo
{
    class Program
    {
        static void Main()
        {
            // Create a new blank document and a builder
            Document doc = new Document();
            DocumentBuilder builder = new DocumentBuilder(doc);

            // Insert an ellipse shape (100 pt × 50 pt)
            Shape ellipse = builder.InsertShape(ShapeType.Ellipse, 100, 50);

            // Position the shape on the page
            ellipse.Left = 150;
            ellipse.Top  = 100;

            // Hide the shape so it is invisible in the UI and on print
            ellipse.Hidden = true;

            // Optional: add a description for later retrieval
            ellipse.AlternativeText = "Hidden marker for internal processing";

            // Save the document
            string outputPath = @"C:\Temp\HiddenEllipse.docx";
            doc.Save(outputPath);

            Console.WriteLine($"Document saved to {outputPath}");
        }
    }
}
```

**Output yang diharapkan:** Konsol mencetak jalur penyimpanan, dan file `HiddenEllipse.docx` terbuka sebagai halaman kosong tanpa grafik yang terlihat kecuali objek tersembunyi ditampilkan.

Anda kini tahu cara **membuat dokumen Word kosong** secara programatis, **cara menyisipkan elips**, **cara memposisikan bentuk**, dan **cara menyembunyikan bentuk** sehingga berperilaku sebagai **hidden object word**. Teknik ini ideal untuk menyematkan penanda tak terlihat, metadata khusus, atau placeholder yang dapat dibaca proses hilir tanpa memengaruhi tata letak visual dokumen.

Silakan bereksperimen dengan koordinat, dimensi, dan flag tersembunyi untuk menyesuaikannya dengan skenario spesifik Anda. Selamat coding!
