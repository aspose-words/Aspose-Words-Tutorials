//ExSummary: Tutorial ini menunjukkan cara secara otomatis menambahkan watermark teks diagonal merah ke setiap dokumen Word baru yang dihasilkan dalam proses laporan batch menggunakan Aspose.Words Document dan DocumentBuilder.
//ExStepSummary:0: Buat folder "GeneratedReports" tempat file output akan disimpan.
//ExStepSummary:1: Mulai loop yang akan menghasilkan tiga dokumen terpisah.
//ExStepSummary:2: Buat objek dokumen Word kosong baru.
//ExStepSummary:3: Gunakan DocumentBuilder untuk menulis baris judul dan deskripsi ke dalam dokumen.
//ExStepSummary:4: Tentukan tampilan watermark, termasuk font, ukuran, warna, dan tata letak diagonal.
//ExStepSummary:5: Terapkan watermark diagonal merah yang telah dikonfigurasi dengan teks "PROTECTED" ke dokumen.
//ExStepSummary:6: Simpan dokumen yang telah diberi watermark ke folder "GeneratedReports" dengan nama file unik.
//ExStepSummary:7: Tutup loop setelah memproses dokumen saat ini.
//ExStepImage:3:images/1.png
//ExStepImage:5:images/2.png
//ExStep:0-
// Prepare a directory where the created files will be placed.
string reportsDir = Path.Combine(Directory.GetCurrentDirectory(), "GeneratedReports");
Directory.CreateDirectory(reportsDir);

//ExStep:1-
// Emulate the production of a few documents.
for (int index = 1; index <= 3; index++)
{

//ExStep:2-
// Instantiate a fresh, empty document.
Document document = new Document();

//ExStep:3-
// Insert some placeholder text.
DocumentBuilder docBuilder = new DocumentBuilder(document);
docBuilder.Writeln($"Document #{index}");
docBuilder.Writeln("This document was produced automatically.");

//ExStep:4-
// Configure how the watermark should look.
TextWatermarkOptions wmOptions = new TextWatermarkOptions
{
    FontFamily = "Arial",
    FontSize = 48,
    Color = Color.Red,
    Layout = WatermarkLayout.Diagonal,
    IsSemitrasparent = false
};

//ExStep:5-
// Add the text watermark to the document.
document.Watermark.SetText("PROTECTED", wmOptions);

//ExStep:6-
// Persist the file to disk.
string outputPath = Path.Combine(reportsDir, $"Summary_{index}.docx");
document.Save(outputPath);

//ExStep:7-
}
