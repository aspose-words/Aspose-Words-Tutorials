# Buat templat faktur dan gabungkan data menggunakan Aspose.Words

Jika Anda perlu **membuat templat faktur** dengan cepat, panduan ini menunjukkan secara tepat caranya. Pada akhir dua kalimat pertama Anda akan mengetahui alur kerja lengkap untuk mengubah file Word kosong menjadi faktur yang terisi penuh, menggunakan API mail‑merge low‑code Aspose.Words.

Membuat faktur adalah kebutuhan umum untuk sistem penagihan, integrasi ERP, dan pelaporan otomatis. Dalam tutorial ini Anda akan belajar **cara melakukan mail merge**, **mengisi templat Word**, **menggabungkan data ke dalam Word**, dan akhirnya **menyimpan dokumen yang telah digabung**—semua dengan beberapa baris kode C#.

## Apa yang akan Anda capai

* Sebuah templat Word yang dapat dipakai kembali (`InvoiceTemplate.docx`) yang berisi field merge untuk pelanggan, tanggal, item baris, dan total.  
* Program C# yang memuat templat, menyuntikkan objek data bertipe kuat, dan menulis hasilnya ke `Invoice_001.docx`.  
* Pemahaman tentang kasus tepi seperti koleksi kosong, tipe data khusus, dan penanganan jalur file.

### Prasyarat

| Requirement | Why it matters |
|-------------|----------------|
| .NET 6 atau lebih baru | Aspose.Words untuk .NET mendukung .NET 6+ dan menyediakan API low‑code yang digunakan dalam panduan ini. |
| Paket NuGet Aspose.Words untuk .NET (`Aspose.Words`) | Menyediakan `Document`, `MailMerger`, dan tipe terkait lainnya. |
| Pengetahuan dasar C# | Diperlukan untuk memahami objek anonim dan LINQ. |
| Visual Studio 2022 (atau IDE apa pun) | Memudahkan pengeditan dan debugging. |

> **Pro tip:** Instal paket NuGet melalui Package Manager Console:  
> `Install-Package Aspose.Words`

## Cara membuat templat faktur dengan mail merge low‑code

Langkah pertama adalah membuat file Word yang berisi field merge yang cocok dengan properti objek data yang akan Anda berikan nanti. Simpan file tersebut sebagai `InvoiceTemplate.docx` di folder yang Anda kontrol (misalnya, `C:\Invoices\Template`).

| Merge field | Contoh placeholder di Word |
|-------------|-----------------------------|
| CustomerName | «CustomerName» |
| InvoiceDate | «InvoiceDate» |
| Items (repeating) | «Items.Description», «Items.Qty», «Items.Price» |
| Total | «Total» |

> **Mengapa ini penting:** API low‑code secara otomatis memetakan nama properti sumber data ke field merge. Menjaga nama tetap identik menghilangkan pemetaan manual field‑ke‑properti dan mengurangi kesalahan saat runtime.

## Langkah 1: Muat templat faktur

```csharp
using Aspose.Words;
using Aspose.Words.LowCode;   // Low‑code mail‑merge API

// Load the Word file that contains the merge fields.
Document template = new Document(@"C:\Invoices\Template\InvoiceTemplate.docx");
```

*Kelas `Document` mewakili seluruh file Word. Memuatnya sekali memungkinkan Anda menggunakan kembali templat yang sama untuk banyak faktur.*

## Langkah 2: Siapkan sumber data

Buat objek anonim yang mencerminkan field merge. API low‑code dapat bekerja dengan objek .NET apa pun, termasuk array dan koleksi bersarang.

```csharp
var invoiceData = new
{
    CustomerName = "Acme Corp",
    InvoiceDate = DateTime.Today,
    Items = new[]
    {
        new { Description = "Widget A", Qty = 10, Price = 9.99M },
        new { Description = "Widget B", Qty = 5,  Price = 19.95M }
    },
    Total = 199.85M
};
```

**Mengapa ini berhasil:**  
* Nama properti (`CustomerName`, `InvoiceDate`, `Items`, `Total`) cocok dengan field merge di templat.  
* `Items` adalah array objek, sehingga mail merger akan mengulang baris tabel untuk setiap elemen secara otomatis.  
* Menggunakan `decimal` (`M` suffix) untuk nilai moneter menghindari masalah pembulatan floating‑point.

### Menangani koleksi kosong

Jika sebuah faktur tidak memiliki item baris, kirimkan array kosong:

```csharp
Items = new object[0]
```

Mesin low‑code akan secara otomatis menghilangkan bagian yang berulang, meninggalkan header tabel tetap ada.

## Langkah 3: Inisialisasi mail merger low‑code

```csharp
MailMerger merger = new MailMerger(template);
```

`MailMerger` adalah titik masuk untuk **cara melakukan mail merge** dengan Aspose.Words. Ia membaca templat, mengikat data, dan menyiapkan dokumen akhir dalam satu panggilan.

## Langkah 4: Jalankan merge – isi templat Word dalam satu baris

```csharp
Document mergedDocument = merger.Execute(invoiceData);
```

* Baris ini **mengisi templat Word** dan menghasilkan instance `Document` baru (`mergedDocument`).  
* Semua field merge digantikan, bagian yang berulang diperluas, dan dokumen hasil berada sepenuhnya di memori.

### Kasus tepi: Pemformatan khusus

Jika Anda memerlukan format tanggal tertentu, tambahkan formatter khusus sebelum merge:

```csharp
merger.Options.DateFormat = "MMMM dd, yyyy"; // e.g., "October 07, 2026"
```

## Langkah 5: Simpan dokumen yang telah digabung

```csharp
mergedDocument.Save(@"C:\Invoices\Output\Invoice_001.docx");
```

Pemanggilan **save merged document** menulis faktur yang terisi penuh ke disk. File tersebut kini dapat dibuka di Microsoft Word, dikirim sebagai lampiran email, atau dikonversi ke PDF.

### Memverifikasi output

Buka `Invoice_001.docx`. Anda harus melihat:

* **CustomerName** diganti dengan *Acme Corp*  
* **InvoiceDate** menampilkan tanggal hari ini dalam format yang dipilih  
* Sebuah baris tabel untuk *Widget A* (10 × 9.99) dan *Widget B* (5 × 19.95)  
* **Total** menampilkan *199.85*  

Jika ada field yang tetap tidak berubah (misalnya masih menampilkan «CustomerName»), periksa kembali bahwa nama properti persis sama dengan nama field merge di templat.

## Contoh lengkap yang dapat dijalankan

Berikut adalah program lengkap yang dapat Anda salin‑tempel ke proyek konsol baru.

```csharp
using System;
using Aspose.Words;
using Aspose.Words.LowCode;   // Low‑code mail‑merge API

namespace InvoiceGenerator
{
    class Program
    {
        static void Main()
        {
            // 1️⃣ Load the template
            Document template = new Document(@"C:\Invoices\Template\InvoiceTemplate.docx");

            // 2️⃣ Build the data source
            var invoiceData = new
            {
                CustomerName = "Acme Corp",
                InvoiceDate = DateTime.Today,
                Items = new[]
                {
                    new { Description = "Widget A", Qty = 10, Price = 9.99M },
                    new { Description = "Widget B", Qty = 5,  Price = 19.95M }
                },
                Total = 199.85M
            };

            // 3️⃣ Initialise the mail merger
            MailMerger merger = new MailMerger(template);

            // Optional: customise date format
            merger.Options.DateFormat = "MMMM dd, yyyy";

            // 4️⃣ Perform the merge (populate word template)
            Document mergedDocument = merger.Execute(invoiceData);

            // 5️⃣ Save the resulting file (save merged document)
            mergedDocument.Save(@"C:\Invoices\Output\Invoice_001.docx");

            Console.WriteLine("Invoice generated successfully.");
        }
    }
}
```

Jalankan program (`dotnet run`). Konsol akan mencetak *Invoice generated successfully.* dan file akan muncul di `C:\Invoices\Output`.
