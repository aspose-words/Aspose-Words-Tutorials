# Cara merangkum dokumen Word dengan penyedia AI di C#

Jika Anda perlu **merangkum dokumen Word** dengan cepat, panduan ini menunjukkan secara tepat cara melakukannya. Anda akan melihat contoh lengkap yang dapat dijalankan yang memungkinkan Anda **memilih penyedia AI** (OpenAI atau Google) dan menangani skenario **merangkum dokumen besar** tanpa meninggalkan IDE Anda.

Merangkum dokumen Word adalah tugas umum saat membangun bot basis pengetahuan, ringkasan laporan, atau ringkasan email otomatis. Pada bagian di bawah ini Anda akan mempelajari paket NuGet mana yang harus diinstal, cara memuat file `.docx`, mengonfigurasi summarizer, dan menghasilkan hasilnya—semua dalam C# biasa.

## Apa yang Anda butuhkan

| Persyaratan | Alasan |
|-------------|--------|
| .NET 6 SDK or later | Menyediakan runtime untuk contoh C# |
| Visual Studio 2022 (or any IDE) | Memudahkan penambahan paket NuGet dan menjalankan aplikasi console |
| `GroupDocs.Summarization` NuGet package | Menyediakan API `DocumentSummarizer` yang digunakan dalam kode |
| An internet connection | Diperlukan bagi penyedia AI (OpenAI atau Google) untuk memproses teks |

> **Tips pro:** Jika Anda berencana untuk **merangkum dokumen besar** (lebih dari 100 KB), aktifkan mode streaming dalam opsi untuk menghindari memuat seluruh file ke memori.

## Cara merangkum dokumen Word langkah demi langkah

### Langkah 1: Instal perpustakaan summarization

Buka Package Manager Console dan jalankan:

```powershell
Install-Package GroupDocs.Summarization
```

Perpustakaan `GroupDocs.Summarization` mengabstraksi panggilan AI yang mendasarinya, sehingga Anda dapat mengganti penyedia tanpa mengubah logika bisnis Anda.

### Langkah 2: Muat dokumen Word

```csharp
using GroupDocs.Summarization;
using GroupDocs.Summarization.Options;

// Step 2: Load the source document
Document doc = new Document("YOUR_DIRECTORY/Report.docx");
```

Kelas `Document` membaca file `.docx` dan menyiapkannya untuk diringkas. Jika file besar, perpustakaan secara otomatis menggunakan parser yang efisien memori.

### Langkah 3: Konfigurasikan opsi summarizer dan **pilih penyedia AI**

```csharp
// Step 3: Set up summarization options (choose the AI provider)
SummarizerOptions options = new SummarizerOptions
{
    Provider = SummarizerProvider.OpenAI   // or SummarizerProvider.Google
};
```

- `Provider = SummarizerProvider.OpenAI` memilih model GPT‑4 milik OpenAI.  
- `Provider = SummarizerProvider.Google` memilih model Gemini milik Google, yang ideal ketika Anda **merangkum dengan Google** untuk dukungan multibahasa yang lebih baik.

Anda **memilih penyedia AI** berdasarkan biaya, latensi, atau kebutuhan bahasa. Objek `options` yang sama bekerja untuk kedua penyedia, menjaga kode Anda tetap bersih.

### Langkah 4: Hasilkan ringkasan – dukungan **merangkum dokumen besar**

```csharp
// Step 4: Generate the summary using the selected provider
string summary = DocumentSummarizer.Summarize(doc, options);
```

Saat Anda **merangkum dokumen besar**, perpustakaan mengalirkan konten ke layanan AI, mencegah kesalahan kehabisan memori. Metode `Summarize` mengembalikan string teks biasa yang berisi kalimat paling relevan.

### Langkah 5: Tampilkan hasil

```csharp
// Step 5: Output the generated summary
Console.WriteLine("Summary:\n" + summary);
```

Menjalankan program mencetak paragraf singkat yang menangkap esensi file Word asli.

## Contoh lengkap yang dapat dijalankan

```csharp
using System;
using GroupDocs.Summarization;
using GroupDocs.Summarization.Options;

namespace WordSummarizerDemo
{
    class Program
    {
        static void Main(string[] args)
        {
            // Load the source Word document
            Document doc = new Document("YOUR_DIRECTORY/Report.docx");

            // Choose the AI provider (OpenAI or Google)
            SummarizerOptions options = new SummarizerOptions
            {
                Provider = SummarizerProvider.Google   // Change to OpenAI if you prefer
            };

            // Generate the summary – works for both small and large documents
            string summary = DocumentSummarizer.Summarize(doc, options);

            // Display the summary in the console
            Console.WriteLine("Summary:\n" + summary);
        }
    }
}
```

**Output yang diharapkan**

```
Summary:
The quarterly sales increased by 12% driven by the new product line, while operational costs fell 3% due to efficiency gains. The report also highlights upcoming market expansion in APAC and recommends allocating additional budget to R&D.
```

Kata-kata tepatnya akan berbeda tergantung pada model AI yang Anda **pilih penyedia AI**, tetapi struktur tetap sama.

## Menangani skenario **merangkum dokumen besar**

Ketika sumber `.docx` melebihi 5 MB, pertimbangkan penyesuaian berikut:

1. **Aktifkan chunking** – perpustakaan membagi dokumen menjadi blok 5 KB sebelum mengirimnya ke layanan AI.
2. **Tingkatkan `MaxSentences`** dalam `SummarizerOptions` jika Anda membutuhkan ringkasan yang lebih panjang.
3. **Setel `Timeout`** ke nilai yang lebih tinggi untuk mengakomodasi waktu pemrosesan yang lebih lama.

```csharp
options.MaxSentences = 8;          // Return up to 8 sentences
options.EnableChunking = true;    // Essential for very large files
options.Timeout = TimeSpan.FromMinutes(2);
```

Penyesuaian ini memastikan operasi **merangkum dokumen besar** tetap cepat dan dapat diandalkan.

## Cara **merangkum dengan Google** secara efektif

Model Gemini milik Google unggul dalam konten multibahasa dan frasa yang ringkas. Untuk mendapatkan hasil terbaik:

- **Tentukan bahasa** (opsional) jika dokumen berisi teks non‑Inggris:
  ```csharp
  options.Language = "es"; // Spanish
  ```
- **Sesuaikan temperature** untuk mengontrol kreativitas:
  ```csharp
  options.Temperature = 0.3; // More deterministic output
  ```

Saat Anda **merangkum dengan Google**, layanan mungkin mengembalikan ringkasan yang sedikit lebih pendek namun sangat terfokus dibandingkan OpenAI. Uji kedua penyedia pada dokumen contoh untuk memutuskan mana yang cocok untuk produk Anda.

## Kesalahan umum dan cara menghindarinya

| Gejala | Penyebab | Solusi |
|---------|-------|-----|
| Ringkasan kosong | Kunci penyedia hilang atau jaringan terblokir | Verifikasi kunci API dalam variabel lingkungan dan pastikan HTTPS keluar diizinkan |
| Teks terpotong | Dokumen melebihi batas token penyedia | Aktifkan `EnableChunking` atau tingkatkan `MaxTokens` jika perpustakaan mendukungnya |
| Bahasa tidak terduga | Opsi `Language` salah | Hapus opsi tersebut atau atur ke bahasa sebenarnya dari dokumen |

Menangani masalah ini lebih awal menghemat waktu debugging, terutama ketika Anda **memilih penyedia AI** untuk beban kerja produksi.

## Kesimpulan

Anda sekarang tahu cara **merangkum dokumen Word** di C# menggunakan lapisan AI yang fleksibel. Dengan mengonfigurasi `SummarizerOptions`, Anda dapat **memilih penyedia AI**, menangani beban kerja **merangkum dokumen besar**, dan bahkan **merangkum dengan Google** untuk kebutuhan multibahasa. Bereksperimenlah dengan `MaxSentences`, `Temperature`, dan pengaturan chunking untuk menyempurnakan output sesuai skenario spesifik Anda.

### Langkah selanjutnya

- Jelajahi fitur lanjutan `DocumentSummarizer` seperti ekstraksi kata kunci.  
- Gabungkan summarization dengan **penerjemahan dokumen** untuk membuat ringkasan multibahasa.  
- Integrasikan ringkasan ke dalam API web sehingga layanan lain dapat meminta ringkasan sesuai permintaan.
