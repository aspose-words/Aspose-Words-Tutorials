# Cara mengonversi docx ke markdown dengan gambar dalam subfolder

Jika Anda perlu **mengonversi docx ke markdown** sambil menjaga setiap gambar yang disematkan tetap teratur, Anda berada di tempat yang tepat. Banyak pengembang menghasilkan laporan, manual, atau draf blog secara programatis dan berakhir dengan campuran berkas gambar yang berantakan tersebar di direktori output. Tutorial ini menunjukkan pendekatan bersih berbasis callback menggunakan Aspose.Words untuk .NET yang mengekspor dokumen ke markdown, menyimpan setiap gambar di folder *md‑resources* khusus, dan menyimpan berkas markdown akhir siap dipublikasikan.

> **Sekilas cepat:**  
> • Siapkan `MarkdownSaveOptions`  
> • Implementasikan `IResourceSavingCallback` untuk mengarahkan gambar  
> • Panggil `Document.Save` dengan opsi yang telah dikonfigurasi  

Setelah Anda memahami mengapa callback lebih disukai daripada pemrosesan pasca‑proses, mari selami solusi langkah‑demi‑langkah.

## Jawaban cepat
- **Apa yang sebenarnya dilakukan “convert docx to markdown”?** Itu mengubah markup pengolah kata menjadi markdown teks biasa sambil mempertahankan heading, daftar, tabel, dan referensi gambar.  
- **Perpustakaan mana yang menangani konversi?** Aspose.Words untuk .NET menyediakan API yang sepenuhnya dikelola, sisi‑server yang berfungsi tanpa Microsoft Word terpasang.  
- **Apakah saya harus menulis kode pemrosesan gambar?** Tidak; `IResourceSavingCallback` menangani penyimpanan setiap gambar ke folder yang Anda tentukan.  
- **Bisakah saya mengubah nama folder output?** Tentu – ganti `"md-resources/"` dengan jalur relatif atau absolut apa pun yang Anda inginkan.  
- **Apakah solusi ini kompatibel dengan .NET 6 dan yang lebih baru?** Ya, berjalan pada .NET 6+, .NET 5, .NET Core 3.1, dan .NET Framework 4.7+.

## Apa itu convert docx to markdown?
**Convert docx to markdown** adalah proses mengambil dokumen Microsoft Word (DOCX) dan menghasilkan berkas markdown (`.md`) yang mewakili konten yang sama menggunakan sintaks markdown. Konversi ini mempertahankan elemen struktural dan secara opsional mengekstrak sumber daya yang disematkan seperti gambar.

Konversi dilakukan oleh Aspose.Words, sebuah perpustakaan yang mendukung **35+ format input dan output**—termasuk DOCX, PDF, HTML, dan Markdown—memungkinkan Anda menangani dokumen ratusan halaman tanpa memuat seluruh berkas ke memori.

## Bagaimana cara mengonversi docx ke markdown? 

Muat dokumen sumber Anda dengan `new Document("source.docx")`, konfigurasikan `MarkdownSaveOptions` untuk menggunakan callback yang menulis setiap gambar ke `md-resources/`, lalu panggil `doc.Save("output.md", saveOptions)`. Pola tiga langkah ini mengonversi berkas, mengekstrak gambar, dan menghasilkan berkas markdown bersih dengan tautan gambar relatif—semua dalam satu pemanggilan metode.

### Langkah 1: konfigurasikan opsi penyimpanan untuk konversi markdown

MarkdownSaveOptions mengatur cara Aspose.Words mengonversi dokumen ke Markdown.

```csharp
// Step 1: Initialize Markdown save options
var markdownSaveOptions = new Aspose.Words.Saving.MarkdownSaveOptions();
```

```csharp
// Step 1: Initialize Markdown save options
var markdownSaveOptions = new Aspose.Words.Saving.MarkdownSaveOptions();
```

> **Mengapa ini penting:**  
> Tanpa secara eksplisit membuat `MarkdownSaveOptions`, perpustakaan akan kembali ke pengaturan default yang menyematkan gambar langsung ke berkas Markdown sebagai string Base64. Hal itu membuat berkas menjadi sangat besar dan menghilangkan tujuan memiliki folder *images* yang bersih.

### Langkah 2: definisikan callback penyimpanan sumber daya untuk mengekspor gambar

`IResourceSavingCallback` memungkinkan Anda mengontrol di mana setiap sumber daya (gambar, SVG) disimpan selama ekspor.

Sekarang kita memberi tahu penyimpan **di mana** menempatkan setiap gambar. Antarmuka `IResourceSavingCallback` memberi kami hook yang dipicu untuk setiap sumber daya (gambar, SVG, dll.) yang ditemukan selama ekspor. Di dalam callback kami:

1. Pastikan folder target ada (`md-resources/`).  
2. Atur `OutputFileName` ke folder ditambah nama sumber daya asli.  

```csharp
// Step 2: Hook into the resource‑saving pipeline
markdownSaveOptions.ResourceSavingCallback = new Aspose.Words.Saving.IResourceSavingCallback(
    (args) =>
    {
        // All images will be placed in "md-resources" relative to the output .md file
        const string folder = "md-resources/";
        Directory.CreateDirectory(folder);          // Create folder if it doesn’t exist

        // Preserve the original file name (e.g., image001.png) but prepend the folder path
        args.OutputFileName = Path.Combine(folder, args.ResourceFileName);

        // Optional: you could also change the format here (e.g., convert BMP to PNG)
        // args.ResourceFileName = Path.ChangeExtension(args.ResourceFileName, ".png");
    });
```

> **Pertanyaan umum:** *Bagaimana jika saya ingin menyematkan gambar alih-alih menyimpannya?*  
> Cukup lewati callback atau set `args.OutputFileName = null;` – penyimpan akan menyematkan gambar sebagai string Base64 secara otomatis.

> **Kasus tepi:** Beberapa dokumen lama berisi nama gambar duplikat. Callback di atas akan menimpa berkas sebelumnya. Untuk menghindarinya, Anda dapat menambahkan GUID:

```csharp
args.OutputFileName = Path.Combine(folder,
    $"{Path.GetFileNameWithoutExtension(args.ResourceFileName)}_{Guid.NewGuid()}{Path.GetExtension(args.ResourceFileName)}");
```

### Langkah 3: simpan dokumen sebagai markdown dan verifikasi output

Dengan opsi yang sudah sepenuhnya dikonfigurasi, pemanggilan akhir cukup satu baris yang menulis berkas Markdown dan gambar terkait ke disk.

```csharp
// Step 3: Perform the actual export
string outputPath = @"C:\Exports\MyReport.md";
doc.Save(outputPath, markdownSaveOptions);
```

Jika semuanya berjalan lancar Anda akan melihat:

- `MyReport.md` – representasi Markdown dari dokumen sumber Anda.  
- `md-resources/` – folder di samping berkas `.md` yang berisi setiap gambar yang diekstrak (misalnya, `image001.png`, `image002.jpg`).  

**Potongan markdown contoh** (dihasilkan otomatis oleh Aspose.Words):

```markdown
# Sample Report

Here is an introductory paragraph.

![Sample image](md-resources/image001.png)

More text follows...
```

[Sample image](md-resources/image001.png)

> **Tips pro:** Buka berkas `.md` yang dihasilkan di VS Code atau pratinjau Markdown apa pun; gambar akan langsung ditampilkan karena jalur relatif cocok dengan struktur folder.

## Contoh lengkap yang dapat dijalankan (tanpa blok kode tambahan)

Berikut adalah program konsol mandiri yang dapat Anda tempel ke proyek .NET baru dan jalankan. Program ini membuat dokumen Word sederhana, menambahkan gambar, lalu **membuat markdown dari dokumen** sambil menyimpan gambar di subfolder.

```csharp
using System;
using System.IO;
using Aspose.Words;
using Aspose.Words.Saving;

class Program
{
    static void Main()
    {
        // 1️⃣ Create a sample Word document with an image
        var doc = new Document();
        var builder = new DocumentBuilder(doc);
        builder.Writeln("Hello, this is a test document.");
        builder.InsertImage("sample-image.png"); // Ensure this file exists next to exe

        // 2️⃣ Configure markdown export options (see Step 1 & 2 above)
        var markdownOptions = new MarkdownSaveOptions();
        markdownOptions.ResourceSavingCallback = new IResourceSavingCallback(
            (args) =>
            {
                const string folder = "md-resources/";
                Directory.CreateDirectory(folder);
                args.OutputFileName = Path.Combine(folder, args.ResourceFileName);
            });

        // 3️⃣ Save as markdown (Step 3)
        string outputFolder = Path.Combine(Environment.CurrentDirectory, "output");
        Directory.CreateDirectory(outputFolder);
        string markdownPath = Path.Combine(outputFolder, "ExportedDoc.md");
        doc.Save(markdownPath, markdownOptions);

        Console.WriteLine($"✅ Markdown saved to: {markdownPath}");
        Console.WriteLine("📂 Images saved in: md-resources/");
    }
}
```

**Apa yang akan Anda lihat** setelah menjalankan:

```
✅ Markdown saved to: C:\MyProject\output\ExportedDoc.md
📂 Images saved in: md-resources/
```

Buka `ExportedDoc.md` – referensi gambar akan mengarah ke `md-resources/sample-image.png`, dan gambar akan ditampilkan dengan benar di penampil Markdown apa pun.

## Variasi yang sering ditanyakan

| Skenario | Cara menyesuaikan kode |
|----------|------------------------|
| **Lewati ekspor gambar** (sematkan sebagai Base64) | Hapus `ResourceSavingCallback` sepenuhnya, atau set `args.OutputFileName = null;` di dalam callback. |
| **Ubah format gambar** (mis., semua PNG) | Di dalam callback, ubah `args.ResourceFileName` dan opsional konversi aliran sebelum menulis. |
| **Nama folder khusus** | Ganti `"md-resources/"` dengan jalur relatif atau absolut apa pun yang Anda inginkan. |
| **Beberapa dokumen dalam batch** | Loop melalui koleksi objek `Document`, gunakan kembali instance `MarkdownSaveOptions` yang sama (pastikan folder dibersihkan atau diberi nama unik per proses). |

## Masalah umum dan solusinya

- **Gambar tidak muncul di pratinjau markdown** – Pastikan jalur relatif di markdown (`md-resources/image001.png`) cocok dengan lokasi folder sebenarnya relatif terhadap berkas `.md`.  
- **Nama gambar duplikat menyebabkan timbulnya timpa** – Tambahkan pengidentifikasi unik (GUID atau penghitung inkremental) di dalam callback untuk menjamin nama berkas yang berbeda.  
- **Dokumen besar menyebabkan tekanan memori** – Gunakan `Document.OptimizeResources()` sebelum menyimpan; ini mengurangi konsumsi memori dengan membuang aliran yang tidak terpakai.  
- **Format gambar tidak didukung** – Aspose.Words mendukung PNG, JPEG, BMP, GIF, dan TIFF. Konversi format yang tidak didukung ke salah satu format ini sebelum menambahkannya ke dokumen sumber.
