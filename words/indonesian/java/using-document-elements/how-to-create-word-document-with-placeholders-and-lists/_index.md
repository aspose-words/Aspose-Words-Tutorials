# Cara membuat dokumen Word dengan placeholder dan daftar

Jika Anda perlu **membuat dokumen word** secara programatis, panduan ini menunjukkan cara melakukannya secara tepat. Kami akan membahas **menetapkan teks placeholder**, **menambahkan item daftar**, dan **cara menggunakan kontrol SDT** (Structured Document Tag) dengan Aspose.Words untuk .NET.

Pengembang sering meminta cara menyisipkan kontrol konten—seperti placeholder teks biasa atau daftar drop‑down—langsung ke dalam file .docx tanpa membuka Word. Tutorial ini memberikan contoh lengkap yang dapat dijalankan, menjelaskan mengapa setiap langkah penting, dan mencakup variasi umum seperti menambahkan kontrol ke dokumen yang sudah ada atau menyesuaikan nilai daftar.

## Prasyarat

Sebelum memulai, pastikan Anda memiliki:

- .NET 6.0 SDK atau yang lebih baru terpasang  
- Visual Studio 2022 (atau IDE C# apa pun)  
- Lisensi aktif Aspose.Words untuk .NET (versi percobaan gratis cukup untuk pengembangan)  
- Familiaritas dasar dengan sintaks C#  

Kode ini menargetkan **Aspose.Words 23.9** (versi stabil terbaru pada saat penulisan). Sesuaikan versi paket NuGet jika Anda menggunakan rilis yang lebih baru.

## Menyisipkan Structured Document Tag teks biasa (menetapkan teks placeholder)

SDT teks biasa berperilaku seperti kontrol konten yang dapat diisi pengguna. Menetapkan `Title` dan `PlaceholderName` memberikan petunjuk ramah di dalam Word.

```csharp
            // Step 2: Insert a plain‑text SDT and set its placeholder text
            StructuredDocumentTag plainTextTag = builder.InsertStructuredDocumentTag(
                StructuredDocumentTagType.PlainText, true);
            plainTextTag.Title = "CustomerName";
            plainTextTag.PlaceholderName = "Enter name";
```

**Penjelasan:**  
- `InsertStructuredDocumentTag` membuat kontrol pada posisi kursor builder saat ini.  
- `StructuredDocumentTagType.PlainText` memberi tahu Word untuk menampilkan kotak teks sederhana.  
- `Title` adalah nama internal yang digunakan oleh XML Word; berguna untuk binding data nanti.  
- `PlaceholderName` adalah petunjuk berwarna abu‑abu yang muncul sampai pengguna mengetik sesuatu.

> **Pro tip:** Jika Anda ingin placeholder muncul di panel *Properties* dokumen, juga setel `plainTextTag.Tag = "CustomerName"`.

## Menyisipkan SDT daftar drop‑down (cara menggunakan sdt)

Daftar drop‑down memungkinkan Anda menyajikan kumpulan pilihan yang telah ditentukan. Inilah inti **cara menggunakan sdt** untuk data enumerasi.

```csharp
            // Step 3: Insert a drop‑down list SDT and define its title
            StructuredDocumentTag dropdownTag = builder.InsertStructuredDocumentTag(
                StructuredDocumentTagType.DropDownList, true);
            dropdownTag.Title = "Country";
```

**Mengapa menggunakan drop‑down?**  
Daftar drop‑down meningkatkan konsistensi data dan mengurangi kesalahan pengetikan. Properti `Title` kembali berfungsi sebagai pengidentifikasi untuk pemrosesan selanjutnya (misalnya, saat mengekstrak data formulir).

## Menambahkan item daftar ke drop‑down (menambahkan item daftar)

Sekarang kita mengisi kontrol dengan nilai yang dapat dipilih. Setiap `ListItem` menerima teks tampilan dan nilai opsional yang dapat disimpan di XML dokumen.

```csharp
            // Step 4: Populate the drop‑down with selectable items
            dropdownTag.ListItems.Add(new ListItem("USA", "US"));
            dropdownTag.ListItems.Add(new ListItem("Canada", "CA"));
            dropdownTag.ListItems.Add(new ListItem("Mexico", "MX"));
```

**Poin penting:**  

- Argumen pertama (`"USA"`) adalah apa yang dilihat pengguna.  
- Argumen kedua (`"US"`) adalah nilai dasar yang dapat Anda baca secara programatis.  
- Anda dapat menambahkan sebanyak yang diperlukan; daftar disimpan dalam elemen `<w:listItem>` pada XML .docx.

### Kasus tepi dan variasi

| Situasi | Penyesuaian yang disarankan |
|-----------|------------------------|
| **Menambahkan kontrol ke file yang sudah ada** | Muat file dengan `new Document("Existing.docx")` alih‑alih membuat `Document` baru. |
| **Membuat placeholder wajib** | Setel `plainTextTag.IsShowingPlaceholderWhenEmpty = false` dan `plainTextTag.IsShowingPlaceholderWhenEmpty = true` berdasarkan logika validasi Anda. |
| **Binding item daftar ke sumber data** | Loop melalui koleksi (`foreach (var country in countries)`) dan panggil `dropdownTag.ListItems.Add(new ListItem(country.Name, country.Code))`. |
| **Menata kontrol** | Gunakan properti `builder.Font` sebelum menyisipkan SDT untuk memengaruhi gaya default teks placeholder. |
| **Menghapus kontrol nanti** | Temukan melalui `doc.GetChildNodes(NodeType.StructuredDocumentTag, true)` dan panggil `tag.Remove();`. |

## Cara membuat kontrol secara programatis – praktik terbaik

1. **Buat dokumen terlebih dahulu** – menginisialisasi `DocumentBuilder` di awal menghindari kejutan posisi kursor.  
2. **Setel judul dan tag** – mereka berfungsi sebagai pengidentifikasi stabil untuk ekstraksi data selanjutnya.  
3. **Tambahkan teks placeholder** – meningkatkan pengalaman pengguna, terutama untuk tag teks biasa.  
4. **Isi item daftar segera** – Word merender drop‑down dengan benar hanya setelah daftar dilampirkan.  
5. **Simpan sekali** – pemanggilan `Save` berulang di dalam loop secara dramatis meningkatkan beban I/O.

Dengan mengikuti langkah‑langkah ini, Anda memastikan file Word bersifat *machine‑readable* (untuk pemrosesan back‑end) dan *user‑friendly* (untuk penyuntingan front‑end).
