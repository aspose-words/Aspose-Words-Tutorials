# Cara membuat diagram donat di dokumen Word dengan Java

Jika Anda perlu **create doughnut chart** di dalam file Word, tutorial ini menunjukkan solusi lengkap yang siap dijalankan. Anda akan melihat cara **insert pie chart**, mengubahnya menjadi donat, **rotate pie chart** untuk keseimbangan yang lebih baik, dan **format pie chart** agar sesuai dengan merek Anda. Pada akhir tutorial Anda akan memiliki dokumen Word profesional yang dapat digunakan dalam laporan, dasbor, atau lampiran email otomatis.

Membuat diagram secara programatik menghilangkan langkah salin‑tempel manual dan menjamin konsistensi gaya di antara puluhan dokumen yang dihasilkan. Contoh ini menggunakan pustaka Aspose.Words for Java, yang bekerja dengan Java 8+ dan tidak memerlukan instalasi Microsoft Office. Tidak ada prasyarat lain yang diperlukan selain JDK standar dan IDE favorit Anda.

## Prasyarat

- Java Development Kit (JDK) 8 atau yang lebih baru  
- Maven atau Gradle untuk manajemen dependensi (tutorial ini menggunakan Maven)  
- Pustaka Aspose.Words for Java (lisensi percobaan gratis sudah cukup untuk pengujian)  

Add the Aspose.Words dependency to your `pom.xml`:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-words</artifactId>
    <version>24.9</version> <!-- Use the latest stable version -->
</dependency>
```

> **Pro tip:** Daftarkan lisensi Anda dengan `License license = new License(); license.setLicense("Aspose.Words.lic");` sebelum membuat dokumen apa pun untuk menghapus watermark evaluasi.

## Membuat diagram donat di dokumen Word

Alur kerja inti terdiri dari lima langkah logis. Setiap langkah dibungkus dalam metode terpisah untuk menjaga kode tetap bersih dan dapat digunakan kembali.

```java
import com.aspose.words.*;
import com.aspose.words.drawing.*;

public class DoughnutChartDemo {

    public static void main(String[] args) throws Exception {
        // Step 1: create blank Word document
        Document doc = createBlankWordDocument();

        // Step 2: insert a pie chart (base for the doughnut)
        Chart chart = insertPieChart(doc, 400, 300);

        // Step 3: convert the pie chart into a doughnut and rotate it
        customizeChartAppearance(chart);

        // Step 4: apply additional formatting to the chart
        formatPieChart(chart);

        // Step 5: save the final document
        doc.save("output/DoughnutChartFormatted.docx");
        System.out.println("Document saved successfully.");
    }

    /** Step 1 – create blank Word document */
    private static Document createBlankWordDocument() {
        // Aspose.Words creates an empty document by default
        return new Document();
    }

    /** Step 2 – insert pie chart with given dimensions */
    private static Chart insertPieChart(Document doc, int width, int height) throws Exception {
        DocumentBuilder builder = new DocumentBuilder(doc);
        // ChartType.PIE creates a standard pie chart that we will later turn into a doughnut
        Chart chart = builder.insertChart(ChartType.PIE, width, height);
        // Populate the chart with sample data
        chart.getSeries().clear(); // Remove default series
        ChartSeries series = chart.getSeries().add("Sales", new String[]{"Q1", "Q2", "Q3", "Q4"},
                new double[]{15000, 23000, 18000, 27000});
        return chart;
    }

    /** Step 3 – rotate pie chart and make it a doughnut */
    private static void customizeChartAppearance(Chart chart) {
        // Explode the first slice for emphasis
        chart.getSeries().get(0).setExplode(20);
        // Convert the pie into a doughnut by setting a hole size (percentage of radius)
        chart.setHoleSize(30); // 30% hole creates a classic doughnut look
        // Rotate the chart so the largest slice starts at 45°
        chart.setRotationAngle(45);
    }

    /** Step 4 – additional formatting of the pie chart */
    private static void formatPieChart(Chart chart) {
        // Example: change the first slice color to a brand color
        chart.getSeries().get(0).getPoints().get(0).getFormat().setFillForegroundColor(Color.fromArgb(0xFF, 0x4A, 0x90));
        // Add a legend and position it at the bottom
        chart.setHasLegend(true);
        chart.getLegend().setPosition(LegendPosition.BOTTOM);
        // Set a title for the chart
        chart.setTitle("Quarterly Sales Distribution");
    }
}
```

### Apa yang dilakukan kode

| Langkah | Aksi | Alasan |
|------|--------|--------|
| **Create blank Word document** | `new Document()` | Memulai dengan file bersih sehingga Anda mengontrol setiap elemen. |
| **Insert pie chart** | `builder.insertChart(ChartType.PIE, …)` | Diagram pai adalah bentuk dasar; Aspose hanya menyediakan donat dengan menyesuaikan ukuran lubang. |
| **Rotate pie chart** | `chart.setRotationAngle(45)` | Rotasi menyelaraskan irisan terbesar ke posisi yang lebih mudah dibaca. |
| **Format pie chart** | `setExplode`, `setHoleSize`, color, legend | Meningkatkan hierarki visual dan menyesuaikan pedoman gaya korporat. |
| **Save document** | `doc.save("…/DoughnutChartFormatted.docx")` | Menulis file .docx akhir ke disk, siap didistribusikan. |

## Sisipkan diagram pai sebelum mengonversi menjadi donat

Aspose.Words tidak menyediakan metode “insert doughnut chart” secara langsung. Sebagai gantinya, Anda **insert pie chart** dan kemudian mengubah propertinya. Pendekatan dua langkah ini memberi Anda kontrol penuh atas seri data, ledakan irisan, dan ukuran lubang. Jika Anda membutuhkan diagram pai murni di tempat lain, cukup hapus pemanggilan `setHoleSize`.

## Rotasi diagram pai untuk keseimbangan visual

Orientasi default memulai irisan pertama pada posisi jam 12. Dalam banyak laporan bisnis, irisan terpenting sebaiknya dimulai pada sudut yang lebih alami, seperti 45 derajat. Metode `setRotationAngle(double angle)` menerima nilai dalam derajat dan memutar seluruh diagram tanpa memengaruhi nilai data.

## Format diagram pai dan sesuaikan tampilan

Selain mengonversi menjadi donat, Anda sering ingin **format pie chart** elemen:

- **Explode** irisan pertama (`setExplode`) untuk menarik perhatian.  
- **Color** setiap irisan menggunakan `getPoints().get(i).getFormat().setFillForegroundColor`.  
- **Legend** penempatan (`setHasLegend`, `setPosition`) membantu pembaca menafsirkan kategori.  
- **Title** (`setTitle`) memberikan konteks secara sekilas.  

Semua pengaturan ini bersifat opsional; Anda dapat menyesuaikannya agar sesuai dengan palet merek atau templat korporat Anda.

## Buat dokumen Word kosong dan simpan hasilnya

Metode `createBlankWordDocument` mengenkapsulasi langkah **create blank word document**. Menjaga logika ini terisolasi memudahkan penggunaan kembali metode saat menghasilkan banyak laporan dalam proses batch. Setelah semua penyesuaian, `doc.save` menulis file dalam format Office Open XML standar (`.docx`), yang dapat dibuka di Microsoft Word, LibreOffice, atau Google Docs tanpa kehilangan kualitas.

### Output yang diharapkan

Saat Anda menjalankan metode `main`, konsol mencetak:

```
Document saved successfully.
```

Dan file `output/DoughnutChartFormatted.docx` berisi satu halaman dengan diagram donat berjudul *Quarterly Sales Distribution*. Diagram tersebut menampilkan empat irisan, irisan pertama meledak, berwarna dengan nuansa merek, dan diputar 45 derajat.

## Variasi umum dan kasus tepi

| Situasi | Penyesuaian |
|-----------|------------|
| **More than one data series** | Tambahkan objek `ChartSeries` tambahan ke `chart.getSeries()`. |
| **Different chart size** | Ubah argumen `width` dan `height` pada `insertPieChart`. |
| **No hole (pure pie)** | Hilangkan `chart.setHoleSize(…)` atau setel ke `0`. |
| **Large documents** | Gunakan `DocumentBuilder` untuk menyisipkan diagram ke bagian atau bookmark tertentu. |
| **License not set** | Pustaka berjalan dalam mode evaluasi, menambahkan watermark pada halaman pertama. Daftarkan lisensi untuk menghapusnya. |

## Kesimpulan

Anda sekarang tahu cara **create doughnut chart** di dokumen Word menggunakan Java, mulai dari **create blank word document** hingga **insert pie chart**, **rotate pie chart**, dan **format pie chart** untuk menghasilkan produk akhir yang halus. Contoh lengkap yang dapat dijalankan dapat dimasukkan ke dalam proyek Java apa pun yang sudah menggunakan Aspose.Words.

Selanjutnya, Anda mungkin ingin mengeksplorasi:

- Menambahkan label data (`chart.getSeries().get(0).setDataLabelType(DataLabelType.CATEGORY_AND_PERCENT);`)  
- Mengekspor diagram sebagai gambar (`chart.toImage`) untuk digunakan dalam email HTML  
- Mengotomatiskan pembuatan banyak dokumen dalam loop untuk pelaporan batch  

Silakan bereksperimen dengan warna, ledakan irisan, dan legenda untuk menyesuaikan bahasa visual organisasi Anda. Selamat membuat diagram!
