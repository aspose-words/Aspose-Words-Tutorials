# Cara mengekspor markdown dan memulihkan DOCX yang rusak dengan Aspose.Words

Jika Anda perlu **mengekspor markdown** dari file Word yang mungkin rusak, panduan ini menunjukkan langkah‑langkah tepatnya. Panduan ini juga mencakup **cara memulihkan dokumen**, **ekspor docx ke txt**, dan **simpan word sebagai pdf** menggunakan Aspose.Words for Python API.

Anda akan mempelajari cara memuat DOCX yang mungkin rusak dalam mode pemulihan, mengonversinya ke Markdown sambil mempertahankan persamaan, menyimpan konten yang sama sebagai teks biasa, menghasilkan PDF yang dapat diakses, dan bahkan menyesuaikan bayangan sebuah bentuk sebelum ekspor akhir. Tidak diperlukan alat eksternal—hanya Aspose.Words dan beberapa baris Python.

## Prasyarat

Sebelum memulai, pastikan Anda memiliki:

* Python 3.8 atau yang lebih baru
* Paket `aspose-words` (`pip install aspose-words`)
* File DOCX yang mungkin rusak (atau DOCX biasa untuk pengujian)
* Familiaritas dasar dengan fungsi dan kelas Python

> **Pro tip:** Simpan cadangan DOCX asli; mode pemulihan mengubah representasi dalam memori tetapi tidak menulis kembali ke file sumber.

## Langkah 1: Cara memulihkan DOCX yang rusak

Hambatan pertama adalah memuat file dengan aman. Aspose.Words menyediakan flag `RecoveryMode.RECOVER_CORRUPTED` yang berusaha membangun kembali struktur dokumen yang rusak.

```python
import aspose.words as aw

# Load the file in recovery mode
load_opts = aw.LoadOptions()
load_opts.recovery_mode = aw.RecoveryMode.RECOVER_CORRUPTED
doc = aw.Document("YOUR_DIRECTORY/input.docx", load_opts)
```

**Mengapa ini penting:**  
Ketika sebuah DOCX sebagian rusak—bagian yang hilang, XML yang rusak, atau hubungan yang tidak valid—pemrosesan standar akan melempar pengecualian. Mode pemulihan mem-parsing apa yang dapat dibaca, membuang fragmen yang tidak dapat dibaca sambil mempertahankan sisanya, yang esensial untuk operasi **ekspor docx ke txt** atau **simpan word sebagai pdf** selanjutnya.

### Kasus tepi umum
Jika dokumen tidak dapat diperbaiki, `doc` tetap akan dibuat tetapi dengan log peringatan. Anda dapat memeriksa `doc.is_dirty` untuk melihat apakah ada konten yang diubah selama pemulihan.

## Langkah 2: Cara mengekspor markdown dengan Aspose.Words

Markdown adalah bahasa markup ringan yang disukai banyak generator situs statis dan alat dokumentasi. Aspose.Words dapat menghasilkan Markdown sambil menjaga persamaan sebagai LaTeX, yang sempurna untuk dokumentasi teknis.

```python
# Configure Markdown export options
md_opts = aw.MarkdownSaveOptions()
md_opts.office_math_export_mode = aw.OfficeMathExportMode.LATEX

# Save as Markdown
doc.save("YOUR_DIRECTORY/output.md", md_opts)
```

**Apa yang Anda dapatkan:**  
* Teks biasa dengan heading, daftar, dan tabel yang dikonversi ke sintaks Markdown.  
* Setiap persamaan Word dirender sebagai blok LaTeX (`$$ … $$`), memastikan matematika tetap dapat diedit di alat downstream.

### Verifikasi output
Buka `output.md` di editor apa pun. Anda seharusnya melihat sesuatu seperti:

```markdown
# Title of the Document

This is a paragraph with **bold** text.

$$
\int_{0}^{\infty} e^{-x} dx = 1
$$
```

Jika Anda memerlukan format persamaan yang berbeda (misalnya MathML), ubah `office_math_export_mode` sesuai kebutuhan.

## Langkah 3: Ekspor docx ke txt sambil mempertahankan persamaan

File teks biasa berguna untuk pencarian cepat atau untuk dimasukkan ke pipeline bahasa alami. `OfficeMathExportMode.LATEX` yang sama juga berfungsi untuk ekspor `.txt`, memberikan LaTeX yang dapat dibaca secara inline.

```python
txt_opts = aw.TxtSaveOptions()
txt_opts.office_math_export_mode = aw.OfficeMathExportMode.LATEX

doc.save("YOUR_DIRECTORY/output.txt", txt_opts)
```

**Mengapa menggunakan ini alih‑alih copy‑paste?**  
Copy‑paste manual sering menghilangkan karakter tersembunyi dan merusak keakuratan persamaan. Pendekatan **ekspor docx ke txt** ini menjamin setiap persamaan muncul sebagai potongan LaTeX, siap untuk diproses lebih lanjut.

## Langkah 4: Simpan word sebagai PDF dengan bentuk inline untuk aksesibilitas lebih baik

PDF adalah format de‑facto untuk publikasi. Ketika dokumen Word berisi gambar atau diagram mengambang, beberapa pembaca mungkin tidak menafsirkannya dengan benar. Menetapkan `export_floating_shapes_as_inline_tag` memaksa bentuk‑bentuk tersebut menjadi inline, meningkatkan aksesibilitas dan konsistensi tata letak.

```python
pdf_opts = aw.PdfSaveOptions()
pdf_opts.export_floating_shapes_as_inline_tag = True

doc.save("YOUR_DIRECTORY/output.pdf", pdf_opts)
```

**Hasil:**  
PDF yang mencerminkan tata letak asli, tetapi semua bentuk kini menjadi bagian dari alur teks. Ini sangat membantu pembaca layar, karena mereka memperlakukan elemen inline sebagai bagian dari urutan bacaan.

### Tips untuk dokumen besar
Jika Anda menghasilkan PDF secara batch, gunakan kembali instance `PdfSaveOptions` yang sama untuk menghindari pembuatan objek yang tidak perlu.

## Langkah 5: Menyetel bayangan bentuk sebelum PDF akhir

Terkadang Anda perlu menyesuaikan detail visual—seperti bayangan logo—sebelum dipublikasikan. Contoh di bawah mengambil bentuk pertama, mengubah properti bayangannya, dan menyimpan PDF baru.

```python
# Retrieve the first shape in the document
shape = doc.get_child(aw.NodeType.SHAPE, 0, True).as_shape()

# Adjust shadow settings
shape.shadow.blur_radius = 5.0   # Soft blur
shape.shadow.distance = 2.0     # Distance from shape edge
shape.shadow.opacity = 0.6      # 60% opacity

# Save the shadow‑enhanced PDF
doc.save("YOUR_DIRECTORY/shadowed.pdf", pdf_opts)
```

**Apa yang dilakukan:**  
* `blur_radius` mengontrol seberapa kabur bayangan terlihat.  
* `distance` memindahkan bayangan menjauh dari bentuk, menciptakan kedalaman.  
* `opacity` membuat bayangan semi‑transparan, yang sering tampak lebih profesional.

Anda dapat mengulangi blok ini untuk bentuk apa pun dengan mengubah indeks pada `get_child`.

## Skrip lengkap untuk copy‑paste cepat

Berikut adalah skrip lengkap yang dapat dijalankan dan menggabungkan semua langkah. Ganti `YOUR_DIRECTORY` dengan jalur tempat file Anda berada.

```python
import aspose.words as aw

# -------------------------------------------------
# 1️⃣ Recover a possibly corrupted DOCX
# -------------------------------------------------
load_opts = aw.LoadOptions()
load_opts.recovery_mode = aw.RecoveryMode.RECOVER_CORRUPTED
doc = aw.Document("YOUR_DIRECTORY/input.docx", load_opts)

# -------------------------------------------------
# 2️⃣ Export to Markdown (how to export markdown)
# -------------------------------------------------
md_opts = aw.MarkdownSaveOptions()
md_opts.office_math_export_mode = aw.OfficeMathExportMode.LATEX
doc.save("YOUR_DIRECTORY/output.md", md_opts)

# -------------------------------------------------
# 3️⃣ Export to plain text (export docx to txt)
# -------------------------------------------------
txt_opts = aw.TxtSaveOptions()
txt_opts.office_math_export_mode = aw.OfficeMathExportMode.LATEX
doc.save("YOUR_DIRECTORY/output.txt", txt_opts)

# -------------------------------------------------
# 4️⃣ Save as PDF (save word as pdf)
# -------------------------------------------------
pdf_opts = aw.PdfSaveOptions()
pdf_opts.export_floating_shapes_as_inline_tag = True
doc.save("YOUR_DIRECTORY/output.pdf", pdf_opts)

# -------------------------------------------------
# 5️⃣ Adjust first shape's shadow and re‑save PDF
# -------------------------------------------------
shape = doc.get_child(aw.NodeType.SHAPE, 0, True).as_shape()
shape.shadow.blur_radius = 5.0
shape.shadow.distance = 2.0
shape.shadow.opacity = 0.6
doc.save("YOUR_DIRECTORY/shadowed.pdf", pdf_opts)
```

Menjalankan skrip menghasilkan:

| File | Tujuan |
|------|--------|
| `output.md` | Markdown dengan persamaan LaTeX (**cara mengekspor markdown**) |
| `output.txt` | Versi teks biasa (**ekspor docx ke txt**) |
| `output.pdf` | PDF yang dapat diakses (**simpan word sebagai pdf**) |
| `shadowed.pdf` | PDF dengan bentuk yang memiliki gaya bayangan khusus |

## Pertanyaan yang sering diajukan

**T: Apakah mode pemulihan memperbaiki gambar yang hilang?**  
J: Mode ini memulihkan struktur dokumen tetapi tidak dapat membuat kembali data biner gambar yang hilang. Jika bagian gambar tidak ada, bentuk akan kosong.

**T: Bisakah saya mengekspor ke HTML alih‑alih Markdown?**  
J: Ya—gunakan `aw.HtmlSaveOptions()` dan atur `office_math_export_mode` sesuai kebutuhan.

**T: Bagaimana jika saya ingin mempertahankan bentuk mengambang?**  
J: Hapus `export_floating_shapes_as_inline_tag` atau setel ke `False`.

**T: Apakah ekspor LaTeX kompatibel dengan MathJax?**  
J: Tentu saja. MathJax dapat merender blok `$$ … $$` yang dihasilkan oleh pengekspor Markdown dan Txt.
