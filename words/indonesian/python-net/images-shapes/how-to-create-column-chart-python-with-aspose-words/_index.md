# Cara membuat diagram kolom python dengan Aspose.Words

Jika Anda perlu membuat diagram kolom python, panduan ini menunjukkan kode dan penjelasan yang tepat yang Anda butuhkan. Dengan menggunakan Aspose.Words chart API, Anda dapat menentukan dimensi yang tepat, menerapkan gaya bawaan, dan mengekspor hasilnya tanpa meninggalkan Python.

Membuat diagram kolom adalah kebutuhan umum untuk laporan, dasbor, dan pembuatan dokumen otomatis. Tutorial ini mencakup setiap langkah—dari mengimpor pustaka hingga memverifikasi gambar yang disimpan—sehingga Anda dapat mengintegrasikan pembuatan diagram ke dalam proyek Python apa pun.

## Prasyarat

Sebelum Anda memulai, pastikan Anda memiliki:

* Python 3.8 atau yang lebih baru terpasang.
* Lisensi Aspose.Words untuk Python yang valid (atau kunci evaluasi gratis).
* Familiaritas dasar dengan modul Python dan kode berorientasi objek.

Mesin diagram Aspose.Words bekerja di Windows, macOS, dan Linux, dan tidak memerlukan pustaka grafis tambahan karena proses rendering terjadi di sisi server.

## Langkah 1: Impor pustaka Aspose.Words

Langkah pertama adalah mengimpor paket `aspose.words` dan memberinya alias singkat. Mengimpor di bagian atas file menjaga namespace tetap rapi dan membuat kode lebih mudah dibaca.

```python
# Step 1: Import the Aspose.Words library
import aspose.words as aw
```

`aw` kini merujuk ke seluruh API Aspose.Words, termasuk kelas `Chart` yang akan Anda gunakan untuk membangun diagram kolom.

## Langkah 2: Buat diagram kolom dengan dimensi yang diinginkan

Diagram kolom memerlukan nilai lebar dan tinggi yang eksplisit agar gambar yang dirender sesuai dengan tata letak dokumen Anda. Konstruktor `Chart` menerima tiga argumen: tipe diagram, lebar (dalam poin), dan tinggi (dalam poin). Menggunakan `aw.ChartType.COLUMN` memberi tahu mesin untuk menghasilkan diagram batang vertikal.

```python
# Step 2: Create a column chart with the desired dimensions
chart = aw.Chart(aw.ChartType.COLUMN, 400, 300)   # width=400pt, height=300pt
```

*Why set dimensions?*  
Ketika Anda menyematkan diagram dalam dokumen Word atau mengekspornya sebagai gambar, konten di sekitarnya menghormati ukuran tepat yang Anda berikan. Ini mencegah skala atau pemotongan yang tidak diinginkan.

### Tips profesional: Gunakan `chart.dimensions` untuk mengubah ukuran secara dinamis

Jika kumpulan data Anda bervariasi, Anda dapat menghitung ukuran berdasarkan jumlah seri:

```python
series_count = 5
base_width = 80
chart.width = base_width * series_count
chart.height = 300
```

## Langkah 3: Terapkan gaya bawaan ke diagram kolom

Aspose.Words menyediakan beberapa tema visual yang telah ditentukan sebelumnya. Memilih gaya menghilangkan kebutuhan untuk mengonfigurasi warna, font, dan garis kisi secara manual. `aw.ChartStyle.STYLE_5` memberikan tampilan bersih dan profesional yang cocok untuk sebagian besar laporan bisnis.

```python
# Step 3: Apply a built‑in style to the chart
chart.style = aw.ChartStyle.STYLE_5
```

Jika Anda menginginkan tampilan yang berbeda, ganti `STYLE_5` dengan salah satu konstanta lain (`STYLE_1` … `STYLE_8`). Setiap gaya mengikuti konvensi penamaan yang sama, sehingga mudah untuk bereksperimen.

### Kasus tepi: Konstanta gaya tidak valid

Mencoba menetapkan gaya yang tidak ada akan memunculkan `AttributeError`. Lindungi kode Anda dengan memeriksa konstanta terhadap enumerasi:

```python
if hasattr(aw.ChartStyle, "STYLE_5"):
    chart.style = aw.ChartStyle.STYLE_5
else:
    raise ValueError("Requested chart style does not exist.")
```

## Langkah 4: Tambahkan seri data ke diagram kolom

Diagram tanpa data tidak memiliki makna. Anda dapat menambahkan satu atau lebih objek `ChartSeries`, masing‑masing mewakili grup kolom. Contoh berikut menambahkan satu seri dengan tiga titik data.

```python
# Step 4: Add data series to the column chart
series = chart.series.add()
series.name = "Quarterly Sales"
series.data = [12000, 15000, 18000]   # Values for Q1, Q2, Q3
```

Anda dapat mengulangi pemanggilan `chart.series.add()` untuk menyertakan seri tambahan (misalnya, “Projected Sales”). API secara otomatis menempatkan kolom berdampingan.

## Langkah 5: Render diagram dan simpan sebagai gambar

Setelah mengonfigurasi diagram, Anda merendernya ke bitmap atau file gambar. Metode `save` menerima jalur file dan format opsional. PNG bersifat lossless dan didukung secara luas.

```python
# Step 5: Render and save the chart as a PNG image
output_path = "column_chart.png"
chart.save(output_path, aw.SaveFormat.PNG)
print(f"Chart saved to {output_path}")
```

Enumerasi `SaveFormat` mencakup PNG, JPEG, BMP, dan lainnya. Pilih format yang sesuai dengan alur kerja downstream Anda.

## Verifikasi output

Buka `column_chart.png` dengan penampil gambar apa pun. Anda harus melihat diagram batang tiga kolom yang bergaya dengan tema bawaan yang dipilih, berukuran tepat 400 × 300 poin.

![Diagram kolom yang dihasilkan oleh Aspose.Words di Python](column_chart.png){: .center alt="Tangkapan layar diagram kolom yang dihasilkan oleh Aspose.Words di Python"}

Jika gambar muncul kosong atau terdistorsi, periksa hal‑hal berikut:

1. Objek `aw.Chart` telah diinstansiasi sebelum menambahkan seri.
2. Konstanta `chart.style` cocok dengan nilai enum yang ada.
3. Pemanggilan `save` menggunakan `SaveFormat` yang didukung.

## Variasi umum dan tips tambahan

| Situasi | Perubahan yang disarankan |
|-----------|--------------------|
| **Multiple data series** | Tambahkan blok `chart.series.add()` tambahan dan atur `series.name` serta `series.data` untuk masing‑masing. |
| **Custom colors** | Setelah menerapkan gaya bawaan, timpa warna kolom individual melalui `series.points[i].fill.fore_color`. |
| **Embedding in a Word document** | Alih‑alih `chart.save()`, gunakan `doc = aw.Document(); doc.sections[0].body.append_child(chart); doc.save("report.docx")`. |
| **Dynamic sizing** | Hitung lebar berdasarkan jumlah seri (`width = 80 * len(chart.series)`). |

Variasi ini menunjukkan bagaimana kode inti yang sama dapat beradaptasi dengan berbagai skenario pelaporan.
