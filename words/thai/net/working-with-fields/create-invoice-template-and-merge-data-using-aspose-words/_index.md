# สร้างเทมเพลตใบแจ้งหนี้และรวมข้อมูลโดยใช้ Aspose.Words

หากคุณต้องการ **สร้างเทมเพลตใบแจ้งหนี้** อย่างรวดเร็ว คู่มือนี้จะแสดงให้คุณเห็นขั้นตอนอย่างชัดเจน หลังจากอ่านสองประโยคแรก คุณจะเข้าใจกระบวนการทำงานทั้งหมดสำหรับการเปลี่ยนไฟล์ Word เปล่าให้เป็นใบแจ้งหนี้ที่เต็มไปด้วยข้อมูลโดยใช้ API การรวมเมลแบบ low‑code ของ Aspose.Words

การสร้างใบแจ้งหนี้เป็นความต้องการทั่วไปสำหรับระบบบิลลิ่ง, การรวม ERP, และการรายงานอัตโนมัติ ในบทเรียนนี้คุณจะได้เรียนรู้ **วิธีทำ mail merge**, **การเติมข้อมูลลงในเทมเพลต Word**, **การรวมข้อมูลเข้าสู่ Word**, และสุดท้าย **การบันทึกเอกสารที่รวมแล้ว** — ทั้งหมดด้วยไม่กี่บรรทัดของ C#

## สิ่งที่คุณจะได้ทำ

* เทมเพลต Word ที่ใช้ซ้ำได้ (`InvoiceTemplate.docx`) ซึ่งมีฟิลด์รวมสำหรับลูกค้า, วันที่, รายการสินค้า, และยอดรวม  
* โปรแกรม C# ที่โหลดเทมเพลต, ฉีดข้อมูลแบบ strongly‑typed, และเขียนผลลัพธ์เป็น `Invoice_001.docx`  
* ความเข้าใจในกรณีขอบเช่น คอลเลกชันว่าง, ชนิดข้อมูลกำหนดเอง, และการจัดการเส้นทางไฟล์

### ข้อกำหนดเบื้องต้น

| Requirement | Why it matters |
|-------------|----------------|
| .NET 6 or later | Aspose.Words for .NET รองรับ .NET 6+ และให้ API low‑code ที่ใช้ในคู่มือนี้ |
| Aspose.Words for .NET NuGet package (`Aspose.Words`) | จัดเตรียม `Document`, `MailMerger` และชนิดข้อมูลที่เกี่ยวข้อง |
| Basic C# knowledge | จำเป็นสำหรับการเข้าใจออบเจ็กต์นิรนามและ LINQ |
| Visual Studio 2022 (or any IDE) | ทำให้การแก้ไขและดีบักเป็นเรื่องง่าย |

> **เคล็ดลับระดับมืออาชีพ:** ติดตั้งแพคเกจ NuGet ผ่าน Package Manager Console:  
> `Install-Package Aspose.Words`

## วิธีสร้างเทมเพลตใบแจ้งหนี้ด้วย low‑code mail merge

ขั้นตอนแรกคือการสร้างไฟล์ Word ที่มีฟิลด์รวมซึ่งตรงกับคุณสมบัติของออบเจ็กต์ข้อมูลที่คุณจะส่งต่อในภายหลัง บันทึกไฟล์เป็น `InvoiceTemplate.docx` ในโฟลเดอร์ที่คุณควบคุม (เช่น `C:\Invoices\Template`)

| Merge field | Example placeholder in Word |
|-------------|-----------------------------|
| CustomerName | «CustomerName» |
| InvoiceDate | «InvoiceDate» |
| Items (repeating) | «Items.Description», «Items.Qty», «Items.Price» |
| Total | «Total» |

> **ทำไมเรื่องนี้ถึงสำคัญ:** API low‑code จะทำการแมปชื่อคุณสมบัติของแหล่งข้อมูลกับฟิลด์รวมโดยอัตโนมัติ การใช้ชื่อเดียวกันช่วยขจัดการแมปฟิลด์‑กับ‑คุณสมบัติด้วยมือและลดข้อผิดพลาดขณะรัน

## ขั้นตอน 1: โหลดเทมเพลตใบแจ้งหนี้

```csharp
using Aspose.Words;
using Aspose.Words.LowCode;   // Low‑code mail‑merge API

// Load the Word file that contains the merge fields.
Document template = new Document(@"C:\Invoices\Template\InvoiceTemplate.docx");
```

*คลาส `Document` แทนไฟล์ Word ทั้งหมด การโหลดเพียงครั้งเดียวทำให้คุณสามารถใช้เทมเพลตเดียวกันซ้ำสำหรับใบแจ้งหนี้หลายฉบับได้*

## ขั้นตอน 2: เตรียมแหล่งข้อมูล

สร้างออบเจ็กต์นิรนามที่สะท้อนฟิลด์รวม API low‑code สามารถทำงานกับออบเจ็กต์ .NET ใดก็ได้ รวมถึงอาเรย์และคอลเลกชันซ้อนกัน

```csharp
var invoiceData = new
{
    CustomerName = "Acme Corp",
    InvoiceDate = DateTime.Today,
    Items = new[]
    {
        new { Description = "Widget A", Qty = 10, Price = 9.99M },
        new { Description = "Widget B", Qty = 5,  Price = 19.95M }
    },
    Total = 199.85M
};
```

**ทำไมวิธีนี้ถึงได้ผล:**  
* ชื่อคุณสมบัติ (`CustomerName`, `InvoiceDate`, `Items`, `Total`) ตรงกับฟิลด์รวมในเทมเพลต  
* `Items` เป็นอาเรย์ของออบเจ็กต์ ดังนั้น mail merger จะทำการซ้ำแถวตารางสำหรับแต่ละรายการโดยอัตโนมัติ  
* การใช้ `decimal` (`M` suffix) สำหรับค่าเงินช่วยหลีกเลี่ยงปัญหา rounding ของ floating‑point

### การจัดการคอลเลกชันว่าง

หากใบแจ้งหนี้ไม่มีรายการสินค้า ให้ส่งอาเรย์ว่าง:

```csharp
Items = new object[0]
```

เครื่องยนต์ low‑code จะละเว้นส่วนที่ทำซ้ำโดยอัตโนมัติ ทำให้ส่วนหัวของตารางคงอยู่

## ขั้นตอน 3: เริ่มต้น low‑code mail merger

```csharp
MailMerger merger = new MailMerger(template);
```

`MailMerger` เป็นจุดเริ่มต้นสำหรับ **วิธีทำ mail merge** ด้วย Aspose.Words มันอ่านเทมเพลต, ผูกข้อมูล, และเตรียมเอกสารสุดท้ายในหนึ่งคำสั่ง

## ขั้นตอน 4: ดำเนินการรวม – เติมข้อมูลลงในเทมเพลต Word ในบรรทัดเดียว

```csharp
Document mergedDocument = merger.Execute(invoiceData);
```

* บรรทัดนี้ **เติมข้อมูลลงในเทมเพลต Word** และสร้างอินสแตนซ์ `Document` ใหม่ (`mergedDocument`)  
* ฟิลด์รวมทั้งหมดถูกแทนที่, ส่วนที่ทำซ้ำถูกขยาย, และเอกสารผลลัพธ์อยู่ในหน่วยความจำทั้งหมด

### กรณีขอบ: การจัดรูปแบบแบบกำหนดเอง

หากต้องการรูปแบบวันที่เฉพาะ ให้เพิ่มฟอร์แมตเตอร์กำหนดเองก่อนทำการรวม:

```csharp
merger.Options.DateFormat = "MMMM dd, yyyy"; // e.g., "October 07, 2026"
```

## ขั้นตอน 5: บันทึกเอกสารที่รวมแล้ว

```csharp
mergedDocument.Save(@"C:\Invoices\Output\Invoice_001.docx");
```

คำสั่ง **save merged document** จะเขียนใบแจ้งหนี้ที่เต็มไปด้วยข้อมูลลงดิสก์ ไฟล์สามารถเปิดด้วย Microsoft Word, ส่งเป็นไฟล์แนบอีเมล, หรือแปลงเป็น PDF ได้

### การตรวจสอบผลลัพธ์

เปิด `Invoice_001.docx` คุณควรเห็น:

* **CustomerName** ถูกแทนที่ด้วย *Acme Corp*  
* **InvoiceDate** แสดงวันที่วันนี้ในรูปแบบที่เลือก  
* แถวตารางสำหรับ *Widget A* (10 × 9.99) และ *Widget B* (5 × 19.95)  
* **Total** แสดงค่า *199.85*  

หากฟิลด์ใดยังคงไม่เปลี่ยน (เช่น ยังคงแสดง «CustomerName») ให้ตรวจสอบว่าชื่อคุณสมบัติตรงกับชื่อฟิลด์รวมในเทมเพลตอย่างแม่นยำ

## ตัวอย่างที่สามารถรันได้เต็มรูปแบบ

ด้านล่างเป็นโปรแกรมครบชุดที่คุณสามารถคัดลอก‑วางลงในโปรเจกต์คอนโซลใหม่ได้

```csharp
using System;
using Aspose.Words;
using Aspose.Words.LowCode;   // Low‑code mail‑merge API

namespace InvoiceGenerator
{
    class Program
    {
        static void Main()
        {
            // 1️⃣ Load the template
            Document template = new Document(@"C:\Invoices\Template\InvoiceTemplate.docx");

            // 2️⃣ Build the data source
            var invoiceData = new
            {
                CustomerName = "Acme Corp",
                InvoiceDate = DateTime.Today,
                Items = new[]
                {
                    new { Description = "Widget A", Qty = 10, Price = 9.99M },
                    new { Description = "Widget B", Qty = 5,  Price = 19.95M }
                },
                Total = 199.85M
            };

            // 3️⃣ Initialise the mail merger
            MailMerger merger = new MailMerger(template);

            // Optional: customise date format
            merger.Options.DateFormat = "MMMM dd, yyyy";

            // 4️⃣ Perform the merge (populate word template)
            Document mergedDocument = merger.Execute(invoiceData);

            // 5️⃣ Save the resulting file (save merged document)
            mergedDocument.Save(@"C:\Invoices\Output\Invoice_001.docx");

            Console.WriteLine("Invoice generated successfully.");
        }
    }
}
```

รันโปรแกรม (`dotnet run`) คอนโซลจะแสดงข้อความ *Invoice generated successfully.* และไฟล์จะปรากฏใน `C:\Invoices\Output`
