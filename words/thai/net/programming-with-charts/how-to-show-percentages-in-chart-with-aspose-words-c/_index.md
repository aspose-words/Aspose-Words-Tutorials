# วิธีแสดงเปอร์เซ็นต์ในแผนภูมิด้วย Aspose.Words C#

เคยสงสัย **วิธีแสดงเปอร์เซ็นต์ในแผนภูมิ** โดยไม่ต้องต่อสู้กับ Office interop ที่ซับซ้อนหรือไม่? คุณไม่ได้อยู่คนเดียว—นักพัฒนาหลายคนเจออุปสรรคนี้เมื่อต้องการวิธีที่รวดเร็วและเป็นโปรแกรมเมติกเพื่อใส่ป้ายกำกับให้กับแผนภูมิพายหรือโดนัท ข่าวดีคือ? ด้วย Aspose.Words for .NET คุณสามารถเปิดใช้งานป้ายข้อมูลเหล่านั้นได้ด้วยเพียงไม่กี่บรรทัดโค้ด

ในบทแนะนำนี้เราจะครอบคลุม **add data labels to pie chart** และ **how to enable chart data labels** เพื่อให้การแสดงผลของคุณทันทีกลายเป็นข้อมูลเชิงลึกมากขึ้น เมื่อเสร็จสิ้นคุณจะได้ไฟล์ Word (`.docx`) ที่พร้อมใช้งานซึ่งแสดงแผนภูมิพายที่สวยงามพร้อมเปอร์เซ็นต์ที่จัดตำแหน่งอย่างเป็นระเบียบนอกแต่ละชิ้น

## Prerequisites

ก่อนที่เราจะเริ่มลงมือทำ โปรดตรวจสอบว่าคุณมี:

- **Aspose.Words for .NET** (เวอร์ชันล่าสุด เช่น 24.9) ติดตั้งผ่าน NuGet
- ไฟล์ **ChartTemplate.docx** ที่มีแผนภูมิพายหรือโดนัทอยู่แล้ว  
  *(หากไม่มี ให้สร้างเอกสาร Word ง่าย ๆ แทรกแผนภูมิพายแล้วบันทึกเป็น `ChartTemplate.docx`)*  
- .NET 6.0 หรือใหม่กว่าและ IDE ที่คุณชอบ (Visual Studio, Rider, VS Code)

ไม่มีการพึ่งพาเพิ่มเติม—Aspose.Words จัดการทุกอย่างภายใน

## How to Show Percentages in Chart – Step‑by‑Step

ด้านล่างเราจะแบ่งกระบวนการเป็นหกขั้นตอนที่ชัดเจน แต่ละขั้นตอนจะมีโค้ด C# ที่คุณสามารถคัดลอก‑วางได้ พร้อมคำอธิบายสั้น ๆ เกี่ยวกับ **ทำไม** เราต้องทำเช่นนั้น

### Step 1: Load the Source Document

```csharp
using Aspose.Words;
using Aspose.Words.Drawing.Charts;

// Load the .docx that already holds a chart.
Document sourceDoc = new Document("YOUR_DIRECTORY/ChartTemplate.docx");
```

*ทำไม?*  
`Document` คือจุดเริ่มต้นสำหรับการจัดการ Word ใด ๆ การโหลดเทมเพลตทำให้เราสามารถเข้าถึงโหนดทั้งหมด—รูปร่าง ตาราง ข้อความ และแน่นอนว่าแผนภูมิที่เราจะปรับแก้

### Step 2: Grab the First Chart Shape

```csharp
// The chart lives inside a Shape node; retrieve it.
Chart chart = (Chart)sourceDoc.GetChild(NodeType.Shape, 0, true);
```

*ทำไม?*  
Aspose เก็บแผนภูมิเป็นอ็อบเจ็กต์ `Shape` `GetChild` จะเดินทางผ่านต้นไม้ของเอกสารและคืนค่า shape ตัวแรกที่พบ ซึ่งในกรณีของเราคือแผนภูมิพายที่ต้องการแก้ไข

### Step 3: Confirm the Chart Type

```csharp
if (chart.ChartType == ChartType.Pie || chart.ChartType == ChartType.Doughnut)
{
    // Inside this block we’ll enable the data labels.
}
else
{
    throw new InvalidOperationException("The chart is not a Pie or Doughnut type.");
}
```

*ทำไม?*  
ป้ายเปอร์เซ็นต์มีความหมายเฉพาะกับแผนภูมิวงกลม การตรวจสอบนี้ช่วยป้องกันไม่ให้เราตั้งค่าผิดพลาดกับแผนภูมิประเภทอื่น เช่น แผนภูมิแท่ง ที่ `ShowPercentage` จะไม่มีผล

### Step 4: Enable Data Labels and Show Percentages

```csharp
// Turn on data labels for the chart.
chart.HasDataLabel = true;

// Show the percentage value for each slice.
chart.DataLabel.ShowPercentage = true;
```

*ทำไม?*  
`HasDataLabel` บอก Aspose ให้แสดงป้ายกำกับสำหรับแต่ละจุดข้อมูล การตั้งค่า `ShowPercentage` ทำให้เนื้อหาป้ายเป็นส่วนแบ่งที่คำนวณจากทั้งหมด—ตรงกับความต้องการของ **add data labels to pie chart** ที่เราต้องการ

### Step 5: Position Labels Outside the Slices

```csharp
// Place the labels outside the pie slices for better readability.
chart.DataLabel.Position = ChartDataLabelPosition.OutSideEnd;
```

*ทำไม?*  
ป้ายภายในชิ้นอาจแออัดโดยเฉพาะเมื่อชิ้นเล็ก `OutSideEnd` จำลองสไตล์ “นอก” ที่คุณเห็นใน UI ของ Word ทำให้แผนภูมิดูสะอาดตา

### Step 6: Save the Updated Document

```csharp
sourceDoc.Save("YOUR_DIRECTORY/FormattedPieChart.docx");
```

*ทำไม?*  
การบันทึกจะเขียนการเปลี่ยนแปลงทั้งหมดลงในไฟล์ใหม่ เปิด `FormattedPieChart.docx` ใน Word แล้วคุณจะเห็นเปอร์เซ็นต์แสดงข้างแต่ละชิ้น

#### Expected Result

เมื่อคุณเปิด `FormattedPieChart.docx` แผนภูมิพายควรมีลักษณะคล้ายกับภาพต่อไปนี้ (สกรีนช็อตสมมติ):

```
[ Pie chart with three slices ]
- Slice A – 45%
- Slice B – 30%
- Slice C – 25%
```

เปอร์เซ็นต์ทั้งหมดคำนวณโดยอัตโนมัติจากชุดข้อมูลพื้นฐาน และป้ายกำกับจะอยู่ด้านนอกแต่ละชิ้นอย่างเป็นระเบียบ

## Common Variations & Edge Cases

| สถานการณ์ | สิ่งที่ต้องปรับ |
|-----------|----------------|
| **หลายแผนภูมิ** ในเอกสารเดียวกัน | วนลูปผ่าน `sourceDoc.GetChildNodes(NodeType.Shape, true)` และแคสท์แต่ละอ็อบเจ็กต์เป็น `Chart` ก่อนนำตรรกะเดียวกันไปใช้ |
| **แผนภูมิแท่งหรือเส้น** ที่คุณยังต้องการป้าย | ใช้ `chart.DataLabel.ShowValue = true;` (หรือ `ShowSeriesName`) แทน `ShowPercentage` |
| **รูปแบบตัวเลขแบบกำหนดเอง** (เช่น “45 %”) | ตั้งค่า `chart.DataLabel.NumberFormat = "0%";` ก่อนบันทึก |
| **ชุดข้อมูลขนาดใหญ่** ทำให้ป้ายทับกัน | พิจารณา `chart.DataLabel.ShowLeaderLines = true;` เพื่อวาดเส้นเชื่อมระหว่างป้ายและชิ้น |

> **เคล็ดลับมืออาชีพ:** หากคุณสร้างเอกสารจำนวนมากเป็นชุด ให้สร้างอ็อบเจ็กต์ `Aspose.Words.License` เพียงครั้งเดียวเมื่อแอปเริ่มทำงาน เพื่อหลีกเลี่ยงการโหลดไลเซนส์ซ้ำ ๆ ที่ทำให้ประสิทธิภาพลดลง

## Full Working Example

นี่คือโปรแกรมเต็มรูปแบบที่พร้อมรัน:

```csharp
using System;
using Aspose.Words;
using Aspose.Words.Drawing.Charts;

class Program
{
    static void Main()
    {
        // 1️⃣ Load the template document.
        Document sourceDoc = new Document("YOUR_DIRECTORY/ChartTemplate.docx");

        // 2️⃣ Retrieve the first chart shape.
        Chart chart = (Chart)sourceDoc.GetChild(NodeType.Shape, 0, true);

        // 3️⃣ Ensure we’re dealing with a Pie or Doughnut chart.
        if (chart.ChartType != ChartType.Pie && chart.ChartType != ChartType.Doughnut)
        {
            Console.WriteLine("The selected shape is not a Pie/Doughnut chart.");
            return;
        }

        // 4️⃣ Enable data labels and show percentages.
        chart.HasDataLabel = true;
        chart.DataLabel.ShowPercentage = true;

        // 5️⃣ Position the labels outside the slices.
        chart.DataLabel.Position = ChartDataLabelPosition.OutSideEnd;

        // 6️⃣ Save the modified document.
        sourceDoc.Save("YOUR_DIRECTORY/FormattedPieChart.docx");

        Console.WriteLine("Chart updated successfully – percentages now visible!");
    }
}
```

คัดลอกโค้ด แทนที่ `YOUR_DIRECTORY` ด้วยพาธจริงบนเครื่องของคุณ แล้วรัน คุณจะได้ไฟล์ Word ที่มีแผนภูมิพายพร้อมป้ายเปอร์เซ็นต์เต็มรูปแบบภายในไม่กี่วินาที

## What’s Next?

- **ปรับสไตล์ป้าย** – เปลี่ยนฟอนต์ สี หรือเพิ่มพื้นหลังด้วย `chart.DataLabel.Font`  
- **สร้างแผนภูมิตั้งแต่ต้น** – สำรวจ `Chart chart = (Chart)sourceDoc.FirstSection.Body.AppendChild(new Shape(sourceDoc, ShapeType.Chart));` เพื่อสร้างแผนภูมิด้วยโค้ด  
- **รวมหลายแผนภูมิ** ในเอกสารเดียวเพื่อทำแดชบอร์ด แล้วส่งออกเป็น PDF ด้วย `sourceDoc.Save("Dashboard.pdf", SaveFormat.Pdf);`

ทดลองใช้งานได้ตามใจ หากเจอปัญหาใด ๆ อย่าลังเลที่จะแสดงความคิดเห็น Happy charting!
