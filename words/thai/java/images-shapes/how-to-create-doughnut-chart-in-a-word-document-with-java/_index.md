# วิธีสร้างแผนภูมโดนัทในเอกสาร Word ด้วย Java

หากคุณต้องการ **create doughnut chart** ภายในไฟล์ Word, บทแนะนำนี้จะแสดงวิธีแก้ไขที่สมบูรณ์และพร้อมรัน คุณจะได้เห็นวิธี **insert pie chart**, แปลงเป็นโดนัท, **rotate pie chart** เพื่อความสมดุลที่ดียิ่งขึ้น, และ **format pie chart** ให้สอดคล้องกับแบรนด์ของคุณ เมื่อเสร็จคุณจะมีเอกสาร Word ระดับมืออาชีพที่สามารถใช้ในรายงาน, แดชบอร์ด หรือแนบอีเมลอัตโนมัติได้

การสร้างแผนภูมิด้วยโปรแกรมช่วยขจัดขั้นตอนคัดลอก‑วางด้วยมือและรับประกันการจัดรูปแบบที่สม่ำเสมอในหลายสิบเอกสารที่สร้างขึ้น ตัวอย่างใช้ไลบรารี Aspose.Words for Java ซึ่งทำงานกับ Java 8+ และไม่ต้องติดตั้ง Microsoft Office ไม่จำเป็นต้องมีเงื่อนไขอื่นใดนอกจาก JDK มาตรฐานและ IDE ที่คุณชื่นชอบ

## ข้อกำหนดเบื้องต้น

- Java Development Kit (JDK) 8 หรือใหม่กว่า  
- Maven หรือ Gradle สำหรับการจัดการ dependencies (บทแนะนำใช้ Maven)  
- ไลบรารี Aspose.Words for Java (ไลเซนส์ทดลองฟรีเพียงพอสำหรับการทดสอบ)  

เพิ่ม dependency ของ Aspose.Words ลงใน `pom.xml` ของคุณ:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-words</artifactId>
    <version>24.9</version> <!-- Use the latest stable version -->
</dependency>
```

> **Pro tip:** ลงทะเบียนไลเซนส์ของคุณด้วย `License license = new License(); license.setLicense("Aspose.Words.lic");` ก่อนสร้างเอกสารใด ๆ เพื่อเอาน้ำลายน้ำการประเมินผลออก

## สร้างแผนภูมโดนัทในเอกสาร Word

กระบวนการทำงานหลักประกอบด้วยห้าขั้นตอนเชิงตรรกะ แต่ละขั้นตอนถูกห่อหุ้มในเมธอดของตนเองเพื่อให้โค้ดสะอาดและนำกลับมาใช้ใหม่ได้

```java
import com.aspose.words.*;
import com.aspose.words.drawing.*;

public class DoughnutChartDemo {

    public static void main(String[] args) throws Exception {
        // Step 1: create blank Word document
        Document doc = createBlankWordDocument();

        // Step 2: insert a pie chart (base for the doughnut)
        Chart chart = insertPieChart(doc, 400, 300);

        // Step 3: convert the pie chart into a doughnut and rotate it
        customizeChartAppearance(chart);

        // Step 4: apply additional formatting to the chart
        formatPieChart(chart);

        // Step 5: save the final document
        doc.save("output/DoughnutChartFormatted.docx");
        System.out.println("Document saved successfully.");
    }

    /** Step 1 – create blank Word document */
    private static Document createBlankWordDocument() {
        // Aspose.Words creates an empty document by default
        return new Document();
    }

    /** Step 2 – insert pie chart with given dimensions */
    private static Chart insertPieChart(Document doc, int width, int height) throws Exception {
        DocumentBuilder builder = new DocumentBuilder(doc);
        // ChartType.PIE creates a standard pie chart that we will later turn into a doughnut
        Chart chart = builder.insertChart(ChartType.PIE, width, height);
        // Populate the chart with sample data
        chart.getSeries().clear(); // Remove default series
        ChartSeries series = chart.getSeries().add("Sales", new String[]{"Q1", "Q2", "Q3", "Q4"},
                new double[]{15000, 23000, 18000, 27000});
        return chart;
    }

    /** Step 3 – rotate pie chart and make it a doughnut */
    private static void customizeChartAppearance(Chart chart) {
        // Explode the first slice for emphasis
        chart.getSeries().get(0).setExplode(20);
        // Convert the pie into a doughnut by setting a hole size (percentage of radius)
        chart.setHoleSize(30); // 30% hole creates a classic doughnut look
        // Rotate the chart so the largest slice starts at 45°
        chart.setRotationAngle(45);
    }

    /** Step 4 – additional formatting of the pie chart */
    private static void formatPieChart(Chart chart) {
        // Example: change the first slice color to a brand color
        chart.getSeries().get(0).getPoints().get(0).getFormat().setFillForegroundColor(Color.fromArgb(0xFF, 0x4A, 0x90));
        // Add a legend and position it at the bottom
        chart.setHasLegend(true);
        chart.getLegend().setPosition(LegendPosition.BOTTOM);
        // Set a title for the chart
        chart.setTitle("Quarterly Sales Distribution");
    }
}
```

### สิ่งที่โค้ดทำ

| ขั้นตอน | การกระทำ | เหตุผล |
|------|--------|--------|
| **Create blank Word document** | `new Document()` | เริ่มด้วยไฟล์เปล่าที่สะอาดเพื่อให้คุณควบคุมทุกองค์ประกอบ |
| **Insert pie chart** | `builder.insertChart(ChartType.PIE, …)` | แผนภูมิพายเป็นรูปแบบพื้นฐาน; Aspose ให้แผนภูมโดนัทโดยการปรับขนาดรู |
| **Rotate pie chart** | `chart.setRotationAngle(45)` | การหมุนทำให้ส่วนที่ใหญ่ที่สุดอยู่ในตำแหน่งที่อ่านง่ายขึ้น |
| **Format pie chart** | `setExplode`, `setHoleSize`, color, legend | ปรับปรุงลำดับชั้นการมองเห็นและสอดคล้องกับแนวทางสไตล์ขององค์กร |
| **Save document** | `doc.save("…/DoughnutChartFormatted.docx")` | เขียนไฟล์ .docx สุดท้ายลงดิสก์ พร้อมสำหรับการแจกจ่าย |

## แทรกแผนภูมพายก่อนแปลงเป็นโดนัท

Aspose.Words ไม่ได้มีเมธอด “insert doughnut chart” โดยตรง แต่คุณต้อง **insert pie chart** แล้วจึงแก้ไขคุณสมบัติต่าง ๆ วิธีการสองขั้นตอนนี้ให้คุณควบคุม series ของข้อมูล, การ explode ของส่วน, และขนาดรูได้อย่างเต็มที่ หากคุณต้องการแผนภูมพายบริสุทธิ์ในที่อื่น เพียงละเว้นการเรียก `setHoleSize`

## หมุนแผนภูมพายเพื่อความสมดุลของภาพ

การวางตำแหน่งเริ่มต้นจะให้ส่วนแรกเริ่มที่ตำแหน่ง 12 นาฬิกา ในหลายรายงานธุรกิจ ส่วนที่สำคัญที่สุดควรเริ่มที่มุมที่เป็นธรรมชาติมากขึ้น เช่น 45 องศา เมธอด `setRotationAngle(double angle)` รับค่ามุมเป็นองศาและหมุนแผนภูมทั้งหมดโดยไม่กระทบค่าข้อมูล

## จัดรูปแบบแผนภูมพายและปรับแต่งลักษณะ

นอกเหนือจากการแปลงเป็นโดนัท คุณมักต้องการ **format pie chart** ส่วนต่าง ๆ:

- **Explode** ส่วนแรก (`setExplode`) เพื่อดึงความสนใจ  
- **Color** แต่ละส่วนโดยใช้ `getPoints().get(i).getFormat().setFillForegroundColor`  
- **Legend** การวางตำแหน่ง (`setHasLegend`, `setPosition`) ช่วยผู้อ่านตีความหมวดหมู่  
- **Title** (`setTitle`) ให้บริบทอย่างรวดเร็ว  

การตั้งค่าทั้งหมดนี้เป็นทางเลือก; คุณสามารถปรับให้ตรงกับพาเลตสีของแบรนด์หรือเทมเพลตองค์กรของคุณ

## สร้างเอกสาร Word เปล่าและบันทึกผลลัพธ์

เมธอด `createBlankWordDocument` รวมขั้นตอน **create blank word document** ไว้ไว้ การแยกตรรกะนี้ทำให้การนำเมธอดไปใช้ซ้ำง่ายเมื่อสร้างหลายรายงานในกระบวนการเป็นชุด หลังจากปรับแต่งทั้งหมด `doc.save` จะเขียนไฟล์ในรูปแบบ Office Open XML มาตรฐาน (`.docx`) ซึ่งสามารถเปิดได้ใน Microsoft Word, LibreOffice หรือ Google Docs โดยไม่มีการสูญเสียความถูกต้อง

### ผลลัพธ์ที่คาดหวัง

เมื่อคุณรันเมธอด `main` คอนโซลจะพิมพ์:

```
Document saved successfully.
```

และไฟล์ `output/DoughnutChartFormatted.docx` จะมีหน้าเดียวพร้อมแผนภูมโดนัทที่มีชื่อ *Quarterly Sales Distribution* แผนภูมแสดงสี่ส่วน ส่วนแรกถูก explode, มีสีตามโทนแบรนด์, และหมุน 45 องศา

## ความแปรผันทั่วไปและกรณีขอบ

| สถานการณ์ | การปรับแต่ง |
|-----------|------------|
| **More than one data series** | เพิ่มอ็อบเจ็กต์ `ChartSeries` เพิ่มเติมใน `chart.getSeries()` |
| **Different chart size** | เปลี่ยนค่าอาร์กิวเมนต์ `width` และ `height` ใน `insertPieChart` |
| **No hole (pure pie)** | ละเว้น `chart.setHoleSize(…)` หรือกำหนดเป็น `0` |
| **Large documents** | ใช้ `DocumentBuilder` เพื่อแทรกแผนภูมิลงในส่วนหรือบุ๊กมาร์กที่กำหนด |
| **License not set** | ไลบรารีทำงานในโหมดประเมินผล เพิ่มน้ำลายน้ำในหน้าแรก ลงทะเบียนไลเซนส์เพื่อเอาออก |

## สรุป

ตอนนี้คุณรู้วิธี **create doughnut chart** ในเอกสาร Word ด้วย Java ตั้งแต่ **create blank word document** ไปจนถึง **insert pie chart**, **rotate pie chart**, และ **format pie chart** เพื่อให้ได้ผลิตภัณฑ์ขั้นสุดท้ายที่ดูดี ตัวอย่างที่สมบูรณ์และรันได้สามารถนำไปใส่ในโปรเจค Java ใด ๆ ที่ใช้ Aspose.Words อยู่แล้ว

ต่อไปคุณอาจสำรวจ:

- เพิ่ม data labels (`chart.getSeries().get(0).setDataLabelType(DataLabelType.CATEGORY_AND_PERCENT);`)  
- ส่งออกแผนภูมิเป็นภาพ (`chart.toImage`) เพื่อใช้ในอีเมล HTML  
- อัตโนมัติการสร้างเอกสารหลายไฟล์ในลูปสำหรับการรายงานเป็นชุด  

คุณสามารถทดลองกับสี, การ explode ของส่วน, และ legend เพื่อให้ตรงกับภาษาภาพขององค์กรของคุณได้เลย ขอให้สนุกกับการสร้างแผนภูมิ!
