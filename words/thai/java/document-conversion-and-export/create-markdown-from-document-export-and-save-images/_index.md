# วิธีแปลง docx เป็น markdown พร้อมรูปภาพในโฟลเดอร์ย่อย

หากคุณต้องการ **แปลง docx เป็น markdown** พร้อมจัดระเบียบรูปภาพที่ฝังอยู่ให้เป็นระเบียบเรียบร้อย คุณมาถูกที่แล้ว นักพัฒนาหลายคนสร้างรายงาน คู่มือ หรือร่างบล็อกโดยอัตโนมัติและจบลงด้วยไฟล์รูปภาพกระจัดกระจายอยู่ทั่วไดเรกทอรีผลลัพธ์ บทแนะนำนี้จะแสดงวิธีที่สะอาดและขับเคลื่อนด้วย callback โดยใช้ Aspose.Words for .NET ที่ส่งออกเอกสารเป็น markdown เก็บรูปแต่ละไฟล์ไว้ในโฟลเดอร์ *md‑resources* แยกจากกัน และบันทึกไฟล์ markdown สุดท้ายพร้อมพร้อมสำหรับการเผยแพร่

> **ภาพรวมอย่างรวดเร็ว:**  
> • ตั้งค่า `MarkdownSaveOptions`  
> • Implement `IResourceSavingCallback` เพื่อเปลี่ยนเส้นทางรูปภาพ  
> • เรียก `Document.Save` พร้อมตัวเลือกที่กำหนดค่าแล้ว  

ตอนนี้คุณเข้าใจแล้วว่าทำไมการใช้ callback จึงดีกว่าการประมวลผลหลังจากบันทึก มาเริ่มทำตามขั้นตอนทีละขั้นตอนกันเลย

## คำตอบสั้น ๆ
- **“แปลง docx เป็น markdown” ทำอะไรจริง ๆ?** มันแปลงมาร์กอัปการประมวลผลคำเป็นข้อความ markdown ธรรมดา พร้อมคงหัวเรื่อง รายการ ตาราง และการอ้างอิงรูปภาพไว้  
- **ไลบรารีใดรับหน้าที่แปลง?** Aspose.Words for .NET ให้ API ที่จัดการทั้งหมดบนเซิร์ฟเวอร์โดยไม่ต้องติดตั้ง Microsoft Word  
- **ต้องเขียนโค้ดประมวลผลรูปภาพหรือไม่?** ไม่ต้อง; `IResourceSavingCallback` จะดูแลการบันทึกรูปแต่ละไฟล์ลงในโฟลเดอร์ที่คุณระบุ  
- **สามารถเปลี่ยนชื่อโฟลเดอร์ผลลัพธ์ได้หรือไม่?** แน่นอน – แทนที่ `"md-resources/"` ด้วยเส้นทางสัมพัทธ์หรือเต็มที่คุณต้องการ  
- **โซลูชันนี้เข้ากันได้กับ .NET 6 ขึ้นไปหรือไม่?** ใช่, ทำงานบน .NET 6+, .NET 5, .NET Core 3.1 และ .NET Framework 4.7+

## Convert docx to markdown คืออะไร?
**Convert docx to markdown** คือกระบวนการนำเอกสาร Microsoft Word (DOCX) มาสร้างไฟล์ markdown (`.md`) ที่แสดงเนื้อหาเดียวกันโดยใช้ไวยากรณ์ markdown การแปลงจะคงองค์ประกอบโครงสร้างและอาจดึงทรัพยากรที่ฝังอยู่เช่นรูปภาพออกมา

การแปลงทำโดย Aspose.Words, ไลบรารีที่รองรับ **35+ รูปแบบการนำเข้าและส่งออก** — รวมถึง DOCX, PDF, HTML, และ Markdown — ทำให้คุณจัดการเอกสารหลายร้อยหน้าโดยไม่ต้องโหลดไฟล์ทั้งหมดเข้าสู่หน่วยความจำ

## วิธีแปลง docx เป็น markdown?

โหลดเอกสารต้นฉบับด้วย `new Document("source.docx")`, ตั้งค่า `MarkdownSaveOptions` ให้ใช้ callback ที่บันทึกรูปแต่ละไฟล์ลงใน `md-resources/`, แล้วเรียก `doc.Save("output.md", saveOptions)` ขั้นตอนสามขั้นตอนนี้จะแปลงไฟล์, แยกรูปภาพ, และสร้างไฟล์ markdown ที่สะอาดพร้อมลิงก์รูปแบบสัมพัทธ์ — ทั้งหมดในคำเรียกเดียว

### ขั้นตอนที่ 1: ตั้งค่าตัวเลือกการบันทึกสำหรับการแปลงเป็น markdown

MarkdownSaveOptions กำหนดวิธีที่ Aspose.Words แปลงเอกสารเป็น Markdown

```csharp
// Step 1: Initialize Markdown save options
var markdownSaveOptions = new Aspose.Words.Saving.MarkdownSaveOptions();
```

```csharp
// Step 1: Initialize Markdown save options
var markdownSaveOptions = new Aspose.Words.Saving.MarkdownSaveOptions();
```

> **ทำไมเรื่องนี้สำคัญ:**  
> หากไม่ได้สร้าง `MarkdownSaveOptions` อย่างชัดเจน ไลบรารีจะใช้ค่าตั้งต้นที่ฝังรูปภาพลงในไฟล์ Markdown เป็นสตริง Base64 ทำให้ไฟล์ใหญ่มากและทำลายจุดประสงค์ของการมีโฟลเดอร์ *images* ที่แยกออกมา

### ขั้นตอนที่ 2: กำหนด callback การบันทึกทรัพยากรเพื่อส่งออกรูปภาพ

`IResourceSavingCallback` ให้คุณควบคุมว่าทรัพยากรแต่ละอัน (รูป, SVG) จะบันทึกที่ไหนระหว่างการส่งออก

ตอนนี้เราบอก saver **ว่าจะเก็บรูปภาพไว้ที่ไหน** อินเทอร์เฟซ `IResourceSavingCallback` ให้ hook ที่ทำงานสำหรับทุกทรัพยากร (รูป, SVG ฯลฯ) ที่พบระหว่างการส่งออก ภายใน callback เรา:

1. ตรวจสอบให้แน่ใจว่าโฟลเดอร์เป้าหมายมีอยู่ (`md-resources/`)  
2. ตั้งค่า `OutputFileName` ให้เป็นโฟลเดอร์บวกกับชื่อทรัพยากรต้นฉบับ  

```csharp
// Step 2: Hook into the resource‑saving pipeline
markdownSaveOptions.ResourceSavingCallback = new Aspose.Words.Saving.IResourceSavingCallback(
    (args) =>
    {
        // All images will be placed in "md-resources" relative to the output .md file
        const string folder = "md-resources/";
        Directory.CreateDirectory(folder);          // Create folder if it doesn’t exist

        // Preserve the original file name (e.g., image001.png) but prepend the folder path
        args.OutputFileName = Path.Combine(folder, args.ResourceFileName);

        // Optional: you could also change the format here (e.g., convert BMP to PNG)
        // args.ResourceFileName = Path.ChangeExtension(args.ResourceFileName, ".png");
    });
```

> **คำถามทั่วไป:** *ถ้าต้องการฝังรูปภาพแทนการบันทึกล่ะ?*  
> เพียงข้าม callback หรือกำหนด `args.OutputFileName = null;` — saver จะฝังรูปภาพเป็นสตริง Base64 โดยอัตโนมัติ

> **กรณีขอบ:** เอกสารบางฉบับเก่าอาจมีชื่อรูปซ้ำกัน Callback ด้านบนจะเขียนทับไฟล์ก่อนหน้า เพื่อหลีกเลี่ยง ให้เพิ่ม GUID:

```csharp
args.OutputFileName = Path.Combine(folder,
    $"{Path.GetFileNameWithoutExtension(args.ResourceFileName)}_{Guid.NewGuid()}{Path.GetExtension(args.ResourceFileName)}");
```

### ขั้นตอนที่ 3: บันทึกเอกสารเป็น markdown และตรวจสอบผลลัพธ์

เมื่อกำหนดตัวเลือกครบถ้วน คำเรียกสุดท้ายคือบรรทัดเดียวที่เขียนไฟล์ Markdown และรูปภาพที่เกี่ยวข้องลงดิสก์

```csharp
// Step 3: Perform the actual export
string outputPath = @"C:\Exports\MyReport.md";
doc.Save(outputPath, markdownSaveOptions);
```

หากทุกอย่างทำงานได้ตามปกติ คุณจะเห็น:

- `MyReport.md` – การแสดงผล Markdown ของเอกสารต้นฉบับของคุณ  
- `md-resources/` – โฟลเดอร์ข้างไฟล์ `.md` ที่บรรจุรูปภาพที่แยกออกมา (เช่น `image001.png`, `image002.jpg`)  

**ตัวอย่างส่วนของ markdown** (สร้างโดยอัตโนมัติจาก Aspose.Words):

```markdown
# Sample Report

Here is an introductory paragraph.

![Sample image](md-resources/image001.png)

More text follows...
```

[Sample image](md-resources/image001.png)

> **เคล็ดลับ:** เปิดไฟล์ `.md` ที่สร้างใน VS Code หรือโปรแกรมดูตัวอย่าง Markdown ใด ๆ; รูปภาพควรแสดงทันทีเพราะเส้นทางสัมพัทธ์ตรงกับโครงสร้างโฟลเดอร์

## ตัวอย่างเต็มที่สามารถรันได้ (ไม่มีบล็อกโค้ดเพิ่มเติม)

ด้านล่างเป็นโปรแกรมคอนโซลที่สมบูรณ์ คุณสามารถคัดลอกไปวางในโปรเจกต์ .NET ใหม่และรันได้ มันสร้างเอกสาร Word ง่าย ๆ เพิ่มรูปภาพ แล้ว **สร้าง markdown จากเอกสาร** พร้อมเก็บรูปในโฟลเดอร์ย่อย

```csharp
using System;
using System.IO;
using Aspose.Words;
using Aspose.Words.Saving;

class Program
{
    static void Main()
    {
        // 1️⃣ Create a sample Word document with an image
        var doc = new Document();
        var builder = new DocumentBuilder(doc);
        builder.Writeln("Hello, this is a test document.");
        builder.InsertImage("sample-image.png"); // Ensure this file exists next to exe

        // 2️⃣ Configure markdown export options (see Step 1 & 2 above)
        var markdownOptions = new MarkdownSaveOptions();
        markdownOptions.ResourceSavingCallback = new IResourceSavingCallback(
            (args) =>
            {
                const string folder = "md-resources/";
                Directory.CreateDirectory(folder);
                args.OutputFileName = Path.Combine(folder, args.ResourceFileName);
            });

        // 3️⃣ Save as markdown (Step 3)
        string outputFolder = Path.Combine(Environment.CurrentDirectory, "output");
        Directory.CreateDirectory(outputFolder);
        string markdownPath = Path.Combine(outputFolder, "ExportedDoc.md");
        doc.Save(markdownPath, markdownOptions);

        Console.WriteLine($"✅ Markdown saved to: {markdownPath}");
        Console.WriteLine("📂 Images saved in: md-resources/");
    }
}
```

**สิ่งที่คุณควรเห็น** หลังจากรัน:

```
✅ Markdown saved to: C:\MyProject\output\ExportedDoc.md
📂 Images saved in: md-resources/
```

เปิด `ExportedDoc.md` – การอ้างอิงรูปภาพจะชี้ไปที่ `md-resources/sample-image.png` และรูปจะปรากฏอย่างถูกต้องในโปรแกรมดู Markdown ใด ๆ

## ปัญหาที่พบบ่อยและวิธีแก้

- **รูปภาพไม่แสดงในตัวอย่าง markdown** – ตรวจสอบว่าเส้นทางสัมพัทธ์ใน markdown (`md-resources/image001.png`) ตรงกับตำแหน่งโฟลเดอร์จริงที่สัมพันธ์กับไฟล์ `.md`  
- **ชื่อรูปซ้ำทำให้ไฟล์ถูกเขียนทับ** – เพิ่มตัวระบุที่ไม่ซ้ำ (GUID หรือเลขลำดับ) ภายใน callback เพื่อให้ชื่อไฟล์เป็นเอกลักษณ์  
- **เอกสารขนาดใหญ่ทำให้หน่วยความจำอัด** – ใช้ `Document.OptimizeResources()` ก่อนบันทึก; จะลดการใช้หน่วยความจำโดยการปล่อยสตรีมที่ไม่ใช้แล้ว  
- **รูปแบบไฟล์ที่ไม่รองรับ** – Aspose.Words รองรับ PNG, JPEG, BMP, GIF, และ TIFF. แปลงรูปแบบที่ไม่รองรับเป็นหนึ่งในเหล่านี้ก่อนเพิ่มลงในเอกสารต้นฉบับ  

## คำถามที่พบบ่อย

**ถาม: สามารถใช้วิธีนี้ใน ASP .NET Web API ที่ส่งคืนไฟล์ ZIP ได้หรือไม่?**  
ตอบ: ได้. สร้าง markdown และรูปภาพในโฟลเดอร์ชั่วคราว, เพิ่มเข้า `ZipArchive`, แล้วสตรีม ZIP กลับไปยังไคลเอนต์. `MarkdownSaveOptions` และ callback ทำงานเช่นเดิม

**ถาม: การแปลงคงสไตล์ Word เช่นหัวเรื่องและตารางหรือไม่?**  
ตอบ: แน่นอน. Aspose.Words แปลงสไตล์หัวเรื่อง Word ไปเป็นหัวเรื่อง markdown `#` และแปลงตารางเป็นไวยากรณ์ pipe ของ markdown, คงเนื้อหาและการจัดแนวของเซลล์ไว้

**ถาม: ต้องมีลิขสิทธิ์เชิงพาณิชย์สำหรับการใช้งานในโปรดักชันหรือไม่?**  
ตอบ: ใช่. มีลิขสิทธิ์ทดลองฟรีสำหรับการทดสอบ, แต่การใช้งานในโปรดักชันต้องซื้อใบอนุญาต Aspose.Words

**ถาม: ไลบรารีจัดการกับเอกสารที่มีรหัสผ่านอย่างไร?**  
ตอบ: โหลดเอกสารด้วย `new Document("file.docx", new LoadOptions { Password = "yourPassword" })` ก่อนเรียกใช้ฟังก์ชันบันทึก markdown

**ถาม: .NET เวอร์ชันใดที่รองรับอย่างเป็นทางการ?**  
ตอบ: Aspose.Words รองรับ .NET Framework 4.7+, .NET Core 3.1+, .NET 5, .NET 6 และเวอร์ชันต่อไป

## สรุป

เราได้สาธิต **วิธีแปลง docx เป็น markdown**, **ส่งออกเอกสารเป็น markdown**, และ **บันทึกรูปภาพลงโฟลเดอร์ย่อย** ด้วยรูปแบบที่สะอาดและขับเคลื่อนด้วย callback ประเด็นสำคัญคือ:

- ใช้ `MarkdownSaveOptions` เพื่อควบคุมอย่างละเอียด  
- Implement `IResourceSavingCallback` เพื่อบันทึกรูปภาพลงในโฟลเดอร์เฉพาะ, ทำให้ markdown ของคุณเป็นระเบียบ  
- เทคนิคเดียวกันใช้ได้กับประเภททรัพยากรอื่น (SVG, audio) โดยตรวจสอบ `args.ResourceType`

ขั้นตอนต่อไปอาจรวมถึงการปรับสไตล์หัวเรื่อง, ผสานกระบวนการนี้เข้ากับ CI pipeline, หรือเปิดให้เป็น microservice ที่ส่งคืน ZIP ที่มี markdown และทรัพยากรของมัน. ตอนนี้คุณมีอุปกรณ์พื้นฐานแล้ว, สามารถทำอัตโนมัติการแปลงเอกสารเป็น markdown ได้อย่างมั่นใจ

มีคำถามเพิ่มเติมหรือพบกรณีที่เราไม่ได้ครอบคลุม? แสดงความคิดเห็นด้านล่าง, และขอให้สนุกกับการเขียนโค้ด!
