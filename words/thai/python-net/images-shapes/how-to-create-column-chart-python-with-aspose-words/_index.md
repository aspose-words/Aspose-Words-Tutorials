# วิธีสร้างแผนภูมิคอลัมน์ใน Python ด้วย Aspose.Words

หากคุณต้องการสร้างแผนภูมิคอลัมน์ใน Python คู่มือนี้จะแสดงโค้ดและเหตุผลที่คุณต้องการอย่างครบถ้วน โดยใช้ Aspose.Words chart API คุณสามารถกำหนดขนาดที่แม่นยำ ใช้สไตล์ที่มีให้ในตัว และส่งออกผลลัพธ์ได้โดยไม่ต้องออกจาก Python

การสร้างแผนภูมิคอลัมน์เป็นความต้องการทั่วไปสำหรับรายงาน แดชบอร์ด และการสร้างเอกสารอัตโนมัติ บทเรียนนี้ครอบคลุมทุกขั้นตอน ตั้งแต่การนำเข้าไลบรารีจนถึงการตรวจสอบภาพที่บันทึกไว้ เพื่อให้คุณสามารถรวมการสร้างแผนภูมิลงในโครงการ Python ใดก็ได้

## ข้อกำหนดเบื้องต้น

ก่อนเริ่มทำงาน ตรวจสอบให้แน่ใจว่าคุณมี:

* Python 3.8 หรือใหม่กว่า
* ใบอนุญาต Aspose.Words for Python ที่ถูกต้อง (หรือคีย์ทดลองฟรี)
* ความคุ้นเคยพื้นฐานกับโมดูลของ Python และโค้ดแบบวัตถุ (object‑oriented)

เครื่องมือสร้างแผนภูมิของ Aspose.Words ทำงานบน Windows, macOS และ Linux และไม่ต้องการไลบรารีกราฟิกเพิ่มเติม เนื่องจากการเรนเดอร์เกิดขึ้นบนเซิร์ฟเวอร์

## ขั้นตอนที่ 1: นำเข้าไลบรารี Aspose.Words

ขั้นตอนแรกคือการนำเข้าแพ็กเกจ `aspose.words` และตั้งนามแฝงสั้น ๆ การนำเข้าที่ส่วนบนของไฟล์ช่วยให้เนมสเปซเป็นระเบียบและทำให้โค้ดอ่านง่ายขึ้น

```python
# Step 1: Import the Aspose.Words library
import aspose.words as aw
```

ตอนนี้ `aw` จะอ้างอิงไปยัง API ของ Aspose.Words ทั้งหมด รวมถึงคลาส `Chart` ที่คุณจะใช้สร้างแผนภูมิคอลัมน์

## ขั้นตอนที่ 2: สร้างแผนภูมิคอลัมน์ด้วยขนาดที่ต้องการ

แผนภูมิคอลัมน์ต้องการค่าความกว้างและความสูงที่ชัดเจนเพื่อให้ภาพที่เรนเดอร์พอดีกับเลย์เอาต์ของเอกสาร ตัวสร้าง `Chart` รับอาร์กิวเมนต์สามค่า: ประเภทแผนภูมิ, ความกว้าง (หน่วย points) และความสูง (หน่วย points) การใช้ `aw.ChartType.COLUMN` บอกให้เอนจินสร้างแผนภูมิกลับแนวตั้ง

```python
# Step 2: Create a column chart with the desired dimensions
chart = aw.Chart(aw.ChartType.COLUMN, 400, 300)   # width=400pt, height=300pt
```

*ทำไมต้องกำหนดขนาด?*  
เมื่อคุณฝังแผนภูมิในเอกสาร Word หรือส่งออกเป็นภาพ เนื้อหาที่ล้อมรอบจะเคารพขนาดที่คุณระบุ ซึ่งช่วยป้องกันการสเกลหรือการคลิปที่ไม่ต้องการ

### เคล็ดลับพิเศษ: ใช้ `chart.dimensions` สำหรับการปรับขนาดแบบไดนามิก

หากชุดข้อมูลของคุณเปลี่ยนแปลง คุณสามารถคำนวณขนาดตามจำนวนซีรีส์ได้ดังนี้

```python
series_count = 5
base_width = 80
chart.width = base_width * series_count
chart.height = 300
```

## ขั้นตอนที่ 3: ใช้สไตล์ที่มีให้ในตัวกับแผนภูมิคอลัมน์

Aspose.Words มาพร้อมธีมภาพลักษณ์ที่กำหนดไว้ล่วงหน้า การเลือกสไตล์ช่วยลดความจำเป็นในการกำหนดสี ฟอนต์ และเส้นกริดด้วยตนเอง `aw.ChartStyle.STYLE_5` ให้ลุคที่สะอาดและเป็นมืออาชีพ เหมาะกับรายงานธุรกิจส่วนใหญ่

```python
# Step 3: Apply a built‑in style to the chart
chart.style = aw.ChartStyle.STYLE_5
```

หากต้องการลุคที่แตกต่าง ให้เปลี่ยน `STYLE_5` เป็นค่าคงที่อื่น (`STYLE_1` … `STYLE_8`) แต่ละสไตล์ใช้ชื่อเดียวกัน ทำให้ทดลองได้ง่าย

### กรณีขอบ: ค่าคงที่สไตล์ไม่ถูกต้อง

การพยายามกำหนดสไตล์ที่ไม่มีอยู่จะทำให้เกิด `AttributeError` ป้องกันโดยตรวจสอบค่าคงที่กับ enumeration ก่อนใช้งาน

```python
if hasattr(aw.ChartStyle, "STYLE_5"):
    chart.style = aw.ChartStyle.STYLE_5
else:
    raise ValueError("Requested chart style does not exist.")
```

## ขั้นตอนที่ 4: เพิ่มชุดข้อมูลลงในแผนภูมิคอลัมน์

แผนภูมิที่ไม่มีข้อมูลไม่มีความหมาย คุณสามารถเพิ่มอ็อบเจ็กต์ `ChartSeries` หนึ่งหรือหลายอ็อบเจ็กต์ ซึ่งแต่ละอ็อบเจ็กต์แทนกลุ่มคอลัมน์ ตัวอย่างต่อไปนี้เพิ่มซีรีส์เดียวที่มีจุดข้อมูลสามค่า

```python
# Step 4: Add data series to the column chart
series = chart.series.add()
series.name = "Quarterly Sales"
series.data = [12000, 15000, 18000]   # Values for Q1, Q2, Q3
```

คุณสามารถเรียก `chart.series.add()` ซ้ำเพื่อเพิ่มซีรีส์อื่น (เช่น “Projected Sales”) API จะจัดคอลัมน์ให้เรียงข้างกันโดยอัตโนมัติ

## ขั้นตอนที่ 5: เรนเดอร์แผนภูมิและบันทึกเป็นภาพ

หลังจากตั้งค่าแผนภูมิแล้ว ให้เรนเดอร์เป็นบิตแมพหรือไฟล์ภาพ วิธี `save` รับพาธไฟล์และรูปแบบที่เป็นตัวเลือก PNG เป็นรูปแบบที่ไม่มีการสูญเสียคุณภาพและได้รับการสนับสนุนอย่างกว้างขวาง

```python
# Step 5: Render and save the chart as a PNG image
output_path = "column_chart.png"
chart.save(output_path, aw.SaveFormat.PNG)
print(f"Chart saved to {output_path}")
```

enumeration `SaveFormat` มี PNG, JPEG, BMP และอื่น ๆ ให้เลือกใช้รูปแบบที่สอดคล้องกับกระบวนการทำงานต่อของคุณ

## ตรวจสอบผลลัพธ์

![Column chart generated by Aspose.Words in Python](column_chart.png){: .center alt="ภาพหน้าจอของแผนภูมิคอลัมน์ที่สร้างโดย Aspose.Words ใน Python"}

หากภาพปรากฏเป็นสีขาวหรือบิดเบี้ยว ให้ตรวจสอบสิ่งต่อไปนี้:

1. วัตถุ `aw.Chart` ถูกสร้างก่อนเพิ่มซีรีส์หรือไม่
2. ค่าคงที่ `chart.style` ตรงกับค่าใน enum ที่มีอยู่หรือไม่
3. การเรียก `save` ใช้ `SaveFormat` ที่รองรับหรือไม่

## ความแปรผันทั่วไปและเคล็ดลับเพิ่มเติม

| สถานการณ์ | การเปลี่ยนแปลงที่แนะนำ |
|-----------|--------------------|
| **หลายชุดข้อมูล** | เพิ่มบล็อก `chart.series.add()` เพิ่มเติมและกำหนด `series.name` กับ `series.data` สำหรับแต่ละชุด |
| **สีที่กำหนดเอง** | หลังจากใช้สไตล์ในตัวแล้ว ให้เขียนทับสีคอลัมน์แต่ละคอลัมน์ผ่าน `series.points[i].fill.fore_color` |
| **ฝังในเอกสาร Word** | แทนการใช้ `chart.save()` ให้ใช้ `doc = aw.Document(); doc.sections[0].body.append_child(chart); doc.save("report.docx")` |
| **การปรับขนาดแบบไดนามิก** | คำนวณความกว้างตามจำนวนซีรีส์ (`width = 80 * len(chart.series)`) |

ความแปรผันเหล่านี้แสดงให้เห็นว่าโค้ดหลักเดียวกันสามารถปรับใช้กับสถานการณ์การรายงานที่แตกต่างกันได้อย่างไร
