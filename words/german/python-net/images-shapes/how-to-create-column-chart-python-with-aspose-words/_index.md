# Wie man ein Säulendiagramm in Python mit Aspose.Words erstellt

Wenn Sie ein Säulendiagramm in Python erstellen müssen, zeigt Ihnen diese Anleitung den genauen Code und die erforderliche Logik. Mit der Aspose.Words Chart‑API können Sie präzise Abmessungen festlegen, einen integrierten Stil anwenden und das Ergebnis exportieren, ohne Python zu verlassen.

Das Erzeugen eines Säulendiagramms ist eine häufige Anforderung für Berichte, Dashboards und die automatisierte Dokumentenerstellung. Dieses Tutorial behandelt jeden Schritt – vom Importieren der Bibliothek bis zur Überprüfung des gespeicherten Bildes – sodass Sie die Diagrammerstellung in jedes Python‑Projekt integrieren können.

## Voraussetzungen

* Python 3.8 oder neuer installiert.
* Eine gültige Aspose.Words‑Lizenz für Python (oder ein kostenloser Evaluierungsschlüssel).
* Grundlegende Kenntnisse von Python‑Modulen und objektorientiertem Code.

Die Aspose.Words‑Chart‑Engine funktioniert unter Windows, macOS und Linux und erfordert keine zusätzlichen Grafikbibliotheken, da das Rendering serverseitig erfolgt.

## Schritt 1: Importieren der Aspose.Words‑Bibliothek

Der erste Schritt besteht darin, das Paket `aspose.words` zu importieren und ihm einen kurzen Alias zu geben. Das Importieren am Anfang der Datei hält den Namensraum übersichtlich und macht den Code leichter lesbar.

```python
# Step 1: Import the Aspose.Words library
import aspose.words as aw
```

`aw` verweist nun auf die vollständige Aspose.Words‑API, einschließlich der `Chart`‑Klasse, die Sie zum Erstellen des Säulendiagramms verwenden werden.

## Schritt 2: Erstellen eines Säulendiagramms mit den gewünschten Abmessungen

Ein Säulendiagramm benötigt explizite Breiten‑ und Höhenwerte, damit das gerenderte Bild in Ihr Dokumentlayout passt. Der `Chart`‑Konstruktor akzeptiert drei Argumente: den Diagrammtyp, die Breite (in Punkten) und die Höhe (in Punkten). Durch die Verwendung von `aw.ChartType.COLUMN` wird der Engine mitgeteilt, ein vertikales Balkendiagramm zu erzeugen.

```python
# Step 2: Create a column chart with the desired dimensions
chart = aw.Chart(aw.ChartType.COLUMN, 400, 300)   # width=400pt, height=300pt
```

*Warum Abmessungen festlegen?*  
Wenn Sie das Diagramm in ein Word‑Dokument einbetten oder als Bild exportieren, respektiert der umgebende Inhalt die exakt von Ihnen angegebene Größe. Dies verhindert unerwünschte Skalierung oder Abschneiden.

### Profi‑Tipp: Verwenden Sie `chart.dimensions` für dynamische Größenanpassung

Wenn sich Ihr Datensatz ändert, können Sie die Größe basierend auf der Anzahl der Serien berechnen:

```python
series_count = 5
base_width = 80
chart.width = base_width * series_count
chart.height = 300
```

## Schritt 3: Anwenden eines integrierten Stils auf das Säulendiagramm

Aspose.Words liefert mehrere vordefinierte visuelle Themen. Die Auswahl eines Stils eliminiert die Notwendigkeit, Farben, Schriftarten und Gitternetzlinien manuell zu konfigurieren. `aw.ChartStyle.STYLE_5` bietet ein klares, professionelles Aussehen, das für die meisten Geschäftsberichte geeignet ist.

```python
# Step 3: Apply a built‑in style to the chart
chart.style = aw.ChartStyle.STYLE_5
```

Wenn Sie ein anderes Aussehen bevorzugen, ersetzen Sie `STYLE_5` durch eine der anderen Konstanten (`STYLE_1` … `STYLE_8`). Jeder Stil folgt derselben Namenskonvention, was das Experimentieren erleichtert.

### Sonderfall: Ungültige Stilkonstante

Der Versuch, einen nicht existierenden Stil zuzuweisen, löst einen `AttributeError` aus. Schützen Sie sich davor, indem Sie die Konstante gegen die Aufzählung prüfen:

```python
if hasattr(aw.ChartStyle, "STYLE_5"):
    chart.style = aw.ChartStyle.STYLE_5
else:
    raise ValueError("Requested chart style does not exist.")
```

## Schritt 4: Hinzufügen von Datenserien zum Säulendiagramm

Ein Diagramm ohne Daten ist sinnlos. Sie können ein oder mehrere `ChartSeries`‑Objekte hinzufügen, von denen jedes eine Spaltengruppe darstellt. Das folgende Beispiel fügt eine einzelne Serie mit drei Datenpunkten hinzu.

```python
# Step 4: Add data series to the column chart
series = chart.series.add()
series.name = "Quarterly Sales"
series.data = [12000, 15000, 18000]   # Values for Q1, Q2, Q3
```

Sie können den Aufruf `chart.series.add()` wiederholen, um zusätzliche Serien hinzuzufügen (z. B. „Projected Sales“). Die API verteilt die Spalten automatisch nebeneinander.

## Schritt 5: Rendern des Diagramms und Speichern als Bild

Nachdem das Diagramm konfiguriert wurde, rendern Sie es zu einem Bitmap‑ oder Bilddatei. Die Methode `save` akzeptiert einen Dateipfad und ein optionales Format. PNG ist verlustfrei und weit verbreitet.

```python
# Step 5: Render and save the chart as a PNG image
output_path = "column_chart.png"
chart.save(output_path, aw.SaveFormat.PNG)
print(f"Chart saved to {output_path}")
```

Die Aufzählung `SaveFormat` enthält PNG, JPEG, BMP und weitere. Wählen Sie das Format, das zu Ihrem nachgelagerten Workflow passt.

## Ausgabe überprüfen

Öffnen Sie `column_chart.png` mit einem beliebigen Bildbetrachter. Sie sollten ein dreispaltiges Balkendiagramm sehen, das mit dem gewählten integrierten Theme gestaltet und exakt 400 × 300 Punkte groß ist.

![Column chart generated by Aspose.Words in Python](column_chart.png){: .center alt="Screenshot eines von Aspose.Words in Python erzeugten Säulendiagramms"}

Wenn das Bild leer oder verzerrt erscheint, überprüfen Sie Folgendes:

1. Das `aw.Chart`‑Objekt wurde vor dem Hinzufügen von Serien instanziiert.
2. Die Konstante `chart.style` entspricht einem vorhandenen Enum‑Wert.
3. Der Aufruf `save` verwendet ein unterstütztes `SaveFormat`.

## Häufige Variationen und zusätzliche Tipps

| Situation | Empfohlene Änderung |
|-----------|---------------------|
| **Mehrere Datenserien** | Weitere `chart.series.add()`‑Blöcke hinzufügen und für jede `series.name` sowie `series.data` festlegen. |
| **Benutzerdefinierte Farben** | Nach dem Anwenden eines integrierten Stils die einzelnen Spaltenfarben über `series.points[i].fill.fore_color` überschreiben. |
| **Einbetten in ein Word‑Dokument** | Statt `chart.save()` verwenden Sie `doc = aw.Document(); doc.sections[0].body.append_child(chart); doc.save("report.docx")`. |
| **Dynamische Größenanpassung** | Die Breite basierend auf der Anzahl der Serien berechnen (`width = 80 * len(chart.series)`). |

Diese Variationen zeigen, wie derselbe Kerncode sich an verschiedene Berichtsszenarien anpasst.
