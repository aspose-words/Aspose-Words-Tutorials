# Leeres Word‑Dokument erstellen und eine Ellipsenform in C# ausblenden

Wenn Sie ein **leeres Word‑Dokument** erstellen und anschließend ein grafisches Element ausblenden möchten, zeigt Ihnen diese Anleitung genau, wie Sie das mit C# erledigen. Sie sehen ein vollständiges, ausführbares Beispiel, das eine Ellipse einfügt, positioniert, als verborgen markiert und die Datei speichert – alles in wenigen Code‑Zeilen.

Das Tutorial deckt alles von der Projekt‑Einrichtung bis zum abschließenden Verifizierungsschritt ab. Am Ende können Sie eine Word‑Datei erzeugen, in der die Ellipse weder auf dem Bildschirm noch im Druck erscheint – praktisch zum Speichern von Metadaten, Lesezeichen oder anderen unsichtbaren Markern.

## Voraussetzungen

Bevor Sie beginnen, stellen Sie sicher, dass Sie Folgendes haben:

* .NET 6.0 SDK oder neuer installiert  
* Eine C#‑Entwicklungsumgebung (Visual Studio 2022, Rider oder VS Code)  
* Das **Aspose.Words for .NET** NuGet‑Paket (`Install-Package Aspose.Words`)  

Diese Werkzeuge stellen die Klassen `Document` und `DocumentBuilder` bereit, die im Code‑Beispiel verwendet werden.

## Schritt 1: Ein leeres Word‑Dokument erstellen

Der erste Vorgang erzeugt ein leeres `Document`‑Objekt und einen `DocumentBuilder`, mit dem Sie Inhalte hinzufügen können.

```csharp
using Aspose.Words;
using Aspose.Words.Drawing;

// Step 1: Initialize an empty document and a builder
Document doc = new Document();
DocumentBuilder builder = new DocumentBuilder(doc);
```

`Document` repräsentiert das gesamte `.docx`‑Paket, während `DocumentBuilder` eine fluente API zum Einfügen von Text, Formen und anderen Objekten bietet. Das Starten mit einem leeren Dokument gibt Ihnen die volle Kontrolle über jedes Element, das Sie hinzufügen.

## Schritt 2: Wie man eine Ellipse einfügt

Eine Ellipse ist eine Vektorform, die als Marker verwendet werden kann. Die Methode `InsertShape` benötigt den Formtyp sowie Breite und Höhe in Punkten.

```csharp
// Step 2: Insert an ellipse shape of the desired size (100 pt × 50 pt)
Shape ellipse = builder.InsertShape(ShapeType.Ellipse, 100, 50);
```

Die Ellipse wird auf der aktuellen Seite an der Cursor‑Position platziert. Sie können ihre Abmessungen ändern, indem Sie die numerischen Argumente anpassen.

## Schritt 3: Wie man die Form positioniert

Nach dem Einfügen können Sie die Form überall auf der Seite platzieren, indem Sie die Eigenschaften `Left` und `Top` setzen, die Punkte relativ zum Seitenrand verwenden.

```csharp
// Step 3: Position the shape on the page
ellipse.Left = 150; // distance from the left margin
ellipse.Top  = 100; // distance from the top margin
```

Diese Koordinaten positionieren die Ellipse etwa in der oberen Mitte einer Standard‑A4‑Seite. Passen Sie die Werte an Ihre Layout‑Anforderungen an.

## Schritt 4: Wie man die Form ausblendet

Ein verborgenes Objekt wird nicht angezeigt, wenn das Dokument geöffnet oder gedruckt wird. Das Setzen des Flags `Hidden` markiert die Form als **hidden object word**.

```csharp
// Step 4: Hide the shape so it never appears
ellipse.Hidden = true;
```

Word respektiert das Hidden‑Flag sowohl für die Bildschirmausgabe als auch für den Druck. Die Form bleibt Teil der Dokumentstruktur, sodass Sie sie später per Code abfragen oder ändern können.

## Schritt 5: Das Dokument speichern

Zum Schluss schreiben Sie das Dokument auf die Festplatte. Wählen Sie einen Ordner, in den Sie Schreibzugriff haben.

```csharp
// Step 5: Save the document to a .docx file
doc.Save(@"C:\Temp\HiddenEllipse.docx");
```

Die Datei `HiddenEllipse.docx` enthält nun eine leere Seite mit einer ausgeblendeten Ellipsenform.

## Verifizierung der ausgeblendeten Ellipse

Öffnen Sie die erzeugte Datei in Microsoft Word und aktivieren Sie die Option **Show hidden text** (Datei → Optionen → Anzeige). Sie sehen eine schwache Kontur der Ellipse. Wenn Sie die Option deaktivieren, verschwindet die Form vollständig, was bestätigt, dass `ellipse.Hidden = true` wie erwartet funktioniert.

## Häufige Varianten und Sonderfälle

| Situation | Empfohlene Anpassung |
|-----------|----------------------|
| **Andere Form** | Ersetzen Sie `ShapeType.Ellipse` durch `ShapeType.Rectangle`, `ShapeType.Arrow` usw. |
| **Mehrere ausgeblendete Objekte** | Wiederholen Sie die Schritte 2‑4 für jede Form; jede kann ihr eigenes `Hidden`‑Flag besitzen. |
| **Andere Seitengröße** | Setzen Sie `doc.FirstSection.PageSetup.PageWidth` und `PageHeight`, bevor Sie die Form einfügen. |
| **Bedingte Sichtbarkeit** | Verwenden Sie `Shape.Visible` zusammen mit `Hidden`, um die Sichtbarkeit zur Laufzeit per Code zu steuern. |

**Pro‑Tipp:** Speichern Sie Identifikationsdaten im `AlternativeText`‑Eigenschaft der Form. Auch wenn sie ausgeblendet ist, können Sie die Form später mit `doc.GetChildNodes(NodeType.Shape, true)` abrufen und nach diesem Text filtern.

## Vollständiger Quellcode

Nachfolgend finden Sie das komplette Programm, das Sie kopieren, einfügen und ausführen können.

```csharp
using System;
using Aspose.Words;
using Aspose.Words.Drawing;

namespace HiddenShapeDemo
{
    class Program
    {
        static void Main()
        {
            // Create a new blank document and a builder
            Document doc = new Document();
            DocumentBuilder builder = new DocumentBuilder(doc);

            // Insert an ellipse shape (100 pt × 50 pt)
            Shape ellipse = builder.InsertShape(ShapeType.Ellipse, 100, 50);

            // Position the shape on the page
            ellipse.Left = 150;
            ellipse.Top  = 100;

            // Hide the shape so it is invisible in the UI and on print
            ellipse.Hidden = true;

            // Optional: add a description for later retrieval
            ellipse.AlternativeText = "Hidden marker for internal processing";

            // Save the document
            string outputPath = @"C:\Temp\HiddenEllipse.docx";
            doc.Save(outputPath);

            Console.WriteLine($"Document saved to {outputPath}");
        }
    }
}
```

**Erwartete Ausgabe:** Die Konsole gibt den Speicherort aus, und die Datei `HiddenEllipse.docx` öffnet sich als leere Seite ohne sichtbare Grafiken, sofern ausgeblendete Objekte nicht angezeigt werden.

## Fazit

Sie wissen jetzt, wie Sie **ein leeres Word‑Dokument** programmgesteuert **eine Ellipse einfügen**, **die Form positionieren** und **die Form ausblenden** können, sodass sie sich wie ein **hidden object word** verhält. Diese Technik eignet sich ideal zum Einbetten unsichtbarer Marker, benutzerdefinierter Metadaten oder Platzhalter, die nachgelagerte Prozesse lesen können, ohne das visuelle Layout des Dokuments zu beeinflussen.

### Nächste Schritte

* Erkunden Sie weitere Formtypen (`ShapeType.Arrow`, `ShapeType.TextBox`), um unterschiedliche Marker einzubetten.  
* Kombinieren Sie ausgeblendete Formen mit benutzerdefinierten XML‑Teilen für umfangreichere Metadaten.  
* Integrieren Sie diesen Code in eine größere Automatisierungspipeline, die Berichte oder Verträge generiert.

Experimentieren Sie gern mit den Koordinaten, Abmessungen und dem Hidden‑Flag, um sie an Ihr konkretes Szenario anzupassen. Viel Spaß beim Coden!
