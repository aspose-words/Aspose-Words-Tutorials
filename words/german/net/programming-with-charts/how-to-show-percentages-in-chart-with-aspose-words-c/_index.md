# Wie man Prozentsätze in Diagrammen mit Aspose.Words C# anzeigt

Haben Sie sich jemals gefragt, **wie man Prozentsätze in Diagrammen** anzeigt, ohne sich mit komplexem Office‑Interop herumzuschlagen? Sie sind nicht allein – viele Entwickler stoßen an diese Grenze, wenn sie schnell und programmatisch Beschriftungen für ein Kreis‑ oder Donut‑Diagramm benötigen. Die gute Nachricht? Mit Aspose.Words für .NET können Sie diese Datenbeschriftungen in nur wenigen Zeilen aktivieren.

In diesem Tutorial behandeln wir außerdem **Datenbeschriftungen zu Kreisdiagrammen hinzufügen** und **wie man Diagrammbeschriftungen aktiviert**, sodass Ihre Visualisierungen sofort aussagekräftiger werden. Am Ende haben Sie ein einsatzbereites Word‑Dokument (`.docx`), das ein professionell aussehendes Kreisdiagramm mit Prozentsätzen, die außerhalb jedes Segments positioniert sind, anzeigt.

## Voraussetzungen

Bevor wir starten, stellen Sie sicher, dass Sie Folgendes haben:

- **Aspose.Words für .NET** (neueste Version, z. B. 24.9) über NuGet installiert.
- Eine **ChartTemplate.docx**‑Datei, die bereits ein Kreis‑ oder Donut‑Diagramm enthält.  
  *(Falls Sie keine haben, erstellen Sie ein einfaches Word‑Dokument, fügen Sie ein Kreisdiagramm ein und speichern Sie es als `ChartTemplate.docx`.)*
- .NET 6.0 oder höher und eine IDE Ihrer Wahl (Visual Studio, Rider, VS Code).

Keine zusätzlichen Abhängigkeiten sind nötig – Aspose.Words erledigt alles intern.

## Wie man Prozentsätze in Diagrammen anzeigt – Schritt für Schritt

Im Folgenden teilen wir den Vorgang in sechs klare Schritte auf. Jeder Schritt enthält den genauen C#‑Code, den Sie kopieren‑und‑einfügen können, plus eine kurze Erklärung, **warum** wir das tun.

### Schritt 1: Das Quell‑Dokument laden

```csharp
using Aspose.Words;
using Aspose.Words.Drawing.Charts;

// Load the .docx that already holds a chart.
Document sourceDoc = new Document("YOUR_DIRECTORY/ChartTemplate.docx");
```

*Warum?*  
`Document` ist der Einstiegspunkt für jede Word‑Manipulation. Durch das Laden der Vorlage erhalten wir Zugriff auf jeden Knoten – Formen, Tabellen, Text und natürlich das Diagramm, das wir ändern werden.

### Schritt 2: Die erste Diagramm‑Form holen

```csharp
// The chart lives inside a Shape node; retrieve it.
Chart chart = (Chart)sourceDoc.GetChild(NodeType.Shape, 0, true);
```

*Warum?*  
Aspose speichert Diagramme als `Shape`‑Objekte. `GetChild` durchläuft den Dokumentbaum und gibt die erste gefundene Form zurück, die in unserem Fall das zu bearbeitende Kreisdiagramm ist.

### Schritt 3: Den Diagrammtyp bestätigen

```csharp
if (chart.ChartType == ChartType.Pie || chart.ChartType == ChartType.Doughnut)
{
    // Inside this block we’ll enable the data labels.
}
else
{
    throw new InvalidOperationException("The chart is not a Pie or Doughnut type.");
}
```

*Warum?*  
Prozentsatz‑Beschriftungen machen nur bei runden Diagrammen Sinn. Diese Prüfung verhindert, dass wir versehentlich Einstellungen auf ein Balkendiagramm anwenden, bei dem `ShowPercentage` ignoriert würde.

### Schritt 4: Datenbeschriftungen aktivieren und Prozentsätze anzeigen

```csharp
// Turn on data labels for the chart.
chart.HasDataLabel = true;

// Show the percentage value for each slice.
chart.DataLabel.ShowPercentage = true;
```

*Warum?*  
`HasDataLabel` weist Aspose an, für jeden Datenpunkt eine Beschriftung zu rendern. Das Setzen von `ShowPercentage` sorgt dafür, dass der Beschriftungsinhalt den berechneten Anteil am Ganzen darstellt – genau das, was die Anforderung **add data labels to pie chart** verlangt.

### Schritt 5: Beschriftungen außerhalb der Segmente positionieren

```csharp
// Place the labels outside the pie slices for better readability.
chart.DataLabel.Position = ChartDataLabelPosition.OutSideEnd;
```

*Warum?*  
Beschriftungen innerhalb der Segmente können eng werden, besonders bei kleinen Segmenten. `OutSideEnd` imitiert den Standard‑„Außen“‑Stil, den Sie in der Word‑Benutzeroberfläche sehen, und hält das Diagramm übersichtlich.

### Schritt 6: Das aktualisierte Dokument speichern

```csharp
sourceDoc.Save("YOUR_DIRECTORY/FormattedPieChart.docx");
```

*Warum?*  
Das Speichern schreibt alle Änderungen in eine neue Datei zurück. Öffnen Sie `FormattedPieChart.docx` in Word und Sie sehen die Prozentsätze neben jedem Segment.

#### Erwartetes Ergebnis

Wenn Sie `FormattedPieChart.docx` öffnen, sollte das Kreisdiagramm etwa wie folgt aussehen (fiktiver Screenshot):

```
[ Pie chart with three slices ]
- Slice A – 45%
- Slice B – 30%
- Slice C – 25%
```

Alle Prozentsätze werden automatisch aus den zugrunde liegenden Datenreihen berechnet, und die Beschriftungen befinden sich direkt außerhalb jedes Segments.

## Häufige Varianten & Sonderfälle

| Situation | Was anzupassen |
|-----------|----------------|
| **Mehrere Diagramme** im selben Dokument | Durchlaufen Sie `sourceDoc.GetChildNodes(NodeType.Shape, true)` und casten Sie jede zu `Chart`, bevor Sie dieselbe Logik anwenden. |
| **Balken‑ oder Liniendiagramm**, bei dem Sie trotzdem Beschriftungen wollen | Verwenden Sie `chart.DataLabel.ShowValue = true;` (oder `ShowSeriesName`) anstelle von `ShowPercentage`. |
| **Benutzerdefiniertes Zahlenformat** (z. B. „45 %“) | Setzen Sie `chart.DataLabel.NumberFormat = "0%";` vor dem Speichern. |
| **Große Datensätze**, die zu überlappenden Beschriftungen führen | Erwägen Sie `chart.DataLabel.ShowLeaderLines = true;`, um Verbindungslinien zu zeichnen. |

> **Pro‑Tipp:** Wenn Sie viele Dokumente stapelweise erzeugen, instanziieren Sie ein einziges `Aspose.Words.License`‑Objekt beim Anwendungsstart, um die Performance‑Einbußen durch wiederholtes Laden der Lizenz zu vermeiden.

## Vollständiges funktionierendes Beispiel

Hier das gesamte Programm, fertig zusammengesetzt und bereit zum Ausführen:

```csharp
using System;
using Aspose.Words;
using Aspose.Words.Drawing.Charts;

class Program
{
    static void Main()
    {
        // 1️⃣ Load the template document.
        Document sourceDoc = new Document("YOUR_DIRECTORY/ChartTemplate.docx");

        // 2️⃣ Retrieve the first chart shape.
        Chart chart = (Chart)sourceDoc.GetChild(NodeType.Shape, 0, true);

        // 3️⃣ Ensure we’re dealing with a Pie or Doughnut chart.
        if (chart.ChartType != ChartType.Pie && chart.ChartType != ChartType.Doughnut)
        {
            Console.WriteLine("The selected shape is not a Pie/Doughnut chart.");
            return;
        }

        // 4️⃣ Enable data labels and show percentages.
        chart.HasDataLabel = true;
        chart.DataLabel.ShowPercentage = true;

        // 5️⃣ Position the labels outside the slices.
        chart.DataLabel.Position = ChartDataLabelPosition.OutSideEnd;

        // 6️⃣ Save the modified document.
        sourceDoc.Save("YOUR_DIRECTORY/FormattedPieChart.docx");

        Console.WriteLine("Chart updated successfully – percentages now visible!");
    }
}
```

Kopieren Sie den Code, ersetzen Sie `YOUR_DIRECTORY` durch den tatsächlichen Pfad auf Ihrem Rechner und führen Sie ihn aus. Sie erhalten in Sekunden ein Word‑File mit einem vollständig beschrifteten Kreisdiagramm.
