# Rechnungsvorlage erstellen und Daten mit Aspose.Words zusammenführen

Wenn Sie schnell eine **Rechnungsvorlage erstellen** müssen, zeigt Ihnen dieser Leitfaden genau, wie es geht. Am Ende der ersten beiden Sätze wissen Sie, wie der komplette Arbeitsablauf funktioniert, um eine leere Word‑Datei in eine vollständig ausgefüllte Rechnung zu verwandeln, wobei Sie die Low‑Code‑Mail‑Merge‑API von Aspose.Words verwenden.

Rechnungen zu erstellen ist eine gängige Anforderung für Abrechnungssysteme, ERP‑Integrationen und automatisierte Berichte. In diesem Tutorial lernen Sie **wie man Mail‑Merge verwendet**, **wie man eine Word‑Vorlage füllt**, **wie man Daten in Word zusammenführt**, und schließlich **wie man das zusammengeführte Dokument speichert** – alles mit ein paar C#‑Zeilen.

## Was Sie erreichen werden

* Eine wiederverwendbare Word‑Vorlage (`InvoiceTemplate.docx`), die Merge‑Felder für Kunde, Datum, Positionen und Gesamtsumme enthält.  
* Ein C#‑Programm, das die Vorlage lädt, ein stark typisiertes Datenobjekt injiziert und das Ergebnis nach `Invoice_001.docx` schreibt.  
* Einblick in Randfälle wie leere Sammlungen, benutzerdefinierte Datentypen und die Handhabung von Dateipfaden.

### Voraussetzungen

| Anforderung | Warum es wichtig ist |
|-------------|----------------------|
| .NET 6 or later | Aspose.Words for .NET unterstützt .NET 6+ und stellt die in diesem Leitfaden verwendete Low‑Code‑API bereit. |
| Aspose.Words for .NET NuGet package (`Aspose.Words`) | Stellt `Document`, `MailMerger` und verwandte Typen bereit. |
| Basic C# knowledge | Erforderlich, um anonyme Objekte und LINQ zu verstehen. |
| Visual Studio 2022 (or any IDE) | Visual Studio 2022 (oder jede IDE) – ermöglicht einfaches Bearbeiten und Debuggen. |

> **Pro Tipp:** Installieren Sie das NuGet‑Paket über die Package Manager Console:  
> `Install-Package Aspose.Words`

## So erstellen Sie eine Rechnungsvorlage mit Low‑Code‑Mail‑Merge

Der erste Schritt besteht darin, eine Word‑Datei zu erstellen, die Merge‑Felder enthält, die den Eigenschaften des später zu übergebenden Datenobjekts entsprechen. Speichern Sie die Datei als `InvoiceTemplate.docx` in einem von Ihnen kontrollierten Ordner (z. B. `C:\Invoices\Template`).

| Merge‑Feld | Beispielplatzhalter in Word |
|-------------|-----------------------------|
| CustomerName | «CustomerName» |
| InvoiceDate | «InvoiceDate» |
| Items (repeating) | «Items.Description», «Items.Qty», «Items.Price» |
| Total | «Total» |

> **Warum das wichtig ist:** Die Low‑Code‑API ordnet die Eigenschaftsnamen der Datenquelle automatisch den Merge‑Feldern zu. Identische Namen vermeiden manuelles Feld‑zu‑Eigenschaft‑Mapping und reduzieren Laufzeitfehler.

## Schritt 1: Rechnungsvorlage laden

```csharp
using Aspose.Words;
using Aspose.Words.LowCode;   // Low‑code mail‑merge API

// Load the Word file that contains the merge fields.
Document template = new Document(@"C:\Invoices\Template\InvoiceTemplate.docx");
```

*Die Klasse `Document` repräsentiert die gesamte Word‑Datei. Durch einmaliges Laden können Sie dieselbe Vorlage für viele Rechnungen wiederverwenden.*

## Schritt 2: Datenquelle vorbereiten

Erstellen Sie ein anonymes Objekt, das die Merge‑Felder widerspiegelt. Die Low‑Code‑API kann mit jedem .NET‑Objekt arbeiten, einschließlich Arrays und verschachtelten Sammlungen.

```csharp
var invoiceData = new
{
    CustomerName = "Acme Corp",
    InvoiceDate = DateTime.Today,
    Items = new[]
    {
        new { Description = "Widget A", Qty = 10, Price = 9.99M },
        new { Description = "Widget B", Qty = 5,  Price = 19.95M }
    },
    Total = 199.85M
};
```

**Warum das funktioniert:**  
* Die Eigenschaftsnamen (`CustomerName`, `InvoiceDate`, `Items`, `Total`) entsprechen den Merge‑Feldern in der Vorlage.  
* `Items` ist ein Array von Objekten, sodass der Mail‑Merger die Tabellenzeile für jedes Element automatisch wiederholt.  
* Die Verwendung von `decimal` (`M`‑Suffix) für Geldbeträge verhindert Rundungsfehler bei Gleitkommazahlen.

### Umgang mit leeren Sammlungen

Falls eine Rechnung keine Positionen hat, übergeben Sie ein leeres Array:

```csharp
Items = new object[0]
```

Die Low‑Code‑Engine lässt den wiederholenden Abschnitt einfach weg und lässt die Tabellenüberschrift unverändert.

## Schritt 3: Low‑Code‑Mail‑Merger initialisieren

```csharp
MailMerger merger = new MailMerger(template);
```

`MailMerger` ist der Einstiegspunkt für **wie man Mail‑Merge verwendet** mit Aspose.Words. Es liest die Vorlage, bindet die Daten und bereitet das endgültige Dokument in einem einzigen Aufruf vor.

## Schritt 4: Merge ausführen – Word‑Vorlage in einer Zeile füllen

```csharp
Document mergedDocument = merger.Execute(invoiceData);
```

* Diese Zeile **füllt die Word‑Vorlage** und erzeugt eine neue `Document`‑Instanz (`mergedDocument`).  
* Alle Merge‑Felder werden ersetzt, wiederholende Abschnitte werden erweitert, und das resultierende Dokument befindet sich vollständig im Speicher.

### Sonderfall: Benutzerdefinierte Formatierung

Falls Sie ein bestimmtes Datumsformat benötigen, fügen Sie vor dem Merge einen benutzerdefinierten Formatter hinzu:

```csharp
merger.Options.DateFormat = "MMMM dd, yyyy"; // e.g., "October 07, 2026"
```

## Schritt 5: Zusammengeführtes Dokument speichern

```csharp
mergedDocument.Save(@"C:\Invoices\Output\Invoice_001.docx");
```

Der Aufruf **save merged document** schreibt die vollständig ausgefüllte Rechnung auf die Festplatte. Die Datei kann nun in Microsoft Word geöffnet, als E‑Mail‑Anhang gesendet oder in PDF konvertiert werden.

### Ausgabe überprüfen

Öffnen Sie `Invoice_001.docx`. Sie sollten sehen:

* **CustomerName** ersetzt durch *Acme Corp*  
* **InvoiceDate** zeigt das heutige Datum im gewählten Format  
* Eine Tabellenzeile für *Widget A* (10 × 9.99) und *Widget B* (5 × 19.95)  
* **Total** zeigt *199.85*  

Falls ein Feld unverändert bleibt (z. B. immer noch «CustomerName» anzeigt), überprüfen Sie, ob die Eigenschaftsnamen exakt mit den Merge‑Feldnamen in der Vorlage übereinstimmen.

## Vollständiges ausführbares Beispiel

Unten finden Sie das komplette Programm, das Sie in ein neues Konsolenprojekt kopieren und einfügen können.

```csharp
using System;
using Aspose.Words;
using Aspose.Words.LowCode;   // Low‑code mail‑merge API

namespace InvoiceGenerator
{
    class Program
    {
        static void Main()
        {
            // 1️⃣ Load the template
            Document template = new Document(@"C:\Invoices\Template\InvoiceTemplate.docx");

            // 2️⃣ Build the data source
            var invoiceData = new
            {
                CustomerName = "Acme Corp",
                InvoiceDate = DateTime.Today,
                Items = new[]
                {
                    new { Description = "Widget A", Qty = 10, Price = 9.99M },
                    new { Description = "Widget B", Qty = 5,  Price = 19.95M }
                },
                Total = 199.85M
            };

            // 3️⃣ Initialise the mail merger
            MailMerger merger = new MailMerger(template);

            // Optional: customise date format
            merger.Options.DateFormat = "MMMM dd, yyyy";

            // 4️⃣ Perform the merge (populate word template)
            Document mergedDocument = merger.Execute(invoiceData);

            // 5️⃣ Save the resulting file (save merged document)
            mergedDocument.Save(@"C:\Invoices\Output\Invoice_001.docx");

            Console.WriteLine("Invoice generated successfully.");
        }
    }
}
```

Führen Sie das Programm aus (`dotnet run`). Die Konsole gibt *Invoice generated successfully.* aus und die Datei erscheint in `C:\Invoices\Output`.
