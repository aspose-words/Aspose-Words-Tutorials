# Wie man ein Donut‑Diagramm in einem Word‑Dokument mit Java erstellt

Wenn Sie ein **create doughnut chart** in einer Word‑Datei benötigen, zeigt Ihnen dieses Tutorial eine vollständige, sofort ausführbare Lösung. Sie sehen, wie Sie **insert pie chart** einfügen, es in ein Donut verwandeln, **rotate pie chart** für bessere Balance und **format pie chart** an Ihr Branding anpassen. Am Ende haben Sie ein professionelles Word‑Dokument, das in Berichten, Dashboards oder automatisierten E‑Mail‑Anhängen verwendet werden kann.

Das programmatische Erstellen eines Diagramms eliminiert manuelle Kopier‑Einfüge‑Schritte und garantiert ein konsistentes Styling über Dutzende generierter Dokumente hinweg. Das Beispiel verwendet die Aspose.Words for Java Bibliothek, die mit Java 8+ funktioniert und keine Microsoft Office‑Installation erfordert. Weitere Voraussetzungen sind über ein Standard‑JDK und Ihre bevorzugte IDE hinaus nicht nötig.

## Voraussetzungen

- Java Development Kit (JDK) 8 oder neuer  
- Maven oder Gradle für das Abhängigkeitsmanagement (das Tutorial verwendet Maven)  
- Aspose.Words for Java Bibliothek (eine kostenlose Testlizenz reicht für Tests)  

Fügen Sie die Aspose.Words‑Abhängigkeit zu Ihrer `pom.xml` hinzu:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-words</artifactId>
    <version>24.9</version> <!-- Use the latest stable version -->
</dependency>
```

> **Profi‑Tipp:** Registrieren Sie Ihre Lizenz mit `License license = new License(); license.setLicense("Aspose.Words.lic");` bevor Sie ein Dokument erstellen, um Evaluationswasserzeichen zu entfernen.

## Donut‑Diagramm in einem Word‑Dokument erstellen

Der Kern‑Workflow besteht aus fünf logischen Schritten. Jeder Schritt ist in einer eigenen Methode gekapselt, um den Code sauber und wiederverwendbar zu halten.

```java
import com.aspose.words.*;
import com.aspose.words.drawing.*;

public class DoughnutChartDemo {

    public static void main(String[] args) throws Exception {
        // Step 1: create blank Word document
        Document doc = createBlankWordDocument();

        // Step 2: insert a pie chart (base for the doughnut)
        Chart chart = insertPieChart(doc, 400, 300);

        // Step 3: convert the pie chart into a doughnut and rotate it
        customizeChartAppearance(chart);

        // Step 4: apply additional formatting to the chart
        formatPieChart(chart);

        // Step 5: save the final document
        doc.save("output/DoughnutChartFormatted.docx");
        System.out.println("Document saved successfully.");
    }

    /** Step 1 – create blank Word document */
    private static Document createBlankWordDocument() {
        // Aspose.Words creates an empty document by default
        return new Document();
    }

    /** Step 2 – insert pie chart with given dimensions */
    private static Chart insertPieChart(Document doc, int width, int height) throws Exception {
        DocumentBuilder builder = new DocumentBuilder(doc);
        // ChartType.PIE creates a standard pie chart that we will later turn into a doughnut
        Chart chart = builder.insertChart(ChartType.PIE, width, height);
        // Populate the chart with sample data
        chart.getSeries().clear(); // Remove default series
        ChartSeries series = chart.getSeries().add("Sales", new String[]{"Q1", "Q2", "Q3", "Q4"},
                new double[]{15000, 23000, 18000, 27000});
        return chart;
    }

    /** Step 3 – rotate pie chart and make it a doughnut */
    private static void customizeChartAppearance(Chart chart) {
        // Explode the first slice for emphasis
        chart.getSeries().get(0).setExplode(20);
        // Convert the pie into a doughnut by setting a hole size (percentage of radius)
        chart.setHoleSize(30); // 30% hole creates a classic doughnut look
        // Rotate the chart so the largest slice starts at 45°
        chart.setRotationAngle(45);
    }

    /** Step 4 – additional formatting of the pie chart */
    private static void formatPieChart(Chart chart) {
        // Example: change the first slice color to a brand color
        chart.getSeries().get(0).getPoints().get(0).getFormat().setFillForegroundColor(Color.fromArgb(0xFF, 0x4A, 0x90));
        // Add a legend and position it at the bottom
        chart.setHasLegend(true);
        chart.getLegend().setPosition(LegendPosition.BOTTOM);
        // Set a title for the chart
        chart.setTitle("Quarterly Sales Distribution");
    }
}
```

### Was der Code macht

| Schritt | Aktion | Grund |
|---------|--------|-------|
| **Leeres Word‑Dokument erstellen** | `new Document()` | Beginnt mit einer leeren Datei, sodass Sie jedes Element kontrollieren können. |
| **Kreisdiagramm einfügen** | `builder.insertChart(ChartType.PIE, …)` | Ein Kreisdiagramm ist die Grundform; Aspose liefert ein Donut‑Diagramm nur durch Anpassen der Lochgröße. |
| **Kreisdiagramm drehen** | `chart.setRotationAngle(45)` | Durch Drehen wird das größte Segment in eine besser lesbare Position gebracht. |
| **Kreisdiagramm formatieren** | `setExplode`, `setHoleSize`, color, legend | Verbessert die visuelle Hierarchie und entspricht den Unternehmens‑Style‑Richtlinien. |
| **Dokument speichern** | `doc.save("…/DoughnutChartFormatted.docx")` | Schreibt die endgültige .docx‑Datei auf die Festplatte, bereit für die Verteilung. |

## Kreisdiagramm einfügen, bevor es in ein Donut umgewandelt wird

Aspose.Words bietet keine direkte „insert doughnut chart“-Methode. Stattdessen **insert pie chart** und ändern anschließend dessen Eigenschaften. Dieser Zwei‑Schritt‑Ansatz gibt Ihnen volle Kontrolle über Datenreihen, Segment‑Explosion und Lochgröße. Wenn Sie an anderer Stelle ein reines Kreisdiagramm benötigen, lassen Sie einfach den Aufruf `setHoleSize` weg.

## Kreisdiagramm für visuelle Balance drehen

Die Standard‑Ausrichtung startet das erste Segment bei der 12‑Uhr‑Position. In vielen Geschäftsberichten sollte das wichtigste Segment bei einem natürlicheren Winkel beginnen, z. B. 45 Grad. Die Methode `setRotationAngle(double angle)` akzeptiert Grad und dreht das gesamte Diagramm, ohne die Datenwerte zu verändern.

## Kreisdiagramm formatieren und Erscheinungsbild anpassen

Neben der Umwandlung in ein Donut möchten Sie oft **format pie chart**‑Elemente:

- **Explode** das erste Segment (`setExplode`), um Aufmerksamkeit zu erzeugen.  
- **Color** jedes Segment mit `getPoints().get(i).getFormat().setFillForegroundColor`.  
- **Legend** Positionierung (`setHasLegend`, `setPosition`) hilft den Lesern, Kategorien zu interpretieren.  
- **Title** (`setTitle`) liefert auf einen Blick Kontext.  

All diese Einstellungen sind optional; Sie können sie an Ihre Markenpalette oder Unternehmensvorlagen anpassen.

## Leeres Word‑Dokument erstellen und das Ergebnis speichern

Die Methode `createBlankWordDocument` kapselt den Schritt **create blank word document**. Diese Logik isoliert zu halten erleichtert die Wiederverwendung der Methode beim Erzeugen mehrerer Berichte in einem Batch‑Prozess. Nach allen Anpassungen schreibt `doc.save` die Datei im Standard‑Office‑Open‑XML‑Format (`.docx`), das in Microsoft Word, LibreOffice oder Google Docs ohne Qualitätsverlust geöffnet werden kann.

### Erwartete Ausgabe

Wenn Sie die `main`‑Methode ausführen, gibt die Konsole aus:

```
Document saved successfully.
```

Und die Datei `output/DoughnutChartFormatted.docx` enthält eine einzelne Seite mit einem Donut‑Diagramm mit dem Titel *Quarterly Sales Distribution*. Das Diagramm zeigt vier Segmente, das erste Segment ist explodiert, in der Markenfarbe eingefärbt und um 45 Grad gedreht.

## Häufige Variationen und Sonderfälle

| Situation | Anpassung |
|-----------|-----------|
| **Mehr als eine Datenreihe** | Fügen Sie zusätzliche `ChartSeries`‑Objekte zu `chart.getSeries()` hinzu. |
| **Andere Diagrammgröße** | Ändern Sie die Argumente `width` und `height` in `insertPieChart`. |
| **Kein Loch (reines Kreisdiagramm)** | Lassen Sie `chart.setHoleSize(…)` weg oder setzen Sie es auf `0`. |
| **Große Dokumente** | Verwenden Sie `DocumentBuilder`, um das Diagramm in einen bestimmten Abschnitt oder ein Lesezeichen einzufügen. |
| **Lizenz nicht gesetzt** | Die Bibliothek läuft im Evaluationsmodus und fügt auf der ersten Seite ein Wasserzeichen hinzu. Registrieren Sie eine Lizenz, um es zu entfernen. |
