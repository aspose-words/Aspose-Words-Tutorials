# Come creare un grafico a colonne in Python con Aspose.Words

Se hai bisogno di creare un grafico a colonne in Python, questa guida mostra il codice esatto e il ragionamento necessari. Utilizzando l'API dei grafici di Aspose.Words, puoi definire dimensioni precise, applicare uno stile predefinito ed esportare il risultato senza uscire da Python.

Generare un grafico a colonne è una necessità comune per report, dashboard e creazione automatizzata di documenti. Questo tutorial copre ogni passaggio—dall'importazione della libreria alla verifica dell'immagine salvata—così da poter integrare la generazione di grafici in qualsiasi progetto Python.

## Prerequisiti

Prima di iniziare, assicurati di avere:

* Python 3.8 o versioni successive installate.  
* Una licenza valida di Aspose.Words per Python (o una chiave di valutazione gratuita).  
* Familiarità di base con i moduli Python e il codice orientato agli oggetti.

Il motore dei grafici di Aspose.Words funziona su Windows, macOS e Linux e non richiede librerie grafiche aggiuntive perché il rendering avviene sul lato server.

## Passo 1: Importare la libreria Aspose.Words

Il primo passo è importare il pacchetto `aspose.words` e assegnargli un alias breve. Importare all'inizio del file mantiene pulito lo spazio dei nomi e rende il codice più leggibile.

```python
# Step 1: Import the Aspose.Words library
import aspose.words as aw
```

`aw` ora fa riferimento all'intera API di Aspose.Words, inclusa la classe `Chart` che utilizzerai per costruire il grafico a colonne.

## Passo 2: Creare un grafico a colonne con le dimensioni desiderate

Un grafico a colonne necessita di valori espliciti di larghezza e altezza affinché l'immagine renderizzata si adatti al layout del documento. Il costruttore `Chart` accetta tre argomenti: il tipo di grafico, la larghezza (in punti) e l'altezza (in punti). Usare `aw.ChartType.COLUMN` indica al motore di generare un grafico a barre verticale.

```python
# Step 2: Create a column chart with the desired dimensions
chart = aw.Chart(aw.ChartType.COLUMN, 400, 300)   # width=400pt, height=300pt
```

*Perché impostare le dimensioni?*  
Quando inserisci il grafico in un documento Word o lo esporti come immagine, il contenuto circostante rispetta le dimensioni esatte che fornisci. Questo evita ridimensionamenti o ritagli indesiderati.

### Consiglio esperto: Usa `chart.dimensions` per il ridimensionamento dinamico

Se il tuo set di dati varia, puoi calcolare la dimensione in base al numero di serie:

```python
series_count = 5
base_width = 80
chart.width = base_width * series_count
chart.height = 300
```

## Passo 3: Applicare uno stile predefinito al grafico a colonne

Aspose.Words include diversi temi visivi predefiniti. Selezionare uno stile elimina la necessità di configurare manualmente colori, caratteri e linee della griglia. `aw.ChartStyle.STYLE_5` è un aspetto pulito e professionale adatto alla maggior parte dei report aziendali.

```python
# Step 3: Apply a built‑in style to the chart
chart.style = aw.ChartStyle.STYLE_5
```

Se preferisci un aspetto diverso, sostituisci `STYLE_5` con una delle altre costanti (`STYLE_1` … `STYLE_8`). Ogni stile segue la stessa convenzione di denominazione, rendendo semplice la sperimentazione.

### Caso limite: Costante di stile non valida

Tentare di assegnare uno stile inesistente genera `AttributeError`. Proteggi il tuo codice verificando la costante rispetto all'enumerazione:

```python
if hasattr(aw.ChartStyle, "STYLE_5"):
    chart.style = aw.ChartStyle.STYLE_5
else:
    raise ValueError("Requested chart style does not exist.")
```

## Passo 4: Aggiungere serie di dati al grafico a colonne

Un grafico senza dati è privo di senso. Puoi aggiungere uno o più oggetti `ChartSeries`, ciascuno rappresentante un gruppo di colonne. L'esempio seguente aggiunge una singola serie con tre punti dati.

```python
# Step 4: Add data series to the column chart
series = chart.series.add()
series.name = "Quarterly Sales"
series.data = [12000, 15000, 18000]   # Values for Q1, Q2, Q3
```

Puoi ripetere la chiamata `chart.series.add()` per includere serie aggiuntive (ad es., “Vendite previste”). L'API distribuisce automaticamente le colonne affiancate.

## Passo 5: Renderizzare il grafico e salvarlo come immagine

Dopo aver configurato il grafico, lo renderizzi in un bitmap o in un file immagine. Il metodo `save` accetta un percorso file e un formato opzionale. PNG è senza perdita e ampiamente supportato.

```python
# Step 5: Render and save the chart as a PNG image
output_path = "column_chart.png"
chart.save(output_path, aw.SaveFormat.PNG)
print(f"Chart saved to {output_path}")
```

L'enumerazione `SaveFormat` include PNG, JPEG, BMP e altri. Scegli il formato che corrisponde al tuo flusso di lavoro successivo.

## Verifica dell'output

Apri `column_chart.png` con qualsiasi visualizzatore di immagini. Dovresti vedere un grafico a barre a tre colonne stilizzato con il tema predefinito scelto, dimensionato esattamente 400 × 300 punti.

Se l'immagine appare vuota o distorta, ricontrolla quanto segue:

1. L'oggetto `aw.Chart` è stato istanziato prima di aggiungere le serie.  
2. La costante `chart.style` corrisponde a un valore enum esistente.  
3. La chiamata `save` utilizza un `SaveFormat` supportato.

## Variazioni comuni e consigli aggiuntivi

| Situazione | Modifica consigliata |
|-----------|----------------------|
| **Serie di dati multiple** | Aggiungi blocchi `chart.series.add()` aggiuntivi e imposta `series.name` e `series.data` per ciascuno. |
| **Colori personalizzati** | Dopo aver applicato uno stile predefinito, sovrascrivi i colori delle singole colonne tramite `series.points[i].fill.fore_color`. |
| **Incorporamento in un documento Word** | Invece di `chart.save()`, usa `doc = aw.Document(); doc.sections[0].body.append_child(chart); doc.save("report.docx")`. |
| **Dimensionamento dinamico** | Calcola la larghezza in base al numero di serie (`width = 80 * len(chart.series)`). |

Queste variazioni dimostrano come lo stesso codice di base si adatti a diversi scenari di reporting.
