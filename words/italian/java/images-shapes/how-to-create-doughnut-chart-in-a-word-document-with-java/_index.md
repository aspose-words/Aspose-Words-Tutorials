# Come creare un grafico a ciambella in un documento Word con Java

Se hai bisogno di **create doughnut chart** all'interno di un file Word, questo tutorial ti mostra una soluzione completa, pronta‑da‑eseguire. Vedrai come **insert pie chart**, trasformarlo in una ciambella, **rotate pie chart** per un migliore equilibrio, e **format pie chart** per corrispondere al tuo branding. Alla fine avrai un documento Word professionale che può essere usato in report, dashboard o allegati email automatizzati.

Creare un grafico programmaticamente elimina i passaggi manuali di copia‑incolla e garantisce uno stile coerente su decine di documenti generati. L'esempio utilizza la libreria Aspose.Words for Java, che funziona con Java 8+ e non richiede l'installazione di Microsoft Office. Non sono necessari altri prerequisiti oltre a un JDK standard e il tuo IDE preferito.

## Prerequisiti

- Java Development Kit (JDK) 8 o più recente  
- Maven o Gradle per la gestione delle dipendenze (il tutorial usa Maven)  
- Libreria Aspose.Words for Java (una licenza di prova gratuita è sufficiente per i test)  

Aggiungi la dipendenza Aspose.Words al tuo `pom.xml`:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-words</artifactId>
    <version>24.9</version> <!-- Use the latest stable version -->
</dependency>
```

> **Pro tip:** Registra la tua licenza con `License license = new License(); license.setLicense("Aspose.Words.lic");` prima di creare qualsiasi documento per rimuovere le filigrane di valutazione.

## Crea un grafico a ciambella in un documento Word

Il flusso di lavoro principale consiste in cinque passaggi logici. Ogni passaggio è racchiuso nel proprio metodo per mantenere il codice pulito e riutilizzabile.

```java
import com.aspose.words.*;
import com.aspose.words.drawing.*;

public class DoughnutChartDemo {

    public static void main(String[] args) throws Exception {
        // Step 1: create blank Word document
        Document doc = createBlankWordDocument();

        // Step 2: insert a pie chart (base for the doughnut)
        Chart chart = insertPieChart(doc, 400, 300);

        // Step 3: convert the pie chart into a doughnut and rotate it
        customizeChartAppearance(chart);

        // Step 4: apply additional formatting to the chart
        formatPieChart(chart);

        // Step 5: save the final document
        doc.save("output/DoughnutChartFormatted.docx");
        System.out.println("Document saved successfully.");
    }

    /** Step 1 – create blank Word document */
    private static Document createBlankWordDocument() {
        // Aspose.Words creates an empty document by default
        return new Document();
    }

    /** Step 2 – insert pie chart with given dimensions */
    private static Chart insertPieChart(Document doc, int width, int height) throws Exception {
        DocumentBuilder builder = new DocumentBuilder(doc);
        // ChartType.PIE creates a standard pie chart that we will later turn into a doughnut
        Chart chart = builder.insertChart(ChartType.PIE, width, height);
        // Populate the chart with sample data
        chart.getSeries().clear(); // Remove default series
        ChartSeries series = chart.getSeries().add("Sales", new String[]{"Q1", "Q2", "Q3", "Q4"},
                new double[]{15000, 23000, 18000, 27000});
        return chart;
    }

    /** Step 3 – rotate pie chart and make it a doughnut */
    private static void customizeChartAppearance(Chart chart) {
        // Explode the first slice for emphasis
        chart.getSeries().get(0).setExplode(20);
        // Convert the pie into a doughnut by setting a hole size (percentage of radius)
        chart.setHoleSize(30); // 30% hole creates a classic doughnut look
        // Rotate the chart so the largest slice starts at 45°
        chart.setRotationAngle(45);
    }

    /** Step 4 – additional formatting of the pie chart */
    private static void formatPieChart(Chart chart) {
        // Example: change the first slice color to a brand color
        chart.getSeries().get(0).getPoints().get(0).getFormat().setFillForegroundColor(Color.fromArgb(0xFF, 0x4A, 0x90));
        // Add a legend and position it at the bottom
        chart.setHasLegend(true);
        chart.getLegend().setPosition(LegendPosition.BOTTOM);
        // Set a title for the chart
        chart.setTitle("Quarterly Sales Distribution");
    }
}
```

### Cosa fa il codice

| Passo | Azione | Motivo |
|------|--------|--------|
| **Crea documento Word vuoto** | `new Document()` | Inizia con un file pulito così controlli ogni elemento. |
| **Inserisci grafico a torta** | `builder.insertChart(ChartType.PIE, …)` | Un grafico a torta è la forma di base; Aspose fornisce una ciambella solo regolando la dimensione del buco. |
| **Ruota grafico a torta** | `chart.setRotationAngle(45)` | Ruotare allinea la fetta più grande a una posizione più leggibile. |
| **Formatta grafico a torta** | `setExplode`, `setHoleSize`, color, legend | Migliora la gerarchia visiva e corrisponde alle linee guida di stile aziendali. |
| **Salva documento** | `doc.save("…/DoughnutChartFormatted.docx")` | Scrive il file .docx finale su disco, pronto per la distribuzione. |

## Inserisci grafico a torta prima di convertirlo in ciambella

Aspose.Words non fornisce un metodo diretto “insert doughnut chart”. Invece, **insert pie chart** e poi modifichi le sue proprietà. Questo approccio a due passaggi ti dà il pieno controllo sulle serie di dati, l'esplosione delle fette e la dimensione del buco. Se ti serve un grafico a torta puro altrove, basta omettere la chiamata `setHoleSize`.

## Ruota grafico a torta per equilibrio visivo

L'orientamento predefinito inizia la prima fetta alla posizione delle 12 ore. In molti report aziendali la fetta più importante dovrebbe iniziare a un angolo più naturale, ad esempio 45 gradi. Il metodo `setRotationAngle(double angle)` accetta i gradi e ruota l'intero grafico senza influire sui valori dei dati.

## Formatta grafico a torta e personalizza l'aspetto

Oltre a convertire in una ciambella, spesso vuoi **format pie chart** gli elementi:

- **Explode** la prima fetta (`setExplode`) per attirare l'attenzione.  
- **Color** ogni fetta usando `getPoints().get(i).getFormat().setFillForegroundColor`.  
- **Legend** posizionamento (`setHasLegend`, `setPosition`) aiuta i lettori a interpretare le categorie.  
- **Title** (`setTitle`) fornisce contesto a colpo d'occhio.  

Tutte queste impostazioni sono opzionali; puoi personalizzarle per corrispondere alla palette del tuo brand o ai modelli aziendali.

## Crea documento Word vuoto e salva il risultato

Il metodo `createBlankWordDocument` incapsula il passaggio **create blank word document**. Tenere questa logica isolata rende facile riutilizzare il metodo quando si generano più report in un processo batch. Dopo tutte le personalizzazioni, `doc.save` scrive il file nel formato standard Office Open XML (`.docx`), che può essere aperto in Microsoft Word, LibreOffice o Google Docs senza perdita di fedeltà.

### Output previsto

Quando esegui il metodo `main`, la console stampa:

```
Document saved successfully.
```

E il file `output/DoughnutChartFormatted.docx` contiene una singola pagina con un grafico a ciambella intitolato *Quarterly Sales Distribution*. Il grafico mostra quattro fette, la prima fetta esplosa, colorata nella tonalità del brand, e ruotata di 45 gradi.

## Variazioni comuni e casi limite

| Situazione | Adeguamento |
|-----------|------------|
| **Più di una serie di dati** | Aggiungi oggetti `ChartSeries` aggiuntivi a `chart.getSeries()`. |
| **Dimensione del grafico diversa** | Modifica gli argomenti `width` e `height` in `insertPieChart`. |
| **Nessun buco (torta pura)** | Ometti `chart.setHoleSize(…)` o impostalo a `0`. |
| **Documenti grandi** | Usa `DocumentBuilder` per inserire il grafico in una sezione o segnalibro specifico. |
| **Licenza non impostata** | La libreria funziona in modalità valutazione, aggiungendo una filigrana sulla prima pagina. Registra una licenza per rimuoverla. |
