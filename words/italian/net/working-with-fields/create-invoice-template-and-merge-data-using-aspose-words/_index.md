# Crea modello di fattura e unisci dati usando Aspose.Words

Se hai bisogno di **creare un modello di fattura** rapidamente, questa guida ti mostra esattamente come fare. Alla fine delle prime due frasi conoscerai l'intero flusso di lavoro per trasformare un file Word vuoto in una fattura completamente popolata, usando l'API low‑code di mail‑merge di Aspose.Words.

Generare fatture è una necessità comune per i sistemi di fatturazione, le integrazioni ERP e i report automatici. In questo tutorial imparerai **come eseguire il mail merge**, **popolare il modello Word**, **unire i dati in Word**, e infine **salvare il documento unito** — tutto con poche righe di C#.

## Cosa otterrai

* Un modello Word riutilizzabile (`InvoiceTemplate.docx`) che contiene campi di merge per cliente, data, righe di articolo e totale.  
* Un programma C# che carica il modello, inietta un oggetto dati tipizzato, e scrive il risultato in `Invoice_001.docx`.  
* Approfondimenti su casi limite come collezioni vuote, tipi di dati personalizzati e gestione dei percorsi file.

### Prerequisiti

| Requisito | Perché è importante |
|-------------|----------------|
| .NET 6 or later | Aspose.Words for .NET supporta .NET 6+ e fornisce l'API low‑code usata in questa guida. |
| Aspose.Words for .NET NuGet package (`Aspose.Words`) | Fornisce `Document`, `MailMerger` e tipi correlati. |
| Basic C# knowledge | Necessario per comprendere oggetti anonimi e LINQ. |
| Visual Studio 2022 (or any IDE) | Rende l'editing e il debugging semplici. |

> **Suggerimento professionale:** Installa il pacchetto NuGet tramite la Package Manager Console:  
> `Install-Package Aspose.Words`

## Come creare un modello di fattura con mail merge low‑code

Il primo passo è creare un file Word che contenga campi di merge corrispondenti alle proprietà dell'oggetto dati che passerai in seguito. Salva il file come `InvoiceTemplate.docx` in una cartella che controlli (ad esempio, `C:\Invoices\Template`).

| Campo di merge | Esempio segnaposto in Word |
|-------------|-----------------------------|
| CustomerName | «CustomerName» |
| InvoiceDate | «InvoiceDate» |
| Items (repeating) | «Items.Description», «Items.Qty», «Items.Price» |
| Total | «Total» |

> **Perché è importante:** L'API low‑code mappa automaticamente i nomi delle proprietà della sorgente dati ai campi di merge. Mantenere i nomi identici elimina la mappatura manuale campo‑a‑proprietà e riduce gli errori a runtime.

## Passo 1: Carica il modello di fattura

```csharp
using Aspose.Words;
using Aspose.Words.LowCode;   // Low‑code mail‑merge API

// Load the Word file that contains the merge fields.
Document template = new Document(@"C:\Invoices\Template\InvoiceTemplate.docx");
```

*La classe `Document` rappresenta l'intero file Word. Caricarla una volta ti consente di riutilizzare lo stesso modello per molte fatture.*

## Passo 2: Prepara la sorgente dati

Crea un oggetto anonimo che rispecchi i campi di merge. L'API low‑code può lavorare con qualsiasi oggetto .NET, incluse array e collezioni nidificate.

```csharp
var invoiceData = new
{
    CustomerName = "Acme Corp",
    InvoiceDate = DateTime.Today,
    Items = new[]
    {
        new { Description = "Widget A", Qty = 10, Price = 9.99M },
        new { Description = "Widget B", Qty = 5,  Price = 19.95M }
    },
    Total = 199.85M
};
```

**Perché funziona:**  
* I nomi delle proprietà (`CustomerName`, `InvoiceDate`, `Items`, `Total`) corrispondono ai campi di merge nel modello.  
* `Items` è un array di oggetti, quindi il mail merger ripeterà la riga della tabella per ogni elemento automaticamente.  
* Usare `decimal` (suffisso `M`) per i valori monetari evita problemi di arrotondamento in virgola mobile.

### Gestione di collezioni vuote

Se una fattura non ha righe di articolo, passa un array vuoto:

```csharp
Items = new object[0]
```

Il motore low‑code semplicemente ometterà la sezione ripetuta, lasciando intatta l'intestazione della tabella.

## Passo 3: Inizializza il mail merger low‑code

```csharp
MailMerger merger = new MailMerger(template);
```

`MailMerger` è il punto di ingresso per **come eseguire il mail merge** con Aspose.Words. Legge il modello, associa i dati e prepara il documento finale in una singola chiamata.

## Passo 4: Esegui il merge – popola il modello Word in una riga

```csharp
Document mergedDocument = merger.Execute(invoiceData);
```

* Questa riga **popola il modello Word** e produce una nuova istanza `Document` (`mergedDocument`).  
* Tutti i campi di merge vengono sostituiti, le sezioni ripetute vengono espanse e il documento risultante risiede interamente in memoria.

### Caso limite: Formattazione personalizzata

Se hai bisogno di un formato data specifico, aggiungi un formattatore personalizzato prima del merge:

```csharp
merger.Options.DateFormat = "MMMM dd, yyyy"; // e.g., "October 07, 2026"
```

## Passo 5: Salva il documento unito

```csharp
mergedDocument.Save(@"C:\Invoices\Output\Invoice_001.docx");
```

La chiamata **save merged document** scrive la fattura completamente popolata su disco. Il file può ora essere aperto in Microsoft Word, inviato come allegato email o convertito in PDF.

### Verifica dell'output

Apri `Invoice_001.docx`. Dovresti vedere:

* **CustomerName** sostituito con *Acme Corp*  
* **InvoiceDate** che mostra la data odierna nel formato scelto  
* Una riga di tabella per *Widget A* (10 × 9.99) e *Widget B* (5 × 19.95)  
* **Total** che visualizza *199.85*

Se qualche campo rimane invariato (ad esempio, mostra ancora «CustomerName»), verifica che i nomi delle proprietà corrispondano esattamente ai nomi dei campi di merge nel modello.

## Esempio completo eseguibile

Di seguito trovi il programma completo che puoi copiare‑incollare in un nuovo progetto console.

```csharp
using System;
using Aspose.Words;
using Aspose.Words.LowCode;   // Low‑code mail‑merge API

namespace InvoiceGenerator
{
    class Program
    {
        static void Main()
        {
            // 1️⃣ Load the template
            Document template = new Document(@"C:\Invoices\Template\InvoiceTemplate.docx");

            // 2️⃣ Build the data source
            var invoiceData = new
            {
                CustomerName = "Acme Corp",
                InvoiceDate = DateTime.Today,
                Items = new[]
                {
                    new { Description = "Widget A", Qty = 10, Price = 9.99M },
                    new { Description = "Widget B", Qty = 5,  Price = 19.95M }
                },
                Total = 199.85M
            };

            // 3️⃣ Initialise the mail merger
            MailMerger merger = new MailMerger(template);

            // Optional: customise date format
            merger.Options.DateFormat = "MMMM dd, yyyy";

            // 4️⃣ Perform the merge (populate word template)
            Document mergedDocument = merger.Execute(invoiceData);

            // 5️⃣ Save the resulting file (save merged document)
            mergedDocument.Save(@"C:\Invoices\Output\Invoice_001.docx");

            Console.WriteLine("Invoice generated successfully.");
        }
    }
}
```

Esegui il programma (`dotnet run`). La console stampa *Invoice generated successfully.* e il file appare in `C:\Invoices\Output`.
