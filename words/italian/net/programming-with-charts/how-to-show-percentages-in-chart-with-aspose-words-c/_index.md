# Come visualizzare le percentuali in un grafico con Aspose.Words C#

Ti sei mai chiesto **how to show percentages in chart** senza dover combattere con l’interoperabilità complessa di Office? Non sei l’unico: molti sviluppatori si trovano di fronte a questo ostacolo quando hanno bisogno di un modo rapido e programmatico per etichettare un grafico a torta o a ciambella. La buona notizia? Con Aspose.Words per .NET puoi abilitare quelle etichette dati in poche righe di codice.

In questo tutorial tratteremo anche **add data labels to pie chart** e **how to enable chart data labels** così le tue visualizzazioni diventeranno immediatamente più incisive. Alla fine avrai un documento Word pronto all’uso (`.docx`) che mostra un grafico a torta rifinito con le percentuali posizionate ordinatamente all’esterno di ogni fetta.

## Prerequisiti

Prima di iniziare, assicurati di avere:

- **Aspose.Words for .NET** (ultima versione, ad es. 24.9) installata via NuGet.  
- Un file **ChartTemplate.docx** che contenga già un grafico a torta o a ciambella.  
  *(Se non ne hai uno, crea un semplice documento Word, inserisci un grafico a torta e salvalo come `ChartTemplate.docx`.)*  
- .NET 6.0 o successivo e qualsiasi IDE preferisci (Visual Studio, Rider, VS Code).

Non sono necessarie dipendenze aggiuntive: Aspose.Words gestisce tutto internamente.

## Come visualizzare le percentuali in un grafico – Passo‑per‑passo

Di seguito suddividiamo il processo in sei passaggi chiari. Ogni passaggio include il codice C# esatto da copiare‑incollare, più una breve spiegazione del **perché** lo facciamo.

### Passo 1: Caricare il documento sorgente

```csharp
using Aspose.Words;
using Aspose.Words.Drawing.Charts;

// Load the .docx that already holds a chart.
Document sourceDoc = new Document("YOUR_DIRECTORY/ChartTemplate.docx");
```

*Perché?*  
`Document` è il punto di ingresso per qualsiasi manipolazione di Word. Caricando il modello otteniamo l’accesso a tutti i nodi—forme, tabelle, testo e, naturalmente, il grafico che modificheremo.

### Passo 2: Recuperare la prima forma grafico

```csharp
// The chart lives inside a Shape node; retrieve it.
Chart chart = (Chart)sourceDoc.GetChild(NodeType.Shape, 0, true);
```

*Perché?*  
Aspose memorizza i grafici come oggetti `Shape`. `GetChild` attraversa l’albero del documento e restituisce la prima forma trovata, che nel nostro caso è il grafico a torta da modificare.

### Passo 3: Confermare il tipo di grafico

```csharp
if (chart.ChartType == ChartType.Pie || chart.ChartType == ChartType.Doughnut)
{
    // Inside this block we’ll enable the data labels.
}
else
{
    throw new InvalidOperationException("The chart is not a Pie or Doughnut type.");
}
```

*Perché?*  
Le etichette percentuali hanno senso solo per grafici circolari. Questa verifica impedisce di applicare accidentalmente le impostazioni a, ad esempio, un grafico a barre dove `ShowPercentage` verrebbe ignorato.

### Passo 4: Abilitare le etichette dati e mostrare le percentuali

```csharp
// Turn on data labels for the chart.
chart.HasDataLabel = true;

// Show the percentage value for each slice.
chart.DataLabel.ShowPercentage = true;
```

*Perché?*  
`HasDataLabel` indica ad Aspose di renderizzare un’etichetta per ogni punto dati. Impostare `ShowPercentage` assicura che il contenuto dell’etichetta sia la quota calcolata del totale—esattamente ciò che richiede **add data labels to pie chart**.

### Passo 5: Posizionare le etichette all’esterno delle fette

```csharp
// Place the labels outside the pie slices for better readability.
chart.DataLabel.Position = ChartDataLabelPosition.OutSideEnd;
```

*Perché?*  
Le etichette all’interno delle fette possono diventare sovraffollate, soprattutto quando le fette sono piccole. `OutSideEnd` imita lo stile “esterno” predefinito che vedi nell’interfaccia di Word, mantenendo il grafico pulito.

### Passo 6: Salvare il documento aggiornato

```csharp
sourceDoc.Save("YOUR_DIRECTORY/FormattedPieChart.docx");
```

*Perché?*  
Il salvataggio scrive tutte le modifiche in un nuovo file. Apri `FormattedPieChart.docx` in Word e vedrai le percentuali visualizzate accanto a ogni fetta.

#### Risultato atteso

Quando apri `FormattedPieChart.docx`, il grafico a torta dovrebbe apparire simile a questo (screenshot immaginario):

```
[ Pie chart with three slices ]
- Slice A – 45%
- Slice B – 30%
- Slice C – 25%
```

Tutte le percentuali sono calcolate automaticamente dalla serie dati sottostante e le etichette sono posizionate appena fuori da ogni fetta.

## Varianti comuni e casi limite

| Situazione | Cosa modificare |
|------------|-----------------|
| **Grafici multipli** nello stesso documento | Itera su `sourceDoc.GetChildNodes(NodeType.Shape, true)` e cast ogni elemento a `Chart` prima di applicare la stessa logica. |
| **Grafico a barre o a linee** dove vuoi comunque le etichette | Usa `chart.DataLabel.ShowValue = true;` (o `ShowSeriesName`) invece di `ShowPercentage`. |
| **Formato numerico personalizzato** (es. “45 %”) | Imposta `chart.DataLabel.NumberFormat = "0%";` prima del salvataggio. |
| **Set di dati grandi** che causano sovrapposizione delle etichette | Considera `chart.DataLabel.ShowLeaderLines = true;` per disegnare linee di collegamento. |

> **Consiglio professionale:** Se generi molti documenti in batch, istanzia un unico oggetto `Aspose.Words.License` all’avvio dell’applicazione per evitare il sovraccarico di caricare la licenza più volte.

## Esempio completo funzionante

Ecco l’intero programma assemblato, pronto per l’esecuzione:

```csharp
using System;
using Aspose.Words;
using Aspose.Words.Drawing.Charts;

class Program
{
    static void Main()
    {
        // 1️⃣ Load the template document.
        Document sourceDoc = new Document("YOUR_DIRECTORY/ChartTemplate.docx");

        // 2️⃣ Retrieve the first chart shape.
        Chart chart = (Chart)sourceDoc.GetChild(NodeType.Shape, 0, true);

        // 3️⃣ Ensure we’re dealing with a Pie or Doughnut chart.
        if (chart.ChartType != ChartType.Pie && chart.ChartType != ChartType.Doughnut)
        {
            Console.WriteLine("The selected shape is not a Pie/Doughnut chart.");
            return;
        }

        // 4️⃣ Enable data labels and show percentages.
        chart.HasDataLabel = true;
        chart.DataLabel.ShowPercentage = true;

        // 5️⃣ Position the labels outside the slices.
        chart.DataLabel.Position = ChartDataLabelPosition.OutSideEnd;

        // 6️⃣ Save the modified document.
        sourceDoc.Save("YOUR_DIRECTORY/FormattedPieChart.docx");

        Console.WriteLine("Chart updated successfully – percentages now visible!");
    }
}
```

Copia il codice, sostituisci `YOUR_DIRECTORY` con il percorso reale sul tuo computer e avvialo. Avrai un file Word con un grafico a torta completamente etichettato in pochi secondi.

## Cosa fare dopo?

- **Stilizzare le etichette** – cambia font, colore o aggiungi uno sfondo usando `chart.DataLabel.Font`.  
- **Creare grafici da zero** – esplora `Chart chart = (Chart)sourceDoc.FirstSection.Body.AppendChild(new Shape(sourceDoc, ShapeType.Chart));` per generare grafici programmaticamente.  
- **Combinare più grafici** in un unico documento per dashboard, quindi esportare in PDF con `sourceDoc.Save("Dashboard.pdf", SaveFormat.Pdf);`.
