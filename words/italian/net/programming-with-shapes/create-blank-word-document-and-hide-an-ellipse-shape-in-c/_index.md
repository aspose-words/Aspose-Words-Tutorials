# Crea un documento Word vuoto e nascondi una forma ellittica in C#

Se hai bisogno di **creare un documento Word vuoto** e poi nascondere un elemento grafico, questa guida ti mostra esattamente come farlo con C#. Vedrai un esempio completo e eseguibile che inserisce un'ellisse, la posiziona, la contrassegna come nascosta e salva il file—tutto in poche righe di codice.

Il tutorial copre tutto, dalla configurazione del progetto al passaggio finale di verifica. Alla fine, potrai generare un file Word in cui l'ellisse non appare né sullo schermo né in stampa, utile per memorizzare metadati, segnalibri o qualsiasi marcatore invisibile.

## Prerequisiti

* .NET 6.0 SDK o versioni successive installato  
* Un ambiente di sviluppo C# (Visual Studio 2022, Rider o VS Code)  
* Il pacchetto NuGet **Aspose.Words for .NET** (`Install-Package Aspose.Words`)  

Questi strumenti forniscono le classi `Document` e `DocumentBuilder` utilizzate nell'esempio di codice.

## Passo 1: Crea un documento Word vuoto

La prima operazione crea un oggetto `Document` vuoto e un `DocumentBuilder` che ti permette di aggiungere contenuti.

```csharp
using Aspose.Words;
using Aspose.Words.Drawing;

// Step 1: Initialize an empty document and a builder
Document doc = new Document();
DocumentBuilder builder = new DocumentBuilder(doc);
```

`Document` rappresenta l'intero pacchetto `.docx`, mentre `DocumentBuilder` offre un'API fluida per inserire testo, forme e altri oggetti. Iniziare con un documento vuoto ti dà il pieno controllo su ogni elemento aggiunto.

## Passo 2: Come inserire un'ellisse

Un'ellisse è una forma vettoriale che può essere usata come marcatore. Il metodo `InsertShape` richiede il tipo di forma e la sua larghezza/altezza in punti.

```csharp
// Step 2: Insert an ellipse shape of the desired size (100 pt × 50 pt)
Shape ellipse = builder.InsertShape(ShapeType.Ellipse, 100, 50);
```

L'ellisse viene posizionata nella pagina corrente nella posizione del cursore. Puoi modificare le sue dimensioni regolando i valori numerici.

## Passo 3: Come posizionare la forma

Dopo l'inserimento, puoi spostare la forma ovunque nella pagina impostando le proprietà `Left` e `Top`, che usano punti relativi al margine della pagina.

```csharp
// Step 3: Position the shape on the page
ellipse.Left = 150; // distance from the left margin
ellipse.Top  = 100; // distance from the top margin
```

Queste coordinate collocano l'ellisse approssimativamente nella parte superiore‑centrale di una pagina A4 standard. Regola i valori per adattarli alle tue esigenze di layout.

## Passo 4: Come nascondere la forma

Un oggetto nascosto non viene visualizzato quando il documento è aperto o stampato. Impostare il flag `Hidden` contrassegna la forma come una **hidden object word**.

```csharp
// Step 4: Hide the shape so it never appears
ellipse.Hidden = true;
```

Word rispetta il flag hidden sia per il rendering a schermo sia per l'output di stampa. La forma rimane parte della struttura del documento, consentendoti di interrogarla o modificarla successivamente tramite codice.

## Passo 5: Salva il documento

Infine, scrivi il documento su disco. Scegli una cartella in cui hai i permessi di scrittura.

```csharp
// Step 5: Save the document to a .docx file
doc.Save(@"C:\Temp\HiddenEllipse.docx");
```

Il file `HiddenEllipse.docx` ora contiene una pagina vuota con una forma ellittica nascosta.

## Verifica dell'ellisse nascosta

Apri il file generato in Microsoft Word e abilita l'opzione **Show hidden text** (File → Options → Display). Vedrai un contorno tenue dell'ellisse. Se disattivi l'opzione, la forma scompare completamente, confermando che `ellipse.Hidden = true` funziona come previsto.

## Variazioni comuni e casi limite

| Situazione | Regolazione consigliata |
|------------|--------------------------|
| **Forma diversa** | Sostituisci `ShapeType.Ellipse` con `ShapeType.Rectangle`, `ShapeType.Arrow`, ecc. |
| **Più oggetti nascosti** | Ripeti i passi 2‑4 per ogni forma; ciascuna può avere il proprio flag `Hidden`. |
| **Dimensione pagina diversa** | Imposta `doc.FirstSection.PageSetup.PageWidth` e `PageHeight` prima di inserire la forma. |
| **Visibilità condizionale** | Usa `Shape.Visible` in combinazione con `Hidden` per attivare/disattivare a runtime tramite codice. |

**Pro tip:** Memorizza i dati di identificazione nella proprietà `AlternativeText` della forma. Anche quando è nascosta, puoi recuperare la forma in seguito con `doc.GetChildNodes(NodeType.Shape, true)` e filtrare per quel testo.

## Codice sorgente completo

Di seguito trovi il programma completo che puoi copiare, incollare ed eseguire.

```csharp
using System;
using Aspose.Words;
using Aspose.Words.Drawing;

namespace HiddenShapeDemo
{
    class Program
    {
        static void Main()
        {
            // Create a new blank document and a builder
            Document doc = new Document();
            DocumentBuilder builder = new DocumentBuilder(doc);

            // Insert an ellipse shape (100 pt × 50 pt)
            Shape ellipse = builder.InsertShape(ShapeType.Ellipse, 100, 50);

            // Position the shape on the page
            ellipse.Left = 150;
            ellipse.Top  = 100;

            // Hide the shape so it is invisible in the UI and on print
            ellipse.Hidden = true;

            // Optional: add a description for later retrieval
            ellipse.AlternativeText = "Hidden marker for internal processing";

            // Save the document
            string outputPath = @"C:\Temp\HiddenEllipse.docx";
            doc.Save(outputPath);

            Console.WriteLine($"Document saved to {outputPath}");
        }
    }
}
```

**Expected output:** la console stampa il percorso di salvataggio e il file `HiddenEllipse.docx` si apre come una pagina vuota senza grafiche visibili, a meno che gli oggetti nascosti non siano mostrati.

## Conclusione

Ora sai come **creare un documento Word vuoto** programmaticamente, **come inserire un'ellisse**, **come posizionare la forma** e **come nascondere la forma** affinché si comporti come una **hidden object word**. Questa tecnica è ideale per incorporare marcatori invisibili, metadati personalizzati o segnaposto che i processi a valle possono leggere senza influire sul layout visivo del documento.

### Prossimi passi

* Integra questo codice in una pipeline di automazione più ampia che genera report o contratti.

Sentiti libero di sperimentare con le coordinate, le dimensioni e il flag hidden per adattarli al tuo scenario specifico. Buon coding!
