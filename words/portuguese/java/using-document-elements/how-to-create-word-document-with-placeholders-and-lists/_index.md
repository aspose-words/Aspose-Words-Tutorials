# Como criar documento Word com marcadores de posição e listas

Se você precisa **criar documento Word** programaticamente, este guia mostra exatamente como fazer. Vamos percorrer **definir texto de marcador de posição**, **adicionar itens de lista**, e **como usar SDT** (Structured Document Tag) controles com Aspose.Words para .NET.

Os desenvolvedores frequentemente pedem uma forma de incorporar controles de conteúdo — como marcadores de posição de texto simples ou listas suspensas — diretamente em um arquivo .docx sem abrir o Word. Este tutorial fornece um exemplo completo e executável, explica por que cada etapa importa e cobre variações comuns, como adicionar os controles a um documento existente ou personalizar os valores da lista.

## Pré‑requisitos

Antes de começar, verifique se você tem:

- .NET 6.0 SDK ou posterior instalado  
- Visual Studio 2022 (ou qualquer IDE C#)  
- Uma licença ativa do Aspose.Words para .NET (uma avaliação gratuita funciona para desenvolvimento)  
- Familiaridade básica com a sintaxe C#  

O código tem como alvo **Aspose.Words 23.9** (a versão estável mais recente no momento da escrita). Ajuste a versão do pacote NuGet se você usar uma versão mais nova.

## Inserir um Structured Document Tag de texto simples (definir texto de placeholder)

Um SDT de texto simples se comporta como um controle de conteúdo que o usuário pode preencher. Definir seu `Title` e `PlaceholderName` fornece uma dica amigável dentro do Word.

```csharp
            // Step 2: Insert a plain‑text SDT and set its placeholder text
            StructuredDocumentTag plainTextTag = builder.InsertStructuredDocumentTag(
                StructuredDocumentTagType.PlainText, true);
            plainTextTag.Title = "CustomerName";
            plainTextTag.PlaceholderName = "Enter name";
```

**Explicação:**  
- `InsertStructuredDocumentTag` cria o controle na posição atual do cursor do builder.  
- `StructuredDocumentTagType.PlainText` indica ao Word que renderize uma caixa de texto simples.  
- `Title` é o nome interno usado pelo XML do Word; é útil para vinculação de dados posterior.  
- `PlaceholderName` é a dica cinza que aparece até o usuário digitar algo.

> **Dica profissional:** Se você precisar que o placeholder apareça no painel *Properties* do documento, também defina `plainTextTag.Tag = "CustomerName"`.

## Inserir um SDT de lista suspensa (como usar sdt)

Uma lista suspensa permite apresentar um conjunto pré‑definido de opções. Este é o núcleo de **como usar sdt** para dados enumerados.

```csharp
            // Step 3: Insert a drop‑down list SDT and define its title
            StructuredDocumentTag dropdownTag = builder.InsertStructuredDocumentTag(
                StructuredDocumentTagType.DropDownList, true);
            dropdownTag.Title = "Country";
```

**Por que uma lista suspensa?**  
Listas suspensas melhoram a consistência dos dados e reduzem erros de digitação. A propriedade `Title` novamente serve como identificador para processamento posterior (por exemplo, ao extrair dados de formulário).

## Adicionar itens de lista à lista suspensa (adicionar itens de lista)

Agora preenchemos o controle com valores selecionáveis. Cada `ListItem` recebe um texto de exibição e um valor opcional que pode ser armazenado no XML do documento.

```csharp
            // Step 4: Populate the drop‑down with selectable items
            dropdownTag.ListItems.Add(new ListItem("USA", "US"));
            dropdownTag.ListItems.Add(new ListItem("Canada", "CA"));
            dropdownTag.ListItems.Add(new ListItem("Mexico", "MX"));
```

**Pontos‑chave:**  

- O primeiro argumento (`"USA"`) é o que o usuário vê.  
- O segundo argumento (`"US"`) é o valor subjacente que você pode ler programaticamente.  
- Você pode adicionar quantos itens precisar; a lista é armazenada nos elementos `<w:listItem>` do XML .docx.

### Casos de borda e variações

| Situação | Ajuste recomendado |
|-----------|------------------------|
| **Adicionar controles a um arquivo existente** | Carregue o arquivo com `new Document("Existing.docx")` em vez de criar um novo `Document`. |
| **Tornar o placeholder obrigatório** | Defina `plainTextTag.IsShowingPlaceholderWhenEmpty = false` e `plainTextTag.IsShowingPlaceholderWhenEmpty = true` com base na sua lógica de validação. |
| **Vincular itens de lista a uma fonte de dados** | Percorra uma coleção (`foreach (var country in countries)`) e chame `dropdownTag.ListItems.Add(new ListItem(country.Name, country.Code))`. |
| **Estilizar o controle** | Use as propriedades `builder.Font` antes de inserir o SDT para afetar o estilo padrão do texto do placeholder. |
| **Remover um controle posteriormente** | Localize‑o via `doc.GetChildNodes(NodeType.StructuredDocumentTag, true)` e chame `tag.Remove();`. |

## Como criar controle programaticamente – melhores práticas

1. **Crie o documento primeiro** – inicializar `DocumentBuilder` cedo evita surpresas na posição do cursor.  
2. **Defina títulos e tags** – eles atuam como identificadores estáveis para extração de dados posterior.  
3. **Adicione texto de placeholder** – melhora a experiência do usuário, especialmente para tags de texto simples.  
4. **Popule os itens de lista imediatamente** – o Word renderiza a lista suspensa corretamente somente após a lista ser anexada.  
5. **Salve uma única vez** – chamadas repetidas a `Save` dentro de um loop aumentam drasticamente a sobrecarga de I/O.  

Seguindo estas etapas, você garante que o arquivo Word seja tanto *legível por máquina* (para processamento back‑end) quanto *amigável ao usuário* (para edição front‑end).
