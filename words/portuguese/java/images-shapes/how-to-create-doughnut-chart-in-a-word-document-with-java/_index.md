# Como criar um gráfico de rosca em um documento Word com Java

Se você precisa **criar um gráfico de rosca** dentro de um arquivo Word, este tutorial mostra uma solução completa, pronta‑para‑executar. Você verá como **inserir um gráfico de pizza**, transformá‑lo em uma rosca, **girar o gráfico de pizza** para melhor equilíbrio e **formatar o gráfico de pizza** para combinar com a identidade visual da sua marca. Ao final, você terá um documento Word profissional que pode ser usado em relatórios, painéis ou anexos de e‑mail automatizados.

Criar um gráfico programaticamente elimina etapas manuais de copiar‑colar e garante um estilo consistente em dezenas de documentos gerados. O exemplo usa a biblioteca Aspose.Words for Java, que funciona com Java 8+ e não requer instalação do Microsoft Office. Não há outros pré‑requisitos além de um JDK padrão e sua IDE favorita.

## Pré‑requisitos

- Java Development Kit (JDK) 8 ou mais recente  
- Maven ou Gradle para gerenciamento de dependências (o tutorial usa Maven)  
- Biblioteca Aspose.Words for Java (licença de avaliação gratuita é suficiente para testes)  

Adicione a dependência Aspose.Words ao seu `pom.xml`:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-words</artifactId>
    <version>24.9</version> <!-- Use the latest stable version -->
</dependency>
```

> **Dica profissional:** Registre sua licença com `License license = new License(); license.setLicense("Aspose.Words.lic");` antes de criar qualquer documento para remover as marcas d'água de avaliação.

## Criar gráfico de rosca em um documento Word

O fluxo de trabalho principal consiste em cinco etapas lógicas. Cada etapa está encapsulada em seu próprio método para manter o código limpo e reutilizável.

```java
import com.aspose.words.*;
import com.aspose.words.drawing.*;

public class DoughnutChartDemo {

    public static void main(String[] args) throws Exception {
        // Step 1: create blank Word document
        Document doc = createBlankWordDocument();

        // Step 2: insert a pie chart (base for the doughnut)
        Chart chart = insertPieChart(doc, 400, 300);

        // Step 3: convert the pie chart into a doughnut and rotate it
        customizeChartAppearance(chart);

        // Step 4: apply additional formatting to the chart
        formatPieChart(chart);

        // Step 5: save the final document
        doc.save("output/DoughnutChartFormatted.docx");
        System.out.println("Document saved successfully.");
    }

    /** Step 1 – create blank Word document */
    private static Document createBlankWordDocument() {
        // Aspose.Words creates an empty document by default
        return new Document();
    }

    /** Step 2 – insert pie chart with given dimensions */
    private static Chart insertPieChart(Document doc, int width, int height) throws Exception {
        DocumentBuilder builder = new DocumentBuilder(doc);
        // ChartType.PIE creates a standard pie chart that we will later turn into a doughnut
        Chart chart = builder.insertChart(ChartType.PIE, width, height);
        // Populate the chart with sample data
        chart.getSeries().clear(); // Remove default series
        ChartSeries series = chart.getSeries().add("Sales", new String[]{"Q1", "Q2", "Q3", "Q4"},
                new double[]{15000, 23000, 18000, 27000});
        return chart;
    }

    /** Step 3 – rotate pie chart and make it a doughnut */
    private static void customizeChartAppearance(Chart chart) {
        // Explode the first slice for emphasis
        chart.getSeries().get(0).setExplode(20);
        // Convert the pie into a doughnut by setting a hole size (percentage of radius)
        chart.setHoleSize(30); // 30% hole creates a classic doughnut look
        // Rotate the chart so the largest slice starts at 45°
        chart.setRotationAngle(45);
    }

    /** Step 4 – additional formatting of the pie chart */
    private static void formatPieChart(Chart chart) {
        // Example: change the first slice color to a brand color
        chart.getSeries().get(0).getPoints().get(0).getFormat().setFillForegroundColor(Color.fromArgb(0xFF, 0x4A, 0x90));
        // Add a legend and position it at the bottom
        chart.setHasLegend(true);
        chart.getLegend().setPosition(LegendPosition.BOTTOM);
        // Set a title for the chart
        chart.setTitle("Quarterly Sales Distribution");
    }
}
```

### O que o código faz

| Etapa | Ação | Motivo |
|------|------|--------|
| **Criar documento Word em branco** | `new Document()` | Começa com um arquivo limpo para que você controle cada elemento. |
| **Inserir gráfico de pizza** | `builder.insertChart(ChartType.PIE, …)` | Um gráfico de pizza é a forma base; a Aspose fornece a rosca apenas ajustando o tamanho do buraco. |
| **Girar o gráfico de pizza** | `chart.setRotationAngle(45)` | Girar alinha a maior fatia a uma posição mais legível. |
| **Formatar o gráfico de pizza** | `setExplode`, `setHoleSize`, cor, legenda | Melhora a hierarquia visual e corresponde às diretrizes de estilo corporativo. |
| **Salvar documento** | `doc.save("…/DoughnutChartFormatted.docx")` | Grava o arquivo .docx final no disco, pronto para distribuição. |

## Inserir gráfico de pizza antes de converter para rosca

Aspose.Words não fornece um método direto “inserir gráfico de rosca”. Em vez disso, você **insere um gráfico de pizza** e depois modifica suas propriedades. Essa abordagem de duas etapas oferece controle total sobre a série de dados, explosão de fatias e tamanho do buraco. Se precisar de um gráfico de pizza puro em outro lugar, basta omitir a chamada `setHoleSize`.

## Girar o gráfico de pizza para equilíbrio visual

A orientação padrão inicia a primeira fatia na posição das 12 horas. Em muitos relatórios empresariais, a fatia mais importante deve começar em um ângulo mais natural, como 45 graus. O método `setRotationAngle(double angle)` aceita graus e gira todo o gráfico sem afetar os valores dos dados.

## Formatando o gráfico de pizza e personalizando a aparência

Além de converter para rosca, você costuma querer **formatar o gráfico de pizza**:

- **Explodir** a primeira fatia (`setExplode`) para chamar atenção.  
- **Colorir** cada fatia usando `getPoints().get(i).getFormat().setFillForegroundColor`.  
- **Posicionamento da legenda** (`setHasLegend`, `setPosition`) ajuda os leitores a interpretar as categorias.  
- **Título** (`setTitle`) fornece contexto de relance.  

Todas essas configurações são opcionais; você pode ajustá‑las para combinar com a paleta da sua marca ou com os modelos corporativos.

## Criar documento Word em branco e salvar o resultado

O método `createBlankWordDocument` encapsula a etapa **criar documento Word em branco**. Manter essa lógica isolada facilita a reutilização do método ao gerar múltiplos relatórios em um processo em lote. Após todas as personalizações, `doc.save` grava o arquivo no formato padrão Office Open XML (`.docx`), que pode ser aberto no Microsoft Word, LibreOffice ou Google Docs sem perda de fidelidade.

### Saída esperada

Ao executar o método `main`, o console exibe:

```
Document saved successfully.
```

E o arquivo `output/DoughnutChartFormatted.docx` contém uma única página com um gráfico de rosca intitulado *Distribuição de Vendas Trimestrais*. O gráfico mostra quatro fatias, a primeira fatia explodida, colorida no tom da marca e girada 45 graus.

## Variações comuns e casos de borda

| Situação | Ajuste |
|----------|--------|
| **Mais de uma série de dados** | Adicione objetos `ChartSeries` adicionais a `chart.getSeries()`. |
| **Tamanho diferente do gráfico** | Altere os argumentos `width` e `height` em `insertPieChart`. |
| **Sem buraco (pizza pura)** | Omitir `chart.setHoleSize(…)` ou definir como `0`. |
| **Documentos grandes** | Use `DocumentBuilder` para inserir o gráfico em uma seção ou marcador específico. |
| **Licença não definida** | A biblioteca roda em modo de avaliação, adicionando uma marca d'água na primeira página. Registre uma licença para removê‑la. |

## Conclusão

Agora você sabe como **criar um gráfico de rosca** em um documento Word usando Java, desde **criar documento Word em branco** até **inserir gráfico de pizza**, **girar o gráfico de pizza** e **formatar o gráfico de pizza** para um produto final polido. O exemplo completo e executável pode ser inserido em qualquer projeto Java que já utilize Aspose.Words.
