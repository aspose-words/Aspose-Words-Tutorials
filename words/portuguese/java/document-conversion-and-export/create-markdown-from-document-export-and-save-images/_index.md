# Como converter docx para markdown com imagens em uma subpasta

Se você precisa **converter docx para markdown** mantendo cada imagem incorporada bem organizada, você está no lugar certo. Muitos desenvolvedores geram relatórios, manuais ou rascunhos de blog programaticamente e acabam com uma mistura caótica de arquivos de imagem espalhados pelo diretório de saída. Este tutorial mostra uma abordagem limpa, orientada por callbacks, usando Aspose.Words para .NET que exporta um documento para markdown, armazena cada imagem em uma pasta dedicada *md‑resources* e salva o arquivo markdown final pronto para publicação.

> **Visão rápida:**  
> • Configurar `MarkdownSaveOptions`  
> • Implementar um `IResourceSavingCallback` para redirecionar imagens  
> • Chamar `Document.Save` com as opções configuradas  

Agora que você entende por que um callback é preferível ao pós‑processamento, vamos mergulhar na solução passo a passo.

## Respostas rápidas
- **O que realmente faz “convert docx to markdown”?** Ele transforma a marcação de processamento de texto do Word em markdown de texto simples, preservando cabeçalhos, listas, tabelas e referências de imagens.  
- **Qual biblioteca realiza a conversão?** Aspose.Words para .NET fornece uma API totalmente gerenciada, do lado do servidor, que funciona sem o Microsoft Word instalado.  
- **Preciso escrever algum código de processamento de imagens?** Não; o `IResourceSavingCallback` cuida de salvar cada imagem na pasta que você especificar.  
- **Posso mudar o nome da pasta de saída?** Absolutamente – substitua `"md-resources/"` por qualquer caminho relativo ou absoluto que preferir.  
- **A solução é compatível com .NET 6 e posteriores?** Sim, funciona em .NET 6+, .NET 5, .NET Core 3.1 e .NET Framework 4.7+.

## O que é converter docx para markdown?
**Convert docx to markdown** é o processo de pegar um documento Microsoft Word (DOCX) e gerar um arquivo markdown (`.md`) que representa o mesmo conteúdo usando a sintaxe markdown. A conversão preserva elementos estruturais e, opcionalmente, extrai recursos incorporados como imagens.

A conversão é realizada pelo Aspose.Words, uma biblioteca que suporta **mais de 35 formatos de entrada e saída** — incluindo DOCX, PDF, HTML e Markdown — permitindo que você manipule documentos de várias centenas de páginas sem carregar o arquivo inteiro na memória.

## Por que usar Aspose.Words para exportação markdown?
Aspose.Words processa documentos na memória e grava o resultado diretamente no formato de destino, o que significa:

Aspose.Words fornece conversão de alto desempenho e precisa, ao mesmo tempo que lhe dá controle total sobre o gerenciamento de recursos. Ele elimina a necessidade de etapas de pós‑processamento, reduz o uso de memória e garante que imagens, tabelas e estilos sejam reproduzidos fielmente na saída markdown.

- **Velocidade:** Arquivos DOCX típicos de 200 páginas são convertidos para markdown em menos de 2 segundos em uma VM padrão.  
- **Precisão:** Todas as mais de 50 variações de markdown incorporadas são suportadas, garantindo que tabelas, blocos de código e notas de rodapé sejam renderizados corretamente.  
- **Controle de recursos:** O `IResourceSavingCallback` incorporado permite que você decida exatamente onde cada imagem será salva, eliminando a necessidade de uma etapa de limpeza separada.

## Pré-requisitos

- .NET 6.0 ou posterior (compatível também com .NET Framework 4.7+)  
- Aspose.Words para .NET (pacote NuGet `Aspose.Words`)  
- Um objeto `Document` de origem (DOCX, PDF, RTF, etc.)  

Nenhuma biblioteca extra é necessária; a API de callback faz parte do Aspose.Words.

## Como converter docx para markdown?

Carregue seu documento de origem com `new Document("source.docx")`, configure `MarkdownSaveOptions` para usar um callback que grava cada imagem em `md-resources/`, e então chame `doc.Save("output.md", saveOptions)`. Esse padrão de três etapas converte o arquivo, extrai as imagens e produz um arquivo markdown limpo com links de imagem relativos — tudo em uma única chamada de método.

### Etapa 1: configurar opções de salvamento para conversão markdown

MarkdownSaveOptions configura como o Aspose.Words converte um documento para Markdown.

```csharp
// Step 1: Initialize Markdown save options
var markdownSaveOptions = new Aspose.Words.Saving.MarkdownSaveOptions();
```

```csharp
// Step 1: Initialize Markdown save options
var markdownSaveOptions = new Aspose.Words.Saving.MarkdownSaveOptions();
```

> **Por que isso importa:**  
> Sem criar explicitamente `MarkdownSaveOptions`, a biblioteca recorre às configurações padrão que incorporam imagens diretamente no arquivo Markdown como strings Base64. Isso torna o arquivo enorme e desfaz o objetivo de ter uma pasta *images* limpa.

### Etapa 2: definir um callback de salvamento de recursos para exportar imagens

`IResourceSavingCallback` permite que você controle onde cada recurso (imagem, SVG) é salvo durante a exportação.

Agora informamos ao salvador **onde** colocar cada imagem. A interface `IResourceSavingCallback` nos fornece um hook que dispara para cada recurso (imagem, SVG, etc.) descoberto durante a exportação. Dentro do callback nós:

1. Garantir que a pasta de destino exista (`md-resources/`).  
2. Definir `OutputFileName` para a pasta mais o nome original do recurso.  

```csharp
// Step 2: Hook into the resource‑saving pipeline
markdownSaveOptions.ResourceSavingCallback = new Aspose.Words.Saving.IResourceSavingCallback(
    (args) =>
    {
        // All images will be placed in "md-resources" relative to the output .md file
        const string folder = "md-resources/";
        Directory.CreateDirectory(folder);          // Create folder if it doesn’t exist

        // Preserve the original file name (e.g., image001.png) but prepend the folder path
        args.OutputFileName = Path.Combine(folder, args.ResourceFileName);

        // Optional: you could also change the format here (e.g., convert BMP to PNG)
        // args.ResourceFileName = Path.ChangeExtension(args.ResourceFileName, ".png");
    });
```

> **Pergunta comum:** *E se eu quiser incorporar imagens em vez de salvá‑las?*  
> Basta pular o callback ou definir `args.OutputFileName = null;` — o salvador incorporará a imagem como uma string Base64 automaticamente.

> **Caso extremo:** Alguns documentos mais antigos contêm nomes de imagem duplicados. O callback acima sobrescreverá o arquivo anterior. Para evitar isso, você pode acrescentar um GUID:

```csharp
args.OutputFileName = Path.Combine(folder,
    $"{Path.GetFileNameWithoutExtension(args.ResourceFileName)}_{Guid.NewGuid()}{Path.GetExtension(args.ResourceFileName)}");
```

### Etapa 3: salvar o documento como markdown e verificar a saída

Com as opções totalmente configuradas, a chamada final é uma única linha que grava o arquivo Markdown e as imagens associadas no disco.

```csharp
// Step 3: Perform the actual export
string outputPath = @"C:\Exports\MyReport.md";
doc.Save(outputPath, markdownSaveOptions);
```

Se tudo correr bem, você verá:

- `MyReport.md` – a representação Markdown do seu documento de origem.  
- `md-resources/` – uma pasta ao lado do arquivo `.md` contendo todas as imagens extraídas (por exemplo, `image001.png`, `image002.jpg`).  

**Trecho de markdown de exemplo** (gerado automaticamente pelo Aspose.Words):

```markdown
# Sample Report

Here is an introductory paragraph.

![Sample image](md-resources/image001.png)

More text follows...
```

[Imagem de exemplo](md-resources/image001.png)

> **Dica profissional:** Abra o arquivo `.md` gerado no VS Code ou em qualquer visualizador de Markdown; as imagens devem ser renderizadas instantaneamente porque os caminhos relativos correspondem à estrutura de pastas.

## Exemplo completo e executável (sem blocos de código adicionais)

Abaixo está um programa de console autônomo que você pode colar em um novo projeto .NET e executar. Ele cria um documento Word simples, adiciona uma imagem e então **cria markdown a partir do documento** enquanto armazena a imagem em uma subpasta.

```csharp
using System;
using System.IO;
using Aspose.Words;
using Aspose.Words.Saving;

class Program
{
    static void Main()
    {
        // 1️⃣ Create a sample Word document with an image
        var doc = new Document();
        var builder = new DocumentBuilder(doc);
        builder.Writeln("Hello, this is a test document.");
        builder.InsertImage("sample-image.png"); // Ensure this file exists next to exe

        // 2️⃣ Configure markdown export options (see Step 1 & 2 above)
        var markdownOptions = new MarkdownSaveOptions();
        markdownOptions.ResourceSavingCallback = new IResourceSavingCallback(
            (args) =>
            {
                const string folder = "md-resources/";
                Directory.CreateDirectory(folder);
                args.OutputFileName = Path.Combine(folder, args.ResourceFileName);
            });

        // 3️⃣ Save as markdown (Step 3)
        string outputFolder = Path.Combine(Environment.CurrentDirectory, "output");
        Directory.CreateDirectory(outputFolder);
        string markdownPath = Path.Combine(outputFolder, "ExportedDoc.md");
        doc.Save(markdownPath, markdownOptions);

        Console.WriteLine($"✅ Markdown saved to: {markdownPath}");
        Console.WriteLine("📂 Images saved in: md-resources/");
    }
}
```

**O que você deve ver** após a execução:

```
✅ Markdown saved to: C:\MyProject\output\ExportedDoc.md
📂 Images saved in: md-resources/
```

Abra `ExportedDoc.md` — a referência da imagem apontará para `md-resources/sample-image.png`, e a imagem será exibida corretamente em qualquer visualizador de Markdown.

## Variações frequentemente perguntadas

| Cenário | Como adaptar o código |
|----------|----------------------|
| **Ignorar exportação de imagem** (incorporar como Base64) | Omitir `ResourceSavingCallback` completamente, ou definir `args.OutputFileName = null;` dentro do callback. |
| **Alterar formato da imagem** (por exemplo, todas PNG) | Dentro do callback, modifique `args.ResourceFileName` e, opcionalmente, converta o fluxo antes de gravar. |
| **Nome de pasta personalizado** | Substitua `"md-resources/"` por qualquer caminho relativo ou absoluto que preferir. |
| **Múltiplos documentos em lote** | Itere sobre uma coleção de objetos `Document`, reutilizando a mesma instância de `MarkdownSaveOptions` (apenas certifique‑se de que a pasta seja limpa ou nomeada de forma única por execução). |

## Problemas comuns e soluções

- **Imagens não aparecem na visualização markdown** – Verifique se o caminho relativo no markdown (`md-resources/image001.png`) corresponde à localização real da pasta em relação ao arquivo `.md`.  
- **Nomes de imagem duplicados causando sobrescritas** – Anexe um identificador único (GUID ou contador incremental) dentro do callback para garantir nomes de arquivos distintos.  
- **Documentos grandes causando pressão de memória** – Use `Document.OptimizeResources()` antes de salvar; isso reduz o consumo de memória ao descartar streams não usados.  
- **Formatos de imagem não suportados** – Aspose.Words suporta PNG, JPEG, BMP, GIF e TIFF. Converta formatos não suportados para um desses antes de adicioná‑los ao documento de origem.  

## Perguntas frequentes

**Q: Posso usar esta abordagem em uma ASP .NET Web API que retorna um arquivo ZIP?**  
A: Sim. Gere o markdown e as imagens em uma pasta temporária, adicione‑as a um `ZipArchive` e envie o ZIP de volta ao cliente. O mesmo `MarkdownSaveOptions` e callback funcionam sem alterações.

**Q: A conversão preserva estilos do Word, como cabeçalhos e tabelas?**  
A: Absolutamente. Aspose.Words mapeia estilos de cabeçalho do Word para cabeçalhos markdown `#` e converte tabelas para a sintaxe de pipe markdown, preservando o conteúdo das células e o alinhamento.

**Q: É necessária uma licença comercial para uso em produção?**  
A: Sim. Uma licença de avaliação gratuita está disponível para testes, mas implantações em produção precisam de uma licença comprada do Aspose.Words.

**Q: Como a biblioteca lida com documentos protegidos por senha?**  
A: Carregue o documento com `new Document("file.docx", new LoadOptions { Password = "yourPassword" })` antes de invocar a rotina de salvamento markdown.

**Q: Quais versões do .NET são oficialmente suportadas?**  
A: Aspose.Words suporta .NET Framework 4.7+, .NET Core 3.1+, .NET 5, .NET 6 e posteriores.

- Implemente `IResourceSavingCallback` para direcionar imagens a uma pasta dedicada, mantendo seu markdown organizado.  
- A mesma técnica funciona para outros tipos de recursos (SVG, áudio) verificando `args.ResourceType`.
