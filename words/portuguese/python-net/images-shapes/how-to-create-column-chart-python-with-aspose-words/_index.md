# Como criar um gráfico de colunas em Python com Aspose.Words

Se você precisa criar um gráfico de colunas em Python, este guia mostra o código exato e o raciocínio necessários. Usando a API de gráficos do Aspose.Words, você pode definir dimensões precisas, aplicar um estilo embutido e exportar o resultado sem sair do Python.

Gerar um gráfico de colunas é uma necessidade comum para relatórios, dashboards e criação automatizada de documentos. Este tutorial cobre cada passo — desde a importação da biblioteca até a verificação da imagem salva — para que você possa integrar a geração de gráficos em qualquer projeto Python.

## Pré‑requisitos

Antes de começar, certifique-se de que você tem:

* Python 3.8 ou mais recente instalado.
* Uma licença válida do Aspose.Words for Python (ou uma chave de avaliação gratuita).
* Familiaridade básica com módulos Python e código orientado a objetos.

O mecanismo de gráficos do Aspose.Words funciona no Windows, macOS e Linux, e não requer bibliotecas gráficas adicionais porque a renderização ocorre no lado do servidor.

## Etapa 1: Importar a biblioteca Aspose.Words

O primeiro passo é importar o pacote `aspose.words` e dar a ele um alias curto. Importar no topo do arquivo mantém o namespace organizado e facilita a leitura do código.

```python
# Step 1: Import the Aspose.Words library
import aspose.words as aw
```

`aw` agora referencia a API completa do Aspose.Words, incluindo a classe `Chart` que você usará para construir o gráfico de colunas.

## Etapa 2: Criar um gráfico de colunas com as dimensões desejadas

Um gráfico de colunas precisa de valores explícitos de largura e altura para que a imagem renderizada se ajuste ao layout do seu documento. O construtor `Chart` recebe três argumentos: o tipo de gráfico, a largura (em pontos) e a altura (em pontos). Usar `aw.ChartType.COLUMN` indica ao motor que ele deve gerar um gráfico de barras vertical.

```python
# Step 2: Create a column chart with the desired dimensions
chart = aw.Chart(aw.ChartType.COLUMN, 400, 300)   # width=400pt, height=300pt
```

*Por que definir dimensões?*  
Ao incorporar o gráfico em um documento Word ou exportá‑lo como imagem, o conteúdo ao redor respeita o tamanho exato que você fornece. Isso evita escalonamento ou recorte indesejado.

### Dica profissional: Use `chart.dimensions` para redimensionamento dinâmico

Se o seu conjunto de dados variar, você pode calcular o tamanho com base no número de séries:

```python
series_count = 5
base_width = 80
chart.width = base_width * series_count
chart.height = 300
```

## Etapa 3: Aplicar um estilo embutido ao gráfico de colunas

O Aspose.Words vem com vários temas visuais predefinidos. Selecionar um estilo elimina a necessidade de configurar cores, fontes e linhas de grade manualmente. `aw.ChartStyle.STYLE_5` oferece um visual limpo e profissional, adequado para a maioria dos relatórios de negócios.

```python
# Step 3: Apply a built‑in style to the chart
chart.style = aw.ChartStyle.STYLE_5
```

Se preferir uma aparência diferente, substitua `STYLE_5` por qualquer outra constante (`STYLE_1` … `STYLE_8`). Cada estilo segue a mesma convenção de nomenclatura, facilitando a experimentação.

### Caso limite: Constante de estilo inválida

Tentar atribuir um estilo inexistente gera `AttributeError`. Proteja seu código verificando a constante contra a enumeração:

```python
if hasattr(aw.ChartStyle, "STYLE_5"):
    chart.style = aw.ChartStyle.STYLE_5
else:
    raise ValueError("Requested chart style does not exist.")
```

## Etapa 4: Adicionar séries de dados ao gráfico de colunas

Um gráfico sem dados não tem sentido. Você pode adicionar um ou mais objetos `ChartSeries`, cada um representando um grupo de colunas. O exemplo a seguir adiciona uma única série com três pontos de dados.

```python
# Step 4: Add data series to the column chart
series = chart.series.add()
series.name = "Quarterly Sales"
series.data = [12000, 15000, 18000]   # Values for Q1, Q2, Q3
```

Você pode repetir a chamada `chart.series.add()` para incluir séries adicionais (por exemplo, “Vendas Projetadas”). A API distribui automaticamente as colunas lado a lado.

## Etapa 5: Renderizar o gráfico e salvá‑lo como imagem

Depois de configurar o gráfico, você o renderiza para um bitmap ou arquivo de imagem. O método `save` aceita um caminho de arquivo e um formato opcional. PNG é sem perdas e amplamente suportado.

```python
# Step 5: Render and save the chart as a PNG image
output_path = "column_chart.png"
chart.save(output_path, aw.SaveFormat.PNG)
print(f"Chart saved to {output_path}")
```

A enumeração `SaveFormat` inclui PNG, JPEG, BMP e outros. Escolha o formato que corresponde ao seu fluxo de trabalho posterior.

## Verificar a saída

Abra `column_chart.png` com qualquer visualizador de imagens. Você deverá ver um gráfico de barras de três colunas estilizado com o tema embutido escolhido, com tamanho exatamente de 400 × 300 pontos.

![Gráfico de colunas gerado pelo Aspose.Words em Python](column_chart.png){: .center alt="Captura de tela de um gráfico de colunas gerado pelo Aspose.Words em Python"}

Se a imagem aparecer em branco ou distorcida, verifique o seguinte:

1. O objeto `aw.Chart` foi instanciado antes de adicionar as séries.
2. A constante `chart.style` corresponde a um valor existente da enumeração.
3. A chamada `save` usa um `SaveFormat` suportado.

## Variações comuns e dicas adicionais

| Situação | Alteração recomendada |
|-----------|--------------------|
| **Múltiplas séries de dados** | Adicione blocos adicionais `chart.series.add()` e defina `series.name` e `series.data` para cada um. |
| **Cores personalizadas** | Após aplicar um estilo embutido, sobrescreva as cores individuais das colunas via `series.points[i].fill.fore_color`. |
| **Incorporação em um documento Word** | Em vez de `chart.save()`, use `doc = aw.Document(); doc.sections[0].body.append_child(chart); doc.save("report.docx")`. |
| **Dimensionamento dinâmico** | Calcule a largura com base no número de séries (`width = 80 * len(chart.series)`). |

Essas variações demonstram como o mesmo código central se adapta a diferentes cenários de relatório.

## Conclusão

Agora você sabe como criar um gráfico de colunas em Python usando Aspose.Words, definir dimensões exatas do gráfico, aplicar um estilo embutido e exportar o resultado como imagem. O fluxo de trabalho completo — importação, instanciação, estilo, preenchimento e renderização — cobre os casos de uso mais comuns para relatórios automatizados.

Experimente diferentes opções de **estilização de gráficos de colunas** para adequar ao seu guia de estilo, e você terá uma solução robusta e pronta para produção em Python.
