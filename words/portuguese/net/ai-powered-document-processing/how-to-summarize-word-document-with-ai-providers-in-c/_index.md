# Como resumir documento Word com provedores de IA em C#

Se você precisa **resumir documento Word** rapidamente, este guia mostra exatamente como fazer. Você verá um exemplo completo e executável que permite **escolher provedor de IA** (OpenAI ou Google) e lidar com um cenário de **resumir documento grande** sem sair do seu IDE.

Resumir um documento Word é uma tarefa comum ao criar bots de base de conhecimento, resumos de relatórios ou briefings de e‑mail automatizados. Nas seções abaixo, você aprenderá qual pacote NuGet instalar, como carregar um arquivo `.docx`, configurar o resumidor e gerar o resultado — tudo em C# puro.

## O que você precisará

| Requisito | Motivo |
|-------------|--------|
| .NET 6 SDK or later | Fornece o runtime para o exemplo em C# |
| Visual Studio 2022 (or any IDE) | Facilita a adição de pacotes NuGet e a execução do aplicativo console |
| `GroupDocs.Summarization` NuGet package | Fornece a API `DocumentSummarizer` usada no código |
| An internet connection | Necessária para que o provedor de IA (OpenAI ou Google) processe o texto |

> **Dica profissional:** Se você planeja **resumir documento grande** arquivos (mais de 100 KB), habilite o modo de streaming nas opções para evitar carregar o arquivo inteiro na memória.

## Como resumir documento Word passo a passo

### Etapa 1: Instalar a biblioteca de resumo

Abra o Console do Gerenciador de Pacotes e execute:

```powershell
Install-Package GroupDocs.Summarization
```

A biblioteca `GroupDocs.Summarization` abstrai as chamadas de IA subjacentes, permitindo que você troque de provedor sem alterar a lógica de negócios.

### Etapa 2: Carregar o documento Word

```csharp
using GroupDocs.Summarization;
using GroupDocs.Summarization.Options;

// Step 2: Load the source document
Document doc = new Document("YOUR_DIRECTORY/Report.docx");
```

A classe `Document` lê o arquivo `.docx` e o prepara para o resumo. Se o arquivo for grande, a biblioteca usa automaticamente um analisador eficiente em memória.

### Etapa 3: Configurar opções do resumidor e **escolher provedor de IA**

```csharp
// Step 3: Set up summarization options (choose the AI provider)
SummarizerOptions options = new SummarizerOptions
{
    Provider = SummarizerProvider.OpenAI   // or SummarizerProvider.Google
};
```

- `Provider = SummarizerProvider.OpenAI` seleciona o modelo GPT‑4 da OpenAI.  
- `Provider = SummarizerProvider.Google` seleciona o modelo Gemini da Google, que é ideal quando você **resuma com Google** para melhor suporte multilíngue.

Você **escolhe provedor de IA** com base em custo, latência ou requisitos de idioma. O mesmo objeto `options` funciona para ambos os provedores, mantendo seu código limpo.

### Etapa 4: Gerar o resumo – suporte a **resumir documento grande**

```csharp
// Step 4: Generate the summary using the selected provider
string summary = DocumentSummarizer.Summarize(doc, options);
```

Quando você **resume documento grande**, a biblioteca transmite o conteúdo para o serviço de IA, evitando erros de falta de memória. O método `Summarize` retorna uma string em texto simples que contém as frases mais relevantes.

### Etapa 5: Exibir o resultado

```csharp
// Step 5: Output the generated summary
Console.WriteLine("Summary:\n" + summary);
```

Executar o programa exibe um parágrafo conciso que captura a essência do arquivo Word original.

## Exemplo completo executável

```csharp
using System;
using GroupDocs.Summarization;
using GroupDocs.Summarization.Options;

namespace WordSummarizerDemo
{
    class Program
    {
        static void Main(string[] args)
        {
            // Load the source Word document
            Document doc = new Document("YOUR_DIRECTORY/Report.docx");

            // Choose the AI provider (OpenAI or Google)
            SummarizerOptions options = new SummarizerOptions
            {
                Provider = SummarizerProvider.Google   // Change to OpenAI if you prefer
            };

            // Generate the summary – works for both small and large documents
            string summary = DocumentSummarizer.Summarize(doc, options);

            // Display the summary in the console
            Console.WriteLine("Summary:\n" + summary);
        }
    }
}
```

**Saída esperada**

```
Summary:
The quarterly sales increased by 12% driven by the new product line, while operational costs fell 3% due to efficiency gains. The report also highlights upcoming market expansion in APAC and recommends allocating additional budget to R&D.
```

A redação exata diferirá dependendo do modelo de IA que você **escolher provedor de IA**, mas a estrutura permanecerá a mesma.

## Lidando com um cenário de **resumir documento grande**

Quando o `.docx` de origem ultrapassa 5 MB, considere estes ajustes:

1. **Habilitar chunking** – a biblioteca divide o documento em blocos de 5 KB antes de enviá-los ao serviço de IA.  
2. **Aumentar `MaxSentences`** em `SummarizerOptions` se precisar de um resumo mais longo.  
3. **Definir `Timeout`** para um valor maior para acomodar tempos de processamento mais longos.

```csharp
options.MaxSentences = 8;          // Return up to 8 sentences
options.EnableChunking = true;    // Essential for very large files
options.Timeout = TimeSpan.FromMinutes(2);
```

Esses ajustes garantem que a operação de **resumir documento grande** permaneça rápida e confiável.

## Como **resumir com Google** efetivamente

O modelo Gemini da Google se destaca em conteúdo multilíngue e formulação concisa. Para obter os melhores resultados:

- **Especificar idioma** (opcional) se o documento contiver texto não‑inglês:  
  ```csharp
  options.Language = "es"; // Spanish
  ```
- **Ajustar temperatura** para controlar a criatividade:  
  ```csharp
  options.Temperature = 0.3; // More deterministic output
  ```

Quando você **resume com Google**, o serviço pode retornar um resumo ligeiramente mais curto, porém altamente focado, comparado ao da OpenAI. Teste ambos os provedores em um documento de exemplo para decidir qual se adequa ao seu produto.

## Armadilhas comuns e como evitá‑las

| Sintoma | Causa | Correção |
|---------|-------|-----|
| Resumo vazio | Chave do provedor ausente ou rede bloqueada | Verifique as chaves de API nas variáveis de ambiente e assegure que o HTTPS de saída está permitido |
| Texto truncado | Documento excede o limite de tokens do provedor | Habilite `EnableChunking` ou aumente `MaxTokens` se a biblioteca suportar |
| Idioma inesperado | Opção `Language` incorreta | Remova a opção ou defina-a para o idioma real do documento |

Resolver esses problemas cedo economiza tempo de depuração, especialmente quando você **escolhe provedor de IA** para cargas de trabalho de produção.

Experimente `MaxSentences`, `Temperature` e as configurações de chunking para ajustar finamente a saída ao seu cenário específico.
