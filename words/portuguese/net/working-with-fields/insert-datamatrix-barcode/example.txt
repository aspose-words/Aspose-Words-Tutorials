//ExSummary: Este tutorial demonstra como criar um novo documento Word, inserir um campo DISPLAYBARCODE, configurá-lo para um código de barras DataMatrix e renderizar a imagem do código de barras usando as classes Document e DocumentBuilder.
//ExStepSummary:0: Crie um novo Documento Word vazio e um DocumentBuilder para editá-lo.
//ExStepSummary:1: Insira um campo DISPLAYBARCODE na posição atual do cursor, o que adiciona um marcador de posição de campo ao documento.
//ExStepSummary:2: Defina o BarcodeType do campo como DataMatrix e forneça a string de dados a ser codificada.
//ExStepSummary:3: Opcionalmente, defina as cores de fundo e de primeiro plano do código de barras.
//ExStepSummary:4: Chame UpdateFields no documento para renderizar a imagem do código de barras dentro do campo.
//ExStepSummary:5: Salve o documento em um arquivo .docx.
//ExStepImage:4:images/1.png
//ExStep:0-
// Initialise an empty Word document.
Document document = new Document();
DocumentBuilder docBuilder = new DocumentBuilder(document);

//ExStep:1-
// Add a DISPLAYBARCODE field to the document.
FieldDisplayBarcode displayBarcodeField = (FieldDisplayBarcode)docBuilder.InsertField(FieldType.FieldDisplayBarcode, true);

//ExStep:2-
// Define the barcode format as DataMatrix and assign a sample payload.
displayBarcodeField.BarcodeType = "DataMatrix";
displayBarcodeField.BarcodeValue = "9876543210";

//ExStep:3-
// (Optional) Specify background and foreground colours.
displayBarcodeField.BackgroundColor = "0xFFFFFF";
displayBarcodeField.ForegroundColor = "0x000000";

//ExStep:4-
// Refresh all fields so the barcode image is rendered.
document.UpdateFields();

//ExStep:5-
// Persist the document to a file.
document.Save("DataMatrix_BarcodeDemo.docx");
//ExEnd
