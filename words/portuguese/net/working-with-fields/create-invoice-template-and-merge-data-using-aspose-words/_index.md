# Criar modelo de fatura e mesclar dados usando Aspose.Words

Se você precisa **criar um modelo de fatura** rapidamente, este guia mostra exatamente como fazer. Ao final das duas primeiras frases, você conhecerá o fluxo completo para transformar um arquivo Word em branco em uma fatura totalmente preenchida, usando a API de mesclagem de correspondência de baixo código do Aspose.Words.

Gerar faturas é uma necessidade comum para sistemas de cobrança, integrações ERP e relatórios automatizados. Neste tutorial você aprenderá **como fazer mail merge**, **preencher modelo Word**, **mesclar dados no Word** e, finalmente, **salvar o documento mesclado** — tudo com algumas linhas de C#.

## O que você vai alcançar

* Um modelo Word reutilizável (`InvoiceTemplate.docx`) que contém campos de mesclagem para cliente, data, itens de linha e total.  
* Um programa C# que carrega o modelo, injeta um objeto de dados fortemente tipado e grava o resultado em `Invoice_001.docx`.  
* Visão sobre casos de borda, como coleções vazias, tipos de dados personalizados e manipulação de caminhos de arquivo.

### Pré‑requisitos

| Requisito | Por que é importante |
|-------------|----------------|
| .NET 6 ou posterior | Aspose.Words for .NET suporta .NET 6+ e fornece a API de baixo código usada neste guia. |
| Pacote NuGet Aspose.Words for .NET (`Aspose.Words`) | Fornece `Document`, `MailMerger` e tipos relacionados. |
| Conhecimento básico de C# | Necessário para entender objetos anônimos e LINQ. |
| Visual Studio 2022 (ou qualquer IDE) | Torna a edição e depuração mais simples. |

> **Dica profissional:** Instale o pacote NuGet via Console do Gerenciador de Pacotes:  
> `Install-Package Aspose.Words`

## Como criar modelo de fatura com mail merge de baixo código

O primeiro passo é construir um arquivo Word que contenha campos de mesclagem correspondentes às propriedades do objeto de dados que você passará posteriormente. Salve o arquivo como `InvoiceTemplate.docx` em uma pasta que você controla (por exemplo, `C:\Invoices\Template`).

| Campo de mesclagem | Exemplo de placeholder no Word |
|-------------|-----------------------------|
| CustomerName | «CustomerName» |
| InvoiceDate | «InvoiceDate» |
| Items (repetindo) | «Items.Description», «Items.Qty», «Items.Price» |
| Total | «Total» |

> **Por que isso importa:** A API de baixo código mapeia automaticamente os nomes das propriedades da fonte de dados para os campos de mesclagem. Manter os nomes idênticos elimina o mapeamento manual campo‑para‑propriedade e reduz erros em tempo de execução.

## Etapa 1: Carregar o modelo de fatura

```csharp
using Aspose.Words;
using Aspose.Words.LowCode;   // Low‑code mail‑merge API

// Load the Word file that contains the merge fields.
Document template = new Document(@"C:\Invoices\Template\InvoiceTemplate.docx");
```

*A classe `Document` representa todo o arquivo Word. Carregá‑lo uma única vez permite reutilizar o mesmo modelo para várias faturas.*

## Etapa 2: Preparar a fonte de dados

Crie um objeto anônimo que reflita os campos de mesclagem. A API de baixo código pode trabalhar com qualquer objeto .NET, incluindo arrays e coleções aninhadas.

```csharp
var invoiceData = new
{
    CustomerName = "Acme Corp",
    InvoiceDate = DateTime.Today,
    Items = new[]
    {
        new { Description = "Widget A", Qty = 10, Price = 9.99M },
        new { Description = "Widget B", Qty = 5,  Price = 19.95M }
    },
    Total = 199.85M
};
```

**Por que isso funciona:**  
* Os nomes das propriedades (`CustomerName`, `InvoiceDate`, `Items`, `Total`) correspondem aos campos de mesclagem no modelo.  
* `Items` é um array de objetos, portanto o mail merger repetirá a linha da tabela para cada elemento automaticamente.  
* Usar `decimal` (`M` sufixo) para valores monetários evita problemas de arredondamento de ponto flutuante.

### Tratamento de coleções vazias

Se uma fatura não possuir itens de linha, passe um array vazio:

```csharp
Items = new object[0]
```

O mecanismo de baixo código simplesmente omitirá a seção repetitiva, mantendo o cabeçalho da tabela intacto.

## Etapa 3: Inicializar o mail merger de baixo código

```csharp
MailMerger merger = new MailMerger(template);
```

`MailMerger` é o ponto de entrada para **como fazer mail merge** com Aspose.Words. Ele lê o modelo, vincula os dados e prepara o documento final em uma única chamada.

## Etapa 4: Executar a mesclagem – preencher modelo Word em uma linha

```csharp
Document mergedDocument = merger.Execute(invoiceData);
```

* Esta linha **preenche o modelo Word** e produz uma nova instância `Document` (`mergedDocument`).  
* Todos os campos de mesclagem são substituídos, as seções repetitivas são expandidas e o documento resultante permanece totalmente na memória.

### Caso de borda: Formatação personalizada

Se precisar de um formato de data específico, adicione um formatador personalizado antes da mesclagem:

```csharp
merger.Options.DateFormat = "MMMM dd, yyyy"; // e.g., "October 07, 2026"
```

## Etapa 5: Salvar documento mesclado

```csharp
mergedDocument.Save(@"C:\Invoices\Output\Invoice_001.docx");
```

A chamada **save merged document** grava a fatura totalmente preenchida no disco. O arquivo pode agora ser aberto no Microsoft Word, enviado como anexo de e‑mail ou convertido para PDF.

### Verificando a saída

Abra `Invoice_001.docx`. Você deverá ver:

* **CustomerName** substituído por *Acme Corp*  
* **InvoiceDate** exibindo a data de hoje no formato escolhido  
* Uma linha de tabela para *Widget A* (10 × 9.99) e *Widget B* (5 × 19.95)  
* **Total** exibindo *199.85*  

Se algum campo permanecer inalterado (por exemplo, ainda mostrar «CustomerName»), verifique se os nomes das propriedades correspondem exatamente aos nomes dos campos de mesclagem no modelo.

## Exemplo completo executável

Abaixo está o programa completo que você pode copiar‑colar em um novo projeto de console.

```csharp
using System;
using Aspose.Words;
using Aspose.Words.LowCode;   // Low‑code mail‑merge API

namespace InvoiceGenerator
{
    class Program
    {
        static void Main()
        {
            // 1️⃣ Load the template
            Document template = new Document(@"C:\Invoices\Template\InvoiceTemplate.docx");

            // 2️⃣ Build the data source
            var invoiceData = new
            {
                CustomerName = "Acme Corp",
                InvoiceDate = DateTime.Today,
                Items = new[]
                {
                    new { Description = "Widget A", Qty = 10, Price = 9.99M },
                    new { Description = "Widget B", Qty = 5,  Price = 19.95M }
                },
                Total = 199.85M
            };

            // 3️⃣ Initialise the mail merger
            MailMerger merger = new MailMerger(template);

            // Optional: customise date format
            merger.Options.DateFormat = "MMMM dd, yyyy";

            // 4️⃣ Perform the merge (populate word template)
            Document mergedDocument = merger.Execute(invoiceData);

            // 5️⃣ Save the resulting file (save merged document)
            mergedDocument.Save(@"C:\Invoices\Output\Invoice_001.docx");

            Console.WriteLine("Invoice generated successfully.");
        }
    }
}
```

Execute o programa (`dotnet run`). O console exibirá *Invoice generated successfully.* e o arquivo aparecerá em `C:\Invoices\Output`.

## Perguntas comuns e solução de problemas

| Pergunta | Resposta |
|----------|----------|
| **E se o meu modelo usar delimitadores de campo diferentes?** | O Aspose.Words usa por padrão delimitadores « ». Você pode alterá‑los via `MailMerger.Options.FieldStartDelimiter` e `FieldEndDelimiter`. |
| **Como tratar valores nulos em campos de mesclagem?** | Defina o valor como `null` no objeto de dados; o motor removerá o marcador ou deixará o texto padrão, conforme a configuração `MailMerger.Options.RemoveEmptyParagraphs`. |
| **Posso mesclar imagens dinamicamente?** | Sim, use `DocumentBuilder.InsertImage` após a mesclagem ou configure campos de imagem com `MailMerger.ExecuteWithRegions`. |
| **O que fazer se a mesclagem falhar por causa de um caminho de arquivo inválido?** | Verifique se o caminho especificado em `Document.Load` ou `Document.Save` existe e tem permissões de leitura/escrita. Use `Path.Combine` para construir caminhos seguros. |
