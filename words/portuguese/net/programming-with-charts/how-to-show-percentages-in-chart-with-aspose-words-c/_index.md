# Como Exibir Percentuais em Gráficos com Aspose.Words C#

Já se perguntou **como exibir percentuais em um gráfico** sem lutar com interop complexa do Office? Você não está sozinho—muitos desenvolvedores se deparam com esse obstáculo quando precisam de uma maneira rápida e programática de rotular um gráfico de pizza ou rosca. A boa notícia? Com Aspose.Words for .NET você pode habilitar esses rótulos de dados em apenas algumas linhas.

Neste tutorial também abordaremos **add data labels to pie chart** e **how to enable chart data labels** para que suas visualizações se tornem instantaneamente mais informativas. Ao final, você terá um documento Word pronto‑para‑usar (`.docx`) que exibe um gráfico de pizza polido com percentuais posicionados ordenadamente fora de cada fatia.

## Pré-requisitos

- **Aspose.Words for .NET** (última versão, por exemplo, 24.9) instalado via NuGet.
- Um arquivo **ChartTemplate.docx** que já contém um gráfico de pizza ou rosca.  
  *(Se você não tem um, crie um documento Word simples, insira um gráfico de pizza e salve como `ChartTemplate.docx`.)*
- .NET 6.0 ou posterior e qualquer IDE que prefira (Visual Studio, Rider, VS Code).

Nenhuma dependência extra é necessária—Aspose.Words lida com tudo internamente.

## Como Exibir Percentuais em Gráficos – Passo a Passo

A seguir, dividimos o processo em seis etapas claras. Cada etapa inclui o código C# exato que você pode copiar‑colar, além de uma breve explicação do **porquê** fazemos isso.

### Etapa 1: Carregar o Documento Fonte

```csharp
using Aspose.Words;
using Aspose.Words.Drawing.Charts;

// Load the .docx that already holds a chart.
Document sourceDoc = new Document("YOUR_DIRECTORY/ChartTemplate.docx");
```

*Por quê?*  
`Document` é o ponto de entrada para qualquer manipulação de Word. Ao carregar o modelo, ganhamos acesso a todos os nós—formas, tabelas, texto e, claro, o gráfico que iremos modificar.

### Etapa 2: Obter a Primeira Forma de Gráfico

```csharp
// The chart lives inside a Shape node; retrieve it.
Chart chart = (Chart)sourceDoc.GetChild(NodeType.Shape, 0, true);
```

*Por quê?*  
Aspose armazena gráficos como objetos `Shape`. `GetChild` percorre a árvore do documento e retorna a primeira forma que encontra, que no nosso caso é o gráfico de pizza que queremos editar.

### Etapa 3: Confirmar o Tipo de Gráfico

```csharp
if (chart.ChartType == ChartType.Pie || chart.ChartType == ChartType.Doughnut)
{
    // Inside this block we’ll enable the data labels.
}
else
{
    throw new InvalidOperationException("The chart is not a Pie or Doughnut type.");
}
```

*Por quê?*  
Rótulos de percentual só fazem sentido para gráficos circulares. Essa verificação nos impede de aplicar acidentalmente as configurações a, por exemplo, um gráfico de barras onde `ShowPercentage` seria ignorado.

### Etapa 4: Habilitar Rótulos de Dados e Exibir Percentuais

```csharp
// Turn on data labels for the chart.
chart.HasDataLabel = true;

// Show the percentage value for each slice.
chart.DataLabel.ShowPercentage = true;
```

*Por quê?*  
`HasDataLabel` indica ao Aspose que deve renderizar um rótulo para cada ponto de dados. Definir `ShowPercentage` garante que o conteúdo do rótulo seja a parte calculada do total—exatamente o que o requisito **add data labels to pie chart** pede.

### Etapa 5: Posicionar Rótulos Fora das Fatias

```csharp
// Place the labels outside the pie slices for better readability.
chart.DataLabel.Position = ChartDataLabelPosition.OutSideEnd;
```

*Por quê?*  
Rótulos dentro da fatia podem ficar apertados, especialmente quando as fatias são pequenas. `OutSideEnd` imita o estilo padrão “externo” que você vê na interface do Word, mantendo o gráfico limpo.

### Etapa 6: Salvar o Documento Atualizado

```csharp
sourceDoc.Save("YOUR_DIRECTORY/FormattedPieChart.docx");
```

*Por quê?*  
Salvar grava todas as alterações em um novo arquivo. Abra `FormattedPieChart.docx` no Word e você verá os percentuais exibidos ao lado de cada fatia.

#### Resultado Esperado

Ao abrir `FormattedPieChart.docx`, o gráfico de pizza deve parecer semelhante a este (captura de tela imaginária):

```
[ Pie chart with three slices ]
- Slice A – 45%
- Slice B – 30%
- Slice C – 25%
```

Todos os percentuais são calculados automaticamente a partir da série de dados subjacente, e os rótulos ficam exatamente fora de cada fatia.

## Variações Comuns & Casos de Borda

| Situação | O que Ajustar |
|-----------|----------------|
| **Múltiplos gráficos** no mesmo documento | Percorra `sourceDoc.GetChildNodes(NodeType.Shape, true)` e faça cast de cada um para `Chart` antes de aplicar a mesma lógica. |
| **Gráfico de barras ou linhas** onde ainda deseja rótulos | Use `chart.DataLabel.ShowValue = true;` (ou `ShowSeriesName`) em vez de `ShowPercentage`. |
| **Formato numérico personalizado** (ex.: “45 %”) | Defina `chart.DataLabel.NumberFormat = "0%";` antes de salvar. |
| **Conjuntos de dados grandes** que causam sobreposição de rótulos | Considere `chart.DataLabel.ShowLeaderLines = true;` para desenhar linhas de ligação. |

> **Dica profissional:** Se você estiver gerando muitos documentos em lote, instancie um único objeto `Aspose.Words.License` no início da aplicação para evitar o impacto de desempenho ao carregar a licença repetidamente.

## Exemplo Completo Funcional

Aqui está o programa completo, pronto para ser executado:

```csharp
using System;
using Aspose.Words;
using Aspose.Words.Drawing.Charts;

class Program
{
    static void Main()
    {
        // 1️⃣ Load the template document.
        Document sourceDoc = new Document("YOUR_DIRECTORY/ChartTemplate.docx");

        // 2️⃣ Retrieve the first chart shape.
        Chart chart = (Chart)sourceDoc.GetChild(NodeType.Shape, 0, true);

        // 3️⃣ Ensure we’re dealing with a Pie or Doughnut chart.
        if (chart.ChartType != ChartType.Pie && chart.ChartType != ChartType.Doughnut)
        {
            Console.WriteLine("The selected shape is not a Pie/Doughnut chart.");
            return;
        }

        // 4️⃣ Enable data labels and show percentages.
        chart.HasDataLabel = true;
        chart.DataLabel.ShowPercentage = true;

        // 5️⃣ Position the labels outside the slices.
        chart.DataLabel.Position = ChartDataLabelPosition.OutSideEnd;

        // 6️⃣ Save the modified document.
        sourceDoc.Save("YOUR_DIRECTORY/FormattedPieChart.docx");

        Console.WriteLine("Chart updated successfully – percentages now visible!");
    }
}
```

Copie o código, substitua `YOUR_DIRECTORY` pelo caminho real em sua máquina e execute-o. Você terá um arquivo Word com um gráfico de pizza totalmente rotulado em segundos.
