# Criar documento Word em branco e ocultar uma forma elíptica em C#

Se você precisa **criar um documento Word em branco** e depois ocultar um elemento gráfico, este guia mostra exatamente como fazer isso com C#. Você verá um exemplo completo e executável que insere uma elipse, posiciona‑a, marca‑a como oculta e salva o arquivo — tudo em poucas linhas de código.

O tutorial cobre tudo, desde a configuração do projeto até a etapa final de verificação. Ao final, você poderá gerar um arquivo Word onde a elipse nunca aparece na tela nem na impressão, o que é útil para armazenar metadados, marcadores ou qualquer indicador invisível.

## Pré‑requisitos

Antes de começar, certifique‑se de que você tem:

* .NET 6.0 SDK ou posterior instalado  
* Um ambiente de desenvolvimento C# (Visual Studio 2022, Rider ou VS Code)  
* O pacote NuGet **Aspose.Words for .NET** (`Install-Package Aspose.Words`)  

Essas ferramentas fornecem as classes `Document` e `DocumentBuilder` usadas no exemplo de código.

## Etapa 1: Criar um documento Word em branco

A primeira operação cria um objeto `Document` vazio e um `DocumentBuilder` que permite adicionar conteúdo.

```csharp
using Aspose.Words;
using Aspose.Words.Drawing;

// Step 1: Initialize an empty document and a builder
Document doc = new Document();
DocumentBuilder builder = new DocumentBuilder(doc);
```

`Document` representa todo o pacote `.docx`, enquanto `DocumentBuilder` oferece uma API fluente para inserir texto, formas e outros objetos. Começar com um documento em branco lhe dá controle total sobre cada elemento que você adiciona.

## Etapa 2: Como inserir a elipse

Uma elipse é uma forma vetorial que pode ser usada como marcador. O método `InsertShape` requer o tipo da forma e sua largura/altura em pontos.

```csharp
// Step 2: Insert an ellipse shape of the desired size (100 pt × 50 pt)
Shape ellipse = builder.InsertShape(ShapeType.Ellipse, 100, 50);
```

A elipse fica na página atual na posição do cursor. Você pode alterar suas dimensões ajustando os argumentos numéricos.

## Etapa 3: Como posicionar a forma

Após a inserção, você pode mover a forma para qualquer lugar da página definindo as propriedades `Left` e `Top`, que usam pontos relativos à margem da página.

```csharp
// Step 3: Position the shape on the page
ellipse.Left = 150; // distance from the left margin
ellipse.Top  = 100; // distance from the top margin
```

Essas coordenadas posicionam a elipse aproximadamente na parte superior‑central de uma página A4 padrão. Ajuste os valores conforme os requisitos do seu layout.

## Etapa 4: Como ocultar a forma

Um objeto oculto não é exibido quando o documento é aberto ou impresso. Definir a bandeira `Hidden` marca a forma como um **hidden object word**.

```csharp
// Step 4: Hide the shape so it never appears
ellipse.Hidden = true;
```

O Word respeita a bandeira hidden tanto para a renderização na tela quanto para a saída de impressão. A forma permanece parte da estrutura do documento, permitindo que você a consulte ou modifique posteriormente por código.

## Etapa 5: Salvar o documento

Por fim, grave o documento no disco. Escolha uma pasta na qual você tenha permissão de gravação.

```csharp
// Step 5: Save the document to a .docx file
doc.Save(@"C:\Temp\HiddenEllipse.docx");
```

O arquivo `HiddenEllipse.docx` agora contém uma página em branco com uma forma elíptica oculta.

## Verificando a elipse oculta

Abra o arquivo gerado no Microsoft Word e habilite a opção **Mostrar texto oculto** (Arquivo → Opções → Exibição). Você verá um contorno tênue da elipse. Se desativar a opção, a forma desaparece completamente, confirmando que `ellipse.Hidden = true` funciona como esperado.

## Variações comuns e casos de borda

| Situação | Ajuste recomendado |
|-----------|------------------------|
| **Forma diferente** | Substitua `ShapeType.Ellipse` por `ShapeType.Rectangle`, `ShapeType.Arrow` etc. |
| **Múltiplos objetos ocultos** | Repita as etapas 2‑4 para cada forma; cada uma pode ter sua própria bandeira `Hidden`. |
| **Tamanho de página diferente** | Defina `doc.FirstSection.PageSetup.PageWidth` e `PageHeight` antes de inserir a forma. |
| **Visibilidade condicional** | Use `Shape.Visible` em combinação com `Hidden` para alternar em tempo de execução via código. |

**Dica profissional:** Armazene dados de identificação na propriedade `AlternativeText` da forma. Mesmo quando ocultada, você pode recuperar a forma posteriormente com `doc.GetChildNodes(NodeType.Shape, true)` e filtrá‑la por esse texto.

## Código‑fonte completo

Abaixo está o programa completo que você pode copiar, colar e executar.

```csharp
using System;
using Aspose.Words;
using Aspose.Words.Drawing;

namespace HiddenShapeDemo
{
    class Program
    {
        static void Main()
        {
            // Create a new blank document and a builder
            Document doc = new Document();
            DocumentBuilder builder = new DocumentBuilder(doc);

            // Insert an ellipse shape (100 pt × 50 pt)
            Shape ellipse = builder.InsertShape(ShapeType.Ellipse, 100, 50);

            // Position the shape on the page
            ellipse.Left = 150;
            ellipse.Top  = 100;

            // Hide the shape so it is invisible in the UI and on print
            ellipse.Hidden = true;

            // Optional: add a description for later retrieval
            ellipse.AlternativeText = "Hidden marker for internal processing";

            // Save the document
            string outputPath = @"C:\Temp\HiddenEllipse.docx";
            doc.Save(outputPath);

            Console.WriteLine($"Document saved to {outputPath}");
        }
    }
}
```

**Saída esperada:** O console imprime o caminho de salvamento, e o arquivo `HiddenEllipse.docx` abre como uma página em branco sem gráficos visíveis, a menos que objetos ocultos estejam habilitados.

## Conclusão

Agora você sabe como **criar um documento Word em branco** programaticamente, **como inserir uma elipse**, **como posicionar a forma** e **como ocultar a forma** para que ela se comporte como um **hidden object word**. Essa técnica é ideal para incorporar marcadores invisíveis, metadados personalizados ou marcadores de posição que processos subsequentes podem ler sem afetar o layout visual do documento.
