# Como criar shape oculto docx com Aspose.Words em C#

Se você precisa **criar shape oculto docx** programaticamente, este tutorial mostra os passos exatos usando Aspose.Words para .NET. Você verá como **definir a cor de preenchimento do shape** para que o shape fique visível durante a edição e, em seguida, **ocultar o shape no documento Word** para que o usuário final nunca o veja, a menos que objetos ocultos estejam exibidos.

O guia cobre tudo o que você precisa saber: pacotes NuGet necessários, um exemplo de código completo e executável, e dicas para solucionar armadilhas comuns. Ao final do artigo, você terá um DOCX que contém uma elipse invisível que pode ser revelada posteriormente, se necessário.

## Pré-requisitos

- .NET 6.0 SDK ou posterior instalado  
- Visual Studio 2022 (ou qualquer IDE C#)  
- Uma licença ativa do Aspose.Words para .NET (ou uma chave de avaliação temporária)  
- Familiaridade básica com a sintaxe C#  

Você **não** precisa de bibliotecas adicionais de interoperação com Word porque o Aspose.Words funciona independentemente do Microsoft Office.

## Etapa 1: Criar shape oculto docx – inicializar o documento

A primeira operação é instanciar um objeto `Document` e um `DocumentBuilder`. O builder fornece a API fluente para inserir shapes, texto e outros elementos.

```csharp
using Aspose.Words;
using Aspose.Words.Drawing;
using System.Drawing;

class Program
{
    static void Main()
    {
        // Initialise an empty DOCX file
        Document doc = new Document();
        DocumentBuilder builder = new DocumentBuilder(doc);
```

*Por que isso importa*: Um `Document` novo representa um arquivo Word vazio. O `DocumentBuilder` atua como um cursor que sabe onde o próximo elemento será colocado. Começar com um documento limpo garante que o shape oculto não herde formatação inesperada.

## Etapa 2: Definir a cor de preenchimento do shape para a elipse

Em seguida, insira um shape de elipse e aplique uma cor de preenchimento. A cor torna o shape visível no editor, o que é útil quando você precisa verificar seu tamanho ou posição antes de ocultá-lo.

```csharp
        // Insert an ellipse 150 pt wide and 100 pt high
        Shape ellipse = builder.InsertShape(ShapeType.Ellipse, 150, 100);

        // Apply a bright fill so the shape can be inspected
        ellipse.FillColor = Color.Yellow;
```

A etapa **definir a cor de preenchimento do shape** é opcional para o documento oculto final, mas ajuda durante o desenvolvimento. Sem preenchimento, o shape ficaria invisível mesmo antes de aplicar a flag oculta, dificultando a depuração.

## Etapa 3: Ocultar o shape no documento Word

Agora aplique a propriedade `Hidden`. Quando `Hidden` é `true`, o Microsoft Word não renderiza o shape na visualização normal. Os usuários ainda podem revelá‑lo ativando “Mostrar objetos ocultos” nas opções do Word.

```csharp
        // Mark the shape as hidden – it will not appear in normal view
        ellipse.Hidden = true;
```

*Nota importante*: A flag oculta funciona com Word 2010 e posteriores. Se você direcionar versões mais antigas, o shape pode ainda aparecer. Além disso, a flag não afeta a posição do shape; ela apenas suprime a renderização.

## Etapa 4: Salvar o arquivo DOCX

Finalmente, grave o documento no disco. O nome do arquivo pode ser qualquer caminho válido; aqui usamos um caminho relativo para simplificar.

```csharp
        // Persist the document with the hidden shape
        doc.Save("HiddenShape.docx");
    }
}
```

Quando você abrir `HiddenShape.docx` no Microsoft Word, a elipse não será visível. Se você ativar **File → Options → Display → Show hidden objects**, a elipse amarela aparecerá exatamente onde você a posicionou.

### Saída esperada

- Um arquivo chamado `HiddenShape.docx` no diretório de trabalho do executável.  
- Abrir o arquivo no Word mostra o conteúdo normal sem **shape visível**.  
- Ativar “Show hidden objects” revela uma elipse amarela de tamanho 150 × 100 pt.

## Etapa 5: Verificar o shape oculto programaticamente (opcional)

Se você precisar confirmar que o shape está realmente oculto sem abrir o Word, pode inspecionar a propriedade `Hidden` após carregar o documento:

```csharp
        Document loaded = new Document("HiddenShape.docx");
        Shape loadedShape = (Shape)loaded.GetChildNodes(NodeType.Shape, true)[0];
        System.Console.WriteLine($"Shape hidden? {loadedShape.Hidden}");
```

O console imprime `Shape hidden? True`, provando que a flag foi mantida.

## Armadilhas comuns e como evitá‑las

| Sintoma | Causa | Correção |
|---------|-------|----------|
| Shape ainda visível após salvar | `Hidden` não definido ou definido após salvar | Garanta que `ellipse.Hidden = true;` seja executado **antes** de `doc.Save()`. |
| Cor de preenchimento não aplicada | `FillColor` atribuído antes da criação do shape | Atribua `FillColor` **depois** que `InsertShape` retorne o objeto `Shape`. |
| DOCX falha ao abrir | Versão do Aspose.Words incompatível com o runtime .NET | Use o pacote NuGet mais recente do Aspose.Words que tem como alvo .NET 6+. |
| Flag oculta ignorada em versões antigas do Word | Word < 2010 | Considere usar uma técnica diferente (por exemplo, definir `WrapType` do shape como `None` e movê‑lo para fora da página). |

## Dica profissional: Reutilizar shapes ocultos como marcadores de posição

Você pode armazenar shapes ocultos em um documento modelo e substituí‑los posteriormente por conteúdo visível. Como o shape está oculto, ele não afeta o layout até que você defina `Hidden = false`. Esse padrão é útil para gerar contratos onde um campo de assinatura começa oculto e se torna visível após o usuário assinar.

## Próximos passos

- **Revelar shapes ocultos**: Use `shape.Hidden = false;` para fazer a elipse aparecer em tempo de execução.  
- **Alterar o tipo de shape**: Substitua `ShapeType.Ellipse` por `ShapeType.Rectangle`, `ShapeType.Polygon`, etc., para atender ao seu caso de uso.  
- **Adicionar texto dentro do shape**: Insira um `TextBox` na propriedade `TextBox` do shape para marcadores de posição com legenda.  
- **Combinar com mala‑direta**: Coloque shapes ocultos em um modelo de mala‑direta e altere a visibilidade por registro.  

Explorar esses tópicos reforça seu domínio dos fluxos de trabalho de **criar shape oculto docx** e amplia as possibilidades para geração automatizada de documentos.
