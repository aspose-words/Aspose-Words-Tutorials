# Créer un document Word vierge et masquer une forme d'ellipse en C#

Si vous devez **créer un document Word vierge** puis masquer un élément graphique, ce guide vous montre exactement comment le faire avec C#. Vous verrez un exemple complet et exécutable qui insère une ellipse, la positionne, la marque comme masquée et enregistre le fichier — le tout en quelques lignes de code.

Le tutoriel couvre tout, de la configuration du projet à l'étape de vérification finale. À la fin, vous pourrez générer un fichier Word où l'ellipse n'apparaît jamais à l'écran ni à l'impression, ce qui est utile pour stocker des métadonnées, des signets ou tout marqueur invisible.

## Prérequis

Avant de commencer, assurez‑vous d'avoir :

* SDK .NET 6.0 ou version ultérieure installé  
* Un environnement de développement C# (Visual Studio 2022, Rider ou VS Code)  
* Le package NuGet **Aspose.Words for .NET** (`Install-Package Aspose.Words`)  

Ces outils fournissent les classes `Document` et `DocumentBuilder` utilisées dans l'exemple de code.

## Étape 1 : Créer un document Word vierge

La première opération crée un objet `Document` vide et un `DocumentBuilder` qui vous permet d’ajouter du contenu.

```csharp
using Aspose.Words;
using Aspose.Words.Drawing;

// Step 1: Initialize an empty document and a builder
Document doc = new Document();
DocumentBuilder builder = new DocumentBuilder(doc);
```

`Document` représente l’ensemble du package `.docx`, tandis que `DocumentBuilder` offre une API fluide pour insérer du texte, des formes et d’autres objets. Commencer avec un document vierge vous donne un contrôle total sur chaque élément que vous ajoutez.

## Étape 2 : Insérer une ellipse

Une ellipse est une forme vectorielle qui peut servir de marqueur. La méthode `InsertShape` nécessite le type de forme ainsi que sa largeur/hauteur en points.

```csharp
// Step 2: Insert an ellipse shape of the desired size (100 pt × 50 pt)
Shape ellipse = builder.InsertShape(ShapeType.Ellipse, 100, 50);
```

L'ellipse apparaît sur la page courante à l'emplacement du curseur. Vous pouvez modifier ses dimensions en ajustant les arguments numériques.

## Étape 3 : Positionner la forme

Après l’insertion, vous pouvez déplacer la forme n’importe où sur la page en définissant les propriétés `Left` et `Top`, qui utilisent des points relatifs à la marge de la page.

```csharp
// Step 3: Position the shape on the page
ellipse.Left = 150; // distance from the left margin
ellipse.Top  = 100; // distance from the top margin
```

Ces coordonnées placent l'ellipse approximativement au centre‑haut d’une page A4 standard. Ajustez les valeurs selon les exigences de votre mise en page.

## Étape 4 : Masquer la forme

Un objet masqué n’est pas affiché lorsque le document est ouvert ou imprimé. Le réglage du drapeau `Hidden` marque la forme comme un **objet masqué**.

```csharp
// Step 4: Hide the shape so it never appears
ellipse.Hidden = true;
```

Word respecte le drapeau masqué tant pour le rendu à l’écran que pour la sortie imprimée. La forme reste partie intégrante de la structure du document, vous permettant de l’interroger ou de la modifier ultérieurement via le code.

## Étape 5 : Enregistrer le document

Enfin, écrivez le document sur le disque. Choisissez un dossier où vous avez les droits d’écriture.

```csharp
// Step 5: Save the document to a .docx file
doc.Save(@"C:\Temp\HiddenEllipse.docx");
```

Le fichier `HiddenEllipse.docx` contient maintenant une page vierge avec une forme d’ellipse masquée.

## Vérification de l'ellipse masquée

Ouvrez le fichier généré dans Microsoft Word et activez l’option **Afficher le texte masqué** (Fichier → Options → Affichage). Vous verrez un contour léger de l’ellipse. Si vous désactivez l’option, la forme disparaît complètement, confirmant que `ellipse.Hidden = true` fonctionne comme prévu.

## Variantes courantes et cas limites

| Situation | Ajustement recommandé |
|-----------|-----------------------|
| **Forme différente** | Remplacez `ShapeType.Ellipse` par `ShapeType.Rectangle`, `ShapeType.Arrow`, etc. |
| **Plusieurs objets masqués** | Répétez les étapes 2‑4 pour chaque forme ; chacune peut avoir son propre drapeau `Hidden`. |
| **Taille de page différente** | Définissez `doc.FirstSection.PageSetup.PageWidth` et `PageHeight` avant d’insérer la forme. |
| **Visibilité conditionnelle** | Utilisez `Shape.Visible` en combinaison avec `Hidden` pour basculer à l’exécution via le code. |

**Astuce :** Stockez les données d’identification dans la propriété `AlternativeText` de la forme. Même lorsqu’elle est masquée, vous pouvez récupérer la forme plus tard avec `doc.GetChildNodes(NodeType.Shape, true)` et la filtrer par ce texte.

## Code source complet

Voici le programme complet que vous pouvez copier, coller et exécuter.

```csharp
using System;
using Aspose.Words;
using Aspose.Words.Drawing;

namespace HiddenShapeDemo
{
    class Program
    {
        static void Main()
        {
            // Create a new blank document and a builder
            Document doc = new Document();
            DocumentBuilder builder = new DocumentBuilder(doc);

            // Insert an ellipse shape (100 pt × 50 pt)
            Shape ellipse = builder.InsertShape(ShapeType.Ellipse, 100, 50);

            // Position the shape on the page
            ellipse.Left = 150;
            ellipse.Top  = 100;

            // Hide the shape so it is invisible in the UI and on print
            ellipse.Hidden = true;

            // Optional: add a description for later retrieval
            ellipse.AlternativeText = "Hidden marker for internal processing";

            // Save the document
            string outputPath = @"C:\Temp\HiddenEllipse.docx";
            doc.Save(outputPath);

            Console.WriteLine($"Document saved to {outputPath}");
        }
    }
}
```

**Résultat attendu :** La console affiche le chemin d’enregistrement, et le fichier `HiddenEllipse.docx` s’ouvre comme une page vierge sans graphique visible, sauf si les objets masqués sont affichés.

## Conclusion

Vous savez maintenant comment **créer un document Word vierge** de façon programmatique, **insérer une ellipse**, **positionner la forme** et **masquer la forme** afin qu’elle se comporte comme un **objet masqué**. Cette technique est idéale pour intégrer des marqueurs invisibles, des métadonnées personnalisées ou des espaces réservés que des processus en aval peuvent lire sans affecter la mise en page visuelle du document.

### Prochaines étapes

* Explorez d’autres types de formes (`ShapeType.Arrow`, `ShapeType.TextBox`) pour intégrer différents marqueurs.  
* Combinez les formes masquées avec des parties XML personnalisées pour un stockage de métadonnées plus riche.  
* Intégrez ce code dans une chaîne d’automatisation plus large qui génère des rapports ou des contrats.

N’hésitez pas à expérimenter avec les coordonnées, les dimensions et le drapeau masqué pour les adapter à votre scénario spécifique. Bon codage !
