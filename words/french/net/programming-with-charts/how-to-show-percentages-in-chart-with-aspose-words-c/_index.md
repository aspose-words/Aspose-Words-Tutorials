# Comment afficher les pourcentages dans un graphique avec Aspose.Words C#

Vous vous êtes déjà demandé **comment afficher les pourcentages dans un graphique** sans vous battre avec l’interopérabilité Office complexe ? Vous n’êtes pas seul — de nombreux développeurs rencontrent ce problème lorsqu’ils ont besoin d’une solution rapide et programmatique pour libeller un graphique en secteurs ou en anneau. La bonne nouvelle ? Avec Aspose.Words pour .NET, vous pouvez activer ces libellés de données en quelques lignes seulement.

Dans ce tutoriel, nous aborderons également **l’ajout de libellés de données à un graphique en secteurs** et **comment activer les libellés de données du graphique** afin que vos visualisations deviennent instantanément plus instructives. À la fin, vous disposerez d’un document Word prêt à l’emploi (`.docx`) affichant un graphique en secteurs soigné avec les pourcentages positionnés proprement à l’extérieur de chaque tranche.

## Prérequis

Avant de commencer, assurez‑vous d’avoir :

- **Aspose.Words pour .NET** (dernière version, par ex. 24.9) installé via NuGet.  
- Un fichier **ChartTemplate.docx** contenant déjà un graphique en secteurs ou en anneau.  
  *(Si vous n’en avez pas, créez un simple document Word, insérez un graphique en secteurs et enregistrez‑le sous le nom `ChartTemplate.docx`.)*  
- .NET 6.0 ou supérieur et l’IDE de votre choix (Visual Studio, Rider, VS Code).

Aucune dépendance supplémentaire n’est requise — Aspose.Words gère tout en interne.

## Comment afficher les pourcentages dans un graphique – Étape par étape

Nous décomposons le processus en six étapes claires. Chaque étape comprend le code C# exact que vous pouvez copier‑coller, ainsi qu’une courte explication du **pourquoi**.

### Étape 1 : Charger le document source

```csharp
using Aspose.Words;
using Aspose.Words.Drawing.Charts;

// Load the .docx that already holds a chart.
Document sourceDoc = new Document("YOUR_DIRECTORY/ChartTemplate.docx");
```

*Pourquoi ?*  
`Document` est le point d’entrée pour toute manipulation Word. En chargeant le modèle, nous obtenons l’accès à chaque nœud — formes, tableaux, texte et bien sûr le graphique que nous allons modifier.

### Étape 2 : Récupérer la première forme de graphique

```csharp
// The chart lives inside a Shape node; retrieve it.
Chart chart = (Chart)sourceDoc.GetChild(NodeType.Shape, 0, true);
```

*Pourquoi ?*  
Aspose stocke les graphiques sous forme d’objets `Shape`. `GetChild` parcourt l’arbre du document et renvoie la première forme trouvée, qui, dans notre cas, est le graphique en secteurs que nous voulons éditer.

### Étape 3 : Confirmer le type de graphique

```csharp
if (chart.ChartType == ChartType.Pie || chart.ChartType == ChartType.Doughnut)
{
    // Inside this block we’ll enable the data labels.
}
else
{
    throw new InvalidOperationException("The chart is not a Pie or Doughnut type.");
}
```

*Pourquoi ?*  
Les libellés de pourcentage n’ont de sens que pour les graphiques circulaires. Cette vérification empêche d’appliquer accidentellement les paramètres à, par exemple, un graphique à barres où `ShowPercentage` serait ignoré.

### Étape 4 : Activer les libellés de données et afficher les pourcentages

```csharp
// Turn on data labels for the chart.
chart.HasDataLabel = true;

// Show the percentage value for each slice.
chart.DataLabel.ShowPercentage = true;
```

*Pourquoi ?*  
`HasDataLabel` indique à Aspose de rendre un libellé pour chaque point de données. Le réglage `ShowPercentage` garantit que le contenu du libellé correspond à la part calculée du total — exactement ce que requiert **l’ajout de libellés de données à un graphique en secteurs**.

### Étape 5 : Positionner les libellés à l’extérieur des tranches

```csharp
// Place the labels outside the pie slices for better readability.
chart.DataLabel.Position = ChartDataLabelPosition.OutSideEnd;
```

*Pourquoi ?*  
Les libellés à l’intérieur des tranches peuvent devenir encombrés, surtout lorsque les tranches sont petites. `OutSideEnd` reproduit le style « extérieur » par défaut que l’on voit dans l’interface Word, gardant le graphique lisible.

### Étape 6 : Enregistrer le document mis à jour

```csharp
sourceDoc.Save("YOUR_DIRECTORY/FormattedPieChart.docx");
```

*Pourquoi ?*  
L’enregistrement écrit toutes les modifications dans un nouveau fichier. Ouvrez `FormattedPieChart.docx` dans Word et vous verrez les pourcentages affichés à côté de chaque tranche.

#### Résultat attendu

Lorsque vous ouvrez `FormattedPieChart.docx`, le graphique en secteurs devrait ressembler à ceci (capture d’écran imaginaire) :

```
[ Pie chart with three slices ]
- Slice A – 45%
- Slice B – 30%
- Slice C – 25%
```

Tous les pourcentages sont calculés automatiquement à partir des séries de données sous‑jacentes, et les libellés sont placés juste à l’extérieur de chaque tranche.

## Variantes courantes et cas limites

| Situation | Ce qu’il faut ajuster |
|-----------|-----------------------|
| **Plusieurs graphiques** dans le même document | Parcourez `sourceDoc.GetChildNodes(NodeType.Shape, true)` et cast chaque forme en `Chart` avant d’appliquer la même logique. |
| **Graphique à barres ou en ligne** où vous voulez tout de même des libellés | Utilisez `chart.DataLabel.ShowValue = true;` (ou `ShowSeriesName`) au lieu de `ShowPercentage`. |
| **Format de nombre personnalisé** (ex. « 45 % ») | Définissez `chart.DataLabel.NumberFormat = "0%";` avant d’enregistrer. |
| **Jeux de données volumineux** provoquant le chevauchement des libellés | Envisagez `chart.DataLabel.ShowLeaderLines = true;` pour tracer des lignes de connexion. |

> **Astuce pro :** Si vous générez de nombreux documents en lot, créez une instance unique de `Aspose.Words.License` au démarrage de l’application afin d’éviter le coût de chargement répété de la licence.

## Exemple complet fonctionnel

Voici le programme complet, prêt à être exécuté :

```csharp
using System;
using Aspose.Words;
using Aspose.Words.Drawing.Charts;

class Program
{
    static void Main()
    {
        // 1️⃣ Load the template document.
        Document sourceDoc = new Document("YOUR_DIRECTORY/ChartTemplate.docx");

        // 2️⃣ Retrieve the first chart shape.
        Chart chart = (Chart)sourceDoc.GetChild(NodeType.Shape, 0, true);

        // 3️⃣ Ensure we’re dealing with a Pie or Doughnut chart.
        if (chart.ChartType != ChartType.Pie && chart.ChartType != ChartType.Doughnut)
        {
            Console.WriteLine("The selected shape is not a Pie/Doughnut chart.");
            return;
        }

        // 4️⃣ Enable data labels and show percentages.
        chart.HasDataLabel = true;
        chart.DataLabel.ShowPercentage = true;

        // 5️⃣ Position the labels outside the slices.
        chart.DataLabel.Position = ChartDataLabelPosition.OutSideEnd;

        // 6️⃣ Save the modified document.
        sourceDoc.Save("YOUR_DIRECTORY/FormattedPieChart.docx");

        Console.WriteLine("Chart updated successfully – percentages now visible!");
    }
}
```

Copiez le code, remplacez `YOUR_DIRECTORY` par le chemin réel sur votre machine, puis lancez‑le. Vous obtiendrez un fichier Word avec un graphique en secteurs entièrement libellé en quelques secondes.

## Récapitulatif

Nous avons répondu à **comment afficher les pourcentages dans un graphique** en utilisant Aspose.Words pour C#. Les étapes couvertes :

1. Charger le modèle.  
2. Récupérer la forme du graphique.  
3. Vérifier qu’il s’agit d’un graphique en secteurs/anneau.  
4. **Ajouter des libellés de données à un graphique en secteurs** et activer les pourcentages.  
5. Positionner ces libellés à l’extérieur.  
6. Enregistrer le résultat.

Avec ces connaissances, vous pouvez automatiser n’importe quel scénario de reporting nécessitant des visualisations claires basées sur des pourcentages.

## Et après ?

- **Styliser les libellés** — modifiez la police, la couleur ou ajoutez un arrière‑plan avec `chart.DataLabel.Font`.  
- **Créer des graphiques à partir de zéro** — explorez `Chart chart = (Chart)sourceDoc.FirstSection.Body.AppendChild(new Shape(sourceDoc, ShapeType.Chart));` pour générer des graphiques programmétiquement.  
- **Combiner plusieurs graphiques** dans un même document pour des tableaux de bord, puis exportez en PDF avec `sourceDoc.Save("Dashboard.pdf", SaveFormat.Pdf);`.

N’hésitez pas à expérimenter, et si vous rencontrez des particularités, laissez un commentaire. Bon charting !
