# Créer un modèle de facture et fusionner les données avec Aspose.Words

Si vous devez **créer rapidement un modèle de facture**, ce guide vous montre exactement comment faire. Au bout des deux premières phrases, vous connaîtrez le flux complet pour transformer un fichier Word vierge en une facture entièrement remplie, en utilisant l’API de fusion‑mail à faible code d’Aspose.Words.

Générer des factures est une exigence courante pour les systèmes de facturation, les intégrations ERP et les rapports automatisés. Dans ce tutoriel, vous apprendrez **comment faire une fusion‑mail**, **remplir un modèle Word**, **fusionner les données dans Word**, et enfin **enregistrer le document fusionné** — le tout avec quelques lignes de C#.

## Ce que vous allez réaliser

* Un modèle Word réutilisable (`InvoiceTemplate.docx`) contenant des champs de fusion pour le client, la date, les lignes d’articles et le total.  
* Un programme C# qui charge le modèle, injecte un objet de données fortement typé, et écrit le résultat dans `Invoice_001.docx`.  
* Une compréhension des cas limites tels que les collections vides, les types de données personnalisés et la gestion des chemins de fichiers.

### Prérequis

| Exigence | Pourquoi c’est important |
|----------|---------------------------|
| .NET 6 ou version ultérieure | Aspose.Words for .NET prend en charge .NET 6+ et fournit l’API à faible code utilisée dans ce guide. |
| Package NuGet Aspose.Words for .NET (`Aspose.Words`) | Fournit les types `Document`, `MailMerger` et associés. |
| Connaissances de base en C# | Nécessaires pour comprendre les objets anonymes et LINQ. |
| Visual Studio 2022 (ou tout IDE) | Facilite l’édition et le débogage. |

> **Astuce pro :** Installez le package NuGet via la console du gestionnaire de packages :  
> `Install-Package Aspose.Words`

## Comment créer un modèle de facture avec la fusion‑mail à faible code

La première étape consiste à créer un fichier Word contenant des champs de fusion correspondant aux propriétés de l’objet de données que vous passerez plus tard. Enregistrez le fichier sous le nom `InvoiceTemplate.docx` dans un dossier que vous contrôlez (par ex., `C:\Invoices\Template`).

| Champ de fusion | Exemple de texte de remplacement dans Word |
|-----------------|--------------------------------------------|
| CustomerName | «CustomerName» |
| InvoiceDate | «InvoiceDate» |
| Items (répétition) | «Items.Description», «Items.Qty», «Items.Price» |
| Total | «Total» |

> **Pourquoi c’est important :** L’API à faible code mappe automatiquement les noms de propriétés de la source de données aux champs de fusion. Garder les noms identiques élimine le mappage manuel champ‑propriété et réduit les erreurs d’exécution.

## Étape 1 : Charger le modèle de facture

```csharp
using Aspose.Words;
using Aspose.Words.LowCode;   // Low‑code mail‑merge API

// Load the Word file that contains the merge fields.
Document template = new Document(@"C:\Invoices\Template\InvoiceTemplate.docx");
```

*La classe `Document` représente l’ensemble du fichier Word. Le charger une fois vous permet de réutiliser le même modèle pour de nombreuses factures.*

## Étape 2 : Préparer la source de données

Créez un objet anonyme qui reflète les champs de fusion. L’API à faible code peut travailler avec n’importe quel objet .NET, y compris les tableaux et les collections imbriquées.

```csharp
var invoiceData = new
{
    CustomerName = "Acme Corp",
    InvoiceDate = DateTime.Today,
    Items = new[]
    {
        new { Description = "Widget A", Qty = 10, Price = 9.99M },
        new { Description = "Widget B", Qty = 5,  Price = 19.95M }
    },
    Total = 199.85M
};
```

**Pourquoi cela fonctionne :**  
* Les noms de propriétés (`CustomerName`, `InvoiceDate`, `Items`, `Total`) correspondent aux champs de fusion du modèle.  
* `Items` est un tableau d’objets, de sorte que le fusionneur répétera automatiquement la ligne du tableau pour chaque élément.  
* Utiliser `decimal` (suffixe `M`) pour les valeurs monétaires évite les problèmes d’arrondi des nombres à virgule flottante.

### Gestion des collections vides

Si une facture n’a aucun article, transmettez un tableau vide :

```csharp
Items = new object[0]
```

Le moteur à faible code omet simplement la section répétitive, en laissant l’en‑tête du tableau intacte.

## Étape 3 : Initialiser le fusionneur de mail à faible code

```csharp
MailMerger merger = new MailMerger(template);
```

`MailMerger` est le point d’entrée pour **comment faire une fusion‑mail** avec Aspose.Words. Il lit le modèle, lie les données et prépare le document final en un seul appel.

## Étape 4 : Exécuter la fusion – remplir le modèle Word en une ligne

```csharp
Document mergedDocument = merger.Execute(invoiceData);
```

* Cette ligne **remplit le modèle Word** et crée une nouvelle instance `Document` (`mergedDocument`).  
* Tous les champs de fusion sont remplacés, les sections répétitives sont développées, et le document résultant réside entièrement en mémoire.

### Cas limite : Formatage personnalisé

Si vous avez besoin d’un format de date spécifique, ajoutez un formateur personnalisé avant la fusion :

```csharp
merger.Options.DateFormat = "MMMM dd, yyyy"; // e.g., "October 07, 2026"
```

## Étape 5 : Enregistrer le document fusionné

```csharp
mergedDocument.Save(@"C:\Invoices\Output\Invoice_001.docx");
```

L’appel **save merged document** écrit la facture entièrement remplie sur le disque. Le fichier peut maintenant être ouvert dans Microsoft Word, envoyé en pièce jointe d’e‑mail, ou converti en PDF.

### Vérifier la sortie

Ouvrez `Invoice_001.docx`. Vous devriez voir :

* **CustomerName** remplacé par *Acme Corp*  
* **InvoiceDate** affichant la date du jour au format choisi  
* Une ligne de tableau pour *Widget A* (10 × 9,99) et *Widget B* (5 × 19,95)  
* **Total** affichant *199,85*  

Si un champ reste inchangé (par ex., il montre toujours «CustomerName»), vérifiez que les noms de propriétés correspondent exactement aux noms des champs de fusion dans le modèle.

## Exemple complet exécutable

Voici le programme complet que vous pouvez copier‑coller dans un nouveau projet console.

```csharp
using System;
using Aspose.Words;
using Aspose.Words.LowCode;   // Low‑code mail‑merge API

namespace InvoiceGenerator
{
    class Program
    {
        static void Main()
        {
            // 1️⃣ Load the template
            Document template = new Document(@"C:\Invoices\Template\InvoiceTemplate.docx");

            // 2️⃣ Build the data source
            var invoiceData = new
            {
                CustomerName = "Acme Corp",
                InvoiceDate = DateTime.Today,
                Items = new[]
                {
                    new { Description = "Widget A", Qty = 10, Price = 9.99M },
                    new { Description = "Widget B", Qty = 5,  Price = 19.95M }
                },
                Total = 199.85M
            };

            // 3️⃣ Initialise the mail merger
            MailMerger merger = new MailMerger(template);

            // Optional: customise date format
            merger.Options.DateFormat = "MMMM dd, yyyy";

            // 4️⃣ Perform the merge (populate word template)
            Document mergedDocument = merger.Execute(invoiceData);

            // 5️⃣ Save the resulting file (save merged document)
            mergedDocument.Save(@"C:\Invoices\Output\Invoice_001.docx");

            Console.WriteLine("Invoice generated successfully.");
        }
    }
}
```

Exécutez le programme (`dotnet run`). La console affiche *Invoice generated successfully.* et le fichier apparaît dans `C:\Invoices\Output`.
