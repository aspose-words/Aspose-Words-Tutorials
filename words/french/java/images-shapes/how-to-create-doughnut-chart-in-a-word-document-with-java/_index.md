# Comment créer un diagramme en anneau dans un document Word avec Java

Si vous devez **créer un diagramme en anneau** dans un fichier Word, ce tutoriel vous propose une solution complète, prête à l’emploi. Vous verrez comment **insérer un diagramme circulaire**, le transformer en anneau, **faire pivoter le diagramme circulaire** pour un meilleur équilibre, et **formater le diagramme circulaire** pour correspondre à votre identité visuelle. À la fin, vous disposerez d’un document Word professionnel pouvant être utilisé dans des rapports, des tableaux de bord ou des pièces jointes d’e‑mail automatisées.

Créer un diagramme de façon programmatique élimine les étapes manuelles de copier‑coller et garantit une mise en forme cohérente sur des dizaines de documents générés. L’exemple utilise la bibliothèque Aspose.Words for Java, qui fonctionne avec Java 8+ et ne nécessite aucune installation de Microsoft Office. Aucun autre prérequis n’est nécessaire au-delà d’un JDK standard et de votre IDE préféré.

## Prérequis

- Kit de développement Java (JDK) 8 ou plus récent  
- Maven ou Gradle pour la gestion des dépendances (le tutoriel utilise Maven)  
- Bibliothèque Aspose.Words for Java (une licence d’essai gratuite suffit pour les tests)  

Ajoutez la dépendance Aspose.Words à votre `pom.xml` :

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-words</artifactId>
    <version>24.9</version> <!-- Use the latest stable version -->
</dependency>
```

> **Astuce :** Enregistrez votre licence avec `License license = new License(); license.setLicense("Aspose.Words.lic");` avant de créer tout document afin de supprimer les filigranes d’évaluation.

## Créer un diagramme en anneau dans un document Word

Le flux de travail principal se compose de cinq étapes logiques. Chaque étape est encapsulée dans sa propre méthode afin de garder le code propre et réutilisable.

```java
import com.aspose.words.*;
import com.aspose.words.drawing.*;

public class DoughnutChartDemo {

    public static void main(String[] args) throws Exception {
        // Step 1: create blank Word document
        Document doc = createBlankWordDocument();

        // Step 2: insert a pie chart (base for the doughnut)
        Chart chart = insertPieChart(doc, 400, 300);

        // Step 3: convert the pie chart into a doughnut and rotate it
        customizeChartAppearance(chart);

        // Step 4: apply additional formatting to the chart
        formatPieChart(chart);

        // Step 5: save the final document
        doc.save("output/DoughnutChartFormatted.docx");
        System.out.println("Document saved successfully.");
    }

    /** Step 1 – create blank Word document */
    private static Document createBlankWordDocument() {
        // Aspose.Words creates an empty document by default
        return new Document();
    }

    /** Step 2 – insert pie chart with given dimensions */
    private static Chart insertPieChart(Document doc, int width, int height) throws Exception {
        DocumentBuilder builder = new DocumentBuilder(doc);
        // ChartType.PIE creates a standard pie chart that we will later turn into a doughnut
        Chart chart = builder.insertChart(ChartType.PIE, width, height);
        // Populate the chart with sample data
        chart.getSeries().clear(); // Remove default series
        ChartSeries series = chart.getSeries().add("Sales", new String[]{"Q1", "Q2", "Q3", "Q4"},
                new double[]{15000, 23000, 18000, 27000});
        return chart;
    }

    /** Step 3 – rotate pie chart and make it a doughnut */
    private static void customizeChartAppearance(Chart chart) {
        // Explode the first slice for emphasis
        chart.getSeries().get(0).setExplode(20);
        // Convert the pie into a doughnut by setting a hole size (percentage of radius)
        chart.setHoleSize(30); // 30% hole creates a classic doughnut look
        // Rotate the chart so the largest slice starts at 45°
        chart.setRotationAngle(45);
    }

    /** Step 4 – additional formatting of the pie chart */
    private static void formatPieChart(Chart chart) {
        // Example: change the first slice color to a brand color
        chart.getSeries().get(0).getPoints().get(0).getFormat().setFillForegroundColor(Color.fromArgb(0xFF, 0x4A, 0x90));
        // Add a legend and position it at the bottom
        chart.setHasLegend(true);
        chart.getLegend().setPosition(LegendPosition.BOTTOM);
        // Set a title for the chart
        chart.setTitle("Quarterly Sales Distribution");
    }
}
```

### Ce que fait le code

| Étape | Action | Raison |
|------|--------|--------|
| **Créer un document Word vierge** | `new Document()` | Commence avec un fichier vierge afin que vous contrôliez chaque élément. |
| **Insérer un diagramme circulaire** | `builder.insertChart(ChartType.PIE, …)` | Un diagramme circulaire est la forme de base ; Aspose ne fournit un anneau qu’en ajustant la taille du trou. |
| **Faire pivoter le diagramme circulaire** | `chart.setRotationAngle(45)` | Faire pivoter aligne la plus grande tranche à une position plus lisible. |
| **Formater le diagramme circulaire** | `setExplode`, `setHoleSize`, color, legend | Améliore la hiérarchie visuelle et correspond aux directives de style de l’entreprise. |
| **Enregistrer le document** | `doc.save("…/DoughnutChartFormatted.docx")` | Écrit le fichier .docx final sur le disque, prêt pour la distribution. |

## Insérer un diagramme circulaire avant de le convertir en anneau

Aspose.Words ne propose pas de méthode directe « insérer un diagramme en anneau ». À la place, vous **insérez un diagramme circulaire** puis modifiez ses propriétés. Cette approche en deux étapes vous donne un contrôle complet sur les séries de données, l’explosion des tranches et la taille du trou. Si vous avez besoin d’un diagramme circulaire pur ailleurs, il suffit d’omettre l’appel `setHoleSize`.

## Faire pivoter le diagramme circulaire pour un équilibre visuel

L’orientation par défaut démarre la première tranche à la position 12 heures. Dans de nombreux rapports d’entreprise, la tranche la plus importante doit commencer à un angle plus naturel, comme 45 degrés. La méthode `setRotationAngle(double angle)` accepte des degrés et fait pivoter l’ensemble du diagramme sans affecter les valeurs des données.

## Formater le diagramme circulaire et personnaliser l’apparence

Au‑delà de la conversion en anneau, vous souhaiterez souvent **formater le diagramme circulaire** :

- **Exploser** la première tranche (`setExplode`) pour attirer l’attention.  
- **Colorer** chaque tranche en utilisant `getPoints().get(i).getFormat().setFillForegroundColor`.  
- **Légende** positionnement (`setHasLegend`, `setPosition`) aide les lecteurs à interpréter les catégories.  
- **Titre** (`setTitle`) donne le contexte d’un coup d’œil.  

Tous ces paramètres sont optionnels ; vous pouvez les ajuster pour correspondre à la palette de votre marque ou aux modèles d’entreprise.

## Créer un document Word vierge et enregistrer le résultat

La méthode `createBlankWordDocument` encapsule l’étape **create blank word document**. Garder cette logique isolée facilite la réutilisation de la méthode lors de la génération de plusieurs rapports en mode batch. Après toutes les personnalisations, `doc.save` écrit le fichier au format Office Open XML standard (`.docx`), qui peut être ouvert dans Microsoft Word, LibreOffice ou Google Docs sans perte de fidélité.

### Résultat attendu

Lorsque vous exécutez la méthode `main`, la console affiche :

```
Document saved successfully.
```

Et le fichier `output/DoughnutChartFormatted.docx` contient une page unique avec un diagramme en anneau intitulé *Quarterly Sales Distribution*. Le diagramme montre quatre tranches, la première tranche explosée, colorée selon la teinte de la marque, et pivotée de 45 degrés.

## Variations courantes et cas limites

| Situation | Ajustement |
|-----------|------------|
| **Plus d’une série de données** | Ajoutez des objets `ChartSeries` supplémentaires à `chart.getSeries()`. |
| **Taille de diagramme différente** | Modifiez les arguments `width` et `height` dans `insertPieChart`. |
| **Pas de trou (diagramme circulaire pur)** | Omettez `chart.setHoleSize(…)` ou définissez‑le à `0`. |
| **Documents volumineux** | Utilisez `DocumentBuilder` pour insérer le diagramme dans une section ou un signet spécifique. |
| **Licence non définie** | La bibliothèque fonctionne en mode évaluation, ajoutant un filigrane sur la première page. Enregistrez une licence pour le supprimer. |

## Conclusion

Vous savez maintenant comment **create doughnut chart** dans un document Word avec Java, depuis **create blank word document** jusqu’à **insert pie chart**, **rotate pie chart** et **format pie chart** pour obtenir un produit final soigné. L’exemple complet et exécutable peut être intégré à n’importe quel projet Java qui utilise déjà Aspose.Words.

Ensuite, vous pourriez explorer :

- Ajout d’étiquettes de données (`chart.getSeries().get(0).setDataLabelType(DataLabelType.CATEGORY_AND_PERCENT);`)  
- Exportation du diagramme en image (`chart.toImage`) pour une utilisation dans les e‑mails HTML  
- Automatisation de la génération de plusieurs documents dans une boucle pour les rapports en lot  

N’hésitez pas à expérimenter avec les couleurs, les explosions de tranches et les légendes pour correspondre au langage visuel de votre organisation. Bon charting !
