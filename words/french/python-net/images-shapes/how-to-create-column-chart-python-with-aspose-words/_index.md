# Comment créer un graphique en colonnes python avec Aspose.Words

Si vous devez créer un graphique en colonnes python, ce guide montre le code exact et le raisonnement dont vous avez besoin. En utilisant l’API de graphiques Aspose.Words, vous pouvez définir des dimensions précises, appliquer un style intégré et exporter le résultat sans quitter Python.

Générer un graphique en colonnes est une exigence courante pour les rapports, les tableaux de bord et la création automatisée de documents. Ce tutoriel couvre chaque étape — de l’importation de la bibliothèque à la vérification de l’image enregistrée — afin que vous puissiez intégrer la génération de graphiques dans n’importe quel projet Python.

## Prérequis

Avant de commencer, assurez‑vous d’avoir :

* Python 3.8 ou version supérieure installé.
* Une licence valide d’Aspose.Words for Python (ou une clé d’évaluation gratuite).
* Une connaissance de base des modules Python et du code orienté objet.

Le moteur de graphiques Aspose.Words fonctionne sous Windows, macOS et Linux, et il ne nécessite aucune bibliothèque graphique supplémentaire car le rendu s’effectue côté serveur.

## Étape 1 : Importer la bibliothèque Aspose.Words

La première étape consiste à importer le package `aspose.words` et à lui donner un alias court. Importer en haut du fichier garde l’espace de noms propre et rend le code plus lisible.

```python
# Step 1: Import the Aspose.Words library
import aspose.words as aw
```

`aw` fait maintenant référence à l’API complète d’Aspose.Words, y compris la classe `Chart` que vous utiliserez pour créer le graphique en colonnes.

## Étape 2 : Créer un graphique en colonnes avec les dimensions souhaitées

Un graphique en colonnes nécessite des valeurs explicites de largeur et de hauteur afin que l’image rendue s’ajuste à la mise en page de votre document. Le constructeur `Chart` accepte trois arguments : le type de graphique, la largeur (en points) et la hauteur (en points). Utiliser `aw.ChartType.COLUMN` indique au moteur de générer un graphique à barres verticales.

```python
# Step 2: Create a column chart with the desired dimensions
chart = aw.Chart(aw.ChartType.COLUMN, 400, 300)   # width=400pt, height=300pt
```

*Pourquoi définir les dimensions ?*  
Lorsque vous intégrez le graphique dans un document Word ou que vous l’exportez en image, le contenu environnant respecte exactement la taille que vous avez fournie. Cela évite les mises à l’échelle ou les découpes indésirables.

### Astuce : Utiliser `chart.dimensions` pour un redimensionnement dynamique

Si votre jeu de données varie, vous pouvez calculer la taille en fonction du nombre de séries :

```python
series_count = 5
base_width = 80
chart.width = base_width * series_count
chart.height = 300
```

## Étape 3 : Appliquer un style intégré au graphique en colonnes

Aspose.Words propose plusieurs thèmes visuels prédéfinis. Sélectionner un style supprime le besoin de configurer manuellement les couleurs, les polices et les quadrillages. `aw.ChartStyle.STYLE_5` offre un rendu épuré et professionnel, adapté à la plupart des rapports d’entreprise.

```python
# Step 3: Apply a built‑in style to the chart
chart.style = aw.ChartStyle.STYLE_5
```

Si vous préférez une apparence différente, remplacez `STYLE_5` par l’une des autres constantes (`STYLE_1` … `STYLE_8`). Chaque style suit la même convention de nommage, ce qui facilite l’expérimentation.

### Cas particulier : Constante de style invalide

Attribuer un style inexistant déclenche une `AttributeError`. Protégez‑vous en vérifiant la constante par rapport à l’énumération :

```python
if hasattr(aw.ChartStyle, "STYLE_5"):
    chart.style = aw.ChartStyle.STYLE_5
else:
    raise ValueError("Requested chart style does not exist.")
```

## Étape 4 : Ajouter des séries de données au graphique en colonnes

Un graphique sans données n’a aucun sens. Vous pouvez ajouter une ou plusieurs objets `ChartSeries`, chacun représentant un groupe de colonnes. L’exemple suivant ajoute une seule série avec trois points de données.

```python
# Step 4: Add data series to the column chart
series = chart.series.add()
series.name = "Quarterly Sales"
series.data = [12000, 15000, 18000]   # Values for Q1, Q2, Q3
```

Vous pouvez répéter l’appel `chart.series.add()` pour inclure des séries supplémentaires (par ex., « Ventes projetées »). L’API répartit automatiquement les colonnes côte à côte.

## Étape 5 : Rendre le graphique et l’enregistrer en tant qu’image

Après avoir configuré le graphique, vous le rendez sous forme de bitmap ou de fichier image. La méthode `save` accepte un chemin de fichier et un format optionnel. PNG est sans perte et largement supporté.

```python
# Step 5: Render and save the chart as a PNG image
output_path = "column_chart.png"
chart.save(output_path, aw.SaveFormat.PNG)
print(f"Chart saved to {output_path}")
```

L’énumération `SaveFormat` comprend PNG, JPEG, BMP et d’autres formats. Choisissez celui qui correspond à votre flux de travail en aval.

## Vérifier la sortie

Ouvrez `column_chart.png` avec n’importe quel visualiseur d’images. Vous devriez voir un graphique à barres à trois colonnes, stylisé avec le thème intégré choisi, dimensionné exactement à 400 × 300 points.

![Graphique en colonnes généré par Aspose.Words en Python](column_chart.png){: .center alt="Capture d’écran d’un graphique en colonnes généré par Aspose.Words en Python"}

Si l’image apparaît vide ou déformée, revérifiez les points suivants :

1. L’objet `aw.Chart` a été instancié avant d’ajouter les séries.
2. La constante `chart.style` correspond à une valeur d’énumération existante.
3. L’appel `save` utilise un `SaveFormat` supporté.

## Variations courantes et conseils supplémentaires

| Situation | Modification recommandée |
|-----------|--------------------------|
| **Séries de données multiples** | Ajoutez des blocs `chart.series.add()` supplémentaires et définissez `series.name` et `series.data` pour chacune. |
| **Couleurs personnalisées** | Après avoir appliqué un style intégré, surchargez les couleurs individuelles des colonnes via `series.points[i].fill.fore_color`. |
| **Intégration dans un document Word** | Au lieu de `chart.save()`, utilisez `doc = aw.Document(); doc.sections[0].body.append_child(chart); doc.save("report.docx")`. |
| **Dimensionnement dynamique** | Calculez la largeur en fonction du nombre de séries (`width = 80 * len(chart.series)`). |

Ces variations montrent comment le même code de base s’adapte à différents scénarios de reporting.

Vous savez maintenant comment créer un graphique en colonnes python avec Aspose.Words, définir des dimensions exactes, appliquer un style intégré et exporter le résultat en image. Le flux de travail complet — importation, instanciation, style, remplissage et rendu — couvre les cas d’utilisation les plus courants pour le reporting automatisé.

Expérimentez différentes options de **stylisation de graphiques en colonnes** pour correspondre à votre charte graphique, et vous disposerez d’une solution de création de graphiques robuste et prête pour la production en Python.
