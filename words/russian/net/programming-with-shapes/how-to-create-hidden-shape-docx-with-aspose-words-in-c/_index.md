# Как создать скрытую форму docx с помощью Aspose.Words в C#

Если вам нужно **создавать скрытые формы docx** программно, этот учебник показывает точные шаги с использованием Aspose.Words для .NET. Вы увидите, как **установить цвет заливки формы**, чтобы форма была видна при редактировании, а затем **скрыть форму в документе Word**, чтобы конечный пользователь никогда её не видел, если только не включено отображение скрытых объектов.

В руководстве покрыты все необходимые детали: требуемые пакеты NuGet, полностью рабочий пример кода и советы по устранению распространённых проблем. К концу статьи у вас будет DOCX, содержащий невидимый эллипс, который при необходимости можно будет раскрыть.

## Предварительные требования

Перед началом убедитесь, что у вас есть:

- .NET 6.0 SDK или более поздняя версия  
- Visual Studio 2022 (или любой IDE для C#)  
- Активная лицензия Aspose.Words для .NET (или временный оценочный ключ)  
- Базовое знакомство с синтаксисом C#  

Вы **не** нуждаетесь в дополнительных библиотеках Word interop, поскольку Aspose.Words работает независимо от Microsoft Office.

## Шаг 1: Создать скрытую форму docx – инициализировать документ

Первая операция – создать объект `Document` и `DocumentBuilder`. Builder предоставляет удобный API для вставки форм, текста и других элементов.

```csharp
using Aspose.Words;
using Aspose.Words.Drawing;
using System.Drawing;

class Program
{
    static void Main()
    {
        // Initialise an empty DOCX file
        Document doc = new Document();
        DocumentBuilder builder = new DocumentBuilder(doc);
```

*Почему это важно*: Новый `Document` представляет пустой файл Word. `DocumentBuilder` выступает в роли курсора, который знает, куда будет помещён следующий элемент. Начало с чистого документа гарантирует, что скрытая форма не унаследует неожиданное форматирование.

## Шаг 2: Установить цвет заливки формы для эллипса

Далее вставляем форму‑эллипс и задаём цвет заливки. Цвет делает форму видимой в редакторе, что удобно, когда нужно проверить её размер или позицию перед скрытием.

```csharp
        // Insert an ellipse 150 pt wide and 100 pt high
        Shape ellipse = builder.InsertShape(ShapeType.Ellipse, 150, 100);

        // Apply a bright fill so the shape can be inspected
        ellipse.FillColor = Color.Yellow;
```

Шаг **установить цвет заливки формы** необязателен для окончательного скрытого документа, но помогает в процессе разработки. Без заливки форма будет невидима даже до применения флага скрытия, что усложняет отладку.

## Шаг 3: Скрыть форму в документе Word

Теперь применяем свойство `Hidden`. Когда `Hidden` равно `true`, Microsoft Word не будет отображать форму в обычном виде. Пользователи всё ещё могут её увидеть, включив «Show hidden objects» в параметрах Word.

```csharp
        // Mark the shape as hidden – it will not appear in normal view
        ellipse.Hidden = true;
```

*Важно*: Флаг скрытия работает в Word 2010 и новее. Если вы нацеливаетесь на более старые версии, форма может всё равно отображаться. Кроме того, флаг не влияет на позицию формы; он лишь подавляет её отрисовку.

## Шаг 4: Сохранить файл DOCX

Наконец, записываем документ на диск. Имя файла может быть любым допустимым путём; здесь мы используем относительный путь для простоты.

```csharp
        // Persist the document with the hidden shape
        doc.Save("HiddenShape.docx");
    }
}
```

Когда вы откроете `HiddenShape.docx` в Microsoft Word, эллипс будет не виден. Если включить **File → Options → Display → Show hidden objects**, желтый эллипс появится точно там, где вы его разместили.

### Ожидаемый результат

- Файл с именем `HiddenShape.docx` в рабочем каталоге исполняемого файла.  
- Открытие файла в Word показывает обычное содержимое без **видимой формы**.  
- Включение «Show hidden objects» отображает желтую эллипс размером 150 × 100 pt.

## Шаг 5: Программно проверить скрытую форму (по желанию)

Если нужно убедиться, что форма действительно скрыта без открытия Word, можно проверить свойство `Hidden` после загрузки документа:

```csharp
        Document loaded = new Document("HiddenShape.docx");
        Shape loadedShape = (Shape)loaded.GetChildNodes(NodeType.Shape, true)[0];
        System.Console.WriteLine($"Shape hidden? {loadedShape.Hidden}");
```

Консоль выводит `Shape hidden? True`, подтверждая, что флаг сохранён.

## Распространённые ошибки и как их избежать

| Признак | Причина | Решение |
|---------|---------|---------|
| Форма всё ещё видна после сохранения | `Hidden` не установлен или установлен после сохранения | Убедитесь, что `ellipse.Hidden = true;` выполняется **до** `doc.Save()`. |
| Цвет заливки не применён | `FillColor` назначен до создания формы | Назначьте `FillColor` **после** того, как `InsertShape` вернёт объект `Shape`. |
| DOCX не открывается | Несоответствие версии Aspose.Words и среды .NET | Используйте последнюю версию пакета Aspose.Words NuGet, ориентированную на .NET 6+. |
| Флаг Hidden игнорируется в более старых версиях Word | Word < 2010 | Рассмотрите альтернативный метод (например, установить `WrapType` формы в `None` и переместить её за пределы страницы). |

## Совет профессионала: повторное использование скрытых форм как заполнителей

Вы можете хранить скрытые формы в шаблонном документе и позже заменять их видимым содержимым. Поскольку форма скрыта, она не влияет на макет, пока вы не установите `Hidden = false`. Такой подход удобен при генерации контрактов, где поле подписи изначально скрыто и становится видимым после подписи пользователем.

## Следующие шаги

- **Показать скрытые формы**: используйте `shape.Hidden = false;`, чтобы эллипс появился во время выполнения.  
- **Изменить тип формы**: замените `ShapeType.Ellipse` на `ShapeType.Rectangle`, `ShapeType.Polygon` и т.д., в зависимости от задачи.  
- **Добавить текст внутрь формы**: вставьте `TextBox` в свойство `TextBox` формы для подписанных заполнителей.  
- **Комбинировать с рассылкой**: разместите скрытые формы в шаблоне слияния и переключайте их видимость для каждой записи.  

Изучение этих тем укрепит ваше владение процессами **create hidden shape docx** и расширит возможности автоматической генерации документов.
