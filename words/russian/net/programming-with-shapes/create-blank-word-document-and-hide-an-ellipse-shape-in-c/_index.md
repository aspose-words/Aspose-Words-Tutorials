# Создать пустой документ Word и скрыть форму эллипса в C#

Если вам нужно **создать пустой документ Word** и затем скрыть графический элемент, это руководство покажет, как сделать это с помощью C#. Вы увидите полный, исполняемый пример, который вставляет эллипс, позиционирует его, помечает как скрытый и сохраняет файл — всё в нескольких строках кода.

Учебник охватывает всё, от настройки проекта до финального шага проверки. К концу вы сможете генерировать файл Word, в котором эллипс никогда не появляется на экране или в печати, что полезно для хранения метаданных, закладок или любого невидимого маркера.

## Предварительные требования

* .NET 6.0 SDK или более поздняя версия, установленная  
* Среда разработки C# (Visual Studio 2022, Rider или VS Code)  
* Пакет NuGet **Aspose.Words for .NET** (`Install-Package Aspose.Words`)  

Эти инструменты предоставляют классы `Document` и `DocumentBuilder`, используемые в примере кода.

## Шаг 1: Создать пустой документ Word

Первая операция создаёт пустой объект `Document` и `DocumentBuilder`, который позволяет добавлять содержимое.

```csharp
using Aspose.Words;
using Aspose.Words.Drawing;

// Step 1: Initialize an empty document and a builder
Document doc = new Document();
DocumentBuilder builder = new DocumentBuilder(doc);
```

`Document` представляет весь пакет `.docx`, тогда как `DocumentBuilder` предлагает fluent API для вставки текста, форм и других объектов. Начало с пустого документа даёт полный контроль над каждым добавляемым элементом.

## Шаг 2: Как вставить эллипс

Эллипс — это векторная форма, которую можно использовать как маркер. Метод `InsertShape` требует тип формы и её ширину/высоту в пунктах.

```csharp
// Step 2: Insert an ellipse shape of the desired size (100 pt × 50 pt)
Shape ellipse = builder.InsertShape(ShapeType.Ellipse, 100, 50);
```

Эллипс располагается на текущей странице в месте курсора. Вы можете изменить его размеры, скорректировав числовые аргументы.

## Шаг 3: Как позиционировать форму

После вставки вы можете переместить форму в любое место страницы, задав свойства `Left` и `Top`, которые используют пункты относительно полей страницы.

```csharp
// Step 3: Position the shape on the page
ellipse.Left = 150; // distance from the left margin
ellipse.Top  = 100; // distance from the top margin
```

Эти координаты размещают эллипс примерно в верхней‑середине стандартной страницы A4. Подгоняйте значения под требования вашего макета.

## Шаг 4: Как скрыть форму

Скрытый объект не отображается при открытии или печати документа. Установка флага `Hidden` помечает форму как **hidden object word**.

```csharp
// Step 4: Hide the shape so it never appears
ellipse.Hidden = true;
```

Word учитывает флаг hidden как при отображении на экране, так и при печати. Форма остаётся частью структуры документа, позволяя позже запросить или изменить её через код.

## Шаг 5: Сохранить документ

Наконец, запишите документ на диск. Выберите папку, в которую у вас есть права записи.

```csharp
// Step 5: Save the document to a .docx file
doc.Save(@"C:\Temp\HiddenEllipse.docx");
```

Файл `HiddenEllipse.docx` теперь содержит пустую страницу со скрытой формой эллипса.

## Проверка скрытого эллипса

Откройте сгенерированный файл в Microsoft Word и включите опцию **Show hidden text** (File → Options → Display). Вы увидите лёгкий контур эллипса. Если отключить эту опцию, форма исчезнет полностью, подтверждая, что `ellipse.Hidden = true` работает как ожидается.

## Распространённые варианты и граничные случаи

| Ситуация | Рекомендуемая корректировка |
|-----------|------------------------|
| **Другая форма** | Замените `ShapeType.Ellipse` на `ShapeType.Rectangle`, `ShapeType.Arrow` и т.д. |
| **Несколько скрытых объектов** | Повторите шаги 2‑4 для каждой формы; каждая может иметь свой собственный флаг `Hidden`. |
| **Другой размер страницы** | Установите `doc.FirstSection.PageSetup.PageWidth` и `PageHeight` перед вставкой формы. |
| **Условная видимость** | Используйте `Shape.Visible` в сочетании с `Hidden`, чтобы переключать видимость во время выполнения через код. |

**Совет:** Сохраняйте идентификационные данные в свойстве `AlternativeText` формы. Даже когда она скрыта, вы можете позже получить форму с помощью `doc.GetChildNodes(NodeType.Shape, true)` и отфильтровать по этому тексту.

## Полный исходный код

Ниже приведена полная программа, которую можно скопировать, вставить и запустить.

```csharp
using System;
using Aspose.Words;
using Aspose.Words.Drawing;

namespace HiddenShapeDemo
{
    class Program
    {
        static void Main()
        {
            // Create a new blank document and a builder
            Document doc = new Document();
            DocumentBuilder builder = new DocumentBuilder(doc);

            // Insert an ellipse shape (100 pt × 50 pt)
            Shape ellipse = builder.InsertShape(ShapeType.Ellipse, 100, 50);

            // Position the shape on the page
            ellipse.Left = 150;
            ellipse.Top  = 100;

            // Hide the shape so it is invisible in the UI and on print
            ellipse.Hidden = true;

            // Optional: add a description for later retrieval
            ellipse.AlternativeText = "Hidden marker for internal processing";

            // Save the document
            string outputPath = @"C:\Temp\HiddenEllipse.docx";
            doc.Save(outputPath);

            Console.WriteLine($"Document saved to {outputPath}");
        }
    }
}
```

**Ожидаемый вывод:** Консоль выводит путь сохранения, а файл `HiddenEllipse.docx` открывается как пустая страница без видимых графических элементов, если скрытые объекты не отображаются.

## Заключение

Теперь вы знаете, как **создать пустой документ Word** программно, **как вставить эллипс**, **как позиционировать форму** и **как скрыть форму**, чтобы она вела себя как **hidden object word**. Эта техника идеальна для внедрения невидимых маркеров, пользовательских метаданных или заполнителей, которые последующие процессы могут читать без влияния на визуальное оформление документа.

* Комбинируйте скрытые формы с пользовательскими XML‑частями для более богатого хранения метаданных.  
* Интегрируйте этот код в более крупный конвейер автоматизации, генерирующий отчёты или контракты.

Не стесняйтесь экспериментировать с координатами, размерами и флагом hidden, чтобы подобрать оптимальные параметры под ваш конкретный сценарий. Приятного кодинга!
