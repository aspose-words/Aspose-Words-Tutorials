# Создание шаблона счета и объединение данных с помощью Aspose.Words

Если вам нужно **быстро создать шаблон счета**, это руководство покажет, как именно это сделать. К концу первых двух предложений вы будете знать полный процесс преобразования пустого файла Word в полностью заполненный счет, используя low‑code API слияния почты Aspose.Words.

Создание счетов — распространённая задача для систем биллинга, интеграций ERP и автоматизированной отчетности. В этом руководстве вы узнаете **как выполнять слияние почты**, **заполнять шаблон Word**, **объединять данные в Word**, и, наконец, **сохранять объединённый документ** — всё это с помощью нескольких строк кода на C#.

## Что вы достигнете

* Повторно используемый шаблон Word (`InvoiceTemplate.docx`), содержащий поля слияния для клиента, даты, позиций и общей суммы.  
* Программа на C#, которая загружает шаблон, внедряет строго типизированный объект данных и записывает результат в `Invoice_001.docx`.  
* Понимание граничных случаев, таких как пустые коллекции, пользовательские типы данных и работа с путями к файлам.

### Необходимые условия

| Требование | Почему это важно |
|-------------|-------------------|
| .NET 6 или новее | Aspose.Words for .NET поддерживает .NET 6+ и предоставляет low‑code API, используемый в этом руководстве. |
| NuGet‑пакет Aspose.Words for .NET (`Aspose.Words`) | Содержит типы `Document`, `MailMerger` и связанные типы. |
| Базовые знания C# | Необходимы для понимания анонимных объектов и LINQ. |

> **Полезный совет:** Установите NuGet‑пакет через консоль диспетчера пакетов:  
> `Install-Package Aspose.Words`

## Как создать шаблон счета с помощью low‑code mail merge

Первый шаг — создать файл Word, содержащий поля слияния, соответствующие свойствам объекта данных, который вы передадите позже. Сохраните файл как `InvoiceTemplate.docx` в папке, которой вы управляете (например, `C:\Invoices\Template`).

| Поле слияния | Пример заполнителя в Word |
|-------------|-----------------------------|
| CustomerName | «CustomerName» |
| InvoiceDate | «InvoiceDate» |
| Items (repeating) | «Items.Description», «Items.Qty», «Items.Price» |
| Total | «Total» |

> **Почему это важно:** Low‑code API автоматически сопоставляет имена свойств источника данных с полями слияния. Сохранение одинаковых имен устраняет необходимость ручного сопоставления полей со свойствами и снижает количество ошибок во время выполнения.

## Шаг 1: Загрузка шаблона счета

```csharp
using Aspose.Words;
using Aspose.Words.LowCode;   // Low‑code mail‑merge API

// Load the Word file that contains the merge fields.
Document template = new Document(@"C:\Invoices\Template\InvoiceTemplate.docx");
```

*Класс `Document` представляет весь файл Word. Однократная загрузка позволяет переиспользовать один и тот же шаблон для множества счетов.*

## Шаг 2: Подготовка источника данных

Создайте анонимный объект, отражающий поля слияния. Low‑code API может работать с любым объектом .NET, включая массивы и вложенные коллекции.

```csharp
var invoiceData = new
{
    CustomerName = "Acme Corp",
    InvoiceDate = DateTime.Today,
    Items = new[]
    {
        new { Description = "Widget A", Qty = 10, Price = 9.99M },
        new { Description = "Widget B", Qty = 5,  Price = 19.95M }
    },
    Total = 199.85M
};
```

**Почему это работает:**  
* Имена свойств (`CustomerName`, `InvoiceDate`, `Items`, `Total`) совпадают с полями слияния в шаблоне.  
* `Items` — массив объектов, поэтому mail merger автоматически повторит строку таблицы для каждого элемента.  
* Использование `decimal` (суффикс `M`) для денежных значений избегает проблем округления с плавающей точкой.

### Обработка пустых коллекций

Если в счете нет позиций, передайте пустой массив:

```csharp
Items = new object[0]
```

Low‑code движок просто опустит повторяющуюся секцию, оставив заголовок таблицы нетронутым.

## Шаг 3: Инициализация low‑code mail merger

```csharp
MailMerger merger = new MailMerger(template);
```

`MailMerger` — точка входа для **сведения слияния почты** с Aspose.Words. Он читает шаблон, привязывает данные и готовит окончательный документ одним вызовом.

## Шаг 4: Выполнение слияния — заполнение шаблона Word в одну строку

```csharp
Document mergedDocument = merger.Execute(invoiceData);
```

* Эта строка **заполняет шаблон Word** и создает новый экземпляр `Document` (`mergedDocument`).  
* Все поля слияния заменяются, повторяющиеся секции расширяются, и полученный документ полностью находится в памяти.

### Граничный случай: Пользовательское форматирование

Если вам нужен определённый формат даты, добавьте пользовательский форматтер перед слиянием:

```csharp
merger.Options.DateFormat = "MMMM dd, yyyy"; // e.g., "October 07, 2026"
```

## Шаг 5: Сохранение объединённого документа

```csharp
mergedDocument.Save(@"C:\Invoices\Output\Invoice_001.docx");
```

Вызов **save merged document** записывает полностью заполненный счет на диск. Файл теперь можно открыть в Microsoft Word, отправить как вложение письма или конвертировать в PDF.

### Проверка результата

Откройте `Invoice_001.docx`. Вы должны увидеть:

* **CustomerName** заменён на *Acme Corp*  
* **InvoiceDate** отображает текущую дату в выбранном формате  
* Строка таблицы для *Widget A* (10 × 9.99) и *Widget B* (5 × 19.95)  
* **Total** показывает *199.85*  

Если какое‑либо поле осталось неизменным (например, всё ещё отображает «CustomerName»), проверьте, что имена свойств точно совпадают с именами полей слияния в шаблоне.

## Полный рабочий пример

Ниже представлен полный код программы, который вы можете скопировать и вставить в новый консольный проект.

```csharp
using System;
using Aspose.Words;
using Aspose.Words.LowCode;   // Low‑code mail‑merge API

namespace InvoiceGenerator
{
    class Program
    {
        static void Main()
        {
            // 1️⃣ Load the template
            Document template = new Document(@"C:\Invoices\Template\InvoiceTemplate.docx");

            // 2️⃣ Build the data source
            var invoiceData = new
            {
                CustomerName = "Acme Corp",
                InvoiceDate = DateTime.Today,
                Items = new[]
                {
                    new { Description = "Widget A", Qty = 10, Price = 9.99M },
                    new { Description = "Widget B", Qty = 5,  Price = 19.95M }
                },
                Total = 199.85M
            };

            // 3️⃣ Initialise the mail merger
            MailMerger merger = new MailMerger(template);

            // Optional: customise date format
            merger.Options.DateFormat = "MMMM dd, yyyy";

            // 4️⃣ Perform the merge (populate word template)
            Document mergedDocument = merger.Execute(invoiceData);

            // 5️⃣ Save the resulting file (save merged document)
            mergedDocument.Save(@"C:\Invoices\Output\Invoice_001.docx");

            Console.WriteLine("Invoice generated successfully.");
        }
    }
}
```

Запустите программу (`dotnet run`). Консоль выведет *Invoice generated successfully.* и файл появится в `C:\Invoices\Output`.
