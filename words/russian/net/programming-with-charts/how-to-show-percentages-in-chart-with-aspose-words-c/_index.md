# Как показывать проценты в диаграмме с Aspose.Words C#

Когда‑то задавались вопросом **как показывать проценты в диаграмме** без борьбы с сложным Office interop? Вы не одиноки — многие разработчики сталкиваются с этой проблемой, когда им нужен быстрый программный способ добавить подписи к круговой или кольцевой диаграмме. Хорошая новость: с Aspose.Words для .NET вы можете включить эти подписи данных всего в несколько строк кода.

В этом руководстве мы также рассмотрим **add data labels to pie chart** и **how to enable chart data labels**, чтобы ваши визуализации сразу стали более информативными. К концу вы получите готовый к использованию документ Word (`.docx`) с аккуратно оформленной круговой диаграммой, где проценты расположены снаружи каждого сектора.

## Prerequisites

Прежде чем начать, убедитесь, что у вас есть:

- **Aspose.Words for .NET** (последняя версия, например, 24.9), установленный через NuGet.  
- Файл **ChartTemplate.docx**, уже содержащий круговую или кольцевую диаграмму.  
  *(Если такого файла нет, создайте простой документ Word, вставьте круговую диаграмму и сохраните его как `ChartTemplate.docx`.)*  
- .NET 6.0 или новее и любая удобная IDE (Visual Studio, Rider, VS Code).

Дополнительные зависимости не требуются — Aspose.Words обрабатывает всё внутри.

## How to Show Percentages in Chart – Step‑by‑Step

Ниже процесс разбит на шесть чётких шагов. Каждый шаг содержит точный код C#, который можно скопировать‑вставить, а также краткое объяснение **почему** мы делаем именно так.

### Step 1: Load the Source Document

```csharp
using Aspose.Words;
using Aspose.Words.Drawing.Charts;

// Load the .docx that already holds a chart.
Document sourceDoc = new Document("YOUR_DIRECTORY/ChartTemplate.docx");
```

*Почему?*  
`Document` — точка входа для любой работы с Word. Загрузив шаблон, мы получаем доступ ко всем узлам — фигурам, таблицам, тексту и, конечно, к диаграмме, которую будем менять.

### Step 2: Grab the First Chart Shape

```csharp
// The chart lives inside a Shape node; retrieve it.
Chart chart = (Chart)sourceDoc.GetChild(NodeType.Shape, 0, true);
```

*Почему?*  
Aspose хранит диаграммы как объекты `Shape`. `GetChild` проходит по дереву документа и возвращает первую найденную фигуру, которой в нашем случае является нужная круговая диаграмма.

### Step 3: Confirm the Chart Type

```csharp
if (chart.ChartType == ChartType.Pie || chart.ChartType == ChartType.Doughnut)
{
    // Inside this block we’ll enable the data labels.
}
else
{
    throw new InvalidOperationException("The chart is not a Pie or Doughnut type.");
}
```

*Почему?*  
Подписи с процентами имеют смысл только для круглых диаграмм. Эта проверка защищает от случайного применения настроек к, скажем, гистограмме, где `ShowPercentage` будет игнорироваться.

### Step 4: Enable Data Labels and Show Percentages

```csharp
// Turn on data labels for the chart.
chart.HasDataLabel = true;

// Show the percentage value for each slice.
chart.DataLabel.ShowPercentage = true;
```

*Почему?*  
`HasDataLabel` указывает Aspose отрисовывать подпись для каждой точки данных. Установка `ShowPercentage` гарантирует, что содержимое подписи — вычисленная доля от общего количества, что полностью отвечает требованию **add data labels to pie chart**.

### Step 5: Position Labels Outside the Slices

```csharp
// Place the labels outside the pie slices for better readability.
chart.DataLabel.Position = ChartDataLabelPosition.OutSideEnd;
```

*Почему?*  
Подписи внутри секторов могут сдавливаться, особенно когда сектора малы. `OutSideEnd` имитирует стандартный стиль «снаружи», который вы видите в интерфейсе Word, и сохраняет чистоту диаграммы.

### Step 6: Save the Updated Document

```csharp
sourceDoc.Save("YOUR_DIRECTORY/FormattedPieChart.docx");
```

*Почему?*  
Сохранение записывает все изменения в новый файл. Откройте `FormattedPieChart.docx` в Word, и вы увидите проценты, отображённые рядом с каждым сектором.

#### Expected Result

При открытии `FormattedPieChart.docx` диаграмма должна выглядеть примерно так (воображаемый скриншот):

```
[ Pie chart with three slices ]
- Slice A – 45%
- Slice B – 30%
- Slice C – 25%
```

Все проценты рассчитываются автоматически из базовых рядов данных, а подписи располагаются сразу за каждым сектором.

## Common Variations & Edge Cases

| Situation | What to Adjust |
|-----------|----------------|
| **Multiple charts** in the same document | Loop through `sourceDoc.GetChildNodes(NodeType.Shape, true)` and cast each to `Chart` before applying the same logic. |
| **Bar or line chart** where you still want labels | Use `chart.DataLabel.ShowValue = true;` (or `ShowSeriesName`) instead of `ShowPercentage`. |
| **Custom number format** (e.g., “45 %”) | Set `chart.DataLabel.NumberFormat = "0%";` before saving. |
| **Large data sets** causing label overlap | Consider `chart.DataLabel.ShowLeaderLines = true;` to draw connector lines. |

> **Pro tip:** If you’re generating many documents in a batch, instantiate a single `Aspose.Words.License` object at application start to avoid the performance hit of loading the license repeatedly.

## Full Working Example

Вот полностью готовая программа, которую можно сразу запустить:

```csharp
using System;
using Aspose.Words;
using Aspose.Words.Drawing.Charts;

class Program
{
    static void Main()
    {
        // 1️⃣ Load the template document.
        Document sourceDoc = new Document("YOUR_DIRECTORY/ChartTemplate.docx");

        // 2️⃣ Retrieve the first chart shape.
        Chart chart = (Chart)sourceDoc.GetChild(NodeType.Shape, 0, true);

        // 3️⃣ Ensure we’re dealing with a Pie or Doughnut chart.
        if (chart.ChartType != ChartType.Pie && chart.ChartType != ChartType.Doughnut)
        {
            Console.WriteLine("The selected shape is not a Pie/Doughnut chart.");
            return;
        }

        // 4️⃣ Enable data labels and show percentages.
        chart.HasDataLabel = true;
        chart.DataLabel.ShowPercentage = true;

        // 5️⃣ Position the labels outside the slices.
        chart.DataLabel.Position = ChartDataLabelPosition.OutSideEnd;

        // 6️⃣ Save the modified document.
        sourceDoc.Save("YOUR_DIRECTORY/FormattedPieChart.docx");

        Console.WriteLine("Chart updated successfully – percentages now visible!");
    }
}
```

Скопируйте код, замените `YOUR_DIRECTORY` на реальный путь к вашей папке и запустите. Через несколько секунд у вас будет Word‑файл с полностью подписанной круговой диаграммой.
