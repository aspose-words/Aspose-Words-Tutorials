# Как суммировать документ Word с помощью AI‑провайдеров в C#

Если вам нужно **быстро суммировать документ Word**, это руководство покажет, как это сделать. Вы увидите полностью готовый, исполняемый пример, который позволяет **выбрать AI‑провайдера** (OpenAI или Google) и обрабатывать сценарий **summarize large document** без выхода из IDE.

Суммирование документа Word — распространённая задача при создании ботов базы знаний, дайджестов отчётов или автоматических email‑резюме. В нижеприведённых разделах вы узнаете, какой NuGet‑пакет установить, как загрузить файл `.docx`, настроить суммаризатор и вывести результат — всё на чистом C#.

## Что понадобится

| Требование | Причина |
|-------------|--------|
| .NET 6 SDK или новее | Предоставляет среду выполнения для примера на C# |
| Visual Studio 2022 (или любой IDE) | Упрощает добавление NuGet‑пакетов и запуск консольного приложения |
| NuGet‑пакет `GroupDocs.Summarization` | Содержит API `DocumentSummarizer`, используемое в коде |
| Интернет‑соединение | Необходимо для работы AI‑провайдера (OpenAI или Google) с текстом |

> **Pro tip:** Если планируете **summarize large document** (файлы более 100 KB), включите режим потоковой передачи в параметрах, чтобы избежать загрузки всего файла в память.

## Как суммировать документ Word шаг за шагом

### Шаг 1: Установить библиотеку суммаризации

Откройте консоль диспетчера пакетов и выполните:

```powershell
Install-Package GroupDocs.Summarization
```

Библиотека `GroupDocs.Summarization` абстрагирует вызовы AI, поэтому вы можете менять провайдеров, не меняя бизнес‑логику.

### Шаг 2: Загрузить документ Word

```csharp
using GroupDocs.Summarization;
using GroupDocs.Summarization.Options;

// Step 2: Load the source document
Document doc = new Document("YOUR_DIRECTORY/Report.docx");
```

Класс `Document` читает файл `.docx` и подготавливает его к суммированию. Если файл большой, библиотека автоматически использует парсер с низким потреблением памяти.

### Шаг 3: Настроить параметры суммаризатора и **выбрать AI‑провайдера**

```csharp
// Step 3: Set up summarization options (choose the AI provider)
SummarizerOptions options = new SummarizerOptions
{
    Provider = SummarizerProvider.OpenAI   // or SummarizerProvider.Google
};
```

- `Provider = SummarizerProvider.OpenAI` выбирает модель GPT‑4 от OpenAI.  
- `Provider = SummarizerProvider.Google` выбирает модель Gemini от Google, что идеально подходит, когда вы **summarize with Google** для лучшей поддержки многоязычности.

Вы **choose AI provider** в зависимости от стоимости, задержки или языковых требований. Один и тот же объект `options` работает для обоих провайдеров, сохраняя код чистым.

### Шаг 4: Сгенерировать резюме – поддержка **summarize large document**

```csharp
// Step 4: Generate the summary using the selected provider
string summary = DocumentSummarizer.Summarize(doc, options);
```

Когда вы **summarize large document**, библиотека передаёт содержимое сервису AI потоково, предотвращая ошибки «недостаточно памяти». Метод `Summarize` возвращает строку простого текста с наиболее релевантными предложениями.

### Шаг 5: Вывести результат

```csharp
// Step 5: Output the generated summary
Console.WriteLine("Summary:\n" + summary);
```

Запуск программы выводит лаконичный абзац, отражающий суть исходного файла Word.

## Полный исполняемый пример

```csharp
using System;
using GroupDocs.Summarization;
using GroupDocs.Summarization.Options;

namespace WordSummarizerDemo
{
    class Program
    {
        static void Main(string[] args)
        {
            // Load the source Word document
            Document doc = new Document("YOUR_DIRECTORY/Report.docx");

            // Choose the AI provider (OpenAI or Google)
            SummarizerOptions options = new SummarizerOptions
            {
                Provider = SummarizerProvider.Google   // Change to OpenAI if you prefer
            };

            // Generate the summary – works for both small and large documents
            string summary = DocumentSummarizer.Summarize(doc, options);

            // Display the summary in the console
            Console.WriteLine("Summary:\n" + summary);
        }
    }
}
```

**Ожидаемый вывод**

```
Summary:
The quarterly sales increased by 12% driven by the new product line, while operational costs fell 3% due to efficiency gains. The report also highlights upcoming market expansion in APAC and recommends allocating additional budget to R&D.
```

Точный формулировка будет отличаться в зависимости от выбранной вами **choose AI provider** модели, но структура останется той же.

## Обработка сценария **summarize large document**

Если исходный `.docx` превышает 5 MB, рассмотрите следующие настройки:

1. **Включить разбиение** – библиотека делит документ на блоки по 5 KB перед отправкой в AI‑сервис.
2. **Увеличить `MaxSentences`** в `SummarizerOptions`, если нужен более длинный реферат.
3. **Установить больший `Timeout`**, чтобы учесть более длительное время обработки.

```csharp
options.MaxSentences = 8;          // Return up to 8 sentences
options.EnableChunking = true;    // Essential for very large files
options.Timeout = TimeSpan.FromMinutes(2);
```

Эти правки обеспечивают быструю и надёжную работу операции **summarize large document**.

## Как эффективно **summarize with Google**

Модель Gemini от Google отлично справляется с многоязычным контентом и лаконичной формулировкой. Чтобы получить лучший результат:

- **Указать язык** (необязательно), если документ содержит неанглийский текст:
  ```csharp
  options.Language = "es"; // Spanish
  ```
- **Отрегулировать temperature** для контроля креативности:
  ```csharp
  options.Temperature = 0.3; // More deterministic output
  ```

При **summarize with Google** сервис может вернуть чуть более короткое, но сильно сфокусированное резюме по сравнению с OpenAI. Протестируйте оба провайдера на образце документа, чтобы решить, какой лучше подходит вашему продукту.

## Распространённые подводные камни и как их избежать

| Симптом | Причина | Решение |
|---------|-------|-----|
| Пустое резюме | Отсутствует ключ провайдера или сеть заблокирована | Проверьте API‑ключи в переменных окружения и убедитесь, что исходящий HTTPS разрешён |
| Обрезанный текст | Документ превышает лимит токенов провайдера | Включите `EnableChunking` или увеличьте `MaxTokens`, если библиотека это поддерживает |
| Неправильный язык | Неправильно указана опция `Language` | Удалите опцию или задайте язык, соответствующий документу |

Раннее решение этих проблем экономит время отладки, особенно когда вы **choose AI provider** для продакшн‑нагрузок.

Экспериментируйте с `MaxSentences`, `Temperature` и настройками chunking, чтобы точно подогнать вывод под ваш сценарий.
