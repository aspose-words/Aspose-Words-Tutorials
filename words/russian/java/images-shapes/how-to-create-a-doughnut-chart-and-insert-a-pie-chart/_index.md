# Как создать кольцевую диаграмму и вставить круговую диаграмму

Если вам нужно **создать кольцевую диаграмму** в Java, этот учебник проведет вас через все шаги. Мы также покажем, как **вставить круговую диаграмму** с помощью того же API построителя, чтобы вы могли без труда переключаться между визуальными стилями. К концу руководства у вас будет полностью готовая, исполняемая программа, которая генерирует оба типа диаграмм и демонстрирует распространённые настройки.

The tutorial covers:

* Инициализация построителя диаграмм, предоставляемого выбранной библиотекой.  
* Создание кольцевой диаграммы и настройка размера отверстия.  
* Вставка круговой диаграммы и «взрыв» сектора для выделения.  
* Советы по обработке граничных случаев, таких как отсутствие рядов данных или неподдерживаемые типы диаграмм.

Вам понадобится только современный JDK (8 или новее) и JAR библиотеки диаграмм в вашем classpath. Внешние сервисы не требуются.

## Требования

| Элемент | Причина |
|------|--------|
| Java Development Kit (JDK) 8+ | Требуется для компиляции и выполнения примера. |
| Библиотека диаграмм (например, **Aspose.Cells for Java** или **JFreeChart**) | Предоставляет `ChartBuilder`, `ChartType` и методы манипуляции рядами, используемые в коде. |
| IDE или текстовый редактор | Для написания и выполнения Java‑файла. |

Убедитесь, что JAR библиотеки добавлен в путь сборки вашего проекта. Если вы используете Maven, добавьте соответствующую зависимость; в противном случае поместите JAR в папку `libs` и укажите его при компиляции.

## Шаг 1: Настройка построителя диаграмм

Первый шаг — создать экземпляр `ChartBuilder` (или аналогичный), который будет генерировать объекты диаграмм. Этот объект выступает в роли фабрики и хранит лист или холст, где будет размещена диаграмма.

```java
import com.aspose.cells.*;

public class DoughnutAndPieDemo {
    public static void main(String[] args) throws Exception {
        // Create a new workbook to host the charts
        Workbook workbook = new Workbook();
        Worksheet sheet = workbook.getWorksheets().get(0);

        // Initialize the chart builder with the worksheet
        ChartBuilder builder = new ChartBuilder(sheet);
```

**Почему это важно:**  
Построитель привязывает диаграмму к конкретному листу, гарантируя, что все последующие объекты диаграмм используют одну и ту же поверхность рисования. Пропуск этого шага оставит вас без целевого места для визуальных элементов.

## Шаг 2: **Создать кольцевую диаграмму**

Теперь мы создаём кольцевую диаграмму с заданным размером. Размер отверстия определяет, какая часть центра диаграммы будет пустой, превращая обычную круговую диаграмму в кольцевую.

```java
        // Insert a doughnut chart with a width of 500 and height of 350
        Chart doughnutChart = builder.insertChart(ChartType.DOUGHNUT, 500, 350);

        // Set the hole size to 30% of the chart radius
        doughnutChart.getDoughnutChart().setHoleSize(30);

        // Add sample data series
        doughnutChart.getNSeries().add("{10, 20, 30, 40}", true);
```

**Explanation:**  

* `insertChart(ChartType.DOUGHNUT, 500, 350)` создает объект диаграммы и резервирует место на листе.  
* `setHoleSize(30)` преобразует круговую диаграмму в кольцевую с 30 % пустым центром.  
* `add("{10, 20, 30, 40}", true)` предоставляет четыре значения; флаг `true` указывает библиотеке рассматривать их как один ряд.

**Граничный случай:** Если выбранный тип диаграммы не поддерживает отверстие (например, столбчатая диаграмма), вызов `getDoughnutChart()` генерирует исключение. Всегда проверяйте тип диаграммы перед изменением размера отверстия.

## Шаг 3: **Вставить круговую диаграмму**

После того как кольцевая диаграмма готова, мы демонстрируем, как **вставить круговую диаграмму** с помощью того же построителя. Этот шаг подчёркивает схожесть двух типов диаграмм и показывает, как выделить сектор.

```java
        // Insert a pie chart next to the doughnut
        Chart pieChart = builder.insertChart(ChartType.PIE, 400, 300);

        // Add the same data series for consistency
        pieChart.getNSeries().add("{10, 20, 30, 40}", true);

        // Explode the first slice by 10% to draw attention
        pieChart.getSeries().get(0).setExplode(10);
```

**Explanation:**  

* `ChartType.PIE` указывает построителю создать классическую круговую диаграмму.  
* `setExplode(10)` смещает первый сектор на 10 % от радиуса, что является распространённым способом выделить ключевой показатель.  

**Подсказка:** Метод `setExplode` работает только с первым рядом круговой диаграммы. Если у вас несколько рядов, необходимо указать правильный индекс.

## Шаг 4: Сохранить рабочую книгу

Наконец, запишите рабочую книгу в файл, чтобы вы могли просматривать диаграммы в Excel или любом совместимом просмотрщике.

```java
        // Save the workbook to a file
        workbook.save("DoughnutAndPieChart.xlsx");
        System.out.println("Workbook created with doughnut and pie charts.");
    }
}
```

**Почему сохранять сейчас:** Сохранение рабочей книги завершает все операции рисования. Попытка открыть файл до сохранения приводит к пустому или неполному документу.

**Результат:** При открытии *DoughnutAndPieChart.xlsx* слева будет отображаться кольцевая диаграмма с 30 % отверстием, а справа — круговая диаграмма с «взрывом» первого сектора.

## Шаг 5: Распространённые варианты и устранение неполадок

| Ситуация | Корректировка |
|-----------|------------|
| **Разные размеры диаграммы** | Измените аргументы ширины и высоты в `insertChart`. |
| **Несколько рядов данных** | Вызовите `add` несколько раз или передайте строку двумерного массива. |
| **Динамический размер отверстия** | Вычислите размер отверстия на основе диапазона данных, затем вызовите `setHoleSize`. |
| **Взрыв нескольких секторов** | Пройдитесь в цикле по `chart.getSeries().get(i).setExplode(percent)` для каждого сектора, который нужно сместить. |
| **Библиотека не поддерживает кольцевую диаграмму** | Используйте круговую диаграмму и вручную нарисуйте наложение белого круга, хотя это менее точно. |

**Совет:** Всегда вызывайте `builder.flush()` (если доступно) после вставки диаграмм при работе с большими рабочими книгами. Это освобождает внутренние буферы и предотвращает утечки памяти.
