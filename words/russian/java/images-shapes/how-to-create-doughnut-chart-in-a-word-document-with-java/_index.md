# Как создать кольцевую диаграмму в документе Word с помощью Java

Если вам нужно **create doughnut chart** внутри файла Word, этот учебник покажет полное, готовое к запуску решение. Вы увидите, как **insert pie chart**, превратить его в кольцевую диаграмму, **rotate pie chart** для лучшего баланса и **format pie chart** в соответствии с вашим брендом. К концу вы получите профессиональный документ Word, который можно использовать в отчетах, панелях мониторинга или автоматических вложениях к письмам.

Создание диаграммы программно устраняет ручные операции копирования‑вставки и гарантирует единообразный стиль во многих сгенерированных документах. В примере используется библиотека Aspose.Words for Java, которая работает с Java 8+ и не требует установки Microsoft Office. Других предварительных условий не требуется, кроме стандартного JDK и вашей любимой IDE.

## Предварительные требования

- Java Development Kit (JDK) 8 или новее  
- Maven или Gradle для управления зависимостями (в учебнике используется Maven)  
- библиотека Aspose.Words for Java (достаточна бесплатная пробная лицензия для тестирования)  

Add the Aspose.Words dependency to your `pom.xml`:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-words</artifactId>
    <version>24.9</version> <!-- Use the latest stable version -->
</dependency>
```

> **Совет:** Зарегистрируйте вашу лицензию с помощью `License license = new License(); license.setLicense("Aspose.Words.lic");` перед созданием любого документа, чтобы убрать водяные знаки оценки.

## Создание кольцевой диаграммы в документе Word

Основной рабочий процесс состоит из пяти логических шагов. Каждый шаг помещён в отдельный метод, чтобы код оставался чистым и переиспользуемым.

```java
import com.aspose.words.*;
import com.aspose.words.drawing.*;

public class DoughnutChartDemo {

    public static void main(String[] args) throws Exception {
        // Step 1: create blank Word document
        Document doc = createBlankWordDocument();

        // Step 2: insert a pie chart (base for the doughnut)
        Chart chart = insertPieChart(doc, 400, 300);

        // Step 3: convert the pie chart into a doughnut and rotate it
        customizeChartAppearance(chart);

        // Step 4: apply additional formatting to the chart
        formatPieChart(chart);

        // Step 5: save the final document
        doc.save("output/DoughnutChartFormatted.docx");
        System.out.println("Document saved successfully.");
    }

    /** Step 1 – create blank Word document */
    private static Document createBlankWordDocument() {
        // Aspose.Words creates an empty document by default
        return new Document();
    }

    /** Step 2 – insert pie chart with given dimensions */
    private static Chart insertPieChart(Document doc, int width, int height) throws Exception {
        DocumentBuilder builder = new DocumentBuilder(doc);
        // ChartType.PIE creates a standard pie chart that we will later turn into a doughnut
        Chart chart = builder.insertChart(ChartType.PIE, width, height);
        // Populate the chart with sample data
        chart.getSeries().clear(); // Remove default series
        ChartSeries series = chart.getSeries().add("Sales", new String[]{"Q1", "Q2", "Q3", "Q4"},
                new double[]{15000, 23000, 18000, 27000});
        return chart;
    }

    /** Step 3 – rotate pie chart and make it a doughnut */
    private static void customizeChartAppearance(Chart chart) {
        // Explode the first slice for emphasis
        chart.getSeries().get(0).setExplode(20);
        // Convert the pie into a doughnut by setting a hole size (percentage of radius)
        chart.setHoleSize(30); // 30% hole creates a classic doughnut look
        // Rotate the chart so the largest slice starts at 45°
        chart.setRotationAngle(45);
    }

    /** Step 4 – additional formatting of the pie chart */
    private static void formatPieChart(Chart chart) {
        // Example: change the first slice color to a brand color
        chart.getSeries().get(0).getPoints().get(0).getFormat().setFillForegroundColor(Color.fromArgb(0xFF, 0x4A, 0x90));
        // Add a legend and position it at the bottom
        chart.setHasLegend(true);
        chart.getLegend().setPosition(LegendPosition.BOTTOM);
        // Set a title for the chart
        chart.setTitle("Quarterly Sales Distribution");
    }
}
```

### Что делает код

| Шаг | Действие | Причина |
|------|--------|--------|
| **Создать пустой документ Word** | `new Document()` | Начинает с чистого файла, чтобы вы контролировали каждый элемент. |
| **Вставить круговую диаграмму** | `builder.insertChart(ChartType.PIE, …)` | Круговая диаграмма — базовая форма; Aspose предоставляет кольцевую, регулируя размер отверстия. |
| **Повернуть круговую диаграмму** | `chart.setRotationAngle(45)` | Поворот выравнивает крупнейший сектор в более читаемое положение. |
| **Форматировать круговую диаграмму** | `setExplode`, `setHoleSize`, color, legend | Улучшает визуальную иерархию и соответствует корпоративным стилевым рекомендациям. |
| **Сохранить документ** | `doc.save("…/DoughnutChartFormatted.docx")` | Записывает окончательный .docx файл на диск, готовый к распространению. |

## Вставка круговой диаграммы перед преобразованием в кольцевую

Aspose.Words не предоставляет прямой метод “insert doughnut chart”. Вместо этого вы **insert pie chart** и затем изменяете её свойства. Такой двухшаговый подход даёт полный контроль над серией данных, взрывом срезов и размером отверстия. Если вам нужна чистая круговая диаграмма в другом месте, просто опустите вызов `setHoleSize`.

## Поворот круговой диаграммы для визуального баланса

Ориентация по умолчанию начинается с первого сектора в положении 12 часов. Во многих бизнес‑отчётах самый важный сектор должен начинаться под более естественным углом, например 45 градусов. Метод `setRotationAngle(double angle)` принимает градусы и вращает всю диаграмму, не влияя на значения данных.

## Форматирование круговой диаграммы и настройка внешнего вида

Помимо преобразования в кольцевую диаграмму, часто требуется **format pie chart** элементы:

- **Explode** первый сектор (`setExplode`) для привлечения внимания.  
- **Color** каждый сектор с помощью `getPoints().get(i).getFormat().setFillForegroundColor`.  
- **Legend** позиционирование (`setHasLegend`, `setPosition`) помогает читателям интерпретировать категории.  
- **Title** (`setTitle`) даёт контекст с первого взгляда.  

Все эти настройки являются необязательными; вы можете адаптировать их под палитру вашего бренда или корпоративные шаблоны.

## Создание пустого документа Word и сохранение результата

Метод `createBlankWordDocument` инкапсулирует шаг **create blank word document**. Изоляция этой логики упрощает повторное использование метода при генерации нескольких отчётов в пакетном процессе. После всех настроек `doc.save` записывает файл в стандартном формате Office Open XML (`.docx`), который можно открыть в Microsoft Word, LibreOffice или Google Docs без потери качества.

### Ожидаемый вывод

При запуске метода `main` консоль выводит:

```
Document saved successfully.
```

И файл `output/DoughnutChartFormatted.docx` содержит одну страницу с кольцевой диаграммой под заголовком *Quarterly Sales Distribution*. Диаграмма показывает четыре сектора, первый сектор взорван, окрашен в фирменный цвет и повернут на 45 градусов.

## Распространённые варианты и граничные случаи

| Ситуация | Корректировка |
|-----------|------------|
| **Более одной серии данных** | Добавьте дополнительные объекты `ChartSeries` в `chart.getSeries()`. |
| **Другой размер диаграммы** | Измените аргументы `width` и `height` в `insertPieChart`. |
| **Без отверстия (чистая круговая)** | Опустите `chart.setHoleSize(…)` или установите его в `0`. |
| **Большие документы** | Используйте `DocumentBuilder` для вставки диаграммы в конкретный раздел или закладку. |
| **Лицензия не установлена** | Библиотека работает в режиме оценки, добавляя водяной знак на первую страницу. Зарегистрируйте лицензию, чтобы убрать его. |

## Заключение

Теперь вы знаете, как **create doughnut chart** в документе Word с помощью Java, от **create blank word document** до **insert pie chart**, **rotate pie chart** и **format pie chart** для получения отполированного конечного продукта. Полный, исполняемый пример можно добавить в любой Java‑проект, уже использующий Aspose.Words.

Далее вы можете изучить:

- Автоматизация генерации нескольких документов в цикле для пакетной отчётности  

Не стесняйтесь экспериментировать с цветами, взрывом срезов и легендами, чтобы соответствовать визуальному стилю вашей организации. Удачной работы с диаграммами!
