## Как создавать переиспользуемые шаблоны aspose

Класс `Document` представляет документ Word, который можно загрузить, отредактировать и сохранить. Загрузите файл шаблона с помощью `Document doc = new Document("Template.docx");` и используйте `DocumentBuilder` для вставки заполнителей. `DocumentBuilder` предоставляет методы для построения и изменения содержимого документа программно. Замените заполнители во время выполнения с помощью `doc.getRange().replace("{Name}", actualName, new FindReplaceOptions());`. `FindReplaceOptions` задаёт параметры операций поиска‑и‑замены, такие как чувствительность к регистру. Сохраните результат с помощью `doc.save("Result.docx");`. Этот шаблон позволяет генерировать сотни персонализированных документов из одного переиспользуемого шаблона без ручного редактирования.

## Как программно изменять документ Word

`DocumentBuilder` используется для вставки текста, таблиц, изображений и других элементов в экземпляр `Document`. Используйте `DocumentBuilder` для вставки текста, таблиц или изображений непосредственно в живой объект `Document`. Например, `builder.writeln("New paragraph");` записывает строку текста с разрывом строки и добавляет содержимое в текущую позицию курсора. Все изменения выполняются в памяти, поэтому временные файлы не требуются, а API работает на любой платформе, поддерживающей Java.

## Как форматировать документ Word java

`Style` определяет набор атрибутов форматирования, которые могут быть применены к абзацам, символам или таблицам. Применяйте стили с помощью `Style style = doc.getStyles().add(StyleType.PARAGRAPH, "MyStyle");`. `StyleType.PARAGRAPH` указывает, что стиль применяется к элементам абзаца. Установите свойства шрифта, интервалов и выравнивания, затем назначьте стиль абзацу через `paragraph.getParagraphFormat().setStyle(style);`. Такой подход гарантирует единообразное форматирование во всех сгенерированных документах. Вы также можете настроить межстрочный интервал, отступы и выравнивание в соответствии с корпоративными руководствами по брендингу. После создания стиля применяйте его к любому абзацу, чтобы обеспечить одинаковый внешний вид по всему документу.
