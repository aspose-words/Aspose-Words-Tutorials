# Как создать столбчатую диаграмму в Python с помощью Aspose.Words

Если вам нужно создать столбчатую диаграмму в Python, это руководство покажет точный код и логику, необходимые для этого. С помощью API диаграмм Aspose.Words вы можете задать точные размеры, применить встроенный стиль и экспортировать результат, не покидая Python.

Создание столбчатой диаграммы — распространённая задача для отчётов, панелей мониторинга и автоматизированного создания документов. В этом учебнике рассматривается каждый шаг — от импорта библиотеки до проверки сохранённого изображения — чтобы вы могли интегрировать генерацию диаграмм в любой проект на Python.

## Требования

Прежде чем начать, убедитесь, что у вас есть:

* Python 3.8 или новее.
* Действительная лицензия Aspose.Words for Python (или бесплатный оценочный ключ).
* Базовые знания модулей Python и объектно‑ориентированного кода.

Движок диаграмм Aspose.Words работает на Windows, macOS и Linux и не требует дополнительных графических библиотек, поскольку рендеринг происходит на стороне сервера.

## Шаг 1: Импортировать библиотеку Aspose.Words

Первый шаг — импортировать пакет `aspose.words` и задать ему короткий псевдоним. Импорт в начале файла упрощает пространство имён и делает код более читабельным.

```python
# Step 1: Import the Aspose.Words library
import aspose.words as aw
```

`aw` теперь ссылается на полный API Aspose.Words, включая класс `Chart`, который вы будете использовать для построения столбчатой диаграммы.

## Шаг 2: Создать столбчатую диаграмму с нужными размерами

Для столбчатой диаграммы необходимо явно указать ширину и высоту, чтобы полученное изображение соответствовало макету вашего документа. Конструктор `Chart` принимает три аргумента: тип диаграммы, ширину (в пунктах) и высоту (в пунктах). Использование `aw.ChartType.COLUMN` указывает движку генерировать вертикальную столбчатую диаграмму.

```python
# Step 2: Create a column chart with the desired dimensions
chart = aw.Chart(aw.ChartType.COLUMN, 400, 300)   # width=400pt, height=300pt
```

*Зачем задавать размеры?*  
Когда вы встраиваете диаграмму в документ Word или экспортируете её как изображение, окружающий контент учитывает именно те размеры, которые вы указали. Это предотвращает нежелательное масштабирование или обрезку.

### Совет: используйте `chart.dimensions` для динамического изменения размеров

Если ваш набор данных меняется, вы можете вычислять размер на основе количества рядов:

```python
series_count = 5
base_width = 80
chart.width = base_width * series_count
chart.height = 300
```

## Шаг 3: Применить встроенный стиль к столбчатой диаграмме

Aspose.Words поставляется с несколькими предопределёнными визуальными темами. Выбор стиля избавляет от необходимости вручную настраивать цвета, шрифты и сетку. `aw.ChartStyle.STYLE_5` — чистый, профессиональный вид, подходящий для большинства бизнес‑отчётов.

```python
# Step 3: Apply a built‑in style to the chart
chart.style = aw.ChartStyle.STYLE_5
```

Если вам нужен иной внешний вид, замените `STYLE_5` любой другой константой (`STYLE_1` … `STYLE_8`). Каждый стиль следует единой схеме именования, что упрощает экспериментирование.

### Пограничный случай: неверная константа стиля

Попытка присвоить несуществующий стиль вызовет `AttributeError`. Защититесь, проверив константу против перечисления:

```python
if hasattr(aw.ChartStyle, "STYLE_5"):
    chart.style = aw.ChartStyle.STYLE_5
else:
    raise ValueError("Requested chart style does not exist.")
```

## Шаг 4: Добавить серии данных в столбчатую диаграмму

Диаграмма без данных бессмысленна. Вы можете добавить один или несколько объектов `ChartSeries`, каждый из которых представляет группу столбцов. В примере ниже добавляется одна серия с тремя точками данных.

```python
# Step 4: Add data series to the column chart
series = chart.series.add()
series.name = "Quarterly Sales"
series.data = [12000, 15000, 18000]   # Values for Q1, Q2, Q3
```

Вы можете повторять вызов `chart.series.add()`, чтобы добавить дополнительные серии (например, «Прогнозируемые продажи»). API автоматически размещает столбцы рядом друг с другом.

## Шаг 5: Отрисовать диаграмму и сохранить её как изображение

После настройки диаграммы вы рендерите её в bitmap или файл изображения. Метод `save` принимает путь к файлу и необязательный формат. PNG — без потерь и широко поддерживается.

```python
# Step 5: Render and save the chart as a PNG image
output_path = "column_chart.png"
chart.save(output_path, aw.SaveFormat.PNG)
print(f"Chart saved to {output_path}")
```

Перечисление `SaveFormat` включает PNG, JPEG, BMP и другие. Выберите формат, соответствующий вашему последующему рабочему процессу.

## Проверка результата

Откройте `column_chart.png` в любом просмотрщике изображений. Вы должны увидеть столбчатую диаграмму из трёх столбцов, оформленную выбранной встроенной темой, размером ровно 400 × 300 пунктов.

![Column chart generated by Aspose.Words in Python](column_chart.png){: .center alt="Скриншот столбчатой диаграммы, сгенерированной Aspose.Words в Python"}

Если изображение пустое или искажённое, проверьте следующее:

1. Объект `aw.Chart` был создан до добавления серий.
2. Константа `chart.style` соответствует существующему значению перечисления.
3. Вызов `save` использует поддерживаемый `SaveFormat`.

## Распространённые варианты и дополнительные советы

| Ситуация | Рекомендуемое изменение |
|-----------|--------------------|
| **Несколько серий данных** | Добавьте дополнительные блоки `chart.series.add()` и задайте `series.name` и `series.data` для каждой. |
| **Пользовательские цвета** | После применения встроенного стиля переопределите отдельные цвета столбцов через `series.points[i].fill.fore_color`. |
| **Встраивание в документ Word** | Вместо `chart.save()` используйте `doc = aw.Document(); doc.sections[0].body.append_child(chart); doc.save("report.docx")`. |
| **Динамический размер** | Вычисляйте ширину на основе количества серий (`width = 80 * len(chart.series)`). |

Эти варианты показывают, как один и тот же базовый код адаптируется к различным сценариям отчётности.
