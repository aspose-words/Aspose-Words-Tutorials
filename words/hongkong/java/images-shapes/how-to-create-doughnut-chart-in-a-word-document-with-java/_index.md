# 如何在 Word 文件中使用 Java 建立 doughnut chart

如果您需要在 Word 檔案中 **create doughnut chart**，本教學將提供完整、可直接執行的解決方案。您將會看到如何 **insert pie chart**、將其轉換為 doughnut、**rotate pie chart** 以取得更佳的平衡，以及 **format pie chart** 以符合您的品牌形象。完成後，您將擁有一份可用於報告、儀表板或自動化電子郵件附件的專業 Word 文件。

以程式方式建立圖表可省去手動複製貼上的步驟，並確保在大量產生的文件中保持一致的樣式。範例使用 Aspose.Words for Java 函式庫，支援 Java 8 以上，且不需要安裝 Microsoft Office。除標準 JDK 與您喜愛的 IDE 外，無需其他前置條件。

## 前置條件

- Java Development Kit (JDK) 8 或更新版本  
- Maven 或 Gradle 用於相依管理（本教學使用 Maven）  
- Aspose.Words for Java 函式庫（免費試用授權足以進行測試）  

將 Aspose.Words 相依加入您的 `pom.xml`：

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-words</artifactId>
    <version>24.9</version> <!-- Use the latest stable version -->
</dependency>
```

> **Pro tip:** 在建立任何文件之前，使用 `License license = new License(); license.setLicense("Aspose.Words.lic");` 註冊授權，以移除評估水印。

## 在 Word 文件中建立 doughnut chart

核心工作流程包含五個邏輯步驟。每個步驟皆封裝於各自的方法中，以保持程式碼的簡潔與可重用性。

```java
import com.aspose.words.*;
import com.aspose.words.drawing.*;

public class DoughnutChartDemo {

    public static void main(String[] args) throws Exception {
        // Step 1: create blank Word document
        Document doc = createBlankWordDocument();

        // Step 2: insert a pie chart (base for the doughnut)
        Chart chart = insertPieChart(doc, 400, 300);

        // Step 3: convert the pie chart into a doughnut and rotate it
        customizeChartAppearance(chart);

        // Step 4: apply additional formatting to the chart
        formatPieChart(chart);

        // Step 5: save the final document
        doc.save("output/DoughnutChartFormatted.docx");
        System.out.println("Document saved successfully.");
    }

    /** Step 1 – create blank Word document */
    private static Document createBlankWordDocument() {
        // Aspose.Words creates an empty document by default
        return new Document();
    }

    /** Step 2 – insert pie chart with given dimensions */
    private static Chart insertPieChart(Document doc, int width, int height) throws Exception {
        DocumentBuilder builder = new DocumentBuilder(doc);
        // ChartType.PIE creates a standard pie chart that we will later turn into a doughnut
        Chart chart = builder.insertChart(ChartType.PIE, width, height);
        // Populate the chart with sample data
        chart.getSeries().clear(); // Remove default series
        ChartSeries series = chart.getSeries().add("Sales", new String[]{"Q1", "Q2", "Q3", "Q4"},
                new double[]{15000, 23000, 18000, 27000});
        return chart;
    }

    /** Step 3 – rotate pie chart and make it a doughnut */
    private static void customizeChartAppearance(Chart chart) {
        // Explode the first slice for emphasis
        chart.getSeries().get(0).setExplode(20);
        // Convert the pie into a doughnut by setting a hole size (percentage of radius)
        chart.setHoleSize(30); // 30% hole creates a classic doughnut look
        // Rotate the chart so the largest slice starts at 45°
        chart.setRotationAngle(45);
    }

    /** Step 4 – additional formatting of the pie chart */
    private static void formatPieChart(Chart chart) {
        // Example: change the first slice color to a brand color
        chart.getSeries().get(0).getPoints().get(0).getFormat().setFillForegroundColor(Color.fromArgb(0xFF, 0x4A, 0x90));
        // Add a legend and position it at the bottom
        chart.setHasLegend(true);
        chart.getLegend().setPosition(LegendPosition.BOTTOM);
        // Set a title for the chart
        chart.setTitle("Quarterly Sales Distribution");
    }
}
```

### 程式碼功能說明

| 步驟 | 操作 | 原因 |
|------|--------|--------|
| **Create blank Word document** | `new Document()` | 從乾淨的檔案開始，讓您能控制每個元素。 |
| **Insert pie chart** | `builder.insertChart(ChartType.PIE, …)` | pie chart 為基礎形狀；Aspose 只能透過調整孔徑大小來產生 doughnut。 |
| **Rotate pie chart** | `chart.setRotationAngle(45)` | 旋轉可將最大切片對齊至較易閱讀的位置。 |
| **Format pie chart** | `setExplode`, `setHoleSize`, color, legend | 提升視覺層次，並符合企業樣式指南。 |
| **Save document** | `doc.save("…/DoughnutChartFormatted.docx")` | 將最終的 .docx 檔寫入磁碟，準備發佈。 |

## 在轉換為 doughnut 前插入 pie chart

Aspose.Words 並未提供直接的「insert doughnut chart」方法。相反地，您需要 **insert pie chart**，然後再修改其屬性。這種兩步驟的方式讓您能完整控制資料系列、切片爆炸與孔徑大小。若在其他情況下只需純粹的 pie chart，只需省略 `setHoleSize` 呼叫即可。

## 為視覺平衡旋轉 pie chart

預設方向會將第一個切片置於 12 點鐘位置。在許多商業報告中，最重要的切片應該從較自然的角度開始，例如 45 度。`setRotationAngle(double angle)` 方法接受度數，並旋轉整個圖表而不影響資料值。

## 格式化 pie chart 並自訂外觀

除了轉換為 doughnut，您通常還會想要 **format pie chart** 元素：

- **Explode** 第一個切片（`setExplode`）以吸引注意。  
- **Color** 每個切片，使用 `getPoints().get(i).getFormat().setFillForegroundColor`。  
- **Legend** 位置（`setHasLegend`、`setPosition`）有助於讀者解讀類別。  
- **Title**（`setTitle`）提供一目了然的說明。  

上述設定皆為可選，您可依品牌配色或企業範本自行調整。

## 建立空白 Word 文件並儲存結果

`createBlankWordDocument` 方法封裝了 **create blank word document** 步驟。將此邏輯獨立化可在批次產生多份報告時輕鬆重複使用。完成所有自訂後，`doc.save` 會以標準的 Office Open XML 格式（`.docx`）寫入檔案，該檔案可在 Microsoft Word、LibreOffice 或 Google Docs 中開啟且不失真。

### 預期輸出

執行 `main` 方法時，主控台會輸出：

```
Document saved successfully.
```

而檔案 `output/DoughnutChartFormatted.docx` 會包含一頁，內有標題為 *Quarterly Sales Distribution* 的 doughnut chart。圖表顯示四個切片，第一個切片已爆炸，使用品牌色調著色，且旋轉 45 度。

## 常見變化與邊緣案例

| 情況 | 調整 |
|-----------|------------|
| **More than one data series** | 在 `chart.getSeries()` 中加入額外的 `ChartSeries` 物件。 |
| **Different chart size** | 修改 `insertPieChart` 的 `width` 與 `height` 參數。 |
| **No hole (pure pie)** | 省略 `chart.setHoleSize(…)` 或將其設為 `0`。 |
| **Large documents** | 使用 `DocumentBuilder` 將圖表插入特定章節或書籤。 |
| **License not set** | 庫會以評估模式執行，於首頁加上水印。註冊授權即可移除。 |

## 結論

現在您已了解如何使用 Java 在 Word 文件中 **create doughnut chart**，從 **create blank word document** 到 **insert pie chart**、**rotate pie chart**，以及 **format pie chart**，以製作出精緻的最終產品。完整且可執行的範例可直接放入任何已使用 Aspose.Words 的 Java 專案中。

接下來，您可以探索：

- 加入資料標籤（`chart.getSeries().get(0).setDataLabelType(DataLabelType.CATEGORY_AND_PERCENT);`）  
- 將圖表匯出為影像（`chart.toImage`），以用於 HTML 電子郵件  
- 在迴圈中自動產生多份文件，以進行批次報告  

歡迎自行嘗試不同的顏色、切片爆炸與圖例設定，以符合貴組織的視覺語言。祝您圖表製作愉快！
