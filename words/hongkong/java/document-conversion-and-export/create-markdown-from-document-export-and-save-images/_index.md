# 如何將 docx 轉換為 markdown 並將圖片存放於子資料夾

如果你需要在**將 docx 轉換為 markdown**的同時，保持每張嵌入的圖片整齊有序，你來對地方了。許多開發者以程式方式產生報告、手冊或部落格草稿，結果會在輸出目錄中出現一堆雜亂的圖片檔案。本教學示範使用 Aspose.Words for .NET 的乾淨、回呼驅動方式，將文件匯出為 markdown，將每張圖片存入專屬的 *md‑resources* 資料夾，並儲存最終可直接發布的 markdown 檔案。

> **快速概覽:**  
> • 設定 `MarkdownSaveOptions`  
> • 實作 `IResourceSavingCallback` 以重新導向圖片  
> • 使用已設定的選項呼叫 `Document.Save`

既然你已了解為何回呼比事後處理更佳，讓我們深入一步步的解決方案。

## 快速解答
- **「將 docx 轉換為 markdown」實際上是做什麼？** 它將 Word 處理標記轉換為純文字 markdown，同時保留標題、清單、表格與圖片參照。  
- **哪個函式庫負責轉換？** Aspose.Words for .NET 提供完整管理的伺服器端 API，無需安裝 Microsoft Word 即可運作。  
- **我需要撰寫任何圖片處理程式碼嗎？** 不需要；`IResourceSavingCallback` 會負責將每張圖片儲存至你指定的資料夾。  
- **我可以更改輸出資料夾名稱嗎？** 當然可以 – 將 `"md-resources/"` 替換為任意相對或絕對路徑即可。  
- **此解決方案相容於 .NET 6 及更高版本嗎？** 是的，它可在 .NET 6+、.NET 5、.NET Core 3.1 以及 .NET Framework 4.7+ 上執行。

## 什麼是將 docx 轉換為 markdown？
**將 docx 轉換為 markdown** 是將 Microsoft Word 文件（DOCX）轉換為使用 markdown 語法的 markdown（`.md`）檔案的過程。此轉換會保留結構元素，並可選擇性抽取嵌入的資源，例如圖片。

轉換由 Aspose.Words 執行，這是一個支援 **35+ 種輸入與輸出格式** 的函式庫——包括 DOCX、PDF、HTML 與 Markdown——讓你在不將整個檔案載入記憶體的情況下處理數百頁的文件。

## 為何使用 Aspose.Words 進行 markdown 匯出？
Aspose.Words 在記憶體中處理文件，並直接將結果寫入目標格式，這意味著：

- **速度：** 一般 200 頁的 DOCX 檔案在標準虛擬機上可於 2 秒內轉換為 markdown。  
- **準確度：** 支援所有 50+ 種內建 markdown 風格，確保表格、程式碼區塊與註腳正確呈現。  
- **資源控制：** 內建的 `IResourceSavingCallback` 讓你精確決定每張圖片的儲存位置，省去額外的清理步驟。

Aspose.Words 提供高效、精確的轉換，同時讓你完整掌控資源處理。它免除事後處理步驟，降低記憶體使用，並確保圖片、表格與樣式在 markdown 輸出中忠實再現。

## 如何將 docx 轉換為 markdown？

使用 `new Document("source.docx")` 載入來源文件，設定 `MarkdownSaveOptions` 以使用回呼將每張圖片寫入 `md-resources/`，最後呼叫 `doc.Save("output.md", saveOptions)`。這個三步驟模式會轉換檔案、抽取圖片，並產生帶有相對圖片連結的乾淨 markdown 檔案——全部在一次方法呼叫中完成。

### 步驟 1：設定 markdown 轉換的儲存選項

MarkdownSaveOptions 設定 Aspose.Words 如何將文件轉換為 Markdown。

```csharp
// Step 1: Initialize Markdown save options
var markdownSaveOptions = new Aspose.Words.Saving.MarkdownSaveOptions();
```

```csharp
// Step 1: Initialize Markdown save options
var markdownSaveOptions = new Aspose.Words.Saving.MarkdownSaveOptions();
```

> **為何這很重要：**  
> 若未明確建立 `MarkdownSaveOptions`，函式庫會回退至預設設定，將圖片直接嵌入 Markdown 檔案為 Base64 字串。這會使檔案變得龐大，且失去擁有乾淨 *images* 資料夾的目的。

### 步驟 2：定義資源儲存回呼以匯出圖片

`IResourceSavingCallback` 讓你在匯出過程中控制每個資源（圖片、SVG）的儲存位置。

現在我們告訴儲存器 **放置** 每張圖片的位置。`IResourceSavingCallback` 介面提供一個掛鉤，於匯出時對每個發現的資源（圖片、SVG 等）觸發。在回呼內我們會：

1. 確認目標資料夾存在（`md-resources/`）。  
2. 設定 `OutputFileName` 為資料夾加上原始資源名稱。  

```csharp
// Step 2: Hook into the resource‑saving pipeline
markdownSaveOptions.ResourceSavingCallback = new Aspose.Words.Saving.IResourceSavingCallback(
    (args) =>
    {
        // All images will be placed in "md-resources" relative to the output .md file
        const string folder = "md-resources/";
        Directory.CreateDirectory(folder);          // Create folder if it doesn’t exist

        // Preserve the original file name (e.g., image001.png) but prepend the folder path
        args.OutputFileName = Path.Combine(folder, args.ResourceFileName);

        // Optional: you could also change the format here (e.g., convert BMP to PNG)
        // args.ResourceFileName = Path.ChangeExtension(args.ResourceFileName, ".png");
    });
```

> **常見問題：** *如果我想嵌入圖片而不是儲存它們呢？*  
> 只要省略回呼或設定 `args.OutputFileName = null;` —— 儲存器會自動將圖片以 Base64 字串嵌入。

> **邊緣情況：** 某些舊文件包含重複的圖片名稱。上述回呼會覆寫先前的檔案。為避免此情況，可在檔名後加上 GUID：

```csharp
args.OutputFileName = Path.Combine(folder,
    $"{Path.GetFileNameWithoutExtension(args.ResourceFileName)}_{Guid.NewGuid()}{Path.GetExtension(args.ResourceFileName)}");
```

### 步驟 3：將文件儲存為 markdown 並驗證輸出

在完整設定選項後，最後的呼叫只需一行程式碼，即可將 Markdown 檔案與相關圖片寫入磁碟。

```csharp
// Step 3: Perform the actual export
string outputPath = @"C:\Exports\MyReport.md";
doc.Save(outputPath, markdownSaveOptions);
```

如果一切順利，你會看到：

- `MyReport.md` – 你的來源文件的 Markdown 表示。  
- `md-resources/` – 位於 `.md` 檔案旁的資料夾，包含所有抽取的圖片（例如 `image001.png`、`image002.jpg`）。

**範例 markdown 片段**（由 Aspose.Words 自動產生）：

```markdown
# Sample Report

Here is an introductory paragraph.

![Sample image](md-resources/image001.png)

More text follows...
```

[範例圖片](md-resources/image001.png)

> **專業提示：** 在 VS Code 或任何 Markdown 預覽器中開啟產生的 `.md` 檔案；圖片應立即顯示，因為相對路徑與資料夾結構相符。

## 完整、可執行的範例（無額外程式碼區塊）

以下是一個自包含的主控台程式，你可以貼到新的 .NET 專案中執行。它會建立一個簡單的 Word 文件，加入圖片，然後 **從文件建立 markdown**，同時將圖片存放於子資料夾。

```csharp
using System;
using System.IO;
using Aspose.Words;
using Aspose.Words.Saving;

class Program
{
    static void Main()
    {
        // 1️⃣ Create a sample Word document with an image
        var doc = new Document();
        var builder = new DocumentBuilder(doc);
        builder.Writeln("Hello, this is a test document.");
        builder.InsertImage("sample-image.png"); // Ensure this file exists next to exe

        // 2️⃣ Configure markdown export options (see Step 1 & 2 above)
        var markdownOptions = new MarkdownSaveOptions();
        markdownOptions.ResourceSavingCallback = new IResourceSavingCallback(
            (args) =>
            {
                const string folder = "md-resources/";
                Directory.CreateDirectory(folder);
                args.OutputFileName = Path.Combine(folder, args.ResourceFileName);
            });

        // 3️⃣ Save as markdown (Step 3)
        string outputFolder = Path.Combine(Environment.CurrentDirectory, "output");
        Directory.CreateDirectory(outputFolder);
        string markdownPath = Path.Combine(outputFolder, "ExportedDoc.md");
        doc.Save(markdownPath, markdownOptions);

        Console.WriteLine($"✅ Markdown saved to: {markdownPath}");
        Console.WriteLine("📂 Images saved in: md-resources/");
    }
}
```

**執行後你應該看到**：

```
✅ Markdown saved to: C:\MyProject\output\ExportedDoc.md
📂 Images saved in: md-resources/
```

開啟 `ExportedDoc.md` —— 圖片參照會指向 `md-resources/sample-image.png`，且圖片會在任何 Markdown 檢視器中正確顯示。

## 常見變體問答

| 情境 | 如何調整程式碼 |
|----------|----------------------|
| **跳過圖片匯出**（嵌入為 Base64） | 完全省略 `ResourceSavingCallback`，或在回呼內設定 `args.OutputFileName = null;`。 |
| **變更圖片格式**（例如全部轉為 PNG） | 在回呼內修改 `args.ResourceFileName`，並可在寫入前將串流轉換為所需格式。 |
| **自訂資料夾名稱** | 將 `"md-resources/"` 替換為任意相對或絕對路徑。 |
| **批次處理多個文件** | 對 `Document` 物件集合迴圈，重複使用相同的 `MarkdownSaveOptions` 實例（只需確保每次執行前資料夾已清空或使用唯一名稱）。 |

## 常見問題與解決方案

- **圖片未在 markdown 預覽中顯示** – 確認 markdown 中的相對路徑 (`md-resources/image001.png`) 與 `.md` 檔案相對的實際資料夾位置相符。  
- **重複的圖片名稱導致覆寫** – 在回呼內附加唯一識別碼（GUID 或遞增計數）以保證檔名唯一。  
- **大型文件導致記憶體壓力** – 在儲存前使用 `Document.OptimizeResources()`；此方法會釋放未使用的串流，降低記憶體使用。  
- **不支援的圖片格式** – Aspose.Words 支援 PNG、JPEG、BMP、GIF 與 TIFF。請在加入來源文件前將不支援的格式轉換為上述任一格式。

**Q: 轉換是否保留 Word 樣式，例如標題與表格？**  
A: 當然。Aspose.Words 會將 Word 標題樣式映射為 markdown 的 `#` 標題，並將表格轉換為 markdown 的管道語法，保留儲存格內容與對齊方式。

**Q: 函式庫如何處理受密碼保護的文件？**

**Q: 官方支援哪些 .NET 版本？**
