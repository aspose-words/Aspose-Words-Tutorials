# 如何建立帶有佔位符與清單的 Word 文件

如果您需要 **以程式方式建立 Word 文件**，本指南將一步步示範。內容涵蓋 **設定佔位文字**、**新增清單項目**，以及 **如何使用 SDT**（結構化文件標記）控制項，搭配 Aspose.Words for .NET。

開發人員常常想要在 .docx 檔案中直接嵌入內容控制項——例如純文字佔位符或下拉式清單——而不必開啟 Word。本教學提供完整、可執行的範例，說明每一步的意義，並討論常見變化，例如將控制項加入既有文件或自訂清單值。

## 前置條件

開始之前，請確保您已具備：

- 已安裝 .NET 6.0 SDK 或更新版本  
- Visual Studio 2022（或任何 C# IDE）  
- 有效的 Aspose.Words for .NET 授權（開發階段可使用免費試用版）  
- 基本的 C# 語法概念  

程式碼以 **Aspose.Words 23.9**（撰寫時的最新穩定版）為目標。如使用更新的版本，請自行調整 NuGet 套件版本。

## 插入純文字 Structured Document Tag（設定佔位文字）

純文字 SDT 的行為類似可讓使用者填寫的內容控制項。設定 `Title` 與 `PlaceholderName` 可在 Word 中提供友善提示。

```csharp
            // Step 2: Insert a plain‑text SDT and set its placeholder text
            StructuredDocumentTag plainTextTag = builder.InsertStructuredDocumentTag(
                StructuredDocumentTagType.PlainText, true);
            plainTextTag.Title = "CustomerName";
            plainTextTag.PlaceholderName = "Enter name";
```

**說明：**  
- `InsertStructuredDocumentTag` 會在 builder 目前的游標位置插入控制項。  
- `StructuredDocumentTagType.PlainText` 告訴 Word 以簡易文字框呈現。  
- `Title` 是 Word XML 使用的內部名稱，方便之後的資料繫結。  
- `PlaceholderName` 是使用者未輸入前顯示的灰色提示文字。

> **小技巧：** 若需讓佔位文字出現在文件的 *Properties* 面板，亦可設定 `plainTextTag.Tag = "CustomerName"`。

## 插入下拉式清單 SDT（如何使用 sdt）

下拉式清單讓您提供預先定義好的選項集合。這正是 **如何使用 sdt** 於列舉資料的核心。

```csharp
            // Step 3: Insert a drop‑down list SDT and define its title
            StructuredDocumentTag dropdownTag = builder.InsertStructuredDocumentTag(
                StructuredDocumentTagType.DropDownList, true);
            dropdownTag.Title = "Country";
```

**為什麼使用下拉式清單？**  
下拉式清單可提升資料一致性並減少打字錯誤。`Title` 屬性同樣作為後續處理（例如擷取表單資料）時的識別碼。

## 為下拉式清單新增清單項目（add list items）

現在為控制項填入可供選擇的值。每個 `ListItem` 需要顯示文字，並可選擇性提供儲存於文件 XML 中的值。

```csharp
            // Step 4: Populate the drop‑down with selectable items
            dropdownTag.ListItems.Add(new ListItem("USA", "US"));
            dropdownTag.ListItems.Add(new ListItem("Canada", "CA"));
            dropdownTag.ListItems.Add(new ListItem("Mexico", "MX"));
```

**重點說明：**  

- 第一個參數（`"USA"`）是使用者看到的文字。  
- 第二個參數（`"US"`）是您可程式化讀取的底層值。  
- 可依需求加入任意數量的項目；清單會以 .docx XML 中的 `<w:listItem>` 元素儲存。

### 邊緣案例與變化

| 情境 | 推薦調整 |
|-----------|------------------------|
| **將控制項加入既有檔案** | 使用 `new Document("Existing.docx")` 載入檔案，而非建立新 `Document`。 |
| **將佔位文字設為必填** | 依驗證邏輯設定 `plainTextTag.IsShowingPlaceholderWhenEmpty = false` 或 `true`。 |
| **將清單項目繫結至資料來源** | 以集合迴圈（`foreach (var country in countries)`）呼叫 `dropdownTag.ListItems.Add(new ListItem(country.Name, country.Code))`。 |
| **自訂控制項樣式** | 在插入 SDT 前使用 `builder.Font` 屬性，影響佔位文字的預設樣式。 |
| **日後移除控制項** | 透過 `doc.GetChildNodes(NodeType.StructuredDocumentTag, true)` 找到目標，然後呼叫 `tag.Remove();`。 |

## 程式化建立控制項的最佳實踐

1. **先建立文件** – 盡早初始化 `DocumentBuilder` 可避免游標位置的意外。  
2. **設定 Title 與 Tag** – 這些是後續資料抽取的穩定識別碼。  
3. **加入佔位文字** – 可提升使用者體驗，特別是純文字標記。  
4. **立即填入清單項目** – Word 只有在清單附加後才會正確呈現下拉式選單。  
5. **一次性儲存** – 在迴圈內多次呼叫 `Save` 會大幅增加 I/O 負擔。

遵循上述步驟，您即可確保 Word 檔案同時具備 *機器可讀*（供後端處理）與 *使用者友善*（供前端編輯）的特性。
