# 如何使用 Aspose.Words 在 Python 中建立直條圖

如果您需要在 Python 中建立直條圖，本指南將提供完整的程式碼與說明。透過 Aspose.Words 圖表 API，您可以精確設定尺寸、套用內建樣式，並在不離開 Python 的情況下匯出結果。

產生直條圖是報表、儀表板與自動化文件產生的常見需求。本教學涵蓋從匯入函式庫到驗證已儲存影像的每一步，讓您能將圖表產生整合到任何 Python 專案中。

## 前置條件

開始之前，請確保您已具備：

* 已安裝 Python 3.8 或更新版本。
* 有效的 Aspose.Words for Python 授權（或免費評估金鑰）。
* 基本的 Python 模組與物件導向程式碼概念。

Aspose.Words 圖表引擎支援 Windows、macOS 與 Linux，且不需要額外的圖形函式庫，因為渲染在伺服器端完成。

## 步驟 1：匯入 Aspose.Words 函式庫

第一步是匯入 `aspose.words` 套件並給予簡短別名。將匯入放在檔案最上方可保持命名空間整潔，讓程式碼更易閱讀。

```python
# Step 1: Import the Aspose.Words library
import aspose.words as aw
```

`aw` 現在指向完整的 Aspose.Words API，包括您將用來建立直條圖的 `Chart` 類別。

## 步驟 2：以所需尺寸建立直條圖

直條圖必須明確指定寬度與高度，以確保渲染出的影像符合文件版面配置。`Chart` 建構子接受三個參數：圖表類型、寬度（點數）與高度（點數）。使用 `aw.ChartType.COLUMN` 會告訴引擎產生垂直長條圖。

```python
# Step 2: Create a column chart with the desired dimensions
chart = aw.Chart(aw.ChartType.COLUMN, 400, 300)   # width=400pt, height=300pt
```

*為什麼要設定尺寸？*  
當您將圖表嵌入 Word 文件或匯出為影像時，周圍內容會遵循您提供的精確大小，避免不必要的縮放或裁切。

### 小技巧：使用 `chart.dimensions` 進行動態調整

若資料集大小不固定，您可以根據系列數量計算尺寸：

```python
series_count = 5
base_width = 80
chart.width = base_width * series_count
chart.height = 300
```

## 步驟 3：為直條圖套用內建樣式

Aspose.Words 內建多種預設視覺主題。選擇樣式即可免除手動設定顏色、字型與格線的工作。`aw.ChartStyle.STYLE_5` 提供乾淨、專業的外觀，適合大多數商業報告。

```python
# Step 3: Apply a built‑in style to the chart
chart.style = aw.ChartStyle.STYLE_5
```

若您想要不同的外觀，只需將 `STYLE_5` 替換為其他常數（`STYLE_1` … `STYLE_8`）。每個樣式的命名規則相同，便於嘗試。

### 邊緣情況：無效的樣式常數

嘗試指派不存在的樣式會拋出 `AttributeError`。可透過檢查列舉值來避免此問題：

```python
if hasattr(aw.ChartStyle, "STYLE_5"):
    chart.style = aw.ChartStyle.STYLE_5
else:
    raise ValueError("Requested chart style does not exist.")
```

## 步驟 4：為直條圖加入資料系列

沒有資料的圖表毫無意義。您可以加入一個或多個 `ChartSeries` 物件，每個物件代表一組直條。以下範例加入單一系列，包含三個資料點。

```python
# Step 4: Add data series to the column chart
series = chart.series.add()
series.name = "Quarterly Sales"
series.data = [12000, 15000, 18000]   # Values for Q1, Q2, Q3
```

您可以重複呼叫 `chart.series.add()` 以加入其他系列（例如「預估銷售」）。API 會自動將直條並排排列。

## 步驟 5：渲染圖表並儲存為影像

完成圖表設定後，將其渲染為點陣圖或影像檔。`save` 方法接受檔案路徑與可選的格式。PNG 為無損且廣受支援的格式。

```python
# Step 5: Render and save the chart as a PNG image
output_path = "column_chart.png"
chart.save(output_path, aw.SaveFormat.PNG)
print(f"Chart saved to {output_path}")
```

`SaveFormat` 列舉包含 PNG、JPEG、BMP 等格式。依您的後續工作流程選擇合適的格式即可。

## 驗證輸出

使用任何影像檢視器開啟 `column_chart.png`。您應該會看到一個三欄直條圖，已套用選定的內建主題，尺寸正好為 400 × 300 點。

![Aspose.Words 在 Python 中產生的直條圖](column_chart.png){: .center alt="Aspose.Words 在 Python 中產生的直條圖截圖"}

若影像顯示為空白或變形，請檢查以下項目：

1. `aw.Chart` 物件已在加入系列之前實例化。
2. `chart.style` 常數對應到現有的列舉值。
3. `save` 呼叫使用了支援的 `SaveFormat`。

## 常見變化與額外提示

| 情境 | 建議變更 |
|-----------|--------------------|
| **多個資料系列** | 新增額外的 `chart.series.add()` 區塊，並為每個系列設定 `series.name` 與 `series.data`。 |
| **自訂顏色** | 在套用內建樣式後，透過 `series.points[i].fill.fore_color` 覆寫個別直條顏色。 |
| **嵌入 Word 文件** | 改用 `doc = aw.Document(); doc.sections[0].body.append_child(chart); doc.save("report.docx")` 取代 `chart.save()`。 |
| **動態尺寸** | 依系列數量計算寬度（`width = 80 * len(chart.series)`）。 |

以上變化說明了相同核心程式碼如何因應不同報表情境而調整。
