# 如何使用 Aspose.Words 匯出 Markdown 並復原受損的 DOCX

如果您需要 **how to export markdown** 從可能受損的 Word 檔案中匯出，本指南將向您展示完整步驟。它亦涵蓋 **how to recover document** 的問題、**export docx to txt**，以及使用 Aspose.Words for Python API 的 **save word as pdf**。

您將會學會在復原模式下載入可能受損的 DOCX，將其轉換為保留方程式的 Markdown，將相同內容另存為純文字，產生可存取的 PDF，甚至在最終匯出前微調形狀的陰影。無需任何外部工具——只要 Aspose.Words 與少量 Python 程式碼即可。

## 前置條件

在開始之前，請確保您已具備：

* Python 3.8 或更新版本
* `aspose-words` 套件 (`pip install aspose-words`)
* 可能受損的 DOCX 檔案（或任何一般的 DOCX 用於測試）
* 對 Python 函式與類別有基本了解

> **Pro tip:** 保留原始 DOCX 的備份；復原模式會修改記憶體中的表示，但不會寫回來源檔案。

## Step 1: How to recover corrupted DOCX

第一個挑戰是安全地載入檔案。Aspose.Words 提供 `RecoveryMode.RECOVER_CORRUPTED` 旗標，可嘗試重建損壞的文件結構。

```python
import aspose.words as aw

# Load the file in recovery mode
load_opts = aw.LoadOptions()
load_opts.recovery_mode = aw.RecoveryMode.RECOVER_CORRUPTED
doc = aw.Document("YOUR_DIRECTORY/input.docx", load_opts)
```

**為何這很重要：**  
當 DOCX 部分受損——缺少部件、XML 損壞或關係錯誤——標準載入會拋出例外。復原模式會盡可能解析可讀取的部分，丟棄無法讀取的片段，同時保留其餘內容，這對於後續的 **export docx to txt** 或 **save word as pdf** 操作至關重要。

### 常見邊緣情況
如果文件已無法修復，`doc` 仍會被建立，但會產生警告日誌。您可以檢查 `doc.is_dirty` 以了解復原過程中是否有內容被更改。

## Step 2: How to export markdown with Aspose.Words

Markdown 是許多靜態網站產生器與文件工具喜愛的輕量標記語言。Aspose.Words 能在保留方程式為 LaTeX 的同時輸出 Markdown，這對技術文件而言相當理想。

```python
# Configure Markdown export options
md_opts = aw.MarkdownSaveOptions()
md_opts.office_math_export_mode = aw.OfficeMathExportMode.LATEX

# Save as Markdown
doc.save("YOUR_DIRECTORY/output.md", md_opts)
```

**您將得到：**  
* 純文字，標題、清單與表格皆轉換為 Markdown 語法。  
* 每個 Word 方程式皆以 LaTeX 區塊 (`$$ … $$`) 呈現，確保數學式在後續工具中仍可編輯。

### 驗證輸出
在任何編輯器中開啟 `output.md`。您應該會看到類似以下內容：

```markdown
# Title of the Document

This is a paragraph with **bold** text.

$$
\int_{0}^{\infty} e^{-x} dx = 1
$$
```

如果需要其他方程式格式（例如 MathML），請相應調整 `office_math_export_mode`。

## Step 3: Export docx to txt while preserving equations

純文字檔案對於快速搜尋或輸入自然語言管線非常有用。相同的 `OfficeMathExportMode.LATEX` 亦適用於 `.txt` 匯出，讓您得到可讀的 LaTeX 內嵌式方程式。

```python
txt_opts = aw.TxtSaveOptions()
txt_opts.office_math_export_mode = aw.OfficeMathExportMode.LATEX

doc.save("YOUR_DIRECTORY/output.txt", txt_opts)
```

**為何使用此方式而非手動複製貼上？**  
手動複製貼上常會剝除隱藏字元並失去方程式的完整性。此 **export docx to txt** 方法保證每個方程式皆以 LaTeX 片段呈現，方便後續處理。

## Step 4: Save word as PDF with inline shapes for better accessibility

PDF 是事實上的出版格式。當 Word 文件包含浮動圖片或圖表時，某些閱讀器可能無法正確解讀。設定 `export_floating_shapes_as_inline_tag` 可將這些形狀轉為行內，提升可存取性與版面一致性。

```python
pdf_opts = aw.PdfSaveOptions()
pdf_opts.export_floating_shapes_as_inline_tag = True

doc.save("YOUR_DIRECTORY/output.pdf", pdf_opts)
```

**結果：**  
產生的 PDF 版面與原始文件相同，但所有形狀現在皆屬於文字流的一部份。這對螢幕閱讀器特別有幫助，因為它們會將行內元素視為閱讀順序的一部份。

### 大型文件的提示
若批次產生 PDF，請重複使用同一個 `PdfSaveOptions` 實例，以避免不必要的物件建立。

## Step 5: Fine‑tune a shape’s shadow before the final PDF

有時在發佈前需要調整視覺細節——例如調整標誌的陰影。以下範例取得第一個形狀，修改其陰影屬性，並儲存為新 PDF。

```python
# Retrieve the first shape in the document
shape = doc.get_child(aw.NodeType.SHAPE, 0, True).as_shape()

# Adjust shadow settings
shape.shadow.blur_radius = 5.0   # Soft blur
shape.shadow.distance = 2.0     # Distance from shape edge
shape.shadow.opacity = 0.6      # 60% opacity

# Save the shadow‑enhanced PDF
doc.save("YOUR_DIRECTORY/shadowed.pdf", pdf_opts)
```

**此程式碼的作用：**  
* `blur_radius` 控制陰影的模糊程度。  
* `distance` 將陰影從形狀移開，產生深度感。  
* `opacity` 使陰影半透明，通常看起來更專業。

您可以透過變更 `get_child` 中的索引，對任何形狀重複此區塊。

## Full script for quick copy‑paste

以下是結合所有步驟的完整可執行腳本。將 `YOUR_DIRECTORY` 替換為您檔案所在的路徑。

```python
import aspose.words as aw

# -------------------------------------------------
# 1️⃣ Recover a possibly corrupted DOCX
# -------------------------------------------------
load_opts = aw.LoadOptions()
load_opts.recovery_mode = aw.RecoveryMode.RECOVER_CORRUPTED
doc = aw.Document("YOUR_DIRECTORY/input.docx", load_opts)

# -------------------------------------------------
# 2️⃣ Export to Markdown (how to export markdown)
# -------------------------------------------------
md_opts = aw.MarkdownSaveOptions()
md_opts.office_math_export_mode = aw.OfficeMathExportMode.LATEX
doc.save("YOUR_DIRECTORY/output.md", md_opts)

# -------------------------------------------------
# 3️⃣ Export to plain text (export docx to txt)
# -------------------------------------------------
txt_opts = aw.TxtSaveOptions()
txt_opts.office_math_export_mode = aw.OfficeMathExportMode.LATEX
doc.save("YOUR_DIRECTORY/output.txt", txt_opts)

# -------------------------------------------------
# 4️⃣ Save as PDF (save word as pdf)
# -------------------------------------------------
pdf_opts = aw.PdfSaveOptions()
pdf_opts.export_floating_shapes_as_inline_tag = True
doc.save("YOUR_DIRECTORY/output.pdf", pdf_opts)

# -------------------------------------------------
# 5️⃣ Adjust first shape's shadow and re‑save PDF
# -------------------------------------------------
shape = doc.get_child(aw.NodeType.SHAPE, 0, True).as_shape()
shape.shadow.blur_radius = 5.0
shape.shadow.distance = 2.0
shape.shadow.opacity = 0.6
doc.save("YOUR_DIRECTORY/shadowed.pdf", pdf_opts)
```

執行腳本後會產生：

| File | Purpose |
|------|---------|
| `output.md` | 含 LaTeX 方程式的 Markdown (**how to export markdown**) |
| `output.txt` | 純文字版本 (**export docx to txt**) |
| `output.pdf` | 可存取的 PDF (**save word as pdf**) |
| `shadowed.pdf` | 具自訂樣式形狀的 PDF |

## Frequently asked questions

**問：復原模式能修復遺失的圖片嗎？**  
**答：** 它會還原文件結構，但無法重新建立遺失的二進位圖片資料。如果圖片部件缺失，形狀將會是空的。

**問：我可以匯出成 HTML 而不是 Markdown 嗎？**  
**答：** 可以——使用 `aw.HtmlSaveOptions()`，並依需求設定 `office_math_export_mode`。

**問：如果我需要保持浮動形狀為浮動該怎麼辦？**  
**答：** 省略 `export_floating_shapes_as_inline_tag` 或將其設為 `False`。

**問：LaTeX 匯出與 MathJax 相容嗎？**  
**答：** 完全相容。MathJax 能正確渲染 Markdown 與 Txt 匯出產生的 `$$ … $$` 區塊。
