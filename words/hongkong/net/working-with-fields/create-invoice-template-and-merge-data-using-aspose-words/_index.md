# 建立發票範本並使用 Aspose.Words 合併資料

如果您需要快速**建立發票範本**，本指南會精確說明操作步驟。閱讀完前兩句後，您將了解將空白 Word 檔案轉換為完整填寫發票的完整工作流程，使用 Aspose.Words 的低程式碼 mail‑merge API。

產生發票是計費系統、ERP 整合與自動化報告的常見需求。在本教學中，您將學習**如何進行 mail merge**、**填充 word 範本**、**將資料合併至 word**，最後**儲存合併後的文件**——全部只需少量 C# 程式碼。

## 您將達成的目標

* 一個可重複使用的 Word 範本 (`InvoiceTemplate.docx`)，其中包含客戶、日期、明細項目與總計的合併欄位。  
* 一個 C# 程式，載入範本、注入強型別資料物件，並將結果寫入 `Invoice_001.docx`。  
* 了解如空集合、自訂資料類型、檔案路徑處理等邊緣情況。  

### 前置條件

| 需求 | 重要性 |
|-------------|----------------|
| .NET 6 or later | Aspose.Words for .NET 支援 .NET 6+，並提供本指南中使用的低程式碼 API。 |
| Aspose.Words for .NET NuGet package (`Aspose.Words`) | 提供 `Document`、`MailMerger` 以及相關類型。 |
| Basic C# knowledge | 需要了解匿名物件與 LINQ。 |
| Visual Studio 2022 (or any IDE) | 讓編輯與除錯變得簡單直觀。 |

> **專業提示：** 透過套件管理員主控台安裝 NuGet 套件：  
> `Install-Package Aspose.Words`

## 如何使用低程式碼 mail merge 建立發票範本

第一步是建立一個 Word 檔案，內含與稍後傳入之資料物件屬性相對應的合併欄位。將檔案儲存為 `InvoiceTemplate.docx`，放置於您自行管理的資料夾中（例如 `C:\Invoices\Template`）。

| 合併欄位 | Word 中的範例佔位符 |
|-------------|-----------------------------|
| CustomerName | «CustomerName» |
| InvoiceDate | «InvoiceDate» |
| Items (repeating) | «Items.Description», «Items.Qty», «Items.Price» |
| Total | «Total» |

> **為何重要：** 低程式碼 API 會自動將資料來源的屬性名稱對應到合併欄位。保持名稱一致即可免除手動欄位與屬性對應，並降低執行時錯誤。

## 步驟 1：載入發票範本

```csharp
using Aspose.Words;
using Aspose.Words.LowCode;   // Low‑code mail‑merge API

// Load the Word file that contains the merge fields.
Document template = new Document(@"C:\Invoices\Template\InvoiceTemplate.docx");
```

*`Document` 類別代表整個 Word 檔案。只需載入一次，即可在多張發票中重複使用相同的範本。*

## 步驟 2：準備資料來源

建立一個與合併欄位相對應的匿名物件。低程式碼 API 可接受任何 .NET 物件，包括陣列與巢狀集合。

```csharp
var invoiceData = new
{
    CustomerName = "Acme Corp",
    InvoiceDate = DateTime.Today,
    Items = new[]
    {
        new { Description = "Widget A", Qty = 10, Price = 9.99M },
        new { Description = "Widget B", Qty = 5,  Price = 19.95M }
    },
    Total = 199.85M
};
```

**為何可行：**  
* 屬性名稱（`CustomerName`、`InvoiceDate`、`Items`、`Total`）與範本中的合併欄位相同。  
* `Items` 為物件陣列，mail merger 會自動為每個元素重複表格列。  
* 使用 `decimal`（`M` 後綴）表示金額可避免浮點數四捨五入問題。

### 處理空集合

若發票沒有明細項目，傳入空陣列：

```csharp
Items = new object[0]
```

低程式碼引擎會直接省略重複區段，保留表格標頭。

## 步驟 3：初始化低程式碼 mail merger

```csharp
MailMerger merger = new MailMerger(template);
```

`MailMerger` 是使用 Aspose.Words 進行**mail merge**的入口點。它會讀取範本、綁定資料，並在一次呼叫中準備最終文件。

## 步驟 4：執行合併 – 一行程式碼填充 word 範本

```csharp
Document mergedDocument = merger.Execute(invoiceData);
```

* 這行程式碼**填充 word 範本**，並產生新的 `Document` 實例（`mergedDocument`）。  
* 所有合併欄位皆被取代，重複區段會展開，最終文件完整保存在記憶體中。

### 邊緣情況：自訂格式

若需要特定日期格式，可在合併前加入自訂格式化程式：

```csharp
merger.Options.DateFormat = "MMMM dd, yyyy"; // e.g., "October 07, 2026"
```

## 步驟 5：儲存合併後的文件

```csharp
mergedDocument.Save(@"C:\Invoices\Output\Invoice_001.docx");
```

此呼叫**儲存合併後的文件**，將完整填寫的發票寫入磁碟。該檔案可於 Microsoft Word 開啟、作為電子郵件附件傳送，或轉換為 PDF。

### 驗證輸出

開啟 `Invoice_001.docx`，您應該會看到：

* **CustomerName** 被替換為 *Acme Corp*  
* **InvoiceDate** 顯示今日日期（使用所選格式）  
* 表格列顯示 *Widget A*（10 × 9.99）與 *Widget B*（5 × 19.95）  
* **Total** 顯示 *199.85*  

若有任何欄位仍未變更（例如仍顯示 «CustomerName»），請再次確認屬性名稱與範本中的合併欄位名稱完全相同。

## 完整可執行範例

以下是完整程式碼，您可直接複製貼上至新的 Console 專案中。

```csharp
using System;
using Aspose.Words;
using Aspose.Words.LowCode;   // Low‑code mail‑merge API

namespace InvoiceGenerator
{
    class Program
    {
        static void Main()
        {
            // 1️⃣ Load the template
            Document template = new Document(@"C:\Invoices\Template\InvoiceTemplate.docx");

            // 2️⃣ Build the data source
            var invoiceData = new
            {
                CustomerName = "Acme Corp",
                InvoiceDate = DateTime.Today,
                Items = new[]
                {
                    new { Description = "Widget A", Qty = 10, Price = 9.99M },
                    new { Description = "Widget B", Qty = 5,  Price = 19.95M }
                },
                Total = 199.85M
            };

            // 3️⃣ Initialise the mail merger
            MailMerger merger = new MailMerger(template);

            // Optional: customise date format
            merger.Options.DateFormat = "MMMM dd, yyyy";

            // 4️⃣ Perform the merge (populate word template)
            Document mergedDocument = merger.Execute(invoiceData);

            // 5️⃣ Save the resulting file (save merged document)
            mergedDocument.Save(@"C:\Invoices\Output\Invoice_001.docx");

            Console.WriteLine("Invoice generated successfully.");
        }
    }
}
```

執行程式 (`dotnet run`) 後，主控台會顯示 *Invoice generated successfully.*，且檔案會出現在 `C:\Invoices\Output`。
