# 如何在圖表中顯示百分比（使用 Aspose.Words C#）

有沒有想過 **如何在圖表中顯示百分比**，卻不想與複雜的 Office interop 纏鬥？你並不孤單——許多開發人員在需要快速、程式化地為圓形或環形圖添加標籤時，都會碰到這個問題。好消息是？使用 Aspose.Words for .NET，你只需幾行程式碼即可啟用這些資料標籤。

在本教學中，我們還會說明 **add data labels to pie chart** 與 **how to enable chart data labels**，讓你的視覺化即刻變得更具洞察力。完成後，你將擁有一個可直接使用的 Word 文件（`.docx`），其中展示了一個精緻的圓形圖，百分比整齊地顯示在每個切片的外側。

## 前置條件

- **Aspose.Words for .NET**（最新版本，例如 24.9）已透過 NuGet 安裝。
- 一個已包含圓形或環形圖的 **ChartTemplate.docx** 檔案。  
  *(如果沒有，可建立一個簡單的 Word 文件，插入圓形圖，並另存為 `ChartTemplate.docx`。)*
- .NET 6.0 或更新版本，以及你偏好的任何 IDE（Visual Studio、Rider、VS Code）。

不需要額外的相依性——Aspose.Words 內部已處理所有事宜。

## 如何在圖表中顯示百分比 – 步驟說明

以下我們將流程分為六個清晰的步驟。每個步驟都包含可直接複製貼上的 C# 程式碼，並簡短說明 **為何** 這樣做。

### 步驟 1：載入來源文件

```csharp
using Aspose.Words;
using Aspose.Words.Drawing.Charts;

// Load the .docx that already holds a chart.
Document sourceDoc = new Document("YOUR_DIRECTORY/ChartTemplate.docx");
```

*Why?*  
`Document` 是任何 Word 操作的入口點。載入範本後，我們即可存取所有節點——圖形、表格、文字，當然還有我們即將修改的圖表。

### 步驟 2：取得第一個圖表 Shape

```csharp
// The chart lives inside a Shape node; retrieve it.
Chart chart = (Chart)sourceDoc.GetChild(NodeType.Shape, 0, true);
```

*Why?*  
Aspose 以 `Shape` 物件儲存圖表。`GetChild` 會遍歷文件樹，回傳找到的第一個 Shape，在本例中即是我們要編輯的圓形圖。

### 步驟 3：確認圖表類型

```csharp
if (chart.ChartType == ChartType.Pie || chart.ChartType == ChartType.Doughnut)
{
    // Inside this block we’ll enable the data labels.
}
else
{
    throw new InvalidOperationException("The chart is not a Pie or Doughnut type.");
}
```

*Why?*  
百分比標籤僅對圓形圖有意義。此檢查可防止我們不小心將設定套用到例如長條圖之類的圖表，因為 `ShowPercentage` 會被忽略。

### 步驟 4：啟用資料標籤並顯示百分比

```csharp
// Turn on data labels for the chart.
chart.HasDataLabel = true;

// Show the percentage value for each slice.
chart.DataLabel.ShowPercentage = true;
```

*Why?*  
`HasDataLabel` 告訴 Aspose 為每個資料點繪製標籤。設定 `ShowPercentage` 可確保標籤內容為整體的計算比例——正是 **add data labels to pie chart** 所要求的。

### 步驟 5：將標籤置於切片外側

```csharp
// Place the labels outside the pie slices for better readability.
chart.DataLabel.Position = ChartDataLabelPosition.OutSideEnd;
```

*Why?*  
切片內部的標籤可能會擠在一起，特別是切片很小時。`OutSideEnd` 模仿 Word 介面中預設的「外側」樣式，使圖表保持整潔。

### 步驟 6：儲存更新後的文件

```csharp
sourceDoc.Save("YOUR_DIRECTORY/FormattedPieChart.docx");
```

*Why?*  
儲存會將所有變更寫回新檔案。於 Word 中開啟 `FormattedPieChart.docx`，即可看到每個切片旁顯示的百分比。

#### 預期結果

當你開啟 `FormattedPieChart.docx` 時，圓形圖應該會類似以下（示意圖）：

```
[ Pie chart with three slices ]
- Slice A – 45%
- Slice B – 30%
- Slice C – 25%
```

所有百分比皆自底層資料系列自動計算，且標籤恰好位於每個切片的外側。

## 常見變化與邊緣情況

| 情況 | 調整方式 |
|-----------|----------------|
| **同一文件中有多個圖表** | 迭代 `sourceDoc.GetChildNodes(NodeType.Shape, true)`，將每個轉型為 `Chart` 後套用相同的邏輯。 |
| **長條圖或折線圖** 仍想顯示標籤 | 使用 `chart.DataLabel.ShowValue = true;`（或 `ShowSeriesName`）取代 `ShowPercentage`。 |
| **自訂數字格式**（例如 “45 %”） | 在儲存前設定 `chart.DataLabel.NumberFormat = "0%";`。 |
| **大型資料集** 造成標籤重疊 | 考慮設定 `chart.DataLabel.ShowLeaderLines = true;` 以繪製連接線。 |

> **專業提示：** 若你在批次產生大量文件，請在應用程式啟動時實例化單一的 `Aspose.Words.License` 物件，以避免重複載入授權所帶來的效能損耗。

## 完整範例程式

以下是完整的程式碼，已整合好，可直接執行：

```csharp
using System;
using Aspose.Words;
using Aspose.Words.Drawing.Charts;

class Program
{
    static void Main()
    {
        // 1️⃣ Load the template document.
        Document sourceDoc = new Document("YOUR_DIRECTORY/ChartTemplate.docx");

        // 2️⃣ Retrieve the first chart shape.
        Chart chart = (Chart)sourceDoc.GetChild(NodeType.Shape, 0, true);

        // 3️⃣ Ensure we’re dealing with a Pie or Doughnut chart.
        if (chart.ChartType != ChartType.Pie && chart.ChartType != ChartType.Doughnut)
        {
            Console.WriteLine("The selected shape is not a Pie/Doughnut chart.");
            return;
        }

        // 4️⃣ Enable data labels and show percentages.
        chart.HasDataLabel = true;
        chart.DataLabel.ShowPercentage = true;

        // 5️⃣ Position the labels outside the slices.
        chart.DataLabel.Position = ChartDataLabelPosition.OutSideEnd;

        // 6️⃣ Save the modified document.
        sourceDoc.Save("YOUR_DIRECTORY/FormattedPieChart.docx");

        Console.WriteLine("Chart updated successfully – percentages now visible!");
    }
}
```

複製程式碼，將 `YOUR_DIRECTORY` 替換為你機器上的實際路徑，然後執行。你將在幾秒鐘內得到一個帶有完整標籤的圓形圖 Word 檔案。
