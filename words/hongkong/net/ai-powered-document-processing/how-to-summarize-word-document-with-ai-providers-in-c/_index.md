# 如何在 C# 中使用 AI 供應商摘要 Word 文件

如果您需要快速 **摘要 Word 文件**，本指南會一步步示範。您將看到完整、可執行的範例，讓您 **選擇 AI 供應商**（OpenAI 或 Google）並在不離開 IDE 的情況下處理 **摘要大型文件** 的情境。

在建立知識庫機器人、報告摘要或自動化電郵簡報時，摘要 Word 文件是一項常見任務。以下章節將教您安裝哪個 NuGet 套件、如何載入 `.docx` 檔案、設定摘要器，並輸出結果——全部使用純 C#。

## 您需要的條件

| Requirement | Reason |
|-------------|--------|
| .NET 6 SDK 或更新版本 | 為 C# 範例提供執行環境 |
| Visual Studio 2022（或任何 IDE） | 方便加入 NuGet 套件並執行主控台應用程式 |
| `GroupDocs.Summarization` NuGet 套件 | 提供程式碼中使用的 `DocumentSummarizer` API |
| 網際網路連線 | AI 供應商（OpenAI 或 Google）處理文字時必須使用 |

> **專業提示：** 若您打算 **摘要大型文件**（超過 100 KB），請在選項中啟用串流模式，以避免一次載入整個檔案至記憶體。

## 如何一步步摘要 Word 文件

### 步驟 1：安裝摘要函式庫

在套件管理員主控台執行：

```powershell
Install-Package GroupDocs.Summarization
```

`GroupDocs.Summarization` 函式庫將底層 AI 呼叫抽象化，讓您在不更改業務邏輯的情況下切換供應商。

### 步驟 2：載入 Word 文件

```csharp
using GroupDocs.Summarization;
using GroupDocs.Summarization.Options;

// Step 2: Load the source document
Document doc = new Document("YOUR_DIRECTORY/Report.docx");
```

`Document` 類別會讀取 `.docx` 檔案並為摘要做準備。若檔案較大，函式庫會自動使用記憶體效能較佳的解析器。

### 步驟 3：設定摘要選項並 **選擇 AI 供應商**

```csharp
// Step 3: Set up summarization options (choose the AI provider)
SummarizerOptions options = new SummarizerOptions
{
    Provider = SummarizerProvider.OpenAI   // or SummarizerProvider.Google
};
```

- `Provider = SummarizerProvider.OpenAI` 會選擇 OpenAI 的 GPT‑4 模型。  
- `Provider = SummarizerProvider.Google` 會選擇 Google 的 Gemini 模型，適合在 **使用 Google 進行摘要** 時獲得更好的多語言支援。

您可以根據成本、延遲或語言需求 **選擇 AI 供應商**。同一個 `options` 物件同時適用於兩種供應商，保持程式碼整潔。

### 步驟 4：產生摘要 – 支援 **摘要大型文件**

```csharp
// Step 4: Generate the summary using the selected provider
string summary = DocumentSummarizer.Summarize(doc, options);
```

當您 **摘要大型文件** 時，函式庫會將內容串流至 AI 服務，避免記憶體不足的錯誤。`Summarize` 方法會回傳純文字字串，包含最相關的句子。

### 步驟 5：輸出結果

```csharp
// Step 5: Output the generated summary
Console.WriteLine("Summary:\n" + summary);
```

執行程式後會印出一段簡潔的段落，概括原始 Word 檔的要旨。

## 完整可執行範例

```csharp
using System;
using GroupDocs.Summarization;
using GroupDocs.Summarization.Options;

namespace WordSummarizerDemo
{
    class Program
    {
        static void Main(string[] args)
        {
            // Load the source Word document
            Document doc = new Document("YOUR_DIRECTORY/Report.docx");

            // Choose the AI provider (OpenAI or Google)
            SummarizerOptions options = new SummarizerOptions
            {
                Provider = SummarizerProvider.Google   // Change to OpenAI if you prefer
            };

            // Generate the summary – works for both small and large documents
            string summary = DocumentSummarizer.Summarize(doc, options);

            // Display the summary in the console
            Console.WriteLine("Summary:\n" + summary);
        }
    }
}
```

**預期輸出**

```
Summary:
The quarterly sales increased by 12% driven by the new product line, while operational costs fell 3% due to efficiency gains. The report also highlights upcoming market expansion in APAC and recommends allocating additional budget to R&D.
```

具體文字會因您 **選擇 AI 供應商** 的模型不同而有所差異，但結構保持一致。

## 處理 **摘要大型文件** 情境

當來源 `.docx` 超過 5 MB 時，建議採取以下調整：

1. **啟用分塊** – 函式庫會在送至 AI 服務前，將文件切成 5 KB 的區塊。  
2. 若需要較長的摘要，**增加 `MaxSentences`**（於 `SummarizerOptions` 中）。  
3. 為因應較長的處理時間，**設定較高的 `Timeout`**。

```csharp
options.MaxSentences = 8;          // Return up to 8 sentences
options.EnableChunking = true;    // Essential for very large files
options.Timeout = TimeSpan.FromMinutes(2);
```

這些微調可確保 **摘要大型文件** 的操作仍然快速且可靠。

## 如何有效 **使用 Google 進行摘要**

Google 的 Gemini 模型在多語言內容與簡潔措辭上表現優異。取得最佳結果的方法：

- 若文件包含非英文文字，可 **指定語言**（選用）：
  ```csharp
  options.Language = "es"; // Spanish
  ```
- **調整 temperature** 以控制創意度：
  ```csharp
  options.Temperature = 0.3; // More deterministic output
  ```

使用 **Google 進行摘要** 時，服務可能會回傳較短但高度聚焦的摘要，與 OpenAI 相比略有不同。建議在樣本文件上測試兩種供應商，決定最適合您的產品。

## 常見陷阱與避免方式

| Symptom | Cause | Fix |
|---------|-------|-----|
| 空的摘要 | 缺少供應商金鑰或網路被阻擋 | 確認環境變數中的 API 金鑰，並確保允許向外的 HTTPS 連線 |
| 文字被截斷 | 文件超過供應商的 token 限制 | 啟用 `EnableChunking` 或在函式庫支援時增加 `MaxTokens` |
| 語言不符 | `Language` 選項設定錯誤 | 移除該選項或改為文件實際的語言 |

提前解決這些問題，可節省大量除錯時間，特別是當您 **選擇 AI 供應商** 用於正式環境時。

## 結論

現在您已掌握如何在 C# 中使用彈性的 AI 層 **摘要 Word 文件**。只要設定 `SummarizerOptions`，即可 **選擇 AI 供應商**、處理 **摘要大型文件** 工作負載，甚至 **使用 Google 進行摘要** 以因應多語言需求。可自行調整 `MaxSentences`、`Temperature` 與分塊設定，微調輸出以符合特定情境。
