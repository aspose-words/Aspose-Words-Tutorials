# 建立空白 Word 文件並在 C# 中隱藏橢圓形狀

如果你需要 **建立空白 Word 文件**，然後隱藏圖形元素，本教學會一步一步示範如何使用 C# 完成。你將看到完整、可執行的範例，內容包括插入橢圓、設定位置、標記為隱藏，最後儲存檔案——全部只需幾行程式碼。

本教學涵蓋從專案設定到最終驗證的每個步驟。完成後，你即可產生一個橢圓永遠不會在螢幕或列印時顯示的 Word 檔，適合用來儲存中繼資料、書籤或任何不可見的標記。

## 前置條件

在開始之前，請確保你已具備以下環境：

* 已安裝 .NET 6.0 SDK 或更新版本  
* C# 開發環境（Visual Studio 2022、Rider 或 VS Code）  
* **Aspose.Words for .NET** NuGet 套件 (`Install-Package Aspose.Words`)  

這些工具會提供範例程式中使用的 `Document` 與 `DocumentBuilder` 類別。

## 步驟 1：建立空白 Word 文件

第一步會建立一個空的 `Document` 物件，並取得可用來加入內容的 `DocumentBuilder`。

```csharp
using Aspose.Words;
using Aspose.Words.Drawing;

// Step 1: Initialize an empty document and a builder
Document doc = new Document();
DocumentBuilder builder = new DocumentBuilder(doc);
```

`Document` 代表整個 `.docx` 套件，而 `DocumentBuilder` 則提供流暢的 API 讓你插入文字、圖形與其他物件。從空白文件開始，讓你能完整掌控之後加入的每個元素。

## 步驟 2：插入橢圓形

橢圓是一種向量圖形，可作為標記使用。`InsertShape` 方法需要指定圖形類型以及寬度/高度（單位為點）。

```csharp
// Step 2: Insert an ellipse shape of the desired size (100 pt × 50 pt)
Shape ellipse = builder.InsertShape(ShapeType.Ellipse, 100, 50);
```

橢圓會出現在目前頁面的游標位置。你可以透過調整數值參數來改變其尺寸。

## 步驟 3：設定圖形位置

插入後，你可以透過設定 `Left` 與 `Top` 屬性，把圖形移動到頁面上的任意位置，這兩個屬性以相對於頁邊距的點數為單位。

```csharp
// Step 3: Position the shape on the page
ellipse.Left = 150; // distance from the left margin
ellipse.Top  = 100; // distance from the top margin
```

這些座標會把橢圓大致放在標準 A4 頁面的上方中間。依需求自行調整數值即可。

## 步驟 4：隱藏圖形

隱藏的物件在文件開啟或列印時都不會顯示。將 `Hidden` 屬性設為 `true` 即可將圖形標記為 **hidden object word**。

```csharp
// Step 4: Hide the shape so it never appears
ellipse.Hidden = true;
```

Word 會同時遵守螢幕顯示與列印的隱藏旗標。圖形仍然是文件結構的一部份，之後仍可透過程式碼查詢或修改。

## 步驟 5：儲存文件

最後，將文件寫入磁碟。請選擇一個你有寫入權限的資料夾。

```csharp
// Step 5: Save the document to a .docx file
doc.Save(@"C:\Temp\HiddenEllipse.docx");
```

`HiddenEllipse.docx` 檔案現在包含一頁空白頁面，內部有一個已隱藏的橢圓形狀。

## 驗證隱藏的橢圓

在 Microsoft Word 中開啟產生的檔案，並啟用 **顯示隱藏文字**（檔案 → 選項 → 顯示）。此時會看到橢圓的淡淡輪廓。若關閉此選項，圖形會完全消失，證實 `ellipse.Hidden = true` 如預期運作。

## 常見變化與例外情況

| 情境 | 建議調整 |
|-----------|------------------------|
| **不同圖形** | 將 `ShapeType.Ellipse` 改為 `ShapeType.Rectangle`、`ShapeType.Arrow` 等。 |
| **多個隱藏物件** | 為每個圖形重複步驟 2‑4；每個圖形皆可擁有自己的 `Hidden` 旗標。 |
| **不同頁面尺寸** | 在插入圖形前設定 `doc.FirstSection.PageSetup.PageWidth` 與 `PageHeight`。 |
| **條件顯示** | 結合 `Shape.Visible` 與 `Hidden`，在程式執行時動態切換可見性。 |

**小技巧：** 將識別資料存放在圖形的 `AlternativeText` 屬性中。即使圖形被隱藏，也能透過 `doc.GetChildNodes(NodeType.Shape, true)` 取得圖形，並以該文字作為篩選條件。

## 完整原始碼

以下是可直接複製、貼上並執行的完整程式。

```csharp
using System;
using Aspose.Words;
using Aspose.Words.Drawing;

namespace HiddenShapeDemo
{
    class Program
    {
        static void Main()
        {
            // Create a new blank document and a builder
            Document doc = new Document();
            DocumentBuilder builder = new DocumentBuilder(doc);

            // Insert an ellipse shape (100 pt × 50 pt)
            Shape ellipse = builder.InsertShape(ShapeType.Ellipse, 100, 50);

            // Position the shape on the page
            ellipse.Left = 150;
            ellipse.Top  = 100;

            // Hide the shape so it is invisible in the UI and on print
            ellipse.Hidden = true;

            // Optional: add a description for later retrieval
            ellipse.AlternativeText = "Hidden marker for internal processing";

            // Save the document
            string outputPath = @"C:\Temp\HiddenEllipse.docx";
            doc.Save(outputPath);

            Console.WriteLine($"Document saved to {outputPath}");
        }
    }
}
```

**預期輸出：** 主控台會印出儲存路徑，`HiddenEllipse.docx` 會以空白頁面開啟，除非開啟「顯示隱藏文字」選項，否則不會看到任何圖形。
