# Tạo tài liệu Word trống và ẩn hình ellipse trong C#

Nếu bạn cần **tạo tài liệu Word trống** và sau đó ẩn một phần tử đồ họa, hướng dẫn này sẽ chỉ cho bạn cách thực hiện bằng C#. Bạn sẽ thấy một ví dụ hoàn chỉnh, có thể chạy được, chèn một ellipse, định vị nó, đánh dấu là ẩn và lưu tệp—tất cả chỉ trong vài dòng mã.

Bài học bao gồm mọi thứ từ thiết lập dự án đến bước xác minh cuối cùng. Khi kết thúc, bạn có thể tạo một tệp Word trong đó ellipse không bao giờ xuất hiện trên màn hình hay khi in, hữu ích cho việc lưu trữ siêu dữ liệu, bookmark hoặc bất kỳ dấu hiệu vô hình nào.

## Yêu cầu trước

Trước khi bắt đầu, hãy chắc chắn rằng bạn đã có:

* .NET 6.0 SDK hoặc phiên bản mới hơn được cài đặt  
* Môi trường phát triển C# (Visual Studio 2022, Rider, hoặc VS Code)  
* Gói NuGet **Aspose.Words for .NET** (`Install-Package Aspose.Words`)  

Các công cụ này cung cấp các lớp `Document` và `DocumentBuilder` được sử dụng trong mẫu mã.

## Bước 1: Tạo tài liệu Word trống

Hoạt động đầu tiên tạo một đối tượng `Document` rỗng và một `DocumentBuilder` cho phép bạn thêm nội dung.

```csharp
using Aspose.Words;
using Aspose.Words.Drawing;

// Step 1: Initialize an empty document and a builder
Document doc = new Document();
DocumentBuilder builder = new DocumentBuilder(doc);
```

`Document` đại diện cho toàn bộ gói `.docx`, trong khi `DocumentBuilder` cung cấp một API dạng fluent để chèn văn bản, hình dạng và các đối tượng khác. Bắt đầu với một tài liệu trống giúp bạn kiểm soát hoàn toàn mọi yếu tố bạn thêm vào.

## Bước 2: Cách chèn ellipse

Ellipse là một hình vector có thể dùng làm dấu hiệu. Phương thức `InsertShape` yêu cầu loại hình và chiều rộng/chiều cao tính bằng điểm.

```csharp
// Step 2: Insert an ellipse shape of the desired size (100 pt × 50 pt)
Shape ellipse = builder.InsertShape(ShapeType.Ellipse, 100, 50);
```

Ellipse được đặt trên trang hiện tại tại vị trí con trỏ. Bạn có thể thay đổi kích thước của nó bằng cách điều chỉnh các đối số số.

## Bước 3: Cách định vị hình dạng

Sau khi chèn, bạn có thể di chuyển hình dạng tới bất kỳ vị trí nào trên trang bằng cách thiết lập các thuộc tính `Left` và `Top`, chúng sử dụng đơn vị điểm tính từ lề trang.

```csharp
// Step 3: Position the shape on the page
ellipse.Left = 150; // distance from the left margin
ellipse.Top  = 100; // distance from the top margin
```

Các tọa độ này đặt ellipse gần phần giữa‑trên của một trang A4 tiêu chuẩn. Điều chỉnh các giá trị để phù hợp với yêu cầu bố cục của bạn.

## Bước 4: Cách ẩn hình dạng

Một đối tượng ẩn sẽ không được hiển thị khi tài liệu được mở hoặc in. Đặt cờ `Hidden` sẽ đánh dấu hình dạng là một **hidden object word**.

```csharp
// Step 4: Hide the shape so it never appears
ellipse.Hidden = true;
```

Word tôn trọng cờ hidden cho cả việc hiển thị trên màn hình và khi in. Hình dạng vẫn tồn tại trong cấu trúc tài liệu, cho phép bạn truy vấn hoặc sửa đổi nó sau này bằng mã.

## Bước 5: Lưu tài liệu

Cuối cùng, ghi tài liệu ra đĩa. Chọn một thư mục mà bạn có quyền ghi.

```csharp
// Step 5: Save the document to a .docx file
doc.Save(@"C:\Temp\HiddenEllipse.docx");
```

Tệp `HiddenEllipse.docx` hiện chứa một trang trống với một hình ellipse ẩn.

## Xác minh ellipse ẩn

Mở tệp vừa tạo trong Microsoft Word và bật tùy chọn **Show hidden text** (File → Options → Display). Bạn sẽ thấy một đường viền mờ của ellipse. Nếu tắt tùy chọn này, hình dạng sẽ biến mất hoàn toàn, xác nhận rằng `ellipse.Hidden = true` hoạt động như mong đợi.

## Các biến thể phổ biến và trường hợp đặc biệt

| Tình huống | Điều chỉnh đề xuất |
|-----------|--------------------|
| **Hình dạng khác** | Thay `ShapeType.Ellipse` bằng `ShapeType.Rectangle`, `ShapeType.Arrow`, v.v. |
| **Nhiều đối tượng ẩn** | Lặp lại các bước 2‑4 cho mỗi hình; mỗi hình có thể có cờ `Hidden` riêng. |
| **Kích thước trang khác** | Đặt `doc.FirstSection.PageSetup.PageWidth` và `PageHeight` trước khi chèn hình. |
| **Hiển thị có điều kiện** | Sử dụng `Shape.Visible` kết hợp với `Hidden` để bật/tắt tại thời gian chạy bằng mã. |

**Mẹo chuyên nghiệp:** Lưu dữ liệu nhận dạng trong thuộc tính `AlternativeText` của hình dạng. Ngay cả khi ẩn, bạn vẫn có thể lấy lại hình dạng sau này bằng `doc.GetChildNodes(NodeType.Shape, true)` và lọc theo văn bản đó.

## Toàn bộ mã nguồn

Dưới đây là chương trình hoàn chỉnh mà bạn có thể sao chép, dán và chạy.

```csharp
using System;
using Aspose.Words;
using Aspose.Words.Drawing;

namespace HiddenShapeDemo
{
    class Program
    {
        static void Main()
        {
            // Create a new blank document and a builder
            Document doc = new Document();
            DocumentBuilder builder = new DocumentBuilder(doc);

            // Insert an ellipse shape (100 pt × 50 pt)
            Shape ellipse = builder.InsertShape(ShapeType.Ellipse, 100, 50);

            // Position the shape on the page
            ellipse.Left = 150;
            ellipse.Top  = 100;

            // Hide the shape so it is invisible in the UI and on print
            ellipse.Hidden = true;

            // Optional: add a description for later retrieval
            ellipse.AlternativeText = "Hidden marker for internal processing";

            // Save the document
            string outputPath = @"C:\Temp\HiddenEllipse.docx";
            doc.Save(outputPath);

            Console.WriteLine($"Document saved to {outputPath}");
        }
    }
}
```

**Kết quả mong đợi:** Console in ra đường dẫn lưu, và tệp `HiddenEllipse.docx` mở ra như một trang trống không có đồ họa nào hiển thị trừ khi bật hiển thị các đối tượng ẩn.

## Kết luận

Bây giờ bạn đã biết cách **tạo tài liệu Word trống** bằng lập trình, **cách chèn ellipse**, **cách định vị hình dạng**, và **cách ẩn hình dạng** sao cho nó hoạt động như một **hidden object word**. Kỹ thuật này lý tưởng để nhúng các dấu hiệu vô hình, siêu dữ liệu tùy chỉnh, hoặc các placeholder mà các quy trình downstream có thể đọc mà không ảnh hưởng đến bố cục trực quan của tài liệu.

### Các bước tiếp theo

* Khám phá các loại hình dạng khác (`ShapeType.Arrow`, `ShapeType.TextBox`) để nhúng các dấu hiệu khác nhau.  
* Kết hợp các hình dạng ẩn với các phần XML tùy chỉnh để lưu trữ siêu dữ liệu phong phú hơn.  
* Tích hợp đoạn mã này vào một pipeline tự động hoá lớn hơn để tạo báo cáo hoặc hợp đồng.

Hãy thoải mái thử nghiệm các tọa độ, kích thước và cờ hidden để phù hợp với kịch bản cụ thể của bạn. Chúc lập trình vui vẻ!
