# Tạo mẫu hoá đơn và hợp nhất dữ liệu bằng Aspose.Words

Nếu bạn cần **tạo mẫu hoá đơn** nhanh chóng, hướng dẫn này sẽ chỉ cho bạn cách thực hiện. Sau hai câu đầu tiên, bạn sẽ nắm rõ quy trình chuyển một tệp Word trống thành hoá đơn đã được điền đầy đủ, bằng cách sử dụng API mail‑merge low‑code của Aspose.Words.

Việc tạo hoá đơn là yêu cầu phổ biến cho các hệ thống thanh toán, tích hợp ERP và báo cáo tự động. Trong tutorial này, bạn sẽ học **cách mail merge**, **điền dữ liệu vào mẫu Word**, **hợp nhất dữ liệu vào Word**, và cuối cùng **lưu tài liệu đã hợp nhất**—tất cả chỉ với một vài dòng C#.

## Những gì bạn sẽ đạt được

* Một mẫu Word có thể tái sử dụng (`InvoiceTemplate.docx`) chứa các trường hợp hợp cho khách hàng, ngày, các mục hàng, và tổng cộng.  
* Một chương trình C# tải mẫu, chèn một đối tượng dữ liệu kiểu mạnh, và ghi kết quả ra `Invoice_001.docx`.  
* Kiến thức về các trường hợp đặc biệt như bộ sưu tập rỗng, kiểu dữ liệu tùy chỉnh, và xử lý đường dẫn tệp.

### Yêu cầu trước

| Yêu cầu | Lý do quan trọng |
|-------------|----------------|
| .NET 6 hoặc mới hơn | Aspose.Words for .NET hỗ trợ .NET 6+ và cung cấp API low‑code được dùng trong hướng dẫn này. |
| Gói NuGet Aspose.Words for .NET (`Aspose.Words`) | Cung cấp các kiểu `Document`, `MailMerger`, và các loại liên quan. |
| Kiến thức cơ bản về C# | Cần để hiểu các đối tượng ẩn danh và LINQ. |
| Visual Studio 2022 (hoặc bất kỳ IDE nào) | Giúp việc chỉnh sửa và gỡ lỗi trở nên đơn giản. |

> **Mẹo chuyên nghiệp:** Cài đặt gói NuGet qua Package Manager Console:  
> `Install-Package Aspose.Words`

## Cách tạo mẫu hoá đơn bằng mail merge low‑code

Bước đầu tiên là xây dựng một tệp Word chứa các trường hợp hợp tương ứng với các thuộc tính của đối tượng dữ liệu mà bạn sẽ truyền sau này. Lưu tệp dưới tên `InvoiceTemplate.docx` trong một thư mục bạn kiểm soát (ví dụ: `C:\Invoices\Template`).

| Trường hợp hợp | Ví dụ placeholder trong Word |
|-------------|-----------------------------|
| CustomerName | «CustomerName» |
| InvoiceDate | «InvoiceDate» |
| Items (lặp lại) | «Items.Description», «Items.Qty», «Items.Price» |
| Total | «Total» |

> **Tại sao điều này quan trọng:** API low‑code tự động ánh xạ tên thuộc tính của nguồn dữ liệu tới các trường hợp hợp. Giữ tên giống hệt nhau loại bỏ việc ánh xạ thủ công và giảm lỗi thời gian chạy.

## Bước 1: Tải mẫu hoá đơn

```csharp
using Aspose.Words;
using Aspose.Words.LowCode;   // Low‑code mail‑merge API

// Load the Word file that contains the merge fields.
Document template = new Document(@"C:\Invoices\Template\InvoiceTemplate.docx");
```

*Lớp `Document` đại diện cho toàn bộ tệp Word. Việc tải nó một lần cho phép bạn tái sử dụng cùng một mẫu cho nhiều hoá đơn.*

## Bước 2: Chuẩn bị nguồn dữ liệu

Tạo một đối tượng ẩn danh phản ánh các trường hợp hợp. API low‑code có thể làm việc với bất kỳ đối tượng .NET nào, bao gồm mảng và các bộ sưu tập lồng nhau.

```csharp
var invoiceData = new
{
    CustomerName = "Acme Corp",
    InvoiceDate = DateTime.Today,
    Items = new[]
    {
        new { Description = "Widget A", Qty = 10, Price = 9.99M },
        new { Description = "Widget B", Qty = 5,  Price = 19.95M }
    },
    Total = 199.85M
};
```

**Tại sao cách này hoạt động:**  
* Các tên thuộc tính (`CustomerName`, `InvoiceDate`, `Items`, `Total`) khớp với các trường hợp hợp trong mẫu.  
* `Items` là một mảng các đối tượng, vì vậy mail merger sẽ tự động lặp lại hàng bảng cho mỗi phần tử.  
* Sử dụng `decimal` (`M` suffix) cho các giá trị tiền tệ tránh các vấn đề làm tròn của floating‑point.

### Xử lý bộ sưu tập rỗng

Nếu một hoá đơn không có mục hàng, truyền một mảng rỗng:

```csharp
Items = new object[0]
```

Công cụ low‑code sẽ chỉ bỏ qua phần lặp lại, để lại tiêu đề bảng nguyên vẹn.

## Bước 3: Khởi tạo mail merger low‑code

```csharp
MailMerger merger = new MailMerger(template);
```

`MailMerger` là điểm vào để **cách thực hiện mail merge** với Aspose.Words. Nó đọc mẫu, ràng buộc dữ liệu, và chuẩn bị tài liệu cuối cùng trong một lời gọi duy nhất.

## Bước 4: Thực hiện hợp nhất – điền mẫu Word trong một dòng

```csharp
Document mergedDocument = merger.Execute(invoiceData);
```

* Dòng này **điền mẫu Word** và tạo một thể hiện `Document` mới (`mergedDocument`).  
* Tất cả các trường hợp hợp được thay thế, các phần lặp lại được mở rộng, và tài liệu kết quả tồn tại hoàn toàn trong bộ nhớ.

### Trường hợp đặc biệt: Định dạng tùy chỉnh

Nếu bạn cần định dạng ngày tháng cụ thể, thêm một bộ định dạng tùy chỉnh trước khi hợp nhất:

```csharp
merger.Options.DateFormat = "MMMM dd, yyyy"; // e.g., "October 07, 2026"
```

## Bước 5: Lưu tài liệu đã hợp nhất

```csharp
mergedDocument.Save(@"C:\Invoices\Output\Invoice_001.docx");
```

Lệnh **save merged document** ghi hoá đơn đã được điền đầy đủ lên đĩa. Tệp giờ có thể mở trong Microsoft Word, gửi dưới dạng đính kèm email, hoặc chuyển đổi sang PDF.

### Kiểm tra đầu ra

Mở `Invoice_001.docx`. Bạn sẽ thấy:

* **CustomerName** được thay bằng *Acme Corp*  
* **InvoiceDate** hiển thị ngày hiện tại theo định dạng đã chọn  
* Một hàng bảng cho *Widget A* (10 × 9.99) và *Widget B* (5 × 19.95)  
* **Total** hiển thị *199.85*  

Nếu bất kỳ trường nào vẫn chưa thay đổi (ví dụ, vẫn hiển thị «CustomerName»), hãy kiểm tra lại xem tên thuộc tính có khớp chính xác với tên trường hợp hợp trong mẫu hay không.

## Ví dụ đầy đủ có thể chạy

Dưới đây là chương trình hoàn chỉnh bạn có thể sao chép‑dán vào một dự án console mới.

```csharp
using System;
using Aspose.Words;
using Aspose.Words.LowCode;   // Low‑code mail‑merge API

namespace InvoiceGenerator
{
    class Program
    {
        static void Main()
        {
            // 1️⃣ Load the template
            Document template = new Document(@"C:\Invoices\Template\InvoiceTemplate.docx");

            // 2️⃣ Build the data source
            var invoiceData = new
            {
                CustomerName = "Acme Corp",
                InvoiceDate = DateTime.Today,
                Items = new[]
                {
                    new { Description = "Widget A", Qty = 10, Price = 9.99M },
                    new { Description = "Widget B", Qty = 5,  Price = 19.95M }
                },
                Total = 199.85M
            };

            // 3️⃣ Initialise the mail merger
            MailMerger merger = new MailMerger(template);

            // Optional: customise date format
            merger.Options.DateFormat = "MMMM dd, yyyy";

            // 4️⃣ Perform the merge (populate word template)
            Document mergedDocument = merger.Execute(invoiceData);

            // 5️⃣ Save the resulting file (save merged document)
            mergedDocument.Save(@"C:\Invoices\Output\Invoice_001.docx");

            Console.WriteLine("Invoice generated successfully.");
        }
    }
}
```

Chạy chương trình (`dotnet run`). Console sẽ in *Invoice generated successfully.* và tệp sẽ xuất hiện trong `C:\Invoices\Output`.
