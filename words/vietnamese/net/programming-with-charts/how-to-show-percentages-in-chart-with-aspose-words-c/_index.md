# Cách Hiển Thị Phần Trăm Trong Biểu Đồ với Aspose.Words C#

Bạn đã bao giờ tự hỏi **cách hiển thị phần trăm trong biểu đồ** mà không phải vật lộn với Office interop phức tạp chưa? Bạn không phải là người duy nhất—nhiều lập trình viên gặp khó khăn này khi cần một cách nhanh chóng, lập trình để gắn nhãn cho biểu đồ tròn hoặc bánh donut. Tin tốt là gì? Với Aspose.Words cho .NET, bạn có thể bật các nhãn dữ liệu chỉ trong vài dòng mã.

Trong hướng dẫn này, chúng ta cũng sẽ đề cập đến **add data labels to pie chart** và **how to enable chart data labels** để các biểu đồ của bạn ngay lập tức trở nên sâu sắc hơn. Khi hoàn thành, bạn sẽ có một tài liệu Word sẵn sàng (`.docx`) hiển thị biểu đồ tròn được đánh dấu phần trăm gọn gàng ở ngoài mỗi lát.

## Prerequisites

Trước khi bắt đầu, hãy chắc chắn rằng bạn có:

- **Aspose.Words for .NET** (phiên bản mới nhất, ví dụ 24.9) được cài đặt qua NuGet.  
- Một tệp **ChartTemplate.docx** đã chứa sẵn biểu đồ tròn hoặc bánh donut.  
  *(Nếu bạn chưa có, tạo một tài liệu Word đơn giản, chèn một biểu đồ tròn và lưu dưới tên `ChartTemplate.docx`.)*  
- .NET 6.0 hoặc mới hơn và bất kỳ IDE nào bạn thích (Visual Studio, Rider, VS Code).

Không cần bất kỳ phụ thuộc nào khác—Aspose.Words tự xử lý mọi thứ bên trong.

## How to Show Percentages in Chart – Step‑by‑Step

Dưới đây chúng ta chia quá trình thành sáu bước rõ ràng. Mỗi bước bao gồm đoạn mã C# chính xác mà bạn có thể sao chép‑dán, kèm theo một giải thích ngắn về **tại sao** chúng ta làm như vậy.

### Step 1: Load the Source Document

```csharp
using Aspose.Words;
using Aspose.Words.Drawing.Charts;

// Load the .docx that already holds a chart.
Document sourceDoc = new Document("YOUR_DIRECTORY/ChartTemplate.docx");
```

*Why?*  
`Document` là điểm vào cho mọi thao tác với Word. Khi tải mẫu, chúng ta có quyền truy cập vào mọi nút—hình dạng, bảng, văn bản và tất nhiên là biểu đồ mà chúng ta sẽ chỉnh sửa.

### Step 2: Grab the First Chart Shape

```csharp
// The chart lives inside a Shape node; retrieve it.
Chart chart = (Chart)sourceDoc.GetChild(NodeType.Shape, 0, true);
```

*Why?*  
Aspose lưu trữ biểu đồ dưới dạng đối tượng `Shape`. `GetChild` duyệt cây tài liệu và trả về hình dạng đầu tiên tìm thấy, trong trường hợp này là biểu đồ tròn chúng ta muốn chỉnh sửa.

### Step 3: Confirm the Chart Type

```csharp
if (chart.ChartType == ChartType.Pie || chart.ChartType == ChartType.Doughnut)
{
    // Inside this block we’ll enable the data labels.
}
else
{
    throw new InvalidOperationException("The chart is not a Pie or Doughnut type.");
}
```

*Why?*  
Nhãn phần trăm chỉ có ý nghĩa với các biểu đồ vòng. Điều kiện này ngăn chúng ta vô tình áp dụng cài đặt cho, ví dụ, biểu đồ cột nơi `ShowPercentage` sẽ bị bỏ qua.

### Step 4: Enable Data Labels and Show Percentages

```csharp
// Turn on data labels for the chart.
chart.HasDataLabel = true;

// Show the percentage value for each slice.
chart.DataLabel.ShowPercentage = true;
```

*Why?*  
`HasDataLabel` báo cho Aspose vẽ một nhãn cho mỗi điểm dữ liệu. Đặt `ShowPercentage` đảm bảo nội dung nhãn là tỷ lệ phần trăm tính toán từ toàn bộ—đúng như yêu cầu **add data labels to pie chart**.

### Step 5: Position Labels Outside the Slices

```csharp
// Place the labels outside the pie slices for better readability.
chart.DataLabel.Position = ChartDataLabelPosition.OutSideEnd;
```

*Why?*  
Nhãn bên trong lát có thể bị chật chội, đặc biệt khi các lát nhỏ. `OutSideEnd` mô phỏng kiểu “bên ngoài” mặc định mà bạn thấy trong giao diện Word, giữ cho biểu đồ gọn gàng.

### Step 6: Save the Updated Document

```csharp
sourceDoc.Save("YOUR_DIRECTORY/FormattedPieChart.docx");
```

*Why?*  
Lưu lại ghi lại tất cả các thay đổi vào một tệp mới. Mở `FormattedPieChart.docx` trong Word và bạn sẽ thấy các phần trăm hiển thị bên cạnh mỗi lát.

#### Expected Result

Khi bạn mở `FormattedPieChart.docx`, biểu đồ tròn sẽ trông giống như sau (ảnh minh hoạ tưởng tượng):

```
[ Pie chart with three slices ]
- Slice A – 45%
- Slice B – 30%
- Slice C – 25%
```

Tất cả các phần trăm được tính tự động từ chuỗi dữ liệu gốc, và các nhãn nằm ngay ngoài mỗi lát.

## Common Variations & Edge Cases

| Situation | What to Adjust |
|-----------|----------------|
| **Multiple charts** in the same document | Loop through `sourceDoc.GetChildNodes(NodeType.Shape, true)` and cast each to `Chart` before applying the same logic. |
| **Bar or line chart** where you still want labels | Use `chart.DataLabel.ShowValue = true;` (or `ShowSeriesName`) instead of `ShowPercentage`. |
| **Custom number format** (e.g., “45 %”) | Set `chart.DataLabel.NumberFormat = "0%";` before saving. |
| **Large data sets** causing label overlap | Consider `chart.DataLabel.ShowLeaderLines = true;` to draw connector lines. |

> **Pro tip:** Nếu bạn tạo nhiều tài liệu trong một batch, khởi tạo một đối tượng `Aspose.Words.License` duy nhất khi ứng dụng khởi động để tránh chi phí hiệu năng khi tải giấy phép lặp lại.

## Full Working Example

Dưới đây là toàn bộ chương trình được ghép lại, sẵn sàng chạy:

```csharp
using System;
using Aspose.Words;
using Aspose.Words.Drawing.Charts;

class Program
{
    static void Main()
    {
        // 1️⃣ Load the template document.
        Document sourceDoc = new Document("YOUR_DIRECTORY/ChartTemplate.docx");

        // 2️⃣ Retrieve the first chart shape.
        Chart chart = (Chart)sourceDoc.GetChild(NodeType.Shape, 0, true);

        // 3️⃣ Ensure we’re dealing with a Pie or Doughnut chart.
        if (chart.ChartType != ChartType.Pie && chart.ChartType != ChartType.Doughnut)
        {
            Console.WriteLine("The selected shape is not a Pie/Doughnut chart.");
            return;
        }

        // 4️⃣ Enable data labels and show percentages.
        chart.HasDataLabel = true;
        chart.DataLabel.ShowPercentage = true;

        // 5️⃣ Position the labels outside the slices.
        chart.DataLabel.Position = ChartDataLabelPosition.OutSideEnd;

        // 6️⃣ Save the modified document.
        sourceDoc.Save("YOUR_DIRECTORY/FormattedPieChart.docx");

        Console.WriteLine("Chart updated successfully – percentages now visible!");
    }
}
```

Sao chép đoạn mã, thay `YOUR_DIRECTORY` bằng đường dẫn thực tế trên máy của bạn, và chạy nó. Bạn sẽ có một tệp Word với biểu đồ tròn được gắn nhãn đầy đủ trong vài giây.

- **Style the labels** – thay đổi phông chữ, màu sắc, hoặc thêm nền bằng `chart.DataLabel.Font`.  
- **Create charts from scratch** – khám phá `Chart chart = (Chart)sourceDoc.FirstSection.Body.AppendChild(new Shape(sourceDoc, ShapeType.Chart));` để tạo biểu đồ bằng mã.  
- **Combine multiple charts** trong một tài liệu để làm dashboard, sau đó xuất ra PDF bằng `sourceDoc.Save("Dashboard.pdf", SaveFormat.Pdf);`.
