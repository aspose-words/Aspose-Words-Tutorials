# Cách chuyển đổi docx sang markdown với hình ảnh trong một thư mục con

Nếu bạn cần **convert docx to markdown** trong khi giữ mọi hình ảnh nhúng được sắp xếp gọn gàng, bạn đã đến đúng nơi. Nhiều nhà phát triển tạo báo cáo, hướng dẫn, hoặc bản nháp blog một cách tự động và kết thúc với một hỗn hợp hỗn loạn các tệp hình ảnh rải rác trong thư mục đầu ra. Hướng dẫn này cho bạn một cách tiếp cận sạch sẽ, dựa trên callback sử dụng Aspose.Words cho .NET, xuất tài liệu sang markdown, lưu mỗi hình ảnh vào thư mục *md‑resources* riêng biệt, và lưu tệp markdown cuối cùng sẵn sàng để xuất bản.

> **Tổng quan nhanh:**  
> • Thiết lập `MarkdownSaveOptions`  
> • Triển khai `IResourceSavingCallback` để chuyển hướng hình ảnh  
> • Gọi `Document.Save` với các tùy chọn đã cấu hình  

Bây giờ bạn đã hiểu tại sao callback ưu tiên hơn việc xử lý sau, hãy đi sâu vào giải pháp từng bước.

## Câu trả lời nhanh
- **Công việc của “convert docx to markdown” thực sự là gì?** Nó chuyển đổi đánh dấu xử lý Word thành markdown dạng văn bản thuần trong khi giữ nguyên các tiêu đề, danh sách, bảng và tham chiếu hình ảnh.  
- **Thư viện nào thực hiện việc chuyển đổi?** Aspose.Words cho .NET cung cấp một API được quản lý hoàn toàn, chạy phía máy chủ mà không cần cài đặt Microsoft Word.  
- **Tôi có cần viết mã xử lý hình ảnh không?** Không; `IResourceSavingCallback` sẽ lo việc lưu mỗi hình ảnh vào thư mục bạn chỉ định.  
- **Tôi có thể thay đổi tên thư mục đầu ra không?** Chắc chắn – thay thế `"md-resources/"` bằng bất kỳ đường dẫn tương đối hoặc tuyệt đối nào bạn muốn.  
- **Giải pháp có tương thích với .NET 6 và các phiên bản sau không?** Có, nó chạy trên .NET 6+, .NET 5, .NET Core 3.1 và .NET Framework 4.7+.

## Convert docx sang markdown là gì?
**Convert docx to markdown** là quá trình lấy một tài liệu Microsoft Word (DOCX) và tạo ra một tệp markdown (`.md`) đại diện cho cùng nội dung bằng cú pháp markdown. Việc chuyển đổi giữ lại các yếu tố cấu trúc và tùy chọn trích xuất các tài nguyên nhúng như hình ảnh.

Quá trình chuyển đổi được thực hiện bởi Aspose.Words, một thư viện hỗ trợ **hơn 35 định dạng đầu vào và đầu ra** — bao gồm DOCX, PDF, HTML và Markdown — cho phép bạn xử lý các tài liệu hàng trăm trang mà không cần tải toàn bộ tệp vào bộ nhớ.

## Cách chuyển đổi docx sang markdown? 
Tải tài liệu nguồn của bạn bằng `new Document("source.docx")`, cấu hình `MarkdownSaveOptions` để sử dụng một callback ghi mỗi hình ảnh vào `md-resources/`, sau đó gọi `doc.Save("output.md", saveOptions)`. Mô hình ba bước này chuyển đổi tệp, trích xuất hình ảnh, và tạo ra một tệp markdown sạch sẽ với các liên kết hình ảnh tương đối — tất cả trong một lời gọi phương thức duy nhất.

### Bước 1: cấu hình tùy chọn lưu cho chuyển đổi markdown

`MarkdownSaveOptions` cấu hình cách Aspose.Words chuyển đổi tài liệu sang Markdown.

```csharp
// Step 1: Initialize Markdown save options
var markdownSaveOptions = new Aspose.Words.Saving.MarkdownSaveOptions();
```

```csharp
// Step 1: Initialize Markdown save options
var markdownSaveOptions = new Aspose.Words.Saving.MarkdownSaveOptions();
```

> **Tại sao điều này quan trọng:**  
> Nếu không tạo rõ ràng `MarkdownSaveOptions`, thư viện sẽ quay lại cài đặt mặc định nhúng hình ảnh trực tiếp vào tệp Markdown dưới dạng chuỗi Base64. Điều này làm tệp trở nên rất lớn và làm mất mục đích của việc có một thư mục *images* sạch sẽ.

### Bước 2: định nghĩa callback lưu tài nguyên để xuất hình ảnh

`IResourceSavingCallback` cho phép bạn kiểm soát nơi mỗi tài nguyên (hình ảnh, SVG) được lưu trong quá trình xuất.

Bây giờ chúng ta cho bộ lưu **nơi** đặt mỗi hình ảnh. Giao diện `IResourceSavingCallback` cung cấp một hook được kích hoạt cho mỗi tài nguyên (hình ảnh, SVG, v.v.) được phát hiện trong quá trình xuất. Trong callback chúng ta:

1. Đảm bảo thư mục đích tồn tại (`md-resources/`).  
2. Đặt `OutputFileName` thành thư mục cộng với tên tài nguyên gốc.  

```csharp
// Step 2: Hook into the resource‑saving pipeline
markdownSaveOptions.ResourceSavingCallback = new Aspose.Words.Saving.IResourceSavingCallback(
    (args) =>
    {
        // All images will be placed in "md-resources" relative to the output .md file
        const string folder = "md-resources/";
        Directory.CreateDirectory(folder);          // Create folder if it doesn’t exist

        // Preserve the original file name (e.g., image001.png) but prepend the folder path
        args.OutputFileName = Path.Combine(folder, args.ResourceFileName);

        // Optional: you could also change the format here (e.g., convert BMP to PNG)
        // args.ResourceFileName = Path.ChangeExtension(args.ResourceFileName, ".png");
    });
```

> **Câu hỏi thường gặp:** *Nếu tôi muốn nhúng hình ảnh thay vì lưu chúng thì sao?*  
> Chỉ cần bỏ qua callback hoặc đặt `args.OutputFileName = null;` — bộ lưu sẽ tự động nhúng hình ảnh dưới dạng chuỗi Base64.

> **Trường hợp đặc biệt:** Một số tài liệu cũ chứa tên hình ảnh trùng lặp. Callback ở trên sẽ ghi đè lên tệp trước. Để tránh điều này, bạn có thể thêm một GUID:

```csharp
args.OutputFileName = Path.Combine(folder,
    $"{Path.GetFileNameWithoutExtension(args.ResourceFileName)}_{Guid.NewGuid()}{Path.GetExtension(args.ResourceFileName)}");
```

### Bước 3: lưu tài liệu dưới dạng markdown và xác minh đầu ra

Với các tùy chọn đã được cấu hình đầy đủ, lời gọi cuối cùng là một dòng lệnh duy nhất ghi tệp Markdown và các hình ảnh liên quan lên đĩa.

```csharp
// Step 3: Perform the actual export
string outputPath = @"C:\Exports\MyReport.md";
doc.Save(outputPath, markdownSaveOptions);
```

Nếu mọi thứ diễn ra tốt, bạn sẽ thấy:

- `MyReport.md` – bản đại diện Markdown của tài liệu nguồn của bạn.  
- `md-resources/` – một thư mục bên cạnh tệp `.md` chứa mọi hình ảnh đã được trích xuất (ví dụ, `image001.png`, `image002.jpg`).  

**Đoạn mã markdown mẫu** (tự động tạo bởi Aspose.Words):

```markdown
# Sample Report

Here is an introductory paragraph.

![Sample image](md-resources/image001.png)

More text follows...
```

[Hình mẫu](md-resources/image001.png)

> **Mẹo chuyên nghiệp:** Mở tệp `.md` đã tạo trong VS Code hoặc bất kỳ trình xem Markdown nào; các hình ảnh sẽ hiển thị ngay lập tức vì các đường dẫn tương đối khớp với cấu trúc thư mục.

## Ví dụ đầy đủ, có thể chạy (không có khối mã bổ sung)

Dưới đây là một chương trình console tự chứa mà bạn có thể dán vào một dự án .NET mới và chạy. Nó tạo một tài liệu Word đơn giản, thêm một hình ảnh, và sau đó **tạo markdown từ tài liệu** trong khi lưu hình ảnh vào một thư mục con.

```csharp
using System;
using System.IO;
using Aspose.Words;
using Aspose.Words.Saving;

class Program
{
    static void Main()
    {
        // 1️⃣ Create a sample Word document with an image
        var doc = new Document();
        var builder = new DocumentBuilder(doc);
        builder.Writeln("Hello, this is a test document.");
        builder.InsertImage("sample-image.png"); // Ensure this file exists next to exe

        // 2️⃣ Configure markdown export options (see Step 1 & 2 above)
        var markdownOptions = new MarkdownSaveOptions();
        markdownOptions.ResourceSavingCallback = new IResourceSavingCallback(
            (args) =>
            {
                const string folder = "md-resources/";
                Directory.CreateDirectory(folder);
                args.OutputFileName = Path.Combine(folder, args.ResourceFileName);
            });

        // 3️⃣ Save as markdown (Step 3)
        string outputFolder = Path.Combine(Environment.CurrentDirectory, "output");
        Directory.CreateDirectory(outputFolder);
        string markdownPath = Path.Combine(outputFolder, "ExportedDoc.md");
        doc.Save(markdownPath, markdownOptions);

        Console.WriteLine($"✅ Markdown saved to: {markdownPath}");
        Console.WriteLine("📂 Images saved in: md-resources/");
    }
}
```

**Bạn sẽ thấy** sau khi chạy:

```
✅ Markdown saved to: C:\MyProject\output\ExportedDoc.md
📂 Images saved in: md-resources/
```

Mở `ExportedDoc.md` — tham chiếu hình ảnh sẽ trỏ tới `md-resources/sample-image.png`, và hình ảnh sẽ hiển thị đúng trong bất kỳ trình xem Markdown nào.

## Các vấn đề thường gặp và giải pháp
- **Hình ảnh không hiển thị trong bản xem trước markdown** – Kiểm tra rằng đường dẫn tương đối trong markdown (`md-resources/image001.png`) khớp với vị trí thực tế của thư mục so với tệp `.md`.  
- **Tên hình ảnh trùng gây ghi đè** – Thêm một định danh duy nhất (GUID hoặc bộ đếm tăng dần) trong callback để đảm bảo tên tệp khác nhau.  
- **Tài liệu lớn gây áp lực bộ nhớ** – Sử dụng `Document.OptimizeResources()` trước khi lưu; điều này giảm tiêu thụ bộ nhớ bằng cách giải phóng các luồng không dùng.  
- **Định dạng hình ảnh không được hỗ trợ** – Aspose.Words hỗ trợ PNG, JPEG, BMP, GIF và TIFF. Chuyển đổi các định dạng không được hỗ trợ sang một trong các định dạng này trước khi thêm chúng vào tài liệu nguồn.
