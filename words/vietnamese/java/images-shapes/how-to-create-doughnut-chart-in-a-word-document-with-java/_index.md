# Cách tạo biểu đồ bánh donut trong tài liệu Word bằng Java

Nếu bạn cần **create doughnut chart** trong một tệp Word, hướng dẫn này sẽ cho bạn một giải pháp hoàn chỉnh, sẵn sàng chạy. Bạn sẽ thấy cách **insert pie chart**, chuyển nó thành donut, **rotate pie chart** để cân bằng tốt hơn, và **format pie chart** để phù hợp với thương hiệu của bạn. Khi kết thúc, bạn sẽ có một tài liệu Word chuyên nghiệp có thể dùng trong báo cáo, bảng điều khiển, hoặc đính kèm email tự động.

Tạo biểu đồ bằng chương trình loại bỏ các bước sao chép‑dán thủ công và đảm bảo kiểu dáng nhất quán trên hàng chục tài liệu được tạo. Ví dụ sử dụng thư viện Aspose.Words for Java, hoạt động với Java 8+ và không yêu cầu cài đặt Microsoft Office. Không có yêu cầu tiên quyết nào khác ngoài JDK tiêu chuẩn và IDE yêu thích của bạn.

## Yêu cầu trước

- Java Development Kit (JDK) 8 hoặc mới hơn  
- Maven hoặc Gradle để quản lý phụ thuộc (hướng dẫn này sử dụng Maven)  
- Thư viện Aspose.Words for Java (giấy phép dùng thử miễn phí đủ cho việc thử nghiệm)  

Thêm phụ thuộc Aspose.Words vào `pom.xml` của bạn:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-words</artifactId>
    <version>24.9</version> <!-- Use the latest stable version -->
</dependency>
```

> **Pro tip:** Đăng ký giấy phép của bạn với `License license = new License(); license.setLicense("Aspose.Words.lic");` trước khi tạo bất kỳ tài liệu nào để loại bỏ watermark đánh giá.

## Tạo biểu đồ bánh donut trong tài liệu Word

Quy trình chính bao gồm năm bước logic. Mỗi bước được gói trong một phương thức riêng để giữ mã sạch sẽ và tái sử dụng.

```java
import com.aspose.words.*;
import com.aspose.words.drawing.*;

public class DoughnutChartDemo {

    public static void main(String[] args) throws Exception {
        // Step 1: create blank Word document
        Document doc = createBlankWordDocument();

        // Step 2: insert a pie chart (base for the doughnut)
        Chart chart = insertPieChart(doc, 400, 300);

        // Step 3: convert the pie chart into a doughnut and rotate it
        customizeChartAppearance(chart);

        // Step 4: apply additional formatting to the chart
        formatPieChart(chart);

        // Step 5: save the final document
        doc.save("output/DoughnutChartFormatted.docx");
        System.out.println("Document saved successfully.");
    }

    /** Step 1 – create blank Word document */
    private static Document createBlankWordDocument() {
        // Aspose.Words creates an empty document by default
        return new Document();
    }

    /** Step 2 – insert pie chart with given dimensions */
    private static Chart insertPieChart(Document doc, int width, int height) throws Exception {
        DocumentBuilder builder = new DocumentBuilder(doc);
        // ChartType.PIE creates a standard pie chart that we will later turn into a doughnut
        Chart chart = builder.insertChart(ChartType.PIE, width, height);
        // Populate the chart with sample data
        chart.getSeries().clear(); // Remove default series
        ChartSeries series = chart.getSeries().add("Sales", new String[]{"Q1", "Q2", "Q3", "Q4"},
                new double[]{15000, 23000, 18000, 27000});
        return chart;
    }

    /** Step 3 – rotate pie chart and make it a doughnut */
    private static void customizeChartAppearance(Chart chart) {
        // Explode the first slice for emphasis
        chart.getSeries().get(0).setExplode(20);
        // Convert the pie into a doughnut by setting a hole size (percentage of radius)
        chart.setHoleSize(30); // 30% hole creates a classic doughnut look
        // Rotate the chart so the largest slice starts at 45°
        chart.setRotationAngle(45);
    }

    /** Step 4 – additional formatting of the pie chart */
    private static void formatPieChart(Chart chart) {
        // Example: change the first slice color to a brand color
        chart.getSeries().get(0).getPoints().get(0).getFormat().setFillForegroundColor(Color.fromArgb(0xFF, 0x4A, 0x90));
        // Add a legend and position it at the bottom
        chart.setHasLegend(true);
        chart.getLegend().setPosition(LegendPosition.BOTTOM);
        // Set a title for the chart
        chart.setTitle("Quarterly Sales Distribution");
    }
}
```

### Những gì mã thực hiện

| Bước | Hành động | Lý do |
|------|-----------|-------|
| **Create blank Word document** | `new Document()` | Bắt đầu với một tệp sạch để bạn kiểm soát mọi yếu tố. |
| **Insert pie chart** | `builder.insertChart(ChartType.PIE, …)` | Biểu đồ bánh tròn là hình dạng cơ bản; Aspose chỉ cung cấp donut bằng cách điều chỉnh kích thước lỗ. |
| **Rotate pie chart** | `chart.setRotationAngle(45)` | Việc xoay căn chỉnh lát lớn nhất vào vị trí dễ đọc hơn. |
| **Format pie chart** | `setExplode`, `setHoleSize`, color, legend | Cải thiện thứ tự hiển thị và phù hợp với hướng dẫn phong cách công ty. |
| **Save document** | `doc.save("…/DoughnutChartFormatted.docx")` | Ghi tệp .docx cuối cùng vào đĩa, sẵn sàng để phân phối. |

## Chèn biểu đồ bánh tròn trước khi chuyển thành donut

Aspose.Words không cung cấp phương thức “insert doughnut chart” trực tiếp. Thay vào đó, bạn **insert pie chart** và sau đó chỉnh sửa các thuộc tính của nó. Cách tiếp cận hai bước này cho phép bạn kiểm soát toàn bộ series dữ liệu, việc nổ lát, và kích thước lỗ. Nếu bạn cần một biểu đồ bánh tròn thuần túy ở nơi khác, chỉ cần bỏ qua lệnh `setHoleSize`.

## Xoay biểu đồ bánh tròn để cân bằng hình ảnh

Hướng mặc định bắt đầu lát đầu tiên ở vị trí 12 giờ. Trong nhiều báo cáo kinh doanh, lát quan trọng nhất nên bắt đầu ở góc tự nhiên hơn, chẳng hạn 45 độ. Phương thức `setRotationAngle(double angle)` nhận giá trị độ và xoay toàn bộ biểu đồ mà không ảnh hưởng đến giá trị dữ liệu.

## Định dạng biểu đồ bánh tròn và tùy chỉnh giao diện

Ngoài việc chuyển thành donut, bạn thường muốn **format pie chart** các yếu tố:

- **Explode** lát đầu tiên (`setExplode`) để thu hút sự chú ý.  
- **Color** mỗi lát bằng cách sử dụng `getPoints().get(i).getFormat().setFillForegroundColor`.  
- Vị trí **Legend** (`setHasLegend`, `setPosition`) giúp người đọc giải thích các danh mục.  
- **Title** (`setTitle`) cung cấp ngữ cảnh ngay lập tức.  

Tất cả các cài đặt này là tùy chọn; bạn có thể điều chỉnh chúng để phù hợp với bảng màu thương hiệu hoặc mẫu công ty.

## Tạo tài liệu Word trống và lưu kết quả

Phương thức `createBlankWordDocument` bao gồm bước **create blank word document**. Giữ logic này riêng biệt giúp dễ dàng tái sử dụng phương thức khi tạo nhiều báo cáo trong quy trình batch. Sau khi tùy chỉnh, `doc.save` ghi tệp ở định dạng Office Open XML chuẩn (`.docx`), có thể mở trong Microsoft Word, LibreOffice hoặc Google Docs mà không mất độ chính xác.

### Kết quả mong đợi

Khi bạn chạy phương thức `main`, console sẽ in:

```
Document saved successfully.
```

Và tệp `output/DoughnutChartFormatted.docx` chứa một trang duy nhất với biểu đồ donut có tiêu đề *Quarterly Sales Distribution*. Biểu đồ hiển thị bốn lát, lát đầu tiên nổ, màu theo tông màu thương hiệu, và được xoay 45 độ.

## Các biến thể phổ biến và trường hợp đặc biệt

| Tình huống | Điều chỉnh |
|-----------|------------|
| **More than one data series** | Thêm các đối tượng `ChartSeries` bổ sung vào `chart.getSeries()`. |
| **Different chart size** | Thay đổi các đối số `width` và `height` trong `insertPieChart`. |
| **No hole (pure pie)** | Bỏ qua `chart.setHoleSize(…)` hoặc đặt nó thành `0`. |
| **Large documents** | Sử dụng `DocumentBuilder` để chèn biểu đồ vào một phần cụ thể hoặc bookmark. |
| **License not set** | Thư viện chạy ở chế độ đánh giá, thêm watermark trên trang đầu. Đăng ký giấy phép để loại bỏ. |

## Kết luận

Bây giờ bạn đã biết cách **create doughnut chart** trong tài liệu Word bằng Java, từ **create blank word document** đến **insert pie chart**, **rotate pie chart**, và **format pie chart** để có sản phẩm cuối cùng hoàn thiện. Ví dụ đầy đủ, có thể chạy được có thể được chèn vào bất kỳ dự án Java nào đã sử dụng Aspose.Words.

Tiếp theo, bạn có thể khám phá:

- Thêm nhãn dữ liệu (`chart.getSeries().get(0).setDataLabelType(DataLabelType.CATEGORY_AND_PERCENT);`)  
- Xuất biểu đồ dưới dạng hình ảnh (`chart.toImage`) để sử dụng trong email HTML  
- Tự động tạo nhiều tài liệu trong vòng lặp cho báo cáo hàng loạt  

Hãy thoải mái thử nghiệm màu sắc, việc nổ lát, và legend để phù hợp với ngôn ngữ trực quan của tổ chức bạn. Chúc bạn vẽ biểu đồ vui vẻ!
