# Hur man visar procenttal i diagram med Aspose.Words C#

Har du någonsin undrat **hur man visar procenttal i diagram** utan att kämpa med komplicerad Office‑interop? Du är inte ensam – många utvecklare stöter på detta när de behöver ett snabbt, programatiskt sätt att märka ett paj‑ eller donuts‑diagram. Den goda nyheten? Med Aspose.Words för .NET kan du aktivera dessa datamärkningar på bara några få rader kod.

I den här handledningen går vi också igenom **add data labels to pie chart** och **how to enable chart data labels** så att dina visualiseringar omedelbart blir mer insiktsfulla. När du är klar har du ett färdigt Word‑dokument (`.docx`) som visar ett snyggt paj‑diagram med procenttal placerade snyggt utanför varje segment.

## Förutsättningar

Innan vi dyker ner, se till att du har:

- **Aspose.Words for .NET** (senaste versionen, t.ex. 24.9) installerad via NuGet.  
- En **ChartTemplate.docx**‑fil som redan innehåller ett paj‑ eller donuts‑diagram.  
  *(Om du inte har en, skapa ett enkelt Word‑dokument, infoga ett paj‑diagram och spara det som `ChartTemplate.docx`.)*  
- .NET 6.0 eller senare och valfri IDE (Visual Studio, Rider, VS Code).

Inga extra beroenden krävs – Aspose.Words hanterar allt internt.

## Så visar du procenttal i diagram – Steg‑för‑steg

Nedan delar vi upp processen i sex tydliga steg. Varje steg innehåller exakt C#‑kod som du kan kopiera‑klistra in, samt en kort förklaring av **varför** vi gör det.

### Steg 1: Läs in källdokumentet

```csharp
using Aspose.Words;
using Aspose.Words.Drawing.Charts;

// Load the .docx that already holds a chart.
Document sourceDoc = new Document("YOUR_DIRECTORY/ChartTemplate.docx");
```

*Varför?*  
`Document` är startpunkten för all Word‑manipulation. Genom att läsa in mallen får vi åtkomst till varje nod – former, tabeller, text och naturligtvis diagrammet vi ska ändra.

### Steg 2: Hämta den första diagramformen

```csharp
// The chart lives inside a Shape node; retrieve it.
Chart chart = (Chart)sourceDoc.GetChild(NodeType.Shape, 0, true);
```

*Varför?*  
Aspose lagrar diagram som `Shape`‑objekt. `GetChild` går igenom dokumentträdet och returnerar den första form den hittar, vilket i vårt fall är paj‑diagrammet vi vill redigera.

### Steg 3: Bekräfta diagramtypen

```csharp
if (chart.ChartType == ChartType.Pie || chart.ChartType == ChartType.Doughnut)
{
    // Inside this block we’ll enable the data labels.
}
else
{
    throw new InvalidOperationException("The chart is not a Pie or Doughnut type.");
}
```

*Varför?*  
Procent‑etiketter har bara mening för cirkulära diagram. Detta skydd hindrar oss från att av misstag applicera inställningarna på t.ex. ett stapeldiagram där `ShowPercentage` skulle ignoreras.

### Steg 4: Aktivera datamärkningar och visa procenttal

```csharp
// Turn on data labels for the chart.
chart.HasDataLabel = true;

// Show the percentage value for each slice.
chart.DataLabel.ShowPercentage = true;
```

*Varför?*  
`HasDataLabel` talar om för Aspose att rendera en etikett för varje datapunkt. Genom att sätta `ShowPercentage` säkerställer vi att etikettens innehåll är den beräknade andelen av helheten – exakt det som **add data labels to pie chart**‑kravet efterfrågar.

### Steg 5: Placera etiketter utanför segmenten

```csharp
// Place the labels outside the pie slices for better readability.
chart.DataLabel.Position = ChartDataLabelPosition.OutSideEnd;
```

*Varför?*  
Etiketter inuti segment kan bli trånga, särskilt när segmenten är små. `OutSideEnd` efterliknar standardstilen “utanför” som du ser i Word‑gränssnittet och håller diagrammet rent.

### Steg 6: Spara det uppdaterade dokumentet

```csharp
sourceDoc.Save("YOUR_DIRECTORY/FormattedPieChart.docx");
```

*Varför?*  
Sparandet skriver tillbaka alla ändringar till en ny fil. Öppna `FormattedPieChart.docx` i Word så ser du procenttalen bredvid varje segment.

#### Förväntat resultat

När du öppnar `FormattedPieChart.docx` bör paj‑diagrammet se ut ungefär så här (fiktiv skärmdump):

```
[ Pie chart with three slices ]
- Slice A – 45%
- Slice B – 30%
- Slice C – 25%
```

Alla procenttal beräknas automatiskt från underliggande dataserier, och etiketterna sitter precis utanför varje segment.

## Vanliga variationer & kantfall

| Situation | Vad som måste justeras |
|-----------|------------------------|
| **Flera diagram** i samma dokument | Loopa igenom `sourceDoc.GetChildNodes(NodeType.Shape, true)` och kasta varje till `Chart` innan du applicerar samma logik. |
| **Stapeldiagram eller linjediagram** där du ändå vill ha etiketter | Använd `chart.DataLabel.ShowValue = true;` (eller `ShowSeriesName`) istället för `ShowPercentage`. |
| **Anpassat talformat** (t.ex. “45 %”) | Sätt `chart.DataLabel.NumberFormat = "0%";` innan du sparar. |
| **Stora dataset** som orsakar överlappning av etiketter | Överväg `chart.DataLabel.ShowLeaderLines = true;` för att rita förbindelselänkar. |

> **Pro tip:** Om du genererar många dokument i en batch, skapa ett enda `Aspose.Words.License`‑objekt vid applikationsstart för att undvika prestandakostnaden att ladda licensen upprepade gånger.

## Fullständigt fungerande exempel

Här är hela programmet sammansatt, redo att köras:

```csharp
using System;
using Aspose.Words;
using Aspose.Words.Drawing.Charts;

class Program
{
    static void Main()
    {
        // 1️⃣ Load the template document.
        Document sourceDoc = new Document("YOUR_DIRECTORY/ChartTemplate.docx");

        // 2️⃣ Retrieve the first chart shape.
        Chart chart = (Chart)sourceDoc.GetChild(NodeType.Shape, 0, true);

        // 3️⃣ Ensure we’re dealing with a Pie or Doughnut chart.
        if (chart.ChartType != ChartType.Pie && chart.ChartType != ChartType.Doughnut)
        {
            Console.WriteLine("The selected shape is not a Pie/Doughnut chart.");
            return;
        }

        // 4️⃣ Enable data labels and show percentages.
        chart.HasDataLabel = true;
        chart.DataLabel.ShowPercentage = true;

        // 5️⃣ Position the labels outside the slices.
        chart.DataLabel.Position = ChartDataLabelPosition.OutSideEnd;

        // 6️⃣ Save the modified document.
        sourceDoc.Save("YOUR_DIRECTORY/FormattedPieChart.docx");

        Console.WriteLine("Chart updated successfully – percentages now visible!");
    }
}
```

Kopiera koden, ersätt `YOUR_DIRECTORY` med den faktiska sökvägen på din maskin, och kör den. Du får en Word‑fil med ett fullt märkt paj‑diagram på några sekunder.

## Vad blir nästa steg?

- **Styla etiketterna** – ändra teckensnitt, färg eller lägg till en bakgrund med `chart.DataLabel.Font`.  
- **Skapa diagram från grunden** – utforska `Chart chart = (Chart)sourceDoc.FirstSection.Body.AppendChild(new Shape(sourceDoc, ShapeType.Chart));` för att programatiskt generera diagram.  
- **Kombinera flera diagram** i ett enda dokument för instrumentpaneler, och exportera sedan till PDF med `sourceDoc.Save("Dashboard.pdf", SaveFormat.Pdf);`.
