# Skapa fakturamall och slå ihop data med Aspose.Words

Om du snabbt behöver **skapa fakturamall**, visar den här guiden exakt hur. Efter de första två meningarna kommer du att känna till hela arbetsflödet för att omvandla en tom Word‑fil till en fullt ifylld faktura, med hjälp av Aspose.Words låg‑kod mail‑merge‑API.

Att generera fakturor är ett vanligt krav för faktureringssystem, ERP‑integrationer och automatiserad rapportering. I den här handledningen kommer du att lära dig **hur man mail‑mergar**, **fylla i Word‑mall**, **slå ihop data i Word**, och slutligen **spara det sammanslagna dokumentet** — allt med några få C#‑rader.

## Vad du kommer att uppnå

* En återanvändbar Word‑mall (`InvoiceTemplate.docx`) som innehåller sammanslagningsfält för kund, datum, radposter och total.  
* Ett C#‑program som laddar mallen, injicerar ett starkt typat dataobjekt och skriver resultatet till `Invoice_001.docx`.  
* Insikt i kantfall såsom tomma samlingar, anpassade datatyper och hantering av filsökvägar.

### Förutsättningar

| Requirement | Why it matters |
|-------------|----------------|
| .NET 6 or later | Aspose.Words för .NET stödjer .NET 6+ och tillhandahåller den låg‑kod API som används i den här guiden. |
| Aspose.Words for .NET NuGet package (`Aspose.Words`) | Tillhandahåller `Document`, `MailMerger` och relaterade typer. |
| Basic C# knowledge | Behövs för att förstå anonyma objekt och LINQ. |
| Visual Studio 2022 (or any IDE) | Gör redigering och felsökning enkel. |

> **Pro tip:** Installera NuGet‑paketet via Package Manager Console:  
> `Install-Package Aspose.Words`

## Så skapar du fakturamall med låg‑code mail merge

Det första steget är att skapa en Word‑fil som innehåller sammanslagningsfält som matchar egenskaperna i det dataobjekt du senare kommer att skicka. Spara filen som `InvoiceTemplate.docx` i en mapp du kontrollerar (t.ex. `C:\Invoices\Template`).

| Sammanslagningsfält | Exempelplatshållare i Word |
|-------------|-----------------------------|
| CustomerName | «CustomerName» |
| InvoiceDate | «InvoiceDate» |
| Items (repeating) | «Items.Description», «Items.Qty», «Items.Price» |
| Total | «Total» |

> **Varför detta är viktigt:** Låg‑kod‑API:t mappar automatiskt egenskapsnamnen i datakällan till sammanslagningsfälten. Att hålla namnen identiska eliminerar manuell fält‑till‑egenskap‑mappning och minskar körningsfel.

## Steg 1: Ladda fakturamallen

```csharp
using Aspose.Words;
using Aspose.Words.LowCode;   // Low‑code mail‑merge API

// Load the Word file that contains the merge fields.
Document template = new Document(@"C:\Invoices\Template\InvoiceTemplate.docx");
```

*`Document`‑klassen representerar hela Word‑filen. Att ladda den en gång låter dig återanvända samma mall för många fakturor.*

## Steg 2: Förbered datakällan

Skapa ett anonymt objekt som speglar sammanslagningsfälten. Låg‑kod‑API:t kan arbeta med vilket .NET‑objekt som helst, inklusive arrayer och nästlade samlingar.

```csharp
var invoiceData = new
{
    CustomerName = "Acme Corp",
    InvoiceDate = DateTime.Today,
    Items = new[]
    {
        new { Description = "Widget A", Qty = 10, Price = 9.99M },
        new { Description = "Widget B", Qty = 5,  Price = 19.95M }
    },
    Total = 199.85M
};
```

**Varför detta fungerar:**  
* Egenskapsnamnen (`CustomerName`, `InvoiceDate`, `Items`, `Total`) matchar sammanslagningsfälten i mallen.  
* `Items` är en array av objekt, så mail‑mergern kommer automatiskt att upprepa tabellraden för varje element.  
* Att använda `decimal` (`M`‑suffix) för monetära värden undviker flyttalsavrundningsproblem.

### Hantera tomma samlingar

Om en faktura saknar radposter, skicka en tom array:

```csharp
Items = new object[0]
```

Låg‑kod‑motorn kommer helt enkelt att utelämna den upprepande sektionen, och låta tabellrubriken intakt.

## Steg 3: Initiera låg‑code mail merger

```csharp
MailMerger merger = new MailMerger(template);
```

`MailMerger` är ingångspunkten för **hur man mail‑mergar** med Aspose.Words. Den läser mallen, binder data och förbereder det slutgiltiga dokumentet i ett enda anrop.

## Steg 4: Utför sammanslagningen – fyll i Word‑mallen i en rad

```csharp
Document mergedDocument = merger.Execute(invoiceData);
```

* Denna rad **fyller i Word‑mallen** och skapar en ny `Document`‑instans (`mergedDocument`).  
* Alla sammanslagningsfält ersätts, upprepande sektioner expanderas, och det resulterande dokumentet finns helt i minnet.

### Kantfall: Anpassad formatering

Om du behöver ett specifikt datumformat, lägg till en anpassad formatterare före sammanslagningen:

```csharp
merger.Options.DateFormat = "MMMM dd, yyyy"; // e.g., "October 07, 2026"
```

## Steg 5: Spara det sammanslagna dokumentet

```csharp
mergedDocument.Save(@"C:\Invoices\Output\Invoice_001.docx");
```

Anropet **save merged document** skriver den fullt ifyllda fakturan till disk. Filen kan nu öppnas i Microsoft Word, skickas som e‑postbilaga eller konverteras till PDF.

### Verifiera resultatet

Öppna `Invoice_001.docx`. Du bör se:

* **CustomerName** ersatt med *Acme Corp*  
* **InvoiceDate** visar dagens datum i det valda formatet  
* En tabellrad för *Widget A* (10 × 9.99) och *Widget B* (5 × 19.95)  
* **Total** visar *199.85*  

Om något fält förblir oförändrat (t.ex. fortfarande visar «CustomerName»), dubbelkolla att egenskapsnamnen exakt matchar sammanslagningsfältnamnen i mallen.

## Fullt körbart exempel

Nedan är det kompletta programmet som du kan kopiera‑klistra in i ett nytt konsolprojekt.

```csharp
using System;
using Aspose.Words;
using Aspose.Words.LowCode;   // Low‑code mail‑merge API

namespace InvoiceGenerator
{
    class Program
    {
        static void Main()
        {
            // 1️⃣ Load the template
            Document template = new Document(@"C:\Invoices\Template\InvoiceTemplate.docx");

            // 2️⃣ Build the data source
            var invoiceData = new
            {
                CustomerName = "Acme Corp",
                InvoiceDate = DateTime.Today,
                Items = new[]
                {
                    new { Description = "Widget A", Qty = 10, Price = 9.99M },
                    new { Description = "Widget B", Qty = 5,  Price = 19.95M }
                },
                Total = 199.85M
            };

            // 3️⃣ Initialise the mail merger
            MailMerger merger = new MailMerger(template);

            // Optional: customise date format
            merger.Options.DateFormat = "MMMM dd, yyyy";

            // 4️⃣ Perform the merge (populate word template)
            Document mergedDocument = merger.Execute(invoiceData);

            // 5️⃣ Save the resulting file (save merged document)
            mergedDocument.Save(@"C:\Invoices\Output\Invoice_001.docx");

            Console.WriteLine("Invoice generated successfully.");
        }
    }
}
```

Kör programmet (`dotnet run`). Konsolen skriver ut *Invoice generated successfully.* och filen visas i `C:\Invoices\Output`.
