# Skapa ett tomt Word-dokument och dölja en ellipsform i C#

Om du behöver **skapa ett tomt Word-dokument** och sedan dölja ett grafiskt element, visar den här guiden exakt hur du gör det med C#. Du får ett komplett, körbart exempel som infogar en ellips, placerar den, markerar den som dold och sparar filen – allt på några rader kod.

Handledningen täcker allt från projektuppsättning till det sista verifieringssteget. När du är klar kan du generera en Word‑fil där ellipsen aldrig visas på skärmen eller i utskrift, vilket är användbart för att lagra metadata, bokmärken eller någon annan osynlig markör.

## Förutsättningar

Innan du börjar, se till att du har:

* .NET 6.0 SDK eller senare installerad  
* En C#‑utvecklingsmiljö (Visual Studio 2022, Rider eller VS Code)  
* **Aspose.Words for .NET**‑paketet via NuGet (`Install-Package Aspose.Words`)  

Dessa verktyg tillhandahåller klasserna `Document` och `DocumentBuilder` som används i kodexemplet.

## Steg 1: Skapa ett tomt Word-dokument

Den första operationen skapar ett tomt `Document`‑objekt och en `DocumentBuilder` som låter dig lägga till innehåll.

```csharp
using Aspose.Words;
using Aspose.Words.Drawing;

// Step 1: Initialize an empty document and a builder
Document doc = new Document();
DocumentBuilder builder = new DocumentBuilder(doc);
```

`Document` representerar hela `.docx`‑paketet, medan `DocumentBuilder` erbjuder ett flytande API för att infoga text, former och andra objekt. Att börja med ett tomt dokument ger dig full kontroll över varje element du lägger till.

## Steg 2: Så infogar du en ellips

En ellips är en vektorform som kan användas som markör. Metoden `InsertShape` kräver formtypen samt dess bredd/höjd i punkter.

```csharp
// Step 2: Insert an ellipse shape of the desired size (100 pt × 50 pt)
Shape ellipse = builder.InsertShape(ShapeType.Ellipse, 100, 50);
```

Ellipsen placeras på den aktuella sidan vid markörens position. Du kan ändra dess dimensioner genom att justera de numeriska argumenten.

## Steg 3: Så positionerar du formen

Efter infogning kan du flytta formen var som helst på sidan genom att sätta egenskaperna `Left` och `Top`, som använder punkter relativt till sidmarginalen.

```csharp
// Step 3: Position the shape on the page
ellipse.Left = 150; // distance from the left margin
ellipse.Top  = 100; // distance from the top margin
```

Dessa koordinater placerar ellipsen ungefär i övre‑mitten av en standard A4‑sida. Justera värdena för att passa ditt layoutbehov.

## Steg 4: Så döljer du formen

Ett dolt objekt visas inte när dokumentet öppnas eller skrivs ut. Genom att sätta flaggan `Hidden` markeras formen som ett **dolt objekt**.

```csharp
// Step 4: Hide the shape so it never appears
ellipse.Hidden = true;
```

Word respekterar den dolda flaggan både för skärmrendering och utskriftsoutput. Formen förblir en del av dokumentstrukturen, så du kan senare fråga efter eller modifiera den via kod.

## Steg 5: Spara dokumentet

Till sist skriver du dokumentet till disk. Välj en mapp där du har skrivrättigheter.

```csharp
// Step 5: Save the document to a .docx file
doc.Save(@"C:\Temp\HiddenEllipse.docx");
```

Filen `HiddenEllipse.docx` innehåller nu en tom sida med en dold ellipsform.

## Verifiera den dolda ellipsen

Öppna den genererade filen i Microsoft Word och aktivera alternativet **Visa dold text** (File → Options → Display). Du kommer då att se en svag kontur av ellipsen. Om du stänger av alternativet försvinner formen helt, vilket bekräftar att `ellipse.Hidden = true` fungerar som förväntat.

## Vanliga variationer och kantfall

| Situation | Rekommenderad justering |
|-----------|------------------------|
| **Olika form** | Byt ut `ShapeType.Ellipse` mot `ShapeType.Rectangle`, `ShapeType.Arrow` osv. |
| **Flera dolda objekt** | Upprepa steg 2‑4 för varje form; varje kan ha sin egen `Hidden`‑flagga. |
| **Olika sidstorlek** | Sätt `doc.FirstSection.PageSetup.PageWidth` och `PageHeight` innan du infogar formen. |
| **Villkorlig synlighet** | Använd `Shape.Visible` i kombination med `Hidden` för att växla vid körning via kod. |

**Proffstips:** Lagra identifieringsdata i formens `AlternativeText`‑egenskap. Även när den är dold kan du hämta formen senare med `doc.GetChildNodes(NodeType.Shape, true)` och filtrera på den texten.

## Fullständig källkod

Nedan är hela programmet som du kan kopiera, klistra in och köra.

```csharp
using System;
using Aspose.Words;
using Aspose.Words.Drawing;

namespace HiddenShapeDemo
{
    class Program
    {
        static void Main()
        {
            // Create a new blank document and a builder
            Document doc = new Document();
            DocumentBuilder builder = new DocumentBuilder(doc);

            // Insert an ellipse shape (100 pt × 50 pt)
            Shape ellipse = builder.InsertShape(ShapeType.Ellipse, 100, 50);

            // Position the shape on the page
            ellipse.Left = 150;
            ellipse.Top  = 100;

            // Hide the shape so it is invisible in the UI and on print
            ellipse.Hidden = true;

            // Optional: add a description for later retrieval
            ellipse.AlternativeText = "Hidden marker for internal processing";

            // Save the document
            string outputPath = @"C:\Temp\HiddenEllipse.docx";
            doc.Save(outputPath);

            Console.WriteLine($"Document saved to {outputPath}");
        }
    }
}
```

**Förväntad utskrift:** Konsolen skriver ut sparvägen, och filen `HiddenEllipse.docx` öppnas som en tom sida utan synlig grafik såvida inte dolda objekt visas.

## Slutsats

Du vet nu hur du **skapar ett tomt Word-dokument** programatiskt, **infogar en ellips**, **positionerar formen** och **döljer formen** så att den beter sig som ett **dolt objekt**. Denna teknik är idealisk för att bädda in osynliga markörer, anpassad metadata eller platshållare som efterföljande processer kan läsa utan att påverka dokumentets visuella layout.

### Nästa steg

* Utforska andra formtyper (`ShapeType.Arrow`, `ShapeType.TextBox`) för att bädda in olika markörer.  
* Kombinera dolda former med anpassade XML‑delar för rikare metadata‑lagring.  
* Integrera denna kod i en större automatiseringspipeline som genererar rapporter eller kontrakt.

Känn dig fri att experimentera med koordinater, dimensioner och den dolda flaggan för att passa ditt specifika scenario. Lycka till med kodandet!
