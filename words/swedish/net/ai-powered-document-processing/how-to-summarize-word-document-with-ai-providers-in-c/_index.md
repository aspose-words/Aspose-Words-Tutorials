# Så sammanfattar du Word-dokument med AI-leverantörer i C#

Om du snabbt behöver **sammanfatta Word-dokument** visar den här guiden exakt hur. Du får ett komplett, körbart exempel som låter dig **välja AI-leverantör** (OpenAI eller Google) och hantera ett **sammanfatta stort dokument**-scenario utan att lämna din IDE.

Att sammanfatta ett Word-dokument är en vanlig uppgift när du bygger kunskapsbas‑botar, rapport‑sammanfattningar eller automatiserade e‑post‑briefs. I avsnitten nedan lär du dig vilket NuGet‑paket du ska installera, hur du läser in en `.docx`‑fil, konfigurerar sammanfattaren och skriver ut resultatet – allt i ren C#.

## Vad du behöver

| Krav | Anledning |
|------|-----------|
| .NET 6 SDK eller senare | Tillhandahåller runtime för C#‑exemplet |
| Visual Studio 2022 (eller någon IDE) | Gör det enkelt att lägga till NuGet‑paket och köra konsolappen |
| `GroupDocs.Summarization` NuGet‑paket | Tillhandahåller `DocumentSummarizer`‑API:t som används i koden |
| En internetanslutning | Krävs för att AI‑leverantören (OpenAI eller Google) ska kunna bearbeta texten |

> **Proffstips:** Om du planerar att **sammanfatta stora dokument** (över 100 KB), aktivera streaming‑läget i alternativen för att undvika att läsa in hela filen i minnet.

## Så sammanfattar du Word-dokument steg för steg

### Steg 1: Installera sammanfattningsbiblioteket

Öppna Package Manager Console och kör:

```powershell
Install-Package GroupDocs.Summarization
```

`GroupDocs.Summarization`‑biblioteket abstraherar de underliggande AI‑anropen, så du kan byta leverantör utan att ändra din affärslogik.

### Steg 2: Läs in Word-dokumentet

```csharp
using GroupDocs.Summarization;
using GroupDocs.Summarization.Options;

// Step 2: Load the source document
Document doc = new Document("YOUR_DIRECTORY/Report.docx");
```

`Document`‑klassen läser `.docx`‑filen och förbereder den för sammanfattning. Om filen är stor använder biblioteket automatiskt en minnes‑effektiv parser.

### Steg 3: Konfigurera sammanfattningsalternativ och **välja AI-leverantör**

```csharp
// Step 3: Set up summarization options (choose the AI provider)
SummarizerOptions options = new SummarizerOptions
{
    Provider = SummarizerProvider.OpenAI   // or SummarizerProvider.Google
};
```

- `Provider = SummarizerProvider.OpenAI` väljer OpenAI:s GPT‑4‑modell.  
- `Provider = SummarizerProvider.Google` väljer Googles Gemini‑modell, vilket är idealiskt när du **sammanfattar med Google** för bättre flerspråkigt stöd.

Du **väljer AI-leverantör** baserat på kostnad, latens eller språkkrav. Samma `options`‑objekt fungerar för båda leverantörerna, vilket håller koden ren.

### Steg 4: Generera sammanfattningen – stöd för **sammanfatta stort dokument**

```csharp
// Step 4: Generate the summary using the selected provider
string summary = DocumentSummarizer.Summarize(doc, options);
```

När du **sammanfattar stora dokument** strömmar biblioteket innehållet till AI‑tjänsten, vilket förhindrar minnesfel. Metoden `Summarize` returnerar en ren‑text‑sträng som innehåller de mest relevanta meningarna.

### Steg 5: Skriv ut resultatet

```csharp
// Step 5: Output the generated summary
Console.WriteLine("Summary:\n" + summary);
```

När programmet körs skrivs ett koncist stycke ut som fångar essensen av den ursprungliga Word‑filen.

## Fullt körbart exempel

```csharp
using System;
using GroupDocs.Summarization;
using GroupDocs.Summarization.Options;

namespace WordSummarizerDemo
{
    class Program
    {
        static void Main(string[] args)
        {
            // Load the source Word document
            Document doc = new Document("YOUR_DIRECTORY/Report.docx");

            // Choose the AI provider (OpenAI or Google)
            SummarizerOptions options = new SummarizerOptions
            {
                Provider = SummarizerProvider.Google   // Change to OpenAI if you prefer
            };

            // Generate the summary – works for both small and large documents
            string summary = DocumentSummarizer.Summarize(doc, options);

            // Display the summary in the console
            Console.WriteLine("Summary:\n" + summary);
        }
    }
}
```

**Förväntad utskrift**

```
Summary:
The quarterly sales increased by 12% driven by the new product line, while operational costs fell 3% due to efficiency gains. The report also highlights upcoming market expansion in APAC and recommends allocating additional budget to R&D.
```

Den exakta formuleringen kommer att variera beroende på vilken AI‑modell du **väljer AI-leverantör**, men strukturen förblir densamma.

## Hantera ett **sammanfatta stort dokument**-scenario

När käll‑`.docx`‑filen överstiger 5 MB, överväg följande justeringar:

1. **Aktivera chunking** – biblioteket delar upp dokumentet i 5 KB‑block innan de skickas till AI‑tjänsten.  
2. **Öka `MaxSentences`** i `SummarizerOptions` om du behöver en längre sammanfattning.  
3. **Sätt `Timeout`** till ett högre värde för att hantera längre bearbetningstider.

```csharp
options.MaxSentences = 8;          // Return up to 8 sentences
options.EnableChunking = true;    // Essential for very large files
options.Timeout = TimeSpan.FromMinutes(2);
```

Dessa justeringar säkerställer att **sammanfatta stort dokument**‑operationen förblir snabb och pålitlig.

## Så **sammanfattar du med Google** effektivt

Googles Gemini‑modell utmärker sig på flerspråkigt innehåll och koncisa formuleringar. För bästa resultat:

- **Ange språk** (valfritt) om dokumentet innehåller icke‑engelsk text:  
  ```csharp
  options.Language = "es"; // Spanish
  ```
- **Justera temperatur** för att kontrollera kreativiteten:  
  ```csharp
  options.Temperature = 0.3; // More deterministic output
  ```

När du **sammanfattar med Google** kan tjänsten returnera en något kortare men mycket fokuserad sammanfattning jämfört med OpenAI. Testa båda leverantörerna på ett provdokument för att avgöra vilken som passar ditt projekt bäst.

## Vanliga fallgropar och hur du undviker dem

| Symptom | Orsak | Åtgärd |
|---------|-------|--------|
| Tom sammanfattning | Leverantörsnyckel saknas eller nätverk blockerat | Verifiera API‑nycklar i miljövariabler och säkerställ att utgående HTTPS är tillåtet |
| Avklippt text | Dokumentet överskrider leverantörens token‑gräns | Aktivera `EnableChunking` eller öka `MaxTokens` om biblioteket stödjer det |
| Oväntat språk | Fel `Language`‑alternativ | Ta bort alternativet eller sätt det till dokumentets faktiska språk |

Att hantera dessa problem tidigt sparar debug‑tid, särskilt när du **väljer AI-leverantör** för produktionsarbetsbelastningar.

Experimentera med `MaxSentences`, `Temperature` och chunk‑inställningar för att finjustera resultatet för ditt specifika scenario.
