# Så skapar du ett stapeldiagram i Python med Aspose.Words

Om du behöver skapa ett stapeldiagram i Python visar den här guiden exakt kod och resonemang du behöver. Med Aspose.Words diagram‑API kan du definiera exakta dimensioner, tillämpa en inbyggd stil och exportera resultatet utan att lämna Python.

Att generera ett stapeldiagram är ett vanligt krav för rapporter, instrumentpaneler och automatiserad dokumentgenerering. Denna handledning täcker varje steg—från att importera biblioteket till att verifiera den sparade bilden—så att du kan integrera diagramgenerering i vilket Python‑projekt som helst.

## Förutsättningar

* Python 3.8 eller nyare installerat.
* En giltig Aspose.Words för Python‑licens (eller en gratis utvärderingsnyckel).
* Grundläggande kunskap om Python‑moduler och objektorienterad kod.

Aspose.Words diagram‑motor fungerar på Windows, macOS och Linux, och den kräver inga extra grafiska bibliotek eftersom rendering sker på serversidan.

## Steg 1: Importera Aspose.Words‑biblioteket

Det första steget är att importera paketet `aspose.words` och ge det ett kort alias. Att importera högst upp i filen håller namnrymden ren och gör koden lättare att läsa.

```python
# Step 1: Import the Aspose.Words library
import aspose.words as aw
```

`aw` refererar nu till hela Aspose.Words‑API:et, inklusive `Chart`‑klassen som du kommer att använda för att bygga stapeldiagrammet.

## Steg 2: Skapa ett stapeldiagram med önskade dimensioner

Ett stapeldiagram kräver explicita bredd‑ och höjdvärden så att den renderade bilden passar ditt dokumentlayout. `Chart`‑konstruktorn tar tre argument: diagramtypen, bredden (i punkter) och höjden (i punkter). Genom att använda `aw.ChartType.COLUMN` talar du om för motorn att generera ett vertikalt stapeldiagram.

```python
# Step 2: Create a column chart with the desired dimensions
chart = aw.Chart(aw.ChartType.COLUMN, 400, 300)   # width=400pt, height=300pt
```

*Varför ange dimensioner?*  
När du bäddar in diagrammet i ett Word‑dokument eller exporterar det som en bild, respekterar det omgivande innehållet den exakta storlek du anger. Detta förhindrar oönskad skalning eller beskärning.

### Proffstips: Använd `chart.dimensions` för dynamisk storleksändring

Om din datamängd varierar kan du beräkna storleken baserat på antalet serier:

```python
series_count = 5
base_width = 80
chart.width = base_width * series_count
chart.height = 300
```

## Steg 3: Tillämpa en inbyggd stil på stapeldiagrammet

Aspose.Words levereras med flera fördefinierade visuella teman. Att välja en stil tar bort behovet av att manuellt konfigurera färger, typsnitt och rutnät. `aw.ChartStyle.STYLE_5` är ett rent, professionellt utseende som passar de flesta affärsrapporter.

```python
# Step 3: Apply a built‑in style to the chart
chart.style = aw.ChartStyle.STYLE_5
```

Om du föredrar ett annat utseende, ersätt `STYLE_5` med någon av de andra konstanterna (`STYLE_1` … `STYLE_8`). Varje stil följer samma namngivningskonvention, vilket gör det enkelt att experimentera.

### Edge case: Ogiltig stilkonstant

Att försöka tilldela en icke‑existerande stil resulterar i ett `AttributeError`. Skydda dig mot detta genom att kontrollera konstanten mot uppräkningen:

```python
if hasattr(aw.ChartStyle, "STYLE_5"):
    chart.style = aw.ChartStyle.STYLE_5
else:
    raise ValueError("Requested chart style does not exist.")
```

## Steg 4: Lägg till dataserier i stapeldiagrammet

Ett diagram utan data är meningslöst. Du kan lägga till ett eller flera `ChartSeries`‑objekt, där varje representerar en stapelgrupp. Följande exempel lägger till en enda serie med tre datapunkter.

```python
# Step 4: Add data series to the column chart
series = chart.series.add()
series.name = "Quarterly Sales"
series.data = [12000, 15000, 18000]   # Values for Q1, Q2, Q3
```

Du kan upprepa anropet `chart.series.add()` för att inkludera ytterligare serier (t.ex. “Projected Sales”). API‑et distribuerar automatiskt kolumner sida‑vid‑sida.

## Steg 5: Rendera diagrammet och spara det som en bild

Efter att ha konfigurerat diagrammet renderar du det till en bitmap eller en bildfil. `save`‑metoden accepterar en filsökväg och ett valfritt format. PNG är förlustfritt och brett stödjat.

```python
# Step 5: Render and save the chart as a PNG image
output_path = "column_chart.png"
chart.save(output_path, aw.SaveFormat.PNG)
print(f"Chart saved to {output_path}")
```

`SaveFormat`‑uppräkningen inkluderar PNG, JPEG, BMP och andra. Välj det format som matchar ditt efterföljande arbetsflöde.

## Verifiera resultatet

Öppna `column_chart.png` med någon bildvisare. Du bör se ett stapeldiagram med tre kolumner, stylat med det valda inbyggda temat, med exakt storlek 400 × 300 punkter.

![Column chart generated by Aspose.Words in Python](column_chart.png){: .center alt="Skärmbild av ett stapeldiagram genererat av Aspose.Words i Python"}

Om bilden visas tom eller förvrängd, dubbelkolla följande:

1. `aw.Chart`‑objektet skapades innan serier lades till.
2. `chart.style`‑konstanten matchar ett befintligt enum‑värde.
3. `save`‑anropet använder ett stödjt `SaveFormat`.

## Vanliga variationer och ytterligare tips

| Situation | Rekommenderad ändring |
|-----------|-----------------------|
| **Flera dataserier** | Lägg till ytterligare `chart.series.add()`‑block och sätt `series.name` och `series.data` för varje. |
| **Anpassade färger** | Efter att ha tillämpat en inbyggd stil, åsidosätt individuella kolorfärger via `series.points[i].fill.fore_color`. |
| **Inbäddning i ett Word‑dokument** | Istället för `chart.save()`, använd `doc = aw.Document(); doc.sections[0].body.append_child(chart); doc.save("report.docx")`. |
| **Dynamisk storlek** | Beräkna bredden baserat på antalet serier (`width = 80 * len(chart.series)`). |
