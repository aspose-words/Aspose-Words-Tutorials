# Hur man exporterar markdown och återställer en korrupt DOCX med Aspose.Words

Om du behöver **how to export markdown** från en Word‑fil som kan vara skadad, visar den här guiden dig de exakta stegen. Den täcker också **how to recover document**‑problem, **export docx to txt**, och **save word as pdf** med Aspose.Words för Python‑API.

Du kommer att gå igenom att ladda en eventuellt korrupt DOCX i återställningsläge, konvertera den till Markdown samtidigt som ekvationer bevaras, spara samma innehåll som ren text, generera en tillgänglig PDF och till och med justera en formskugga innan den slutgiltiga exporten. Inga externa verktyg krävs—bara Aspose.Words och några rader Python.

## Förutsättningar

* Python 3.8 eller nyare
* `aspose-words`‑paketet (`pip install aspose-words`)
* En DOCX‑fil som kan vara korrupt (eller vilken vanlig DOCX som helst för testning)
* Grundläggande kunskap om Python‑funktioner och -klasser

> **Pro tip:** Behåll en säkerhetskopia av den ursprungliga DOCX‑filen; återställningsläget ändrar representationen i minnet men skriver aldrig tillbaka till källfilen.

## Steg 1: Hur man återställer en korrupt DOCX

Det första hindret är att ladda filen på ett säkert sätt. Aspose.Words tillhandahåller en `RecoveryMode.RECOVER_CORRUPTED`‑flagga som försöker återskapa en trasig dokumentstruktur.

```python
import aspose.words as aw

# Load the file in recovery mode
load_opts = aw.LoadOptions()
load_opts.recovery_mode = aw.RecoveryMode.RECOVER_CORRUPTED
doc = aw.Document("YOUR_DIRECTORY/input.docx", load_opts)
```

**Varför detta är viktigt:**  
När en DOCX är delvis skadad—saknade delar, trasig XML eller felaktiga relationer—kastar standardladdning ett undantag. Återställningsläget parsar det den kan, kastar bort oläsliga fragment samtidigt som resten bevaras, vilket är avgörande för alla efterföljande **export docx to txt**‑ eller **save word as pdf**‑operationer.

### Vanligt specialfall
Om dokumentet är bortom reparation kommer `doc` fortfarande att skapas men med en varningslogg. Du kan inspektera `doc.is_dirty` för att se om något innehåll ändrades under återställningen.

## Steg 2: Hur man exporterar markdown med Aspose.Words

Markdown är ett lättviktigt markeringsspråk som många statiska webbplatsgeneratorer och dokumentationsverktyg älskar. Aspose.Words kan generera Markdown samtidigt som ekvationer behålls som LaTeX, vilket är perfekt för teknisk dokumentation.

```python
# Configure Markdown export options
md_opts = aw.MarkdownSaveOptions()
md_opts.office_math_export_mode = aw.OfficeMathExportMode.LATEX

# Save as Markdown
doc.save("YOUR_DIRECTORY/output.md", md_opts)
```

**Vad du får:**  
* Ren text med rubriker, listor och tabeller konverterade till Markdown‑syntax.  
* Varje Word‑ekvation renderas som ett LaTeX‑block (`$$ … $$`), vilket säkerställer att matematik förblir redigerbar i efterföljande verktyg.

### Verifiera resultatet
Öppna `output.md` i någon editor. Du bör se något liknande:

```markdown
# Title of the Document

This is a paragraph with **bold** text.

$$
\int_{0}^{\infty} e^{-x} dx = 1
$$
```

Om du behöver ett annat ekvationsformat (t.ex. MathML), ändra `office_math_export_mode` därefter.

## Steg 3: Exportera docx till txt samtidigt som ekvationer bevaras

Ren‑textfiler är användbara för snabba sökningar eller för att mata in i naturliga språk‑pipelines. Samma `OfficeMathExportMode.LATEX` fungerar för `.txt`‑export, vilket ger dig läsbar LaTeX inline.

```python
txt_opts = aw.TxtSaveOptions()
txt_opts.office_math_export_mode = aw.OfficeMathExportMode.LATEX

doc.save("YOUR_DIRECTORY/output.txt", txt_opts)
```

**Varför använda detta istället för kopiera‑och‑klistra?**  
Manuell kopiering och inklistring tar ofta bort dolda tecken och förlorar ekvationsnoggrannhet. Denna **export docx to txt**‑metod garanterar att varje ekvation visas som ett LaTeX‑snutt, redo för vidare bearbetning.

## Steg 4: Spara Word som PDF med inline‑former för bättre tillgänglighet

PDF är det de‑facto formatet för publicering. När ett Word‑dokument innehåller flytande bilder eller diagram kan vissa läsare tolka dem felaktigt. Genom att sätta `export_floating_shapes_as_inline_tag` tvingas dessa former att bli inline, vilket förbättrar tillgänglighet och layoutkonsistens.

```python
pdf_opts = aw.PdfSaveOptions()
pdf_opts.export_floating_shapes_as_inline_tag = True

doc.save("YOUR_DIRECTORY/output.pdf", pdf_opts)
```

**Resultat:**  
En PDF som speglar den ursprungliga layouten, men alla former är nu en del av textflödet. Detta är särskilt hjälpsamt för skärmläsare, eftersom de behandlar inline‑element som en del av läsordningen.

### Tips för stora dokument
Om du genererar PDF‑filer i batch, återanvänd samma `PdfSaveOptions`‑instans för att undvika onödig objektskapande.

## Steg 5: Finjustera en forms skugga innan den slutgiltiga PDF‑en

Ibland behöver du justera visuella detaljer—som en logotyps skugga—innan publicering. Exemplet nedan hämtar den första formen, ändrar dess skuggegenskaper och sparar en ny PDF.

```python
# Retrieve the first shape in the document
shape = doc.get_child(aw.NodeType.SHAPE, 0, True).as_shape()

# Adjust shadow settings
shape.shadow.blur_radius = 5.0   # Soft blur
shape.shadow.distance = 2.0     # Distance from shape edge
shape.shadow.opacity = 0.6      # 60% opacity

# Save the shadow‑enhanced PDF
doc.save("YOUR_DIRECTORY/shadowed.pdf", pdf_opts)
```

**Vad detta gör:**  
* `blur_radius` styr hur suddig skuggan ser ut.  
* `distance` flyttar skuggan bort från formen, vilket skapar djup.  
* `opacity` gör skuggan halvtransparent, vilket ofta ser mer professionellt ut.

Du kan upprepa detta block för vilken form som helst genom att ändra indexet i `get_child`.

## Fullt skript för snabb kopiera‑och‑klistra

Nedan är det kompletta, körbara skriptet som kombinerar alla steg. Ersätt `YOUR_DIRECTORY` med sökvägen där dina filer finns.

```python
import aspose.words as aw

# -------------------------------------------------
# 1️⃣ Recover a possibly corrupted DOCX
# -------------------------------------------------
load_opts = aw.LoadOptions()
load_opts.recovery_mode = aw.RecoveryMode.RECOVER_CORRUPTED
doc = aw.Document("YOUR_DIRECTORY/input.docx", load_opts)

# -------------------------------------------------
# 2️⃣ Export to Markdown (how to export markdown)
# -------------------------------------------------
md_opts = aw.MarkdownSaveOptions()
md_opts.office_math_export_mode = aw.OfficeMathExportMode.LATEX
doc.save("YOUR_DIRECTORY/output.md", md_opts)

# -------------------------------------------------
# 3️⃣ Export to plain text (export docx to txt)
# -------------------------------------------------
txt_opts = aw.TxtSaveOptions()
txt_opts.office_math_export_mode = aw.OfficeMathExportMode.LATEX
doc.save("YOUR_DIRECTORY/output.txt", txt_opts)

# -------------------------------------------------
# 4️⃣ Save as PDF (save word as pdf)
# -------------------------------------------------
pdf_opts = aw.PdfSaveOptions()
pdf_opts.export_floating_shapes_as_inline_tag = True
doc.save("YOUR_DIRECTORY/output.pdf", pdf_opts)

# -------------------------------------------------
# 5️⃣ Adjust first shape's shadow and re‑save PDF
# -------------------------------------------------
shape = doc.get_child(aw.NodeType.SHAPE, 0, True).as_shape()
shape.shadow.blur_radius = 5.0
shape.shadow.distance = 2.0
shape.shadow.opacity = 0.6
doc.save("YOUR_DIRECTORY/shadowed.pdf", pdf_opts)
```

Att köra skriptet producerar:

| File | Purpose |
|------|---------|
| `output.md` | Markdown med LaTeX‑ekvationer (**how to export markdown**) |
| `output.txt` | Ren‑textversion (**export docx to txt**) |
| `output.pdf` | Tillgänglig PDF (**save word as pdf**) |
| `shadowed.pdf` | PDF med en anpassad formstil |

## Vanliga frågor

**Q: Fixar återställningsläget saknade bilder?**  
A: Det återställer dokumentstrukturen men kan inte återskapa förlorad binär bilddata. Om en bilddel saknas blir formen tom.

**Q: Kan jag exportera till HTML istället för Markdown?**  
A: Ja—använd `aw.HtmlSaveOptions()` och sätt `office_math_export_mode` efter behov.

**Q: Vad händer om jag behöver behålla flytande former som flytande?**  
A: Utelämna `export_floating_shapes_as_inline_tag` eller sätt den till `False`.

**Q: Är LaTeX‑exporten kompatibel med MathJax?**  
A: Absolut. MathJax renderar `$$ … $$`‑blocken som genereras av Markdown‑ och Txt‑exportörerna.
