# Hur man skapar donutdiagram i ett Word-dokument med Java

Om du behöver **create doughnut chart** i en Word‑fil, visar den här handledningen en komplett, färdig‑att‑köra lösning. Du kommer att se hur du **insert pie chart**, omvandlar den till en donut, **rotate pie chart** för bättre balans och **format pie chart** för att matcha ditt varumärke. I slutet har du ett professionellt Word‑dokument som kan användas i rapporter, instrumentpaneler eller automatiska e‑postbilagor.

Att skapa ett diagram programatiskt eliminerar manuella kopiera‑och‑klistra‑steg och garanterar konsekvent stil över dussintals genererade dokument. Exemplet använder Aspose.Words for Java‑biblioteket, som fungerar med Java 8+ och kräver ingen Microsoft Office‑installation. Inga andra förutsättningar behövs förutom en standard‑JDK och din favoriteditor.

## Förutsättningar

- Java Development Kit (JDK) 8 eller nyare  
- Maven eller Gradle för beroendehantering (handledningen använder Maven)  
- Aspose.Words for Java‑biblioteket (gratis provlicens räcker för testning)  

Lägg till Aspose.Words‑beroendet i din `pom.xml`:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-words</artifactId>
    <version>24.9</version> <!-- Use the latest stable version -->
</dependency>
```

> **Pro tip:** Registrera din licens med `License license = new License(); license.setLicense("Aspose.Words.lic");` innan du skapar något dokument för att ta bort utvärderingsvattenstämplar.

## Skapa donutdiagram i ett Word-dokument

Det centrala arbetsflödet består av fem logiska steg. Varje steg är inneslutet i sin egen metod för att hålla koden ren och återanvändbar.

```java
import com.aspose.words.*;
import com.aspose.words.drawing.*;

public class DoughnutChartDemo {

    public static void main(String[] args) throws Exception {
        // Step 1: create blank Word document
        Document doc = createBlankWordDocument();

        // Step 2: insert a pie chart (base for the doughnut)
        Chart chart = insertPieChart(doc, 400, 300);

        // Step 3: convert the pie chart into a doughnut and rotate it
        customizeChartAppearance(chart);

        // Step 4: apply additional formatting to the chart
        formatPieChart(chart);

        // Step 5: save the final document
        doc.save("output/DoughnutChartFormatted.docx");
        System.out.println("Document saved successfully.");
    }

    /** Step 1 – create blank Word document */
    private static Document createBlankWordDocument() {
        // Aspose.Words creates an empty document by default
        return new Document();
    }

    /** Step 2 – insert pie chart with given dimensions */
    private static Chart insertPieChart(Document doc, int width, int height) throws Exception {
        DocumentBuilder builder = new DocumentBuilder(doc);
        // ChartType.PIE creates a standard pie chart that we will later turn into a doughnut
        Chart chart = builder.insertChart(ChartType.PIE, width, height);
        // Populate the chart with sample data
        chart.getSeries().clear(); // Remove default series
        ChartSeries series = chart.getSeries().add("Sales", new String[]{"Q1", "Q2", "Q3", "Q4"},
                new double[]{15000, 23000, 18000, 27000});
        return chart;
    }

    /** Step 3 – rotate pie chart and make it a doughnut */
    private static void customizeChartAppearance(Chart chart) {
        // Explode the first slice for emphasis
        chart.getSeries().get(0).setExplode(20);
        // Convert the pie into a doughnut by setting a hole size (percentage of radius)
        chart.setHoleSize(30); // 30% hole creates a classic doughnut look
        // Rotate the chart so the largest slice starts at 45°
        chart.setRotationAngle(45);
    }

    /** Step 4 – additional formatting of the pie chart */
    private static void formatPieChart(Chart chart) {
        // Example: change the first slice color to a brand color
        chart.getSeries().get(0).getPoints().get(0).getFormat().setFillForegroundColor(Color.fromArgb(0xFF, 0x4A, 0x90));
        // Add a legend and position it at the bottom
        chart.setHasLegend(true);
        chart.getLegend().setPosition(LegendPosition.BOTTOM);
        // Set a title for the chart
        chart.setTitle("Quarterly Sales Distribution");
    }
}
```

### Vad koden gör

| Steg | Åtgärd | Orsak |
|------|--------|--------|
| **Create blank Word document** | `new Document()` | Börjar med en ren fil så att du kontrollerar varje element. |
| **Insert pie chart** | `builder.insertChart(ChartType.PIE, …)` | Ett pajdiagram är grundformen; Aspose tillhandahåller endast en donut genom att justera hålstorleken. |
| **Rotate pie chart** | `chart.setRotationAngle(45)` | Rotationen placerar den största delen på en mer läsbar position. |
| **Format pie chart** | `setExplode`, `setHoleSize`, color, legend | Förbättrar den visuella hierarkin och matchar företagets stilriktlinjer. |
| **Save document** | `doc.save("…/DoughnutChartFormatted.docx")` | Skriver den slutliga .docx‑filen till disk, klar för distribution. |

## Infoga pajdiagram innan konvertering till donut

Aspose.Words erbjuder inte en direkt “insert doughnut chart”-metod. Istället **insert pie chart** och modifierar sedan dess egenskaper. Detta tvåstegstillvägagångssätt ger dig full kontroll över dataserier, delexplosion och hålstorlek. Om du behöver ett rent pajdiagram någon annanstans, utelämna helt enkelt anropet `setHoleSize`.

## Rotera pajdiagram för visuell balans

Standardorienteringen startar den första delen vid klockan 12. I många affärsrapporter bör den viktigaste delen börja vid en mer naturlig vinkel, till exempel 45 grader. Metoden `setRotationAngle(double angle)` accepterar grader och roterar hela diagrammet utan att påverka datavärdena.

## Formatera pajdiagram och anpassa utseendet

Utöver att konvertera till en donut vill du ofta **format pie chart**‑element:

- **Explode** den första delen (`setExplode`) för att dra uppmärksamhet.  
- **Color** varje del med `getPoints().get(i).getFormat().setFillForegroundColor`.  
- **Legend**‑positionering (`setHasLegend`, `setPosition`) hjälper läsare att tolka kategorier.  
- **Title** (`setTitle`) ger kontext på ett ögonblick.  

Alla dessa inställningar är valfria; du kan anpassa dem för att matcha ditt varumärkespalett eller företagets mallar.

## Skapa tomt Word-dokument och spara resultatet

`createBlankWordDocument`‑metoden kapslar in steget **create blank word document**. Att hålla denna logik isolerad gör det enkelt att återanvända metoden när man genererar flera rapporter i ett batch‑förlopp. Efter alla anpassningar skriver `doc.save` filen i det standardiserade Office Open XML‑formatet (`.docx`), som kan öppnas i Microsoft Word, LibreOffice eller Google Docs utan förlust av kvalitet.

### Förväntad output

När du kör `main`‑metoden skriver konsolen ut:

```
Document saved successfully.
```

Och filen `output/DoughnutChartFormatted.docx` innehåller en enda sida med ett donutdiagram med rubriken *Quarterly Sales Distribution*. Diagrammet visar fyra delar, den första delen exploderad, färgad i varumärkets nyans, och roterad 45 grader.

## Vanliga variationer och kantfall

| Situation | Justering |
|-----------|------------|
| **More than one data series** | Lägg till ytterligare `ChartSeries`‑objekt till `chart.getSeries()`. |
| **Different chart size** | Ändra argumenten `width` och `height` i `insertPieChart`. |
| **No hole (pure pie)** | Utelämna `chart.setHoleSize(…)` eller sätt den till `0`. |
| **Large documents** | Använd `DocumentBuilder` för att infoga diagrammet i ett specifikt avsnitt eller bokmärke. |
| **License not set** | Biblioteket körs i utvärderingsläge, vilket lägger till en vattenstämpel på första sidan. Registrera en licens för att ta bort den. |
