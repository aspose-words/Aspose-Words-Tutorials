# Cómo convertir docx a markdown con imágenes en una subcarpeta

Si necesitas **convertir docx a markdown** mientras mantienes cada imagen incrustada bien organizada, has llegado al lugar correcto. Muchos desarrolladores generan informes, manuales o borradores de blogs de forma programática y terminan con una mezcla caótica de archivos de imagen dispersos por el directorio de salida. Este tutorial te muestra un enfoque limpio, impulsado por callbacks, usando Aspose.Words para .NET que exporta un documento a markdown, almacena cada imagen en una carpeta *md‑resources* dedicada y guarda el archivo markdown final listo para publicar.

> **Vista rápida:**  
> • Configura `MarkdownSaveOptions`  
> • Implementa un `IResourceSavingCallback` para redirigir imágenes  
> • Llama a `Document.Save` con las opciones configuradas  

Ahora que entiendes por qué un callback es preferible al post‑procesamiento, sumerjámonos en la solución paso a paso.

## Respuestas rápidas
- **¿Qué hace realmente “convertir docx a markdown”?** Transforma el marcado de procesamiento de Word en markdown de texto plano mientras preserva encabezados, listas, tablas y referencias de imágenes.  
- **¿Qué biblioteca maneja la conversión?** Aspose.Words para .NET proporciona una API totalmente gestionada del lado del servidor que funciona sin necesidad de tener Microsoft Word instalado.  
- **¿Necesito escribir código de procesamiento de imágenes?** No; el `IResourceSavingCallback` se encarga de guardar cada imagen en la carpeta que especifiques.  
- **¿Puedo cambiar el nombre de la carpeta de salida?** Absolutamente – reemplaza `"md-resources/"` por cualquier ruta relativa o absoluta que prefieras.  
- **¿Es la solución compatible con .NET 6 y posteriores?** Sí, funciona en .NET 6+, .NET 5, .NET Core 3.1 y .NET Framework 4.7+.

## ¿Qué es convertir docx a markdown?
**Convertir docx a markdown** es el proceso de tomar un documento de Microsoft Word (DOCX) y generar un archivo markdown (`.md`) que representa el mismo contenido usando la sintaxis markdown. La conversión preserva los elementos estructurales y opcionalmente extrae recursos incrustados como imágenes.

La conversión la realiza Aspose.Words, una biblioteca que soporta **más de 35 formatos de entrada y salida** —incluyendo DOCX, PDF, HTML y Markdown— permitiéndote manejar documentos de cientos de páginas sin cargar todo el archivo en memoria.

## ¿Por qué usar Aspose.Words para exportar a markdown?
Aspose.Words procesa los documentos en memoria y escribe el resultado directamente al formato objetivo, lo que significa:

Aspose.Words ofrece una conversión de alto rendimiento y precisión mientras te brinda control total sobre el manejo de recursos. Elimina la necesidad de pasos de post‑procesamiento, reduce el uso de memoria y garantiza que las imágenes, tablas y estilos se reproduzcan fielmente en la salida markdown.

- **Velocidad:** Los archivos DOCX típicos de 200 páginas se convierten a markdown en menos de 2 segundos en una VM estándar.  
- **Precisión:** Se admiten más de 50 sabores de markdown incorporados, garantizando que tablas, bloques de código y notas al pie se rendericen correctamente.  
- **Control de recursos:** El `IResourceSavingCallback` incorporado te permite decidir exactamente dónde se guarda cada imagen, eliminando la necesidad de un paso de limpieza separado.

## Requisitos previos

- .NET 6.0 o posterior (compatible también con .NET Framework 4.7+)
- Aspose.Words para .NET (paquete NuGet `Aspose.Words`)
- Un objeto `Document` de origen (DOCX, PDF, RTF, etc.)

No se requieren bibliotecas adicionales; la API de callbacks es parte de Aspose.Words.

## ¿Cómo convertir docx a markdown?

Carga tu documento de origen con `new Document("source.docx")`, configura `MarkdownSaveOptions` para usar un callback que escriba cada imagen en `md-resources/`, y luego llama a `doc.Save("output.md", saveOptions)`. Este patrón de tres pasos convierte el archivo, extrae imágenes y produce un archivo markdown limpio con enlaces de imagen relativos, todo en una sola llamada de método.

### Paso 1: configurar opciones de guardado para la conversión a markdown

MarkdownSaveOptions configura cómo Aspose.Words convierte un documento a Markdown.

```csharp
// Step 1: Initialize Markdown save options
var markdownSaveOptions = new Aspose.Words.Saving.MarkdownSaveOptions();
```

```csharp
// Step 1: Initialize Markdown save options
var markdownSaveOptions = new Aspose.Words.Saving.MarkdownSaveOptions();
```

> **Por qué esto importa:**  
> Sin crear explícitamente `MarkdownSaveOptions`, la biblioteca recurre a la configuración predeterminada que incrusta imágenes directamente en el archivo Markdown como cadenas Base64. Eso hace que el archivo sea enorme y derrota el propósito de tener una carpeta *images* limpia.

### Paso 2: definir un callback de guardado de recursos para exportar imágenes

`IResourceSavingCallback` te permite controlar dónde se guarda cada recurso (imagen, SVG) durante la exportación.

Ahora le indicamos al guardador **dónde** colocar cada imagen. La interfaz `IResourceSavingCallback` nos brinda un hook que se dispara para cada recurso (imagen, SVG, etc.) descubierto durante la exportación. Dentro del callback hacemos lo siguiente:

1. Asegurarnos de que la carpeta de destino exista (`md-resources/`).  
2. Establecer `OutputFileName` a la carpeta más el nombre original del recurso.  

```csharp
// Step 2: Hook into the resource‑saving pipeline
markdownSaveOptions.ResourceSavingCallback = new Aspose.Words.Saving.IResourceSavingCallback(
    (args) =>
    {
        // All images will be placed in "md-resources" relative to the output .md file
        const string folder = "md-resources/";
        Directory.CreateDirectory(folder);          // Create folder if it doesn’t exist

        // Preserve the original file name (e.g., image001.png) but prepend the folder path
        args.OutputFileName = Path.Combine(folder, args.ResourceFileName);

        // Optional: you could also change the format here (e.g., convert BMP to PNG)
        // args.ResourceFileName = Path.ChangeExtension(args.ResourceFileName, ".png");
    });
```

> **Pregunta común:** *¿Qué pasa si quiero incrustar imágenes en lugar de guardarlas?*  
> Simplemente omite el callback o establece `args.OutputFileName = null;` – el guardador incrustará la imagen como una cadena Base64 automáticamente.

> **Caso límite:** Algunos documentos antiguos contienen nombres de imagen duplicados. El callback anterior sobrescribirá el archivo anterior. Para evitarlo, podrías añadir un GUID:  

```csharp
args.OutputFileName = Path.Combine(folder,
    $"{Path.GetFileNameWithoutExtension(args.ResourceFileName)}_{Guid.NewGuid()}{Path.GetExtension(args.ResourceFileName)}");
```

### Paso 3: guardar el documento como markdown y verificar la salida

Con las opciones totalmente configuradas, la llamada final es una única línea que escribe el archivo Markdown y las imágenes asociadas en el disco.

```csharp
// Step 3: Perform the actual export
string outputPath = @"C:\Exports\MyReport.md";
doc.Save(outputPath, markdownSaveOptions);
```

Si todo va bien verás:

- `MyReport.md` – la representación Markdown de tu documento de origen.  
- `md-resources/` – una carpeta junto al archivo `.md` que contiene cada imagen extraída (p.ej., `image001.png`, `image002.jpg`).  

**Fragmento de markdown de ejemplo** (generado automáticamente por Aspose.Words):

```markdown
# Sample Report

Here is an introductory paragraph.

![Sample image](md-resources/image001.png)

More text follows...
```

[Imagen de ejemplo](md-resources/image001.png)

> **Consejo profesional:** Abre el archivo `.md` generado en VS Code o cualquier visor de Markdown; las imágenes deberían mostrarse instantáneamente porque las rutas relativas coinciden con la estructura de carpetas.

## Ejemplo completo y ejecutable (sin bloques de código adicionales)

Abajo hay un programa de consola autocontenido que puedes pegar en un nuevo proyecto .NET y ejecutar. Crea un documento Word sencillo, añade una imagen y luego **crea markdown a partir del documento** mientras almacena la imagen en una subcarpeta.

```csharp
using System;
using System.IO;
using Aspose.Words;
using Aspose.Words.Saving;

class Program
{
    static void Main()
    {
        // 1️⃣ Create a sample Word document with an image
        var doc = new Document();
        var builder = new DocumentBuilder(doc);
        builder.Writeln("Hello, this is a test document.");
        builder.InsertImage("sample-image.png"); // Ensure this file exists next to exe

        // 2️⃣ Configure markdown export options (see Step 1 & 2 above)
        var markdownOptions = new MarkdownSaveOptions();
        markdownOptions.ResourceSavingCallback = new IResourceSavingCallback(
            (args) =>
            {
                const string folder = "md-resources/";
                Directory.CreateDirectory(folder);
                args.OutputFileName = Path.Combine(folder, args.ResourceFileName);
            });

        // 3️⃣ Save as markdown (Step 3)
        string outputFolder = Path.Combine(Environment.CurrentDirectory, "output");
        Directory.CreateDirectory(outputFolder);
        string markdownPath = Path.Combine(outputFolder, "ExportedDoc.md");
        doc.Save(markdownPath, markdownOptions);

        Console.WriteLine($"✅ Markdown saved to: {markdownPath}");
        Console.WriteLine("📂 Images saved in: md-resources/");
    }
}
```

**Lo que deberías ver** después de ejecutar:

```
✅ Markdown saved to: C:\MyProject\output\ExportedDoc.md
📂 Images saved in: md-resources/
```

Abre `ExportedDoc.md` – la referencia de la imagen apuntará a `md-resources/sample-image.png`, y la imagen se mostrará correctamente en cualquier visor de Markdown.

## Variaciones frecuentemente solicitadas

| Escenario | Cómo adaptar el código |
|----------|----------------------|
| **Omitir exportación de imágenes** (incrustar como Base64) | Omitir `ResourceSavingCallback` por completo, o establecer `args.OutputFileName = null;` dentro del callback. |
| **Cambiar formato de imagen** (p.ej., todo PNG) | Dentro del callback, modifica `args.ResourceFileName` y opcionalmente convierte el flujo antes de escribir. |
| **Nombre de carpeta personalizado** | Reemplaza `"md-resources/"` por cualquier ruta relativa o absoluta que prefieras. |
| **Múltiples documentos en lote** | Itera sobre una colección de objetos `Document`, reutilizando la misma instancia de `MarkdownSaveOptions` (solo asegúrate de que la carpeta se limpie o tenga un nombre único por ejecución). |

## Problemas comunes y soluciones

- **Las imágenes no aparecen en la vista previa del markdown** – Verifica que la ruta relativa en el markdown (`md-resources/image001.png`) coincida con la ubicación real de la carpeta respecto al archivo `.md`.  
- **Nombres de imagen duplicados que causan sobrescrituras** – Añade un identificador único (GUID o contador incremental) dentro del callback para garantizar nombres de archivo distintos.  
- **Documentos grandes que generan presión de memoria** – Usa `Document.OptimizeResources()` antes de guardar; esto reduce el consumo de memoria al disponer de flujos no usados.  
- **Formatos de imagen no soportados** – Aspose.Words soporta PNG, JPEG, BMP, GIF y TIFF. Convierte los formatos no soportados a uno de estos antes de añadirlos al documento de origen.

## Preguntas frecuentes

**Q: ¿Puedo usar este enfoque en un ASP .NET Web API que devuelve un archivo ZIP?**  
A: Sí. Genera el markdown y las imágenes en una carpeta temporal, añádelas a un `ZipArchive` y envía el ZIP al cliente. Los mismos `MarkdownSaveOptions` y callback funcionan sin cambios.

**Q: ¿La conversión preserva estilos de Word como encabezados y tablas?**  
A: Absolutamente. Aspose.Words asigna los estilos de encabezado de Word a encabezados markdown `#` y convierte las tablas a la sintaxis de tuberías markdown, preservando el contenido y la alineación de las celdas.

**Q: ¿Se requiere una licencia comercial para uso en producción?**  
A: Sí. Hay una licencia de evaluación gratuita disponible para pruebas, pero los despliegues en producción necesitan una licencia comprada de Aspose.Words.

**Q: ¿Cómo maneja la biblioteca los documentos protegidos con contraseña?**  
A: Carga el documento con `new Document("file.docx", new LoadOptions { Password = "yourPassword" })` antes de invocar la rutina de guardado a markdown.

**Q: ¿Qué versiones de .NET son oficialmente compatibles?**  
A: Aspose.Words soporta .NET Framework 4.7+, .NET Core 3.1+, .NET 5, .NET 6 y posteriores.

- Utiliza `MarkdownSaveOptions` para un control fino.  
- Implementa `IResourceSavingCallback` para dirigir las imágenes a una carpeta dedicada, manteniendo tu markdown ordenado.
