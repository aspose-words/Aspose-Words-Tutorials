# Cómo crear un gráfico de dona en un documento Word con Java

Si necesitas **crear un gráfico de dona** dentro de un archivo Word, este tutorial te muestra una solución completa y lista‑para‑ejecutar. Verás cómo **insertar un gráfico de pastel**, convertirlo en una dona, **rotar el gráfico de pastel** para lograr un mejor equilibrio, y **formatear el gráfico de pastel** para que coincida con tu marca. Al final tendrás un documento Word profesional que puede usarse en informes, paneles de control o adjuntos de correo electrónico automatizados.

Crear un gráfico programáticamente elimina los pasos manuales de copiar‑pegar y garantiza un estilo consistente en docenas de documentos generados. El ejemplo utiliza la biblioteca Aspose.Words for Java, que funciona con Java 8+ y no requiere la instalación de Microsoft Office. No se necesitan otros requisitos más allá de un JDK estándar y tu IDE favorito.

## Prerequisitos

- Java Development Kit (JDK) 8 o superior  
- Maven o Gradle para la gestión de dependencias (el tutorial usa Maven)  
- Biblioteca Aspose.Words for Java (una licencia de prueba gratuita es suficiente para pruebas)  

Agrega la dependencia Aspose.Words a tu `pom.xml`:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-words</artifactId>
    <version>24.9</version> <!-- Use the latest stable version -->
</dependency>
```

> **Consejo profesional:** Registra tu licencia con `License license = new License(); license.setLicense("Aspose.Words.lic");` antes de crear cualquier documento para eliminar las marcas de agua de evaluación.

## Crear un gráfico de dona en un documento Word

El flujo de trabajo central consta de cinco pasos lógicos. Cada paso está envuelto en su propio método para mantener el código limpio y reutilizable.

```java
import com.aspose.words.*;
import com.aspose.words.drawing.*;

public class DoughnutChartDemo {

    public static void main(String[] args) throws Exception {
        // Step 1: create blank Word document
        Document doc = createBlankWordDocument();

        // Step 2: insert a pie chart (base for the doughnut)
        Chart chart = insertPieChart(doc, 400, 300);

        // Step 3: convert the pie chart into a doughnut and rotate it
        customizeChartAppearance(chart);

        // Step 4: apply additional formatting to the chart
        formatPieChart(chart);

        // Step 5: save the final document
        doc.save("output/DoughnutChartFormatted.docx");
        System.out.println("Document saved successfully.");
    }

    /** Step 1 – create blank Word document */
    private static Document createBlankWordDocument() {
        // Aspose.Words creates an empty document by default
        return new Document();
    }

    /** Step 2 – insert pie chart with given dimensions */
    private static Chart insertPieChart(Document doc, int width, int height) throws Exception {
        DocumentBuilder builder = new DocumentBuilder(doc);
        // ChartType.PIE creates a standard pie chart that we will later turn into a doughnut
        Chart chart = builder.insertChart(ChartType.PIE, width, height);
        // Populate the chart with sample data
        chart.getSeries().clear(); // Remove default series
        ChartSeries series = chart.getSeries().add("Sales", new String[]{"Q1", "Q2", "Q3", "Q4"},
                new double[]{15000, 23000, 18000, 27000});
        return chart;
    }

    /** Step 3 – rotate pie chart and make it a doughnut */
    private static void customizeChartAppearance(Chart chart) {
        // Explode the first slice for emphasis
        chart.getSeries().get(0).setExplode(20);
        // Convert the pie into a doughnut by setting a hole size (percentage of radius)
        chart.setHoleSize(30); // 30% hole creates a classic doughnut look
        // Rotate the chart so the largest slice starts at 45°
        chart.setRotationAngle(45);
    }

    /** Step 4 – additional formatting of the pie chart */
    private static void formatPieChart(Chart chart) {
        // Example: change the first slice color to a brand color
        chart.getSeries().get(0).getPoints().get(0).getFormat().setFillForegroundColor(Color.fromArgb(0xFF, 0x4A, 0x90));
        // Add a legend and position it at the bottom
        chart.setHasLegend(true);
        chart.getLegend().setPosition(LegendPosition.BOTTOM);
        // Set a title for the chart
        chart.setTitle("Quarterly Sales Distribution");
    }
}
```

### Qué hace el código

| Paso | Acción | Razón |
|------|--------|--------|
| **Crear documento Word en blanco** | `new Document()` | Comienza con un archivo limpio para que controles cada elemento. |
| **Insertar gráfico de pastel** | `builder.insertChart(ChartType.PIE, …)` | Un gráfico de pastel es la forma base; Aspose solo proporciona una dona ajustando el tamaño del agujero. |
| **Rotar gráfico de pastel** | `chart.setRotationAngle(45)` | Rotar alinea la porción más grande a una posición más legible. |
| **Formatear gráfico de pastel** | `setExplode`, `setHoleSize`, color, legend | Mejora la jerarquía visual y coincide con las directrices de estilo corporativo. |
| **Guardar documento** | `doc.save("…/DoughnutChartFormatted.docx")` | Escribe el archivo .docx final en disco, listo para distribución. |

## Insertar gráfico de pastel antes de convertir a dona

Aspose.Words no proporciona un método directo de “insertar gráfico de dona”. En su lugar, **insertas un gráfico de pastel** y luego modificas sus propiedades. Este enfoque de dos pasos te brinda control total sobre las series de datos, la explosión de porciones y el tamaño del agujero. Si necesitas un gráfico de pastel puro en otro lugar, simplemente omite la llamada a `setHoleSize`.

## Rotar gráfico de pastel para equilibrio visual

La orientación predeterminada inicia la primera porción en la posición de las 12 en punto. En muchos informes empresariales la porción más importante debería comenzar en un ángulo más natural, como 45 grados. El método `setRotationAngle(double angle)` acepta grados y rota todo el gráfico sin afectar los valores de los datos.

## Formatear gráfico de pastel y personalizar la apariencia

Más allá de convertir a una dona, a menudo deseas **formatear el gráfico de pastel**:

- **Explotar** la primera porción (`setExplode`) para llamar la atención.  
- **Color** de cada porción usando `getPoints().get(i).getFormat().setFillForegroundColor`.  
- Posicionamiento de **leyenda** (`setHasLegend`, `setPosition`) ayuda a los lectores a interpretar las categorías.  
- **Título** (`setTitle`) brinda contexto de un vistazo.  

Todas estas configuraciones son opcionales; puedes adaptarlas para que coincidan con la paleta de tu marca o plantillas corporativas.

## Crear documento Word en blanco y guardar el resultado

El método `createBlankWordDocument` encapsula el paso de **crear documento Word en blanco**. Mantener esta lógica aislada facilita reutilizar el método al generar múltiples informes en un proceso por lotes. Después de todas las personalizaciones, `doc.save` escribe el archivo en el formato estándar Office Open XML (`.docx`), que puede abrirse en Microsoft Word, LibreOffice o Google Docs sin pérdida de fidelidad.

### Salida esperada

Cuando ejecutas el método `main`, la consola imprime:

```
Document saved successfully.
```

Y el archivo `output/DoughnutChartFormatted.docx` contiene una sola página con un gráfico de dona titulado *Quarterly Sales Distribution*. El gráfico muestra cuatro porciones, la primera porción explotada, coloreada con el tono de la marca y rotada 45 grados.

## Variaciones comunes y casos límite

| Situación | Ajuste |
|-----------|--------|
| **Más de una serie de datos** | Agregar objetos `ChartSeries` adicionales a `chart.getSeries()`. |
| **Tamaño de gráfico diferente** | Cambiar los argumentos `width` y `height` en `insertPieChart`. |
| **Sin agujero (pastel puro)** | Omitir `chart.setHoleSize(…)` o establecerlo en `0`. |
| **Documentos grandes** | Usar `DocumentBuilder` para insertar el gráfico en una sección o marcador específico. |
| **Licencia no establecida** | La biblioteca se ejecuta en modo de evaluación, añadiendo una marca de agua en la primera página. Registra una licencia para eliminarla. |

## Conclusión

Ahora sabes cómo **crear un gráfico de dona** en un documento Word usando Java, desde **crear documento Word en blanco** hasta **insertar gráfico de pastel**, **rotar gráfico de pastel** y **formatear gráfico de pastel** para obtener un producto final pulido. El ejemplo completo y ejecutable puede incorporarse en cualquier proyecto Java que ya use Aspose.Words.

A continuación, podrías explorar:

- Automatizar la generación de múltiples documentos en un bucle para informes por lotes  

Siéntete libre de experimentar con colores, explosiones de porciones y leyendas para que coincidan con el lenguaje visual de tu organización. ¡Feliz creación de gráficos!
