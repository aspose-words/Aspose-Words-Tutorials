# Crear documento Word en blanco y ocultar una forma elíptica en C#

Si necesitas **crear un documento Word en blanco** y luego ocultar un elemento gráfico, esta guía te muestra exactamente cómo hacerlo con C#. Verás un ejemplo completo y ejecutable que inserta una elipse, la posiciona, la marca como oculta y guarda el archivo, todo en unas pocas líneas de código.

El tutorial cubre todo, desde la configuración del proyecto hasta el paso final de verificación. Al terminar, podrás generar un archivo Word donde la elipse nunca aparece en pantalla ni en la impresión, lo que es útil para almacenar metadatos, marcadores o cualquier indicador invisible.

## Requisitos previos

Antes de comenzar, asegúrate de tener:

* SDK .NET 6.0 o posterior instalado  
* Un entorno de desarrollo C# (Visual Studio 2022, Rider o VS Code)  
* El paquete NuGet **Aspose.Words for .NET** (`Install-Package Aspose.Words`)  

Estas herramientas proporcionan las clases `Document` y `DocumentBuilder` usadas en el ejemplo de código.

## Paso 1: Crear un documento Word en blanco

La primera operación crea un objeto `Document` vacío y un `DocumentBuilder` que te permite añadir contenido.

```csharp
using Aspose.Words;
using Aspose.Words.Drawing;

// Step 1: Initialize an empty document and a builder
Document doc = new Document();
DocumentBuilder builder = new DocumentBuilder(doc);
```

`Document` representa todo el paquete `.docx`, mientras que `DocumentBuilder` ofrece una API fluida para insertar texto, formas y otros objetos. Comenzar con un documento en blanco te brinda control total sobre cada elemento que agregues.

## Paso 2: Cómo insertar una elipse

Una elipse es una forma vectorial que puede usarse como marcador. El método `InsertShape` requiere el tipo de forma y su ancho/alto en puntos.

```csharp
// Step 2: Insert an ellipse shape of the desired size (100 pt × 50 pt)
Shape ellipse = builder.InsertShape(ShapeType.Ellipse, 100, 50);
```

La elipse se coloca en la página actual en la posición del cursor. Puedes cambiar sus dimensiones ajustando los argumentos numéricos.

## Paso 3: Cómo posicionar la forma

Después de la inserción, puedes mover la forma a cualquier parte de la página estableciendo las propiedades `Left` y `Top`, que usan puntos relativos al margen de la página.

```csharp
// Step 3: Position the shape on the page
ellipse.Left = 150; // distance from the left margin
ellipse.Top  = 100; // distance from the top margin
```

Estas coordenadas sitúan la elipse aproximadamente en la zona superior‑media de una página A4 estándar. Ajusta los valores según los requisitos de tu diseño.

## Paso 4: Cómo ocultar la forma

Un objeto oculto no se muestra cuando el documento se abre ni se imprime. Establecer la bandera `Hidden` marca la forma como un **objeto oculto**.

```csharp
// Step 4: Hide the shape so it never appears
ellipse.Hidden = true;
```

Word respeta la bandera oculta tanto para la representación en pantalla como para la salida de impresión. La forma sigue formando parte de la estructura del documento, lo que permite consultarla o modificarla más tarde mediante código.

## Paso 5: Guardar el documento

Finalmente, escribe el documento en disco. Elige una carpeta en la que tengas permiso de escritura.

```csharp
// Step 5: Save the document to a .docx file
doc.Save(@"C:\Temp\HiddenEllipse.docx");
```

El archivo `HiddenEllipse.docx` ahora contiene una página en blanco con una forma elíptica oculta.

## Verificando la elipse oculta

Abre el archivo generado en Microsoft Word y habilita la opción **Mostrar texto oculto** (Archivo → Opciones → Mostrar). Verás un contorno tenue de la elipse. Si desactivas la opción, la forma desaparece por completo, confirmando que `ellipse.Hidden = true` funciona como se espera.

## Variaciones comunes y casos límite

| Situación | Ajuste recomendado |
|-----------|--------------------|
| **Forma diferente** | Reemplaza `ShapeType.Ellipse` por `ShapeType.Rectangle`, `ShapeType.Arrow`, etc. |
| **Múltiples objetos ocultos** | Repite los pasos 2‑4 para cada forma; cada una puede tener su propia bandera `Hidden`. |
| **Tamaño de página diferente** | Establece `doc.FirstSection.PageSetup.PageWidth` y `PageHeight` antes de insertar la forma. |
| **Visibilidad condicional** | Usa `Shape.Visible` en combinación con `Hidden` para alternar en tiempo de ejecución mediante código. |

**Consejo:** Almacena datos de identificación en la propiedad `AlternativeText` de la forma. Incluso cuando está oculta, puedes recuperar la forma más tarde con `doc.GetChildNodes(NodeType.Shape, true)` y filtrarla por ese texto.

## Código fuente completo

```csharp
using System;
using Aspose.Words;
using Aspose.Words.Drawing;

namespace HiddenShapeDemo
{
    class Program
    {
        static void Main()
        {
            // Create a new blank document and a builder
            Document doc = new Document();
            DocumentBuilder builder = new DocumentBuilder(doc);

            // Insert an ellipse shape (100 pt × 50 pt)
            Shape ellipse = builder.InsertShape(ShapeType.Ellipse, 100, 50);

            // Position the shape on the page
            ellipse.Left = 150;
            ellipse.Top  = 100;

            // Hide the shape so it is invisible in the UI and on print
            ellipse.Hidden = true;

            // Optional: add a description for later retrieval
            ellipse.AlternativeText = "Hidden marker for internal processing";

            // Save the document
            string outputPath = @"C:\Temp\HiddenEllipse.docx";
            doc.Save(outputPath);

            Console.WriteLine($"Document saved to {outputPath}");
        }
    }
}
```

**Salida esperada:** La consola muestra la ruta de guardado, y el archivo `HiddenEllipse.docx` se abre como una página en blanco sin gráficos visibles a menos que se muestren los objetos ocultos.

## Conclusión

Ahora sabes cómo **crear un documento Word en blanco** programáticamente, **cómo insertar una elipse**, **cómo posicionar la forma** y **cómo ocultar la forma** para que se comporte como un **objeto oculto**. Esta técnica es ideal para incrustar marcadores invisibles, metadatos personalizados o marcadores de posición que procesos posteriores pueden leer sin afectar el diseño visual del documento.
