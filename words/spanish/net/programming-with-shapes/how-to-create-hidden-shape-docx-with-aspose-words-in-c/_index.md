# Cómo crear un shape oculto en un docx con Aspose.Words en C#

Si necesitas **crear archivos docx con shape oculto** de forma programática, este tutorial muestra los pasos exactos usando Aspose.Words para .NET. Verás cómo **establecer el color de relleno del shape** para que sea visible mientras editas, y luego **ocultar el shape en el documento Word** para que el usuario final nunca lo vea a menos que se muestren los objetos ocultos.

La guía cubre todo lo que necesitas saber: paquetes NuGet requeridos, un ejemplo de código completo y ejecutable, y consejos para solucionar problemas comunes. Al final del artículo tendrás un DOCX que contiene una elipse invisible que puede revelarse más tarde si es necesario.

## Requisitos previos

Antes de comenzar, asegúrate de tener:

- .NET 6.0 SDK o una versión posterior instalada  
- Visual Studio 2022 (o cualquier IDE de C#)  
- Una licencia activa de Aspose.Words para .NET (o una clave de evaluación temporal)  
- Familiaridad básica con la sintaxis de C#  

No **necesitas** bibliotecas adicionales de interop de Word porque Aspose.Words funciona de forma independiente de Microsoft Office.

## Paso 1: Crear shape oculto docx – inicializar el documento

La primera operación es instanciar un objeto `Document` y un `DocumentBuilder`. El builder proporciona la API fluida para insertar shapes, texto y otros elementos.

```csharp
using Aspose.Words;
using Aspose.Words.Drawing;
using System.Drawing;

class Program
{
    static void Main()
    {
        // Initialise an empty DOCX file
        Document doc = new Document();
        DocumentBuilder builder = new DocumentBuilder(doc);
```

*Por qué es importante*: Un `Document` nuevo representa un archivo Word vacío. El `DocumentBuilder` actúa como un cursor que sabe dónde se colocará el siguiente elemento. Comenzar con un documento limpio garantiza que el shape oculto no herede un formato inesperado.

## Paso 2: Establecer el color de relleno del shape para la elipse

A continuación, inserta una forma elíptica y aplica un color de relleno. El color hace que el shape sea visible en el editor, lo cual es útil cuando necesitas verificar su tamaño o posición antes de ocultarlo.

```csharp
        // Insert an ellipse 150 pt wide and 100 pt high
        Shape ellipse = builder.InsertShape(ShapeType.Ellipse, 150, 100);

        // Apply a bright fill so the shape can be inspected
        ellipse.FillColor = Color.Yellow;
```

El paso de **establecer el color de relleno del shape** es opcional para el documento final oculto, pero ayuda durante el desarrollo. Sin un relleno, el shape sería invisible incluso antes de aplicar la bandera de oculto, lo que dificulta la depuración.

## Paso 3: Ocultar el shape en el documento Word

Ahora aplica la propiedad `Hidden`. Cuando `Hidden` es `true`, Microsoft Word no renderizará el shape en la vista normal. Los usuarios aún pueden revelarlo habilitando “Mostrar objetos ocultos” en las opciones de Word.

```csharp
        // Mark the shape as hidden – it will not appear in normal view
        ellipse.Hidden = true;
```

*Nota importante*: La bandera de oculto funciona con Word 2010 y versiones posteriores. Si apuntas a versiones más antiguas, el shape puede seguir apareciendo. Además, la bandera no afecta la posición del shape; solo suprime el renderizado.

## Paso 4: Guardar el archivo DOCX

Finalmente, escribe el documento en disco. El nombre del archivo puede ser cualquier ruta válida; aquí usamos una ruta relativa por simplicidad.

```csharp
        // Persist the document with the hidden shape
        doc.Save("HiddenShape.docx");
    }
}
```

Al abrir `HiddenShape.docx` en Microsoft Word, la elipse no será visible. Si habilitas **Archivo → Opciones → Pantalla → Mostrar objetos ocultos**, la elipse amarilla aparecerá exactamente donde la colocaste.

### Resultado esperado

- Un archivo llamado `HiddenShape.docx` en el directorio de trabajo del ejecutable.  
- Al abrir el archivo en Word se muestra el contenido normal **sin shape visible**.  
- Al habilitar “Mostrar objetos ocultos” se revela una elipse amarilla de tamaño 150 × 100 pt.

## Paso 5: Verificar el shape oculto programáticamente (opcional)

Si necesitas confirmar que el shape está realmente oculto sin abrir Word, puedes inspeccionar la propiedad `Hidden` después de cargar el documento:

```csharp
        Document loaded = new Document("HiddenShape.docx");
        Shape loadedShape = (Shape)loaded.GetChildNodes(NodeType.Shape, true)[0];
        System.Console.WriteLine($"Shape hidden? {loadedShape.Hidden}");
```

La consola imprime `Shape hidden? True`, demostrando que la bandera se mantuvo.

## Problemas comunes y cómo evitarlos

| Síntoma | Causa | Solución |
|---------|-------|----------|
| El shape sigue visible después de guardar | `Hidden` no está configurado o se establece después de guardar | Asegúrate de que `ellipse.Hidden = true;` se ejecute **antes** de `doc.Save()`. |
| El color de relleno no se aplica | `FillColor` asignado antes de crear el shape | Asigna `FillColor` **después** de que `InsertShape` devuelva el objeto `Shape`. |
| El DOCX no se abre | Versión de Aspose.Words no coincide con el runtime de .NET | Usa la última versión del paquete NuGet Aspose.Words que apunte a .NET 6+. |
| La bandera oculta se ignora en versiones antiguas de Word | Word < 2010 | Considera usar una técnica diferente (p. ej., establecer `WrapType` del shape a `None` y moverlo fuera de la página). |

## Consejo profesional: Reutilizar shapes ocultos como marcadores de posición

Puedes almacenar shapes ocultos en un documento plantilla y luego reemplazarlos con contenido visible. Como el shape está oculto, no afecta el diseño hasta que establezcas `Hidden = false`. Este patrón es útil para generar contratos donde un campo de firma comienza oculto y se vuelve visible después de que el usuario firma.

## Próximos pasos

- **Revelar shapes ocultos**: Usa `shape.Hidden = false;` para que la elipse aparezca en tiempo de ejecución.  
- **Cambiar el tipo de shape**: Reemplaza `ShapeType.Ellipse` por `ShapeType.Rectangle`, `ShapeType.Polygon`, etc., según tu caso de uso.  
- **Agregar texto dentro del shape**: Inserta un `TextBox` en la propiedad `TextBox` del shape para marcadores de posición con leyenda.  
- **Combinar con combinación de correspondencia**: Coloca shapes ocultos en una plantilla de combinación de correspondencia y alterna su visibilidad por registro.

Explorar estos temas fortalece tu dominio de los flujos de trabajo **create hidden shape docx** y amplía las posibilidades para la generación automática de documentos.
