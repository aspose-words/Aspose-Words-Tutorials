# Crear plantilla de factura y combinar datos usando Aspose.Words

Si necesitas **crear una plantilla de factura** rápidamente, esta guía te muestra exactamente cómo. Al final de las dos primeras frases conocerás el flujo de trabajo completo para convertir un archivo Word en blanco en una factura totalmente poblada, usando la API de combinación de correspondencia de bajo código de Aspose.Words.

Generar facturas es un requisito común para sistemas de facturación, integraciones ERP y reportes automatizados. En este tutorial aprenderás **cómo combinar correspondencia**, **poblar una plantilla de Word**, **combinar datos en Word**, y finalmente **guardar el documento combinado** — todo con un puñado de líneas de C#.

## Lo que lograrás

* Una plantilla de Word reutilizable (`InvoiceTemplate.docx`) que contiene campos de combinación para cliente, fecha, líneas de detalle y total.  
* Un programa en C# que carga la plantilla, inyecta un objeto de datos fuertemente tipado y escribe el resultado en `Invoice_001.docx`.  
* Perspectiva sobre casos límite como colecciones vacías, tipos de datos personalizados y manejo de rutas de archivo.

### Requisitos previos

| Requisito | Por qué es importante |
|-------------|----------------|
| .NET 6 o posterior | Aspose.Words for .NET admite .NET 6+ y proporciona la API de bajo código utilizada en esta guía. |
| Paquete NuGet Aspose.Words for .NET (`Aspose.Words`) | Proporciona `Document`, `MailMerger` y tipos relacionados. |
| Conocimientos básicos de C# | Necesario para entender objetos anónimos y LINQ. |
| Visual Studio 2022 (o cualquier IDE) | Facilita la edición y depuración. |

> **Consejo profesional:** Instala el paquete NuGet mediante la Consola del Administrador de Paquetes:  
> `Install-Package Aspose.Words`

## Cómo crear una plantilla de factura con combinación de correspondencia de bajo código

El primer paso es crear un archivo Word que contenga campos de combinación que coincidan con las propiedades del objeto de datos que pasarás más adelante. Guarda el archivo como `InvoiceTemplate.docx` en una carpeta que controles (p. ej., `C:\Invoices\Template`).

| Campo de combinación | Marcador de posición de ejemplo en Word |
|-------------|-----------------------------|
| CustomerName | «CustomerName» |
| InvoiceDate | «InvoiceDate» |
| Items (repeating) | «Items.Description», «Items.Qty», «Items.Price» |
| Total | «Total» |

> **Por qué es importante:** La API de bajo código asigna automáticamente los nombres de propiedad de la fuente de datos a los campos de combinación. Mantener los nombres idénticos elimina la asignación manual de campo a propiedad y reduce errores en tiempo de ejecución.

## Paso 1: Cargar la plantilla de factura

```csharp
using Aspose.Words;
using Aspose.Words.LowCode;   // Low‑code mail‑merge API

// Load the Word file that contains the merge fields.
Document template = new Document(@"C:\Invoices\Template\InvoiceTemplate.docx");
```

*La clase `Document` representa todo el archivo Word. Cargarla una vez te permite reutilizar la misma plantilla para muchas facturas.*

## Paso 2: Preparar la fuente de datos

Crea un objeto anónimo que refleje los campos de combinación. La API de bajo código puede trabajar con cualquier objeto .NET, incluidas matrices y colecciones anidadas.

```csharp
var invoiceData = new
{
    CustomerName = "Acme Corp",
    InvoiceDate = DateTime.Today,
    Items = new[]
    {
        new { Description = "Widget A", Qty = 10, Price = 9.99M },
        new { Description = "Widget B", Qty = 5,  Price = 19.95M }
    },
    Total = 199.85M
};
```

**Por qué funciona esto:**  
* Los nombres de propiedad (`CustomerName`, `InvoiceDate`, `Items`, `Total`) coinciden con los campos de combinación en la plantilla.  
* `Items` es una matriz de objetos, por lo que el combinador de correspondencia repetirá la fila de la tabla para cada elemento automáticamente.  
* Usar `decimal` (`M` suffix) para valores monetarios evita problemas de redondeo de punto flotante.

### Manejo de colecciones vacías

Si una factura no tiene líneas de detalle, pasa una matriz vacía:

```csharp
Items = new object[0]
```

El motor de bajo código simplemente omitirá la sección repetitiva, dejando intacto el encabezado de la tabla.

## Paso 3: Inicializar el combinador de correspondencia de bajo código

```csharp
MailMerger merger = new MailMerger(template);
```

`MailMerger` es el punto de entrada para **cómo combinar correspondencia** con Aspose.Words. Lee la plantilla, enlaza los datos y prepara el documento final en una única llamada.

## Paso 4: Ejecutar la combinación – poblar la plantilla de Word en una sola línea

```csharp
Document mergedDocument = merger.Execute(invoiceData);
```

* Esta línea **puebla la plantilla de Word** y produce una nueva instancia de `Document` (`mergedDocument`).  
* Todos los campos de combinación son reemplazados, las secciones repetitivas se expanden y el documento resultante reside completamente en memoria.

### Caso límite: Formato personalizado

Si necesitas un formato de fecha específico, agrega un formateador personalizado antes de la combinación:

```csharp
merger.Options.DateFormat = "MMMM dd, yyyy"; // e.g., "October 07, 2026"
```

## Paso 5: Guardar el documento combinado

```csharp
mergedDocument.Save(@"C:\Invoices\Output\Invoice_001.docx");
```

La llamada **save merged document** escribe la factura completamente poblada en el disco. El archivo ahora puede abrirse en Microsoft Word, enviarse como adjunto de correo electrónico o convertirse a PDF.

### Verificando la salida

Abre `Invoice_001.docx`. Deberías ver:

* **CustomerName** reemplazado por *Acme Corp*  
* **InvoiceDate** mostrando la fecha de hoy en el formato elegido  
* Una fila de tabla para *Widget A* (10 × 9.99) y *Widget B* (5 × 19.95)  
* **Total** mostrando *199.85*  

Si algún campo permanece sin cambios (p. ej., sigue mostrando «CustomerName»), verifica que los nombres de propiedad coincidan exactamente con los nombres de los campos de combinación en la plantilla.

## Ejemplo completo ejecutable

A continuación se muestra el programa completo que puedes copiar y pegar en un nuevo proyecto de consola.

```csharp
using System;
using Aspose.Words;
using Aspose.Words.LowCode;   // Low‑code mail‑merge API

namespace InvoiceGenerator
{
    class Program
    {
        static void Main()
        {
            // 1️⃣ Load the template
            Document template = new Document(@"C:\Invoices\Template\InvoiceTemplate.docx");

            // 2️⃣ Build the data source
            var invoiceData = new
            {
                CustomerName = "Acme Corp",
                InvoiceDate = DateTime.Today,
                Items = new[]
                {
                    new { Description = "Widget A", Qty = 10, Price = 9.99M },
                    new { Description = "Widget B", Qty = 5,  Price = 19.95M }
                },
                Total = 199.85M
            };

            // 3️⃣ Initialise the mail merger
            MailMerger merger = new MailMerger(template);

            // Optional: customise date format
            merger.Options.DateFormat = "MMMM dd, yyyy";

            // 4️⃣ Perform the merge (populate word template)
            Document mergedDocument = merger.Execute(invoiceData);

            // 5️⃣ Save the resulting file (save merged document)
            mergedDocument.Save(@"C:\Invoices\Output\Invoice_001.docx");

            Console.WriteLine("Invoice generated successfully.");
        }
    }
}
```

Ejecuta el programa (`dotnet run`). La consola imprime *Invoice generated successfully.* y el archivo aparece en `C:\Invoices\Output`.
