# Cómo mostrar porcentajes en un gráfico con Aspose.Words C#

¿Alguna vez te has preguntado **cómo mostrar porcentajes en un gráfico** sin luchar con interop de Office complejo? No estás solo—muchos desarrolladores se topan con ese obstáculo cuando necesitan una forma rápida y programática de etiquetar un gráfico de pastel o rosquilla. ¿La buena noticia? Con Aspose.Words for .NET puedes habilitar esas etiquetas de datos en solo unas pocas líneas.

En este tutorial también cubriremos **add data labels to pie chart** y **how to enable chart data labels** para que tus visualizaciones se vuelvan instantáneamente más informativas. Al final tendrás un documento Word listo‑para‑usar (`.docx`) que muestra un gráfico de pastel pulido con los porcentajes colocados ordenadamente fuera de cada porción.

## Requisitos previos

Antes de sumergirnos, asegúrate de tener:

- **Aspose.Words for .NET** (última versión, por ejemplo, 24.9) instalado vía NuGet.
- Un archivo **ChartTemplate.docx** que ya contiene un gráfico de pastel o rosquilla.  
  *(Si no tienes uno, crea un documento Word sencillo, inserta un gráfico de pastel y guárdalo como `ChartTemplate.docx`.)*
- .NET 6.0 o posterior y cualquier IDE que prefieras (Visual Studio, Rider, VS Code).

No se requieren dependencias adicionales—Aspose.Words maneja todo internamente.

## Cómo mostrar porcentajes en un gráfico – Paso a paso

A continuación dividimos el proceso en seis pasos claros. Cada paso incluye el código C# exacto que puedes copiar‑pegar, más una breve explicación de **por qué** lo hacemos.

### Paso 1: Cargar el documento fuente

```csharp
using Aspose.Words;
using Aspose.Words.Drawing.Charts;

// Load the .docx that already holds a chart.
Document sourceDoc = new Document("YOUR_DIRECTORY/ChartTemplate.docx");
```

*¿Por qué?*  
`Document` es el punto de entrada para cualquier manipulación de Word. Al cargar la plantilla obtenemos acceso a cada nodo—formas, tablas, texto y, por supuesto, el gráfico que modificaremos.

### Paso 2: Obtener la primera forma de gráfico

```csharp
// The chart lives inside a Shape node; retrieve it.
Chart chart = (Chart)sourceDoc.GetChild(NodeType.Shape, 0, true);
```

*¿Por qué?*  
Aspose almacena los gráficos como objetos `Shape`. `GetChild` recorre el árbol del documento y devuelve la primera forma que encuentra, que en nuestro caso es el gráfico de pastel que queremos editar.

### Paso 3: Confirmar el tipo de gráfico

```csharp
if (chart.ChartType == ChartType.Pie || chart.ChartType == ChartType.Doughnut)
{
    // Inside this block we’ll enable the data labels.
}
else
{
    throw new InvalidOperationException("The chart is not a Pie or Doughnut type.");
}
```

*¿Por qué?*  
Las etiquetas de porcentaje solo tienen sentido para gráficos circulares. Esta comprobación evita que apliquemos la configuración accidentalmente a, por ejemplo, un gráfico de barras donde `ShowPercentage` sería ignorado.

### Paso 4: Habilitar etiquetas de datos y mostrar porcentajes

```csharp
// Turn on data labels for the chart.
chart.HasDataLabel = true;

// Show the percentage value for each slice.
chart.DataLabel.ShowPercentage = true;
```

*¿Por qué?*  
`HasDataLabel` indica a Aspose que renderice una etiqueta para cada punto de datos. Establecer `ShowPercentage` asegura que el contenido de la etiqueta sea la parte calculada del total—exactamente lo que solicita el requisito **add data labels to pie chart**.

### Paso 5: Posicionar las etiquetas fuera de las porciones

```csharp
// Place the labels outside the pie slices for better readability.
chart.DataLabel.Position = ChartDataLabelPosition.OutSideEnd;
```

*¿Por qué?*  
Las etiquetas dentro de la porción pueden quedar apretadas, sobre todo cuando las porciones son pequeñas. `OutSideEnd` imita el estilo “externo” predeterminado que ves en la UI de Word, manteniendo el gráfico limpio.

### Paso 6: Guardar el documento actualizado

```csharp
sourceDoc.Save("YOUR_DIRECTORY/FormattedPieChart.docx");
```

*¿Por qué?*  
Guardar escribe todos los cambios en un nuevo archivo. Abre `FormattedPieChart.docx` en Word y verás los porcentajes mostrados junto a cada porción.

#### Resultado esperado

Al abrir `FormattedPieChart.docx`, el gráfico de pastel debería verse similar a esto (captura de pantalla imaginaria):

```
[ Pie chart with three slices ]
- Slice A – 45%
- Slice B – 30%
- Slice C – 25%
```

Todos los porcentajes se calculan automáticamente a partir de la serie de datos subyacente, y las etiquetas se sitúan justo fuera de cada porción.

## Variaciones comunes y casos límite

| Situación | Qué ajustar |
|-----------|----------------|
| **Múltiples gráficos** en el mismo documento | Recorrer `sourceDoc.GetChildNodes(NodeType.Shape, true)` y convertir cada uno a `Chart` antes de aplicar la misma lógica. |
| **Gráfico de barras o de líneas** donde aún deseas etiquetas | Usa `chart.DataLabel.ShowValue = true;` (o `ShowSeriesName`) en lugar de `ShowPercentage`. |
| **Formato numérico personalizado** (p.ej., “45 %”) | Establece `chart.DataLabel.NumberFormat = "0%";` antes de guardar. |
| **Conjuntos de datos grandes** que causan superposición de etiquetas | Considera `chart.DataLabel.ShowLeaderLines = true;` para dibujar líneas de conexión. |

> **Consejo profesional:** Si estás generando muchos documentos en lote, instancia un único objeto `Aspose.Words.License` al iniciar la aplicación para evitar el impacto de rendimiento de cargar la licencia repetidamente.

## Ejemplo completo funcionando

Aquí tienes el programa completo, listo para ejecutar:

```csharp
using System;
using Aspose.Words;
using Aspose.Words.Drawing.Charts;

class Program
{
    static void Main()
    {
        // 1️⃣ Load the template document.
        Document sourceDoc = new Document("YOUR_DIRECTORY/ChartTemplate.docx");

        // 2️⃣ Retrieve the first chart shape.
        Chart chart = (Chart)sourceDoc.GetChild(NodeType.Shape, 0, true);

        // 3️⃣ Ensure we’re dealing with a Pie or Doughnut chart.
        if (chart.ChartType != ChartType.Pie && chart.ChartType != ChartType.Doughnut)
        {
            Console.WriteLine("The selected shape is not a Pie/Doughnut chart.");
            return;
        }

        // 4️⃣ Enable data labels and show percentages.
        chart.HasDataLabel = true;
        chart.DataLabel.ShowPercentage = true;

        // 5️⃣ Position the labels outside the slices.
        chart.DataLabel.Position = ChartDataLabelPosition.OutSideEnd;

        // 6️⃣ Save the modified document.
        sourceDoc.Save("YOUR_DIRECTORY/FormattedPieChart.docx");

        Console.WriteLine("Chart updated successfully – percentages now visible!");
    }
}
```

Copia el código, reemplaza `YOUR_DIRECTORY` con la ruta real en tu máquina y ejecútalo. Tendrás un archivo Word con un gráfico de pastel totalmente etiquetado en segundos.

3. Verificar que sea un pastel/rosquilla.

## ¿Qué sigue?

- **Crear gráficos desde cero** – explorar `Chart chart = (Chart)sourceDoc.FirstSection.Body.AppendChild(new Shape(sourceDoc, ShapeType.Chart));` para generar gráficos programáticamente.  
- **Combinar múltiples gráficos** en un solo documento para paneles, y luego exportar a PDF con `sourceDoc.Save("Dashboard.pdf", SaveFormat.Pdf);`.
