# كيفية إنشاء مخطط عمودي في بايثون باستخدام Aspose.Words

إذا كنت بحاجة إلى إنشاء مخطط عمودي في بايثون، يوضح لك هذا الدليل الشيفرة الدقيقة والمنطق اللازم. باستخدام Aspose.Words chart API، يمكنك تحديد أبعاد دقيقة، وتطبيق نمط مدمج، وتصدير النتيجة دون مغادرة بايثون.

إنشاء مخطط عمودي هو طلب شائع للتقارير، ولوحات المعلومات، وإنشاء المستندات تلقائيًا. يغطي هذا الدرس كل خطوة — من استيراد المكتبة إلى التحقق من الصورة المحفوظة — حتى تتمكن من دمج إنشاء المخططات في أي مشروع بايثون.

## المتطلبات المسبقة

* تثبيت Python 3.8 أو أحدث.
* ترخيص صالح لـ Aspose.Words for Python (أو مفتاح تقييم مجاني).
* إلمام أساسي بوحدات بايثون والبرمجة الكائنية.

محرك مخططات Aspose.Words يعمل على Windows و macOS و Linux، ولا يتطلب مكتبات رسومية إضافية لأن عملية التصيير تتم على جانب الخادم.

## الخطوة 1: استيراد مكتبة Aspose.Words

الخطوة الأولى هي استيراد حزمة `aspose.words` وإعطائها اختصارًا قصيرًا. الاستيراد في أعلى الملف يحافظ على نظافة مساحة الأسماء ويسهل قراءة الشيفرة.

```python
# Step 1: Import the Aspose.Words library
import aspose.words as aw
```

`aw` الآن يشير إلى كامل Aspose.Words API، بما في ذلك فئة `Chart` التي ستستخدمها لإنشاء المخطط العمودي.

## الخطوة 2: إنشاء مخطط عمودي بالأبعاد المطلوبة

المخطط العمودي يحتاج إلى قيم صريحة للعرض والارتفاع حتى تتناسب الصورة المصدرة مع تنسيق المستند. مُنشئ `Chart` يأخذ ثلاثة معطيات: نوع المخطط، العرض (بالنقاط)، والارتفاع (بالنقاط). استخدام `aw.ChartType.COLUMN` يُخبر المحرك بإنشاء مخطط شريطي عمودي.

```python
# Step 2: Create a column chart with the desired dimensions
chart = aw.Chart(aw.ChartType.COLUMN, 400, 300)   # width=400pt, height=300pt
```

*لماذا ضبط الأبعاد؟*  
عند تضمين المخطط في مستند Word أو تصديره كصورة، يحترم المحتوى المحيط الحجم الدقيق الذي تقدمه. هذا يمنع التحجيم أو القطع غير المرغوب فيه.

### نصيحة احترافية: استخدم `chart.dimensions` لإعادة التحجيم الديناميكي

إذا كان مجموعة البيانات مختلفة، يمكنك حساب الحجم بناءً على عدد السلاسل:

```python
series_count = 5
base_width = 80
chart.width = base_width * series_count
chart.height = 300
```

## الخطوة 3: تطبيق نمط مدمج على المخطط العمودي

تأتي Aspose.Words مع عدة سمات بصرية معرفة مسبقًا. اختيار نمط يزيل الحاجة إلى ضبط الألوان والخطوط وخطوط الشبكة يدويًا. `aw.ChartStyle.STYLE_5` هو مظهر نظيف واحترافي يناسب معظم التقارير التجارية.

```python
# Step 3: Apply a built‑in style to the chart
chart.style = aw.ChartStyle.STYLE_5
```

إذا كنت تفضل مظهرًا مختلفًا، استبدل `STYLE_5` بأي من الثوابت الأخرى (`STYLE_1` … `STYLE_8`). كل نمط يتبع نفس نمط التسمية، مما يسهل التجربة.

### حالة خاصة: ثابت نمط غير صالح

محاولة تعيين نمط غير موجود تُثير استثناء `AttributeError`. احمِ نفسك من ذلك بالتحقق من الثابت مقابل التعداد:

```python
if hasattr(aw.ChartStyle, "STYLE_5"):
    chart.style = aw.ChartStyle.STYLE_5
else:
    raise ValueError("Requested chart style does not exist.")
```

## الخطوة 4: إضافة سلاسل بيانات إلى المخطط العمودي

المخطط بدون بيانات لا معنى له. يمكنك إضافة كائن أو أكثر من `ChartSeries`، كل واحد يمثل مجموعة أعمدة. المثال التالي يضيف سلسلة واحدة بثلاث نقاط بيانات.

```python
# Step 4: Add data series to the column chart
series = chart.series.add()
series.name = "Quarterly Sales"
series.data = [12000, 15000, 18000]   # Values for Q1, Q2, Q3
```

يمكنك تكرار استدعاء `chart.series.add()` لإضافة سلاسل إضافية (مثلاً، “Projected Sales”). الـ API يوزع الأعمدة تلقائيًا جنبًا إلى جنب.

## الخطوة 5: تصيير المخطط وحفظه كصورة

بعد تكوين المخطط، تقوم بتصيره إلى صورة bitmap أو ملف صورة. طريقة `save` تقبل مسار ملف وصيغة اختيارية. PNG صيغة غير مضغوطة وتدعم على نطاق واسع.

```python
# Step 5: Render and save the chart as a PNG image
output_path = "column_chart.png"
chart.save(output_path, aw.SaveFormat.PNG)
print(f"Chart saved to {output_path}")
```

تعداد `SaveFormat` يضم PNG، JPEG، BMP، وغيرها. اختر الصيغة التي تتوافق مع سير عملك اللاحق.

## التحقق من النتيجة

افتح `column_chart.png` بأي عارض صور. يجب أن ترى مخططًا شريطيًا بثلاثة أعمدة مُنسقًا بالنمط المدمج المختار، بحجم 400 × 300 نقطة بالضبط.

![مخطط عمودي تم إنشاؤه بواسطة Aspose.Words في بايثون](column_chart.png){: .center alt="لقطة شاشة لمخطط عمودي تم إنشاؤه بواسطة Aspose.Words في بايثون"}

إذا ظهرت الصورة فارغة أو مشوهة، تحقق مرة أخرى من ما يلي:

1. تم إنشاء كائن `aw.Chart` قبل إضافة السلاسل.
2. ثابت `chart.style` يطابق قيمة موجودة في التعداد.
3. استدعاء `save` يستخدم `SaveFormat` مدعوم.

## تنويعات شائعة ونصائح إضافية

| الوضع | التغيير الموصى به |
|-----------|--------------------|
| **سلاسل بيانات متعددة** | أضف كتل `chart.series.add()` إضافية وحدد `series.name` و `series.data` لكل منها. |
| **ألوان مخصصة** | بعد تطبيق نمط مدمج، تجاوز ألوان الأعمدة الفردية عبر `series.points[i].fill.fore_color`. |
| **تضمين في مستند Word** | بدلاً من `chart.save()`، استخدم `doc = aw.Document(); doc.sections[0].body.append_child(chart); doc.save(\"report.docx\")`. |
| **تحجيم ديناميكي** | احسب العرض بناءً على عدد السلاسل (`width = 80 * len(chart.series)`). |

تظهر هذه التنويعات كيف يتكيف نفس الكود الأساسي مع سيناريوهات تقارير مختلفة.
