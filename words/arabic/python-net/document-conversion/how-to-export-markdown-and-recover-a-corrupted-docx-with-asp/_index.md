# كيفية تصدير markdown واستعادة ملف DOCX تالف باستخدام Aspose.Words

إذا كنت بحاجة إلى **كيفية تصدير markdown** من ملف Word قد يكون تالفًا، يوضح لك هذا الدليل الخطوات الدقيقة. كما يغطي **كيفية استعادة المستند**، **تصدير docx إلى txt**، و**حفظ Word كـ pdf** باستخدام Aspose.Words for Python API.

ستمر بعملية تحميل DOCX قد يكون تالفًا في وضع الاستعادة، تحويله إلى Markdown مع الحفاظ على المعادلات، حفظ المحتوى نفسه كنص عادي، إنشاء PDF سهل الوصول، وحتى تعديل ظل شكل قبل التصدير النهائي. لا تحتاج إلى أدوات خارجية—فقط Aspose.Words وبعض أسطر Python.

## المتطلبات المسبقة

قبل أن تبدأ، تأكد من وجود:

* Python 3.8 أو أحدث
* حزمة `aspose-words` (`pip install aspose-words`)
* ملف DOCX قد يكون تالفًا (أو أي ملف DOCX عادي للاختبار)
* إلمام أساسي بدوال وفئات Python

> **نصيحة احترافية:** احتفظ بنسخة احتياطية من ملف DOCX الأصلي؛ وضع الاستعادة يغيّر التمثيل في الذاكرة لكنه لا يكتب مرة أخرى إلى الملف المصدر.

## الخطوة 1: كيفية استعادة DOCX تالف

العقبة الأولى هي تحميل الملف بأمان. توفر Aspose.Words علم `RecoveryMode.RECOVER_CORRUPTED` الذي يحاول إعادة بناء بنية المستند المكسورة.

```python
import aspose.words as aw

# Load the file in recovery mode
load_opts = aw.LoadOptions()
load_opts.recovery_mode = aw.RecoveryMode.RECOVER_CORRUPTED
doc = aw.Document("YOUR_DIRECTORY/input.docx", load_opts)
```

**لماذا هذا مهم:**  
عندما يكون DOCX متضررًا جزئيًا—أجزاء مفقودة، XML مكسور، أو علاقات غير صحيحة—يؤدي التحميل القياسي إلى استثناء. يقوم وضع الاستعادة بتحليل ما يمكن، ويتجاهل القطع غير القابلة للقراءة مع الحفاظ على البقية، وهو أمر أساسي لأي عملية **تصدير docx إلى txt** أو **حفظ Word كـ pdf** لاحقة.

### حالة حافة شائعة
إذا كان المستند خارج نطاق الإصلاح، سيظل `doc` يُنشأ لكن مع سجل تحذير. يمكنك فحص `doc.is_dirty` لمعرفة ما إذا تم تعديل أي محتوى أثناء الاستعادة.

## الخطوة 2: كيفية تصدير markdown باستخدام Aspose.Words

Markdown هي لغة توصيف خفيفة يحبها العديد من مولّدات المواقع الثابتة وأدوات التوثيق. يمكن لـ Aspose.Words إنتاج Markdown مع إبقاء المعادلات بصيغة LaTeX، وهو مثالي للتوثيق التقني.

```python
# Configure Markdown export options
md_opts = aw.MarkdownSaveOptions()
md_opts.office_math_export_mode = aw.OfficeMathExportMode.LATEX

# Save as Markdown
doc.save("YOUR_DIRECTORY/output.md", md_opts)
```

**ما ستحصل عليه:**  
* نص عادي مع عناوين، قوائم، وجداول تم تحويلها إلى صيغة Markdown.  
* كل معادلة Word تُعرض ككتلة LaTeX (`$$ … $$`)، مما يضمن بقاء الرياضيات قابلة للتحرير في الأدوات اللاحقة.

### تحقق من النتيجة
افتح `output.md` في أي محرر. يجب أن ترى شيئًا مشابهًا لـ:

```markdown
# Title of the Document

This is a paragraph with **bold** text.

$$
\int_{0}^{\infty} e^{-x} dx = 1
$$
```

إذا كنت تحتاج إلى صيغة معادلة مختلفة (مثل MathML)، غيّر `office_math_export_mode` وفقًا لذلك.

## الخطوة 3: تصدير docx إلى txt مع الحفاظ على المعادلات

ملفات النص العادي مفيدة للبحث السريع أو لتغذيتها إلى خطوط معالجة اللغة الطبيعية. يعمل نفس `OfficeMathExportMode.LATEX` لتصدير `.txt`، مما يمنحك LaTeX مقروءًا داخل النص.

```python
txt_opts = aw.TxtSaveOptions()
txt_opts.office_math_export_mode = aw.OfficeMathExportMode.LATEX

doc.save("YOUR_DIRECTORY/output.txt", txt_opts)
```

**لماذا تستخدم هذا بدلاً من النسخ‑اللصق؟**  
النسخ‑اللصق اليدوي غالبًا ما يزيل الأحرف المخفية ويفقد دقة المعادلات. يضمن هذا النهج **تصدير docx إلى txt** ظهور كل معادلة كقطعة LaTeX، جاهزة للمعالجة الإضافية.

## الخطوة 4: حفظ Word كـ PDF مع أشكال داخلية لتحسين إمكانية الوصول

PDF هو الصيغة السائدة للنشر. عندما يحتوي مستند Word على صور أو مخططات عائمة، قد لا يفسّرها بعض القارئات بشكل صحيح. يفرض `export_floating_shapes_as_inline_tag` تحويل تلك الأشكال إلى داخلية، مما يحسّن إمكانية الوصول وتناسق التخطيط.

```python
pdf_opts = aw.PdfSaveOptions()
pdf_opts.export_floating_shapes_as_inline_tag = True

doc.save("YOUR_DIRECTORY/output.pdf", pdf_opts)
```

**النتيجة:**  
PDF يعكس التخطيط الأصلي، لكن جميع الأشكال أصبحت الآن جزءًا من تدفق النص. هذا مفيد بشكل خاص لقارئات الشاشة، حيث تُعامل العناصر الداخلية كجزء من ترتيب القراءة.

### نصيحة للمستندات الكبيرة
إذا كنت تُنشئ ملفات PDF على دفعات، أعد استخدام نفس كائن `PdfSaveOptions` لتجنب إنشاء كائنات غير ضرورية.

## الخطوة 5: ضبط ظل الشكل قبل PDF النهائي

أحيانًا تحتاج إلى تعديل تفاصيل بصرية—مثل ظل الشعار—قبل النشر. المثال أدناه يلتقط الشكل الأول، يغيّر خصائص الظل، ويحفظ PDF جديد.

```python
# Retrieve the first shape in the document
shape = doc.get_child(aw.NodeType.SHAPE, 0, True).as_shape()

# Adjust shadow settings
shape.shadow.blur_radius = 5.0   # Soft blur
shape.shadow.distance = 2.0     # Distance from shape edge
shape.shadow.opacity = 0.6      # 60% opacity

# Save the shadow‑enhanced PDF
doc.save("YOUR_DIRECTORY/shadowed.pdf", pdf_opts)
```

**ما يفعله هذا:**  
* `blur_radius` يتحكم في مدى ضبابية الظل.  
* `distance` يبعد الظل عن الشكل، مخلقًا عمقًا.  
* `opacity` يجعل الظل شبه شفاف، وهو ما يبدو أكثر احترافية غالبًا.

يمكنك تكرار هذا الكود لأي شكل بتغيير الفهرس في `get_child`.

## البرنامج الكامل للنسخ‑اللصق السريع

فيما يلي البرنامج الكامل القابل للتنفيذ الذي يجمع جميع الخطوات. استبدل `YOUR_DIRECTORY` بالمسار الذي توجد فيه ملفاتك.

```python
import aspose.words as aw

# -------------------------------------------------
# 1️⃣ Recover a possibly corrupted DOCX
# -------------------------------------------------
load_opts = aw.LoadOptions()
load_opts.recovery_mode = aw.RecoveryMode.RECOVER_CORRUPTED
doc = aw.Document("YOUR_DIRECTORY/input.docx", load_opts)

# -------------------------------------------------
# 2️⃣ Export to Markdown (how to export markdown)
# -------------------------------------------------
md_opts = aw.MarkdownSaveOptions()
md_opts.office_math_export_mode = aw.OfficeMathExportMode.LATEX
doc.save("YOUR_DIRECTORY/output.md", md_opts)

# -------------------------------------------------
# 3️⃣ Export to plain text (export docx to txt)
# -------------------------------------------------
txt_opts = aw.TxtSaveOptions()
txt_opts.office_math_export_mode = aw.OfficeMathExportMode.LATEX
doc.save("YOUR_DIRECTORY/output.txt", txt_opts)

# -------------------------------------------------
# 4️⃣ Save as PDF (save word as pdf)
# -------------------------------------------------
pdf_opts = aw.PdfSaveOptions()
pdf_opts.export_floating_shapes_as_inline_tag = True
doc.save("YOUR_DIRECTORY/output.pdf", pdf_opts)

# -------------------------------------------------
# 5️⃣ Adjust first shape's shadow and re‑save PDF
# -------------------------------------------------
shape = doc.get_child(aw.NodeType.SHAPE, 0, True).as_shape()
shape.shadow.blur_radius = 5.0
shape.shadow.distance = 2.0
shape.shadow.opacity = 0.6
doc.save("YOUR_DIRECTORY/shadowed.pdf", pdf_opts)
```

تشغيل البرنامج ينتج:

| الملف | الغرض |
|------|---------|
| `output.md` | Markdown مع معادلات LaTeX (**كيفية تصدير markdown**) |
| `output.txt` | نسخة نصية عادية (**تصدير docx إلى txt**) |
| `output.pdf` | PDF سهل الوصول (**حفظ Word كـ pdf**) |
| `shadowed.pdf` | PDF مع شكل مُصمم بظل مخصص |

## الأسئلة المتكررة

**س: هل يقوم وضع الاستعادة بإصلاح الصور المفقودة؟**  
ج: يعيد وضع الاستعادة بنية المستند لكنه لا يستطيع إعادة إنشاء بيانات الصورة الثنائية المفقودة. إذا كان جزء الصورة مفقودًا، سيبقى الشكل فارغًا.

**س: هل يمكنني التصدير إلى HTML بدلاً من Markdown؟**  
ج: نعم—استخدم `aw.HtmlSaveOptions()` واضبط `office_math_export_mode` حسب الحاجة.

**س: ماذا لو أردت إبقاء الأشكال العائمة كعائمة؟**  
ج: احذف `export_floating_shapes_as_inline_tag` أو عيّن قيمته إلى `False`.

**س: هل تصدير LaTeX متوافق مع MathJax؟**  
ج: بالتأكيد. MathJax يعرض كتل `$$ … $$` التي يولدها مُصدّرا الـ Markdown وTxt.
