# كيفية تحويل docx إلى markdown مع الصور في مجلد فرعي

إذا كنت بحاجة إلى **convert docx to markdown** مع الحفاظ على كل صورة مدمجة منظمة بشكل أنيق، فأنت في المكان الصحيح. العديد من المطورين يولدون تقارير، أدلة، أو مسودات مدونات برمجياً وينتهي بهم الأمر بخلط فوضوي لملفات الصور المنتشرة عبر دليل الإخراج. يوضح هذا الدرس نهجًا نظيفًا يعتمد على رد النداء باستخدام Aspose.Words for .NET لتصدير المستند إلى markdown، وتخزين كل صورة في مجلد *md‑resources* مخصص، وحفظ ملف markdown النهائي جاهزًا للنشر.

> **نظرة سريعة:**  
> • إعداد `MarkdownSaveOptions`  
> • تنفيذ `IResourceSavingCallback` لإعادة توجيه الصور  
> • استدعاء `Document.Save` مع الخيارات المكوَّنة  

الآن بعد أن فهمت لماذا يُفضَّل رد النداء على المعالجة اللاحقة، دعنا نغوص في الحل خطوة بخطوة.

## إجابات سريعة
- **ماذا يعني “convert docx to markdown” فعليًا؟** يحول تنسيق معالجة النصوص إلى نص markdown عادي مع الحفاظ على العناوين والقوائم والجداول وإشارات الصور.  
- **أي مكتبة تتولى التحويل؟** توفر Aspose.Words for .NET واجهة برمجة تطبيقات مدارة بالكامل تعمل على الخادم دون الحاجة إلى تثبيت Microsoft Word.  
- **هل أحتاج إلى كتابة أي كود لمعالجة الصور؟** لا؛ يتولى `IResourceSavingCallback` حفظ كل صورة في المجلد الذي تحدده.  
- **هل يمكنني تغيير اسم مجلد الإخراج؟** بالتأكيد – استبدل `"md-resources/"` بأي مسار نسبي أو مطلق تفضله.  
- **هل الحل متوافق مع .NET 6 وما بعده؟** نعم، يعمل على .NET 6+، .NET 5، .NET Core 3.1 و .NET Framework 4.7+.

## ما هو تحويل docx إلى markdown؟
**Convert docx to markdown** هو عملية أخذ مستند Microsoft Word (DOCX) وإنشاء ملف markdown (`.md`) يمثل نفس المحتوى باستخدام صيغة markdown. يحافظ التحويل على العناصر الهيكلية ويستخرج اختياريًا الموارد المدمجة مثل الصور.

يتم التحويل بواسطة Aspose.Words، مكتبة تدعم **35+ تنسيقًا للإدخال والإخراج** — بما في ذلك DOCX، PDF، HTML، و Markdown — مما يتيح لك التعامل مع مستندات مئات الصفحات دون تحميل الملف بالكامل في الذاكرة.

## لماذا نستخدم Aspose.Words لتصدير markdown؟
تعالج Aspose.Words المستندات في الذاكرة وتكتب النتيجة مباشرةً إلى الصيغة المستهدفة، مما يعني:

توفر Aspose.Words تحويلًا عالي الأداء ودقيقًا مع إعطائك تحكمًا كاملاً في معالجة الموارد. يلغي الحاجة إلى خطوات ما بعد المعالجة، يقلل من استهلاك الذاكرة، ويضمن أن الصور والجداول والأنماط تُعاد إنتاجها بأمان في ناتج markdown.

- **السرعة:** تُحوَّل ملفات DOCX ذات 200 صفحة عادةً إلى markdown في أقل من ثانيتين على جهاز افتراضي قياسي.  
- **الدقة:** تدعم جميع نكهات markdown الـ 50+ المدمجة، مما يضمن عرض الجداول، كتل الشيفرة، والحواشي بشكل صحيح.  
- **التحكم في الموارد:** يتيح `IResourceSavingCallback` المدمج لك تحديد بالضبط أين تُحفظ كل صورة، مما يلغي الحاجة إلى خطوة تنظيف منفصلة.

## المتطلبات المسبقة

- .NET 6.0 أو أحدث (متوافق مع .NET Framework 4.7+ أيضًا)  
- Aspose.Words for .NET (حزمة NuGet `Aspose.Words`)  
- كائن `Document` مصدر (DOCX، PDF، RTF، إلخ)  

لا توجد مكتبات إضافية مطلوبة؛ واجهة رد النداء جزء من Aspose.Words.

## كيفية تحويل docx إلى markdown؟

حمِّل مستندك المصدر باستخدام `new Document("source.docx")`، واضبط `MarkdownSaveOptions` لاستخدام رد نداء يكتب كل صورة إلى `md-resources/`، ثم استدعِ `doc.Save("output.md", saveOptions)`. هذا النمط المكوَّن من ثلاث خطوات يحول الملف، يستخرج الصور، وينتج ملف markdown نظيف مع روابط صور نسبية — كل ذلك في استدعاء طريقة واحد.

### الخطوة 1: تكوين خيارات الحفظ لتحويل markdown

MarkdownSaveOptions تُحدد كيفية تحويل Aspose.Words للمستند إلى Markdown.

```csharp
// Step 1: Initialize Markdown save options
var markdownSaveOptions = new Aspose.Words.Saving.MarkdownSaveOptions();
```

```csharp
// Step 1: Initialize Markdown save options
var markdownSaveOptions = new Aspose.Words.Saving.MarkdownSaveOptions();
```

> **لماذا هذا مهم:**  
> بدون إنشاء `MarkdownSaveOptions` صراحةً، تعود المكتبة إلى الإعدادات الافتراضية التي تُضمِّن الصور مباشرةً في ملف Markdown كسلاسل Base64. هذا يجعل الملف ضخمًا ويُفقد الهدف من وجود مجلد *الصور* المنظم.

### الخطوة 2: تعريف رد نداء حفظ الموارد لتصدير الصور

`IResourceSavingCallback` يتيح لك التحكم في مكان حفظ كل مورد (صورة، SVG) أثناء التصدير.

الآن نخبر الحافظ **أين** يضع كل صورة. تُوفر واجهة `IResourceSavingCallback` نقطة ارتكاز تُطلق لكل مورد (صورة، SVG، إلخ) يُكتشف أثناء التصدير. داخل رد النداء نقوم بـ:

1. التأكد من وجود المجلد الهدف (`md-resources/`).  
2. تعيين `OutputFileName` إلى المجلد مضافًا إليه اسم المورد الأصلي.  

```csharp
// Step 2: Hook into the resource‑saving pipeline
markdownSaveOptions.ResourceSavingCallback = new Aspose.Words.Saving.IResourceSavingCallback(
    (args) =>
    {
        // All images will be placed in "md-resources" relative to the output .md file
        const string folder = "md-resources/";
        Directory.CreateDirectory(folder);          // Create folder if it doesn’t exist

        // Preserve the original file name (e.g., image001.png) but prepend the folder path
        args.OutputFileName = Path.Combine(folder, args.ResourceFileName);

        // Optional: you could also change the format here (e.g., convert BMP to PNG)
        // args.ResourceFileName = Path.ChangeExtension(args.ResourceFileName, ".png");
    });
```

> **سؤال شائع:** *ماذا لو أردت تضمين الصور بدلاً من حفظها؟*  
> فقط تجاهل رد النداء أو عيّن `args.OutputFileName = null;` — سيُضمِّن الحافظ الصورة كسلسلة Base64 تلقائيًا.

> **حالة حافة:** بعض المستندات القديمة تحتوي على أسماء صور مكررة. سيُعيد رد النداء أعلاه الكتابة فوق الملف السابق. لتجنب ذلك، يمكنك إلحاق GUID:

```csharp
args.OutputFileName = Path.Combine(folder,
    $"{Path.GetFileNameWithoutExtension(args.ResourceFileName)}_{Guid.NewGuid()}{Path.GetExtension(args.ResourceFileName)}");
```

### الخطوة 3: حفظ المستند كـ markdown والتحقق من النتيجة

مع تكوين الخيارات بالكامل، يكون الاستدعاء النهائي سطرًا واحدًا يكتب ملف Markdown والصور المرتبطة إلى القرص.

```csharp
// Step 3: Perform the actual export
string outputPath = @"C:\Exports\MyReport.md";
doc.Save(outputPath, markdownSaveOptions);
```

إذا سارت الأمور كما هو متوقع، سترى:

- `MyReport.md` – تمثيل Markdown لمستندك المصدر.  
- `md-resources/` – مجلد بجوار ملف `.md` يحتوي على كل صورة مستخرجة (مثلًا `image001.png`, `image002.jpg`).  

**مقتطف markdown نموذجي** (تم توليده تلقائيًا بواسطة Aspose.Words):

```markdown
# Sample Report

Here is an introductory paragraph.

![Sample image](md-resources/image001.png)

More text follows...
```

[صورة مثال](md-resources/image001.png)

> **نصيحة احترافية:** افتح ملف `.md` المُولد في VS Code أو أي عارض Markdown؛ يجب أن تُعرض الصور فورًا لأن المسارات النسبية تتطابق مع بنية المجلد.

## مثال كامل قابل للتنفيذ (بدون كتل شفرة إضافية)

فيما يلي برنامج وحدة تحكم مستقل يمكنك لصقه في مشروع .NET جديد وتشغيله. ينشئ مستند Word بسيطًا، يضيف صورة، ثم **ينشئ markdown من المستند** مع تخزين الصورة في مجلد فرعي.

```csharp
using System;
using System.IO;
using Aspose.Words;
using Aspose.Words.Saving;

class Program
{
    static void Main()
    {
        // 1️⃣ Create a sample Word document with an image
        var doc = new Document();
        var builder = new DocumentBuilder(doc);
        builder.Writeln("Hello, this is a test document.");
        builder.InsertImage("sample-image.png"); // Ensure this file exists next to exe

        // 2️⃣ Configure markdown export options (see Step 1 & 2 above)
        var markdownOptions = new MarkdownSaveOptions();
        markdownOptions.ResourceSavingCallback = new IResourceSavingCallback(
            (args) =>
            {
                const string folder = "md-resources/";
                Directory.CreateDirectory(folder);
                args.OutputFileName = Path.Combine(folder, args.ResourceFileName);
            });

        // 3️⃣ Save as markdown (Step 3)
        string outputFolder = Path.Combine(Environment.CurrentDirectory, "output");
        Directory.CreateDirectory(outputFolder);
        string markdownPath = Path.Combine(outputFolder, "ExportedDoc.md");
        doc.Save(markdownPath, markdownOptions);

        Console.WriteLine($"✅ Markdown saved to: {markdownPath}");
        Console.WriteLine("📂 Images saved in: md-resources/");
    }
}
```

**ما يجب أن تراه** بعد التشغيل:

```
✅ Markdown saved to: C:\MyProject\output\ExportedDoc.md
📂 Images saved in: md-resources/
```

افتح `ExportedDoc.md` — ستشير إشارة الصورة إلى `md-resources/sample-image.png`، وستظهر الصورة بشكل صحيح في أي عارض Markdown.

## المشكلات الشائعة والحلول

- **عدم ظهور الصور في معاينة markdown** – تحقق من أن المسار النسبي في markdown (`md-resources/image001.png`) يطابق الموقع الفعلي للمجلد بالنسبة لملف `.md`.  
- **تكرار أسماء الصور يسبب الكتابة فوقها** – أضف معرفًا فريدًا (GUID أو عداد تزايدي) داخل رد النداء لضمان أسماء ملفات مميزة.  
- **المستندات الكبيرة تسبب ضغطًا على الذاكرة** – استخدم `Document.OptimizeResources()` قبل الحفظ؛ هذا يقلل استهلاك الذاكرة عن طريق التخلص من التيارات غير المستخدمة.  
- **تنسيقات صور غير مدعومة** – تدعم Aspose.Words PNG، JPEG، BMP، GIF، و TIFF. حوّل التنسيقات غير المدعومة إلى أحد هذه قبل إضافتها إلى المستند المصدر.

## الخلاصة

لقد عرضنا **كيفية تحويل docx إلى markdown**، **تصدير المستند إلى markdown**، و**حفظ الصور في مجلد فرعي** باستخدام نمط نظيف يعتمد على رد النداء. النقاط الرئيسية هي:

- استخدم `MarkdownSaveOptions` للتحكم الدقيق.

الخطوات التالية قد تشمل تخصيص أنماط العناوين، دمج الروتين في خط أنابيب CI، أو تقديمه كخدمة مصغرة تُعيد ملف ZIP يحتوي على markdown وموارده. الآن لديك اللبنات الأساسية في صندوق أدواتك، لذا يمكنك أتمتة خطوط تحويل المستند إلى markdown بثقة.
