# كيفية إنشاء مخطط دونات في مستند Word باستخدام Java

إذا كنت بحاجة إلى **إنشاء مخطط دونات** داخل ملف Word، فإن هذا الدليل يوضح لك حلاً كاملاً جاهزًا للتنفيذ. ستتعرف على كيفية **إدراج مخطط دائري**، تحويله إلى دونات، **تدوير المخطط الدائري** لتحقيق توازن أفضل، و**تنسيق المخطط الدائري** ليتماشى مع هوية علامتك التجارية. في النهاية ستحصل على مستند Word احترافي يمكن استخدامه في التقارير، لوحات التحكم، أو مرفقات البريد الإلكتروني الآلية.

إنشاء المخطط برمجيًا يلغي خطوات النسخ واللصق اليدوية ويضمن تنسيقًا موحدًا عبر العشرات من المستندات المولدة. يستخدم المثال مكتبة Aspose.Words for Java، التي تعمل مع Java 8+ ولا تتطلب تثبيت Microsoft Office. لا توجد متطلبات أخرى سوى JDK قياسي وبيئة التطوير المتكاملة المفضلة لديك.

## المتطلبات المسبقة

- مجموعة تطوير جافا (JDK) 8 أو أحدث  
- Maven أو Gradle لإدارة التبعيات (الدليل يستخدم Maven)  
- مكتبة Aspose.Words for Java (رخصة التجربة المجانية كافية للاختبار)  

أضف تبعية Aspose.Words إلى ملف `pom.xml` الخاص بك:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-words</artifactId>
    <version>24.9</version> <!-- Use the latest stable version -->
</dependency>
```

> **نصيحة احترافية:** سجّل رخصتك باستخدام `License license = new License(); license.setLicense("Aspose.Words.lic");` قبل إنشاء أي مستند لإزالة العلامات المائية الخاصة بالتقييم.

## إنشاء مخطط دونات في مستند Word

تتكون سير العمل الأساسية من خمس خطوات منطقية. كل خطوة موضوعة في طريقة خاصة بها للحفاظ على نظافة وإعادة استخدام الكود.

```java
import com.aspose.words.*;
import com.aspose.words.drawing.*;

public class DoughnutChartDemo {

    public static void main(String[] args) throws Exception {
        // Step 1: create blank Word document
        Document doc = createBlankWordDocument();

        // Step 2: insert a pie chart (base for the doughnut)
        Chart chart = insertPieChart(doc, 400, 300);

        // Step 3: convert the pie chart into a doughnut and rotate it
        customizeChartAppearance(chart);

        // Step 4: apply additional formatting to the chart
        formatPieChart(chart);

        // Step 5: save the final document
        doc.save("output/DoughnutChartFormatted.docx");
        System.out.println("Document saved successfully.");
    }

    /** Step 1 – create blank Word document */
    private static Document createBlankWordDocument() {
        // Aspose.Words creates an empty document by default
        return new Document();
    }

    /** Step 2 – insert pie chart with given dimensions */
    private static Chart insertPieChart(Document doc, int width, int height) throws Exception {
        DocumentBuilder builder = new DocumentBuilder(doc);
        // ChartType.PIE creates a standard pie chart that we will later turn into a doughnut
        Chart chart = builder.insertChart(ChartType.PIE, width, height);
        // Populate the chart with sample data
        chart.getSeries().clear(); // Remove default series
        ChartSeries series = chart.getSeries().add("Sales", new String[]{"Q1", "Q2", "Q3", "Q4"},
                new double[]{15000, 23000, 18000, 27000});
        return chart;
    }

    /** Step 3 – rotate pie chart and make it a doughnut */
    private static void customizeChartAppearance(Chart chart) {
        // Explode the first slice for emphasis
        chart.getSeries().get(0).setExplode(20);
        // Convert the pie into a doughnut by setting a hole size (percentage of radius)
        chart.setHoleSize(30); // 30% hole creates a classic doughnut look
        // Rotate the chart so the largest slice starts at 45°
        chart.setRotationAngle(45);
    }

    /** Step 4 – additional formatting of the pie chart */
    private static void formatPieChart(Chart chart) {
        // Example: change the first slice color to a brand color
        chart.getSeries().get(0).getPoints().get(0).getFormat().setFillForegroundColor(Color.fromArgb(0xFF, 0x4A, 0x90));
        // Add a legend and position it at the bottom
        chart.setHasLegend(true);
        chart.getLegend().setPosition(LegendPosition.BOTTOM);
        // Set a title for the chart
        chart.setTitle("Quarterly Sales Distribution");
    }
}
```

### ما يفعله الكود

| الخطوة | الإجراء | السبب |
|------|--------|--------|
| **إنشاء مستند Word فارغ** | `new Document()` | يبدأ بملف نظيف لتتحكم في كل عنصر. |
| **إدراج مخطط دائري** | `builder.insertChart(ChartType.PIE, …)` | المخطط الدائري هو الشكل الأساسي؛ Aspose يوفر فقط دونات عبر تعديل حجم الفتحة. |
| **تدوير المخطط الدائري** | `chart.setRotationAngle(45)` | التدوير يضع أكبر شريحة في موضع أكثر قابلية للقراءة. |
| **تنسيق المخطط الدائري** | `setExplode`, `setHoleSize`, اللون, الوسيلة الإيضاحية | يحسن التسلسل البصري ويتماشى مع إرشادات نمط الشركة. |
| **حفظ المستند** | `doc.save("…/DoughnutChartFormatted.docx")` | يكتب ملف .docx النهائي إلى القرص، جاهزًا للتوزيع. |

## إدراج مخطط دائري قبل تحويله إلى دونات

لا توفر Aspose.Words طريقة مباشرة لـ “إدراج مخطط دونات”. بدلاً من ذلك، **تقوم بإدراج مخطط دائري** ثم تعديل خصائصه. يمنحك هذا النهج ذو الخطوتين تحكمًا كاملاً في سلسلة البيانات، انفجار الشرائح، وحجم الفتحة. إذا كنت بحاجة إلى مخطط دائري نقي في مكان آخر، ما عليك سوى حذف استدعاء `setHoleSize`.

## تدوير المخطط الدائري لتحقيق توازن بصري

الاتجاه الافتراضي يبدأ الشريحة الأولى عند موضع الساعة 12. في العديد من التقارير التجارية، يجب أن تبدأ الشريحة الأكثر أهمية بزاوية أكثر طبيعية، مثل 45 درجة. تقبل الطريقة `setRotationAngle(double angle)` القيم بالدرجات وتدوّر المخطط بالكامل دون التأثير على قيم البيانات.

## تنسيق المخطط الدائري وتخصيص المظهر

إلى جانب تحويله إلى دونات، غالبًا ما ترغب في **تنسيق المخطط الدائري**:

- **انفجار** الشريحة الأولى (`setExplode`) لجذب الانتباه.  
- **تلوين** كل شريحة باستخدام `getPoints().get(i).getFormat().setFillForegroundColor`.  
- **موضع** الوسيلة الإيضاحية (`setHasLegend`, `setPosition`) يساعد القراء على تفسير الفئات.  
- **العنوان** (`setTitle`) يوفّر سياقًا سريعًا.  

جميع هذه الإعدادات اختيارية؛ يمكنك تعديلها لتتناسب مع لوحة ألوان علامتك التجارية أو القوالب المؤسسية.

## إنشاء مستند Word فارغ وحفظ النتيجة

طريقة `createBlankWordDocument` تغلف خطوة **إنشاء مستند Word فارغ**. عزل هذه المنطق يجعل من السهل إعادة استخدام الطريقة عند توليد تقارير متعددة في عملية دفعة. بعد جميع التخصيصات، تقوم `doc.save` بكتابة الملف بصيغة Office Open XML القياسية (`.docx`)، والتي يمكن فتحها في Microsoft Word أو LibreOffice أو Google Docs دون فقدان الجودة.

### النتيجة المتوقعة

عند تشغيل طريقة `main`، سيطبع الطرفية:

```
Document saved successfully.
```

ويحتوي الملف `output/DoughnutChartFormatted.docx` على صفحة واحدة بها مخطط دونات بعنوان *توزيع المبيعات الربع سنوية*. يظهر المخطط أربع شرائح، الشريحة الأولى منفجرة، ملونة بلون العلامة التجارية، ومُدوَّرة 45 درجة.

## الاختلافات الشائعة وحالات الحافة

| الحالة | التعديل |
|-----------|------------|
| **أكثر من سلسلة بيانات واحدة** | أضف كائنات `ChartSeries` إضافية إلى `chart.getSeries()`. |
| **حجم مخطط مختلف** | غيّر قيمتي `width` و `height` في `insertPieChart`. |
| **بدون فتحة (دائري نقي)** | احذف `chart.setHoleSize(…)` أو اضبطه على `0`. |
| **مستندات كبيرة** | استخدم `DocumentBuilder` لإدراج المخطط في قسم أو إشارة مرجعية محددة. |
| **لم يتم ضبط الرخصة** | تعمل المكتبة في وضع التقييم، وتضيف علامة مائية على الصفحة الأولى. سجّل رخصة لإزالتها. |

## الخلاصة

أنت الآن تعرف كيف **تنشئ مخطط دونات** في مستند Word باستخدام Java، بدءًا من **إنشاء مستند Word فارغ** إلى **إدراج مخطط دائري**، **تدوير المخطط الدائري**، و**تنسيق المخطط الدائري** للحصول على منتج نهائي مصقول. يمكن إدراج المثال الكامل القابل للتنفيذ في أي مشروع Java يستخدم Aspose.Words.

بعد ذلك، قد ترغب في استكشاف:

- إضافة تسميات البيانات (`chart.getSeries().get(0).setDataLabelType(DataLabelType.CATEGORY_AND_PERCENT);`)  
- تصدير المخطط كصورة (`chart.toImage`) للاستخدام في رسائل البريد الإلكتروني HTML  
- أتمتة إنشاء مستندات متعددة داخل حلقة لتقارير الدفعات  

لا تتردد في تجربة الألوان، انفجار الشرائح، والوسائل الإيضاحية لتتناسب مع اللغة البصرية لمنظمتك. نتمنى لك رسمًا موفقًا!
