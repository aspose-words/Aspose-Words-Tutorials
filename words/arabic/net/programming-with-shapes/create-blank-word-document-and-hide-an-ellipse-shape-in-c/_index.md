# إنشاء مستند Word فارغ وإخفاء شكل إهليلجي في C#

إذا كنت بحاجة إلى **إنشاء مستند Word فارغ** ثم إخفاء عنصر رسومي، يوضح لك هذا الدليل بالضبط كيفية القيام بذلك باستخدام C#. ستشاهد مثالًا كاملاً قابلًا للتنفيذ يُدرج إهليلجًا، يحدد موقعه، يعلّمه ككائن مخفي، ويحفظ الملف—كل ذلك في بضع أسطر من الشيفرة.

يغطي البرنامج التعليمي كل شيء من إعداد المشروع إلى خطوة التحقق النهائية. في النهاية، يمكنك توليد ملف Word لا يظهر فيه الإهليلج على الشاشة أو في الطباعة، وهو مفيد لتخزين البيانات الوصفية، العلامات المرجعية، أو أي علامة غير مرئية.

## المتطلبات المسبقة

قبل أن تبدأ، تأكد من وجود ما يلي:

* .NET 6.0 SDK أو أحدث مثبت  
* بيئة تطوير C# (Visual Studio 2022، Rider، أو VS Code)  
* حزمة **Aspose.Words for .NET** من NuGet (`Install-Package Aspose.Words`)  

توفر هذه الأدوات الفئات `Document` و `DocumentBuilder` المستخدمة في عينة الشيفرة.

## الخطوة 1: إنشاء مستند Word فارغ

العملية الأولى تنشئ كائن `Document` فارغ و`DocumentBuilder` يتيح لك إضافة محتوى.

```csharp
using Aspose.Words;
using Aspose.Words.Drawing;

// Step 1: Initialize an empty document and a builder
Document doc = new Document();
DocumentBuilder builder = new DocumentBuilder(doc);
```

يمثل `Document` الحزمة الكاملة `.docx`، بينما يوفر `DocumentBuilder` واجهة برمجة تطبيقات سلسة لإدراج النصوص، الأشكال، والكائنات الأخرى. بدءًا بمستند فارغ يمنحك التحكم الكامل في كل عنصر تضيفه.

## الخطوة 2: كيفية إدراج إهليلج

الإهليلج هو شكل متجهي يمكن استخدامه كعلامة. تتطلب طريقة `InsertShape` نوع الشكل وعرضه/ارتفاعه بالنقاط.

```csharp
// Step 2: Insert an ellipse shape of the desired size (100 pt × 50 pt)
Shape ellipse = builder.InsertShape(ShapeType.Ellipse, 100, 50);
```

يظهر الإهليلج في الصفحة الحالية عند موقع المؤشر. يمكنك تغيير أبعاده بتعديل القيم الرقمية.

## الخطوة 3: كيفية تحديد موضع الشكل

بعد الإدراج، يمكنك نقل الشكل إلى أي مكان في الصفحة عن طريق ضبط خاصيتي `Left` و `Top`، اللتين تستخدمان النقاط نسبةً إلى هوامش الصفحة.

```csharp
// Step 3: Position the shape on the page
ellipse.Left = 150; // distance from the left margin
ellipse.Top  = 100; // distance from the top margin
```

توضع هذه الإحداثيات الإهليلج تقريبًا في الجزء العلوي‑الوسط من صفحة A4 القياسية. عدّل القيم لتتناسب مع متطلبات التخطيط لديك.

## الخطوة 4: كيفية إخفاء الشكل

الكائن المخفي لا يُعرض عندما يُفتح المستند أو يُطبع. ضبط علم `Hidden` يعلّم الشكل كـ **كلمة كائن مخفي**.

```csharp
// Step 4: Hide the shape so it never appears
ellipse.Hidden = true;
```

يتعامل Word مع علم الإخفاء لكل من العرض على الشاشة وإخراج الطباعة. يبقى الشكل جزءًا من بنية المستند، مما يتيح لك استعلامه أو تعديلّه لاحقًا عبر الشيفرة.

## الخطوة 5: حفظ المستند

أخيرًا، اكتب المستند إلى القرص. اختر مجلدًا لديك صلاحية كتابة فيه.

```csharp
// Step 5: Save the document to a .docx file
doc.Save(@"C:\Temp\HiddenEllipse.docx");
```

الملف `HiddenEllipse.docx` الآن يحتوي على صفحة فارغة مع شكل إهليلجي مخفي.

## التحقق من الإهليلج المخفي

افتح الملف المُولد في Microsoft Word وفعل خيار **إظهار النص المخفي** (File → Options → Display). ستظهر لك حدود خفيفة للإهليلج. إذا أوقفت الخيار، يختفي الشكل تمامًا، مما يؤكد أن `ellipse.Hidden = true` يعمل كما هو متوقع.

## الاختلافات الشائعة وحالات الحافة

| الحالة | التعديل الموصى به |
|-----------|------------------------|
| **شكل مختلف** | استبدل `ShapeType.Ellipse` بـ `ShapeType.Rectangle` أو `ShapeType.Arrow` وغيرها. |
| **عدة كائنات مخفية** | كرّر الخطوات 2‑4 لكل شكل؛ يمكن لكل منها أن يمتلك علم `Hidden` الخاص به. |
| **حجم صفحة مختلف** | اضبط `doc.FirstSection.PageSetup.PageWidth` و `PageHeight` قبل إدراج الشكل. |
| **رؤية شرطية** | استخدم `Shape.Visible` بالاشتراك مع `Hidden` لتبديل الظهور أثناء التشغيل عبر الشيفرة. |

**نصيحة احترافية:** خزن بيانات التعريف في خاصية `AlternativeText` الخاصة بالشكل. حتى عندما يكون مخفيًا، يمكنك استرجاع الشكل لاحقًا باستخدام `doc.GetChildNodes(NodeType.Shape, true)` وتصفية النتائج بناءً على ذلك النص.

## الشيفرة المصدرية الكاملة

فيما يلي البرنامج الكامل الذي يمكنك نسخه، لصقه، وتشغيله.

```csharp
using System;
using Aspose.Words;
using Aspose.Words.Drawing;

namespace HiddenShapeDemo
{
    class Program
    {
        static void Main()
        {
            // Create a new blank document and a builder
            Document doc = new Document();
            DocumentBuilder builder = new DocumentBuilder(doc);

            // Insert an ellipse shape (100 pt × 50 pt)
            Shape ellipse = builder.InsertShape(ShapeType.Ellipse, 100, 50);

            // Position the shape on the page
            ellipse.Left = 150;
            ellipse.Top  = 100;

            // Hide the shape so it is invisible in the UI and on print
            ellipse.Hidden = true;

            // Optional: add a description for later retrieval
            ellipse.AlternativeText = "Hidden marker for internal processing";

            // Save the document
            string outputPath = @"C:\Temp\HiddenEllipse.docx";
            doc.Save(outputPath);

            Console.WriteLine($"Document saved to {outputPath}");
        }
    }
}
```

**الناتج المتوقع:** يطبع الطرفية مسار الحفظ، ويُفتح الملف `HiddenEllipse.docx` كصفحة فارغة دون رسومات مرئية ما لم يتم إظهار الكائنات المخفية.
