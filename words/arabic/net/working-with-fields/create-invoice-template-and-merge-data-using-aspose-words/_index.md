# إنشاء قالب الفاتورة ودمج البيانات باستخدام Aspose.Words

إذا كنت بحاجة إلى **create invoice template** بسرعة، يوضح لك هذا الدليل بالضبط كيفية القيام بذلك. بنهاية الجملتين الأوليين ستعرف سير العمل الكامل لتحويل ملف Word فارغ إلى فاتورة مكتملة، باستخدام واجهة برمجة التطبيقات منخفضة الكود للدمج البريدي في Aspose.Words.

إنشاء الفواتير هو طلب شائع لأنظمة الفوترة، وتكاملات ERP، والتقارير الآلية. في هذا البرنامج التعليمي ستتعلم **كيفية دمج البريد**، **ملء قالب Word**، **دمج البيانات في Word**، وأخيرًا **حفظ المستند المدمج**—كل ذلك بضع أسطر من C#.

## ما ستحققه

* قالب Word قابل لإعادة الاستخدام (`InvoiceTemplate.docx`) يحتوي على حقول دمج للعميل، التاريخ، بنود السطر، والإجمالي.  
* برنامج C# يقوم بتحميل القالب، يحقن كائن بيانات من نوع قوي، ويكتب النتيجة إلى `Invoice_001.docx`.  
* نظرة عميقة على الحالات الخاصة مثل المجموعات الفارغة، الأنواع المخصصة، ومعالجة مسارات الملفات.

### المتطلبات المسبقة

| المتطلب | لماذا يهم |
|-------------|----------------|
| .NET 6 أو أحدث | يدعم Aspose.Words for .NET .NET 6+ ويوفر واجهة برمجة التطبيقات منخفضة الكود المستخدمة في هذا الدليل. |
| حزمة NuGet لـ Aspose.Words for .NET (`Aspose.Words`) | تزودك بـ `Document`، `MailMerger`، والأنواع المرتبطة. |
| معرفة أساسية بـ C# | ضرورية لفهم الكائنات المجهولة وLINQ. |
| Visual Studio 2022 (أو أي بيئة تطوير) | يجعل التحرير وتصحيح الأخطاء أمرًا بسيطًا. |

> **نصيحة احترافية:** قم بتثبيت حزمة NuGet عبر وحدة تحكم مدير الحزم:  
> `Install-Package Aspose.Words`

## كيفية إنشاء قالب الفاتورة باستخدام دمج البريد منخفض الكود

الخطوة الأولى هي بناء ملف Word يحتوي على حقول دمج تتطابق مع خصائص كائن البيانات الذي ستمرره لاحقًا. احفظ الملف باسم `InvoiceTemplate.docx` في مجلد تتحكم فيه (مثال: `C:\Invoices\Template`).

| حقل الدمج | مثال العنصر النائب في Word |
|-------------|-----------------------------|
| CustomerName | «CustomerName» |
| InvoiceDate | «InvoiceDate» |
| Items (متكرر) | «Items.Description», «Items.Qty», «Items.Price» |
| Total | «Total» |

> **لماذا يهم هذا:** تقوم واجهة برمجة التطبيقات منخفضة الكود تلقائيًا بربط أسماء الخصائص في مصدر البيانات مع حقول الدمج. الحفاظ على الأسماء متطابقة يلغي الحاجة إلى ربط يدوي بين الحقل والخاصية ويقلل الأخطاء وقت التشغيل.

## الخطوة 1: تحميل قالب الفاتورة

```csharp
using Aspose.Words;
using Aspose.Words.LowCode;   // Low‑code mail‑merge API

// Load the Word file that contains the merge fields.
Document template = new Document(@"C:\Invoices\Template\InvoiceTemplate.docx");
```

*فئة `Document` تمثل ملف Word بالكامل. تحميلها مرة واحدة يتيح لك إعادة استخدام القالب نفسه للعديد من الفواتير.*

## الخطوة 2: إعداد مصدر البيانات

أنشئ كائنًا مجهولًا يعكس حقول الدمج. يمكن لواجهة برمجة التطبيقات منخفضة الكود العمل مع أي كائن .NET، بما في ذلك المصفوفات والمجموعات المتداخلة.

```csharp
var invoiceData = new
{
    CustomerName = "Acme Corp",
    InvoiceDate = DateTime.Today,
    Items = new[]
    {
        new { Description = "Widget A", Qty = 10, Price = 9.99M },
        new { Description = "Widget B", Qty = 5,  Price = 19.95M }
    },
    Total = 199.85M
};
```

**لماذا يعمل هذا:**  
* أسماء الخصائص (`CustomerName`, `InvoiceDate`, `Items`, `Total`) تتطابق مع حقول الدمج في القالب.  
* `Items` هي مصفوفة من الكائنات، لذا سيقوم دمج البريد بتكرار صف الجدول لكل عنصر تلقائيًا.  
* استخدام `decimal` (`M` suffix) للقيم المالية يجنب مشاكل التقريب في النقاط العائمة.

### معالجة المجموعات الفارغة

إذا كانت الفاتورة لا تحتوي على بنود، مرّر مصفوفة فارغة:

```csharp
Items = new object[0]
```

محرك الدمج منخفض الكود سيحذف ببساطة القسم المتكرر، مع إبقاء رأس الجدول كما هو.

## الخطوة 3: تهيئة دمج البريد منخفض الكود

```csharp
MailMerger merger = new MailMerger(template);
```

`MailMerger` هو نقطة الدخول لـ **how to mail merge** مع Aspose.Words. يقرأ القالب، يربط البيانات، ويجهز المستند النهائي في استدعاء واحد.

## الخطوة 4: تنفيذ الدمج – ملء قالب Word في سطر واحد

```csharp
Document mergedDocument = merger.Execute(invoiceData);
```

* هذا السطر **populates the word template** وينتج كائن `Document` جديد (`mergedDocument`).  
* جميع حقول الدمج تُستبدل، الأقسام المتكررة تُوسع، والمستند الناتج يُحفظ بالكامل في الذاكرة.

### حالة خاصة: تنسيق مخصص

إذا كنت تحتاج إلى تنسيق تاريخ محدد، أضف مُنسقًا مخصصًا قبل الدمج:

```csharp
merger.Options.DateFormat = "MMMM dd, yyyy"; // e.g., "October 07, 2026"
```

## الخطوة 5: حفظ المستند المدمج

```csharp
mergedDocument.Save(@"C:\Invoices\Output\Invoice_001.docx");
```

استدعاء **save merged document** يكتب الفاتورة المكتملة إلى القرص. يمكن الآن فتح الملف في Microsoft Word، إرساله كمرفق بريد إلكتروني، أو تحويله إلى PDF.

### التحقق من النتيجة

افتح `Invoice_001.docx`. يجب أن ترى:

* **CustomerName** مستبدلًا بـ *Acme Corp*  
* **InvoiceDate** يظهر تاريخ اليوم بالتنسيق المختار  
* صف جدول لـ *Widget A* (10 × 9.99) و*Widget B* (5 × 19.95)  
* **Total** يعرض *199.85*  

إذا ظل أي حقل دون تغيير (مثلاً لا يزال يظهر «CustomerName»)، تحقق مرة أخرى من أن أسماء الخصائص تتطابق تمامًا مع أسماء حقول الدمج في القالب.

## مثال كامل قابل للتنفيذ

فيما يلي البرنامج الكامل الذي يمكنك نسخه ولصقه في مشروع وحدة تحكم جديد.

```csharp
using System;
using Aspose.Words;
using Aspose.Words.LowCode;   // Low‑code mail‑merge API

namespace InvoiceGenerator
{
    class Program
    {
        static void Main()
        {
            // 1️⃣ Load the template
            Document template = new Document(@"C:\Invoices\Template\InvoiceTemplate.docx");

            // 2️⃣ Build the data source
            var invoiceData = new
            {
                CustomerName = "Acme Corp",
                InvoiceDate = DateTime.Today,
                Items = new[]
                {
                    new { Description = "Widget A", Qty = 10, Price = 9.99M },
                    new { Description = "Widget B", Qty = 5,  Price = 19.95M }
                },
                Total = 199.85M
            };

            // 3️⃣ Initialise the mail merger
            MailMerger merger = new MailMerger(template);

            // Optional: customise date format
            merger.Options.DateFormat = "MMMM dd, yyyy";

            // 4️⃣ Perform the merge (populate word template)
            Document mergedDocument = merger.Execute(invoiceData);

            // 5️⃣ Save the resulting file (save merged document)
            mergedDocument.Save(@"C:\Invoices\Output\Invoice_001.docx");

            Console.WriteLine("Invoice generated successfully.");
        }
    }
}
```

شغّل البرنامج (`dotnet run`). سيتطبع في وحدة التحكم *Invoice generated successfully.* وسيظهر الملف في `C:\Invoices\Output`.
