# كيفية إظهار النسب المئوية في المخطط باستخدام Aspose.Words C#

هل تساءلت يومًا **كيف يتم إظهار النسب المئوية في المخطط** دون الخوض في تعقيدات Office interop؟ لست وحدك—فالعديد من المطورين يواجهون هذه المشكلة عندما يحتاجون إلى طريقة سريعة برمجية لتسمية مخطط دائري أو مخطط دونات. الخبر السار؟ باستخدام Aspose.Words for .NET يمكنك تمكين تلك تسميات البيانات في بضع أسطر فقط.

في هذا الدرس سنغطي أيضًا **إضافة تسميات البيانات إلى مخطط دائري** و **كيفية تمكين تسميات بيانات المخطط** بحيث تصبح تصوراتك أكثر وضوحًا على الفور. في النهاية ستحصل على مستند Word جاهز للاستخدام (`.docx`) يعرض مخططًا دائريًا مصقولًا مع النسب المئوية موضوعة بدقة خارج كل شريحة.

## المتطلبات المسبقة

- **Aspose.Words for .NET** (أحدث نسخة، على سبيل المثال 24.9) مثبتة عبر NuGet.
- ملف **ChartTemplate.docx** يحتوي بالفعل على مخطط دائري أو مخطط دونات.  
  *(إذا لم يكن لديك ملف، أنشئ مستند Word بسيطًا، أدخل مخططًا دائريًا، واحفظه باسم `ChartTemplate.docx`.)*
- .NET 6.0 أو أحدث وأي بيئة تطوير تفضلها (Visual Studio، Rider، VS Code).

لا توجد تبعيات إضافية مطلوبة—Aspose.Words يتعامل مع كل شيء داخليًا.

## كيفية إظهار النسب المئوية في المخطط – خطوة بخطوة

فيما يلي نقسم العملية إلى ست خطوات واضحة. كل خطوة تتضمن شفرة C# الدقيقة التي يمكنك نسخها ولصقها، بالإضافة إلى شرح قصير **لماذا** نقوم بذلك.

### الخطوة 1: تحميل المستند المصدر

```csharp
using Aspose.Words;
using Aspose.Words.Drawing.Charts;

// Load the .docx that already holds a chart.
Document sourceDoc = new Document("YOUR_DIRECTORY/ChartTemplate.docx");
```

*لماذا؟*  
`Document` هو نقطة الدخول لأي تعديل على Word. بتحميل القالب نحصل على إمكانية الوصول إلى كل عقدة—الأشكال، الجداول، النص، وبالطبع المخطط الذي سنعدله.

### الخطوة 2: الحصول على أول شكل مخطط

```csharp
// The chart lives inside a Shape node; retrieve it.
Chart chart = (Chart)sourceDoc.GetChild(NodeType.Shape, 0, true);
```

*لماذا؟*  
Aspose يخزن المخططات ككائنات `Shape`. `GetChild` يتجول في شجرة المستند ويعيد أول شكل يجده، وهو في حالتنا المخطط الدائري الذي نريد تحريره.

### الخطوة 3: تأكيد نوع المخطط

```csharp
if (chart.ChartType == ChartType.Pie || chart.ChartType == ChartType.Doughnut)
{
    // Inside this block we’ll enable the data labels.
}
else
{
    throw new InvalidOperationException("The chart is not a Pie or Doughnut type.");
}
```

*لماذا؟*  
تسميات النسب المئوية لا تكون منطقية إلا للمخططات الدائرية. هذه الحماية تمنعنا من تطبيق الإعدادات عن طريق الخطأ على مخطط شريطي مثلاً حيث سيتم تجاهل `ShowPercentage`.

### الخطوة 4: تمكين تسميات البيانات وإظهار النسب المئوية

```csharp
// Turn on data labels for the chart.
chart.HasDataLabel = true;

// Show the percentage value for each slice.
chart.DataLabel.ShowPercentage = true;
```

*لماذا؟*  
`HasDataLabel` يخبر Aspose بإنشاء تسمية لكل نقطة بيانات. ضبط `ShowPercentage` يضمن أن محتوى التسمية هو النسبة المحسوبة من الكل—وهو بالضبط ما يتطلبه **إضافة تسميات البيانات إلى مخطط دائري**.

### الخطوة 5: وضع التسميات خارج الشرائح

```csharp
// Place the labels outside the pie slices for better readability.
chart.DataLabel.Position = ChartDataLabelPosition.OutSideEnd;
```

*لماذا؟*  
التسميات داخل الشريحة قد تصبح مكتظة، خاصةً عندما تكون الشرائح صغيرة. `OutSideEnd` يحاكي النمط الافتراضي “الخارج” الذي تراه في واجهة Word، مما يحافظ على نظافة المخطط.

### الخطوة 6: حفظ المستند المحدث

```csharp
sourceDoc.Save("YOUR_DIRECTORY/FormattedPieChart.docx");
```

*لماذا؟*  
الحفظ يكتب جميع التغييرات إلى ملف جديد. افتح `FormattedPieChart.docx` في Word وسترى النسب المئوية معروضة بجانب كل شريحة.

#### النتيجة المتوقعة

عند فتح `FormattedPieChart.docx`، يجب أن يبدو المخطط الدائري مشابهًا لهذا (لقطة شاشة تخيلية):

```
[ Pie chart with three slices ]
- Slice A – 45%
- Slice B – 30%
- Slice C – 25%
```

جميع النسب المئوية تُحسب تلقائيًا من سلسلة البيانات الأساسية، والتسميات تقع خارج كل شريحة.

## الاختلافات الشائعة وحالات الحافة

| Situation | What to Adjust |
|-----------|----------------|
| **مخططات متعددة** في نفس المستند | التكرار عبر `sourceDoc.GetChildNodes(NodeType.Shape, true)` وتحويل كل عنصر إلى `Chart` قبل تطبيق نفس المنطق. |
| **مخطط شريطي أو خطي** حيث لا تزال تريد التسميات | استخدم `chart.DataLabel.ShowValue = true;` (أو `ShowSeriesName`) بدلاً من `ShowPercentage`. |
| **تنسيق رقم مخصص** (مثال: “45 %”) | عيّن `chart.DataLabel.NumberFormat = "0%";` قبل الحفظ. |
| **مجموعات بيانات كبيرة** تسبب تداخل التسميات | فكّر في `chart.DataLabel.ShowLeaderLines = true;` لرسم خطوط وصل. |

> **نصيحة احترافية:** إذا كنت تُنشئ العديد من المستندات دفعةً واحدة، أنشئ كائن `Aspose.Words.License` واحد عند بدء التطبيق لتجنب تأثير الأداء الناتج عن تحميل الترخيص مرارًا.

## مثال كامل يعمل

إليك البرنامج الكامل مجمعًا، جاهزًا للتنفيذ:

```csharp
using System;
using Aspose.Words;
using Aspose.Words.Drawing.Charts;

class Program
{
    static void Main()
    {
        // 1️⃣ Load the template document.
        Document sourceDoc = new Document("YOUR_DIRECTORY/ChartTemplate.docx");

        // 2️⃣ Retrieve the first chart shape.
        Chart chart = (Chart)sourceDoc.GetChild(NodeType.Shape, 0, true);

        // 3️⃣ Ensure we’re dealing with a Pie or Doughnut chart.
        if (chart.ChartType != ChartType.Pie && chart.ChartType != ChartType.Doughnut)
        {
            Console.WriteLine("The selected shape is not a Pie/Doughnut chart.");
            return;
        }

        // 4️⃣ Enable data labels and show percentages.
        chart.HasDataLabel = true;
        chart.DataLabel.ShowPercentage = true;

        // 5️⃣ Position the labels outside the slices.
        chart.DataLabel.Position = ChartDataLabelPosition.OutSideEnd;

        // 6️⃣ Save the modified document.
        sourceDoc.Save("YOUR_DIRECTORY/FormattedPieChart.docx");

        Console.WriteLine("Chart updated successfully – percentages now visible!");
    }
}
```

انسخ الشفرة، استبدل `YOUR_DIRECTORY` بالمسار الفعلي على جهازك، وشغّلها. ستحصل على ملف Word يحتوي على مخطط دائري مُوسم بالكامل في ثوانٍ.

## ملخص

لقد أجبنا على **كيفية إظهار النسب المئوية في المخطط** باستخدام Aspose.Words للـ C#. الخطوات التي تم تغطيتها:

1. تحميل القالب.  
2. الحصول على شكل المخطط.  
3. التحقق من أنه مخطط دائري/دونات.  
4. **إضافة تسميات البيانات إلى مخطط دائري** وتمكين النسب المئوية.  
5. وضع تلك التسميات خارج المخطط.  
6. حفظ النتيجة.

مع هذه المعرفة يمكنك الآن أتمتة أي سيناريو تقارير يتطلب تصورات واضحة مبنية على النسب المئوية.

## ما التالي؟

- **تنسيق التسميات** – غيّر الخط، اللون، أو أضف خلفية باستخدام `chart.DataLabel.Font`.  
- **إنشاء مخططات من الصفر** – استكشف `Chart chart = (Chart)sourceDoc.FirstSection.Body.AppendChild(new Shape(sourceDoc, ShapeType.Chart));` لإنشاء مخططات برمجيًا.  
- **دمج مخططات متعددة** في مستند واحد لإنشاء لوحات معلومات، ثم تصدير إلى PDF باستخدام `sourceDoc.Save("Dashboard.pdf", SaveFormat.Pdf);`.

لا تتردد في التجربة، وإذا واجهت أي مشاكل، اترك تعليقًا. نتمنى لك رسمًا ممتعًا!
