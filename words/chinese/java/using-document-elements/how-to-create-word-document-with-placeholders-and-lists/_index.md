# 如何创建带占位符和列表的 Word 文档

如果您需要 **以编程方式创建 word 文档**，本指南将一步步演示。我们将讲解 **设置占位符文本**、**添加列表项**，以及 **如何使用 SDT**（结构化文档标签）控件，使用 Aspose.Words for .NET。

开发者经常询问如何在不打开 Word 的情况下，将内容控件——如纯文本占位符或下拉列表——直接嵌入 .docx 文件。本教程提供完整可运行的示例，解释每一步的意义，并涵盖常见变体，例如向现有文档添加控件或自定义列表值。

## 前置条件

在开始之前，请确保您拥有：

- 已安装 .NET 6.0 SDK 或更高版本  
- Visual Studio 2022（或任意 C# IDE）  
- 有效的 Aspose.Words for .NET 许可证（免费试用版可用于开发）  
- 基本的 C# 语法了解  

代码针对 **Aspose.Words 23.9**（撰写时的最新稳定版本）。如果使用更新的版本，请相应调整 NuGet 包版本。

## 插入纯文本结构化文档标签（设置占位符文本）

纯文本 SDT 类似于用户可以填写的内容控件。设置其 `Title` 和 `PlaceholderName` 可在 Word 中提供友好的提示。

```csharp
            // Step 2: Insert a plain‑text SDT and set its placeholder text
            StructuredDocumentTag plainTextTag = builder.InsertStructuredDocumentTag(
                StructuredDocumentTagType.PlainText, true);
            plainTextTag.Title = "CustomerName";
            plainTextTag.PlaceholderName = "Enter name";
```

**说明：**  
- `InsertStructuredDocumentTag` 在构建器当前光标位置创建控件。  
- `StructuredDocumentTagType.PlainText` 告诉 Word 渲染一个简单的文本框。  
- `Title` 是 Word XML 中使用的内部名称，便于后续数据绑定。  
- `PlaceholderName` 是用户未输入时显示的灰色提示。

> **专业提示：** 若需在文档的 *Properties* 面板中显示占位符，还需设置 `plainTextTag.Tag = "CustomerName"`。

## 插入下拉列表 SDT（如何使用 sdt）

下拉列表可让您提供预定义的选项集合。这是 **如何使用 sdt** 处理枚举数据的核心。

```csharp
            // Step 3: Insert a drop‑down list SDT and define its title
            StructuredDocumentTag dropdownTag = builder.InsertStructuredDocumentTag(
                StructuredDocumentTagType.DropDownList, true);
            dropdownTag.Title = "Country";
```

**为什么使用下拉列表？**  
下拉列表提升数据一致性并减少输入错误。`Title` 属性同样充当下游处理（例如提取表单数据）时的标识符。

## 为下拉列表添加列表项（add list items）

现在为控件填充可选值。每个 `ListItem` 包含显示文本和可选的内部值，后者会存储在文档的 XML 中。

```csharp
            // Step 4: Populate the drop‑down with selectable items
            dropdownTag.ListItems.Add(new ListItem("USA", "US"));
            dropdownTag.ListItems.Add(new ListItem("Canada", "CA"));
            dropdownTag.ListItems.Add(new ListItem("Mexico", "MX"));
```

**关键要点：**  

- 第一个参数（`"USA"`）是用户看到的文本。  
- 第二个参数（`"US"`）是您可以通过代码读取的底层值。  
- 可以根据需要添加任意数量的项；列表会存储在 .docx XML 的 `<w:listItem>` 元素中。

### 边缘情况和变体

| 情形 | 推荐调整 |
|-----------|------------------------|
| **向已有文件添加控件** | 使用 `new Document("Existing.docx")` 加载文件，而不是创建新 `Document`。 |
| **将占位符设为必填** | 根据验证逻辑设置 `plainTextTag.IsShowingPlaceholderWhenEmpty = false` 或 `true`。 |
| **将列表项绑定到数据源** | 遍历集合（`foreach (var country in countries)`），并调用 `dropdownTag.ListItems.Add(new ListItem(country.Name, country.Code))`。 |
| **为控件设置样式** | 在插入 SDT 前使用 `builder.Font` 属性，以影响占位符文本的默认样式。 |
| **后期删除控件** | 通过 `doc.GetChildNodes(NodeType.StructuredDocumentTag, true)` 定位，然后调用 `tag.Remove();`。 |

## 如何以编程方式创建控件 – 最佳实践

1. **先创建文档** – 提前初始化 `DocumentBuilder` 可避免光标位置意外。  
2. **设置标题和标签** – 它们是后续数据提取的稳定标识符。  
3. **添加占位符文本** – 提升用户体验，尤其是对纯文本标签。  
4. **立即填充列表项** – Word 只有在列表附加后才会正确渲染下拉列表。  
5. **一次性保存** – 在循环中多次调用 `Save` 会显著增加 I/O 开销。

遵循这些步骤，可确保 Word 文件既 **机器可读**（用于后端处理），又 **用户友好**（便于前端编辑）。
