# 使用 Java 在 Word 文档中创建 doughnut chart

如果您需要在 Word 文件中 **创建 doughnut chart**，本教程提供了一个完整、可直接运行的解决方案。您将看到如何 **插入饼图**、将其转换为 doughnut、**旋转饼图** 以获得更好的平衡，以及 **格式化饼图** 以匹配品牌风格。完成后，您将拥有一个专业的 Word 文档，可用于报告、仪表盘或自动化的电子邮件附件。

以编程方式创建图表可消除手动复制‑粘贴的步骤，并确保在大量生成的文档中保持一致的样式。示例使用 Aspose.Words for Java 库，支持 Java 8 及以上，无需安装 Microsoft Office。除标准 JDK 和您喜爱的 IDE 外，无需其他前置条件。

## 前置条件

- Java Development Kit (JDK) 8 或更高版本  
- 用于依赖管理的 Maven 或 Gradle（本教程使用 Maven）  
- Aspose.Words for Java 库（免费试用许可证足以进行测试）  

在 `pom.xml` 中添加 Aspose.Words 依赖：

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-words</artifactId>
    <version>24.9</version> <!-- Use the latest stable version -->
</dependency>
```

> **专业提示：** 在创建任何文档之前使用 `License license = new License(); license.setLicense("Aspose.Words.lic");` 注册许可证，以去除评估水印。

## 在 Word 文档中创建 doughnut chart

核心工作流由五个逻辑步骤组成。每个步骤都封装在各自的方法中，以保持代码简洁且可复用。

```java
import com.aspose.words.*;
import com.aspose.words.drawing.*;

public class DoughnutChartDemo {

    public static void main(String[] args) throws Exception {
        // Step 1: create blank Word document
        Document doc = createBlankWordDocument();

        // Step 2: insert a pie chart (base for the doughnut)
        Chart chart = insertPieChart(doc, 400, 300);

        // Step 3: convert the pie chart into a doughnut and rotate it
        customizeChartAppearance(chart);

        // Step 4: apply additional formatting to the chart
        formatPieChart(chart);

        // Step 5: save the final document
        doc.save("output/DoughnutChartFormatted.docx");
        System.out.println("Document saved successfully.");
    }

    /** Step 1 – create blank Word document */
    private static Document createBlankWordDocument() {
        // Aspose.Words creates an empty document by default
        return new Document();
    }

    /** Step 2 – insert pie chart with given dimensions */
    private static Chart insertPieChart(Document doc, int width, int height) throws Exception {
        DocumentBuilder builder = new DocumentBuilder(doc);
        // ChartType.PIE creates a standard pie chart that we will later turn into a doughnut
        Chart chart = builder.insertChart(ChartType.PIE, width, height);
        // Populate the chart with sample data
        chart.getSeries().clear(); // Remove default series
        ChartSeries series = chart.getSeries().add("Sales", new String[]{"Q1", "Q2", "Q3", "Q4"},
                new double[]{15000, 23000, 18000, 27000});
        return chart;
    }

    /** Step 3 – rotate pie chart and make it a doughnut */
    private static void customizeChartAppearance(Chart chart) {
        // Explode the first slice for emphasis
        chart.getSeries().get(0).setExplode(20);
        // Convert the pie into a doughnut by setting a hole size (percentage of radius)
        chart.setHoleSize(30); // 30% hole creates a classic doughnut look
        // Rotate the chart so the largest slice starts at 45°
        chart.setRotationAngle(45);
    }

    /** Step 4 – additional formatting of the pie chart */
    private static void formatPieChart(Chart chart) {
        // Example: change the first slice color to a brand color
        chart.getSeries().get(0).getPoints().get(0).getFormat().setFillForegroundColor(Color.fromArgb(0xFF, 0x4A, 0x90));
        // Add a legend and position it at the bottom
        chart.setHasLegend(true);
        chart.getLegend().setPosition(LegendPosition.BOTTOM);
        // Set a title for the chart
        chart.setTitle("Quarterly Sales Distribution");
    }
}
```

### 代码功能说明

| 步骤 | 操作 | 原因 |
|------|--------|--------|
| **Create blank Word document** | `new Document()` | 从空白文件开始，您可以控制每个元素。 |
| **Insert pie chart** | `builder.insertChart(ChartType.PIE, …)` | 饼图是基础形状；Aspose 通过调整孔径大小来提供 doughnut。 |
| **Rotate pie chart** | `chart.setRotationAngle(45)` | 旋转可将最大切片对齐到更易读的位置。 |
| **Format pie chart** | `setExplode`, `setHoleSize`, color, legend | 改善视觉层次并符合企业风格指南。 |
| **Save document** | `doc.save("…/DoughnutChartFormatted.docx")` | 将最终的 .docx 文件写入磁盘，准备分发。 |

## 在转换为 doughnut 之前插入饼图

Aspose.Words 并未提供直接的 “插入 doughnut chart” 方法。相反，您需要 **插入饼图**，随后修改其属性。这种两步法让您能够完全控制数据系列、切片爆炸和孔径大小。如果您在其他地方只需要纯饼图，只需省略 `setHoleSize` 调用。

## 为视觉平衡旋转饼图

默认方向会在 12 点位置开始第一块切片。在许多业务报告中，最重要的切片应从更自然的角度开始，例如 45 度。`setRotationAngle(double angle)` 方法接受角度值，并在不影响数据值的前提下旋转整个图表。

## 格式化饼图并自定义外观

除了转换为 doughnut，您通常还想 **格式化饼图** 的各个元素：

- **Explode** 第一个切片（`setExplode`）以吸引注意。  
- 使用 `getPoints().get(i).getFormat().setFillForegroundColor` 为每个切片 **着色**。  
- **图例** 位置（`setHasLegend`, `setPosition`）帮助读者解释类别。  
- **标题**（`setTitle`）提供一目了然的上下文。  

所有这些设置均为可选，您可以根据品牌配色或企业模板进行定制。

## 创建空白 Word 文档并保存结果

`createBlankWordDocument` 方法封装了 **create blank word document** 步骤。将此逻辑单独抽离，可在批量生成多个报告时轻松复用。所有自定义完成后，`doc.save` 以标准的 Office Open XML 格式（`.docx`）写入文件，可在 Microsoft Word、LibreOffice 或 Google Docs 中打开且不会失真。

### 预期输出

运行 `main` 方法后，控制台会打印：

```
Document saved successfully.
```

文件 `output/DoughnutChartFormatted.docx` 包含一页，图表标题为 *Quarterly Sales Distribution*，显示四个切片，第一块已爆炸、使用品牌色并旋转 45 度。

## 常见变体和边缘情况

| 场景 | 调整 |
|-----------|------------|
| **More than one data series** | 向 `chart.getSeries()` 添加额外的 `ChartSeries` 对象。 |
| **Different chart size** | 更改 `insertPieChart` 中的 `width` 和 `height` 参数。 |
| **No hole (pure pie)** | 省略 `chart.setHoleSize(…)` 或将其设为 `0`。 |
| **Large documents** | 使用 `DocumentBuilder` 将图表插入特定章节或书签。 |
| **License not set** | 库将在评估模式下运行，在首页添加水印。注册许可证即可去除。 |
