# 创建发票模板并使用 Aspose.Words 合并数据

如果您需要**快速创建发票模板**，本指南将一步步演示。阅读前两句话后，您就能了解将空白 Word 文件转换为完整填充发票的完整工作流，使用 Aspose.Words 的低代码邮件合并 API。

生成发票是计费系统、ERP 集成和自动化报表的常见需求。在本教程中，您将学习**如何进行邮件合并**、**填充 Word 模板**、**将数据合并到 Word**，以及最后**保存合并后的文档**——全部只需几行 C# 代码。

## 您将实现的目标

* 一个可复用的 Word 模板（`InvoiceTemplate.docx`），其中包含客户、日期、明细行和总计的合并字段。  
* 一个 C# 程序，加载模板、注入强类型数据对象，并将结果写入 `Invoice_001.docx`。  
* 对空集合、自定义数据类型以及文件路径处理等边缘情况的深入了解。

### 前置条件

| Requirement | Why it matters |
|-------------|----------------|
| .NET 6 或更高版本 | Aspose.Words for .NET 支持 .NET 6+，并提供本指南使用的低代码 API。 |
| Aspose.Words for .NET NuGet 包（`Aspose.Words`） | 提供 `Document`、`MailMerger` 等相关类型。 |
| 基础 C# 知识 | 需要理解匿名对象和 LINQ。 |
| Visual Studio 2022（或任意 IDE） | 便于编辑和调试。 |

> **专业提示：** 通过包管理器控制台安装 NuGet 包：  
> `Install-Package Aspose.Words`

## 如何使用低代码邮件合并创建发票模板

第一步是构建一个 Word 文件，其中的合并字段与稍后传入的数据对象属性相匹配。将文件保存为 `InvoiceTemplate.docx`，放在您可控制的文件夹中（例如 `C:\Invoices\Template`）。

| Merge field | Example placeholder in Word |
|-------------|-----------------------------|
| CustomerName | «CustomerName» |
| InvoiceDate | «InvoiceDate» |
| Items (repeating) | «Items.Description», «Items.Qty», «Items.Price» |
| Total | «Total» |

> **为何重要：** 低代码 API 会自动将数据源的属性名称映射到合并字段。保持名称一致可省去手动字段‑属性映射，降低运行时错误。

## 步骤 1：加载发票模板

```csharp
using Aspose.Words;
using Aspose.Words.LowCode;   // Low‑code mail‑merge API

// Load the Word file that contains the merge fields.
Document template = new Document(@"C:\Invoices\Template\InvoiceTemplate.docx");
```

*`Document` 类代表整个 Word 文件。一次加载后即可在多个发票中复用同一模板。*

## 步骤 2：准备数据源

创建一个与合并字段对应的匿名对象。低代码 API 能处理任何 .NET 对象，包括数组和嵌套集合。

```csharp
var invoiceData = new
{
    CustomerName = "Acme Corp",
    InvoiceDate = DateTime.Today,
    Items = new[]
    {
        new { Description = "Widget A", Qty = 10, Price = 9.99M },
        new { Description = "Widget B", Qty = 5,  Price = 19.95M }
    },
    Total = 199.85M
};
```

**工作原理：**  
* 属性名称（`CustomerName`、`InvoiceDate`、`Items`、`Total`）与模板中的合并字段相匹配。  
* `Items` 是对象数组，邮件合并器会自动为每个元素重复表格行。  
* 使用 `decimal`（`M` 后缀）表示货币值，可避免浮点数四舍五入问题。

### 处理空集合

如果发票没有明细行，传入空数组：

```csharp
Items = new object[0]
```

低代码引擎会直接省略重复部分，保留表头。

## 步骤 3：初始化低代码邮件合并器

```csharp
MailMerger merger = new MailMerger(template);
```

`MailMerger` 是使用 Aspose.Words **进行邮件合并**的入口。它读取模板、绑定数据，并在一次调用中准备最终文档。

## 步骤 4：执行合并 – 一行代码填充 Word 模板

```csharp
Document mergedDocument = merger.Execute(invoiceData);
```

* 该行**填充 Word 模板**并生成一个新的 `Document` 实例（`mergedDocument`）。  
* 所有合并字段被替换，重复段落被展开，生成的文档完整驻留在内存中。

### 边缘情况：自定义格式

如果需要特定的日期格式，可在合并前添加自定义格式化器：

```csharp
merger.Options.DateFormat = "MMMM dd, yyyy"; // e.g., "October 07, 2026"
```

## 步骤 5：保存合并后的文档

```csharp
mergedDocument.Save(@"C:\Invoices\Output\Invoice_001.docx");
```

此调用**保存合并文档**，将完整填充的发票写入磁盘。文件随后可在 Microsoft Word 中打开、作为电子邮件附件发送，或转换为 PDF。

### 验证输出

打开 `Invoice_001.docx`，您应看到：

* **CustomerName** 被 *Acme Corp* 替换  
* **InvoiceDate** 显示今日日期（使用所选格式）  
* 表格行显示 *Widget A*（10 × 9.99）和 *Widget B*（5 × 19.95）  
* **Total** 显示 *199.85*  

如果仍有字段未被替换（例如仍显示 «CustomerName»），请检查属性名称是否与模板中的合并字段名称完全一致。

## 完整可运行示例

以下是完整程序，可直接复制粘贴到新建的控制台项目中。

```csharp
using System;
using Aspose.Words;
using Aspose.Words.LowCode;   // Low‑code mail‑merge API

namespace InvoiceGenerator
{
    class Program
    {
        static void Main()
        {
            // 1️⃣ Load the template
            Document template = new Document(@"C:\Invoices\Template\InvoiceTemplate.docx");

            // 2️⃣ Build the data source
            var invoiceData = new
            {
                CustomerName = "Acme Corp",
                InvoiceDate = DateTime.Today,
                Items = new[]
                {
                    new { Description = "Widget A", Qty = 10, Price = 9.99M },
                    new { Description = "Widget B", Qty = 5,  Price = 19.95M }
                },
                Total = 199.85M
            };

            // 3️⃣ Initialise the mail merger
            MailMerger merger = new MailMerger(template);

            // Optional: customise date format
            merger.Options.DateFormat = "MMMM dd, yyyy";

            // 4️⃣ Perform the merge (populate word template)
            Document mergedDocument = merger.Execute(invoiceData);

            // 5️⃣ Save the resulting file (save merged document)
            mergedDocument.Save(@"C:\Invoices\Output\Invoice_001.docx");

            Console.WriteLine("Invoice generated successfully.");
        }
    }
}
```

运行程序（`dotnet run`）。控制台会打印 *Invoice generated successfully.*，文件会出现在 `C:\Invoices\Output`。
