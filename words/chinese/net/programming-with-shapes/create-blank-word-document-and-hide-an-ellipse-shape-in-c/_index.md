# 在 C# 中创建空白 Word 文档并隐藏椭圆形状

如果您需要**创建空白 Word 文档**并随后隐藏图形元素，本指南将向您展示如何使用 C# 完成此操作。您将看到一个完整的、可运行的示例，插入椭圆、定位它、将其标记为隐藏，并保存文件——全部只需几行代码。

本教程涵盖了从项目设置到最终验证步骤的全部内容。完成后，您可以生成一个 Word 文件，其中的椭圆既不会在屏幕上显示，也不会在打印时出现，这对于存储元数据、书签或任何不可见标记非常有用。

## 前置条件

* 已安装 .NET 6.0 SDK 或更高版本  
* C# 开发环境（Visual Studio 2022、Rider 或 VS Code）  
* **Aspose.Words for .NET** NuGet 包 (`Install-Package Aspose.Words`)  

这些工具提供了代码示例中使用的 `Document` 和 `DocumentBuilder` 类。

## 步骤 1：创建空白 Word 文档

第一步操作创建一个空的 `Document` 对象和一个允许您添加内容的 `DocumentBuilder`。

```csharp
using Aspose.Words;
using Aspose.Words.Drawing;

// Step 1: Initialize an empty document and a builder
Document doc = new Document();
DocumentBuilder builder = new DocumentBuilder(doc);
```

`Document` 表示整个 `.docx` 包，而 `DocumentBuilder` 提供了用于插入文本、形状和其他对象的流畅 API。从空白文档开始可以让您完全控制所添加的每个元素。

## 步骤 2：插入椭圆

椭圆是一种可用作标记的矢量形状。`InsertShape` 方法需要指定形状类型以及其宽度/高度（单位为点）。

```csharp
// Step 2: Insert an ellipse shape of the desired size (100 pt × 50 pt)
Shape ellipse = builder.InsertShape(ShapeType.Ellipse, 100, 50);
```

椭圆位于光标所在的当前页面上。您可以通过调整数值参数来更改其尺寸。

## 步骤 3：定位形状

插入后，您可以通过设置 `Left` 和 `Top` 属性将形状移动到页面的任意位置，这些属性使用相对于页面边距的点数。

```csharp
// Step 3: Position the shape on the page
ellipse.Left = 150; // distance from the left margin
ellipse.Top  = 100; // distance from the top margin
```

这些坐标大致将椭圆放置在标准 A4 页面上部中间。根据您的布局需求调整这些数值即可。

## 步骤 4：隐藏形状

隐藏对象在文档打开或打印时不会显示。设置 `Hidden` 标志会将形状标记为**隐藏对象**。

```csharp
// Step 4: Hide the shape so it never appears
ellipse.Hidden = true;
```

Word 会在屏幕渲染和打印输出时都遵守隐藏标志。该形状仍然是文档结构的一部分，您可以稍后通过代码查询或修改它。

## 步骤 5：保存文档

最后，将文档写入磁盘。请选择一个您拥有写入权限的文件夹。

```csharp
// Step 5: Save the document to a .docx file
doc.Save(@"C:\Temp\HiddenEllipse.docx");
```

文件 `HiddenEllipse.docx` 现在包含一个带有隐藏椭圆形状的空白页。

## 验证隐藏的椭圆

在 Microsoft Word 中打开生成的文件，并启用**显示隐藏文本**选项（文件 → 选项 → 显示）。您会看到椭圆的淡淡轮廓。若关闭该选项，形状将完全消失，验证了 `ellipse.Hidden = true` 按预期工作。

## 常见变体和边缘情况

| Situation | Recommended adjustment |
|-----------|------------------------|
| **不同的形状** | 将 `ShapeType.Ellipse` 替换为 `ShapeType.Rectangle`、`ShapeType.Arrow` 等。 |
| **多个隐藏对象** | 对每个形状重复步骤 2‑4；每个形状都可以拥有自己的 `Hidden` 标志。 |
| **不同的页面尺寸** | 在插入形状之前设置 `doc.FirstSection.PageSetup.PageWidth` 和 `PageHeight`。 |
| **条件可见性** | 在代码中结合使用 `Shape.Visible` 与 `Hidden`，以在运行时切换可见性。 |

**技巧提示：** 将标识数据存储在形状的 `AlternativeText` 属性中。即使隐藏，也可以使用 `doc.GetChildNodes(NodeType.Shape, true)` 稍后检索该形状，并通过该文本进行过滤。

## 完整源代码

下面是完整的程序，您可以复制、粘贴并运行。

```csharp
using System;
using Aspose.Words;
using Aspose.Words.Drawing;

namespace HiddenShapeDemo
{
    class Program
    {
        static void Main()
        {
            // Create a new blank document and a builder
            Document doc = new Document();
            DocumentBuilder builder = new DocumentBuilder(doc);

            // Insert an ellipse shape (100 pt × 50 pt)
            Shape ellipse = builder.InsertShape(ShapeType.Ellipse, 100, 50);

            // Position the shape on the page
            ellipse.Left = 150;
            ellipse.Top  = 100;

            // Hide the shape so it is invisible in the UI and on print
            ellipse.Hidden = true;

            // Optional: add a description for later retrieval
            ellipse.AlternativeText = "Hidden marker for internal processing";

            // Save the document
            string outputPath = @"C:\Temp\HiddenEllipse.docx";
            doc.Save(outputPath);

            Console.WriteLine($"Document saved to {outputPath}");
        }
    }
}
```

**预期输出：** 控制台会打印保存路径，文件 `HiddenEllipse.docx` 打开后是一个空白页，除非显示隐藏对象，否则没有可见图形。
