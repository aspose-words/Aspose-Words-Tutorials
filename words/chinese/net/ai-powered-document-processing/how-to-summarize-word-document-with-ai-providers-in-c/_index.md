# 如何在 C# 中使用 AI 提供商对 Word 文档进行摘要

如果您需要**快速摘要 Word 文档**，本指南将为您展示完整的实现方式。您将看到一个可直接运行的示例，能够**选择 AI 提供商**（OpenAI 或 Google），并在不离开 IDE 的情况下处理**大文档摘要**场景。

对 Word 文档进行摘要是构建知识库机器人、报告摘要或自动化邮件简报时的常见任务。下面的章节将教您如何安装 NuGet 包、加载 `.docx` 文件、配置摘要器并输出结果——全部使用纯 C#。

## 您需要的条件

| 要求 | 原因 |
|------|------|
| .NET 6 SDK 或更高版本 | 为 C# 示例提供运行时 |
| Visual Studio 2022（或任意 IDE） | 便于添加 NuGet 包并运行控制台应用 |
| `GroupDocs.Summarization` NuGet 包 | 提供代码中使用的 `DocumentSummarizer` API |
| 网络连接 | AI 提供商（OpenAI 或 Google）处理文本所必需 |

> **专业提示：** 如果您计划**摘要大文档**（超过 100 KB），请在选项中启用流式模式，以避免一次性将整个文件加载到内存。

## 分步摘要 Word 文档

### 步骤 1：安装摘要库

打开 Package Manager Console 并运行：

```powershell
Install-Package GroupDocs.Summarization
```

`GroupDocs.Summarization` 库抽象了底层的 AI 调用，使您无需更改业务逻辑即可切换提供商。

### 步骤 2：加载 Word 文档

```csharp
using GroupDocs.Summarization;
using GroupDocs.Summarization.Options;

// Step 2: Load the source document
Document doc = new Document("YOUR_DIRECTORY/Report.docx");
```

`Document` 类读取 `.docx` 文件并为摘要做好准备。如果文件较大，库会自动使用内存高效的解析器。

### 步骤 3：配置摘要器选项并**选择 AI 提供商**

```csharp
// Step 3: Set up summarization options (choose the AI provider)
SummarizerOptions options = new SummarizerOptions
{
    Provider = SummarizerProvider.OpenAI   // or SummarizerProvider.Google
};
```

- `Provider = SummarizerProvider.OpenAI` 选择 OpenAI 的 GPT‑4 模型。  
- `Provider = SummarizerProvider.Google` 选择 Google 的 Gemini 模型，在**使用 Google 进行摘要**时可获得更好的多语言支持。

您可以根据成本、延迟或语言需求**选择 AI 提供商**。同一个 `options` 对象同时适用于两种提供商，保持代码简洁。

### 步骤 4：生成摘要 – 支持**大文档摘要**

```csharp
// Step 4: Generate the summary using the selected provider
string summary = DocumentSummarizer.Summarize(doc, options);
```

当您**摘要大文档**时，库会将内容流式传输至 AI 服务，防止内存溢出错误。`Summarize` 方法返回包含最相关句子的纯文本字符串。

### 步骤 5：输出结果

```csharp
// Step 5: Output the generated summary
Console.WriteLine("Summary:\n" + summary);
```

运行程序后会打印出一段简明的段落，捕捉原始 Word 文件的核心要点。

## 完整可运行示例

```csharp
using System;
using GroupDocs.Summarization;
using GroupDocs.Summarization.Options;

namespace WordSummarizerDemo
{
    class Program
    {
        static void Main(string[] args)
        {
            // Load the source Word document
            Document doc = new Document("YOUR_DIRECTORY/Report.docx");

            // Choose the AI provider (OpenAI or Google)
            SummarizerOptions options = new SummarizerOptions
            {
                Provider = SummarizerProvider.Google   // Change to OpenAI if you prefer
            };

            // Generate the summary – works for both small and large documents
            string summary = DocumentSummarizer.Summarize(doc, options);

            // Display the summary in the console
            Console.WriteLine("Summary:\n" + summary);
        }
    }
}
```

**预期输出**

```
Summary:
The quarterly sales increased by 12% driven by the new product line, while operational costs fell 3% due to efficiency gains. The report also highlights upcoming market expansion in APAC and recommends allocating additional budget to R&D.
```

具体措辞会因您**选择的 AI 提供商**而异，但结构保持一致。

## 处理**大文档摘要**场景

当源 `.docx` 文件超过 5 MB 时，可考虑以下调整：

1. **启用分块** – 库会在发送至 AI 服务前将文档拆分为 5 KB 的块。
2. 如需更长的摘要，可在 `SummarizerOptions` 中**增加 `MaxSentences`**。
3. 为适应更长的处理时间，可**设置更高的 `Timeout`**。

```csharp
options.MaxSentences = 8;          // Return up to 8 sentences
options.EnableChunking = true;    // Essential for very large files
options.Timeout = TimeSpan.FromMinutes(2);
```

这些调优可确保**大文档摘要**操作保持快速且可靠。

## 如何高效**使用 Google 进行摘要**

Google 的 Gemini 模型在多语言内容和简洁表达方面表现出色。获取最佳结果的做法：

- 如文档包含非英文文本，可**指定语言**（可选）：
  ```csharp
  options.Language = "es"; // Spanish
  ```
- **调整 temperature** 以控制创造性：
  ```csharp
  options.Temperature = 0.3; // More deterministic output
  ```

使用**Google 进行摘要**时，服务可能返回略短但高度聚焦的摘要，相比 OpenAI 更适合多语言场景。请在示例文档上测试两种提供商，以决定最适合您产品的方案。

## 常见陷阱及规避方法

| 症状 | 原因 | 解决方案 |
|------|------|----------|
| 摘要为空 | 提供商密钥缺失或网络受阻 | 检查环境变量中的 API 密钥，并确保允许外部 HTTPS 访问 |
| 文本被截断 | 文档超出提供商的 token 限制 | 启用 `EnableChunking` 或在库支持的情况下增加 `MaxTokens` |
| 语言不符 | `Language` 选项设置错误 | 移除该选项或将其设为文档实际语言 |

提前解决这些问题可节省调试时间，尤其是在**选择 AI 提供商**用于生产工作负载时。

## 结论

现在，您已经掌握了在 C# 中使用灵活的 AI 层**摘要 Word 文档**的方法。通过配置 `SummarizerOptions`，您可以**选择 AI 提供商**、处理**大文档摘要**工作负载，甚至**使用 Google 进行摘要**以满足多语言需求。尝试调节 `MaxSentences`、`Temperature` 和分块设置，以针对特定场景微调输出。
