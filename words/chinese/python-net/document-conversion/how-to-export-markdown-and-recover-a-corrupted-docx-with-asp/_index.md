# 如何使用 Aspose.Words 导出 Markdown 并恢复损坏的 DOCX

如果您需要从可能已损坏的 Word 文件 **如何导出 markdown**，本指南将向您展示具体步骤。它还涵盖了使用 Aspose.Words for Python API 的 **如何恢复文档** 问题、**export docx to txt**，以及 **save word as pdf**。

您将学习如何在恢复模式下加载可能损坏的 DOCX、在保留公式的同时将其转换为 Markdown、将相同内容保存为纯文本、生成可访问的 PDF，甚至在最终导出前微调形状的阴影。无需任何外部工具——只需 Aspose.Words 和几行 Python 代码。

## Prerequisites

在开始之前，请确保您已具备：

* Python 3.8 或更高版本
* `aspose-words` 包（`pip install aspose-words`）
* 可能已损坏的 DOCX 文件（或用于测试的普通 DOCX）
* 对 Python 函数和类的基本了解

> **Pro tip:** 保留原始 DOCX 的备份；恢复模式只会修改内存中的表示，永远不会写回源文件。

## Step 1: 如何恢复损坏的 DOCX

首要任务是安全地加载文件。Aspose.Words 提供了 `RecoveryMode.RECOVER_CORRUPTED` 标志，可尝试重建破损的文档结构。

```python
import aspose.words as aw

# Load the file in recovery mode
load_opts = aw.LoadOptions()
load_opts.recovery_mode = aw.RecoveryMode.RECOVER_CORRUPTED
doc = aw.Document("YOUR_DIRECTORY/input.docx", load_opts)
```

**这有什么意义：**  
当 DOCX 部分损坏——缺少部件、XML 损坏或关系异常——标准加载会抛出异常。恢复模式会尽可能解析内容，丢弃不可读取的片段，同时保留其余部分，这对于后续的 **export docx to txt** 或 **save word as pdf** 操作至关重要。

### 常见边缘情况
如果文档已无法修复，仍会创建 `doc`，但会有警告日志。您可以检查 `doc.is_dirty` 来判断恢复过程中是否有内容被修改。

## Step 2: 如何使用 Aspose.Words 导出 markdown

Markdown 是一种轻量级标记语言，深受静态站点生成器和文档工具的喜爱。Aspose.Words 能在保留公式为 LaTeX 的同时导出 Markdown，非常适合技术文档。

```python
# Configure Markdown export options
md_opts = aw.MarkdownSaveOptions()
md_opts.office_math_export_mode = aw.OfficeMathExportMode.LATEX

# Save as Markdown
doc.save("YOUR_DIRECTORY/output.md", md_opts)
```

**您将得到：**  
* 将标题、列表和表格转换为 Markdown 语法的纯文本。  
* 每个 Word 公式都以 LaTeX 块（`$$ … $$`）形式呈现，确保数学在下游工具中仍可编辑。

### 验证输出
在任意编辑器中打开 `output.md`。您应该看到类似如下内容：

```markdown
# Title of the Document

This is a paragraph with **bold** text.

$$
\int_{0}^{\infty} e^{-x} dx = 1
$$
```

如果需要不同的公式格式（例如 MathML），请相应地更改 `office_math_export_mode`。

## Step 3: export docx to txt 并保留公式

纯文本文件对于快速搜索或喂入自然语言管道非常有用。同样的 `OfficeMathExportMode.LATEX` 适用于 `.txt` 导出，能够提供可读的 LaTeX 内联公式。

```python
txt_opts = aw.TxtSaveOptions()
txt_opts.office_math_export_mode = aw.OfficeMathExportMode.LATEX

doc.save("YOUR_DIRECTORY/output.txt", txt_opts)
```

**为何使用此方式而非复制粘贴？**  
手动复制粘贴往往会剥离隐藏字符并导致公式失真。此 **export docx to txt** 方法保证每个公式都以 LaTeX 片段出现，便于后续处理。

## Step 4: save word as PDF 并将浮动形状设为内联以提升可访问性

PDF 是发布的事实标准。当 Word 文档包含浮动图片或图表时，某些阅读器可能无法正确解释它们。设置 `export_floating_shapes_as_inline_tag` 可强制这些形状转为内联，从而提升可访问性和布局一致性。

```python
pdf_opts = aw.PdfSaveOptions()
pdf_opts.export_floating_shapes_as_inline_tag = True

doc.save("YOUR_DIRECTORY/output.pdf", pdf_opts)
```

**结果：**  
生成的 PDF 与原始布局基本一致，但所有形状已成为文本流的一部分。这对屏幕阅读器尤为有益，因为它们会将内联元素视为阅读顺序的一部分。

### 大文档提示
如果批量生成 PDF，重复使用同一个 `PdfSaveOptions` 实例可避免不必要的对象创建。

## Step 5: 在最终 PDF 前微调形状的阴影

有时需要在发布前调整视觉细节——例如徽标的阴影。下面的示例获取第一个形状，修改其阴影属性，并保存为新的 PDF。

```python
# Retrieve the first shape in the document
shape = doc.get_child(aw.NodeType.SHAPE, 0, True).as_shape()

# Adjust shadow settings
shape.shadow.blur_radius = 5.0   # Soft blur
shape.shadow.distance = 2.0     # Distance from shape edge
shape.shadow.opacity = 0.6      # 60% opacity

# Save the shadow‑enhanced PDF
doc.save("YOUR_DIRECTORY/shadowed.pdf", pdf_opts)
```

**此代码的作用：**  
* `blur_radius` 控制阴影的模糊程度。  
* `distance` 将阴影从形状向外移动，营造深度感。  
* `opacity` 使阴影半透明，通常更显专业。

通过更改 `get_child` 中的索引，您可以对任意形状重复此块代码。

## 完整脚本，快速复制粘贴

以下是将所有步骤组合在一起的完整可运行脚本。将 `YOUR_DIRECTORY` 替换为您文件所在的路径。

```python
import aspose.words as aw

# -------------------------------------------------
# 1️⃣ Recover a possibly corrupted DOCX
# -------------------------------------------------
load_opts = aw.LoadOptions()
load_opts.recovery_mode = aw.RecoveryMode.RECOVER_CORRUPTED
doc = aw.Document("YOUR_DIRECTORY/input.docx", load_opts)

# -------------------------------------------------
# 2️⃣ Export to Markdown (how to export markdown)
# -------------------------------------------------
md_opts = aw.MarkdownSaveOptions()
md_opts.office_math_export_mode = aw.OfficeMathExportMode.LATEX
doc.save("YOUR_DIRECTORY/output.md", md_opts)

# -------------------------------------------------
# 3️⃣ Export to plain text (export docx to txt)
# -------------------------------------------------
txt_opts = aw.TxtSaveOptions()
txt_opts.office_math_export_mode = aw.OfficeMathExportMode.LATEX
doc.save("YOUR_DIRECTORY/output.txt", txt_opts)

# -------------------------------------------------
# 4️⃣ Save as PDF (save word as pdf)
# -------------------------------------------------
pdf_opts = aw.PdfSaveOptions()
pdf_opts.export_floating_shapes_as_inline_tag = True
doc.save("YOUR_DIRECTORY/output.pdf", pdf_opts)

# -------------------------------------------------
# 5️⃣ Adjust first shape's shadow and re‑save PDF
# -------------------------------------------------
shape = doc.get_child(aw.NodeType.SHAPE, 0, True).as_shape()
shape.shadow.blur_radius = 5.0
shape.shadow.distance = 2.0
shape.shadow.opacity = 0.6
doc.save("YOUR_DIRECTORY/shadowed.pdf", pdf_opts)
```

运行脚本后将生成：

| 文件 | 用途 |
|------|------|
| `output.md` | 包含 LaTeX 公式的 Markdown（**如何导出 markdown**） |
| `output.txt` | 纯文本版本（**export docx to txt**） |
| `output.pdf` | 可访问的 PDF（**save word as pdf**） |
| `shadowed.pdf` | 带自定义阴影的 PDF |

## Frequently asked questions

**问：恢复模式能修复缺失的图片吗？**  
答：它可以恢复文档结构，但无法重新生成丢失的二进制图片数据。如果图片部件缺失，形状将为空。

**问：我可以导出为 HTML 而不是 Markdown 吗？**  
答：可以——使用 `aw.HtmlSaveOptions()` 并根据需要设置 `office_math_export_mode`。

**问：如果我想保留浮动形状为浮动该怎么办？**  
答：省略 `export_floating_shapes_as_inline_tag` 或将其设为 `False`。

**问：LaTeX 导出是否兼容 MathJax？**  
答：完全兼容。MathJax 能渲染 Markdown 和 Txt 导出器生成的 `$$ … $$` 块。
