# 如何使用 Aspose.Words 在 Python 中创建柱形图

如果您需要在 Python 中创建柱形图，本指南将展示您所需的完整代码和思路。使用 Aspose.Words 图表 API，您可以精确定义尺寸、应用内置样式，并在不离开 Python 的情况下导出结果。

生成柱形图是报告、仪表盘和自动化文档创建中的常见需求。本教程涵盖了从导入库到验证保存的图像的每一步，帮助您将图表生成集成到任何 Python 项目中。

## 前置条件

在开始之前，请确保您具备：

* 已安装 Python 3.8 或更高版本。
* 有效的 Aspose.Words for Python 许可证（或免费评估密钥）。
* 对 Python 模块和面向对象代码有基本了解。

Aspose.Words 图表引擎可在 Windows、macOS 和 Linux 上运行，且无需额外的图形库，因为渲染在服务器端完成。

## 步骤 1：导入 Aspose.Words 库

第一步是导入 `aspose.words` 包并为其起一个简短别名。将导入放在文件顶部可以保持命名空间整洁，使代码更易阅读。

```python
# Step 1: Import the Aspose.Words library
import aspose.words as aw
```

现在 `aw` 引用了完整的 Aspose.Words API，包括您将用于构建柱形图的 `Chart` 类。

## 步骤 2：使用所需尺寸创建柱形图

柱形图需要明确的宽度和高度，以便渲染的图像适配文档布局。`Chart` 构造函数接受三个参数：图表类型、宽度（单位为点）和高度（单位为点）。使用 `aw.ChartType.COLUMN` 告诉引擎生成垂直条形图。

```python
# Step 2: Create a column chart with the desired dimensions
chart = aw.Chart(aw.ChartType.COLUMN, 400, 300)   # width=400pt, height=300pt
```

**为什么要设置尺寸？**  
当您将图表嵌入 Word 文档或导出为图像时，周围内容会遵循您提供的精确大小。这可以防止不必要的缩放或裁剪。

### 小技巧：使用 `chart.dimensions` 动态调整大小

如果数据集大小不固定，您可以根据系列数量计算尺寸：

```python
series_count = 5
base_width = 80
chart.width = base_width * series_count
chart.height = 300
```

## 步骤 3：为柱形图应用内置样式

Aspose.Words 附带了多种预定义的视觉主题。选择样式可以免去手动配置颜色、字体和网格线的工作。`aw.ChartStyle.STYLE_5` 是一种简洁、专业的外观，适用于大多数业务报告。

```python
# Step 3: Apply a built‑in style to the chart
chart.style = aw.ChartStyle.STYLE_5
```

如果您想要不同的外观，只需将 `STYLE_5` 替换为其他常量（`STYLE_1` … `STYLE_8`）即可。每种样式遵循相同的命名规则，便于实验。

### 边缘情况：无效的样式常量

尝试分配不存在的样式会抛出 `AttributeError`。通过检查常量是否在枚举中来防止此类错误：

```python
if hasattr(aw.ChartStyle, "STYLE_5"):
    chart.style = aw.ChartStyle.STYLE_5
else:
    raise ValueError("Requested chart style does not exist.")
```

## 步骤 4：向柱形图添加数据系列

没有数据的图表毫无意义。您可以添加一个或多个 `ChartSeries` 对象，每个对象代表一组柱形。下面的示例添加了一个包含三个数据点的单一系列。

```python
# Step 4: Add data series to the column chart
series = chart.series.add()
series.name = "Quarterly Sales"
series.data = [12000, 15000, 18000]   # Values for Q1, Q2, Q3
```

您可以重复调用 `chart.series.add()` 来加入更多系列（例如 “Projected Sales”）。API 会自动将柱形并排排列。

## 步骤 5：渲染图表并保存为图像

配置完图表后，您可以将其渲染为位图或图像文件。`save` 方法接受文件路径和可选的格式。PNG 是无损且广泛支持的格式。

```python
# Step 5: Render and save the chart as a PNG image
output_path = "column_chart.png"
chart.save(output_path, aw.SaveFormat.PNG)
print(f"Chart saved to {output_path}")
```

`SaveFormat` 枚举包括 PNG、JPEG、BMP 等。请选择与后续工作流匹配的格式。

## 验证输出

使用任意图像查看器打开 `column_chart.png`。您应该看到一个三列柱形图，已应用所选内置主题，尺寸恰好为 400 × 300 点。

![由 Aspose.Words 在 Python 中生成的柱形图](column_chart.png){: .center alt="由 Aspose.Words 在 Python 中生成的柱形图的截图"}

如果图像为空白或失真，请检查以下事项：

1. 在添加系列之前已实例化 `aw.Chart` 对象。
2. `chart.style` 常量对应于现有的枚举值。
3. `save` 调用使用了受支持的 `SaveFormat`。

## 常见变体及附加技巧

| 场景 | 推荐更改 |
|-----------|--------------------|
| **多个数据系列** | 添加额外的 `chart.series.add()` 块，并为每个系列设置 `series.name` 和 `series.data`。 |
| **自定义颜色** | 在应用内置样式后，通过 `series.points[i].fill.fore_color` 覆盖单个柱形的颜色。 |
| **嵌入 Word 文档** | 使用 `doc = aw.Document(); doc.sections[0].body.append_child(chart); doc.save("report.docx")` 替代 `chart.save()`。 |
| **动态尺寸** | 根据系列数量计算宽度（`width = 80 * len(chart.series)`）。 |

这些变体展示了相同核心代码如何适配不同的报告场景。
