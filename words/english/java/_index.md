## How to generate pdf from word using Aspose.Words for Java?
`Document` is the Aspose.Words object that loads and represents a Word file. To generate a PDF, load an existing Word file with `new Document("input.docx")` and call `doc.save("output.pdf", SaveFormat.PDF)`. Aspose.Words automatically preserves fonts, tables, images, and complex layouts, delivering a PDF that looks identical to the source document while handling large files efficiently.

## How to convert word to pdf java?
`Document` loads a Word file and provides conversion methods. To convert Word to PDF in Java, open the document with `new Document("input.docx")` and invoke `doc.save("output.pdf", SaveFormat.PDF)`. For batch conversion, iterate through a folder of `.docx` files, loading each into a `Document` and saving as PDF. No external converters or Office installations are required.

## How to extract text word java?
`Document` represents the loaded Word file and provides methods to access its content. To extract plain text, create a `Document` object with the source file and call `doc.getText()`, which returns the document’s text without any formatting. The resulting string can be indexed, searched, or fed into NLP pipelines for further processing.
