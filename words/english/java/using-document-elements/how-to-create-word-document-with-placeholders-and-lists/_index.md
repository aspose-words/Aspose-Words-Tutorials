# How to create word document with placeholders and lists

If you need to **create word document** programmatically, this guide shows you exactly how. We'll walk through **set placeholder text**, **add list items**, and **how to use SDT** (Structured Document Tag) controls with Aspose.Words for .NET.

Developers often ask for a way to embed content controls—like plain‑text placeholders or drop‑down lists—directly into a .docx file without opening Word. This tutorial gives you a complete, runnable example, explains why each step matters, and covers common variations such as adding the controls to an existing document or customizing list values.

## Prerequisites

Before you start, make sure you have:

- .NET 6.0 SDK or later installed  
- Visual Studio 2022 (or any C# IDE)  
- An active Aspose.Words for .NET license (a free trial works for development)  
- Basic familiarity with C# syntax  

The code targets **Aspose.Words 23.9** (the latest stable version at the time of writing). Adjust the NuGet package version if you use a newer release.

## Insert a plain‑text Structured Document Tag (set placeholder text)

A plain‑text SDT behaves like a content control that the user can fill in. Setting its `Title` and `PlaceholderName` provides a friendly hint inside Word.

```csharp
            // Step 2: Insert a plain‑text SDT and set its placeholder text
            StructuredDocumentTag plainTextTag = builder.InsertStructuredDocumentTag(
                StructuredDocumentTagType.PlainText, true);
            plainTextTag.Title = "CustomerName";
            plainTextTag.PlaceholderName = "Enter name";
```

**Explanation:**  
- `InsertStructuredDocumentTag` creates the control at the builder’s current cursor position.  
- `StructuredDocumentTagType.PlainText` tells Word to render a simple text box.  
- `Title` is the internal name used by Word’s XML; it’s handy for later data binding.  
- `PlaceholderName` is the gray hint that appears until the user types something.

> **Pro tip:** If you need the placeholder to appear in the document’s *Properties* pane, also set `plainTextTag.Tag = "CustomerName"`.

## Insert a drop‑down list SDT (how to use sdt)

A drop‑down list lets you present a predefined set of choices. This is the core of **how to use sdt** for enumerated data.

```csharp
            // Step 3: Insert a drop‑down list SDT and define its title
            StructuredDocumentTag dropdownTag = builder.InsertStructuredDocumentTag(
                StructuredDocumentTagType.DropDownList, true);
            dropdownTag.Title = "Country";
```

**Why a drop‑down?**  
Drop‑down lists improve data consistency and reduce typing errors. The `Title` property again serves as an identifier for downstream processing (e.g., when extracting form data).

## Add list items to the drop‑down (add list items)

Now we populate the control with selectable values. Each `ListItem` takes a display text and an optional value that can be stored in the document’s XML.

```csharp
            // Step 4: Populate the drop‑down with selectable items
            dropdownTag.ListItems.Add(new ListItem("USA", "US"));
            dropdownTag.ListItems.Add(new ListItem("Canada", "CA"));
            dropdownTag.ListItems.Add(new ListItem("Mexico", "MX"));
```

**Key points:**  

- The first argument (`"USA"`) is what the user sees.  
- The second argument (`"US"`) is the underlying value you can read programmatically.  
- You can add as many items as needed; the list is stored in the `<w:listItem>` elements of the .docx XML.

### Edge cases and variations

| Situation | Recommended adjustment |
|-----------|------------------------|
| **Adding controls to an existing file** | Load the file with `new Document("Existing.docx")` instead of creating a new `Document`. |
| **Making the placeholder required** | Set `plainTextTag.IsShowingPlaceholderWhenEmpty = false` and `plainTextTag.IsShowingPlaceholderWhenEmpty = true` based on your validation logic. |
| **Binding list items to a data source** | Loop through a collection (`foreach (var country in countries)`) and call `dropdownTag.ListItems.Add(new ListItem(country.Name, country.Code))`. |
| **Styling the control** | Use `builder.Font` properties before inserting the SDT to affect the default style of the placeholder text. |
| **Removing a control later** | Locate it via `doc.GetChildNodes(NodeType.StructuredDocumentTag, true)` and call `tag.Remove();`. |

## How to create control programmatically – best practices

1. **Create the document first** – initializing `DocumentBuilder` early avoids cursor‑position surprises.  
2. **Set titles and tags** – they act as stable identifiers for later data extraction.  
3. **Add placeholder text** – improves user experience, especially for plain‑text tags.  
4. **Populate list items immediately** – Word renders the drop‑down correctly only after the list is attached.  
5. **Save once** – repeated `Save` calls inside a loop dramatically increase I/O overhead.

By following these steps, you ensure that the Word file is both *machine‑readable* (for back‑end processing) and *user‑friendly* (for front‑end editing).
