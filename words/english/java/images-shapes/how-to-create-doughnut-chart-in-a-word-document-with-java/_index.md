# How to create doughnut chart in a Word document with Java

If you need to **create doughnut chart** inside a Word file, this tutorial shows you a complete, ready‑to‑run solution. You’ll see how to **insert pie chart**, turn it into a doughnut, **rotate pie chart** for better balance, and **format pie chart** to match your branding. By the end you’ll have a professional Word document that can be used in reports, dashboards, or automated email attachments.

Creating a chart programmatically eliminates manual copy‑paste steps and guarantees consistent styling across dozens of generated documents. The example uses the Aspose.Words for Java library, which works with Java 8+ and requires no Microsoft Office installation. No other prerequisites are needed beyond a standard JDK and your favorite IDE.

## Prerequisites

- Java Development Kit (JDK) 8 or newer  
- Maven or Gradle for dependency management (the tutorial uses Maven)  
- Aspose.Words for Java library (free trial license is sufficient for testing)  

Add the Aspose.Words dependency to your `pom.xml`:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-words</artifactId>
    <version>24.9</version> <!-- Use the latest stable version -->
</dependency>
```

> **Pro tip:** Register your license with `License license = new License(); license.setLicense("Aspose.Words.lic");` before creating any document to remove evaluation watermarks.

## Create doughnut chart in a Word document

The core workflow consists of five logical steps. Each step is wrapped in its own method to keep the code clean and reusable.

```java
import com.aspose.words.*;
import com.aspose.words.drawing.*;

public class DoughnutChartDemo {

    public static void main(String[] args) throws Exception {
        // Step 1: create blank Word document
        Document doc = createBlankWordDocument();

        // Step 2: insert a pie chart (base for the doughnut)
        Chart chart = insertPieChart(doc, 400, 300);

        // Step 3: convert the pie chart into a doughnut and rotate it
        customizeChartAppearance(chart);

        // Step 4: apply additional formatting to the chart
        formatPieChart(chart);

        // Step 5: save the final document
        doc.save("output/DoughnutChartFormatted.docx");
        System.out.println("Document saved successfully.");
    }

    /** Step 1 – create blank Word document */
    private static Document createBlankWordDocument() {
        // Aspose.Words creates an empty document by default
        return new Document();
    }

    /** Step 2 – insert pie chart with given dimensions */
    private static Chart insertPieChart(Document doc, int width, int height) throws Exception {
        DocumentBuilder builder = new DocumentBuilder(doc);
        // ChartType.PIE creates a standard pie chart that we will later turn into a doughnut
        Chart chart = builder.insertChart(ChartType.PIE, width, height);
        // Populate the chart with sample data
        chart.getSeries().clear(); // Remove default series
        ChartSeries series = chart.getSeries().add("Sales", new String[]{"Q1", "Q2", "Q3", "Q4"},
                new double[]{15000, 23000, 18000, 27000});
        return chart;
    }

    /** Step 3 – rotate pie chart and make it a doughnut */
    private static void customizeChartAppearance(Chart chart) {
        // Explode the first slice for emphasis
        chart.getSeries().get(0).setExplode(20);
        // Convert the pie into a doughnut by setting a hole size (percentage of radius)
        chart.setHoleSize(30); // 30% hole creates a classic doughnut look
        // Rotate the chart so the largest slice starts at 45°
        chart.setRotationAngle(45);
    }

    /** Step 4 – additional formatting of the pie chart */
    private static void formatPieChart(Chart chart) {
        // Example: change the first slice color to a brand color
        chart.getSeries().get(0).getPoints().get(0).getFormat().setFillForegroundColor(Color.fromArgb(0xFF, 0x4A, 0x90));
        // Add a legend and position it at the bottom
        chart.setHasLegend(true);
        chart.getLegend().setPosition(LegendPosition.BOTTOM);
        // Set a title for the chart
        chart.setTitle("Quarterly Sales Distribution");
    }
}
```

### What the code does

| Step | Action | Reason |
|------|--------|--------|
| **Create blank Word document** | `new Document()` | Starts with a clean file so you control every element. |
| **Insert pie chart** | `builder.insertChart(ChartType.PIE, …)` | A pie chart is the base shape; Aspose only provides a doughnut by adjusting the hole size. |
| **Rotate pie chart** | `chart.setRotationAngle(45)` | Rotating aligns the largest slice to a more readable position. |
| **Format pie chart** | `setExplode`, `setHoleSize`, color, legend | Improves visual hierarchy and matches corporate style guidelines. |
| **Save document** | `doc.save("…/DoughnutChartFormatted.docx")` | Writes the final .docx file to disk, ready for distribution. |

## Insert pie chart before converting to doughnut

Aspose.Words does not provide a direct “insert doughnut chart” method. Instead, you **insert pie chart** and then modify its properties. This two‑step approach gives you full control over data series, slice explosion, and hole size. If you need a pure pie chart elsewhere, simply omit the `setHoleSize` call.

## Rotate pie chart for visual balance

The default orientation starts the first slice at the 12 o’clock position. In many business reports the most important slice should start at a more natural angle, such as 45 degrees. The `setRotationAngle(double angle)` method accepts degrees and rotates the entire chart without affecting data values.

## Format pie chart and customize appearance

Beyond converting to a doughnut, you often want to **format pie chart** elements:

- **Explode** the first slice (`setExplode`) to draw attention.  
- **Color** each slice using `getPoints().get(i).getFormat().setFillForegroundColor`.  
- **Legend** positioning (`setHasLegend`, `setPosition`) helps readers interpret categories.  
- **Title** (`setTitle`) gives context at a glance.  

All these settings are optional; you can tailor them to match your brand palette or corporate templates.

## Create blank Word document and save the result

The `createBlankWordDocument` method encapsulates the **create blank word document** step. Keeping this logic isolated makes it easy to reuse the method when generating multiple reports in a batch process. After all customizations, `doc.save` writes the file in the standard Office Open XML format (`.docx`), which can be opened in Microsoft Word, LibreOffice, or Google Docs without loss of fidelity.

### Expected output

When you run the `main` method, the console prints:

```
Document saved successfully.
```

And the file `output/DoughnutChartFormatted.docx` contains a single page with a doughnut chart titled *Quarterly Sales Distribution*. The chart shows four slices, the first slice exploded, colored in the brand hue, and rotated 45 degrees.

## Common variations and edge cases

| Situation | Adjustment |
|-----------|------------|
| **More than one data series** | Add additional `ChartSeries` objects to `chart.getSeries()`. |
| **Different chart size** | Change the `width` and `height` arguments in `insertPieChart`. |
| **No hole (pure pie)** | Omit `chart.setHoleSize(…)` or set it to `0`. |
| **Large documents** | Use `DocumentBuilder` to insert the chart into a specific section or bookmark. |
| **License not set** | The library runs in evaluation mode, adding a watermark on the first page. Register a license to remove it. |
