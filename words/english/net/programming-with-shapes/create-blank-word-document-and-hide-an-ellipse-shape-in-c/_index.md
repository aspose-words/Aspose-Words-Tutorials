# Create blank Word document and hide an ellipse shape in C#

If you need to **create blank Word document** and then hide a graphical element, this guide shows you exactly how to do it with C#. You’ll see a complete, runnable example that inserts an ellipse, positions it, marks it as hidden, and saves the file—all in a few lines of code.

The tutorial covers everything from project setup to the final verification step. By the end, you can generate a Word file where the ellipse never appears on screen or in print, which is useful for storing metadata, bookmarks, or any invisible marker.

## Prerequisites

Before you start, make sure you have:

* .NET 6.0 SDK or later installed  
* A C# development environment (Visual Studio 2022, Rider, or VS Code)  
* The **Aspose.Words for .NET** NuGet package (`Install-Package Aspose.Words`)  

These tools provide the `Document` and `DocumentBuilder` classes used in the code sample.

## Step 1: Create a blank Word document

The first operation creates an empty `Document` object and a `DocumentBuilder` that lets you add content.

```csharp
using Aspose.Words;
using Aspose.Words.Drawing;

// Step 1: Initialize an empty document and a builder
Document doc = new Document();
DocumentBuilder builder = new DocumentBuilder(doc);
```

`Document` represents the entire `.docx` package, while `DocumentBuilder` offers a fluent API for inserting text, shapes, and other objects. Starting with a blank document gives you full control over every element you add.

## Step 2: How to insert ellipse

An ellipse is a vector shape that can be used as a marker. The `InsertShape` method requires the shape type and its width/height in points.

```csharp
// Step 2: Insert an ellipse shape of the desired size (100 pt × 50 pt)
Shape ellipse = builder.InsertShape(ShapeType.Ellipse, 100, 50);
```

The ellipse lives on the current page at the cursor location. You can change its dimensions by adjusting the numeric arguments.

## Step 3: How to position shape

After insertion, you can move the shape anywhere on the page by setting the `Left` and `Top` properties, which use points relative to the page margin.

```csharp
// Step 3: Position the shape on the page
ellipse.Left = 150; // distance from the left margin
ellipse.Top  = 100; // distance from the top margin
```

These coordinates place the ellipse roughly in the upper‑middle of a standard A4 page. Adjust the values to fit your layout requirements.

## Step 4: How to hide shape

A hidden object is not displayed when the document is opened or printed. Setting the `Hidden` flag marks the shape as a **hidden object word**.

```csharp
// Step 4: Hide the shape so it never appears
ellipse.Hidden = true;
```

Word respects the hidden flag for both on‑screen rendering and print output. The shape remains part of the document structure, allowing you to query or modify it later through code.

## Step 5: Save the document

Finally, write the document to disk. Choose a folder you have write access to.

```csharp
// Step 5: Save the document to a .docx file
doc.Save(@"C:\Temp\HiddenEllipse.docx");
```

The file `HiddenEllipse.docx` now contains a blank page with a hidden ellipse shape.

## Verifying the hidden ellipse

Open the generated file in Microsoft Word and enable the **Show hidden text** option (File → Options → Display). You’ll see a faint outline of the ellipse. If you turn the option off, the shape disappears completely, confirming that `ellipse.Hidden = true` works as expected.

## Common variations and edge cases

| Situation | Recommended adjustment |
|-----------|------------------------|
| **Different shape** | Replace `ShapeType.Ellipse` with `ShapeType.Rectangle`, `ShapeType.Arrow`, etc. |
| **Multiple hidden objects** | Repeat steps 2‑4 for each shape; each can have its own `Hidden` flag. |
| **Different page size** | Set `doc.FirstSection.PageSetup.PageWidth` and `PageHeight` before inserting the shape. |
| **Conditional visibility** | Use `Shape.Visible` in combination with `Hidden` to toggle at runtime via code. |

**Pro tip:** Store identification data in the shape’s `AlternativeText` property. Even when hidden, you can retrieve the shape later with `doc.GetChildNodes(NodeType.Shape, true)` and filter by that text.

## Full source code

Below is the complete program you can copy, paste, and run.

```csharp
using System;
using Aspose.Words;
using Aspose.Words.Drawing;

namespace HiddenShapeDemo
{
    class Program
    {
        static void Main()
        {
            // Create a new blank document and a builder
            Document doc = new Document();
            DocumentBuilder builder = new DocumentBuilder(doc);

            // Insert an ellipse shape (100 pt × 50 pt)
            Shape ellipse = builder.InsertShape(ShapeType.Ellipse, 100, 50);

            // Position the shape on the page
            ellipse.Left = 150;
            ellipse.Top  = 100;

            // Hide the shape so it is invisible in the UI and on print
            ellipse.Hidden = true;

            // Optional: add a description for later retrieval
            ellipse.AlternativeText = "Hidden marker for internal processing";

            // Save the document
            string outputPath = @"C:\Temp\HiddenEllipse.docx";
            doc.Save(outputPath);

            Console.WriteLine($"Document saved to {outputPath}");
        }
    }
}
```

**Expected output:** The console prints the save path, and the file `HiddenEllipse.docx` opens as a blank page with no visible graphics unless hidden objects are shown.
