# How to create hidden shape docx with Aspose.Words in C#

If you need to **create hidden shape docx** files programmatically, this tutorial shows the exact steps using Aspose.Words for .NET. You will see how to **set shape fill color** so the shape is visible while editing, and then **hide shape in Word document** so the end user never sees it unless hidden objects are displayed.

The guide covers everything you need to know: required NuGet packages, a full, runnable code example, and tips for troubleshooting common pitfalls. By the end of the article you will have a DOCX that contains an invisible ellipse that can be revealed later if needed.

## Prerequisites

Before you start, make sure you have:

- .NET 6.0 SDK or later installed  
- Visual Studio 2022 (or any C# IDE)  
- An active Aspose.Words for .NET license (or a temporary evaluation key)  
- Basic familiarity with C# syntax  

You do **not** need any additional Word interop libraries because Aspose.Words works independently of Microsoft Office.

## Step 1: Create hidden shape docx – initialise the document

The first operation is to instantiate a `Document` object and a `DocumentBuilder`. The builder provides the fluent API for inserting shapes, text, and other elements.

```csharp
using Aspose.Words;
using Aspose.Words.Drawing;
using System.Drawing;

class Program
{
    static void Main()
    {
        // Initialise an empty DOCX file
        Document doc = new Document();
        DocumentBuilder builder = new DocumentBuilder(doc);
```

*Why this matters*: A fresh `Document` represents an empty Word file. The `DocumentBuilder` acts as a cursor that knows where the next element will be placed. Starting with a clean document ensures that the hidden shape does not inherit unexpected formatting.

## Step 2: Set shape fill color for the ellipse

Next, insert an ellipse shape and apply a fill color. The color makes the shape visible in the editor, which is useful when you need to verify its size or position before hiding it.

```csharp
        // Insert an ellipse 150 pt wide and 100 pt high
        Shape ellipse = builder.InsertShape(ShapeType.Ellipse, 150, 100);

        // Apply a bright fill so the shape can be inspected
        ellipse.FillColor = Color.Yellow;
```

The **set shape fill color** step is optional for the final hidden document, but it helps during development. Without a fill, the shape would be invisible even before you apply the hidden flag, making debugging harder.

## Step 3: Hide shape in Word document

Now apply the `Hidden` property. When `Hidden` is `true`, Microsoft Word will not render the shape in normal view. Users can still reveal it by enabling “Show hidden objects” in Word’s options.

```csharp
        // Mark the shape as hidden – it will not appear in normal view
        ellipse.Hidden = true;
```

*Important note*: The hidden flag works with Word 2010 and later. If you target older versions, the shape may still appear. Also, the flag does not affect the shape’s position; it merely suppresses rendering.

## Step 4: Save the DOCX file

Finally, write the document to disk. The file name can be any valid path; here we use a relative path for simplicity.

```csharp
        // Persist the document with the hidden shape
        doc.Save("HiddenShape.docx");
    }
}
```

When you open `HiddenShape.docx` in Microsoft Word, the ellipse will not be visible. If you enable **File → Options → Display → Show hidden objects**, the yellow ellipse appears exactly where you placed it.

### Expected output

- A file named `HiddenShape.docx` in the executable’s working directory.  
- Opening the file in Word shows normal content with **no visible shape**.  
- Enabling “Show hidden objects” reveals a yellow ellipse of size 150 × 100 pt.

## Step 5: Verify the hidden shape programmatically (optional)

If you need to confirm that the shape is indeed hidden without opening Word, you can inspect the `Hidden` property after loading the document:

```csharp
        Document loaded = new Document("HiddenShape.docx");
        Shape loadedShape = (Shape)loaded.GetChildNodes(NodeType.Shape, true)[0];
        System.Console.WriteLine($"Shape hidden? {loadedShape.Hidden}");
```

The console prints `Shape hidden? True`, proving that the flag persisted.

## Common pitfalls and how to avoid them

| Symptom | Cause | Fix |
|---------|-------|-----|
| Shape still visible after saving | `Hidden` not set or set after saving | Ensure `ellipse.Hidden = true;` runs **before** `doc.Save()`. |
| Fill color not applied | `FillColor` assigned before shape creation | Assign `FillColor` **after** `InsertShape` returns the `Shape` object. |
| DOCX fails to open | Mismatched Aspose.Words version vs .NET runtime | Use the latest Aspose.Words NuGet package that targets .NET 6+. |
| Hidden flag ignored on older Word versions | Word < 2010 | Consider using a different technique (e.g., setting shape’s `WrapType` to `None` and moving it off‑page). |

## Pro tip: Re‑using hidden shapes as placeholders

You can store hidden shapes in a template document and later replace them with visible content. Because the shape is hidden, it does not affect the layout until you set `Hidden = false`. This pattern is handy for generating contracts where a signature field starts hidden and becomes visible after a user signs.

## Next steps

- **Reveal hidden shapes**: Use `shape.Hidden = false;` to make the ellipse appear at runtime.  
- **Change shape type**: Replace `ShapeType.Ellipse` with `ShapeType.Rectangle`, `ShapeType.Polygon`, etc., to fit your use case.  
- **Add text inside the shape**: Insert a `TextBox` into the shape’s `TextBox` property for captioned placeholders.  
- **Combine with mail‑merge**: Place hidden shapes in a mail‑merge template and toggle visibility per record.
