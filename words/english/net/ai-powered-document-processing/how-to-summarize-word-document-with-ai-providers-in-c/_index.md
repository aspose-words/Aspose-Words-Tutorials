# How to summarize Word document with AI providers in C#

If you need to **summarize Word document** quickly, this guide shows you exactly how. You’ll see a complete, runnable example that lets you **choose AI provider** (OpenAI or Google) and handle a **summarize large document** scenario without leaving your IDE.

Summarizing a Word document is a common task when building knowledge‑base bots, report digests, or automated email briefs. In the sections below you’ll learn which NuGet package to install, how to load a `.docx` file, configure the summarizer, and output the result—all in plain C#.

## What you’ll need

| Requirement | Reason |
|-------------|--------|
| .NET 6 SDK or later | Provides the runtime for the C# example |
| Visual Studio 2022 (or any IDE) | Makes it easy to add NuGet packages and run the console app |
| `GroupDocs.Summarization` NuGet package | Supplies the `DocumentSummarizer` API used in the code |
| An internet connection | Required for the AI provider (OpenAI or Google) to process the text |

> **Pro tip:** If you plan to **summarize large document** files (over 100 KB), enable streaming mode in the options to avoid loading the entire file into memory.

## How to summarize Word document step by step

### Step 1: Install the summarization library

Open the Package Manager Console and run:

```powershell
Install-Package GroupDocs.Summarization
```

The `GroupDocs.Summarization` library abstracts the underlying AI calls, so you can switch providers without changing your business logic.

### Step 2: Load the Word document

```csharp
using GroupDocs.Summarization;
using GroupDocs.Summarization.Options;

// Step 2: Load the source document
Document doc = new Document("YOUR_DIRECTORY/Report.docx");
```

The `Document` class reads the `.docx` file and prepares it for summarization. If the file is large, the library automatically uses a memory‑efficient parser.

### Step 3: Configure summarizer options and **choose AI provider**

```csharp
// Step 3: Set up summarization options (choose the AI provider)
SummarizerOptions options = new SummarizerOptions
{
    Provider = SummarizerProvider.OpenAI   // or SummarizerProvider.Google
};
```

- `Provider = SummarizerProvider.OpenAI` selects OpenAI’s GPT‑4 model.  
- `Provider = SummarizerProvider.Google` selects Google’s Gemini model, which is ideal when you **summarize with Google** for better multilingual support.

You **choose AI provider** based on cost, latency, or language requirements. The same `options` object works for both providers, keeping your code clean.

### Step 4: Generate the summary – **summarize large document** support

```csharp
// Step 4: Generate the summary using the selected provider
string summary = DocumentSummarizer.Summarize(doc, options);
```

When you **summarize large document** files, the library streams the content to the AI service, preventing out‑of‑memory errors. The `Summarize` method returns a plain‑text string that contains the most relevant sentences.

### Step 5: Output the result

```csharp
// Step 5: Output the generated summary
Console.WriteLine("Summary:\n" + summary);
```

Running the program prints a concise paragraph that captures the essence of the original Word file.

## Full runnable example

```csharp
using System;
using GroupDocs.Summarization;
using GroupDocs.Summarization.Options;

namespace WordSummarizerDemo
{
    class Program
    {
        static void Main(string[] args)
        {
            // Load the source Word document
            Document doc = new Document("YOUR_DIRECTORY/Report.docx");

            // Choose the AI provider (OpenAI or Google)
            SummarizerOptions options = new SummarizerOptions
            {
                Provider = SummarizerProvider.Google   // Change to OpenAI if you prefer
            };

            // Generate the summary – works for both small and large documents
            string summary = DocumentSummarizer.Summarize(doc, options);

            // Display the summary in the console
            Console.WriteLine("Summary:\n" + summary);
        }
    }
}
```

**Expected output**

```
Summary:
The quarterly sales increased by 12% driven by the new product line, while operational costs fell 3% due to efficiency gains. The report also highlights upcoming market expansion in APAC and recommends allocating additional budget to R&D.
```

The exact wording will differ depending on the AI model you **choose AI provider**, but the structure remains the same.

## Handling a **summarize large document** scenario

When the source `.docx` exceeds 5 MB, consider these adjustments:

1. **Enable chunking** – the library splits the document into 5 KB blocks before sending them to the AI service.
2. **Increase `MaxSentences`** in `SummarizerOptions` if you need a longer summary.
3. **Set `Timeout`** to a higher value to accommodate longer processing times.

```csharp
options.MaxSentences = 8;          // Return up to 8 sentences
options.EnableChunking = true;    // Essential for very large files
options.Timeout = TimeSpan.FromMinutes(2);
```

These tweaks ensure the **summarize large document** operation remains fast and reliable.

## How to **summarize with Google** effectively

Google’s Gemini model excels at multilingual content and concise phrasing. To get the best results:

- **Specify language** (optional) if the document contains non‑English text:
  ```csharp
  options.Language = "es"; // Spanish
  ```
- **Adjust temperature** to control creativity:
  ```csharp
  options.Temperature = 0.3; // More deterministic output
  ```

When you **summarize with Google**, the service may return a slightly shorter but highly focused summary compared to OpenAI. Test both providers on a sample document to decide which fits your product.

## Common pitfalls and how to avoid them

| Symptom | Cause | Fix |
|---------|-------|-----|
| Empty summary | Provider key missing or network blocked | Verify API keys in environment variables and ensure outbound HTTPS is allowed |
| Truncated text | Document exceeds provider token limit | Enable `EnableChunking` or increase `MaxTokens` if the library supports it |
| Unexpected language | Wrong `Language` option | Remove the option or set it to the document’s actual language |

Addressing these issues early saves debugging time, especially when you **choose AI provider** for production workloads.
