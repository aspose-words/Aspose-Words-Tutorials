# Create invoice template and merge data using Aspose.Words

If you need to **create invoice template** quickly, this guide shows you exactly how. By the end of the first two sentences you’ll know the complete workflow for turning a blank Word file into a fully populated invoice, using Aspose.Words’ low‑code mail‑merge API.

Generating invoices is a common requirement for billing systems, ERP integrations, and automated reporting. In this tutorial you will learn **how to mail merge**, **populate word template**, **merge data into word**, and finally **save merged document**—all with a handful of C# lines.

## What you’ll achieve

* A reusable Word template (`InvoiceTemplate.docx`) that contains merge fields for customer, date, line items, and total.  
* A C# program that loads the template, injects a strongly‑typed data object, and writes the result to `Invoice_001.docx`.  
* Insight into edge cases such as empty collections, custom data types, and file‑path handling.

### Prerequisites

| Requirement | Why it matters |
|-------------|----------------|
| .NET 6 or later | Aspose.Words for .NET supports .NET 6+ and provides the low‑code API used in this guide. |
| Aspose.Words for .NET NuGet package (`Aspose.Words`) | Supplies `Document`, `MailMerger`, and related types. |
| Basic C# knowledge | Needed to understand anonymous objects and LINQ. |
| Visual Studio 2022 (or any IDE) | Makes editing and debugging straightforward. |

> **Pro tip:** Install the NuGet package via the Package Manager Console:  
> `Install-Package Aspose.Words`

## How to create invoice template with low‑code mail merge

The first step is to build a Word file that contains merge fields matching the properties of the data object you will pass later. Save the file as `InvoiceTemplate.docx` in a folder you control (e.g., `C:\Invoices\Template`).

| Merge field | Example placeholder in Word |
|-------------|-----------------------------|
| CustomerName | «CustomerName» |
| InvoiceDate | «InvoiceDate» |
| Items (repeating) | «Items.Description», «Items.Qty», «Items.Price» |
| Total | «Total» |

> **Why this matters:** The low‑code API automatically maps the property names of the data source to the merge fields. Keeping names identical eliminates manual field‑to‑property mapping and reduces runtime errors.

## Step 1: Load the invoice template

```csharp
using Aspose.Words;
using Aspose.Words.LowCode;   // Low‑code mail‑merge API

// Load the Word file that contains the merge fields.
Document template = new Document(@"C:\Invoices\Template\InvoiceTemplate.docx");
```

*The `Document` class represents the entire Word file. Loading it once lets you reuse the same template for many invoices.*

## Step 2: Prepare the data source

Create an anonymous object that mirrors the merge fields. The low‑code API can work with any .NET object, including arrays and nested collections.

```csharp
var invoiceData = new
{
    CustomerName = "Acme Corp",
    InvoiceDate = DateTime.Today,
    Items = new[]
    {
        new { Description = "Widget A", Qty = 10, Price = 9.99M },
        new { Description = "Widget B", Qty = 5,  Price = 19.95M }
    },
    Total = 199.85M
};
```

**Why this works:**  
* The property names (`CustomerName`, `InvoiceDate`, `Items`, `Total`) match the merge fields in the template.  
* `Items` is an array of objects, so the mail merger will repeat the table row for each element automatically.  
* Using `decimal` (`M` suffix) for monetary values avoids floating‑point rounding issues.

### Handling empty collections

If an invoice has no line items, pass an empty array:

```csharp
Items = new object[0]
```

The low‑code engine will simply omit the repeating section, leaving the table header intact.

## Step 3: Initialise the low‑code mail merger

```csharp
MailMerger merger = new MailMerger(template);
```

`MailMerger` is the entry point for **how to mail merge** with Aspose.Words. It reads the template, binds the data, and prepares the final document in a single call.

## Step 4: Execute the merge – populate word template in one line

```csharp
Document mergedDocument = merger.Execute(invoiceData);
```

* This line **populates the word template** and produces a new `Document` instance (`mergedDocument`).  
* All merge fields are replaced, repeating sections are expanded, and the resulting document resides entirely in memory.

### Edge case: Custom formatting

If you need a specific date format, add a custom formatter before the merge:

```csharp
merger.Options.DateFormat = "MMMM dd, yyyy"; // e.g., "October 07, 2026"
```

## Step 5: Save merged document

```csharp
mergedDocument.Save(@"C:\Invoices\Output\Invoice_001.docx");
```

The call **save merged document** writes the fully populated invoice to disk. The file can now be opened in Microsoft Word, sent as an email attachment, or converted to PDF.

### Verifying the output

Open `Invoice_001.docx`. You should see:

* **CustomerName** replaced with *Acme Corp*  
* **InvoiceDate** showing today’s date in the chosen format  
* A table row for *Widget A* (10 × 9.99) and *Widget B* (5 × 19.95)  
* **Total** displaying *199.85*  

If any field remains unchanged (e.g., still shows «CustomerName»), double‑check that the property names exactly match the merge field names in the template.

## Full runnable example

Below is the complete program you can copy‑paste into a new console project.

```csharp
using System;
using Aspose.Words;
using Aspose.Words.LowCode;   // Low‑code mail‑merge API

namespace InvoiceGenerator
{
    class Program
    {
        static void Main()
        {
            // 1️⃣ Load the template
            Document template = new Document(@"C:\Invoices\Template\InvoiceTemplate.docx");

            // 2️⃣ Build the data source
            var invoiceData = new
            {
                CustomerName = "Acme Corp",
                InvoiceDate = DateTime.Today,
                Items = new[]
                {
                    new { Description = "Widget A", Qty = 10, Price = 9.99M },
                    new { Description = "Widget B", Qty = 5,  Price = 19.95M }
                },
                Total = 199.85M
            };

            // 3️⃣ Initialise the mail merger
            MailMerger merger = new MailMerger(template);

            // Optional: customise date format
            merger.Options.DateFormat = "MMMM dd, yyyy";

            // 4️⃣ Perform the merge (populate word template)
            Document mergedDocument = merger.Execute(invoiceData);

            // 5️⃣ Save the resulting file (save merged document)
            mergedDocument.Save(@"C:\Invoices\Output\Invoice_001.docx");

            Console.WriteLine("Invoice generated successfully.");
        }
    }
}
```

Run the program (`dotnet run`). The console prints *Invoice generated successfully.* and the file appears in `C:\Invoices\Output`.
