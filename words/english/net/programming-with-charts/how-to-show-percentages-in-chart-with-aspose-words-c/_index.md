# How to Show Percentages in Chart with Aspose.Words C#

Ever wondered **how to show percentages in chart** without wrestling with complex Office interop? You're not alone—many developers hit that wall when they need a quick, programmatic way to label a pie or doughnut chart. The good news? With Aspose.Words for .NET you can enable those data labels in just a handful of lines.

In this tutorial we’ll also cover **add data labels to pie chart** and **how to enable chart data labels** so your visualizations instantly become more insightful. By the end you’ll have a ready‑to‑use Word document (`.docx`) that displays a polished pie chart with percentages neatly positioned outside each slice.

## Prerequisites

Before we dive in, make sure you have:

- **Aspose.Words for .NET** (latest version, e.g., 24.9) installed via NuGet.
- A **ChartTemplate.docx** file that already contains a pie or doughnut chart.  
  *(If you don’t have one, create a simple Word document, insert a pie chart, and save it as `ChartTemplate.docx`.)*
- .NET 6.0 or later and any IDE you prefer (Visual Studio, Rider, VS Code).

No extra dependencies are required—Aspose.Words handles everything internally.

## How to Show Percentages in Chart – Step‑by‑Step

Below we break the process into six clear steps. Each step includes the exact C# code you can copy‑paste, plus a short explanation of **why** we do it.

### Step 1: Load the Source Document

```csharp
using Aspose.Words;
using Aspose.Words.Drawing.Charts;

// Load the .docx that already holds a chart.
Document sourceDoc = new Document("YOUR_DIRECTORY/ChartTemplate.docx");
```

*Why?*  
`Document` is the entry point for any Word manipulation. By loading the template we gain access to every node—shapes, tables, text, and of course the chart we’ll modify.

### Step 2: Grab the First Chart Shape

```csharp
// The chart lives inside a Shape node; retrieve it.
Chart chart = (Chart)sourceDoc.GetChild(NodeType.Shape, 0, true);
```

*Why?*  
Aspose stores charts as `Shape` objects. `GetChild` walks the document tree and returns the first shape it finds, which in our case is the pie chart we want to edit.

### Step 3: Confirm the Chart Type

```csharp
if (chart.ChartType == ChartType.Pie || chart.ChartType == ChartType.Doughnut)
{
    // Inside this block we’ll enable the data labels.
}
else
{
    throw new InvalidOperationException("The chart is not a Pie or Doughnut type.");
}
```

*Why?*  
Percentage labels only make sense for circular charts. This guard prevents us from accidentally applying settings to, say, a bar chart where `ShowPercentage` would be ignored.

### Step 4: Enable Data Labels and Show Percentages

```csharp
// Turn on data labels for the chart.
chart.HasDataLabel = true;

// Show the percentage value for each slice.
chart.DataLabel.ShowPercentage = true;
```

*Why?*  
`HasDataLabel` tells Aspose to render a label for each data point. Setting `ShowPercentage` ensures the label content is the calculated share of the whole—exactly what the **add data labels to pie chart** requirement asks for.

### Step 5: Position Labels Outside the Slices

```csharp
// Place the labels outside the pie slices for better readability.
chart.DataLabel.Position = ChartDataLabelPosition.OutSideEnd;
```

*Why?*  
Inside‑slice labels can become cramped, especially when slices are small. `OutSideEnd` mimics the default “outside” style you see in the Word UI, keeping the chart clean.

### Step 6: Save the Updated Document

```csharp
sourceDoc.Save("YOUR_DIRECTORY/FormattedPieChart.docx");
```

*Why?*  
Saving writes all the changes back to a new file. Open `FormattedPieChart.docx` in Word and you’ll see the percentages displayed next to each slice.

#### Expected Result

When you open `FormattedPieChart.docx`, the pie chart should look similar to this (imaginary screenshot):

```
[ Pie chart with three slices ]
- Slice A – 45%
- Slice B – 30%
- Slice C – 25%
```

All percentages are calculated automatically from the underlying data series, and the labels sit just outside each slice.

## Common Variations & Edge Cases

| Situation | What to Adjust |
|-----------|----------------|
| **Multiple charts** in the same document | Loop through `sourceDoc.GetChildNodes(NodeType.Shape, true)` and cast each to `Chart` before applying the same logic. |
| **Bar or line chart** where you still want labels | Use `chart.DataLabel.ShowValue = true;` (or `ShowSeriesName`) instead of `ShowPercentage`. |
| **Custom number format** (e.g., “45 %”) | Set `chart.DataLabel.NumberFormat = "0%";` before saving. |
| **Large data sets** causing label overlap | Consider `chart.DataLabel.ShowLeaderLines = true;` to draw connector lines. |

> **Pro tip:** If you’re generating many documents in a batch, instantiate a single `Aspose.Words.License` object at application start to avoid the performance hit of loading the license repeatedly.

## Full Working Example

Here’s the entire program put together, ready to run:

```csharp
using System;
using Aspose.Words;
using Aspose.Words.Drawing.Charts;

class Program
{
    static void Main()
    {
        // 1️⃣ Load the template document.
        Document sourceDoc = new Document("YOUR_DIRECTORY/ChartTemplate.docx");

        // 2️⃣ Retrieve the first chart shape.
        Chart chart = (Chart)sourceDoc.GetChild(NodeType.Shape, 0, true);

        // 3️⃣ Ensure we’re dealing with a Pie or Doughnut chart.
        if (chart.ChartType != ChartType.Pie && chart.ChartType != ChartType.Doughnut)
        {
            Console.WriteLine("The selected shape is not a Pie/Doughnut chart.");
            return;
        }

        // 4️⃣ Enable data labels and show percentages.
        chart.HasDataLabel = true;
        chart.DataLabel.ShowPercentage = true;

        // 5️⃣ Position the labels outside the slices.
        chart.DataLabel.Position = ChartDataLabelPosition.OutSideEnd;

        // 6️⃣ Save the modified document.
        sourceDoc.Save("YOUR_DIRECTORY/FormattedPieChart.docx");

        Console.WriteLine("Chart updated successfully – percentages now visible!");
    }
}
```

Copy the code, replace `YOUR_DIRECTORY` with the actual path on your machine, and run it. You’ll have a Word file with a fully‑labeled pie chart in seconds.
