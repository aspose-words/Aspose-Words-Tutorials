# Üres Word dokumentum létrehozása és ellipszis alakzat elrejtése C#-ban

Ha **üres Word dokumentumot** kell létrehoznod, majd elrejteni egy grafikus elemet, ez az útmutató pontosan megmutatja, hogyan teheted ezt C#-ban. Egy teljes, futtatható példát láthatsz, amely ellipszist szúr be, elhelyezi, rejtettként jelöli, és elmenti a fájlt – minde néhány kódsorban.

Az oktatóanyag mindent lefed a projekt beállításától a végső ellenőrzési lépésig. A végére képes leszel olyan Word fájlt generálni, ahol az ellipszis soha nem jelenik meg a képernyőn vagy nyomtatáskor, ami hasznos metaadatok, könyvjelzők vagy bármilyen láthatatlan jelölő tárolására.

## Előfeltételek

Mielőtt elkezdenéd, győződj meg róla, hogy rendelkezel:

* .NET 6.0 SDK vagy újabb telepítve  
* C# fejlesztői környezet (Visual Studio 2022, Rider vagy VS Code)  
* A **Aspose.Words for .NET** NuGet csomag (`Install-Package Aspose.Words`)  

Ezek az eszközök biztosítják a kódrészletben használt `Document` és `DocumentBuilder` osztályokat.

## 1. lépés: Üres Word dokumentum létrehozása

Az első művelet egy üres `Document` objektumot és egy `DocumentBuilder`‑t hoz létre, amely lehetővé teszi a tartalom hozzáadását.

```csharp
using Aspose.Words;
using Aspose.Words.Drawing;

// Step 1: Initialize an empty document and a builder
Document doc = new Document();
DocumentBuilder builder = new DocumentBuilder(doc);
```

A `Document` képviseli a teljes `.docx` csomagot, míg a `DocumentBuilder` egy folyékony API‑t kínál szöveg, alakzat és egyéb objektumok beszúrásához. Egy üres dokumentummal kezdve teljes irányítást kapsz minden hozzáadott elem felett.

## 2. lépés: Ellipszis beszúrása

Az ellipszis egy vektoros alakzat, amelyet jelölőként lehet használni. Az `InsertShape` metódus megköveteli az alakzat típusát és a szélesség/magasság pontokban megadott értékét.

```csharp
// Step 2: Insert an ellipse shape of the desired size (100 pt × 50 pt)
Shape ellipse = builder.InsertShape(ShapeType.Ellipse, 100, 50);
```

Az ellipszis az aktuális oldalon a kurzor helyén jelenik meg. Méreteit a numerikus argumentumok módosításával változtathatod.

## 3. lépés: Alakzat pozicionálása

Beszúrás után a `Left` és `Top` tulajdonságok beállításával bárhová mozgathatod az alakzatot az oldalon, ezek a pontok a lap margójához viszonyítva értendők.

```csharp
// Step 3: Position the shape on the page
ellipse.Left = 150; // distance from the left margin
ellipse.Top  = 100; // distance from the top margin
```

Ezek a koordináták az ellipszist nagyjából a standard A4 oldal felső‑középső részébe helyezik. Igazítsd az értékeket a saját elrendezési igényeidhez.

## 4. lépés: Alakzat elrejtése

Egy rejtett objektum nem jelenik meg a dokumentum megnyitásakor vagy nyomtatásakor. A `Hidden` jelző beállítása az alakzatot **rejtett objektumként** jelöli.

```csharp
// Step 4: Hide the shape so it never appears
ellipse.Hidden = true;
```

A Word figyelembe veszi a rejtett jelzőt mind a képernyőn, mind a nyomtatási kimeneten. Az alakzat továbbra is része marad a dokumentum szerkezetének, így később kóddal lekérdezhető vagy módosítható.

## 5. lépés: Dokumentum mentése

Végül írd a dokumentumot a lemezre. Válassz egy olyan mappát, amelyhez írási jogosultságod van.

```csharp
// Step 5: Save the document to a .docx file
doc.Save(@"C:\Temp\HiddenEllipse.docx");
```

A `HiddenEllipse.docx` fájl most egy üres oldalt tartalmaz egy rejtett ellipszis alakzattal.

## Az elrejtett ellipszis ellenőrzése

Nyisd meg a generált fájlt a Microsoft Wordben, és engedélyezd a **Show hidden text** (Rejtett szöveg megjelenítése) opciót (File → Options → Display). Látnod kell az ellipszis halvány körvonalát. Ha kikapcsolod az opciót, az alakzat teljesen eltűnik, ezzel megerősítve, hogy az `ellipse.Hidden = true` a várt módon működik.

## Gyakori variációk és szélhelyzetek

| Helyzet | Javasolt módosítás |
|-----------|------------------------|
| **Másik alakzat** | Cseréld le a `ShapeType.Ellipse`-t `ShapeType.Rectangle`, `ShapeType.Arrow` stb.-re. |
| **Több rejtett objektum** | Ismételd meg a 2‑4. lépéseket minden alakzatra; mindegyiknek saját `Hidden` jelzője lehet. |
| **Másik oldalméret** | Állítsd be a `doc.FirstSection.PageSetup.PageWidth` és `PageHeight` értékeket az alakzat beszúrása előtt. |
| **Feltételes láthatóság** | Használd a `Shape.Visible`-t a `Hidden`-del kombinálva, hogy futásidőben kóddal kapcsolhasd be vagy ki. |

**Pro tip:** Tárold az azonosító adatokat az alakzat `AlternativeText` tulajdonságában. Még rejtett állapotban is később lekérheted az alakzatot a `doc.GetChildNodes(NodeType.Shape, true)` segítségével, és szűrhetsz a szöveg alapján.

## Teljes forráskód

Az alábbiakban a teljes programot találod, amelyet másolhatsz, beilleszthetsz és futtathatsz.

```csharp
using System;
using Aspose.Words;
using Aspose.Words.Drawing;

namespace HiddenShapeDemo
{
    class Program
    {
        static void Main()
        {
            // Create a new blank document and a builder
            Document doc = new Document();
            DocumentBuilder builder = new DocumentBuilder(doc);

            // Insert an ellipse shape (100 pt × 50 pt)
            Shape ellipse = builder.InsertShape(ShapeType.Ellipse, 100, 50);

            // Position the shape on the page
            ellipse.Left = 150;
            ellipse.Top  = 100;

            // Hide the shape so it is invisible in the UI and on print
            ellipse.Hidden = true;

            // Optional: add a description for later retrieval
            ellipse.AlternativeText = "Hidden marker for internal processing";

            // Save the document
            string outputPath = @"C:\Temp\HiddenEllipse.docx";
            doc.Save(outputPath);

            Console.WriteLine($"Document saved to {outputPath}");
        }
    }
}
```

**Várt kimenet:** A konzol kiírja a mentési útvonalat, és a `HiddenEllipse.docx` fájl üres oldalként nyílik meg, látható grafika nélkül, hacsak a rejtett objektumok nincsenek megjelenítve.

## Következtetés

Most már tudod, hogyan **hozz létre üres Word dokumentumot** programozottan, **hogyan szúrj be ellipszist**, **hogyan pozicionáld az alakzatot**, és **hogyan rejtsd el az alakzatot**, hogy **rejtett objektumként** viselkedjen. Ez a technika ideális láthatatlan jelölők, egyedi metaadatok vagy helyőrzők beágyazására, amelyeket a downstream folyamatok olvashatnak anélkül, hogy befolyásolnák a dokumentum vizuális elrendezését.

### Következő lépések

* Fedezd fel a többi alakzat típust (`ShapeType.Arrow`, `ShapeType.TextBox`), hogy különböző jelölőket ágyazz be.  
* Kombináld a rejtett alakzatokat egyedi XML részekkel a gazdagabb metaadat-tárolásért.  
* Integráld ezt a kódot egy nagyobb automatizálási folyamatba, amely jelentéseket vagy szerződéseket generál.

Nyugodtan kísérletezz a koordinátákkal, méretekkel és a rejtett jelzővel, hogy a saját forgatókönyvednek megfelelően alakítsd őket. Boldog kódolást!
