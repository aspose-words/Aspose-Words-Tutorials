# Számlasablon létrehozása és adatok egyesítése az Aspose.Words segítségével

Ha gyorsan **számlasablont** kell létrehoznod, ez az útmutató pontosan megmutatja, hogyan. Az első két mondat végére már ismerni fogod a teljes munkafolyamatot, amely egy üres Word fájlt teljesen kitöltött számlává alakít át, az Aspose.Words alacsony‑kódú mail‑merge API-jának használatával.

Számlák generálása gyakori követelmény a számlázási rendszerek, ERP integrációk és automatizált jelentések számára. Ebben az útmutatóban megtanulod, hogyan **mail merge‑t** hajts végre, **kitöltsd ki a Word sablont**, **egyesítsd az adatokat a Word-be**, és végül **mentsd el az egyesített dokumentumot** – mindezt néhány C# sorral.

## Amit el fogsz érni

* Egy újrahasználható Word sablon (`InvoiceTemplate.docx`), amely tartalmazza az ügyfél, dátum, tételsorok és összeg merge mezőket.  
* Egy C# program, amely betölti a sablont, injektál egy erősen típusos adatobjektumot, és az eredményt a `Invoice_001.docx` fájlba írja.  
* Rálátás a szélhelyzetekre, például üres gyűjtemények, egyedi adat típusok és fájl‑útvonal kezelés.

### Előfeltételek

| Requirement | Why it matters |
|-------------|----------------|
| .NET 6 or later | Az Aspose.Words for .NET támogatja a .NET 6+ verziókat, és biztosítja az ebben az útmutatóban használt alacsony‑kódú API-t. |
| Aspose.Words for .NET NuGet package (`Aspose.Words`) | Biztosítja a `Document`, `MailMerger` és a kapcsolódó típusokat. |
| Basic C# knowledge | Szükséges az anonim objektumok és a LINQ megértéséhez. |
| Visual Studio 2022 (or any IDE) | Megkönnyíti a szerkesztést és a hibakeresést. |

> **Pro tipp:** Telepítsd a NuGet csomagot a Package Manager Console‑on keresztül:  
> `Install-Package Aspose.Words`

## Hogyan hozz létre számlasablont alacsony‑kódú mail merge‑vel

Az első lépés egy Word fájl létrehozása, amely tartalmazza a merge mezőket, amelyek megegyeznek a később átadott adatobjektum tulajdonságaival. Mentsd a fájlt `InvoiceTemplate.docx` néven egy általad irányított mappába (pl. `C:\Invoices\Template`).

| Merge mező | Példa helyőrző a Wordben |
|-------------|-----------------------------|
| CustomerName | «CustomerName» |
| InvoiceDate | «InvoiceDate» |
| Items (repeating) | «Items.Description», «Items.Qty», «Items.Price» |
| Total | «Total» |

> **Miért fontos:** Az alacsony‑kódú API automatikusan leképezi az adatforrás tulajdonságneveit a merge mezőkre. Az azonos nevek használata kiküszöböli a manuális mező‑tulajdonság leképezést és csökkenti a futásidejű hibákat.

## 1. lépés: Számlasablon betöltése

```csharp
using Aspose.Words;
using Aspose.Words.LowCode;   // Low‑code mail‑merge API

// Load the Word file that contains the merge fields.
Document template = new Document(@"C:\Invoices\Template\InvoiceTemplate.docx");
```

*A `Document` osztály a teljes Word fájlt képviseli. Egyszeri betöltése lehetővé teszi, hogy ugyanazt a sablont sok számlához újrahasználd.*

## 2. lépés: Adatforrás előkészítése

Hozz létre egy anonim objektumot, amely tükrözi a merge mezőket. Az alacsony‑kódú API bármely .NET objektummal tud dolgozni, beleértve a tömböket és a beágyazott gyűjteményeket.

```csharp
var invoiceData = new
{
    CustomerName = "Acme Corp",
    InvoiceDate = DateTime.Today,
    Items = new[]
    {
        new { Description = "Widget A", Qty = 10, Price = 9.99M },
        new { Description = "Widget B", Qty = 5,  Price = 19.95M }
    },
    Total = 199.85M
};
```

**Miért működik:**  
* A tulajdonságnevek (`CustomerName`, `InvoiceDate`, `Items`, `Total`) megegyeznek a sablonban lévő merge mezőkkel.  
* Az `Items` egy objektumok tömbje, így a mail merger automatikusan megismétli a táblasort minden elemhez.  
* A `decimal` (`M` utótag) használata a pénzügyi értékekhez elkerüli a lebegőpontos kerekítési problémákat.

### Üres gyűjtemények kezelése

Ha egy számlának nincsenek tételsorai, adj át egy üres tömböt:

```csharp
Items = new object[0]
```

Az alacsony‑kódú motor egyszerűen kihagyja az ismétlődő részt, a táblázat fejlécét érintetlenül hagyva.

## 3. lépés: Az alacsony‑kódú mail merger inicializálása

```csharp
MailMerger merger = new MailMerger(template);
```

`MailMerger` az a belépési pont, amely **mail merge‑t** tesz lehetővé az Aspose.Words használatával. Beolvassa a sablont, összekapcsolja az adatokat, és egyetlen hívással előkészíti a végső dokumentumot.

## 4. lépés: Az egyesítés végrehajtása – a Word sablon kitöltése egy sorban

```csharp
Document mergedDocument = merger.Execute(invoiceData);
```

* Ez a sor **kitölti a Word sablont** és egy új `Document` példányt (`mergedDocument`) hoz létre.  
* Minden merge mező helyettesítésre kerül, az ismétlődő részek kibővülnek, és a keletkezett dokumentum teljes egészében a memóriában marad.

### Szélhelyzet: Egyedi formázás

Ha egy adott dátumformátumra van szükséged, adj hozzá egy egyedi formázót az egyesítés előtt:

```csharp
merger.Options.DateFormat = "MMMM dd, yyyy"; // e.g., "October 07, 2026"
```

## 5. lépés: Egyesített dokumentum mentése

```csharp
mergedDocument.Save(@"C:\Invoices\Output\Invoice_001.docx");
```

A **save merged document** hívás a teljesen kitöltött számlát a lemezre írja. A fájl most már megnyitható a Microsoft Wordben, elküldhető e‑mail mellékletként, vagy PDF‑re konvertálható.

### A kimenet ellenőrzése

Nyisd meg a `Invoice_001.docx` fájlt. A következőket kell látnod:

* **CustomerName** helyettesítve *Acme Corp*-val  
* **InvoiceDate** a kiválasztott formátumban mutatja a mai dátumot  
* Egy táblasor *Widget A* (10 × 9.99) és *Widget B* (5 × 19.95) számára  
* **Total** értéke *199.85*  

Ha bármely mező változatlan marad (pl. még mindig «CustomerName»), ellenőrizd, hogy a tulajdonságnevek pontosan megegyeznek-e a sablonban lévő merge mezőnevekkel.

## Teljes futtatható példa

Az alábbiakban a teljes program látható, amelyet bemásolhatsz egy új konzolprojektbe.

```csharp
using System;
using Aspose.Words;
using Aspose.Words.LowCode;   // Low‑code mail‑merge API

namespace InvoiceGenerator
{
    class Program
    {
        static void Main()
        {
            // 1️⃣ Load the template
            Document template = new Document(@"C:\Invoices\Template\InvoiceTemplate.docx");

            // 2️⃣ Build the data source
            var invoiceData = new
            {
                CustomerName = "Acme Corp",
                InvoiceDate = DateTime.Today,
                Items = new[]
                {
                    new { Description = "Widget A", Qty = 10, Price = 9.99M },
                    new { Description = "Widget B", Qty = 5,  Price = 19.95M }
                },
                Total = 199.85M
            };

            // 3️⃣ Initialise the mail merger
            MailMerger merger = new MailMerger(template);

            // Optional: customise date format
            merger.Options.DateFormat = "MMMM dd, yyyy";

            // 4️⃣ Perform the merge (populate word template)
            Document mergedDocument = merger.Execute(invoiceData);

            // 5️⃣ Save the resulting file (save merged document)
            mergedDocument.Save(@"C:\Invoices\Output\Invoice_001.docx");

            Console.WriteLine("Invoice generated successfully.");
        }
    }
}
```

Futtasd a programot (`dotnet run`). A konzol kiírja, hogy *Invoice generated successfully.*, és a fájl megjelenik a `C:\Invoices\Output` mappában.
