# Hogyan jelenítsünk meg százalékokat diagramon az Aspose.Words C#‑val

Gondoltad már, **hogyan jelenítsünk meg százalékokat diagramon** anélkül, hogy bonyolult Office interop‑dal küzdenél? Nem vagy egyedül – sok fejlesztő ütközik ebbe a helyzetbe, amikor gyors, programozott módon kell feliratozni egy kör- vagy gyűrűdiagramot. A jó hír? Az Aspose.Words for .NET‑tel néhány sor kóddal engedélyezheted ezeket a adatcímkéket.

Ebben az útmutatóban azt is bemutatjuk, **hogyan adjunk adatcímkéket kördiagramhoz** és **hogyan engedélyezzük a diagram adatcímkéit**, hogy a vizualizációid azonnal informatívabbak legyenek. A végére egy használatra kész Word‑dokumentumot (`.docx`) kapsz, amely egy letisztult kördiagramot mutat százalékokkal, szép módon elhelyezve minden szelet mellett.

## Előfeltételek

Mielőtt belevágnánk, győződj meg róla, hogy rendelkezel a következőkkel:

- **Aspose.Words for .NET** (legújabb verzió, pl. 24.9) telepítve NuGet‑en keresztül.
- Egy **ChartTemplate.docx** fájl, amely már tartalmaz egy kör‑ vagy gyűrűdiagramot.  
  *(Ha nincs ilyen, hozz létre egy egyszerű Word‑dokumentumot, illessz be egy kördiagramot, és mentsd el `ChartTemplate.docx`‑ként.)*
- .NET 6.0 vagy újabb, valamint a kedvenc IDE‑d (Visual Studio, Rider, VS Code).

További függőségek nem szükségesek – az Aspose.Words mindent belsőleg kezel.

## Hogyan jelenítsünk meg százalékokat diagramon – Lépés‑ről‑lépésre

Az alábbiakban a folyamatot hat egyértelmű lépésre bontjuk. Minden lépéshez pontos C#‑kódot adunk, amelyet egyszerűen másolhatsz‑beilleszthetsz, valamint egy rövid magyarázatot, **miért** szükséges az adott lépés.

### 1. lépés: A forrásdokumentum betöltése

```csharp
using Aspose.Words;
using Aspose.Words.Drawing.Charts;

// Load the .docx that already holds a chart.
Document sourceDoc = new Document("YOUR_DIRECTORY/ChartTemplate.docx");
```

*Miért?*  
A `Document` a belépési pont minden Word‑manipulációhoz. A sablon betöltésével hozzáférünk minden csomóponthoz – alakzatokhoz, táblázatokhoz, szöveghez és természetesen a módosítani kívánt diagramhoz.

### 2. lépés: Az első diagram‑alakzat lekérése

```csharp
// The chart lives inside a Shape node; retrieve it.
Chart chart = (Chart)sourceDoc.GetChild(NodeType.Shape, 0, true);
```

*Miért?*  
Az Aspose a diagramokat `Shape` objektumként tárolja. A `GetChild` bejárja a dokumentumfát, és visszaadja az első megtalált alakzatot, amely ebben az esetben a szerkeszteni kívánt kördiagram.

### 3. lépés: A diagram típusának ellenőrzése

```csharp
if (chart.ChartType == ChartType.Pie || chart.ChartType == ChartType.Doughnut)
{
    // Inside this block we’ll enable the data labels.
}
else
{
    throw new InvalidOperationException("The chart is not a Pie or Doughnut type.");
}
```

*Miért?*  
A százalékcímkék csak kördiagramok esetén értelmesek. Ez a védelem megakadályozza, hogy véletlenül például egy oszlopdiagramra alkalmazzuk a beállítást, ahol a `ShowPercentage` figyelmen kívül maradna.

### 4. lépés: Adatcímkék engedélyezése és a százalékok megjelenítése

```csharp
// Turn on data labels for the chart.
chart.HasDataLabel = true;

// Show the percentage value for each slice.
chart.DataLabel.ShowPercentage = true;
```

*Miért?*  
A `HasDataLabel` azt mondja az Aspose‑nak, hogy minden adatponthoz jelenítsen meg egy címkét. A `ShowPercentage` beállítása biztosítja, hogy a címke tartalma a teljeshez viszonyított arány legyen – pontosan az, amit a **add data labels to pie chart** követelmény megkíván.

### 5. lépés: Címkék elhelyezése a szeletek kívül

```csharp
// Place the labels outside the pie slices for better readability.
chart.DataLabel.Position = ChartDataLabelPosition.OutSideEnd;
```

*Miért?*  
A szeletek belsejében lévő címkék zsúfoltak lehetnek, különösen kis szeleteknél. Az `OutSideEnd` a Word UI‑ban látható alapértelmezett „kívül” stílust utánozza, így a diagram tiszta marad.

### 6. lépés: A módosított dokumentum mentése

```csharp
sourceDoc.Save("YOUR_DIRECTORY/FormattedPieChart.docx");
```

*Miért?*  
A mentés visszaírja a változtatásokat egy új fájlba. Nyisd meg a `FormattedPieChart.docx`‑et Word‑ben, és láthatod a százalékok megjelenését minden szelet mellett.

#### Várt eredmény

Amikor megnyitod a `FormattedPieChart.docx`‑et, a kördiagramnak hasonlónak kell lennie az alábbi (képzeletbeli) képernyőképre:

```
[ Pie chart with three slices ]
- Slice A – 45%
- Slice B – 30%
- Slice C – 25%
```

Minden százalékot az alapul szolgáló adatcsalád automatikusan számol, a címkék pedig közvetlenül a szeletek kívül helyezkednek el.

## Gyakori variációk és szélhelyzetek

| Helyzet | Mit kell módosítani |
|-----------|----------------|
| **Több diagram** ugyanabban a dokumentumban | Iterálj a `sourceDoc.GetChildNodes(NodeType.Shape, true)`‑en, és minden elemet castolj `Chart`‑re, mielőtt ugyanazt a logikát alkalmaznád. |
| **Oszlop- vagy vonaldiagram**, ahol mégis szeretnél címkéket | Használd a `chart.DataLabel.ShowValue = true;`‑t (vagy `ShowSeriesName`‑t) a `ShowPercentage` helyett. |
| **Egyedi számformátum** (pl. “45 %”) | Állítsd be a `chart.DataLabel.NumberFormat = "0%";`‑t a mentés előtt. |
| **Nagy adathalmaz**, amely címke‑átfedést okoz | Fontold meg a `chart.DataLabel.ShowLeaderLines = true;` használatát, hogy csatlakozó vonalak jelenjenek meg. |

> **Pro tip:** Ha sok dokumentumot generálsz kötegelt módon, hozz létre egyetlen `Aspose.Words.License` objektumot az alkalmazás indításakor, hogy elkerüld a licenc többszöri betöltésének teljesítménybeli hátrányát.

## Teljes működő példa

Az alábbiakban a teljes program látható, készen áll a futtatásra:

```csharp
using System;
using Aspose.Words;
using Aspose.Words.Drawing.Charts;

class Program
{
    static void Main()
    {
        // 1️⃣ Load the template document.
        Document sourceDoc = new Document("YOUR_DIRECTORY/ChartTemplate.docx");

        // 2️⃣ Retrieve the first chart shape.
        Chart chart = (Chart)sourceDoc.GetChild(NodeType.Shape, 0, true);

        // 3️⃣ Ensure we’re dealing with a Pie or Doughnut chart.
        if (chart.ChartType != ChartType.Pie && chart.ChartType != ChartType.Doughnut)
        {
            Console.WriteLine("The selected shape is not a Pie/Doughnut chart.");
            return;
        }

        // 4️⃣ Enable data labels and show percentages.
        chart.HasDataLabel = true;
        chart.DataLabel.ShowPercentage = true;

        // 5️⃣ Position the labels outside the slices.
        chart.DataLabel.Position = ChartDataLabelPosition.OutSideEnd;

        // 6️⃣ Save the modified document.
        sourceDoc.Save("YOUR_DIRECTORY/FormattedPieChart.docx");

        Console.WriteLine("Chart updated successfully – percentages now visible!");
    }
}
```

Másold be a kódot, cseréld le a `YOUR_DIRECTORY`‑t a géped tényleges elérési útjára, és futtasd. Néhány másodperc alatt egy Word‑fájlban lesz egy teljesen feliratozott kördiagram.

1. A sablon betöltése.  
2. A diagram alakzatának lekérése.  
3. A típus ellenőrzése (kör/gyűrű).  
4. **Add data labels to pie chart** és a százalékok engedélyezése.  
5. A címkék elhelyezése kívülre.  
6. Az eredmény mentése.

Ezzel a tudással most már automatizálhatod bármely jelentéskészítési szituációt, amely egyértelmű, százalék‑alapú vizualizációt igényel.

## Mi a következő lépés?

- **Címkék stílusának testreszabása** – változtasd a betűtípust, színt, vagy adj hozzá háttérszínt a `chart.DataLabel.Font`‑szal.  
- **Diagramok létrehozása a semmiből** – fedezd fel a `Chart chart = (Chart)sourceDoc.FirstSection.Body.AppendChild(new Shape(sourceDoc, ShapeType.Chart));` használatát, hogy programozottan generálj diagramokat.  
- **Több diagram kombinálása** egyetlen dokumentumban dashboard‑okhoz, majd exportálás PDF‑be a `sourceDoc.Save("Dashboard.pdf", SaveFormat.Pdf);`‑vel.

Kísérletezz nyugodtan, és ha bármilyen furcsaságra bukkansz, írj egy megjegyzést. Boldog diagramkészítést!
