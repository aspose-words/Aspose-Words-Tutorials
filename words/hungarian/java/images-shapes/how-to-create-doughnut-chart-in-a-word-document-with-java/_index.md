# Hogyan készítsünk doughnut chart-ot Word dokumentumban Java-val

Ha **create doughnut chart**-ra van szükséged egy Word fájlban, ez a tutorial egy teljes, azonnal futtatható megoldást mutat be. Meg fogod látni, hogyan **insert pie chart**, hogyan alakítható fánkká, hogyan **rotate pie chart** a jobb egyensúlyért, és hogyan **format pie chart** a márkádhoz igazítva. A végére egy professzionális Word dokumentumod lesz, amely jelentésekben, irányítópultokban vagy automatizált e‑mail mellékletekben használható.

A diagram programozott létrehozása kiküszöböli a manuális másolás‑beillesztés lépéseit, és biztosítja a konzisztens stílusokat tucatnyi generált dokumentumban. A példa az Aspose.Words for Java könyvtárat használja, amely Java 8+ verzióval működik, és nem igényel Microsoft Office telepítést. Egyéb előfeltételek nincsenek a szabványos JDK és a kedvenc IDE mellett.

## Előkövetelmények

- Java Development Kit (JDK) 8 vagy újabb  
- Maven vagy Gradle a függőségkezeléshez (a tutorial Maven-t használ)  
- Aspose.Words for Java könyvtár (az ingyenes próbalicenc elegendő a teszteléshez)  

Add the Aspose.Words dependency to your `pom.xml`:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-words</artifactId>
    <version>24.9</version> <!-- Use the latest stable version -->
</dependency>
```

> **Pro tipp:** Regisztráld a licencet a `License license = new License(); license.setLicense("Aspose.Words.lic");` kóddal a dokumentum létrehozása előtt, hogy eltávolítsd a kiértékelési vízjelet.

## Doughnut chart létrehozása Word dokumentumban

A fő munkafolyamat öt logikai lépésből áll. Minden lépést saját metódusba csomagolunk, hogy a kód tiszta és újrahasználható legyen.

```java
import com.aspose.words.*;
import com.aspose.words.drawing.*;

public class DoughnutChartDemo {

    public static void main(String[] args) throws Exception {
        // Step 1: create blank Word document
        Document doc = createBlankWordDocument();

        // Step 2: insert a pie chart (base for the doughnut)
        Chart chart = insertPieChart(doc, 400, 300);

        // Step 3: convert the pie chart into a doughnut and rotate it
        customizeChartAppearance(chart);

        // Step 4: apply additional formatting to the chart
        formatPieChart(chart);

        // Step 5: save the final document
        doc.save("output/DoughnutChartFormatted.docx");
        System.out.println("Document saved successfully.");
    }

    /** Step 1 – create blank Word document */
    private static Document createBlankWordDocument() {
        // Aspose.Words creates an empty document by default
        return new Document();
    }

    /** Step 2 – insert pie chart with given dimensions */
    private static Chart insertPieChart(Document doc, int width, int height) throws Exception {
        DocumentBuilder builder = new DocumentBuilder(doc);
        // ChartType.PIE creates a standard pie chart that we will later turn into a doughnut
        Chart chart = builder.insertChart(ChartType.PIE, width, height);
        // Populate the chart with sample data
        chart.getSeries().clear(); // Remove default series
        ChartSeries series = chart.getSeries().add("Sales", new String[]{"Q1", "Q2", "Q3", "Q4"},
                new double[]{15000, 23000, 18000, 27000});
        return chart;
    }

    /** Step 3 – rotate pie chart and make it a doughnut */
    private static void customizeChartAppearance(Chart chart) {
        // Explode the first slice for emphasis
        chart.getSeries().get(0).setExplode(20);
        // Convert the pie into a doughnut by setting a hole size (percentage of radius)
        chart.setHoleSize(30); // 30% hole creates a classic doughnut look
        // Rotate the chart so the largest slice starts at 45°
        chart.setRotationAngle(45);
    }

    /** Step 4 – additional formatting of the pie chart */
    private static void formatPieChart(Chart chart) {
        // Example: change the first slice color to a brand color
        chart.getSeries().get(0).getPoints().get(0).getFormat().setFillForegroundColor(Color.fromArgb(0xFF, 0x4A, 0x90));
        // Add a legend and position it at the bottom
        chart.setHasLegend(true);
        chart.getLegend().setPosition(LegendPosition.BOTTOM);
        // Set a title for the chart
        chart.setTitle("Quarterly Sales Distribution");
    }
}
```

### Mit csinál a kód

| Lépés | Művelet | Indok |
|------|--------|--------|
| **Create blank Word document** | `new Document()` | Egy tiszta fájllal kezd, így minden elemet te irányíthatsz. |
| **Insert pie chart** | `builder.insertChart(ChartType.PIE, …)` | A pie chart a kiinduló alak; az Aspose csak a lyuk méretének módosításával biztosít doughnut-ot. |
| **Rotate pie chart** | `chart.setRotationAngle(45)` | A forgatás a legnagyobb szeletet olvashatóbb pozícióba helyezi. |
| **Format pie chart** | `setExplode`, `setHoleSize`, szín, legend | Javítja a vizuális hierarchiát és megfelel a vállalati stílusirányelveknek. |
| **Save document** | `doc.save("…/DoughnutChartFormatted.docx")` | Kiírja a végleges .docx fájlt a lemezre, készen a terjesztésre. |

## Pie chart beszúrása a fánkká alakítás előtt

Az Aspose.Words nem biztosít közvetlen “insert doughnut chart” metódust. Ehelyett **insert pie chart**-ot használsz, majd módosítod a tulajdonságait. Ez a kétlépéses megközelítés teljes kontrollt ad az adat sorok, szelet robbantás és lyuk mérete felett. Ha máshol tiszta pie chart-ra van szükséged, egyszerűen hagyd ki a `setHoleSize` hívást.

## Pie chart forgatása a vizuális egyensúlyért

Az alapértelmezett orientáció a első szeletet a 12 óra pozícióban kezdi. Sok üzleti jelentésben a legfontosabb szeletnek természetesebb szögben kell indulnia, például 45 fokban. A `setRotationAngle(double angle)` metódus fokban várja az értéket, és a teljes diagramot forgatja anélkül, hogy az adatértékek változnának.

## Pie chart formázása és megjelenés testreszabása

A fánkká alakítás mellett gyakran szeretnéd **format pie chart** elemeit:

- **Explode** az első szeletet (`setExplode`), hogy felhívja a figyelmet.  
- **Color** minden szeletet a `getPoints().get(i).getFormat().setFillForegroundColor` használatával.  
- **Legend** pozicionálás (`setHasLegend`, `setPosition`) segíti az olvasót a kategóriák értelmezésében.  
- **Title** (`setTitle`) egy pillantásra ad kontextust.  

Mindezek a beállítások opcionálisak; a márka palettádhoz vagy vállalati sablonjaidhoz igazíthatod őket.

## Üres Word dokumentum létrehozása és az eredmény mentése

A `createBlankWordDocument` metódus magába foglalja a **create blank word document** lépést. Ennek a logikának az elkülönítése megkönnyíti a metódus újrafelhasználását, ha több jelentést generálsz egy kötegelt folyamatban. Az összes testreszabás után a `doc.save` a szabványos Office Open XML formátumban (`.docx`) írja a fájlt, amely megnyitható Microsoft Word, LibreOffice vagy Google Docs segítségével adatvesztés nélkül.

### Várható kimenet

Document saved successfully.

És a `output/DoughnutChartFormatted.docx` fájl egyetlen oldalt tartalmaz egy *Quarterly Sales Distribution* címmel ellátott doughnut chart-tal. A diagram négy szeletet mutat, az első szelet robbant, a vállalati színben színezett, és 45 fokban el van forgatva.

## Gyakori variációk és szélhelyzetek

| Helyzet | Módosítás |
|-----------|------------|
| **Több adat sor** | Adj hozzá további `ChartSeries` objektumokat a `chart.getSeries()`-hez. |
| **Eltérő diagramméret** | Módosítsd a `width` és `height` argumentumokat az `insertPieChart` hívásban. |
| **Nincs lyuk (tiszta pie)** | Hagyd ki a `chart.setHoleSize(…)` hívást vagy állítsd 0-ra. |
| **Nagy dokumentumok** | Használd a `DocumentBuilder`-t a diagram egy adott szakaszba vagy könyvjelzőbe való beszúrásához. |
| **Licenc nincs beállítva** | A könyvtár kiértékelési módban fut, és vízjelet helyez az első oldalra. Regisztrálj licencet a vízjel eltávolításához. |

## Következtetés

Most már tudod, hogyan **create doughnut chart**-ot készíts Word dokumentumban Java-val, a **create blank word document** lépéstől a **insert pie chart**, **rotate pie chart** és **format pie chart** lépéseken át egy kifinomult végtermékig. A teljes, futtatható példát bármely Java projektbe beillesztheted, amely már használja az Aspose.Words‑t.

Ezután érdemes lehet:

- Adatcímkék hozzáadása (`chart.getSeries().get(0).setDataLabelType(DataLabelType.CATEGORY_AND_PERCENT);`)

Nyugodtan kísérletezz színekkel, szelet robbantásokkal és legendákkal, hogy a szervezeted vizuális nyelvéhez illeszkedjen. Boldog diagramkészítést!
