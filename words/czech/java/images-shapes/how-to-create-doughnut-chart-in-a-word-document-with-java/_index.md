# Jak vytvořit donutový graf ve Word dokumentu pomocí Javy

Pokud potřebujete **vytvořit donutový graf** uvnitř souboru Word, tento tutoriál vám ukáže kompletní, připravené řešení. Uvidíte, jak **vložit koláčový graf**, převést jej na donut, **otočit koláčový graf** pro lepší vyvážení a **naformátovat koláčový graf** tak, aby odpovídal vaší značce. Na konci budete mít profesionální Word dokument, který lze použít v reportech, dashboardech nebo automatizovaných e‑mailových přílohách.

Programatické vytvoření grafu eliminuje ruční kroky kopírování‑vkládání a zaručuje konzistentní styl napříč desítkami generovaných dokumentů. Příklad používá knihovnu Aspose.Words for Java, která funguje s Java 8+ a nevyžaduje instalaci Microsoft Office. Žádné další předpoklady nejsou potřeba kromě standardního JDK a vašeho oblíbeného IDE.

## Požadavky

- Java Development Kit (JDK) 8 nebo novější  
- Maven nebo Gradle pro správu závislostí (tutoriál používá Maven)  
- Aspose.Words for Java knihovna (pro testování stačí bezplatná zkušební licence)  

Add the Aspose.Words dependency to your `pom.xml`:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-words</artifactId>
    <version>24.9</version> <!-- Use the latest stable version -->
</dependency>
```

> **Tip:** Zaregistrujte svou licenci pomocí `License license = new License(); license.setLicense("Aspose.Words.lic");` před vytvořením jakéhokoli dokumentu, abyste odstranili vodotisk hodnocení.

## Vytvoření donutového grafu ve Word dokumentu

Základní pracovní postup se skládá z pěti logických kroků. Každý krok je zabalen do vlastní metody, aby byl kód čistý a znovupoužitelný.

```java
import com.aspose.words.*;
import com.aspose.words.drawing.*;

public class DoughnutChartDemo {

    public static void main(String[] args) throws Exception {
        // Step 1: create blank Word document
        Document doc = createBlankWordDocument();

        // Step 2: insert a pie chart (base for the doughnut)
        Chart chart = insertPieChart(doc, 400, 300);

        // Step 3: convert the pie chart into a doughnut and rotate it
        customizeChartAppearance(chart);

        // Step 4: apply additional formatting to the chart
        formatPieChart(chart);

        // Step 5: save the final document
        doc.save("output/DoughnutChartFormatted.docx");
        System.out.println("Document saved successfully.");
    }

    /** Step 1 – create blank Word document */
    private static Document createBlankWordDocument() {
        // Aspose.Words creates an empty document by default
        return new Document();
    }

    /** Step 2 – insert pie chart with given dimensions */
    private static Chart insertPieChart(Document doc, int width, int height) throws Exception {
        DocumentBuilder builder = new DocumentBuilder(doc);
        // ChartType.PIE creates a standard pie chart that we will later turn into a doughnut
        Chart chart = builder.insertChart(ChartType.PIE, width, height);
        // Populate the chart with sample data
        chart.getSeries().clear(); // Remove default series
        ChartSeries series = chart.getSeries().add("Sales", new String[]{"Q1", "Q2", "Q3", "Q4"},
                new double[]{15000, 23000, 18000, 27000});
        return chart;
    }

    /** Step 3 – rotate pie chart and make it a doughnut */
    private static void customizeChartAppearance(Chart chart) {
        // Explode the first slice for emphasis
        chart.getSeries().get(0).setExplode(20);
        // Convert the pie into a doughnut by setting a hole size (percentage of radius)
        chart.setHoleSize(30); // 30% hole creates a classic doughnut look
        // Rotate the chart so the largest slice starts at 45°
        chart.setRotationAngle(45);
    }

    /** Step 4 – additional formatting of the pie chart */
    private static void formatPieChart(Chart chart) {
        // Example: change the first slice color to a brand color
        chart.getSeries().get(0).getPoints().get(0).getFormat().setFillForegroundColor(Color.fromArgb(0xFF, 0x4A, 0x90));
        // Add a legend and position it at the bottom
        chart.setHasLegend(true);
        chart.getLegend().setPosition(LegendPosition.BOTTOM);
        // Set a title for the chart
        chart.setTitle("Quarterly Sales Distribution");
    }
}
```

### Co kód dělá

| Krok | Akce | Důvod |
|------|--------|--------|
| **Vytvořit prázdný Word dokument** | `new Document()` | Začíná čistým souborem, takže máte kontrolu nad každým prvkem. |
| **Vložit koláčový graf** | `builder.insertChart(ChartType.PIE, …)` | Koláčový graf je základní tvar; Aspose poskytuje donut pouze úpravou velikosti díry. |
| **Otočit koláčový graf** | `chart.setRotationAngle(45)` | Otočení zarovná největší výseč do čitelnější pozice. |
| **Naformátovat koláčový graf** | `setExplode`, `setHoleSize`, color, legend | Zlepšuje vizuální hierarchii a odpovídá firemním stylovým směrnicím. |
| **Uložit dokument** | `doc.save("…/DoughnutChartFormatted.docx")` | Zapíše finální soubor .docx na disk, připravený k distribuci. |

## Vložení koláčového grafu před převodem na donut

Aspose.Words neposkytuje přímou metodu „vložit donutový graf“. Místo toho **vložíte koláčový graf** a následně upravíte jeho vlastnosti. Tento dvoukrokový přístup vám dává plnou kontrolu nad datovými řadami, výbuchem výsečů a velikostí díry. Pokud jinde potřebujete čistý koláčový graf, jednoduše vynechte volání `setHoleSize`.

## Otočení koláčového grafu pro vizuální rovnováhu

Výchozí orientace začíná první výseč na pozici 12 hodin. V mnoha obchodních reportech by nejdůležitější výseč měla začínat na přirozenějším úhlu, například 45 stupňů. Metoda `setRotationAngle(double angle)` přijímá úhly ve stupních a otáčí celý graf, aniž by ovlivnila datové hodnoty.

## Formátování koláčového grafu a přizpůsobení vzhledu

Kromě převodu na donut často chcete **naformátovat koláčový graf** prvky:

- **Explodovat** první výseč (`setExplode`) pro upoutání pozornosti.  
- **Barva** každé výseče pomocí `getPoints().get(i).getFormat().setFillForegroundColor`.  
- **Umístění legendy** (`setHasLegend`, `setPosition`) pomáhá čtenářům interpretovat kategorie.  
- **Název** (`setTitle`) poskytuje kontext na první pohled.  

Všechna tato nastavení jsou volitelná; můžete je přizpůsobit tak, aby odpovídala vaší firemní paletě nebo šablonám.

## Vytvoření prázdného Word dokumentu a uložení výsledku

`createBlankWordDocument` metoda zapouzdřuje krok **vytvořit prázdný word dokument**. Udržení této logiky izolované usnadňuje opětovné použití metody při generování více reportů v dávkovém procesu. Po všech úpravách `doc.save` zapíše soubor ve standardním formátu Office Open XML (`.docx`), který lze otevřít v Microsoft Word, LibreOffice nebo Google Docs bez ztráty kvality.

### Očekávaný výstup

Když spustíte metodu `main`, konzole vypíše:

```
Document saved successfully.
```

A soubor `output/DoughnutChartFormatted.docx` obsahuje jednu stránku s donutovým grafem nazvaným *Quarterly Sales Distribution*. Graf zobrazuje čtyři výseče, první výseč je explodována, obarvena firemní barvou a otočena o 45 stupňů.

## Běžné varianty a okrajové případy

| Situace | Úprava |
|-----------|------------|
| **Více než jedna datová řada** | Přidejte další objekty `ChartSeries` do `chart.getSeries()`. |
| **Různá velikost grafu** | Změňte argumenty `width` a `height` v `insertPieChart`. |
| **Žádná díra (čistý koláč)** | Vynechte `chart.setHoleSize(…)` nebo nastavte na `0`. |
| **Velké dokumenty** | Použijte `DocumentBuilder` k vložení grafu do konkrétní sekce nebo záložky. |
| **Licence není nastavena** | Knihovna běží v evaluačním režimu, přidává vodotisk na první stránku. Zaregistrujte licenci, aby se odstranil. |

Kompletní, spustitelný příklad můžete vložit do libovolného Java projektu, který již používá Aspose.Words.
