# Jak převést docx na markdown s obrázky v podsložce

Pokud potřebujete **convert docx to markdown** a zároveň udržet každý vložený obrázek přehledně uspořádaný, jste na správném místě. Mnoho vývojářů generuje zprávy, manuály nebo návrhy blogů programově a skončí s chaotickým mixem souborů obrázků rozptýlených po výstupním adresáři. Tento tutoriál vám ukazuje čistý, callback‑driven přístup pomocí Aspose.Words pro .NET, který exportuje dokument do markdown, uloží každý obrázek do vyhrazené složky *md‑resources* a uloží výsledný markdown soubor připravený k publikaci.

> **Rychlý přehled:**  
> • Nastavte `MarkdownSaveOptions`  
> • Implementujte `IResourceSavingCallback` pro přesměrování obrázků  
> • Zavolejte `Document.Save` s nakonfigurovanými možnostmi  

Nyní, když chápete, proč je callback výhodnější než post‑processing, ponořme se do krok‑za‑krokem řešení.

## Rychlé odpovědi
- **Co vlastně dělá “convert docx to markdown”?** Převádí značkování Word‑processing na prostý text markdown a zachovává nadpisy, seznamy, tabulky a odkazy na obrázky.  
- **Která knihovna provádí konverzi?** Aspose.Words pro .NET poskytuje plně spravované, server‑side API, které funguje bez nainstalovaného Microsoft Word.  
- **Musím psát nějaký kód pro zpracování obrázků?** Ne; `IResourceSavingCallback` se postará o ukládání každého obrázku do zadané složky.  
- **Mohu změnit název výstupní složky?** Samozřejmě – nahraďte `"md-resources/"` libovolnou relativní nebo absolutní cestou, kterou preferujete.  
- **Je řešení kompatibilní s .NET 6 a novějšími?** Ano, běží na .NET 6+, .NET 5, .NET Core 3.1 a .NET Framework 4.7+.

## Co je convert docx to markdown?
**Convert docx to markdown** je proces převzetí dokumentu Microsoft Word (DOCX) a vytvoření markdown (`.md`) souboru, který představuje stejný obsah pomocí markdown syntaxe. Konverze zachovává strukturované prvky a volitelně extrahuje vložené zdroje, jako jsou obrázky.

Konverze je prováděna pomocí Aspose.Words, knihovny, která podporuje **35+ vstupních a výstupních formátů** — včetně DOCX, PDF, HTML a Markdown — což vám umožní pracovat s dokumenty o stovkách stránek, aniž byste načítali celý soubor do paměti.

## Proč použít Aspose.Words pro export do markdown?
Aspose.Words zpracovává dokumenty v paměti a zapisuje výsledek přímo do cílového formátu, což znamená:

Aspose.Words poskytuje vysoce výkonnou, přesnou konverzi a zároveň vám dává plnou kontrolu nad správou zdrojů. Odstraňuje potřebu kroků post‑processing, snižuje využití paměti a zajišťuje, že obrázky, tabulky a styly jsou věrně reprodukovány v markdown výstupu.

- **Rychlost:** Typické 200‑stránkové DOCX soubory jsou převedeny do markdown za méně než 2 sekundy na standardním VM.  
- **Přesnost:** Všechny 50+ vestavěné varianty markdown jsou podporovány, což zajišťuje správné vykreslení tabulek, bloků kódu a poznámek pod čarou.  
- **Řízení zdrojů:** Vestavěný `IResourceSavingCallback` vám umožní přesně určit, kam se každý obrázek uloží, čímž eliminuje potřebu samostatného kroku úklidu.

## Požadavky

- .NET 6.0 nebo novější (kompatibilní také s .NET Framework 4.7+)  
- Aspose.Words pro .NET (NuGet balíček `Aspose.Words`)  
- Zdrojový objekt `Document` (DOCX, PDF, RTF, atd.)  

Žádné další knihovny nejsou vyžadovány; callback API je součástí Aspose.Words.

## Jak převést docx na markdown?

Načtěte svůj zdrojový dokument pomocí `new Document("source.docx")`, nakonfigurujte `MarkdownSaveOptions` tak, aby používal callback, který zapisuje každý obrázek do `md-resources/`, a poté zavolejte `doc.Save("output.md", saveOptions)`. Tento tříkrokový vzor převádí soubor, extrahuje obrázky a vytváří čistý markdown soubor s relativními odkazy na obrázky — vše v jediném volání metody.

### Krok 1: nakonfigurujte možnosti uložení pro konverzi do markdown

MarkdownSaveOptions konfiguruje, jak Aspose.Words převádí dokument do Markdown.

```csharp
// Step 1: Initialize Markdown save options
var markdownSaveOptions = new Aspose.Words.Saving.MarkdownSaveOptions();
```

```csharp
// Step 1: Initialize Markdown save options
var markdownSaveOptions = new Aspose.Words.Saving.MarkdownSaveOptions();
```

> **Proč je to důležité:**  
> Bez explicitního vytvoření `MarkdownSaveOptions` knihovna přejde na výchozí nastavení, které vkládá obrázky přímo do Markdown souboru jako Base64 řetězce. To způsobí, že soubor bude obrovský a podkopává smysl mít čistou složku *images*.

### Krok 2: definujte callback pro ukládání zdrojů pro export obrázků

`IResourceSavingCallback` vám umožní řídit, kam se během exportu uloží každý zdroj (obrázek, SVG).

Nyní říkáme saveru **kde** umístit každý obrázek. Rozhraní `IResourceSavingCallback` nám poskytuje hák, který se spustí pro každý zdroj (obrázek, SVG, atd.) objevený během exportu. V rámci callbacku:

1. Zajistíme, že cílová složka existuje (`md-resources/`).  
2. Nastavíme `OutputFileName` na složku plus původní název zdroje.  

```csharp
// Step 2: Hook into the resource‑saving pipeline
markdownSaveOptions.ResourceSavingCallback = new Aspose.Words.Saving.IResourceSavingCallback(
    (args) =>
    {
        // All images will be placed in "md-resources" relative to the output .md file
        const string folder = "md-resources/";
        Directory.CreateDirectory(folder);          // Create folder if it doesn’t exist

        // Preserve the original file name (e.g., image001.png) but prepend the folder path
        args.OutputFileName = Path.Combine(folder, args.ResourceFileName);

        // Optional: you could also change the format here (e.g., convert BMP to PNG)
        // args.ResourceFileName = Path.ChangeExtension(args.ResourceFileName, ".png");
    });
```

> **Častá otázka:** *Co když chci místo ukládání obrázků je vložit?*  
> Stačí vynechat callback nebo nastavit `args.OutputFileName = null;` – saver automaticky vloží obrázek jako Base64 řetězec.

> **Okrajový případ:** Některé starší dokumenty obsahují duplicitní názvy obrázků. Výše uvedený callback přepíše předchozí soubor. Abyste tomu předešli, můžete připojit GUID:

```csharp
args.OutputFileName = Path.Combine(folder,
    $"{Path.GetFileNameWithoutExtension(args.ResourceFileName)}_{Guid.NewGuid()}{Path.GetExtension(args.ResourceFileName)}");
```

### Krok 3: uložte dokument jako markdown a ověřte výstup

S plně nakonfigurovanými možnostmi je poslední volání jednorázovým řádkem, který zapíše Markdown soubor a související obrázky na disk.

```csharp
// Step 3: Perform the actual export
string outputPath = @"C:\Exports\MyReport.md";
doc.Save(outputPath, markdownSaveOptions);
```

Pokud vše proběhne v pořádku, uvidíte:

- `MyReport.md` – Markdown reprezentace vašeho zdrojového dokumentu.  
- `md-resources/` – složka vedle `.md` souboru obsahující každý extrahovaný obrázek (např. `image001.png`, `image002.jpg`).  

**Ukázkový markdown úryvek** (automaticky vygenerovaný Aspose.Words):

```markdown
# Sample Report

Here is an introductory paragraph.

![Sample image](md-resources/image001.png)

More text follows...
```

[Ukázkový obrázek](md-resources/image001.png)

> **Tip:** Otevřete vygenerovaný `.md` soubor ve VS Code nebo v jakémkoli Markdown prohlížeči; obrázky by se měly okamžitě zobrazit, protože relativní cesty odpovídají struktuře složek.

## Kompletní, spustitelný příklad (bez dalších bloků kódu)

Níže je samostatný konzolový program, který můžete vložit do nového .NET projektu a spustit. Vytvoří jednoduchý Word dokument, přidá obrázek a poté **vytvoří markdown z dokumentu** při ukládání obrázku do podsložky.

```csharp
using System;
using System.IO;
using Aspose.Words;
using Aspose.Words.Saving;

class Program
{
    static void Main()
    {
        // 1️⃣ Create a sample Word document with an image
        var doc = new Document();
        var builder = new DocumentBuilder(doc);
        builder.Writeln("Hello, this is a test document.");
        builder.InsertImage("sample-image.png"); // Ensure this file exists next to exe

        // 2️⃣ Configure markdown export options (see Step 1 & 2 above)
        var markdownOptions = new MarkdownSaveOptions();
        markdownOptions.ResourceSavingCallback = new IResourceSavingCallback(
            (args) =>
            {
                const string folder = "md-resources/";
                Directory.CreateDirectory(folder);
                args.OutputFileName = Path.Combine(folder, args.ResourceFileName);
            });

        // 3️⃣ Save as markdown (Step 3)
        string outputFolder = Path.Combine(Environment.CurrentDirectory, "output");
        Directory.CreateDirectory(outputFolder);
        string markdownPath = Path.Combine(outputFolder, "ExportedDoc.md");
        doc.Save(markdownPath, markdownOptions);

        Console.WriteLine($"✅ Markdown saved to: {markdownPath}");
        Console.WriteLine("📂 Images saved in: md-resources/");
    }
}
```

**Co byste měli vidět** po spuštění:

```
✅ Markdown saved to: C:\MyProject\output\ExportedDoc.md
📂 Images saved in: md-resources/
```

## Často kladené varianty

| Scenario | How to adapt the code |
|----------|----------------------|
| **Skip image export** (embed as Base64) | Zcela vynechejte `ResourceSavingCallback`, nebo v callbacku nastavte `args.OutputFileName = null;`. |
| **Change image format** (e.g., all PNG) | V rámci callbacku upravte `args.ResourceFileName` a případně před zápisem převěďte stream. |
| **Custom folder name** | Nahraďte `"md-resources/"` libovolnou relativní nebo absolutní cestou, kterou preferujete. |
| **Multiple documents in a batch** | Procházejte kolekci objektů `Document`, znovu použijte stejnou instanci `MarkdownSaveOptions` (pouze zajistěte, že složka je vyčištěna nebo má jedinečný název pro každý běh). |

## Časté problémy a řešení

- **Obrázky se nezobrazují v markdown náhledu** – Ověřte, že relativní cesta v markdown (`md-resources/image001.png`) odpovídá skutečnému umístění složky relativně k souboru `.md`.  
- **Duplicitní názvy obrázků způsobují přepsání** – Přidejte unikátní identifikátor (GUID nebo inkrementální čítač) v callbacku, aby byly názvy souborů jedinečné.  
- **Velké dokumenty způsobují tlak na paměť** – Použijte `Document.OptimizeResources()` před uložením; tím se sníží spotřeba paměti uvolněním nepoužívaných streamů.  
- **Nepodporované formáty obrázků** – Aspose.Words podporuje PNG, JPEG, BMP, GIF a TIFF. Před přidáním do zdrojového dokumentu převěďte nepodporované formáty na jeden z těchto.

**Q: Mohu použít tento přístup v ASP .NET Web API, který vrací ZIP soubor?**

**Q: Zachovává konverze Word styly, jako jsou nadpisy a tabulky?**  
A: Naprosto. Aspose.Words mapuje Word styly nadpisů na markdown `#` nadpisy a převádí tabulky na markdown pipe syntaxi, zachovávajíc obsah buněk a zarovnání.

**Q: Jaké verze .NET jsou oficiálně podporovány?**
