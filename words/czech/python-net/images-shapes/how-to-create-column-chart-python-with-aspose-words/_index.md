# Jak vytvořit sloupcový graf v Pythonu pomocí Aspose.Words

Pokud potřebujete vytvořit sloupcový graf v Pythonu, tento průvodce vám ukáže přesný kód a postup, který potřebujete. Pomocí API pro grafy v Aspose.Words můžete definovat přesné rozměry, použít vestavěný styl a exportovat výsledek, aniž byste opustili Python.

Vytváření sloupcového grafu je běžná potřeba pro zprávy, dashboardy a automatizované vytváření dokumentů. Tento tutoriál pokrývá každý krok – od importu knihovny po ověření uloženého obrázku – takže můžete generování grafů integrovat do libovolného Python projektu.

## Požadavky

Než začnete, ujistěte se, že máte:

* Python 3.8 nebo novější nainstalovaný.
* Platnou licenci Aspose.Words pro Python (nebo bezplatný evaluační klíč).
* Základní znalosti modulů Pythonu a objektově orientovaného kódu.

Grafický engine Aspose.Words funguje na Windows, macOS i Linuxu a nevyžaduje další grafické knihovny, protože vykreslování probíhá na straně serveru.

## Krok 1: Import knihovny Aspose.Words

Prvním krokem je importovat balíček `aspose.words` a přiřadit mu krátkou zkratku. Import na začátku souboru udržuje jmenný prostor přehledný a usnadňuje čtení kódu.

```python
# Step 1: Import the Aspose.Words library
import aspose.words as aw
```

`aw` nyní odkazuje na kompletní API Aspose.Words, včetně třídy `Chart`, kterou použijete k vytvoření sloupcového grafu.

## Krok 2: Vytvořte sloupcový graf s požadovanými rozměry

Sloupcový graf potřebuje explicitní šířku a výšku, aby vykreslený obrázek zapadl do rozvržení dokumentu. Konstruktor `Chart` přijímá tři argumenty: typ grafu, šířku (v bodech) a výšku (v bodech). Použití `aw.ChartType.COLUMN` říká enginu, aby vygeneroval vertikální sloupcový graf.

```python
# Step 2: Create a column chart with the desired dimensions
chart = aw.Chart(aw.ChartType.COLUMN, 400, 300)   # width=400pt, height=300pt
```

*Proč nastavit rozměry?*  
Když graf vložíte do dokumentu Word nebo jej exportujete jako obrázek, okolní obsah respektuje přesně zadanou velikost. Tím se zabrání nechtěnému škálování nebo oříznutí.

### Tip: Použijte `chart.dimensions` pro dynamické změny velikosti

Pokud se velikost datové sady mění, můžete velikost vypočítat na základě počtu sérií:

```python
series_count = 5
base_width = 80
chart.width = base_width * series_count
chart.height = 300
```

## Krok 3: Použijte vestavěný styl na sloupcový graf

Aspose.Words obsahuje několik předdefinovaných vizuálních motivů. Výběrem stylu se vyhnete ručnímu nastavování barev, fontů a mřížek. `aw.ChartStyle.STYLE_5` poskytuje čistý, profesionální vzhled vhodný pro většinu obchodních zpráv.

```python
# Step 3: Apply a built‑in style to the chart
chart.style = aw.ChartStyle.STYLE_5
```

Pokud preferujete jiný vzhled, nahraďte `STYLE_5` libovolnou jinou konstantou (`STYLE_1` … `STYLE_8`). Každý styl následuje stejnou pojmenovací konvenci, což usnadňuje experimentování.

### Okrajový případ: Neplatná konstanta stylu

Pokus o přiřazení neexistujícího stylu vyvolá `AttributeError`. Ochráníte se tím, že před přiřazením zkontrolujete konstantu vůči výčtu:

```python
if hasattr(aw.ChartStyle, "STYLE_5"):
    chart.style = aw.ChartStyle.STYLE_5
else:
    raise ValueError("Requested chart style does not exist.")
```

## Krok 4: Přidejte datové série do sloupcového grafu

Graf bez dat postrádá smysl. Můžete přidat jeden nebo více objektů `ChartSeries`, z nichž každý představuje skupinu sloupců. Následující příklad přidává jedinou sérii se třemi datovými body.

```python
# Step 4: Add data series to the column chart
series = chart.series.add()
series.name = "Quarterly Sales"
series.data = [12000, 15000, 18000]   # Values for Q1, Q2, Q3
```

Volání `chart.series.add()` můžete opakovat pro zahrnutí dalších sérií (např. „Projekce prodeje“). API automaticky rozmístí sloupce vedle sebe.

## Krok 5: Vykreslete graf a uložte jej jako obrázek

Po nastavení grafu jej vykreslíte do bitmapy nebo souboru obrázku. Metoda `save` přijímá cestu k souboru a volitelný formát. PNG je bezztrátový a široce podporovaný.

```python
# Step 5: Render and save the chart as a PNG image
output_path = "column_chart.png"
chart.save(output_path, aw.SaveFormat.PNG)
print(f"Chart saved to {output_path}")
```

Výčet `SaveFormat` zahrnuje PNG, JPEG, BMP a další. Vyberte formát, který odpovídá vašemu následnému workflow.

## Ověření výstupu

Otevřete `column_chart.png` v libovolném prohlížeči obrázků. Měli byste vidět třísloupcový graf stylizovaný vybraným vestavěným motivem, přesně o rozměrech 400 × 300 bodů.

Pokud se obrázek zobrazí prázdný nebo zkreslený, zkontrolujte následující:

1. Objekt `aw.Chart` byl vytvořen před přidáním sérií.
2. Konstantu `chart.style` odpovídá existující hodnotě výčtu.
3. Volání `save` používá podporovaný `SaveFormat`.

## Běžné varianty a doplňující tipy

| Situace | Doporučená změna |
|-----------|--------------------|
| **Více datových sérií** | Přidejte další bloky `chart.series.add()` a nastavte `series.name` a `series.data` pro každou sérii. |
| **Vlastní barvy** | Po aplikaci vestavěného stylu přepište barvy jednotlivých sloupců pomocí `series.points[i].fill.fore_color`. |
| **Vložení do dokumentu Word** | Místo `chart.save()` použijte `doc = aw.Document(); doc.sections[0].body.append_child(chart); doc.save("report.docx")`. |
| **Dynamické velikosti** | Vypočítejte šířku na základě počtu sérií (`width = 80 * len(chart.series)`). |

Tyto varianty ukazují, jak se stejný základní kód přizpůsobí různým scénářům reportování.

Kompletní workflow – import, vytvoření instance, styl, naplnění daty a vykreslení – pokrývá nejčastější případy použití pro automatizované reportování.

Experimentujte s různými **možnostmi stylování sloupcových grafů**, aby odpovídaly vašim firemním směrnicím, a získáte robustní, připravené řešení pro tvorbu grafů v Pythonu.
