# Jak shrnout Word dokument pomocí AI poskytovatelů v C#

Pokud potřebujete **shrnout Word dokument** rychle, tento návod vám ukáže přesně jak. Uvidíte kompletní, spustitelný příklad, který vám umožní **vybrat AI poskytovatele** (OpenAI nebo Google) a zvládnout scénář **shrnutí velkého dokumentu** bez opuštění IDE.

Shrnutí Word dokumentu je běžný úkol při tvorbě botů pro znalostní báze, souhrnů zpráv nebo automatizovaných e‑mailových výpisů. V následujících sekcích se naučíte, který NuGet balíček nainstalovat, jak načíst soubor `.docx`, nakonfigurovat shrnovač a vypsat výsledek – vše v čistém C#.

## Co budete potřebovat

| Požadavek | Důvod |
|-------------|--------|
| .NET 6 SDK nebo novější | Poskytuje runtime pro C# příklad |
| Visual Studio 2022 (nebo jakékoli IDE) | Usnadňuje přidání NuGet balíčků a spuštění konzolové aplikace |
| `GroupDocs.Summarization` NuGet balíček | Poskytuje API `DocumentSummarizer` použité v kódu |
| Internetové připojení | Nutné pro AI poskytovatele (OpenAI nebo Google) ke zpracování textu |

> **Tip:** Pokud plánujete **shrnout velký dokument** (více než 100 KB), povolte režim streamování v nastavení, aby se předešlo načítání celého souboru do paměti.

## Jak shrnout Word dokument krok za krokem

### Krok 1: Nainstalujte knihovnu pro shrnutí

Otevřete Package Manager Console a spusťte:

```powershell
Install-Package GroupDocs.Summarization
```

Knihovna `GroupDocs.Summarization` abstrahuje podkladová volání AI, takže můžete měnit poskytovatele bez úpravy obchodní logiky.

### Krok 2: Načtěte Word dokument

```csharp
using GroupDocs.Summarization;
using GroupDocs.Summarization.Options;

// Step 2: Load the source document
Document doc = new Document("YOUR_DIRECTORY/Report.docx");
```

Třída `Document` načte soubor `.docx` a připraví jej ke shrnutí. Pokud je soubor velký, knihovna automaticky použije paměťově úsporný parser.

### Krok 3: Nakonfigurujte možnosti shrnovače a **vyberte AI poskytovatele**

```csharp
// Step 3: Set up summarization options (choose the AI provider)
SummarizerOptions options = new SummarizerOptions
{
    Provider = SummarizerProvider.OpenAI   // or SummarizerProvider.Google
};
```

- `Provider = SummarizerProvider.OpenAI` vybírá model GPT‑4 od OpenAI.  
- `Provider = SummarizerProvider.Google` vybírá model Gemini od Google, což je ideální, když **shrnete s Google** pro lepší podporu více jazyků.

**Vyberete AI poskytovatele** podle nákladů, latence nebo jazykových požadavků. Stejný objekt `options` funguje pro oba poskytovatele, což udržuje kód přehledný.

### Krok 4: Vygenerujte shrnutí – podpora **shrnutí velkého dokumentu**

```csharp
// Step 4: Generate the summary using the selected provider
string summary = DocumentSummarizer.Summarize(doc, options);
```

Když **shrnete velký dokument**, knihovna streamuje obsah do AI služby, čímž zabraňuje chybám z nedostatku paměti. Metoda `Summarize` vrací řetězec prostého textu obsahující nejrelevantnější věty.

### Krok 5: Výstup výsledku

```csharp
// Step 5: Output the generated summary
Console.WriteLine("Summary:\n" + summary);
```

Spuštěním programu se vypíše stručný odstavec, který zachycuje podstatu původního Word souboru.

## Kompletní spustitelný příklad

```csharp
using System;
using GroupDocs.Summarization;
using GroupDocs.Summarization.Options;

namespace WordSummarizerDemo
{
    class Program
    {
        static void Main(string[] args)
        {
            // Load the source Word document
            Document doc = new Document("YOUR_DIRECTORY/Report.docx");

            // Choose the AI provider (OpenAI or Google)
            SummarizerOptions options = new SummarizerOptions
            {
                Provider = SummarizerProvider.Google   // Change to OpenAI if you prefer
            };

            // Generate the summary – works for both small and large documents
            string summary = DocumentSummarizer.Summarize(doc, options);

            // Display the summary in the console
            Console.WriteLine("Summary:\n" + summary);
        }
    }
}
```

**Očekávaný výstup**

```
Summary:
The quarterly sales increased by 12% driven by the new product line, while operational costs fell 3% due to efficiency gains. The report also highlights upcoming market expansion in APAC and recommends allocating additional budget to R&D.
```

Přesná formulace se bude lišit podle AI modelu, který **vyberete AI poskytovatele**, ale struktura zůstane stejná.

## Řešení scénáře **shrnutí velkého dokumentu**

Když zdrojový `.docx` přesáhne 5 MB, zvažte následující úpravy:

1. **Povolit chunking** – knihovna rozdělí dokument na bloky po 5 KB před odesláním do AI služby.  
2. **Zvýšit `MaxSentences`** v `SummarizerOptions`, pokud potřebujete delší shrnutí.  
3. **Nastavit vyšší `Timeout`**, aby se vyhovělo delším dobám zpracování.

```csharp
options.MaxSentences = 8;          // Return up to 8 sentences
options.EnableChunking = true;    // Essential for very large files
options.Timeout = TimeSpan.FromMinutes(2);
```

Tyto úpravy zajistí, že operace **shrnutí velkého dokumentu** zůstane rychlá a spolehlivá.

## Jak efektivně **shrnout s Google**

Model Gemini od Google vyniká v multijazykovém obsahu a stručném vyjadřování. Pro dosažení nejlepších výsledků:

- **Zadejte jazyk** (volitelné), pokud dokument obsahuje text v jiném jazyce než angličtině:  
  ```csharp
  options.Language = "es"; // Spanish
  ```
- **Upravte teplotu** pro kontrolu kreativity:  
  ```csharp
  options.Temperature = 0.3; // More deterministic output
  ```

Když **shrnete s Google**, služba může vrátit mírně kratší, ale vysoce zaměřené shrnutí ve srovnání s OpenAI. Otestujte oba poskytovatele na vzorovém dokumentu a rozhodněte, který lépe vyhovuje vašemu produktu.

## Časté problémy a jak se jim vyhnout

| Příznak | Příčina | Řešení |
|---------|-------|-----|
| Prázdné shrnutí | Chybí klíč poskytovatele nebo je síť blokována | Ověřte API klíče v proměnných prostředí a zajistěte povolený odchozí HTTPS |
| Oříznutý text | Dokument překračuje limit tokenů poskytovatele | Povolit `EnableChunking` nebo zvýšit `MaxTokens`, pokud knihovna podporuje |
| Neočekávaný jazyk | Nesprávná volba `Language` | Odstraňte volbu nebo nastavte na skutečný jazyk dokumentu |

Řešení těchto problémů včas šetří čas s laděním, zejména když **vyberete AI poskytovatele** pro produkční zatížení.
