# Vytvořte šablonu faktury a sloučte data pomocí Aspose.Words

Pokud potřebujete rychle **vytvořit šablonu faktury**, tento průvodce vám přesně ukáže, jak na to. Po přečtení prvních dvou vět budete znát kompletní postup, jak ze prázdného souboru Word vytvořit plně vyplněnou fakturu pomocí low‑code mail‑merge API od Aspose.Words.

Generování faktur je běžnou požadavkou pro fakturační systémy, integrace ERP a automatizované reportování. V tomto tutoriálu se naučíte **jak provést mail merge**, **vyplnit šablonu Word**, **sloučit data do Wordu** a nakonec **uložit sloučený dokument** — vše pomocí několika řádků C#.

## Co dosáhnete

* Znovupoužitelná šablona Word (`InvoiceTemplate.docx`) obsahující sloučovací pole pro zákazníka, datum, položky a celkovou částku.  
* C# program, který načte šablonu, vloží silně typovaný datový objekt a zapíše výsledek do `Invoice_001.docx`.  
* Přehled o okrajových případech, jako jsou prázdné kolekce, vlastní datové typy a práce s cestami k souborům.

### Požadavky

| Požadavek | Proč je důležité |
|-----------|-------------------|
| .NET 6 or later | Aspose.Words for .NET podporuje .NET 6+ a poskytuje low‑code API použité v tomto průvodci. |
| Aspose.Words for .NET NuGet package (`Aspose.Words`) | Poskytuje třídy `Document`, `MailMerger` a související typy. |
| Basic C# knowledge | Potřebná pro pochopení anonymních objektů a LINQ. |
| Visual Studio 2022 (or any IDE) | Umožňuje snadnou úpravu a ladění. |

> **Tip:** Nainstalujte NuGet balíček pomocí Package Manager Console:  
> `Install-Package Aspose.Words`

## Jak vytvořit šablonu faktury pomocí low‑code mail merge

Prvním krokem je vytvořit soubor Word, který obsahuje sloučovací pole odpovídající vlastnostem datového objektu, který později předáte. Uložte soubor jako `InvoiceTemplate.docx` do složky, kterou ovládáte (např. `C:\Invoices\Template`).

| Sloučovací pole | Příklad zástupného textu ve Wordu |
|-----------------|-----------------------------------|
| CustomerName | «CustomerName» |
| InvoiceDate | «InvoiceDate» |
| Items (repeating) | «Items.Description», «Items.Qty», «Items.Price» |
| Total | «Total» |

> **Proč je to důležité:** Low‑code API automaticky mapuje názvy vlastností datového zdroje na sloučovací pole. Zachování stejných názvů eliminuje ruční mapování pole‑na‑vlastnost a snižuje chyby za běhu.

## Krok 1: Načtěte šablonu faktury

```csharp
using Aspose.Words;
using Aspose.Words.LowCode;   // Low‑code mail‑merge API

// Load the Word file that contains the merge fields.
Document template = new Document(@"C:\Invoices\Template\InvoiceTemplate.docx");
```

*`Document`* třída představuje celý soubor Word. Jednorázové načtení vám umožní znovu použít stejnou šablonu pro mnoho faktur.

## Krok 2: Připravte zdroj dat

Vytvořte anonymní objekt, který odráží sloučovací pole. Low‑code API může pracovat s libovolným .NET objektem, včetně polí a vnořených kolekcí.

```csharp
var invoiceData = new
{
    CustomerName = "Acme Corp",
    InvoiceDate = DateTime.Today,
    Items = new[]
    {
        new { Description = "Widget A", Qty = 10, Price = 9.99M },
        new { Description = "Widget B", Qty = 5,  Price = 19.95M }
    },
    Total = 199.85M
};
```

**Proč to funguje:**  
* Názvy vlastností (`CustomerName`, `InvoiceDate`, `Items`, `Total`) odpovídají sloučovacím polím v šabloně.  
* `Items` je pole objektů, takže mail merger automaticky opakuje řádek tabulky pro každý prvek.  
* Použití typu `decimal` (`M` přípona) pro peněžní hodnoty zabraňuje problémům s zaokrouhlováním floating‑point.

### Zpracování prázdných kolekcí

Pokud faktura neobsahuje žádné položky, předávejte prázdné pole:

```csharp
Items = new object[0]
```

Low‑code engine jednoduše vynechá opakující se sekci a ponechá záhlaví tabulky nedotčené.

## Krok 3: Inicializujte low‑code mail merger

```csharp
MailMerger merger = new MailMerger(template);
```

`MailMerger` je vstupní bod pro **mail merge** s Aspose.Words. Načte šablonu, sváže data a připraví finální dokument jedním voláním.

## Krok 4: Proveďte sloučení – vyplňte šablonu Word v jednom řádku

```csharp
Document mergedDocument = merger.Execute(invoiceData);
```

* Tento řádek **vyplní šablonu Word** a vytvoří novou instanci `Document` (`mergedDocument`).  
* Všechna sloučovací pole jsou nahrazena, opakující se sekce jsou rozšířeny a výsledný dokument je uložen kompletně v paměti.

### Okrajový případ: Vlastní formátování

Pokud potřebujete konkrétní formát data, přidejte před sloučením vlastní formátovač:

```csharp
merger.Options.DateFormat = "MMMM dd, yyyy"; // e.g., "October 07, 2026"
```

## Krok 5: Uložte sloučený dokument

```csharp
mergedDocument.Save(@"C:\Invoices\Output\Invoice_001.docx");
```

Volání **save merged document** zapíše plně vyplněnou fakturu na disk. Soubor lze nyní otevřít v Microsoft Word, odeslat jako přílohu e‑mailu nebo převést do PDF.

### Ověření výstupu

Otevřete `Invoice_001.docx`. Měli byste vidět:

* **CustomerName** nahrazeno *Acme Corp*  
* **InvoiceDate** zobrazující dnešní datum ve zvoleném formátu  
* Řádek tabulky pro *Widget A* (10 × 9.99) a *Widget B* (5 × 19.95)  
* **Total** zobrazující *199.85*  

Pokud některé pole zůstane nezměněno (např. stále zobrazuje «CustomerName»), zkontrolujte, že názvy vlastností přesně odpovídají názvům sloučovacích polí v šabloně.

## Kompletní spustitelný příklad

Níže je kompletní program, který můžete zkopírovat a vložit do nového konzolového projektu.

```csharp
using System;
using Aspose.Words;
using Aspose.Words.LowCode;   // Low‑code mail‑merge API

namespace InvoiceGenerator
{
    class Program
    {
        static void Main()
        {
            // 1️⃣ Load the template
            Document template = new Document(@"C:\Invoices\Template\InvoiceTemplate.docx");

            // 2️⃣ Build the data source
            var invoiceData = new
            {
                CustomerName = "Acme Corp",
                InvoiceDate = DateTime.Today,
                Items = new[]
                {
                    new { Description = "Widget A", Qty = 10, Price = 9.99M },
                    new { Description = "Widget B", Qty = 5,  Price = 19.95M }
                },
                Total = 199.85M
            };

            // 3️⃣ Initialise the mail merger
            MailMerger merger = new MailMerger(template);

            // Optional: customise date format
            merger.Options.DateFormat = "MMMM dd, yyyy";

            // 4️⃣ Perform the merge (populate word template)
            Document mergedDocument = merger.Execute(invoiceData);

            // 5️⃣ Save the resulting file (save merged document)
            mergedDocument.Save(@"C:\Invoices\Output\Invoice_001.docx");

            Console.WriteLine("Invoice generated successfully.");
        }
    }
}
```

Spusťte program (`dotnet run`). Konzole vypíše *Invoice generated successfully.* a soubor se objeví v `C:\Invoices\Output`.
