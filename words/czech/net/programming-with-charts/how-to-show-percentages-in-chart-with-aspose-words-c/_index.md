# Jak zobrazit procenta v grafu pomocí Aspose.Words C#

Už jste se někdy zamýšleli **jak zobrazit procenta v grafu** bez zdlouhavého používání Office interop? Nejste v tom sami — mnoho vývojářů narazí na tuto překážku, když potřebují rychle a programově označit koláčový nebo prstencový graf. Dobrá zpráva? S Aspose.Words pro .NET můžete povolit tyto popisky dat během několika řádků kódu.

V tomto tutoriálu se také podíváme na **přidání popisků dat do koláčového grafu** a **povolení popisků grafu**, takže vaše vizualizace okamžitě získají na přehlednosti. Na konci budete mít připravený Word dokument (`.docx`), který zobrazuje vylepšený koláčový graf s procenty umístěnými mimo každý výsek.

## Požadavky

Než se pustíme do kódu, ujistěte se, že máte:

- **Aspose.Words pro .NET** (nejnovější verze, např. 24.9) nainstalovanou přes NuGet.
- Soubor **ChartTemplate.docx**, který již obsahuje koláčový nebo prstencový graf.  
  *(Pokud ho nemáte, vytvořte jednoduchý Word dokument, vložte koláčový graf a uložte jej jako `ChartTemplate.docx`.)*
- .NET 6.0 nebo novější a libovolné IDE podle vašeho výběru (Visual Studio, Rider, VS Code).

Žádné další závislosti nejsou potřeba — Aspose.Words vše vyřeší interně.

## Jak zobrazit procenta v grafu – krok za krokem

Níže je proces rozdělen do šesti jasných kroků. Každý krok obsahuje přesný C# kód, který můžete zkopírovat a vložit, plus stručné vysvětlení **proč** to děláme.

### Krok 1: Načtení zdrojového dokumentu

```csharp
using Aspose.Words;
using Aspose.Words.Drawing.Charts;

// Load the .docx that already holds a chart.
Document sourceDoc = new Document("YOUR_DIRECTORY/ChartTemplate.docx");
```

*Proč?*  
`Document` je vstupní bod pro jakoukoli manipulaci s Wordem. Načtením šablony získáme přístup ke všem uzlům — tvarům, tabulkám, textu i samozřejmě grafu, který budeme upravovat.

### Krok 2: Získání prvního tvaru grafu

```csharp
// The chart lives inside a Shape node; retrieve it.
Chart chart = (Chart)sourceDoc.GetChild(NodeType.Shape, 0, true);
```

*Proč?*  
Aspose ukládá grafy jako objekty `Shape`. `GetChild` prochází strom dokumentu a vrací první nalezený tvar, což je v našem případě koláčový graf, který chceme editovat.

### Krok 3: Ověření typu grafu

```csharp
if (chart.ChartType == ChartType.Pie || chart.ChartType == ChartType.Doughnut)
{
    // Inside this block we’ll enable the data labels.
}
else
{
    throw new InvalidOperationException("The chart is not a Pie or Doughnut type.");
}
```

*Proč?*  
Popisky procent mají smysl jen u kruhových grafů. Tento kontrolní krok zabrání aplikaci nastavení na např. sloupcový graf, kde by `ShowPercentage` bylo ignorováno.

### Krok 4: Povolení popisků dat a zobrazení procent

```csharp
// Turn on data labels for the chart.
chart.HasDataLabel = true;

// Show the percentage value for each slice.
chart.DataLabel.ShowPercentage = true;
```

*Proč?*  
`HasDataLabel` říká Aspose, aby vykreslil popisek pro každý datový bod. Nastavení `ShowPercentage` zajistí, že obsahem popisku bude vypočtený podíl celku — právě to, co požadavek **přidání popisků dat do koláčového grafu** vyžaduje.

### Krok 5: Umístění popisků mimo výseky

```csharp
// Place the labels outside the pie slices for better readability.
chart.DataLabel.Position = ChartDataLabelPosition.OutSideEnd;
```

*Proč?*  
Popisky uvnitř výseku mohou být stísněné, zejména u malých výseků. `OutSideEnd` napodobuje výchozí styl „mimo“, který vidíte v uživatelském rozhraní Wordu, a udržuje graf přehledný.

### Krok 6: Uložení aktualizovaného dokumentu

```csharp
sourceDoc.Save("YOUR_DIRECTORY/FormattedPieChart.docx");
```

*Proč?*  
Uložení zapíše všechny změny do nového souboru. Otevřete `FormattedPieChart.docx` ve Wordu a uvidíte procenta zobrazená vedle každého výseku.

#### Očekávaný výsledek

Po otevření `FormattedPieChart.docx` by měl koláčový graf vypadat podobně jako tento (imaginární snímek obrazovky):

```
[ Pie chart with three slices ]
- Slice A – 45%
- Slice B – 30%
- Slice C – 25%
```

Všechna procenta jsou vypočítána automaticky ze základní datové řady a popisky jsou umístěny těsně mimo každý výsek.

## Běžné varianty a okrajové případy

| Situace | Co upravit |
|-----------|----------------|
| **Více grafů** ve stejném dokumentu | Procházejte `sourceDoc.GetChildNodes(NodeType.Shape, true)` a přetypujte každý na `Chart` před aplikací stejné logiky. |
| **Sloupcový nebo čárový graf**, kde stále chcete popisky | Použijte `chart.DataLabel.ShowValue = true;` (nebo `ShowSeriesName`) místo `ShowPercentage`. |
| **Vlastní formát čísla** (např. „45 %“) | Nastavte `chart.DataLabel.NumberFormat = "0%";` před uložením. |
| **Velké datové sady** způsobující překrývání popisků | Zvažte `chart.DataLabel.ShowLeaderLines = true;` pro vykreslení spojnicových čar. |

> **Tip:** Pokud generujete mnoho dokumentů najednou, vytvořte jediný objekt `Aspose.Words.License` při startu aplikace, abyste se vyhnuli výkonovým ztrátám při opakovaném načítání licence.

## Kompletní funkční příklad

Zde je celý program poskládaný dohromady, připravený ke spuštění:

```csharp
using System;
using Aspose.Words;
using Aspose.Words.Drawing.Charts;

class Program
{
    static void Main()
    {
        // 1️⃣ Load the template document.
        Document sourceDoc = new Document("YOUR_DIRECTORY/ChartTemplate.docx");

        // 2️⃣ Retrieve the first chart shape.
        Chart chart = (Chart)sourceDoc.GetChild(NodeType.Shape, 0, true);

        // 3️⃣ Ensure we’re dealing with a Pie or Doughnut chart.
        if (chart.ChartType != ChartType.Pie && chart.ChartType != ChartType.Doughnut)
        {
            Console.WriteLine("The selected shape is not a Pie/Doughnut chart.");
            return;
        }

        // 4️⃣ Enable data labels and show percentages.
        chart.HasDataLabel = true;
        chart.DataLabel.ShowPercentage = true;

        // 5️⃣ Position the labels outside the slices.
        chart.DataLabel.Position = ChartDataLabelPosition.OutSideEnd;

        // 6️⃣ Save the modified document.
        sourceDoc.Save("YOUR_DIRECTORY/FormattedPieChart.docx");

        Console.WriteLine("Chart updated successfully – percentages now visible!");
    }
}
```

Zkopírujte kód, nahraďte `YOUR_DIRECTORY` skutečnou cestou na vašem počítači a spusťte jej. Za pár sekund budete mít Word soubor s plně označeným koláčovým grafem.

## Shrnutí

Odpověděli jsme na otázku **jak zobrazit procenta v grafu** pomocí Aspose.Words pro C#. Pokryté kroky:

1. Načtěte šablonu.
2. Získejte tvar grafu.
3. Ověřte, že jde o koláčový/prstencový graf.
4. **Přidejte popisky dat do koláčového grafu** a povolte procenta.
5. Umístěte popisky mimo výseky.
6. Uložte výsledek.

S těmito znalostmi můžete automatizovat jakýkoli reportingový scénář, který vyžaduje jasné vizualizace založené na procentech.

## Co dál?

- **Styling popisků** — změňte písmo, barvu nebo přidejte pozadí pomocí `chart.DataLabel.Font`.  
- **Vytváření grafů od nuly** — prozkoumejte `Chart chart = (Chart)sourceDoc.FirstSection.Body.AppendChild(new Shape(sourceDoc, ShapeType.Chart));` pro programové generování grafů.  
- **Kombinace více grafů** v jednom dokumentu pro dashboardy a následný export do PDF pomocí `sourceDoc.Save("Dashboard.pdf", SaveFormat.Pdf);`.

Nebojte se experimentovat, a pokud narazíte na nečekané chování, zanechte komentář. Šťastné grafování!
