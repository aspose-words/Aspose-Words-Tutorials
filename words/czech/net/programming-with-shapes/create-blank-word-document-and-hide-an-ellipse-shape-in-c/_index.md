# Vytvořte prázdný dokument Word a skryjte eliptický tvar v C#

Pokud potřebujete **vytvořit prázdný dokument Word** a poté skrýt grafický prvek, tento návod vám přesně ukáže, jak to provést v C#. Uvidíte kompletní, spustitelný příklad, který vloží elipsu, umístí ji, označí ji jako skrytou a uloží soubor – vše během několika řádků kódu.

Návod pokrývá vše od nastavení projektu až po poslední krok ověření. Na konci budete schopni vygenerovat soubor Word, ve kterém se elipsa nikdy neobjeví na obrazovce ani v tisku, což je užitečné pro ukládání metadat, záložek nebo jakéhokoli neviditelného markeru.

## Požadavky

* .NET 6.0 SDK nebo novější nainstalován  
* Vývojové prostředí C# (Visual Studio 2022, Rider nebo VS Code)  
* NuGet balíček **Aspose.Words for .NET** (`Install-Package Aspose.Words`)  

Tyto nástroje poskytují třídy `Document` a `DocumentBuilder`, které jsou použity ve vzorku kódu.

## Krok 1: Vytvořte prázdný dokument Word

První operace vytvoří prázdný objekt `Document` a `DocumentBuilder`, který vám umožní přidávat obsah.

```csharp
using Aspose.Words;
using Aspose.Words.Drawing;

// Step 1: Initialize an empty document and a builder
Document doc = new Document();
DocumentBuilder builder = new DocumentBuilder(doc);
```

`Document` představuje celý balíček `.docx`, zatímco `DocumentBuilder` nabízí plynulé API pro vkládání textu, tvarů a dalších objektů. Začátek s prázdným dokumentem vám dává plnou kontrolu nad každým prvkem, který přidáte.

## Krok 2: Jak vložit elipsu

Elipsa je vektorový tvar, který lze použít jako marker. Metoda `InsertShape` vyžaduje typ tvaru a jeho šířku/výšku v bodech.

```csharp
// Step 2: Insert an ellipse shape of the desired size (100 pt × 50 pt)
Shape ellipse = builder.InsertShape(ShapeType.Ellipse, 100, 50);
```

Elipsa se nachází na aktuální stránce v místě kurzoru. Její rozměry můžete změnit úpravou číselných argumentů.

## Krok 3: Jak umístit tvar

Po vložení můžete tvar přesunout kamkoli na stránce nastavením vlastností `Left` a `Top`, které používají body relativně k okraji stránky.

```csharp
// Step 3: Position the shape on the page
ellipse.Left = 150; // distance from the left margin
ellipse.Top  = 100; // distance from the top margin
```

Tyto souřadnice umisťují elipsu přibližně do horní‑střední části standardní stránky A4. Hodnoty upravte podle požadavků na rozvržení.

## Krok 4: Jak skrýt tvar

Skrytý objekt se nezobrazuje, když je dokument otevřen nebo vytištěn. Nastavením příznaku `Hidden` označíte tvar jako **skrytý objekt word**.

```csharp
// Step 4: Hide the shape so it never appears
ellipse.Hidden = true;
```

Word respektuje příznak hidden jak při vykreslování na obrazovce, tak při tisku. Tvar zůstává součástí struktury dokumentu, což vám umožní jej později dotazovat nebo upravovat pomocí kódu.

## Krok 5: Uložte dokument

Nakonec zapište dokument na disk. Vyberte složku, do které máte právo zápisu.

```csharp
// Step 5: Save the document to a .docx file
doc.Save(@"C:\Temp\HiddenEllipse.docx");
```

Soubor `HiddenEllipse.docx` nyní obsahuje prázdnou stránku se skrytým tvarem elipsy.

## Ověření skryté elipsy

Otevřete vygenerovaný soubor v Microsoft Word a povolte možnost **Zobrazit skrytý text** (Soubor → Možnosti → Zobrazení). Uvidíte slabý obrys elipsy. Pokud možnost vypnete, tvar zmizí úplně, což potvrzuje, že `ellipse.Hidden = true` funguje podle očekávání.

## Běžné varianty a okrajové případy

| Situace | Doporučené úpravy |
|-----------|------------------------|
| **Jiný tvar** | Nahraďte `ShapeType.Ellipse` za `ShapeType.Rectangle`, `ShapeType.Arrow` atd. |
| **Více skrytých objektů** | Opakujte kroky 2‑4 pro každý tvar; každý může mít svůj vlastní příznak `Hidden`. |
| **Jiná velikost stránky** | Nastavte `doc.FirstSection.PageSetup.PageWidth` a `PageHeight` před vložením tvaru. |
| **Podmíněná viditelnost** | Použijte `Shape.Visible` v kombinaci s `Hidden` pro přepínání za běhu pomocí kódu. |

**Tip:** Uložte identifikační data do vlastnosti `AlternativeText` tvaru. I když je skrytý, můžete tvar později získat pomocí `doc.GetChildNodes(NodeType.Shape, true)` a filtrovat podle tohoto textu.

## Kompletní zdrojový kód

Níže je kompletní program, který můžete zkopírovat, vložit a spustit.

```csharp
using System;
using Aspose.Words;
using Aspose.Words.Drawing;

namespace HiddenShapeDemo
{
    class Program
    {
        static void Main()
        {
            // Create a new blank document and a builder
            Document doc = new Document();
            DocumentBuilder builder = new DocumentBuilder(doc);

            // Insert an ellipse shape (100 pt × 50 pt)
            Shape ellipse = builder.InsertShape(ShapeType.Ellipse, 100, 50);

            // Position the shape on the page
            ellipse.Left = 150;
            ellipse.Top  = 100;

            // Hide the shape so it is invisible in the UI and on print
            ellipse.Hidden = true;

            // Optional: add a description for later retrieval
            ellipse.AlternativeText = "Hidden marker for internal processing";

            // Save the document
            string outputPath = @"C:\Temp\HiddenEllipse.docx";
            doc.Save(outputPath);

            Console.WriteLine($"Document saved to {outputPath}");
        }
    }
}
```

**Očekávaný výstup:** Konzole vypíše cestu k uložení a soubor `HiddenEllipse.docx` se otevře jako prázdná stránka bez viditelných grafických prvků, pokud nejsou skryté objekty zobrazeny.

## Závěr

Nyní víte, jak programově **vytvořit prázdný dokument Word**, **vložit elipsu**, **umístit tvar** a **skrýt tvar**, aby se choval jako **skrytý objekt word**. Tato technika je ideální pro vkládání neviditelných markerů, vlastních metadat nebo zástupných znaků, které následné procesy mohou číst, aniž by ovlivnily vizuální rozvržení dokumentu.
