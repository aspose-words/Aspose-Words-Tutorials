# Jak vytvořit skrytý tvar docx pomocí Aspose.Words v C#

Pokud potřebujete programově **vytvořit skrytý tvar docx** soubory, tento tutoriál ukazuje přesné kroky pomocí Aspose.Words pro .NET. Uvidíte, jak **nastavit barvu výplně tvaru**, aby byl tvar viditelný během úprav, a poté **skrýt tvar v dokumentu Word**, aby jej koncový uživatel nikdy neviděl, pokud nejsou zobrazeny skryté objekty.

Průvodce pokrývá vše, co potřebujete vědět: požadované NuGet balíčky, kompletní spustitelný ukázkový kód a tipy pro řešení běžných problémů. Na konci článku budete mít DOCX, který obsahuje neviditelnou elipsu, kterou lze později odhalit, pokud bude potřeba.

## Předpoklady

- .NET 6.0 SDK nebo novější nainstalováno  
- Visual Studio 2022 (nebo jakékoli C# IDE)  
- Aktivní licence Aspose.Words pro .NET (nebo dočasný evaluační klíč)  
- Základní znalost syntaxe C#  

Nemusíte **žádné** další knihovny Word interop, protože Aspose.Words funguje nezávisle na Microsoft Office.

## Krok 1: Vytvořit skrytý tvar docx – inicializace dokumentu

Prvním krokem je vytvořit objekt `Document` a `DocumentBuilder`. Builder poskytuje plynulé API pro vkládání tvarů, textu a dalších prvků.

```csharp
using Aspose.Words;
using Aspose.Words.Drawing;
using System.Drawing;

class Program
{
    static void Main()
    {
        // Initialise an empty DOCX file
        Document doc = new Document();
        DocumentBuilder builder = new DocumentBuilder(doc);
```

*Proč je to důležité*: Čerstvý `Document` představuje prázdný soubor Word. `DocumentBuilder` funguje jako kurzor, který ví, kam bude umístěn další prvek. Začátek s čistým dokumentem zajišťuje, že skrytý tvar nezdědí neočekávané formátování.

## Krok 2: Nastavit barvu výplně tvaru pro elipsu

Dále vložte elipsový tvar a aplikujte barvu výplně. Barva umožní, aby byl tvar viditelný v editoru, což je užitečné, když potřebujete ověřit jeho velikost nebo umístění před jeho skrytím.

```csharp
        // Insert an ellipse 150 pt wide and 100 pt high
        Shape ellipse = builder.InsertShape(ShapeType.Ellipse, 150, 100);

        // Apply a bright fill so the shape can be inspected
        ellipse.FillColor = Color.Yellow;
```

Krok **nastavit barvu výplně tvaru** je pro finální skrytý dokument volitelný, ale pomáhá během vývoje. Bez výplně by byl tvar neviditelný i před nastavením příznaku hidden, což ztěžuje ladění.

## Krok 3: Skrýt tvar v dokumentu Word

Nyní aplikujte vlastnost `Hidden`. Když je `Hidden` nastaveno na `true`, Microsoft Word nebude tvar vykreslovat v normálním zobrazení. Uživatelé jej mohou stále odhalit povolením „Zobrazit skryté objekty“ v nastavení Wordu.

```csharp
        // Mark the shape as hidden – it will not appear in normal view
        ellipse.Hidden = true;
```

*Důležitá poznámka*: Příznak hidden funguje ve Wordu 2010 a novějším. Pokud cílíte na starší verze, tvar se může stále zobrazovat. Také tento příznak neovlivňuje pozici tvaru; pouze potlačuje jeho vykreslení.

## Krok 4: Uložit soubor DOCX

Nakonec zapíšete dokument na disk. Název souboru může být libovolná platná cesta; zde používáme relativní cestu pro jednoduchost.

```csharp
        // Persist the document with the hidden shape
        doc.Save("HiddenShape.docx");
    }
}
```

Když otevřete `HiddenShape.docx` v Microsoft Word, elipsa nebude viditelná. Pokud povolíte **File → Options → Display → Show hidden objects**, žlutá elipsa se objeví přesně tam, kam jste ji umístili.

### Očekávaný výstup

- Soubor pojmenovaný `HiddenShape.docx` v pracovním adresáři spustitelného souboru.  
- Otevření souboru ve Wordu zobrazí normální obsah bez **viditelného tvaru**.  
- Povolení „Show hidden objects“ odhalí žlutou elipsu o velikosti 150 × 100 pt.

## Krok 5: Ověřit skrytý tvar programově (volitelné)

Pokud potřebujete potvrdit, že je tvar skutečně skrytý bez otevření Wordu, můžete po načtení dokumentu zkontrolovat vlastnost `Hidden`:

```csharp
        Document loaded = new Document("HiddenShape.docx");
        Shape loadedShape = (Shape)loaded.GetChildNodes(NodeType.Shape, true)[0];
        System.Console.WriteLine($"Shape hidden? {loadedShape.Hidden}");
```

Konzole vypíše `Shape hidden? True`, což dokazuje, že příznak byl zachován.

## Časté problémy a jak se jim vyhnout

| Problém | Příčina | Řešení |
|---------|---------|--------|
| Tvar je stále viditelný po uložení | `Hidden` není nastaveno nebo nastaveno po uložení | Zajistěte, aby `ellipse.Hidden = true;` běželo **před** `doc.Save()`. |
| Barva výplně není aplikována | `FillColor` přiřazeno před vytvořením tvaru | Přiřaďte `FillColor` **po** tom, co `InsertShape` vrátí objekt `Shape`. |
| DOCX se nepodaří otevřít | Neshodná verze Aspose.Words vůči .NET runtime | Použijte nejnovější Aspose.Words NuGet balíček, který cílí na .NET 6+. |
| Příznak hidden ignorován ve starších verzích Wordu | Word < 2010 | Zvažte použití jiné techniky (např. nastavení `WrapType` tvaru na `None` a jeho přesunutí mimo stránku). |

## Pro tip: Opětovné použití skrytých tvarů jako zástupců

Můžete uložit skryté tvary v šablonovém dokumentu a později je nahradit viditelným obsahem. Protože je tvar skrytý, neovlivňuje rozvržení, dokud nenastavíte `Hidden = false`. Tento vzor je užitečný při generování smluv, kde pole pro podpis začíná skryté a po podpisu uživatele se stane viditelným.

## Další kroky

- **Odhalit skryté tvary**: Použijte `shape.Hidden = false;`, aby se elipsa objevila za běhu.  
- **Změnit typ tvaru**: Nahraďte `ShapeType.Ellipse` za `ShapeType.Rectangle`, `ShapeType.Polygon` atd., aby vyhovoval vašemu použití.  
- **Přidat text uvnitř tvaru**: Vložte `TextBox` do vlastnosti `TextBox` tvaru pro popsané zástupce.  
- **Kombinovat s hromadnou korespondencí**: Umístěte skryté tvary do šablony hromadné korespondence a přepínejte viditelnost podle záznamu.  

Prozkoumání těchto témat posiluje vaši znalost pracovních postupů **create hidden shape docx** a rozšiřuje možnosti automatizované generace dokumentů.

## Závěr

Nyní máte kompletní, připravenou metodu pro **create hidden shape docx** soubory, **nastavit barvu výplně tvaru** pro ladění a **skrýt tvar v dokumentu Word**, aby koncový uživatel viděl jen obsah, který zamýšlíte. Poskytnutý kód funguje ihned po nasazení a vysvětlení pokrývají jak „jak“, tak „proč“, což zajišťuje, že můžete řešení přizpůsobit složitějším scénářům.

Neváhejte experimentovat s různými tvary, barvami a pravidly viditelnosti a sdílet své výsledky v komentářích. Šťastné kódování!
