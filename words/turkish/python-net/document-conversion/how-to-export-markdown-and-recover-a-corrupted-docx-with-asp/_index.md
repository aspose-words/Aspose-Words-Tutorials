# Markdown dışa aktarma ve bozuk bir DOCX'i Aspose.Words ile kurtarma

Eğer hasar görmüş olabilecek bir Word dosyasından **markdown dışa aktarma** ihtiyacınız varsa, bu kılavuz size tam adımları gösterir. Ayrıca **belge kurtarma**, **docx'i txt'ye dışa aktarma** ve **Word'ü pdf olarak kaydetme** konularını Aspose.Words for Python API'si kullanarak kapsar.

Bir bozuk DOCX'i kurtarma modunda yükleme, denklemleri koruyarak Markdown'a dönüştürme, aynı içeriği düz metin olarak kaydetme, erişilebilir bir PDF oluşturma ve son dışa aktarmadan önce bir şeklin gölgesini ayarlama adımlarını adım adım göreceksiniz. Harici araçlara gerek yok—sadece Aspose.Words ve birkaç Python satırı yeterli.

## Önkoşullar

* Python 3.8 ve üzeri
* `aspose-words` paketi (`pip install aspose-words`)
* Bozuk olabilecek bir DOCX dosyası (veya test için herhangi bir normal DOCX)
* Python fonksiyonları ve sınıfları hakkında temel bilgi

> **Pro ipucu:** Orijinal DOCX'in bir yedeğini tutun; kurtarma modu bellek içindeki temsili değiştirir ancak kaynağa geri yazmaz.

## Adım 1: Bozuk DOCX'i kurtarma

İlk engel dosyayı güvenli bir şekilde yüklemektir. Aspose.Words, kırık bir belge yapısını yeniden oluşturmayı deneyen bir `RecoveryMode.RECOVER_CORRUPTED` bayrağı sağlar.

```python
import aspose.words as aw

# Load the file in recovery mode
load_opts = aw.LoadOptions()
load_opts.recovery_mode = aw.RecoveryMode.RECOVER_CORRUPTED
doc = aw.Document("YOUR_DIRECTORY/input.docx", load_opts)
```

**Neden önemli:**  
Bir DOCX kısmen hasar gördüğünde—eksik parçalar, bozuk XML veya hatalı ilişkiler—standart yükleme bir istisna fırlatır. Kurtarma modu okuyamayan parçaları atarak geri kalanını korur; bu, sonraki **docx'i txt'ye dışa aktarma** veya **Word'ü pdf olarak kaydetme** işlemleri için hayati öneme sahiptir.

### Yaygın kenar durumu
Eğer belge onarımın ötesindeyse, `doc` hâlâ bir uyarı kaydıyla oluşturulur. `doc.is_dirty` özelliğini inceleyerek kurtarma sırasında içerikte bir değişiklik olup olmadığını görebilirsiniz.

## Adım 2: Aspose.Words ile markdown dışa aktarma

Markdown, birçok statik site üreticisi ve dokümantasyon aracının sevdiği hafif bir işaretleme dilidir. Aspose.Words, denklemleri LaTeX olarak tutarak Markdown üretebilir; bu da teknik dokümantasyon için mükemmeldir.

```python
# Configure Markdown export options
md_opts = aw.MarkdownSaveOptions()
md_opts.office_math_export_mode = aw.OfficeMathExportMode.LATEX

# Save as Markdown
doc.save("YOUR_DIRECTORY/output.md", md_opts)
```

**Ne elde edersiniz:**  
* Başlıklar, listeler ve tablolar Markdown sözdizimine dönüştürülmüş düz metin.  
* Her Word denklemi LaTeX bloğu (`$$ … $$`) olarak render edilir, böylece matematik sonraki araçlarda düzenlenebilir kalır.

### Çıktıyı doğrulama
`output.md` dosyasını herhangi bir editörde açın. Şuna benzer bir şey görmelisiniz:

```markdown
# Title of the Document

This is a paragraph with **bold** text.

$$
\int_{0}^{\infty} e^{-x} dx = 1
$$
```

Farklı bir denklem formatına (ör. MathML) ihtiyacınız varsa, `office_math_export_mode` değerini buna göre değiştirin.

## Adım 3: Denklemleri koruyarak docx'i txt'ye dışa aktarma

Düz metin dosyaları hızlı aramalar veya doğal dil işleme hatlarına besleme için kullanışlıdır. Aynı `OfficeMathExportMode.LATEX` ayarı `.txt` dışa aktarmada da çalışır ve okunabilir LaTeX satır içi sağlar.

```python
txt_opts = aw.TxtSaveOptions()
txt_opts.office_math_export_mode = aw.OfficeMathExportMode.LATEX

doc.save("YOUR_DIRECTORY/output.txt", txt_opts)
```

**Neden kopyala‑yapıştır yerine bunu kullanmalısınız?**  
Manuel kopyala‑yapıştır genellikle gizli karakterleri atar ve denklemlerin bütünlüğünü kaybeder. Bu **docx'i txt'ye dışa aktarma** yöntemi, her denklemin bir LaTeX snippet'i olarak görünmesini garantiler; böylece sonraki işleme hazır olur.

## Adım 4: Daha iyi erişilebilirlik için satır içi şekillerle Word'ü PDF olarak kaydetme

PDF, yayıncılıkta de‑facto formattır. Bir Word belgesi yüzen görseller veya diyagramlar içerdiğinde, bazı okuyucular bunları doğru yorumlayamayabilir. `export_floating_shapes_as_inline_tag` ayarı, bu şekilleri satır içi hâle getirerek erişilebilirliği ve düzen tutarlılığını artırır.

```python
pdf_opts = aw.PdfSaveOptions()
pdf_opts.export_floating_shapes_as_inline_tag = True

doc.save("YOUR_DIRECTORY/output.pdf", pdf_opts)
```

**Sonuç:**  
Orijinal düzeni yansıtan bir PDF, ancak tüm şekiller artık metin akışının bir parçası. Bu, ekran okuyucular için özellikle faydalıdır; çünkü satır içi öğeler okuma sırasının bir parçası olarak değerlendirilir.

### Büyük belgeler için ipucu
PDF'leri toplu olarak üretirken aynı `PdfSaveOptions` örneğini yeniden kullanın; gereksiz nesne oluşturmayı önler.

## Adım 5: Son PDF'den önce bir şeklin gölgesini ince ayar yapma

Yayınlamadan önce görsel detayları—örneğin bir logonun gölgesi—ayarlamanız gerekebilir. Aşağıdaki örnek, ilk şekli alır, gölge özelliklerini değiştirir ve yeni bir PDF olarak kaydeder.

```python
# Retrieve the first shape in the document
shape = doc.get_child(aw.NodeType.SHAPE, 0, True).as_shape()

# Adjust shadow settings
shape.shadow.blur_radius = 5.0   # Soft blur
shape.shadow.distance = 2.0     # Distance from shape edge
shape.shadow.opacity = 0.6      # 60% opacity

# Save the shadow‑enhanced PDF
doc.save("YOUR_DIRECTORY/shadowed.pdf", pdf_opts)
```

**Bunun yaptığı:**  
* `blur_radius` gölgenin ne kadar bulanık göründüğünü kontrol eder.  
* `distance` gölgeyi şekilden uzaklaştırarak derinlik oluşturur.  
* `opacity` gölgeyi yarı saydam yapar, bu genellikle daha profesyonel görünür.

İndeks değerini `get_child` içinde değiştirerek bu bloğu istediğiniz herhangi bir şekil için tekrarlayabilirsiniz.

## Hızlı kopyala‑yapıştır için tam betik

Aşağıda tüm adımları birleştiren, çalıştırılabilir tam betik yer alıyor. `YOUR_DIRECTORY` kısmını dosyalarınızın bulunduğu yol ile değiştirin.

```python
import aspose.words as aw

# -------------------------------------------------
# 1️⃣ Recover a possibly corrupted DOCX
# -------------------------------------------------
load_opts = aw.LoadOptions()
load_opts.recovery_mode = aw.RecoveryMode.RECOVER_CORRUPTED
doc = aw.Document("YOUR_DIRECTORY/input.docx", load_opts)

# -------------------------------------------------
# 2️⃣ Export to Markdown (how to export markdown)
# -------------------------------------------------
md_opts = aw.MarkdownSaveOptions()
md_opts.office_math_export_mode = aw.OfficeMathExportMode.LATEX
doc.save("YOUR_DIRECTORY/output.md", md_opts)

# -------------------------------------------------
# 3️⃣ Export to plain text (export docx to txt)
# -------------------------------------------------
txt_opts = aw.TxtSaveOptions()
txt_opts.office_math_export_mode = aw.OfficeMathExportMode.LATEX
doc.save("YOUR_DIRECTORY/output.txt", txt_opts)

# -------------------------------------------------
# 4️⃣ Save as PDF (save word as pdf)
# -------------------------------------------------
pdf_opts = aw.PdfSaveOptions()
pdf_opts.export_floating_shapes_as_inline_tag = True
doc.save("YOUR_DIRECTORY/output.pdf", pdf_opts)

# -------------------------------------------------
# 5️⃣ Adjust first shape's shadow and re‑save PDF
# -------------------------------------------------
shape = doc.get_child(aw.NodeType.SHAPE, 0, True).as_shape()
shape.shadow.blur_radius = 5.0
shape.shadow.distance = 2.0
shape.shadow.opacity = 0.6
doc.save("YOUR_DIRECTORY/shadowed.pdf", pdf_opts)
```

Betik çalıştırıldığında şu dosyalar üretilir:

| Dosya | Amaç |
|------|------|
| `output.md` | LaTeX denklemleri içeren Markdown (**markdown dışa aktarma**) |
| `output.txt` | Düz metin sürümü (**docx'i txt'ye dışa aktarma**) |
| `output.pdf` | Erişilebilir PDF (**Word'ü pdf olarak kaydetme**) |
| `shadowed.pdf` | Özel stillendirilmiş şekilli PDF |

## Sıkça Sorulan Sorular

**S: Kurtarma modu eksik görselleri düzeltir mi?**  
C: Belge yapısını yeniden oluşturur ancak kayıp ikili görsel verisini yeniden yaratamaz. Görsel parçası eksikse, şekil boş kalır.

**S: Markdown yerine HTML'ye dışa aktarabilir miyim?**  
C: Evet—`aw.HtmlSaveOptions()` kullanın ve gerektiği gibi `office_math_export_mode` ayarlayın.

**S: Yüzen şekilleri yüzen olarak tutmam gerekirse ne olur?**  
C: `export_floating_shapes_as_inline_tag` ayarını atlayın veya `False` olarak ayarlayın.

**S: LaTeX dışa aktarımı MathJax ile uyumlu mu?**  
C: Kesinlikle. MathJax, Markdown ve Txt dışa aktarıcıları tarafından oluşturulan `$$ … $$` bloklarını sorunsuz render eder.

## Sonuç

Artık potansiyel olarak bozuk bir DOCX'ten **markdown dışa aktarma**, **docx'i txt'ye dışa aktarma**, **Word'ü pdf olarak kaydetme** ve Aspose.Words for Python kullanarak **belge kurtarma** adımlarını biliyorsunuz. Tam betik, sağlıklı ve hasarlı Word dosyaları için denklemleri, şekilleri ve görsel bütünlüğü koruyan güvenilir bir iş akışı sunar.

### Sonraki adımlar

* `OfficeMathExportMode` seçeneklerini, örneğin web‑odaklı akışlar için `MathML` gibi, keşfedin.  
* Bu iş akışını toplu işleme birleştirerek tüm DOCX klasörlerini dönüştürün.  
* Arşiv kalitesinde PDF'lere ihtiyacınız varsa `aw.PdfCompliance.PDF_A_1B`'yi inceleyin.
