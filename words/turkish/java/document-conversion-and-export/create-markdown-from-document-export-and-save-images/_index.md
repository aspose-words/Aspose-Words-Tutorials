# Alt klasördeki görsellerle docx'i markdown'a dönüştürme

Eğer **convert docx to markdown** yaparken gömülü tüm resimleri düzenli bir şekilde tutmak istiyorsanız, doğru yerdesiniz. Birçok geliştirici raporlar, kılavuzlar veya blog taslaklarını programlı olarak oluşturur ve çıktı dizininde dağılmış bir görüntü dosyası karmaşasıyla karşılaşır. Bu öğretici, Aspose.Words for .NET kullanarak belgeyi markdown'a dışa aktaran, her resmi ayrı bir *md‑resources* klasöründe saklayan ve yayınlamaya hazır son markdown dosyasını kaydeden temiz, geri çağırma‑tabanlı bir yaklaşımı gösterir.

> **Hızlı bakış:**  
> • `MarkdownSaveOptions` ayarlayın  
> • Görselleri yönlendirmek için bir `IResourceSavingCallback` uygulayın  
> • Yapılandırılmış seçeneklerle `Document.Save` çağırın  

Artık bir geri çağırmanın post‑processing'e göre neden tercih edildiğini anladığınıza göre, adım‑adım çözüme dalalım.

## Hızlı cevaplar
- **“convert docx to markdown” aslında ne yapar?** Word‑işleme işaretlemesini düz‑metin markdown'a dönüştürürken başlıkları, listeleri, tabloları ve görüntü referanslarını korur.  
- **Dönüşümü hangi kütüphane gerçekleştirir?** Aspose.Words for .NET, Microsoft Word yüklü olmadan çalışan tam yönetilen, sunucu‑tarafı bir API sunar.  
- **Herhangi bir görüntü‑işleme kodu yazmam gerekiyor mu?** Hayır; `IResourceSavingCallback` belirttiğiniz klasöre her görüntüyü kaydetmeyi halleder.  
- **Çıktı klasörünün adını değiştirebilir miyim?** Kesinlikle – `"md-resources/"` ifadesini istediğiniz herhangi bir göreli ya da mutlak yol ile değiştirin.  
- **Çözüm .NET 6 ve sonrası ile uyumlu mu?** Evet, .NET 6+, .NET 5, .NET Core 3.1 ve .NET Framework 4.7+ üzerinde çalışır.

## Convert docx to markdown nedir?
**Convert docx to markdown**, bir Microsoft Word belgesi (DOCX) alıp aynı içeriği markdown sözdizimiyle temsil eden bir markdown (`.md`) dosyası oluşturma sürecidir. Dönüşüm yapısal öğeleri korur ve isteğe bağlı olarak gömülü kaynakları (görseller gibi) çıkarır.

Dönüşüm, **35+ giriş ve çıkış formatını** destekleyen bir kütüphane olan Aspose.Words tarafından gerçekleştirilir—DOCX, PDF, HTML ve Markdown dahil—ve tüm dosyayı belleğe yüklemeden çok sayfalı belgelerle çalışmanıza olanak tanır.

Aspose.Words yüksek performanslı, doğru bir dönüşüm sağlar ve kaynak yönetimi üzerinde tam kontrol sunar. Post‑processing adımlarına gerek kalmaz, bellek kullanımı azalır ve görseller, tablolar ve stiller markdown çıktısında eksiksiz olarak yeniden üretilir.

## Docx'i markdown'a nasıl dönüştürürsünüz? 
Kaynak belgenizi `new Document("source.docx")` ile yükleyin, her görüntüyü `md-resources/` klasörüne yazan bir geri çağırma kullanacak şekilde `MarkdownSaveOptions` yapılandırın ve ardından `doc.Save("output.md", saveOptions)` çağırın. Bu üç‑adımlı desen dosyayı dönüştürür, görselleri çıkarır ve göreli görüntü bağlantılarına sahip temiz bir markdown dosyası üretir—tek bir metod çağrısı ile.

### Adım 1: markdown dönüşümü için kaydetme seçeneklerini yapılandırma

MarkdownSaveOptions, Aspose.Words'un bir belgeyi Markdown'a nasıl dönüştürdüğünü yapılandırır.

```csharp
// Step 1: Initialize Markdown save options
var markdownSaveOptions = new Aspose.Words.Saving.MarkdownSaveOptions();
```

```csharp
// Step 1: Initialize Markdown save options
var markdownSaveOptions = new Aspose.Words.Saving.MarkdownSaveOptions();
```

> **Neden önemli:**  
> `MarkdownSaveOptions` açıkça oluşturulmazsa, kütüphane görüntüleri doğrudan Markdown dosyasına Base64 dizgeleri olarak gömen varsayılan ayarlara geri döner. Bu dosyayı çok büyük yapar ve temiz bir *images* klasörü oluşturma amacını boşa çıkarır.

### Adım 2: Görselleri dışa aktarmak için bir resource‑saving callback tanımlama

`IResourceSavingCallback`, dışa aktarma sırasında her kaynağın (görsel, SVG) nerede kaydedileceğini kontrol etmenizi sağlar.

Şimdi kaydediciye **her görüntünün** nereye konulacağını söylüyoruz. `IResourceSavingCallback` arayüzü, dışa aktarma sırasında keşfedilen her kaynak (görsel, SVG, vb.) için tetiklenen bir kanca sağlar. Callback içinde şunları yaparız:
1. Hedef klasörün var olduğundan emin olun (`md-resources/`).  
2. `OutputFileName` değerini klasör ve orijinal kaynak adıyla ayarlayın.  

```csharp
// Step 2: Hook into the resource‑saving pipeline
markdownSaveOptions.ResourceSavingCallback = new Aspose.Words.Saving.IResourceSavingCallback(
    (args) =>
    {
        // All images will be placed in "md-resources" relative to the output .md file
        const string folder = "md-resources/";
        Directory.CreateDirectory(folder);          // Create folder if it doesn’t exist

        // Preserve the original file name (e.g., image001.png) but prepend the folder path
        args.OutputFileName = Path.Combine(folder, args.ResourceFileName);

        // Optional: you could also change the format here (e.g., convert BMP to PNG)
        // args.ResourceFileName = Path.ChangeExtension(args.ResourceFileName, ".png");
    });
```

> **Sık sorulan soru:** *Görselleri kaydetmek yerine gömmek istersem ne olur?*  
> Callback'i atlayın veya `args.OutputFileName = null;` ayarlayın – kaydedici otomatik olarak görüntüyü Base64 dizgesi olarak gömer.

> **Köşe durum:** Bazı eski belgeler aynı görüntü adlarını içerir. Yukarıdaki callback önceki dosyanın üzerine yazar. Bunu önlemek için bir GUID ekleyebilirsiniz:

```csharp
args.OutputFileName = Path.Combine(folder,
    $"{Path.GetFileNameWithoutExtension(args.ResourceFileName)}_{Guid.NewGuid()}{Path.GetExtension(args.ResourceFileName)}");
```

### Adım 3: belgeyi markdown olarak kaydedin ve çıktıyı doğrulayın

Seçenekler tamamen yapılandırıldığında, son çağrı, Markdown dosyasını ve ilişkili görselleri diske yazan tek satırlık bir komuttur.

```csharp
// Step 3: Perform the actual export
string outputPath = @"C:\Exports\MyReport.md";
doc.Save(outputPath, markdownSaveOptions);
```

Her şey yolunda giderse şunları göreceksiniz:
- `MyReport.md` – kaynağınızın Markdown temsili.  
- `md-resources/` – `.md` dosyasının yanında, çıkarılan tüm görselleri (ör. `image001.png`, `image002.jpg`) içeren bir klasör.  

**Örnek markdown snippet** (Aspose.Words tarafından otomatik oluşturulmuş):

```markdown
# Sample Report

Here is an introductory paragraph.

![Sample image](md-resources/image001.png)

More text follows...
```

[Örnek görüntü](md-resources/image001.png)

> **Pro ipucu:** Oluşturulan `.md` dosyasını VS Code'da veya herhangi bir Markdown önizleyicisinde açın; görüntüler, göreli yollar klasör yapısıyla eşleştiği için anında render edilmelidir.

## Tam, çalıştırılabilir örnek (ek kod blokları yok)
Aşağıda, yeni bir .NET projesine yapıştırıp çalıştırabileceğiniz bağımsız bir konsol programı bulunuyor. Basit bir Word belgesi oluşturur, bir görüntü ekler ve ardından **belgeden markdown oluşturur** ve görüntüyü bir alt klasörde saklar.

```csharp
using System;
using System.IO;
using Aspose.Words;
using Aspose.Words.Saving;

class Program
{
    static void Main()
    {
        // 1️⃣ Create a sample Word document with an image
        var doc = new Document();
        var builder = new DocumentBuilder(doc);
        builder.Writeln("Hello, this is a test document.");
        builder.InsertImage("sample-image.png"); // Ensure this file exists next to exe

        // 2️⃣ Configure markdown export options (see Step 1 & 2 above)
        var markdownOptions = new MarkdownSaveOptions();
        markdownOptions.ResourceSavingCallback = new IResourceSavingCallback(
            (args) =>
            {
                const string folder = "md-resources/";
                Directory.CreateDirectory(folder);
                args.OutputFileName = Path.Combine(folder, args.ResourceFileName);
            });

        // 3️⃣ Save as markdown (Step 3)
        string outputFolder = Path.Combine(Environment.CurrentDirectory, "output");
        Directory.CreateDirectory(outputFolder);
        string markdownPath = Path.Combine(outputFolder, "ExportedDoc.md");
        doc.Save(markdownPath, markdownOptions);

        Console.WriteLine($"✅ Markdown saved to: {markdownPath}");
        Console.WriteLine("📂 Images saved in: md-resources/");
    }
}
```

**Çalıştırdıktan sonra görmeniz gereken**:

```
✅ Markdown saved to: C:\MyProject\output\ExportedDoc.md
📂 Images saved in: md-resources/
```

`ExportedDoc.md` dosyasını açın – görüntü referansı `md-resources/sample-image.png`'e işaret edecek ve resim herhangi bir Markdown görüntüleyicide doğru şekilde gösterilecektir.

## Sıkça sorulan varyasyonlar

| Senaryo | Kodu nasıl uyarlarsınız |
|----------|----------------------|
| **Görsel dışa aktarmayı atla** (Base64 olarak göm) | `ResourceSavingCallback`'i tamamen atlayın veya callback içinde `args.OutputFileName = null;` ayarlayın. |
| **Görsel formatını değiştir** (ör. tüm PNG) | Callback içinde `args.ResourceFileName`'i değiştirin ve isteğe bağlı olarak yazmadan önce akışı dönüştürün. |
| **Özel klasör adı** | `"md-resources/"` ifadesini istediğiniz herhangi bir göreli ya da mutlak yol ile değiştirin. |
| **Toplu halde birden fazla belge** | `Document` nesnelerinin bir koleksiyonu üzerinde döngü yapın, aynı `MarkdownSaveOptions` örneğini yeniden kullanın (yalnızca klasörün temizlendiğinden veya her çalıştırmada benzersiz bir adla adlandırıldığından emin olun). |

## Yaygın sorunlar ve çözümler
- **Görseller markdown önizlemesinde görünmüyor** – Markdown'taki göreli yolun (`md-resources/image001.png`) `.md` dosyasına göre gerçek klasör konumuyla eşleştiğini doğrulayın.  
- **Aynı isimli görüntüler üzerine yazmaya neden oluyor** – Callback içinde benzersiz bir tanımlayıcı (GUID veya artan sayaç) ekleyerek dosya adlarının farklı olmasını sağlayın.  
- **Büyük belgeler bellek baskısına neden oluyor** – Kaydetmeden önce `Document.OptimizeResources()` kullanın; bu kullanılmayan akışları serbest bırakarak bellek tüketimini azaltır.  
- **Desteklenmeyen görüntü formatları** – Aspose.Words PNG, JPEG, BMP, GIF ve TIFF formatlarını destekler. Desteklenmeyen formatları kaynağa eklemeden önce bu formatlardan birine dönüştürün.
