# Java ile Word belgesinde halka (doughnut) grafiği oluşturma

Bir Word dosyası içinde **halka (doughnut) grafiği oluşturmanız** gerektiğinde, bu öğretici size tamamen çalıştırılabilir bir çözüm sunar. **Pasta grafiği ekleme**, onu halka grafiğine dönüştürme, **pasta grafiğini döndürme** ile daha iyi denge sağlama ve **pasta grafiğini biçimlendirme** adımlarını göreceksiniz. Sonunda, raporlar, kontrol panelleri veya otomatik e‑posta ekleri için kullanılabilecek profesyonel bir Word belgeniz olacak.

Grafiği programlı olarak oluşturmak, manuel kopyala‑yapıştır adımlarını ortadan kaldırır ve yüzlerce oluşturulan belgede tutarlı stil garantisi verir. Örnek, Java 8+ ile çalışan ve Microsoft Office kurulumu gerektirmeyen Aspose.Words for Java kütüphanesini kullanır. Standart bir JDK ve sevdiğiniz IDE dışındaki başka bir önkoşul yoktur.

## Önkoşullar

- Java Development Kit (JDK) 8 veya daha yeni bir sürüm  
- Bağımlılık yönetimi için Maven veya Gradle (öğreticide Maven kullanılmıştır)  
- Aspose.Words for Java kütüphanesi (test için ücretsiz deneme lisansı yeterlidir)  

Aspose.Words bağımlılığını `pom.xml` dosyanıza ekleyin:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-words</artifactId>
    <version>24.9</version> <!-- Use the latest stable version -->
</dependency>
```

> **Pro ipucu:** Değerlendirme filigranlarını kaldırmak için herhangi bir belge oluşturmadan önce lisansınızı `License license = new License(); license.setLicense("Aspose.Words.lic");` kodu ile kaydedin.

## Word belgesinde halka grafiği oluşturma

Temel iş akışı beş mantıksal adımdan oluşur. Her adım, kodun temiz ve yeniden kullanılabilir olmasını sağlamak için ayrı bir yönteme sarılmıştır.

```java
import com.aspose.words.*;
import com.aspose.words.drawing.*;

public class DoughnutChartDemo {

    public static void main(String[] args) throws Exception {
        // Step 1: create blank Word document
        Document doc = createBlankWordDocument();

        // Step 2: insert a pie chart (base for the doughnut)
        Chart chart = insertPieChart(doc, 400, 300);

        // Step 3: convert the pie chart into a doughnut and rotate it
        customizeChartAppearance(chart);

        // Step 4: apply additional formatting to the chart
        formatPieChart(chart);

        // Step 5: save the final document
        doc.save("output/DoughnutChartFormatted.docx");
        System.out.println("Document saved successfully.");
    }

    /** Step 1 – create blank Word document */
    private static Document createBlankWordDocument() {
        // Aspose.Words creates an empty document by default
        return new Document();
    }

    /** Step 2 – insert pie chart with given dimensions */
    private static Chart insertPieChart(Document doc, int width, int height) throws Exception {
        DocumentBuilder builder = new DocumentBuilder(doc);
        // ChartType.PIE creates a standard pie chart that we will later turn into a doughnut
        Chart chart = builder.insertChart(ChartType.PIE, width, height);
        // Populate the chart with sample data
        chart.getSeries().clear(); // Remove default series
        ChartSeries series = chart.getSeries().add("Sales", new String[]{"Q1", "Q2", "Q3", "Q4"},
                new double[]{15000, 23000, 18000, 27000});
        return chart;
    }

    /** Step 3 – rotate pie chart and make it a doughnut */
    private static void customizeChartAppearance(Chart chart) {
        // Explode the first slice for emphasis
        chart.getSeries().get(0).setExplode(20);
        // Convert the pie into a doughnut by setting a hole size (percentage of radius)
        chart.setHoleSize(30); // 30% hole creates a classic doughnut look
        // Rotate the chart so the largest slice starts at 45°
        chart.setRotationAngle(45);
    }

    /** Step 4 – additional formatting of the pie chart */
    private static void formatPieChart(Chart chart) {
        // Example: change the first slice color to a brand color
        chart.getSeries().get(0).getPoints().get(0).getFormat().setFillForegroundColor(Color.fromArgb(0xFF, 0x4A, 0x90));
        // Add a legend and position it at the bottom
        chart.setHasLegend(true);
        chart.getLegend().setPosition(LegendPosition.BOTTOM);
        // Set a title for the chart
        chart.setTitle("Quarterly Sales Distribution");
    }
}
```

### Kodun yaptığı şey

| Adım | İşlem | Gerekçe |
|------|--------|--------|
| **Boş Word belgesi oluştur** | `new Document()` | Her öğeyi kontrol edebilmeniz için temiz bir dosyayla başlanır. |
| **Pasta grafiği ekle** | `builder.insertChart(ChartType.PIE, …)` | Pasta grafiği temel şekildir; Aspose, delik boyutunu ayarlayarak halka grafiği sağlar. |
| **Pasta grafiğini döndür** | `chart.setRotationAngle(45)` | Döndürme, en büyük dilimi daha okunabilir bir konuma getirir. |
| **Pasta grafiğini biçimlendir** | `setExplode`, `setHoleSize`, renk, lejant | Görsel hiyerarşiyi iyileştirir ve kurumsal stil yönergelerine uyar. |
| **Belgeyi kaydet** | `doc.save("…/DoughnutChartFormatted.docx")` | Son .docx dosyasını diske yazar, dağıtıma hazır hâle getirir. |

## Halka grafiğe dönüştürmeden önce pasta grafiği ekleme

Aspose.Words doğrudan “halka grafiği ekle” metodunu sunmaz. Bunun yerine **pasta grafiği ekleyip** ardından özelliklerini değiştirirsiniz. Bu iki adımlı yaklaşım, veri serileri, dilim patlaması ve delik boyutu üzerinde tam kontrol sağlar. Başka bir yerde saf bir pasta grafiği gerekiyorsa, sadece `setHoleSize` çağrısını atlayın.

## Görsel denge için pasta grafiğini döndürme

Varsayılan yönelim, ilk dilimi 12 saat konumunda başlatır. Birçok iş raporunda en önemli dilimin daha doğal bir açı, örneğin 45 derece, konumunda başlaması istenir. `setRotationAngle(double angle)` metodu derece alır ve veri değerlerini etkilemeden tüm grafiği döndürür.

## Pasta grafiğini biçimlendirme ve görünümü özelleştirme

Halka grafiğe dönüştürmenin ötesinde, genellikle **pasta grafiği biçimlendirme** öğeleri de istenir:

- İlk dilimi **patlat** (`setExplode`) ve dikkat çek.  
- Her dilimi **renklendir** `getPoints().get(i).getFormat().setFillForegroundColor` ile.  
- **Lejant** konumlandırması (`setHasLegend`, `setPosition`) okuyucuların kategorileri yorumlamasını kolaylaştırır.  
- **Başlık** (`setTitle`) bir bakışta bağlam sağlar.  

Bu ayarlar isteğe bağlıdır; marka paletinize veya kurumsal şablonlarınıza göre özelleştirebilirsiniz.

## Boş Word belgesi oluşturma ve sonucu kaydetme

`createBlankWordDocument` yöntemi **boş word belgesi oluştur** adımını kapsüller. Bu mantığı izole tutmak, toplu işlemde birden fazla rapor üretirken yöntemi yeniden kullanmayı kolaylaştırır. Tüm özelleştirmeler tamamlandıktan sonra `doc.save` dosyayı standart Office Open XML formatında (`.docx`) yazar; bu dosya Microsoft Word, LibreOffice veya Google Docs’da kalite kaybı olmadan açılabilir.

### Beklenen çıktı

`main` metodunu çalıştırdığınızda konsola şu satır yazdırılır:

```
Document saved successfully.
```

Ve `output/DoughnutChartFormatted.docx` dosyası, *Quarterly Sales Distribution* başlıklı tek bir sayfa içerir; grafik dört dilim gösterir, ilk dilim patlatılmış, marka rengine boyanmış ve 45 derece döndürülmüştür.

## Yaygın varyasyonlar ve kenar durumları

| Durum | Ayarlama |
|-----------|------------|
| **Birden fazla veri serisi** | `chart.getSeries()` koleksiyonuna ek `ChartSeries` nesneleri ekleyin. |
| **Farklı grafik boyutu** | `insertPieChart` metodundaki `width` ve `height` argümanlarını değiştirin. |
| **Deliksiz (saf pasta)** | `chart.setHoleSize(…)` çağrısını atlayın veya `0` olarak ayarlayın. |
| **Büyük belgeler** | Belirli bir bölüm veya yer işareti içine grafiği eklemek için `DocumentBuilder` kullanın. |
| **Lisans ayarlanmamış** | Kütüphane değerlendirme modunda çalışır ve ilk sayfada filigran ekler. Filigranı kaldırmak için bir lisans kaydedin. |
