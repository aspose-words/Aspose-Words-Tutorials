### Yer imi ekleme

#### Genel Bakış
Yer imi eklemek, içeriğinizi daha sonra geri getirmek için işaretlemenizi sağlar.

#### Tanım
`DocumentBuilder` metin, tablo, görsel ve yer imlerini programlı olarak bir Word belgesine eklemenizi sağlayan imleç‑tabanlı API'dir.

#### Adımlar
**1. Document ve Builder'ı başlat:**  
```java
Document doc = new Document();
documentBuilder builder = new DocumentBuilder(doc);
```  

**2. Yer imini başlat ve bitir:**  
```java
builder.startBookmark("My Bookmark");
builder.write("Contents of My Bookmark.");
builder.endBookmark("My Bookmark");
doc.save(YOUR_OUTPUT_DIRECTORY + "Bookmarks.Insert.docx");
```  
*Why?* Belirli bir metni yer imiyle işaretlemek, gezinmeyi ve sonraki güncellemeleri çok basit hâle getirir.

### Yer imine erişme ve doğrulama

#### Genel Bakış
Bir yer imi ekledikten sonra, onu manipüle etmeden önce varlığını doğrulamanız sıkça gerekir.

#### Tanım
`Bookmark`, belge ağacında adlandırılmış bir konumu temsil eder; sorgulayabilir, taşıyabilir veya silebilirsiniz.

#### Adımlar
**1. Belgeyi yükle:**  
```java
Document doc = new Document(YOUR_DOCUMENT_DIRECTORY + "Bookmarks.Insert.docx");
```  

**2. Yer imi adını doğrula:**  
```java
String bookmarkName = doc.getRange().getBookmarks().get(0).getName();
if (!"My Bookmark".equals(bookmarkName)) {
    throw new AssertionError("Bookmark name does not match expected value.");
}
```  
*Why?* Doğrulama, yanlış bölüme istem dışı değişiklik yapılmasını önler.

### Yer imleri oluşturma, güncelleme ve yazdırma

#### Genel Bakış
Raporlar ve sözleşmelerde birden fazla yer imini aynı anda yönetmek yaygındır.

#### Adımlar
**1. Birden fazla yer imi oluştur:**  
```java
Document doc = new Document();
documentBuilder builder = new DocumentBuilder(doc);
for (int i = 1; i <= 3; i++) {
    String bookmarkName = "MyBookmark_" + i;
    builder.write("Text before bookmark.");
    builder.startBookmark(bookmarkName);
    builder.write(MessageFormat.format("Text inside {0}.", bookmarkName));
    builder.endBookmark(bookmarkName);
    builder.writeln("Text after bookmark.");
}
```  

**2. Yer imlerini güncelle:**  
```java
BookmarkCollection bookmarks = doc.getRange().getBookmarks();
bookmarks.get(0).setName("{bookmarks[0].Name}_NewName");
bookmarks.get("MyBookmark_2").setText("Updated text contents of {bookmarks[1].Name}");
```  

**3. Yer imi bilgilerini yazdır:**  
```java
for (int i = 0; i < bookmarks.getCount(); i++) {
    Bookmark bookmark = bookmarks.get(i);
    System.out.println(bookmark.getName() + ": " + bookmark.getText().trim());
}
doc.save(YOUR_OUTPUT_DIRECTORY + "UpdatedBookmarks.docx");
```  
*Why?* Yer imi adlarını veya metinlerini güncellemek, belgenin değişen iş kurallarına uyumlu kalmasını sağlar.

### Tablo sütun yer imleriyle çalışma

#### Genel Bakış
Tablolar içindeki yer imleri, veri‑odaklı raporlar için kesin hücreleri hedeflemenizi sağlar.

#### Adımlar
**1. Sütun yer imlerini tanımla:**  
```java
Document doc = new Document(YOUR_DOCUMENT_DIRECTORY + "Table column bookmarks.doc");
for (Bookmark bookmark : doc.getRange().getBookmarks()) {
    if (bookmark.isColumn()) {
        Row row = (Row) bookmark.getBookmarkStart().getAncestor(NodeType.ROW);
        if (row != null && bookmark.getFirstColumn() < row.getCells().getCount()) {
            System.out.println(MessageFormat.format("First Column: {0}", row.getCells().get(bookmark.getFirstColumn()).getText().trim()));
            System.out.println(MessageFormat.format("Last Column: {0}", row.getCells().get(bookmark.getLastColumn()).getText().trim()));
        }
    }
}
```  
*Why?* Bu mantık, tüm tabloyu ayrıştırmadan sütun‑özel verileri çıkarır.

### Bir belgede yer imlerini kaldırma

#### Genel Bakış
Artık ihtiyaç duyulmayan bir yer imi, belgeyi temiz tutar ve performansı artırır.

#### Adımlar
**1. Birden fazla yer imi ekle:**  
```java
Document doc = new Document();
documentBuilder builder = new DocumentBuilder(doc);
for (int i = 1; i <= 5; i++) {
    String bookmarkName = "MyBookmark_" + i;
    builder.startBookmark(bookmarkName);
    builder.write(MessageFormat.format("Text inside {0}.", bookmarkName));
    builder.endBookmark(bookmarkName);
    builder.insertBreak(BreakType.PARAGRAPH_BREAK);
}
```  

**2. Yer imlerini kaldır:**  
```java
BookmarkCollection bookmarks = doc.getRange().getBookmarks();
bookmarks.get(0).remove();
bookmarks.remove(bookmarks.get("MyBookmark_2"));
doc.getRange().getBookmarks().removeAt(1);
doc.getRange().getBookmarks().clear();
doc.save(YOUR_OUTPUT_DIRECTORY + "RemovedBookmarks.docx");
```  
*Why?* Etkin yer imi yönetimi dağınıklığı önler ve dosya boyutunu azaltır.

## Sıkça Sorulan Sorular

**Q: Mevcut bir belgeye tüm dosyayı yeniden yazmadan bir yer imi ekleyebilir miyim?**  
A: Evet. Belgeyi yükleyin, `DocumentBuilder` ile istediğiniz konuma gidin ve `startBookmark`/`endBookmark` çağırın. Ardından belgeyi kaydedin.

**Q: Çevresindeki metni silmeden bir yer imini nasıl silerim?**  
A: `Bookmark.remove()` kullanın; bu sadece yer imi işaretleyicisini siler, içeriği dokunulmaz bırakır.

**Q: Bir belgede tüm yer imi adlarını listelemek mümkün mü?**  
A: `doc.getRange().getBookmarks()` üzerinden döngü kurun ve her `Bookmark` nesnesinin `getName()` metodunu çağırın.

**Q: Aspose.Words şifre korumalı Word dosyalarını destekliyor mu?**  
A: Evet. Şifreyi `Document` yapıcısına şu şekilde geçirin: `new Document(path, new LoadOptions() {{ setPassword("pwd"); }})`.

**Q: Hangi Java sürümleri resmi olarak destekleniyor?**  
A: Aspose.Words for Java, Java 8'den Java 17'ye kadar tüm LTS sürümlerini destekler.
