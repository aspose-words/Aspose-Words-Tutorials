# Boş Word belgesi oluşturma ve C#'ta bir elips şekli gizleme

Eğer **boş bir Word belgesi oluşturmak** ve ardından bir grafik öğesini gizlemek istiyorsanız, bu kılavuz C# ile bunu tam olarak nasıl yapacağınızı gösterir. Elips ekleyen, konumlandıran, gizli olarak işaretleyen ve dosyayı kaydeden tam, çalıştırılabilir bir örnek göreceksiniz—hepsi sadece birkaç satır kodla.

Bu öğretici, proje kurulumundan son doğrulama adımına kadar her şeyi kapsar. Sonunda, ekranda veya yazdırmada hiç görünmeyen bir elipsin bulunduğu bir Word dosyası üretebileceksiniz; bu, meta veri, yer işareti veya herhangi bir görünmez işaretçi depolamak için kullanışlıdır.

## Önkoşullar

Başlamadan önce şunların yüklü olduğundan emin olun:

* .NET 6.0 SDK veya daha yeni bir sürüm  
* Bir C# geliştirme ortamı (Visual Studio 2022, Rider veya VS Code)  
* **Aspose.Words for .NET** NuGet paketi (`Install-Package Aspose.Words`)  

Bu araçlar, kod örneğinde kullanılan `Document` ve `DocumentBuilder` sınıflarını sağlar.

## Adım 1: Boş bir Word belgesi oluşturma

İlk işlem, boş bir `Document` nesnesi ve içerik eklemenizi sağlayan bir `DocumentBuilder` oluşturur.

```csharp
using Aspose.Words;
using Aspose.Words.Drawing;

// Step 1: Initialize an empty document and a builder
Document doc = new Document();
DocumentBuilder builder = new DocumentBuilder(doc);
```

`Document`, tüm `.docx` paketini temsil ederken, `DocumentBuilder` metin, şekil ve diğer nesneleri eklemek için akıcı bir API sunar. Boş bir belgeyle başlamak, eklediğiniz her öğe üzerinde tam kontrol sağlar.

## Adım 2: Elips ekleme

Elips, bir işaretçi olarak kullanılabilen bir vektör şeklidir. `InsertShape` yöntemi, şekil türünü ve genişlik/yüksekliğini puan cinsinden alır.

```csharp
// Step 2: Insert an ellipse shape of the desired size (100 pt × 50 pt)
Shape ellipse = builder.InsertShape(ShapeType.Ellipse, 100, 50);
```

Elips, imleç konumunda geçerli sayfada yer alır. Sayısal argümanları ayarlayarak boyutlarını değiştirebilirsiniz.

## Adım 3: Şekli konumlandırma

Ekleme işleminden sonra, `Left` ve `Top` özelliklerini ayarlayarak şekli sayfa içinde istediğiniz yere taşıyabilirsiniz; bu özellikler sayfa kenar boşluğuna göre puan cinsinden konumlandırma yapar.

```csharp
// Step 3: Position the shape on the page
ellipse.Left = 150; // distance from the left margin
ellipse.Top  = 100; // distance from the top margin
```

Bu koordinatlar, elipsi standart bir A4 sayfasının üst‑orta kısmına yerleştirir. Değerleri, düzen gereksinimlerinize göre ayarlayın.

## Adım 4: Şekli gizleme

Gizli bir nesne, belge açıldığında veya yazdırıldığında gösterilmez. `Hidden` bayrağını ayarlamak, şekli **gizli nesne** olarak işaretler.

```csharp
// Step 4: Hide the shape so it never appears
ellipse.Hidden = true;
```

Word, hem ekranda render hem de yazdırma çıktısı için gizli bayrağı dikkate alır. Şekil, belge yapısının bir parçası olarak kalır; böylece daha sonra kod aracılığıyla sorgulanabilir veya değiştirilebilir.

## Adım 5: Belgeyi kaydetme

Son olarak, belgeyi diske yazın. Yazma izniniz olan bir klasör seçin.

```csharp
// Step 5: Save the document to a .docx file
doc.Save(@"C:\Temp\HiddenEllipse.docx");
```

`HiddenEllipse.docx` dosyası artık gizli bir elips şekli içeren boş bir sayfa barındırıyor.

## Gizli elipsi doğrulama

Oluşturulan dosyayı Microsoft Word'de açın ve **Gizli metni göster** seçeneğini etkinleştirin (Dosya → Seçenekler → Görünüm). Elipsin hafif bir taslağını göreceksiniz. Seçeneği kapatırsanız şekil tamamen kaybolur ve `ellipse.Hidden = true` ifadesinin beklendiği gibi çalıştığını doğrular.

## Yaygın varyasyonlar ve kenar durumları

| Durum | Önerilen ayarlama |
|-----------|------------------------|
| **Farklı şekil** | `ShapeType.Ellipse` yerine `ShapeType.Rectangle`, `ShapeType.Arrow` vb. kullanın |
| **Birden fazla gizli nesne** | Her şekil için adım 2‑4'ü tekrarlayın; her birinin kendi `Hidden` bayrağı olabilir |
| **Farklı sayfa boyutu** | Şekli eklemeden önce `doc.FirstSection.PageSetup.PageWidth` ve `PageHeight` değerlerini ayarlayın |
| **Koşullu görünürlük** | Çalışma zamanında kodla değiştirmek için `Hidden` ile birlikte `Shape.Visible` kullanın |

**İpucu:** Tanımlama verilerini şeklin `AlternativeText` özelliğinde saklayın. Gizli olsa bile, daha sonra `doc.GetChildNodes(NodeType.Shape, true)` ile şekli alıp bu metne göre filtreleyebilirsiniz.

## Tam kaynak kodu

Aşağıda, kopyalayıp yapıştırıp çalıştırabileceğiniz tam program yer alıyor.

```csharp
using System;
using Aspose.Words;
using Aspose.Words.Drawing;

namespace HiddenShapeDemo
{
    class Program
    {
        static void Main()
        {
            // Create a new blank document and a builder
            Document doc = new Document();
            DocumentBuilder builder = new DocumentBuilder(doc);

            // Insert an ellipse shape (100 pt × 50 pt)
            Shape ellipse = builder.InsertShape(ShapeType.Ellipse, 100, 50);

            // Position the shape on the page
            ellipse.Left = 150;
            ellipse.Top  = 100;

            // Hide the shape so it is invisible in the UI and on print
            ellipse.Hidden = true;

            // Optional: add a description for later retrieval
            ellipse.AlternativeText = "Hidden marker for internal processing";

            // Save the document
            string outputPath = @"C:\Temp\HiddenEllipse.docx";
            doc.Save(outputPath);

            Console.WriteLine($"Document saved to {outputPath}");
        }
    }
}
```

**Beklenen çıktı:** Konsol kaydetme yolunu yazdırır ve `HiddenEllipse.docx` dosyası, gizli nesneler gösterilmediği sürece görünür grafik içermeyen boş bir sayfa olarak açılır.
