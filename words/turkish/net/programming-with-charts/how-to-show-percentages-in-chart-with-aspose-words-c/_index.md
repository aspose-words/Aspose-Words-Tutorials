# Aspose.Words C# ile Grafikte Yüzdeleri Gösterme

Karmaşık Office interop ile uğraşmadan **grafikte yüzde nasıl gösterilir** diye hiç merak ettiniz mi? Yalnız değilsiniz—birçok geliştirici, bir pasta veya halka grafiğine hızlı bir şekilde programatik olarak etiket eklemek istediklerinde bu sorunla karşılaşıyor. İyi haber? Aspose.Words for .NET ile bu veri etiketlerini sadece birkaç satırda etkinleştirebilirsiniz.

Bu öğreticide ayrıca **add data labels to pie chart** ve **how to enable chart data labels** konularını da ele alacağız, böylece görselleştirmeleriniz anında daha açıklayıcı hâle gelecek. Sonunda, yüzde değerleri dilimlerin dışına düzgün bir şekilde yerleştirilmiş, cilalı bir pasta grafiği gösteren hazır bir Word belgeniz (`.docx`) olacak.

## Prerequisites

Başlamadan önce şunların yüklü olduğundan emin olun:

- **Aspose.Words for .NET** (en son sürüm, ör. 24.9) NuGet üzerinden kurulu.
- İçinde bir pasta veya halka grafiği bulunan bir **ChartTemplate.docx** dosyası.  
  *(Eğer yoksa, basit bir Word belgesi oluşturun, bir pasta grafiği ekleyin ve `ChartTemplate.docx` olarak kaydedin.)*
- .NET 6.0 veya üzeri ve tercih ettiğiniz herhangi bir IDE (Visual Studio, Rider, VS Code).

Ek bir bağımlılık gerekmez—Aspose.Words her şeyi dahili olarak yönetir.

## How to Show Percentages in Chart – Step‑by‑Step

Aşağıda süreci altı net adıma bölüyoruz. Her adım, kopyalayıp‑yapıştırabileceğiniz tam C# kodunu ve **neden** yaptığımızın kısa bir açıklamasını içerir.

### Step 1: Load the Source Document

```csharp
using Aspose.Words;
using Aspose.Words.Drawing.Charts;

// Load the .docx that already holds a chart.
Document sourceDoc = new Document("YOUR_DIRECTORY/ChartTemplate.docx");
```

*Why?*  
`Document` herhangi bir Word işlemi için giriş noktasıdır. Şablonu yükleyerek şekiller, tablolar, metin ve tabii ki değiştireceğimiz grafiğe erişim sağlarız.

### Step 2: Grab the First Chart Shape

```csharp
// The chart lives inside a Shape node; retrieve it.
Chart chart = (Chart)sourceDoc.GetChild(NodeType.Shape, 0, true);
```

*Why?*  
Aspose grafikleri `Shape` nesneleri olarak depolar. `GetChild` belge ağacını dolaşır ve bulduğu ilk şekli döndürür; bizim durumumuzda düzenlemek istediğimiz pasta grafiği budur.

### Step 3: Confirm the Chart Type

```csharp
if (chart.ChartType == ChartType.Pie || chart.ChartType == ChartType.Doughnut)
{
    // Inside this block we’ll enable the data labels.
}
else
{
    throw new InvalidOperationException("The chart is not a Pie or Doughnut type.");
}
```

*Why?*  
Yüzde etiketleri yalnızca dairesel grafiklerde anlamlıdır. Bu kontrol, örneğin bir çubuk grafiğine `ShowPercentage` uygulamayı önleyerek hatalı ayar yapılmasını engeller.

### Step 4: Enable Data Labels and Show Percentages

```csharp
// Turn on data labels for the chart.
chart.HasDataLabel = true;

// Show the percentage value for each slice.
chart.DataLabel.ShowPercentage = true;
```

*Why?*  
`HasDataLabel` Aspose’a her veri noktası için bir etiket oluşturmasını söyler. `ShowPercentage` ayarı ise etiket içeriğinin bütün içindeki hesaplanmış payı olmasını sağlar—tam da **add data labels to pie chart** ihtiyacının karşılığıdır.

### Step 5: Position Labels Outside the Slices

```csharp
// Place the labels outside the pie slices for better readability.
chart.DataLabel.Position = ChartDataLabelPosition.OutSideEnd;
```

*Why?*  
Dilimin içindeki etiketler özellikle küçük dilimler için sıkışık görünebilir. `OutSideEnd`, Word arayüzünde gördüğünüz varsayılan “dışarı” stilini taklit eder ve grafiği temiz tutar.

### Step 6: Save the Updated Document

```csharp
sourceDoc.Save("YOUR_DIRECTORY/FormattedPieChart.docx");
```

*Why?*  
Kaydetme, tüm değişiklikleri yeni bir dosyaya yazar. `FormattedPieChart.docx` dosyasını Word’te açtığınızda yüzde değerlerinin her dilimin yanında göründüğünü göreceksiniz.

#### Expected Result

`FormattedPieChart.docx` dosyasını açtığınızda, pasta grafiği aşağıdaki (hayali ekran görüntüsü) gibi görünmelidir:

```
[ Pie chart with three slices ]
- Slice A – 45%
- Slice B – 30%
- Slice C – 25%
```

Tüm yüzde değerleri temel veri serisinden otomatik olarak hesaplanır ve etiketler her dilimin hemen dışına yerleştirilir.

## Common Variations & Edge Cases

| Durum | Ne Ayarlanmalı |
|-----------|----------------|
| **Multiple charts** in the same document | Loop through `sourceDoc.GetChildNodes(NodeType.Shape, true)` and cast each to `Chart` before applying the same logic. |
| **Bar or line chart** where you still want labels | Use `chart.DataLabel.ShowValue = true;` (or `ShowSeriesName`) instead of `ShowPercentage`. |
| **Custom number format** (e.g., “45 %”) | Set `chart.DataLabel.NumberFormat = "0%";` before saving. |
| **Large data sets** causing label overlap | Consider `chart.DataLabel.ShowLeaderLines = true;` to draw connector lines. |

> **Pro tip:** Eğer toplu olarak birçok belge üretiyorsanız, uygulama başlangıcında tek bir `Aspose.Words.License` nesnesi oluşturup lisansı tekrar tekrar yüklemekten kaynaklanan performans kaybını önleyin.

## Full Working Example

İşte tüm program bir arada, çalıştırmaya hazır:

```csharp
using System;
using Aspose.Words;
using Aspose.Words.Drawing.Charts;

class Program
{
    static void Main()
    {
        // 1️⃣ Load the template document.
        Document sourceDoc = new Document("YOUR_DIRECTORY/ChartTemplate.docx");

        // 2️⃣ Retrieve the first chart shape.
        Chart chart = (Chart)sourceDoc.GetChild(NodeType.Shape, 0, true);

        // 3️⃣ Ensure we’re dealing with a Pie or Doughnut chart.
        if (chart.ChartType != ChartType.Pie && chart.ChartType != ChartType.Doughnut)
        {
            Console.WriteLine("The selected shape is not a Pie/Doughnut chart.");
            return;
        }

        // 4️⃣ Enable data labels and show percentages.
        chart.HasDataLabel = true;
        chart.DataLabel.ShowPercentage = true;

        // 5️⃣ Position the labels outside the slices.
        chart.DataLabel.Position = ChartDataLabelPosition.OutSideEnd;

        // 6️⃣ Save the modified document.
        sourceDoc.Save("YOUR_DIRECTORY/FormattedPieChart.docx");

        Console.WriteLine("Chart updated successfully – percentages now visible!");
    }
}
```

Kodu kopyalayın, `YOUR_DIRECTORY` kısmını makinenizdeki gerçek yol ile değiştirin ve çalıştırın. Saniyeler içinde tamamen etiketlenmiş bir pasta grafiği içeren bir Word dosyanız olacak.
