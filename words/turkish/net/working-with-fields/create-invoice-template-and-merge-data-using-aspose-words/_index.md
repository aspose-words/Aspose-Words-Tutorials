# Fatura şablonu oluşturma ve Aspose.Words ile veri birleştirme

Hızlı bir şekilde **fatura şablonu oluşturmanız** gerekiyorsa, bu kılavuz tam olarak nasıl yapılacağını gösterir. İlk iki cümlenin sonunda, boş bir Word dosyasını tamamen doldurulmuş bir faturaya dönüştürmek için Aspose.Words'ün düşük‑kodlu mail‑merge API'sını kullanarak tam iş akışını öğreneceksiniz.

Fatura oluşturma, faturalama sistemleri, ERP entegrasyonları ve otomatik raporlama için yaygın bir gereksinimdir. Bu öğreticide **mail merge nasıl yapılır**, **Word şablonu nasıl doldurulur**, **veri nasıl Word'e birleştirilir** ve sonunda **birleştirilmiş belge nasıl kaydedilir** konularını öğreneceksiniz — tüm bunlar birkaç C# satırıyla.

## Başaracaklarınız

* Müşteri, tarih, satır öğeleri ve toplam için birleştirme alanları içeren yeniden kullanılabilir bir Word şablonu (`InvoiceTemplate.docx`).
* Şablonu yükleyen, güçlü tipli bir veri nesnesi enjekte eden ve sonucu `Invoice_001.docx` dosyasına yazan bir C# programı.
* Boş koleksiyonlar, özel veri tipleri ve dosya yolu işleme gibi uç durumlar hakkında bilgi.

### Önkoşullar

| Gereksinim | Neden Önemlidir |
|-------------|----------------|
| .NET 6 or later | Aspose.Words for .NET, .NET 6+ destekler ve bu kılavuzda kullanılan düşük‑kodlu API'yi sağlar. |
| Aspose.Words for .NET NuGet package (`Aspose.Words`) | `Document`, `MailMerger` ve ilgili tipleri sağlar. |
| Basic C# knowledge | Anonim nesneler ve LINQ'i anlamak için gereklidir. |
| Visual Studio 2022 (or any IDE) | Düzenleme ve hata ayıklamayı basitleştirir. |

> **Pro ipucu:** NuGet paketini Package Manager Console üzerinden kurun:  
> `Install-Package Aspose.Words`

## Düşük‑kodlu mail merge ile fatura şablonu nasıl oluşturulur

İlk adım, daha sonra geçireceğiniz veri nesnesinin özellikleriyle eşleşen birleştirme alanları içeren bir Word dosyası oluşturmaktır. Dosyayı `InvoiceTemplate.docx` olarak, kontrol ettiğiniz bir klasöre kaydedin (ör. `C:\Invoices\Template`).

| Birleştirme alanı | Word'deki örnek yer tutucu |
|-------------------|----------------------------|
| CustomerName | «CustomerName» |
| InvoiceDate | «InvoiceDate» |
| Items (repeating) | «Items.Description», «Items.Qty», «Items.Price» |
| Total | «Total» |

> **Neden önemli:** Düşük‑kodlu API, veri kaynağının özellik adlarını birleştirme alanlarıyla otomatik olarak eşleştirir. İsimlerin aynı tutulması, manuel alan‑özellik eşlemesini ortadan kaldırır ve çalışma zamanı hatalarını azaltır.

## Adım 1: Fatura şablonunu yükle

```csharp
using Aspose.Words;
using Aspose.Words.LowCode;   // Low‑code mail‑merge API

// Load the Word file that contains the merge fields.
Document template = new Document(@"C:\Invoices\Template\InvoiceTemplate.docx");
```

`Document` sınıfı, tüm Word dosyasını temsil eder. Bir kez yüklemek, aynı şablonu birçok fatura için yeniden kullanmanıza olanak tanır.

## Adım 2: Veri kaynağını hazırlayın

Birleştirme alanlarını yansıtan anonim bir nesne oluşturun. Düşük‑kodlu API, diziler ve iç içe koleksiyonlar dahil olmak üzere herhangi bir .NET nesnesiyle çalışabilir.

```csharp
var invoiceData = new
{
    CustomerName = "Acme Corp",
    InvoiceDate = DateTime.Today,
    Items = new[]
    {
        new { Description = "Widget A", Qty = 10, Price = 9.99M },
        new { Description = "Widget B", Qty = 5,  Price = 19.95M }
    },
    Total = 199.85M
};
```

**Neden bu çalışır:**  
* Özellik adları (`CustomerName`, `InvoiceDate`, `Items`, `Total`) şablondaki birleştirme alanlarıyla eşleşir.  
* `Items` nesnelerden oluşan bir dizi olduğundan, mail merger her öğe için tablo satırını otomatik olarak tekrar eder.  
* Para değerleri için `decimal` (`M` eki) kullanmak, kayan nokta yuvarlama sorunlarını önler.

### Boş koleksiyonların işlenmesi

Bir faturada satır öğesi yoksa, boş bir dizi gönderin:

```csharp
Items = new object[0]
```

Düşük‑kodlu motor, tekrar eden bölümü basitçe atlayacak ve tablo başlığını olduğu gibi bırakacaktır.

## Adım 3: Düşük‑kodlu mail merger'ı başlatın

```csharp
MailMerger merger = new MailMerger(template);
```

`MailMerger`, Aspose.Words ile **mail merge nasıl yapılır** konusunda giriş noktasıdır. Şablonu okur, veriyi bağlar ve tek bir çağrıda nihai belgeyi hazırlar.

## Adım 4: Birleştirmeyi çalıştır – tek satırda Word şablonunu doldurun

```csharp
Document mergedDocument = merger.Execute(invoiceData);
```

* Bu satır **Word şablonunu doldurur** ve yeni bir `Document` örneği (`mergedDocument`) oluşturur.  
* Tüm birleştirme alanları değiştirilir, tekrar eden bölümler genişletilir ve ortaya çıkan belge tamamen bellek içinde bulunur.

### Uç durum: Özel biçimlendirme

Belirli bir tarih formatına ihtiyacınız varsa, birleştirmeden önce özel bir biçimlendirici ekleyin:

```csharp
merger.Options.DateFormat = "MMMM dd, yyyy"; // e.g., "October 07, 2026"
```

## Adım 5: Birleştirilmiş belgeyi kaydedin

```csharp
mergedDocument.Save(@"C:\Invoices\Output\Invoice_001.docx");
```

**save merged document** çağrısı, tamamen doldurulmuş faturayı diske yazar. Dosya artık Microsoft Word'de açılabilir, e-posta eki olarak gönderilebilir veya PDF'ye dönüştürülebilir.

### Çıktıyı doğrulama

`Invoice_001.docx` dosyasını açın. Şunları görmelisiniz:

* **CustomerName** *Acme Corp* ile değiştirilmiş  
* **InvoiceDate** seçilen formatta bugünün tarihini gösteriyor  
* *Widget A* (10 × 9.99) ve *Widget B* (5 × 19.95) için bir tablo satırı  
* **Total** *199.85* gösteriyor

Herhangi bir alan değişmeden kalırsa (ör. hâlâ «CustomerName» gösteriyorsa), özellik adlarının şablondaki birleştirme alanı adlarıyla tam olarak eşleştiğinden emin olun.

## Tam çalıştırılabilir örnek

Aşağıda, yeni bir konsol projesine kopyalayıp yapıştırabileceğiniz tam program bulunmaktadır.

```csharp
using System;
using Aspose.Words;
using Aspose.Words.LowCode;   // Low‑code mail‑merge API

namespace InvoiceGenerator
{
    class Program
    {
        static void Main()
        {
            // 1️⃣ Load the template
            Document template = new Document(@"C:\Invoices\Template\InvoiceTemplate.docx");

            // 2️⃣ Build the data source
            var invoiceData = new
            {
                CustomerName = "Acme Corp",
                InvoiceDate = DateTime.Today,
                Items = new[]
                {
                    new { Description = "Widget A", Qty = 10, Price = 9.99M },
                    new { Description = "Widget B", Qty = 5,  Price = 19.95M }
                },
                Total = 199.85M
            };

            // 3️⃣ Initialise the mail merger
            MailMerger merger = new MailMerger(template);

            // Optional: customise date format
            merger.Options.DateFormat = "MMMM dd, yyyy";

            // 4️⃣ Perform the merge (populate word template)
            Document mergedDocument = merger.Execute(invoiceData);

            // 5️⃣ Save the resulting file (save merged document)
            mergedDocument.Save(@"C:\Invoices\Output\Invoice_001.docx");

            Console.WriteLine("Invoice generated successfully.");
        }
    }
}
```

Programı çalıştırın (`dotnet run`). Konsol *Invoice generated successfully.* mesajını yazdırır ve dosya `C:\Invoices\Output` içinde görünür.
