# C#'ta AI sağlayıcılarıyla Word belgesini özetleme

Word belgesini **hızlı bir şekilde özetlemeniz** gerektiğinde, bu kılavuz tam olarak nasıl yapılacağını gösterir. **AI sağlayıcıyı seçebileceğiniz** (OpenAI veya Google) ve IDE'nizden çıkmadan **büyük belgeyi özetleme** senaryosunu yönetebileceğiniz tam, çalıştırılabilir bir örnek göreceksiniz.

Word belgesini özetlemek, bilgi tabanı botları, rapor özetleri veya otomatik e‑posta özetleri oluştururken yaygın bir görevdir. Aşağıdaki bölümlerde hangi NuGet paketini kurmanız gerektiğini, bir `.docx` dosyasını nasıl yükleyeceğinizi, özetleyiciyi nasıl yapılandıracağınızı ve sonucu nasıl çıktıya alacağınızı – hepsini sade C# ile öğreneceksiniz.

## Gereksinimler

| Gereksinim | Açıklama |
|-------------|----------|
| .NET 6 SDK veya daha yeni bir sürüm | C# örneği için çalışma zamanını sağlar |
| Visual Studio 2022 (veya herhangi bir IDE) | NuGet paketlerini eklemeyi ve konsol uygulamasını çalıştırmayı kolaylaştırır |
| `GroupDocs.Summarization` NuGet paketi | Kodda kullanılan `DocumentSummarizer` API'sini sağlar |
| İnternet bağlantısı | AI sağlayıcısının (OpenAI veya Google) metni işleyebilmesi için gereklidir |

> **Pro ipucu:** **Büyük belgeyi özetleme** dosyaları (100 KB üzeri) ile çalışıyorsanız, tüm dosyayı belleğe yüklemeyi önlemek için seçeneklerde akış (streaming) modunu etkinleştirin.

## Word belgesini adım adım özetleme

### Adım 1: Özetleme kütüphanesini kurun

Package Manager Console’u açın ve şu komutu çalıştırın:

```powershell
Install-Package GroupDocs.Summarization
```

`GroupDocs.Summarization` kütüphanesi, altındaki AI çağrılarını soyutlayarak sağlayıcıları iş mantığınızı değiştirmeden geçiş yapmanızı sağlar.

### Adım 2: Word belgesini yükleyin

```csharp
using GroupDocs.Summarization;
using GroupDocs.Summarization.Options;

// Step 2: Load the source document
Document doc = new Document("YOUR_DIRECTORY/Report.docx");
```

`Document` sınıfı `.docx` dosyasını okur ve özetleme için hazır hâle getirir. Dosya büyükse, kütüphane otomatik olarak bellek‑verimli bir ayrıştırıcı kullanır.

### Adım 3: Özetleyici seçeneklerini yapılandırın ve **AI sağlayıcıyı seçin**

```csharp
// Step 3: Set up summarization options (choose the AI provider)
SummarizerOptions options = new SummarizerOptions
{
    Provider = SummarizerProvider.OpenAI   // or SummarizerProvider.Google
};
```

- `Provider = SummarizerProvider.OpenAI` OpenAI’nin GPT‑4 modelini seçer.  
- `Provider = SummarizerProvider.Google` Google’ın Gemini modelini seçer; **Google ile özetleme** yaparken çok‑dilli destek açısından idealdir.

**AI sağlayıcıyı** maliyet, gecikme süresi veya dil gereksinimlerine göre seçersiniz. Aynı `options` nesnesi her iki sağlayıcı için de çalışır, kodunuzu temiz tutar.

### Adım 4: Özeti oluşturun – **büyük belgeyi özetleme** desteği

```csharp
// Step 4: Generate the summary using the selected provider
string summary = DocumentSummarizer.Summarize(doc, options);
```

**Büyük belgeyi özetleme** dosyalarında kütüphane içeriği AI servisine akış (stream) eder, bellek taşması hatalarını önler. `Summarize` metodu, en ilgili cümleleri içeren düz metin bir dize döndürür.

### Adım 5: Sonucu çıktı olarak alın

```csharp
// Step 5: Output the generated summary
Console.WriteLine("Summary:\n" + summary);
```

Programı çalıştırdığınızda, orijinal Word dosyasının özünü yakalayan kısa bir paragraf ekrana basılır.

## Tam çalıştırılabilir örnek

```csharp
using System;
using GroupDocs.Summarization;
using GroupDocs.Summarization.Options;

namespace WordSummarizerDemo
{
    class Program
    {
        static void Main(string[] args)
        {
            // Load the source Word document
            Document doc = new Document("YOUR_DIRECTORY/Report.docx");

            // Choose the AI provider (OpenAI or Google)
            SummarizerOptions options = new SummarizerOptions
            {
                Provider = SummarizerProvider.Google   // Change to OpenAI if you prefer
            };

            // Generate the summary – works for both small and large documents
            string summary = DocumentSummarizer.Summarize(doc, options);

            // Display the summary in the console
            Console.WriteLine("Summary:\n" + summary);
        }
    }
}
```

**Beklenen çıktı**

```
Summary:
The quarterly sales increased by 12% driven by the new product line, while operational costs fell 3% due to efficiency gains. The report also highlights upcoming market expansion in APAC and recommends allocating additional budget to R&D.
```

Tam metin, **AI sağlayıcıyı seçtiğiniz** modele bağlı olarak farklılık gösterebilir, ancak yapı aynı kalır.

## **Büyük belgeyi özetleme** senaryosunu ele alma

Kaynak `.docx` 5 MB’ı aşıyorsa, aşağıdaki ayarlamaları göz önünde bulundurun:

1. **Parçalama (chunking) etkinleştir** – kütüphane belgeyi AI servisine göndermeden önce 5 KB bloklara ayırır.  
2. **`MaxSentences`** değerini artır – daha uzun bir özet istiyorsanız `SummarizerOptions` içinde bu değeri yükseltin.  
3. **`Timeout`** değerini yükselt – daha uzun işleme sürelerine izin vermek için zaman aşımını artırın.

```csharp
options.MaxSentences = 8;          // Return up to 8 sentences
options.EnableChunking = true;    // Essential for very large files
options.Timeout = TimeSpan.FromMinutes(2);
```

Bu ince ayarlar, **büyük belgeyi özetleme** işleminin hızlı ve güvenilir kalmasını sağlar.

## **Google ile özetleme**yi etkili bir şekilde yapma

Google’ın Gemini modeli çok‑dilli içerik ve özlü ifadelerde üstündür. En iyi sonuçları almak için:

- Belge İngilizce dışı bir dil içeriyorsa **dil belirt** (isteğe bağlı):
  ```csharp
  options.Language = "es"; // Spanish
  ```
- Yaratıcılığı kontrol etmek için **temperature** değerini ayarla:
  ```csharp
  options.Temperature = 0.3; // More deterministic output
  ```

**Google ile özetleme** yaptığınızda, hizmet OpenAI’ye göre biraz daha kısa ama çok odaklanmış bir özet döndürebilir. Hangi sağlayıcının ihtiyacınıza daha uygun olduğunu görmek için her iki sağlayıcıyı da örnek bir belgede test edin.

## Yaygın hatalar ve önleme yolları

| Belirti | Neden | Çözüm |
|---------|-------|------|
| Boş özet | Sağlayıcı anahtarı eksik veya ağ engellenmiş | API anahtarlarını ortam değişkenlerinde doğrulayın ve dışa giden HTTPS trafiğine izin verildiğinden emin olun |
| Kesilmiş metin | Belge sağlayıcı token limitini aşıyor | `EnableChunking`i etkinleştirin veya kütüphane destekliyorsa `MaxTokens` değerini artırın |
| Beklenmeyen dil | Yanlış `Language` seçeneği | Seçeneği kaldırın veya belgenin gerçek diline ayarlayın |

Bu sorunları erken aşamada çözmek, özellikle **AI sağlayıcıyı seçtiğiniz** üretim ortamlarında hata ayıklama süresini azaltır.

## Sonuç

Artık C#’ta esnek bir AI katmanı kullanarak **Word belgesini özetleme** yöntemini biliyorsunuz. `SummarizerOptions`ı yapılandırarak **AI sağlayıcıyı seçebilir**, **büyük belgeyi özetleme** iş yükünü yönetebilir ve çok‑dilli ihtiyaçlar için **Google ile özetleme** yapabilirsiniz. `MaxSentences`, `Temperature` ve parçalama ayarlarıyla çıktıyı senaryonuza göre ince ayar yapın.

### Sonraki adımlar

- `DocumentSummarizer`ın anahtar kelime çıkarma gibi gelişmiş özelliklerini keşfedin.  
- Özetlemeyi **belge çevirisi** ile birleştirerek çok‑dilli özetler oluşturun.  
- Özeti bir web API’ye entegre edin; böylece diğer servisler talep üzerine özet alabilir.

İyi kodlamalar ve AI‑destekli belge özetlemenin gücünün tadını çıkarın!
