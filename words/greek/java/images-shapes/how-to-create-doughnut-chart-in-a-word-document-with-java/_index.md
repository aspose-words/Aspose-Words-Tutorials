# Πώς να δημιουργήσετε διάγραμμα δακτυλίου σε έγγραφο Word με Java

Αν χρειάζεστε **δημιουργία διαγράμματος δακτυλίου** μέσα σε αρχείο Word, αυτό το tutorial σας δείχνει μια πλήρη, έτοιμη‑για‑εκτέλεση λύση. Θα δείτε πώς να **εισάγετε διάγραμμα πίτας**, να το μετατρέψετε σε δακτύλιο, **περιστρέψετε το διάγραμμα πίτας** για καλύτερη ισορροπία, και **μορφοποιήσετε το διάγραμμα πίτας** ώστε να ταιριάζει με την επωνυμία σας. Στο τέλος θα έχετε ένα επαγγελματικό έγγραφο Word που μπορεί να χρησιμοποιηθεί σε αναφορές, πίνακες ελέγχου ή αυτόματες συνημμένες σε email.

Η δημιουργία διαγράμματος προγραμματιστικά εξαλείφει τα χειροκίνητα βήματα αντιγραφής‑επικόλλησης και εγγυάται συνεπή στυλ σε δεκάδες παραγόμενα έγγραφα. Το παράδειγμα χρησιμοποιεί τη βιβλιοθήκη Aspose.Words for Java, η οποία λειτουργεί με Java 8+ και δεν απαιτεί εγκατάσταση Microsoft Office. Δεν χρειάζονται άλλα προαπαιτούμενα εκτός από ένα τυπικό JDK και το αγαπημένο σας IDE.

## Προαπαιτούμενα

- Java Development Kit (JDK) 8 ή νεότερο  
- Maven ή Gradle για διαχείριση εξαρτήσεων (το tutorial χρησιμοποιεί Maven)  
- Aspose.Words for Java library (αδεια δοκιμής είναι επαρκής για δοκιμές)  

Προσθέστε την εξάρτηση Aspose.Words στο `pom.xml` σας:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-words</artifactId>
    <version>24.9</version> <!-- Use the latest stable version -->
</dependency>
```

> **Pro tip:** Καταχωρίστε την άδειά σας με `License license = new License(); license.setLicense("Aspose.Words.lic");` πριν δημιουργήσετε οποιοδήποτε έγγραφο για να αφαιρέσετε τα υδατογραφήματα αξιολόγησης.

## Δημιουργία διαγράμματος δακτυλίου σε έγγραφο Word

Η βασική ροή εργασίας αποτελείται από πέντε λογικά βήματα. Κάθε βήμα είναι τυλιγμένο σε δική του μέθοδο για να διατηρείται ο κώδικας καθαρός και επαναχρησιμοποιήσιμος.

```java
import com.aspose.words.*;
import com.aspose.words.drawing.*;

public class DoughnutChartDemo {

    public static void main(String[] args) throws Exception {
        // Step 1: create blank Word document
        Document doc = createBlankWordDocument();

        // Step 2: insert a pie chart (base for the doughnut)
        Chart chart = insertPieChart(doc, 400, 300);

        // Step 3: convert the pie chart into a doughnut and rotate it
        customizeChartAppearance(chart);

        // Step 4: apply additional formatting to the chart
        formatPieChart(chart);

        // Step 5: save the final document
        doc.save("output/DoughnutChartFormatted.docx");
        System.out.println("Document saved successfully.");
    }

    /** Step 1 – create blank Word document */
    private static Document createBlankWordDocument() {
        // Aspose.Words creates an empty document by default
        return new Document();
    }

    /** Step 2 – insert pie chart with given dimensions */
    private static Chart insertPieChart(Document doc, int width, int height) throws Exception {
        DocumentBuilder builder = new DocumentBuilder(doc);
        // ChartType.PIE creates a standard pie chart that we will later turn into a doughnut
        Chart chart = builder.insertChart(ChartType.PIE, width, height);
        // Populate the chart with sample data
        chart.getSeries().clear(); // Remove default series
        ChartSeries series = chart.getSeries().add("Sales", new String[]{"Q1", "Q2", "Q3", "Q4"},
                new double[]{15000, 23000, 18000, 27000});
        return chart;
    }

    /** Step 3 – rotate pie chart and make it a doughnut */
    private static void customizeChartAppearance(Chart chart) {
        // Explode the first slice for emphasis
        chart.getSeries().get(0).setExplode(20);
        // Convert the pie into a doughnut by setting a hole size (percentage of radius)
        chart.setHoleSize(30); // 30% hole creates a classic doughnut look
        // Rotate the chart so the largest slice starts at 45°
        chart.setRotationAngle(45);
    }

    /** Step 4 – additional formatting of the pie chart */
    private static void formatPieChart(Chart chart) {
        // Example: change the first slice color to a brand color
        chart.getSeries().get(0).getPoints().get(0).getFormat().setFillForegroundColor(Color.fromArgb(0xFF, 0x4A, 0x90));
        // Add a legend and position it at the bottom
        chart.setHasLegend(true);
        chart.getLegend().setPosition(LegendPosition.BOTTOM);
        // Set a title for the chart
        chart.setTitle("Quarterly Sales Distribution");
    }
}
```

### Τι κάνει ο κώδικας

| Βήμα | Δράση | Αιτία |
|------|--------|--------|
| **Create blank Word document** | `new Document()` | Ξεκινά με ένα καθαρό αρχείο ώστε να ελέγχετε κάθε στοιχείο. |
| **Insert pie chart** | `builder.insertChart(ChartType.PIE, …)` | Ένα διάγραμμα πίτας είναι η βασική μορφή· η Aspose παρέχει μόνο δακτύλιο ρυθμίζοντας το μέγεθος της τρύπας. |
| **Rotate pie chart** | `chart.setRotationAngle(45)` | Η περιστροφή ευθυγραμμίζει το μεγαλύτερο τμήμα σε πιο αναγνώσιμη θέση. |
| **Format pie chart** | `setExplode`, `setHoleSize`, color, legend | Βελτιώνει την οπτική ιεραρχία και ταιριάζει με τις εταιρικές οδηγίες στυλ. |
| **Save document** | `doc.save("…/DoughnutChartFormatted.docx")` | Γράφει το τελικό αρχείο .docx στο δίσκο, έτοιμο για διανομή. |

## Εισαγωγή διαγράμματος πίτας πριν τη μετατροπή σε δακτύλιο

Η Aspose.Words δεν παρέχει άμεση μέθοδο “insert doughnut chart”. Αντίθετα, **εισάγετε διάγραμμα πίτας** και στη συνέχεια τροποποιείτε τις ιδιότητές του. Αυτή η προσέγγιση δύο βημάτων σας δίνει πλήρη έλεγχο πάνω στις σειρές δεδομένων, την έκρηξη τμημάτων και το μέγεθος της τρύπας. Αν χρειάζεστε καθαρό διάγραμμα πίτας αλλού, απλώς παραλείψτε την κλήση `setHoleSize`.

## Περιστροφή διαγράμματος πίτας για οπτική ισορροπία

Η προεπιλεγμένη προσανατολισμός ξεκινά το πρώτο τμήμα στη θέση 12 ωρών. Σε πολλές επιχειρηματικές αναφορές το πιο σημαντικό τμήμα πρέπει να ξεκινά σε πιο φυσική γωνία, όπως 45 μοίρες. Η μέθοδος `setRotationAngle(double angle)` δέχεται μοίρες και περιστρέφει ολόκληρο το διάγραμμα χωρίς να επηρεάζει τις τιμές των δεδομένων.

## Μορφοποίηση διαγράμματος πίτας και προσαρμογή εμφάνισης

Πέρα από τη μετατροπή σε δακτύλιο, συχνά θέλετε να **μορφοποιήσετε στοιχεία διαγράμματος πίτας**:

- **Explode** το πρώτο τμήμα (`setExplode`) για να τραβήξετε την προσοχή.  
- **Color** κάθε τμήμα χρησιμοποιώντας `getPoints().get(i).getFormat().setFillForegroundColor`.  
- **Legend** τοποθέτηση (`setHasLegend`, `setPosition`) βοηθά τους αναγνώστες να ερμηνεύσουν τις κατηγορίες.  
- **Title** (`setTitle`) παρέχει περιεχόμενο με μια ματιά.  

Όλες αυτές οι ρυθμίσεις είναι προαιρετικές· μπορείτε να τις προσαρμόσετε ώστε να ταιριάζουν με την παλέτα της μάρκας ή τα εταιρικά πρότυπα.

## Δημιουργία κενής εγγράφου Word και αποθήκευση του αποτελέσματος

Η μέθοδος `createBlankWordDocument` ενσωματώνει το βήμα **create blank word document**. Η απομόνωση αυτής της λογικής καθιστά εύκολη την επαναχρησιμοποίηση της μεθόδου όταν δημιουργείτε πολλαπλές αναφορές σε μια παρτίδα. Μετά από όλες τις προσαρμογές, το `doc.save` γράφει το αρχείο σε τυπική μορφή Office Open XML (`.docx`), η οποία μπορεί να ανοιχθεί σε Microsoft Word, LibreOffice ή Google Docs χωρίς απώλεια πιστότητας.

### Αναμενόμενο αποτέλεσμα

Όταν εκτελέσετε τη μέθοδο `main`, η κονσόλα εκτυπώνει:

```

```

Και το αρχείο `output/DoughnutChartFormatted.docx` περιέχει μία σελίδα με διάγραμμα δακτυλίου με τίτλο *Quarterly Sales Distribution*. Το διάγραμμα δείχνει τέσσερα τμήματα, το πρώτο τμήμα εκραγμένο, χρωματισμένο στο χρώμα της μάρκας, και περιστρεφόμενο 45 μοίρες.

## Συνηθισμένες παραλλαγές και ειδικές περιπτώσεις

| Κατάσταση | Προσαρμογή |
|-----------|------------|
| **More than one data series** | Προσθέστε επιπλέον αντικείμενα `ChartSeries` στο `chart.getSeries()`. |
| **Different chart size** | Αλλάξτε τα ορίσματα `width` και `height` στη `insertPieChart`. |
| **No hole (pure pie)** | Παραλείψτε `chart.setHoleSize(…)` ή ορίστε το σε `0`. |
| **Large documents** | Χρησιμοποιήστε `DocumentBuilder` για να εισάγετε το διάγραμμα σε συγκεκριμένο τμήμα ή σελιδοδείκτη. |
| **License not set** | Η βιβλιοθήκη λειτουργεί σε λειτουργία αξιολόγησης, προσθέτοντας υδατογράφημα στην πρώτη σελίδα. Καταχωρίστε άδεια για να το αφαιρέσετε. |
