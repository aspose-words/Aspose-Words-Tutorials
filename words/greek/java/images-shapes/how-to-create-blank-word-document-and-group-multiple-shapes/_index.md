# Πώς να δημιουργήσετε κενό έγγραφο Word και να ομαδοποιήσετε πολλαπλά σχήματα

Αν χρειάζεστε να **δημιουργήσετε κενό έγγραφο Word** προγραμματιστικά, αυτό το tutorial σας δείχνει ακριβώς πώς. Θα δείτε πώς να εισάγετε ένα σχήμα ομάδας, στη συνέχεια **προσθέτετε ορθογώνιο** σε αυτήν την ομάδα, καλύπτοντας τη πλήρη ροή εργασίας από ένα κενό έγγραφο μέχρι ένα ομαδοποιημένο σχέδιο.

Η εργασία με αρχεία Word συχνά σημαίνει την οργάνωση πολλών σχεδίων μαζί—σκεφτείτε ένα διάγραμμα που αποτελείται από πολλαπλά σχήματα. Στο τέλος αυτού του οδηγού θα μπορείτε να **ομαδοποιήσετε πολλαπλά σχήματα**, να εισάγετε ένα **σχήμα ορθογωνίου**, και να κατανοήσετε **πώς να εισάγετε ομάδα** και **πώς να προσθέσετε ορθογώνιο** με καθαρό, επαναχρησιμοποιήσιμο τρόπο.

## Τι θα χρειαστείτε

* .NET 6.0 ή νεότερο (ο κώδικας λειτουργεί επίσης με .NET Framework 4.6+)
* **Aspose.Words for .NET** πακέτο NuGet (`Install-Package Aspose.Words`)
* Βασική κατανόηση της C# και του Visual Studio IDE (οποιοδήποτε IDE λειτουργεί)

> **Συμβουλή:** Το Aspose.Words λειτουργεί πλήρως offline· δεν χρειάζεστε σύνδεση στο internet μετά την εγκατάσταση του πακέτου.

## Βήμα 1: Δημιουργήστε ένα κενό έγγραφο Word

Η πρώτη ενέργεια είναι η δημιουργία ενός κενών αντικειμένου `Document`. Αυτό το αντικείμενο αντιπροσωπεύει το **κενό έγγραφο Word** που θα εμπλουτίσετε αργότερα με σχήματα.

```csharp
using Aspose.Words;
using Aspose.Words.Drawing;

class Program
{
    static void Main()
    {
        // Step 1 – create a new blank Word document
        Document doc = new Document();               // <-- blank document
        DocumentBuilder builder = new DocumentBuilder(doc);
```

*Γιατί είναι σημαντικό:* Ένα `Document` χωρίς ενότητες ή παραγράφους είναι ακόμη έγκυρο αρχείο .docx. Ξεκινώντας από μια καθαρή βάση εξασφαλίζετε ότι δεν υπάρχει κρυφή μορφοποίηση που να επηρεάζει τα σχήματα που θα προσθέσετε αργότερα.

## Βήμα 2: Εισαγωγή σχήματος ομάδας (πώς να εισάγετε ομάδα)

Ένα **σχήμα ομάδας** λειτουργεί ως κοντέινερ που μπορεί να περιέχει άλλα αντικείμενα σχεδίασης. Στο Aspose.Words το δημιουργείτε με `InsertGroupShape`.

```csharp
        // Step 2 – insert a group shape that will hold other shapes
        GroupShape group = builder.InsertGroupShape();   // <-- container for shapes
```

*Γιατί να χρησιμοποιήσετε ομάδα;* Η ομαδοποίηση σας επιτρέπει να μετακινείτε, περιστρέφετε ή αλλάζετε το μέγεθος πολλαπλών σχημάτων ως μία ενιαία μονάδα. Αυτό είναι απαραίτητο για διαγράμματα όπου τα στοιχεία πρέπει να παραμένουν ευθυγραμμισμένα.

## Βήμα 3: Εισαγωγή σχήματος ορθογωνίου (εισαγωγή σχήματος ορθογωνίου)

Τώρα προσθέστε ένα ορθογώνιο στο έγγραφο. Η μέθοδος `InsertShape` επιστρέφει ένα αντικείμενο `Shape` που μπορείτε αργότερα να συνδέσετε με την ομάδα.

```csharp
        // Step 3 – create a rectangle shape with specific dimensions
        Shape rectangle = builder.InsertShape(ShapeType.Rectangle, 100, 50); // width=100pt, height=50pt
```

*Γιατί ορθογώνιο;* Τα ορθογώνια είναι το πιο κοινό δομικό στοιχείο για διαγράμματα ροής, προεπισκοπήσεις UI και εικονικές γραφικές παραστάσεις. Οι διαστάσεις εκφράζονται σε points (1 pt ≈ 1/72 inch).

## Βήμα 4: Προσθήκη του ορθογωνίου στην ομάδα (πώς να προσθέσετε ορθογώνιο)

Ένα σχήμα που δημιουργείται με `InsertShape` βρίσκεται απευθείας στο σώμα του εγγράφου. Για να το κάνετε μέρος της ομάδας, καλέστε `AppendChild` στο `GroupShape`.

```csharp
        // Step 4 – add the rectangle to the previously created group
        group.AppendChild(rectangle);   // <-- rectangle now belongs to the group
```

*Τι συμβαίνει εσωτερικά;* Η `AppendChild` μετακινεί τον κόμβο του ορθογωνίου από την κύρια ιστορία του εγγράφου στη εσωτερική συλλογή της ομάδας, διατηρώντας το μέγεθος και τη θέση του σε σχέση με το αρχικό σημείο της ομάδας.

## Βήμα 5: Αποθήκευση του εγγράφου

Τέλος, γράψτε το αρχείο στο δίσκο. Μπορείτε να ανοίξετε το παραγόμενο `.docx` στο Microsoft Word για να δείτε το ομαδοποιημένο ορθογώνιο.

```csharp
        // Step 5 – save the document to a file
        doc.Save("GroupedShapeExample.docx");
    }
}
```

> **Ακραία περίπτωση:** Εάν σκοπεύετε να προσθέσετε περισσότερα σχήματα (π.χ., κύκλους, γραμμές) στην ίδια ομάδα, επαναλάβετε **Βήμα 3** και **Βήμα 4** για κάθε νέο σχήμα πριν από την αποθήκευση. Η ομάδα θα προσαρμόσει αυτόματα το πλαίσιο περιβάλλοντάς της ώστε να περιλαμβάνει όλα τα παιδιά.

## Πώς να ομαδοποιήσετε πολλαπλά σχήματα – επέκταση του παραδείγματος

Παρακάτω υπάρχει ένα σύντομο απόσπασμα που προσθέτει ένα δεύτερο σχήμα (έλλειψη) στην ίδια ομάδα, επιδεικνύοντας **ομαδοποίηση πολλαπλών σχημάτων** σε ένα έγγραφο.

```csharp
        // Additional shape: an ellipse
        Shape ellipse = builder.InsertShape(ShapeType.Ellipse, 80, 40);
        group.AppendChild(ellipse);   // now the group contains rectangle + ellipse
```

Όταν ανοίξετε το `GroupedShapeExample.docx`, θα δείτε το ορθογώνιο και την έλλειψη να κινούνται μαζί όταν επιλέγετε την ομάδα στο Word.

## Συχνές ερωτήσεις και αντιμετώπιση προβλημάτων

| Ερώτηση | Απάντηση |
|----------|--------|
| **Χρειάζομαι άδεια για το Aspose.Words;** | Μια δωρεάν αξιολόγηση λειτουργεί χωρίς άδεια, αλλά προσθέτει υδατογράφημα. Για παραγωγή, εφαρμόστε άδεια για να αφαιρέσετε το υδατογράφημα και να ξεκλειδώσετε πλήρη απόδοση. |
| **Μπορώ να τοποθετήσω τα σχήματα με ακρίβεια;** | Ναι. Μετά την εισαγωγή ενός σχήματος μπορείτε να ορίσετε τις ιδιότητες `Shape.Left`, `Shape.Top`, `Shape.Width` και `Shape.Height`. |
| **Τι γίνεται αν το ορθογώνιο εξαφανιστεί μετά την αποθήκευση;** | Βεβαιωθείτε ότι καλείτε `group.AppendChild(rectangle)` *μετά* την εισαγωγή του ορθογωνίου. Η προσθήκη του σχήματος στο σώμα του εγγράφου πρώτα και η μετακίνηση του στην ομάδα είναι απαραίτητη. |
| **Είναι δυνατόν να ομαδοποιήσετε σχήματα σε διαφορετικές ενότητες;** | Όχι. Όλα τα σχήματα σε μια ομάδα πρέπει να ανήκουν στην ίδια ιστορία (ενότητα). Δημιουργήστε ξεχωριστές ομάδες ανά ενότητα αν χρειάζεται. |

## Επόμενα βήματα

* Δοκιμάστε διαφορετικά μεγέθη και χρώματα του **σχήματος ορθογωνίου** (`rectangle.FillColor = Color.LightBlue;`).

* Μάθετε πώς να μετατρέψετε το τελικό `.docx` σε PDF (`doc.Save("output.pdf");`) για διανομή.  
* Βυθιστείτε στο **πώς να προσθέσετε ορθογώνιο** σε υπάρχοντα έγγραφα που περιέχουν ήδη κείμενο—χρησιμοποιήστε `DocumentBuilder.MoveTo` για να τοποθετήσετε την ομάδα όπου τη χρειάζεστε.
