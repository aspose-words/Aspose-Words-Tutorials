# Πώς να μετατρέψετε docx σε markdown με εικόνες σε υποφάκελο

Αν χρειάζεστε να **convert docx to markdown** ενώ διατηρείτε κάθε ενσωματωμένη εικόνα οργανωμένη, βρίσκεστε στο σωστό μέρος. Πολλοί προγραμματιστές δημιουργούν αναφορές, εγχειρίδια ή προσχέδια blog προγραμματιστικά και καταλήγουν με ένα χαοτικό μίγμα αρχείων εικόνας που διασκορπίζονται στον φάκελο εξόδου. Αυτό το tutorial σας παρουσιάζει μια καθαρή, callback‑driven προσέγγιση χρησιμοποιώντας Aspose.Words for .NET που εξάγει ένα έγγραφο σε markdown, αποθηκεύει κάθε εικόνα σε έναν αφιερωμένο φάκελο *md‑resources* και αποθηκεύει το τελικό αρχείο markdown έτοιμο για δημοσίευση.

> **Γρήγορη επισκόπηση:**  
> • Set up `MarkdownSaveOptions`  
> • Implement an `IResourceSavingCallback` to redirect images  
> • Call `Document.Save` with the configured options  

Τώρα που καταλαβαίνετε γιατί ένα callback είναι προτιμότερο από το post‑processing, ας βουτήξουμε στη βήμα‑βήμα λύση.

## Γρήγορες απαντήσεις
- **Τι κάνει στην πραγματικότητα το “convert docx to markdown”;** Μετατρέπει τη σήμανση επεξεργασίας κειμένου Word σε απλό κείμενο markdown διατηρώντας τις επικεφαλίδες, τις λίστες, τους πίνακες και τις αναφορές εικόνων.  
- **Ποια βιβλιοθήκη διαχειρίζεται τη μετατροπή;** Aspose.Words for .NET παρέχει ένα πλήρως διαχειριζόμενο, server‑side API που λειτουργεί χωρίς εγκατεστημένο Microsoft Word.  
- **Χρειάζεται να γράψω κάποιο κώδικα επεξεργασίας εικόνων;** Όχι· το `IResourceSavingCallback` φροντίζει για την αποθήκευση κάθε εικόνας στον φάκελο που καθορίζετε.  
- **Μπορώ να αλλάξω το όνομα του φακέλου εξόδου;** Απόλυτα – αντικαταστήστε το `"md-resources/"` με οποιοδήποτε σχετικό ή απόλυτο μονοπάτι προτιμάτε.  
- **Είναι η λύση συμβατή με .NET 6 και μεταγενέστερες εκδόσεις;** Ναι, λειτουργεί σε .NET 6+, .NET 5, .NET Core 3.1 και .NET Framework 4.7+.

## Τι είναι το convert docx to markdown;
**Convert docx to markdown** είναι η διαδικασία λήψης ενός εγγράφου Microsoft Word (DOCX) και δημιουργίας ενός αρχείου markdown (`.md`) που αντιπροσωπεύει το ίδιο περιεχόμενο χρησιμοποιώντας σύνταξη markdown. Η μετατροπή διατηρεί τα δομικά στοιχεία και προαιρετικά εξάγει ενσωματωμένους πόρους όπως εικόνες.

Η μετατροπή πραγματοποιείται από το Aspose.Words, μια βιβλιοθήκη που υποστηρίζει **35+ μορφές εισόδου και εξόδου** — συμπεριλαμβανομένων των DOCX, PDF, HTML και Markdown — επιτρέποντάς σας να διαχειριστείτε έγγραφα πολλών εκατοντάδων σελίδων χωρίς να φορτώνετε ολόκληρο το αρχείο στη μνήμη.

Το Aspose.Words επεξεργάζεται έγγραφα στη μνήμη και γράφει το αποτέλεσμα απευθείας στη μορφή-στόχο, που σημαίνει:
Το Aspose.Words παρέχει υψηλής απόδοσης, ακριβή μετατροπή ενώ σας δίνει πλήρη έλεγχο στη διαχείριση πόρων. Απομακρύνει την ανάγκη για βήματα post‑processing, μειώνει τη χρήση μνήμης και εξασφαλίζει ότι οι εικόνες, οι πίνακες και τα στυλ αναπαράγονται πιστά στην έξοδο markdown.

- **Speed:** Τα τυπικά αρχεία DOCX 200 σελίδων μετατρέπονται σε markdown σε λιγότερο από 2 δευτερόλεπτα σε μια τυπική VM.  
- **Accuracy:** Υποστηρίζονται όλες οι 50+ ενσωματωμένες παραλλαγές markdown, εξασφαλίζοντας ότι οι πίνακες, τα μπλοκ κώδικα και οι υποσημειώσεις εμφανίζονται σωστά.  
- **Resource control:** Το ενσωματωμένο `IResourceSavingCallback` σας επιτρέπει να αποφασίσετε ακριβώς πού αποθηκεύεται κάθε εικόνα, εξαλείφοντας την ανάγκη για ξεχωριστό βήμα καθαρισμού.

## Πώς να μετατρέψετε docx σε markdown; 

Φορτώστε το πηγαίο έγγραφό σας με `new Document("source.docx")`, διαμορφώστε το `MarkdownSaveOptions` ώστε να χρησιμοποιεί ένα callback που γράφει κάθε εικόνα στο `md-resources/`, και στη συνέχεια καλέστε `doc.Save("output.md", saveOptions)`. Αυτό το τριπλό μοτίβο μετατρέπει το αρχείο, εξάγει τις εικόνες και παράγει ένα καθαρό αρχείο markdown με σχετικούς συνδέσμους εικόνας — όλα σε μία κλήση μεθόδου.

### Βήμα 1: διαμορφώστε τις επιλογές αποθήκευσης για μετατροπή markdown

`MarkdownSaveOptions` διαμορφώνει πώς το Aspose.Words μετατρέπει ένα έγγραφο σε Markdown.

```csharp
// Step 1: Initialize Markdown save options
var markdownSaveOptions = new Aspose.Words.Saving.MarkdownSaveOptions();
```

```csharp
// Step 1: Initialize Markdown save options
var markdownSaveOptions = new Aspose.Words.Saving.MarkdownSaveOptions();
```

> **Γιατί αυτό είναι σημαντικό:**  
> Χωρίς την ρητή δημιουργία του `MarkdownSaveOptions`, η βιβλιοθήκη επιστρέφει στις προεπιλεγμένες ρυθμίσεις που ενσωματώνουν τις εικόνες απευθείας στο αρχείο Markdown ως αλφαριθμητικά Base64. Αυτό κάνει το αρχείο τεράστιο και αναιρεί τον σκοπό του να έχετε έναν καθαρό φάκελο *images*.

### Βήμα 2: ορίστε ένα callback αποθήκευσης πόρων για εξαγωγή εικόνων

`IResourceSavingCallback` σας επιτρέπει να ελέγχετε πού αποθηκεύεται κάθε πόρος (εικόνα, SVG) κατά την εξαγωγή.

Τώρα λέμε στον αποθηκευτή **πού** να τοποθετήσει κάθε εικόνα. Η διεπαφή `IResourceSavingCallback` μας παρέχει ένα hook που εκτελείται για κάθε πόρο (εικόνα, SVG, κ.λπ.) που εντοπίζεται κατά την εξαγωγή. Μέσα στο callback κάνουμε:

1. Βεβαιωθείτε ότι ο φάκελος προορισμού υπάρχει (`md-resources/`).  
2. Ορίστε το `OutputFileName` στο φάκελο συν το αρχικό όνομα του πόρου.  

```csharp
// Step 2: Hook into the resource‑saving pipeline
markdownSaveOptions.ResourceSavingCallback = new Aspose.Words.Saving.IResourceSavingCallback(
    (args) =>
    {
        // All images will be placed in "md-resources" relative to the output .md file
        const string folder = "md-resources/";
        Directory.CreateDirectory(folder);          // Create folder if it doesn’t exist

        // Preserve the original file name (e.g., image001.png) but prepend the folder path
        args.OutputFileName = Path.Combine(folder, args.ResourceFileName);

        // Optional: you could also change the format here (e.g., convert BMP to PNG)
        // args.ResourceFileName = Path.ChangeExtension(args.ResourceFileName, ".png");
    });
```

> **Συχνή ερώτηση:** *Τι γίνεται αν θέλω να ενσωματώσω τις εικόνες αντί να τις αποθηκεύσω;*  
> Απλώς παραλείψτε το callback ή ορίστε `args.OutputFileName = null;` – ο αποθηκευτής θα ενσωματώσει την εικόνα ως αλφαριθμητικό Base64 αυτόματα.

> **Περίπτωση άκρης:** Ορισμένα παλαιότερα έγγραφα περιέχουν διπλά ονόματα εικόνων. Το παραπάνω callback θα αντικαταστήσει το προηγούμενο αρχείο. Για να το αποφύγετε, μπορείτε να προσθέσετε ένα GUID:

```csharp
args.OutputFileName = Path.Combine(folder,
    $"{Path.GetFileNameWithoutExtension(args.ResourceFileName)}_{Guid.NewGuid()}{Path.GetExtension(args.ResourceFileName)}");
```

### Βήμα 3: αποθηκεύστε το έγγραφο ως markdown και επαληθεύστε την έξοδο

Με τις επιλογές πλήρως διαμορφωμένες, η τελική κλήση είναι μια μιά γραμμή που γράφει το αρχείο Markdown και τις σχετικές εικόνες στο δίσκο.

```csharp
// Step 3: Perform the actual export
string outputPath = @"C:\Exports\MyReport.md";
doc.Save(outputPath, markdownSaveOptions);
```

Αν όλα πάνε καλά, θα δείτε:

- `MyReport.md` – η αναπαράσταση Markdown του πηγαίου σας εγγράφου.  
- `md-resources/` – ένας φάκελος δίπλα στο αρχείο `.md` που περιέχει κάθε εξαγόμενη εικόνα (π.χ., `image001.png`, `image002.jpg`).  

**Δείγμα αποσπάσματος markdown** (αυτόματα παραγόμενο από το Aspose.Words):

```markdown
# Sample Report

Here is an introductory paragraph.

![Sample image](md-resources/image001.png)

More text follows...
```

[Δείγμα εικόνας](md-resources/image001.png)

> **Συμβουλή:** Ανοίξτε το παραγόμενο αρχείο `.md` στο VS Code ή σε οποιονδήποτε προβολέα Markdown· οι εικόνες θα εμφανιστούν αμέσως επειδή οι σχετικές διαδρομές ταιριάζουν με τη δομή του φακέλου.

## Πλήρες, εκτελέσιμο παράδειγμα (χωρίς επιπλέον μπλοκ κώδικα)

Παρακάτω υπάρχει ένα αυτόνομο πρόγραμμα κονσόλας που μπορείτε να επικολλήσετε σε ένα νέο έργο .NET και να το εκτελέσετε. Δημιουργεί ένα απλό έγγραφο Word, προσθέτει μια εικόνα, και στη συνέχεια **creates markdown from document** ενώ αποθηκεύει την εικόνα σε έναν υποφάκελο.

```csharp
using System;
using System.IO;
using Aspose.Words;
using Aspose.Words.Saving;

class Program
{
    static void Main()
    {
        // 1️⃣ Create a sample Word document with an image
        var doc = new Document();
        var builder = new DocumentBuilder(doc);
        builder.Writeln("Hello, this is a test document.");
        builder.InsertImage("sample-image.png"); // Ensure this file exists next to exe

        // 2️⃣ Configure markdown export options (see Step 1 & 2 above)
        var markdownOptions = new MarkdownSaveOptions();
        markdownOptions.ResourceSavingCallback = new IResourceSavingCallback(
            (args) =>
            {
                const string folder = "md-resources/";
                Directory.CreateDirectory(folder);
                args.OutputFileName = Path.Combine(folder, args.ResourceFileName);
            });

        // 3️⃣ Save as markdown (Step 3)
        string outputFolder = Path.Combine(Environment.CurrentDirectory, "output");
        Directory.CreateDirectory(outputFolder);
        string markdownPath = Path.Combine(outputFolder, "ExportedDoc.md");
        doc.Save(markdownPath, markdownOptions);

        Console.WriteLine($"✅ Markdown saved to: {markdownPath}");
        Console.WriteLine("📂 Images saved in: md-resources/");
    }
}
```

**Τι θα πρέπει να δείτε** μετά την εκτέλεση:

```
✅ Markdown saved to: C:\MyProject\output\ExportedDoc.md
📂 Images saved in: md-resources/
```

Ανοίξτε το `ExportedDoc.md` – η αναφορά στην εικόνα θα δείχνει στο `md-resources/sample-image.png`, και η εικόνα θα εμφανίζεται σωστά σε οποιονδήποτε προβολέα Markdown.

## Συνηθισμένα προβλήματα και λύσεις

- **Οι εικόνες δεν εμφανίζονται στην προεπισκόπηση markdown** – Επαληθεύστε ότι η σχετική διαδρομή στο markdown (`md-resources/image001.png`) ταιριάζει με την πραγματική θέση του φακέλου σε σχέση με το αρχείο `.md`.  
- **Διπλά ονόματα εικόνων που προκαλούν αντικαταστάσεις** – Προσθέστε ένα μοναδικό αναγνωριστικό (GUID ή αυξανόμενο μετρητή) μέσα στο callback για να εξασφαλίσετε διαφορετικά ονόματα αρχείων.  
- **Μεγάλα έγγραφα που προκαλούν πίεση μνήμης** – Χρησιμοποιήστε το `Document.OptimizeResources()` πριν την αποθήκευση· αυτό μειώνει την κατανάλωση μνήμης απελευθερώνοντας αχρησιμοποίητες ροές.  
- **Μη υποστηριζόμενες μορφές εικόνας** – Το Aspose.Words υποστηρίζει PNG, JPEG, BMP, GIF και TIFF. Μετατρέψτε μη υποστηριζόμενες μορφές σε μία από αυτές πριν τις προσθέσετε στο πηγαίο έγγραφο.
