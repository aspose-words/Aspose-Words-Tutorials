# Πώς να δημιουργήσετε έγγραφο Word με σύμβολα κράτησης θέσης και λίστες

Αν χρειάζεστε να **δημιουργήσετε έγγραφο Word** προγραμματιστικά, αυτός ο οδηγός σας δείχνει ακριβώς πώς. Θα περάσουμε από **ορισμό κειμένου κράτησης θέσης**, **προσθήκη στοιχείων λίστας**, και **πώς να χρησιμοποιήσετε SDT** (Structured Document Tag) ελέγχους με το Aspose.Words for .NET.

Οι προγραμματιστές συχνά ζητούν έναν τρόπο ενσωμάτωσης ελέγχων περιεχομένου — όπως σύμβολα κράτησης θέσης απλού κειμένου ή λίστες επιλογής — απευθείας σε αρχείο .docx χωρίς το άνοιγμα του Word. Αυτό το tutorial σας παρέχει ένα πλήρες, εκτελέσιμο παράδειγμα, εξηγεί γιατί κάθε βήμα είναι σημαντικό και καλύπτει κοινές παραλλαγές όπως η προσθήκη των ελέγχων σε υπάρχον έγγραφο ή η προσαρμογή των τιμών της λίστας.

## Προαπαιτούμενα

Πριν ξεκινήσετε, βεβαιωθείτε ότι έχετε:

- .NET 6.0 SDK ή νεότερη έκδοση εγκατεστημένη  
- Visual Studio 2022 (ή οποιοδήποτε IDE C#)  
- Ένα ενεργό άδεια Aspose.Words for .NET (μια δωρεάν δοκιμή λειτουργεί για ανάπτυξη)  
- Βασική εξοικείωση με τη σύνταξη C#  

Ο κώδικας στοχεύει στην **Aspose.Words 23.9** (την πιο πρόσφατη σταθερή έκδοση τη στιγμή της συγγραφής). Προσαρμόστε την έκδοση του πακέτου NuGet εάν χρησιμοποιείτε νεότερη έκδοση.

## Εισαγωγή Structured Document Tag απλού κειμένου (ορισμός κειμένου κράτησης θέσης)

Ένα SDT απλού κειμένου λειτουργεί όπως ένας έλεγχος περιεχομένου που ο χρήστης μπορεί να συμπληρώσει. Ο ορισμός του `Title` και του `PlaceholderName` παρέχει μια φιλική υπόδειξη μέσα στο Word.

```csharp
            // Step 2: Insert a plain‑text SDT and set its placeholder text
            StructuredDocumentTag plainTextTag = builder.InsertStructuredDocumentTag(
                StructuredDocumentTagType.PlainText, true);
            plainTextTag.Title = "CustomerName";
            plainTextTag.PlaceholderName = "Enter name";
```

**Εξήγηση:**  
- `InsertStructuredDocumentTag` δημιουργεί τον έλεγχο στη τρέχουσα θέση του κέρσορα του builder.  
- `StructuredDocumentTagType.PlainText` λέει στο Word να εμφανίσει ένα απλό πλαίσιο κειμένου.  
- `Title` είναι το εσωτερικό όνομα που χρησιμοποιεί το XML του Word· είναι χρήσιμο για μελλοντική δέσμευση δεδομένων.  
- `PlaceholderName` είναι η γκρι υπόδειξη που εμφανίζεται μέχρι ο χρήστης να πληκτρολογήσει κάτι.

> **Pro tip:** Εάν χρειάζεστε το σύμβολο κράτησης θέσης να εμφανίζεται στο τμήμα *Properties* του εγγράφου, ορίστε επίσης `plainTextTag.Tag = "CustomerName"`.

## Εισαγωγή λίστας επιλογής (drop‑down) SDT (πώς να χρησιμοποιήσετε sdt)

Μια λίστα επιλογής σας επιτρέπει να παρουσιάσετε ένα προκαθορισμένο σύνολο επιλογών. Αυτό είναι το κύριο στοιχείο του **πώς να χρησιμοποιήσετε sdt** για αριθμημένα δεδομένα.

```csharp
            // Step 3: Insert a drop‑down list SDT and define its title
            StructuredDocumentTag dropdownTag = builder.InsertStructuredDocumentTag(
                StructuredDocumentTagType.DropDownList, true);
            dropdownTag.Title = "Country";
```

**Γιατί μια λίστα επιλογής;**  
Οι λίστες επιλογής βελτιώνουν τη συνέπεια των δεδομένων και μειώνουν τα λάθη πληκτρολόγησης. Η ιδιότητα `Title` ξανά λειτουργεί ως αναγνωριστικό για επεξεργασία downstream (π.χ., κατά την εξαγωγή δεδομένων φόρμας).

## Προσθήκη στοιχείων λίστας στο drop‑down (προσθήκη στοιχείων λίστας)

Τώρα γεμίζουμε τον έλεγχο με επιλέξιμες τιμές. Κάθε `ListItem` παίρνει ένα κείμενο εμφάνισης και μια προαιρετική τιμή που μπορεί να αποθηκευτεί στο XML του εγγράφου.

```csharp
            // Step 4: Populate the drop‑down with selectable items
            dropdownTag.ListItems.Add(new ListItem("USA", "US"));
            dropdownTag.ListItems.Add(new ListItem("Canada", "CA"));
            dropdownTag.ListItems.Add(new ListItem("Mexico", "MX"));
```

**Βασικά σημεία:**  

- Το πρώτο όρισμα (`"USA"`) είναι αυτό που βλέπει ο χρήστης.  
- Το δεύτερο όρισμα (`"US"`) είναι η υποκείμενη τιμή που μπορείτε να διαβάσετε προγραμματιστικά.  
- Μπορείτε να προσθέσετε όσες στοιχεία χρειάζεστε· η λίστα αποθηκεύεται στα στοιχεία `<w:listItem>` του XML του .docx.

### Περιπτώσεις άκρων και παραλλαγές

| Κατάσταση | Συνιστώμενη προσαρμογή |
|-----------|------------------------|
| **Προσθήκη ελέγχων σε υπάρχον αρχείο** | Φορτώστε το αρχείο με `new Document("Existing.docx")` αντί να δημιουργήσετε νέο `Document`. |
| **Κάντε το σύμβολο κράτησης θέσης υποχρεωτικό** | Ορίστε `plainTextTag.IsShowingPlaceholderWhenEmpty = false` και `plainTextTag.IsShowingPlaceholderWhenEmpty = true` ανάλογα με τη λογική επικύρωσής σας. |
| **Δέσμευση στοιχείων λίστας σε πηγή δεδομένων** | Επανάληψη μέσω μιας συλλογής (`foreach (var country in countries)`) και κλήση `dropdownTag.ListItems.Add(new ListItem(country.Name, country.Code))`. |
| **Στυλιζάρισμα του ελέγχου** | Χρησιμοποιήστε ιδιότητες `builder.Font` πριν την εισαγωγή του SDT για να επηρεάσετε το προεπιλεγμένο στυλ του κειμένου κράτησης θέσης. |
| **Αφαίρεση ελέγχου αργότερα** | Εντοπίστε το μέσω `doc.GetChildNodes(NodeType.StructuredDocumentTag, true)` και καλέστε `tag.Remove();`. |

## Πώς να δημιουργήσετε έλεγχο προγραμματιστικά – βέλτιστες πρακτικές

1. **Δημιουργήστε πρώτα το έγγραφο** – η πρώιμη αρχικοποίηση του `DocumentBuilder` αποτρέπει εκπλήξεις στη θέση του κέρσορα.  
2. **Ορίστε τίτλους και ετικέτες** – λειτουργούν ως σταθερά αναγνωριστικά για μελλοντική εξαγωγή δεδομένων.  
3. **Προσθέστε κείμενο κράτησης θέσης** – βελτιώνει την εμπειρία του χρήστη, ειδικά για ετικέτες απλού κειμένου.  
4. **Γεμίστε τα στοιχεία λίστας αμέσως** – το Word αποδίδει σωστά τη λίστα επιλογής μόνο αφού τα στοιχεία προσαρτηθούν.  
5. **Αποθηκεύστε μία φορά** – επαναλαμβανόμενες κλήσεις `Save` μέσα σε βρόχο αυξάνουν δραματικά το κόστος I/O.

Ακολουθώντας αυτά τα βήματα, διασφαλίζετε ότι το αρχείο Word είναι τόσο *machine‑readable* (για επεξεργασία backend) όσο και *user‑friendly* (για επεξεργασία frontend).

Το πλήρες παράδειγμα δείχνει **πώς να δημιουργήσετε αντικείμενα ελέγχου**, να τα διαμορφώσετε και να αποθηκεύσετε το αποτέλεσμα σε αρχείο .docx.

Στη συνέχεια, μπορείτε να εξερευνήσετε:

- **Δέσμευση τιμών SDT σε βάση δεδομένων** (χρησιμοποιώντας `StructuredDocumentTag.GetText()` για εξαγωγή).

- **Προηγμένους ελέγχους περιεχομένου** όπως επιλογείς ημερομηνίας (`StructuredDocumentTagType.Date`) ή ελέγχους επαναλαμβανόμενων τμημάτων.

Νιώστε ελεύθεροι να πειραματιστείτε με διαφορετικούς τύπους ελέγχων, επιλογές στυλ και σενάρια ενσωμάτωσης. Καλή προγραμματιστική!
