# Μορφοποίηση Δευτερεύοντος Άξονα X και Ορισμός Μονάδων Εμφάνισης σε Χιλιάδες σε Γραφήματα Γραμμής Word χρησιμοποιώντας το Aspose.Words
Αυτό το σεμινάριο σας καθοδηγεί στη δημιουργία ενός εγγράφου Word που περιέχει ένα γράφημα γραμμής, στην προσθήκη ενός δευτερεύοντα άξονα X και στη ρύθμιση του άξονα ώστε να εμφανίζει τιμές σε χιλιάδες. Θα μάθετε επίσης πώς να εφαρμόζετε μια προσαρμοσμένη αριθμητική μορφή στις ετικέτες του δευτερεύοντος άξονα, δίνοντάς σας ακριβή έλεγχο του τρόπου παρουσίασης των δεδομένων. Ακολουθήστε τα βήματα για να βελτιώσετε την αναγνωσιμότητα των πολυάξονων γραφημάτων στις αναφορές Word σας.

## Frequently asked questions

**Q: Πρέπει να προσθέσω τη δευτερεύουσα σειρά πριν ορίσω τη μονάδα εμφάνισης και τη μορφή αριθμού στον δευτερεύοντα άξονα X;**  
A: Όχι – οι ρυθμίσεις `AxisX` ανήκουν στο `ChartSeriesGroup`, επομένως μπορείτε να ορίσετε `secondaryGroup.AxisX.DisplayUnit.Unit` και `secondaryGroup.AxisX.NumberFormat.FormatCode` πριν ή μετά την προσθήκη σειρών· η διαμόρφωση θα εφαρμοστεί στον άξονα της ομάδας σε κάθε περίπτωση.

**Q: Μπορώ να χρησιμοποιήσω διαφορετική ενσωματωμένη μονάδα, όπως εκατομμύρια, για τον δευτερεύοντα άξονα X;**  
A: Ναι – εκχωρήστε οποιαδήποτε τιμή `AxisBuiltInUnit`, π.χ. `secondaryGroup.AxisX.DisplayUnit.Unit = AxisBuiltInUnit.Millions;` για να εμφανίσετε τις τιμές του άξονα σε εκατομμύρια αντί για χιλιάδες.

**Q: Θα επηρεάσει η προσαρμοσμένη μορφή `\"#,##0.0\"` τις ετικέτες του κύριου άξονα X;**  
A: Όχι – ο κώδικας μορφής εφαρμόζεται μόνο στον άξονα που τροποποιείτε (`secondaryGroup.AxisX.NumberFormat.FormatCode`), έτσι ο κύριος άξονας X διατηρεί την προεπιλεγμένη μορφοποίηση.

**Q: Τι συμβαίνει αν ξεχάσω να καθαρίσω τη σειρά demo με `lineChart.Series.Clear();`;**  
A: Το γράφημα θα περιέχει τη προεπιλεγμένη σειρά demo επιπλέον των σειρών που προσθέτετε, κάτι που μπορεί να οδηγήσει σε επιπλέον γραμμές και ασυμφωνίες κατηγοριών· ο καθαρισμός της συλλογής εξασφαλίζει ότι εμφανίζονται μόνο τα δεδομένα που προορίζονται.
