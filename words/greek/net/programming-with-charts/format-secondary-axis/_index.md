# Μορφοποίηση του δευτερεύοντα άξονα Y ως νόμισμα σε γράφημα Word χρησιμοποιώντας το Aspose.Words
Σε αυτό το tutorial θα δείτε πώς να δημιουργήσετε ένα έγγραφο Word, να εισάγετε ένα γράφημα γραμμής, να προσθέσετε έναν δευτερεύοντα άξονα Y, να μορφοποιήσετε αυτόν τον άξονα ως νόμισμα με δύο δεκαδικά ψηφία και να συνδέσετε μια δευτερεύουσα σειρά δεδομένων σε αυτό χρησιμοποιώντας το Aspose.Words for .NET. Η μορφοποίηση του δευτερεύοντα άξονα ως νόμισμα σας επιτρέπει να παρουσιάζετε καθαρά οικονομικά δεδομένα μαζί με την κύρια σειρά. Ακολουθήστε τον κώδικα βήμα‑βήμα για να δείτε το γράφημα να αποδίδεται απευθείας στο παραγόμενο έγγραφο.

## Frequently asked questions

**Q: Τι συμβαίνει αν παραλείψω την κλήση `lineChart.Series.Clear()`;**  
A: Το γράφημα θα διατηρήσει τη προεπιλεγμένη σειρά placeholder που εισάγει το Aspose.Words, έτσι η προσαρμοσμένη σας \"Main Series\" θα εμφανιστεί μαζί με ανεπιθύμητα σημεία δεδομένων.

**Q: Πώς μπορώ να εμφανίσω τον δευτερεύοντα άξονα X αντί να τον κρύβω;**  
A: Ορίστε `secondarySeriesGroup.AxisX.Hidden = false;` (ή απλώς παραλείψτε τη γραμμή που το θέτει σε `true`).

**Q: Μπορώ να χρησιμοποιήσω διαφορετικό σύμβολο νομίσματος ή μορφή για τον δευτερεύοντα άξονα Y;**  
A: Ναι – αλλάξτε τη συμβολοσειρά μορφής, π.χ. `secondarySeriesGroup.AxisY.NumberFormat.FormatCode = \"\\\"€\\\"#,##0.00\";` για ευρώ ή προσαρμόστε το πρότυπο ώστε να ταιριάζει στην περιοχή σας.

**Q: Γιατί πρέπει να ορίσω `IsLinkedToSource = false` όταν εφαρμόζω προσαρμοσμένη μορφή αριθμού;**  
A: Όταν το `IsLinkedToSource` είναι true, ο άξονας κληρονομεί τη μορφή αριθμού από την υποκείμενη πηγή δεδομένων, παρακάμπτοντας οποιοδήποτε προσαρμοσμένο `FormatCode`; ορίζοντάς το σε false, εξαναγκάζετε το γράφημα να χρησιμοποιήσει τη μορφή που καθορίζετε.

**Q: Είναι δυνατόν να μετακινήσετε τον δευτερεύοντα άξονα Y στην αριστερή πλευρά του γραφήματος;**  
A: Ναι, αναθέστε `secondarySeriesGroup.AxisY.Position = AxisPosition.Left;` (ή `Right` για την προεπιλογή) για να ελέγξετε σε ποια πλευρά θα σχεδιαστεί ο άξονας.
