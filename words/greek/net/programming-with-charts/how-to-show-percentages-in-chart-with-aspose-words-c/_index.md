# Πώς να εμφανίσετε ποσοστά σε γράφημα με Aspose.Words C#

Έχετε αναρωτηθεί **πώς να εμφανίσετε ποσοστά σε γράφημα** χωρίς να παλεύετε με πολύπλοκο Office interop; Δεν είστε μόνοι—πολλοί προγραμματιστές αντιμετωπίζουν αυτό το πρόβλημα όταν χρειάζονται έναν γρήγορο, προγραμματιζόμενο τρόπο να ετικετοποιήσουν ένα πίτα ή δακτυλιοειδές γράφημα. Τα καλά νέα; Με το Aspose.Words for .NET μπορείτε να ενεργοποιήσετε αυτές τις ετικέτες δεδομένων με λίγες μόνο γραμμές κώδικα.

Σε αυτό το tutorial θα καλύψουμε επίσης **προσθήκη ετικετών δεδομένων σε γράφημα πίτας** και **πώς να ενεργοποιήσετε τις ετικέτες δεδομένων του γραφήματος** ώστε οι οπτικοποιήσεις σας να γίνουν αμέσως πιο κατατοπιστικές. Στο τέλος θα έχετε ένα έτοιμο έγγραφο Word (`.docx`) που εμφανίζει ένα καλοσχεδιασμένο γράφημα πίτας με τα ποσοστά τοποθετημένα έξω από κάθε φέτα.

## Προαπαιτούμενα

Πριν ξεκινήσουμε, βεβαιωθείτε ότι έχετε:

- **Aspose.Words for .NET** (τελευταία έκδοση, π.χ. 24.9) εγκατεστημένο μέσω NuGet.
- Ένα αρχείο **ChartTemplate.docx** που περιέχει ήδη ένα γράφημα πίτας ή δακτυλιοειδές.  
  *(Αν δεν έχετε, δημιουργήστε ένα απλό έγγραφο Word, εισάγετε ένα γράφημα πίτας και αποθηκεύστε το ως `ChartTemplate.docx`.)*
- .NET 6.0 ή νεότερη έκδοση και οποιοδήποτε IDE προτιμάτε (Visual Studio, Rider, VS Code).

Δεν απαιτούνται επιπλέον εξαρτήσεις—το Aspose.Words διαχειρίζεται τα πάντα εσωτερικά.

## Πώς να εμφανίσετε ποσοστά σε γράφημα – Βήμα‑βήμα

Παρακάτω χωρίζουμε τη διαδικασία σε έξι σαφή βήματα. Κάθε βήμα περιλαμβάνει τον ακριβή κώδικα C# που μπορείτε να αντιγράψετε‑επικολλήσετε, μαζί με μια σύντομη εξήγηση **γιατί** το κάνουμε.

### Βήμα 1: Φόρτωση του πηγαίου εγγράφου

```csharp
using Aspose.Words;
using Aspose.Words.Drawing.Charts;

// Load the .docx that already holds a chart.
Document sourceDoc = new Document("YOUR_DIRECTORY/ChartTemplate.docx");
```

*Γιατί;*  
`Document` είναι το σημείο εισόδου για οποιαδήποτε επεξεργασία Word. Φορτώνοντας το πρότυπο αποκτούμε πρόσβαση σε κάθε κόμβο—σχήματα, πίνακες, κείμενο και, φυσικά, το γράφημα που θα τροποποιήσουμε.

### Βήμα 2: Λήψη του πρώτου σχήματος γραφήματος

```csharp
// The chart lives inside a Shape node; retrieve it.
Chart chart = (Chart)sourceDoc.GetChild(NodeType.Shape, 0, true);
```

*Γιατί;*  
Το Aspose αποθηκεύει τα γραφήματα ως αντικείμενα `Shape`. Η μέθοδος `GetChild` διασχίζει το δέντρο του εγγράφου και επιστρέφει το πρώτο σχήμα που βρίσκει, το οποίο στην περίπτωσή μας είναι το γράφημα πίτας που θέλουμε να επεξεργαστούμε.

### Βήμα 3: Επιβεβαίωση του τύπου γραφήματος

```csharp
if (chart.ChartType == ChartType.Pie || chart.ChartType == ChartType.Doughnut)
{
    // Inside this block we’ll enable the data labels.
}
else
{
    throw new InvalidOperationException("The chart is not a Pie or Doughnut type.");
}
```

*Γιατί;*  
Οι ετικέτες ποσοστών έχουν νόημα μόνο για κυκλικά γραφήματα. Αυτό το έλεγχο αποτρέπει την τυχαία εφαρμογή των ρυθμίσεων σε, π.χ., ένα ραβδόγραμμα όπου το `ShowPercentage` θα αγνοηθεί.

### Βήμα 4: Ενεργοποίηση ετικετών δεδομένων και εμφάνιση ποσοστών

```csharp
// Turn on data labels for the chart.
chart.HasDataLabel = true;

// Show the percentage value for each slice.
chart.DataLabel.ShowPercentage = true;
```

*Γιατί;*  
`HasDataLabel` λέει στο Aspose να αποδώσει μια ετικέτα για κάθε σημείο δεδομένων. Ορίζοντας `ShowPercentage` εξασφαλίζουμε ότι το περιεχόμενο της ετικέτας είναι το υπολογισμένο ποσοστό του συνόλου—ακριβώς αυτό που απαιτεί η **προσθήκη ετικετών δεδομένων σε γράφημα πίτας**.

### Βήμα 5: Τοποθέτηση ετικετών έξω από τις φέτες

```csharp
// Place the labels outside the pie slices for better readability.
chart.DataLabel.Position = ChartDataLabelPosition.OutSideEnd;
```

*Γιατί;*  
Οι ετικέτες μέσα στη φέτα μπορεί να γίνουν στενές, ειδικά όταν οι φέτες είναι μικρές. Το `OutSideEnd` μιμείται το προεπιλεγμένο στυλ “εξωτερικά” που βλέπετε στη διεπαφή του Word, διατηρώντας το γράφημα καθαρό.

### Βήμα 6: Αποθήκευση του ενημερωμένου εγγράφου

```csharp
sourceDoc.Save("YOUR_DIRECTORY/FormattedPieChart.docx");
```

*Γιατί;*  
Η αποθήκευση γράφει όλες τις αλλαγές σε ένα νέο αρχείο. Ανοίξτε το `FormattedPieChart.docx` στο Word και θα δείτε τα ποσοστά εμφανιζόμενα δίπλα σε κάθε φέτα.

#### Αναμενόμενο αποτέλεσμα

Όταν ανοίξετε το `FormattedPieChart.docx`, το γράφημα πίτας θα πρέπει να μοιάζει με το παρακάτω (υποθετική λήψη οθόνης):

```
[ Pie chart with three slices ]
- Slice A – 45%
- Slice B – 30%
- Slice C – 25%
```

Όλα τα ποσοστά υπολογίζονται αυτόματα από τις υποκείμενες σειρές δεδομένων, και οι ετικέτες βρίσκονται ακριβώς έξω από κάθε φέτα.

## Συνηθισμένες παραλλαγές & Ακραίες περιπτώσεις

| Κατάσταση | Τι πρέπει να προσαρμόσετε |
|-----------|---------------------------|
| **Πολλαπλά γραφήματα** στο ίδιο έγγραφο | Κάντε βρόχο μέσω `sourceDoc.GetChildNodes(NodeType.Shape, true)` και μετατρέψτε το καθένα σε `Chart` πριν εφαρμόσετε την ίδια λογική. |
| **Ραβδόγραμμα ή γραμμή** όπου θέλετε ακόμα ετικέτες | Χρησιμοποιήστε `chart.DataLabel.ShowValue = true;` (ή `ShowSeriesName`) αντί για `ShowPercentage`. |
| **Προσαρμοσμένη μορφή αριθμού** (π.χ. “45 %”) | Ορίστε `chart.DataLabel.NumberFormat = "0%";` πριν την αποθήκευση. |
| **Μεγάλα σύνολα δεδομένων** που προκαλούν επικάλυψη ετικετών | Σκεφτείτε `chart.DataLabel.ShowLeaderLines = true;` για να σχεδιάσετε γραμμές σύνδεσης. |

> **Συμβουλή:** Αν δημιουργείτε πολλά έγγραφα σε παρτίδα, δημιουργήστε ένα μόνο αντικείμενο `Aspose.Words.License` κατά την εκκίνηση της εφαρμογής για να αποφύγετε το κόστος απόδοσης της επαναλαμβανόμενης φόρτωσης της άδειας.

## Πλήρες λειτουργικό παράδειγμα

Ακολουθεί ολόκληρο το πρόγραμμα, έτοιμο για εκτέλεση:

```csharp
using System;
using Aspose.Words;
using Aspose.Words.Drawing.Charts;

class Program
{
    static void Main()
    {
        // 1️⃣ Load the template document.
        Document sourceDoc = new Document("YOUR_DIRECTORY/ChartTemplate.docx");

        // 2️⃣ Retrieve the first chart shape.
        Chart chart = (Chart)sourceDoc.GetChild(NodeType.Shape, 0, true);

        // 3️⃣ Ensure we’re dealing with a Pie or Doughnut chart.
        if (chart.ChartType != ChartType.Pie && chart.ChartType != ChartType.Doughnut)
        {
            Console.WriteLine("The selected shape is not a Pie/Doughnut chart.");
            return;
        }

        // 4️⃣ Enable data labels and show percentages.
        chart.HasDataLabel = true;
        chart.DataLabel.ShowPercentage = true;

        // 5️⃣ Position the labels outside the slices.
        chart.DataLabel.Position = ChartDataLabelPosition.OutSideEnd;

        // 6️⃣ Save the modified document.
        sourceDoc.Save("YOUR_DIRECTORY/FormattedPieChart.docx");

        Console.WriteLine("Chart updated successfully – percentages now visible!");
    }
}
```

Αντιγράψτε τον κώδικα, αντικαταστήστε το `YOUR_DIRECTORY` με την πραγματική διαδρομή στον υπολογιστή σας και τρέξτε το. Θα έχετε ένα αρχείο Word με πλήρως επισημασμένο γράφημα πίτας σε δευτερόλεπτα.

## Τι ακολουθεί;

- **Στυλ ετικετών** – αλλάξτε γραμματοσειρά, χρώμα ή προσθέστε φόντο χρησιμοποιώντας `chart.DataLabel.Font`.  
- **Δημιουργία γραφημάτων από το μηδέν** – εξερευνήστε `Chart chart = (Chart)sourceDoc.FirstSection.Body.AppendChild(new Shape(sourceDoc, ShapeType.Chart));` για να δημιουργήσετε γραφήματα προγραμματιστικά.
