# Δημιουργία προτύπου τιμολογίου και συγχώνευση δεδομένων χρησιμοποιώντας το Aspose.Words

Αν χρειάζεστε να **δημιουργήσετε πρότυπο τιμολογίου** γρήγορα, αυτός ο οδηγός σας δείχνει ακριβώς πώς. Στο τέλος των πρώτων δύο προτάσεων θα γνωρίζετε τη πλήρη ροή εργασίας για τη μετατροπή ενός κεννού αρχείου Word σε πλήρως συμπληρωμένο τιμολόγιο, χρησιμοποιώντας το low‑code API συγχώνευσης αλληλογραφίας του Aspose.Words.

Η δημιουργία τιμολογίων είναι μια κοινή απαίτηση για συστήματα τιμολόγησης, ενσωματώσεις ERP και αυτοματοποιημένες αναφορές. Σε αυτό το tutorial θα μάθετε **πώς να κάνετε mail merge**, **να γεμίσετε πρότυπο Word**, **να συγχωνεύσετε δεδομένα σε Word**, και τελικά **να αποθηκεύσετε το συγχωνευμένο έγγραφο**—όλα με λίγες γραμμές C#.

## Τι θα επιτύχετε

* Ένα επαναχρησιμοποιήσιμο πρότυπο Word (`InvoiceTemplate.docx`) που περιέχει πεδία συγχώνευσης για πελάτη, ημερομηνία, στοιχεία γραμμής και σύνολο.  
* Ένα πρόγραμμα C# που φορτώνει το πρότυπο, ενσωματώνει ένα αντικείμενο δεδομένων με ισχυρό τύπο, και γράφει το αποτέλεσμα στο `Invoice_001.docx`.  
* Κατανόηση περιπτώσεων άκρων όπως κενές συλλογές, προσαρμοσμένοι τύποι δεδομένων και διαχείριση διαδρομών αρχείων.

### Προαπαιτούμενα

| Requirement | Why it matters |
|-------------|----------------|
| .NET 6 or later | Το Aspose.Words for .NET υποστηρίζει .NET 6+ και παρέχει το low‑code API που χρησιμοποιείται σε αυτόν τον οδηγό. |
| Aspose.Words for .NET NuGet package (`Aspose.Words`) | Παρέχει `Document`, `MailMerger` και σχετικούς τύπους. |
| Basic C# knowledge | Απαιτείται για την κατανόηση ανώνυμων αντικειμένων και LINQ. |
| Visual Studio 2022 (or any IDE) | Κάνει την επεξεργασία και την αποσφαλμάτωση απλή. |

> **Συμβουλή:** Εγκαταστήστε το πακέτο NuGet μέσω του Package Manager Console:  
> `Install-Package Aspose.Words`

## Πώς να δημιουργήσετε πρότυπο τιμολογίου με low‑code mail merge

Το πρώτο βήμα είναι να δημιουργήσετε ένα αρχείο Word που περιέχει πεδία συγχώνευσης που ταιριάζουν με τις ιδιότητες του αντικειμένου δεδομένων που θα περάσετε αργότερα. Αποθηκεύστε το αρχείο ως `InvoiceTemplate.docx` σε έναν φάκελο που ελέγχετε (π.χ., `C:\Invoices\Template`).

| Πεδίο συγχώνευσης | Παράδειγμα placeholder στο Word |
|-------------|-----------------------------|
| CustomerName | «CustomerName» |
| InvoiceDate | «InvoiceDate» |
| Items (repeating) | «Items.Description», «Items.Qty», «Items.Price» |
| Total | «Total» |

> **Γιατί είναι σημαντικό:** Το low‑code API αντιστοιχίζει αυτόματα τα ονόματα ιδιοτήτων της πηγής δεδομένων στα πεδία συγχώνευσης. Η διατήρηση των ονομάτων ταυτοτήτων εξαλείφει την χειροκίνητη αντιστοίχιση πεδίου‑σε‑ιδιότητα και μειώνει τα σφάλματα χρόνου εκτέλεσης.

## Βήμα 1: Φόρτωση του προτύπου τιμολογίου

```csharp
using Aspose.Words;
using Aspose.Words.LowCode;   // Low‑code mail‑merge API

// Load the Word file that contains the merge fields.
Document template = new Document(@"C:\Invoices\Template\InvoiceTemplate.docx");
```

*Η κλάση `Document` αντιπροσωπεύει ολόκληρο το αρχείο Word. Η φόρτωσή του μία φορά σας επιτρέπει να επαναχρησιμοποιήσετε το ίδιο πρότυπο για πολλά τιμολόγια.*

## Βήμα 2: Προετοιμασία της πηγής δεδομένων

Δημιουργήστε ένα ανώνυμο αντικείμενο που αντικατοπτρίζει τα πεδία συγχώνευσης. Το low‑code API μπορεί να λειτουργήσει με οποιοδήποτε αντικείμενο .NET, συμπεριλαμβανομένων πινάκων και ένθετων συλλογών.

```csharp
var invoiceData = new
{
    CustomerName = "Acme Corp",
    InvoiceDate = DateTime.Today,
    Items = new[]
    {
        new { Description = "Widget A", Qty = 10, Price = 9.99M },
        new { Description = "Widget B", Qty = 5,  Price = 19.95M }
    },
    Total = 199.85M
};
```

**Γιατί λειτουργεί αυτό:**  
* Τα ονόματα ιδιοτήτων (`CustomerName`, `InvoiceDate`, `Items`, `Total`) ταιριάζουν με τα πεδία συγχώνευσης στο πρότυπο.  
* Το `Items` είναι ένας πίνακας αντικειμένων, έτσι ο mail merger θα επαναλάβει τη γραμμή του πίνακα για κάθε στοιχείο αυτόματα.  
* Η χρήση του `decimal` (`M` επίθημα) για χρηματικές τιμές αποφεύγει προβλήματα στρογγυλοποίησης κινητής υποδιαστολής.

### Διαχείριση κενών συλλογών

Αν ένα τιμολόγιο δεν έχει στοιχεία γραμμής, περάστε έναν κενό πίνακα:

```csharp
Items = new object[0]
```

Η μηχανή low‑code θα παραλείψει απλώς την επαναλαμβανόμενη ενότητα, αφήνοντας το κεφαλίδα του πίνακα ανέπαφη.

## Βήμα 3: Αρχικοποίηση του low‑code mail merger

```csharp
MailMerger merger = new MailMerger(template);
```

`MailMerger` είναι το σημείο εισόδου για **πώς να κάνετε mail merge** με το Aspose.Words. Διαβάζει το πρότυπο, συνδέει τα δεδομένα και προετοιμάζει το τελικό έγγραφο με μία κλήση.

## Βήμα 4: Εκτέλεση της συγχώνευσης – γέμισμα του προτύπου Word σε μία γραμμή

```csharp
Document mergedDocument = merger.Execute(invoiceData);
```

* Αυτή η γραμμή **γεμίζει το πρότυπο Word** και δημιουργεί ένα νέο αντικείμενο `Document` (`mergedDocument`).  
* Όλα τα πεδία συγχώνευσης αντικαθίστανται, οι επαναλαμβανόμενες ενότητες επεκτείνονται, και το προκύπτον έγγραφο παραμένει εξ ολοκλήρου στη μνήμη.

### Περίπτωση άκρου: Προσαρμοσμένη μορφοποίηση

Αν χρειάζεστε συγκεκριμένη μορφή ημερομηνίας, προσθέστε έναν προσαρμοσμένο μορφοποιητή πριν από τη συγχώνευση:

```csharp
merger.Options.DateFormat = "MMMM dd, yyyy"; // e.g., "October 07, 2026"
```

## Βήμα 5: Αποθήκευση του συγχωνευμένου εγγράφου

```csharp
mergedDocument.Save(@"C:\Invoices\Output\Invoice_001.docx");
```

Η κλήση **save merged document** γράφει το πλήρως γεμάτο τιμολόγιο στο δίσκο. Το αρχείο μπορεί τώρα να ανοιχτεί στο Microsoft Word, να σταλεί ως συνημμένο email ή να μετατραπεί σε PDF.

### Επαλήθευση του αποτελέσματος

Ανοίξτε το `Invoice_001.docx`. Θα πρέπει να δείτε:

* **CustomerName** αντικατεστημένο με *Acme Corp*  
* **InvoiceDate** εμφανίζει την τρέχουσα ημερομηνία στη επιλεγμένη μορφή  
* Μια γραμμή πίνακα για *Widget A* (10 × 9.99) και *Widget B* (5 × 19.95)  
* **Total** εμφανίζει *199.85*

Αν κάποιο πεδίο παραμείνει αμετάβλητο (π.χ., εξακολουθεί να δείχνει «CustomerName»), ελέγξτε ξανά ότι τα ονόματα ιδιοτήτων ταιριάζουν ακριβώς με τα ονόματα των πεδίων συγχώνευσης στο πρότυπο.

## Πλήρες εκτελέσιμο παράδειγμα

Παρακάτω βρίσκεται το πλήρες πρόγραμμα που μπορείτε να αντιγράψετε‑επικολλήσετε σε ένα νέο έργο κονσόλας.

```csharp
using System;
using Aspose.Words;
using Aspose.Words.LowCode;   // Low‑code mail‑merge API

namespace InvoiceGenerator
{
    class Program
    {
        static void Main()
        {
            // 1️⃣ Load the template
            Document template = new Document(@"C:\Invoices\Template\InvoiceTemplate.docx");

            // 2️⃣ Build the data source
            var invoiceData = new
            {
                CustomerName = "Acme Corp",
                InvoiceDate = DateTime.Today,
                Items = new[]
                {
                    new { Description = "Widget A", Qty = 10, Price = 9.99M },
                    new { Description = "Widget B", Qty = 5,  Price = 19.95M }
                },
                Total = 199.85M
            };

            // 3️⃣ Initialise the mail merger
            MailMerger merger = new MailMerger(template);

            // Optional: customise date format
            merger.Options.DateFormat = "MMMM dd, yyyy";

            // 4️⃣ Perform the merge (populate word template)
            Document mergedDocument = merger.Execute(invoiceData);

            // 5️⃣ Save the resulting file (save merged document)
            mergedDocument.Save(@"C:\Invoices\Output\Invoice_001.docx");

            Console.WriteLine("Invoice generated successfully.");
        }
    }
}
```

Εκτελέστε το πρόγραμμα (`dotnet run`). Η κονσόλα εκτυπώνει *Invoice generated successfully.* και το αρχείο εμφανίζεται στο `C:\Invoices\Output`.
