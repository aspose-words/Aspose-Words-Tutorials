# Δημιουργία κενής εγγράφου Word και απόκρυψη σχήματος έλλειψης σε C#

Αν χρειάζεται να **δημιουργήσετε κενό έγγραφο Word** και στη συνέχεια να κρύψετε ένα γραφικό στοιχείο, αυτός ο οδηγός σας δείχνει ακριβώς πώς να το κάνετε με C#. Θα δείτε ένα πλήρες, εκτελέσιμο παράδειγμα που εισάγει μια έλλειψη, την τοποθετεί, την ορίζει ως κρυφή και αποθηκεύει το αρχείο—όλα σε λίγες γραμμές κώδικα.

Το tutorial καλύπτει τα πάντα, από τη ρύθμιση του έργου μέχρι το τελικό βήμα επαλήθευσης. Στο τέλος, θα μπορείτε να δημιουργήσετε ένα αρχείο Word όπου η έλλειψη δεν εμφανίζεται ούτε στην οθόνη ούτε στην εκτύπωση, κάτι χρήσιμο για αποθήκευση μεταδεδομένων, σελιδοδεικτών ή οποιουδήποτε αόρατου δείκτη.

## Προαπαιτούμενα

Πριν ξεκινήσετε, βεβαιωθείτε ότι έχετε:

* .NET 6.0 SDK ή νεότερη έκδοση εγκατεστημένη  
* Περιβάλλον ανάπτυξης C# (Visual Studio 2022, Rider ή VS Code)  
* Το **Aspose.Words for .NET** πακέτο NuGet (`Install-Package Aspose.Words`)  

Αυτά τα εργαλεία παρέχουν τις κλάσεις `Document` και `DocumentBuilder` που χρησιμοποιούνται στο παράδειγμα κώδικα.

## Βήμα 1: Δημιουργία κενής εγγράφου Word

Η πρώτη ενέργεια δημιουργεί ένα κενό αντικείμενο `Document` και έναν `DocumentBuilder` που σας επιτρέπει να προσθέτετε περιεχόμενο.

```csharp
using Aspose.Words;
using Aspose.Words.Drawing;

// Step 1: Initialize an empty document and a builder
Document doc = new Document();
DocumentBuilder builder = new DocumentBuilder(doc);
```

Το `Document` αντιπροσωπεύει ολόκληρο το πακέτο `.docx`, ενώ το `DocumentBuilder` προσφέρει μια fluent API για εισαγωγή κειμένου, σχημάτων και άλλων αντικειμένων. Ξεκινώντας με ένα κενό έγγραφο έχετε πλήρη έλεγχο σε κάθε στοιχείο που προσθέτετε.

## Βήμα 2: Πώς να εισάγετε έλλειψη

Μια έλλειψη είναι ένα διανυσματικό σχήμα που μπορεί να χρησιμοποιηθεί ως δείκτης. Η μέθοδος `InsertShape` απαιτεί τον τύπο σχήματος και το πλάτος/ύψος του σε points.

```csharp
// Step 2: Insert an ellipse shape of the desired size (100 pt × 50 pt)
Shape ellipse = builder.InsertShape(ShapeType.Ellipse, 100, 50);
```

Η έλλειψη τοποθετείται στη τρέχουσα σελίδα στη θέση του δρομέα. Μπορείτε να αλλάξετε τις διαστάσεις της προσαρμόζοντας τα αριθμητικά ορίσματα.

## Βήμα 3: Πώς να τοποθετήσετε το σχήμα

Μετά την εισαγωγή, μπορείτε να μετακινήσετε το σχήμα οπουδήποτε στη σελίδα ορίζοντας τις ιδιότητες `Left` και `Top`, οι οποίες χρησιμοποιούν points σε σχέση με το περιθώριο της σελίδας.

```csharp
// Step 3: Position the shape on the page
ellipse.Left = 150; // distance from the left margin
ellipse.Top  = 100; // distance from the top margin
```

Αυτές οι συντεταγμένες τοποθετούν την έλλειψη περίπου στο πάνω‑μέσο μιας τυπικής σελίδας A4. Προσαρμόστε τις τιμές ώστε να ταιριάζουν στις απαιτήσεις του σχεδίου σας.

## Βήμα 4: Πώς να κρύψετε το σχήμα

Ένα κρυφό αντικείμενο δεν εμφανίζεται όταν το έγγραφο ανοίγει ή εκτυπώνεται. Ορίζοντας τη σημαία `Hidden` το σχήμα χαρακτηρίζεται ως **hidden object word**.

```csharp
// Step 4: Hide the shape so it never appears
ellipse.Hidden = true;
```

Το Word σέβεται τη σημαία hidden τόσο για την απόδοση στην οθόνη όσο και για την εκτύπωση. Το σχήμα παραμένει μέρος της δομής του εγγράφου, επιτρέποντάς σας να το ερωτήσετε ή να το τροποποιήσετε αργότερα μέσω κώδικα.

## Βήμα 5: Αποθήκευση του εγγράφου

Τέλος, γράψτε το έγγραφο στο δίσκο. Επιλέξτε έναν φάκελο όπου έχετε δικαιώματα εγγραφής.

```csharp
// Step 5: Save the document to a .docx file
doc.Save(@"C:\Temp\HiddenEllipse.docx");
```

Το αρχείο `HiddenEllipse.docx` περιέχει τώρα μια κενή σελίδα με ένα κρυφό σχήμα έλλειψης.

## Επαλήθευση της κρυφής έλλειψης

Ανοίξτε το παραγόμενο αρχείο στο Microsoft Word και ενεργοποιήστε την επιλογή **Show hidden text** (Αρχείο → Επιλογές → Προβολή). Θα δείτε ένα αχνό περίγραμμα της έλλειψης. Αν απενεργοποιήσετε την επιλογή, το σχήμα εξαφανίζεται εντελώς, επιβεβαιώνοντας ότι `ellipse.Hidden = true` λειτουργεί όπως αναμένεται.

## Συνηθισμένες παραλλαγές και ειδικές περιπτώσεις

| Κατάσταση | Συνιστώμενη προσαρμογή |
|-----------|------------------------|
| **Διαφορετικό σχήμα** | Αντικαταστήστε το `ShapeType.Ellipse` με `ShapeType.Rectangle`, `ShapeType.Arrow` κ.λπ. |
| **Πολλαπλά κρυφά αντικείμενα** | Επαναλάβετε τα βήματα 2‑4 για κάθε σχήμα· το καθένα μπορεί να έχει τη δική του σημαία `Hidden`. |
| **Διαφορετικό μέγεθος σελίδας** | Ορίστε `doc.FirstSection.PageSetup.PageWidth` και `PageHeight` πριν την εισαγωγή του σχήματος. |
| **Υποσυνθήκη ορατότητας** | Χρησιμοποιήστε `Shape.Visible` σε συνδυασμό με `Hidden` για εναλλαγή κατά το runtime μέσω κώδικα. |

**Συμβουλή:** Αποθηκεύστε δεδομένα ταυτοποίησης στην ιδιότητα `AlternativeText` του σχήματος. Ακόμη και όταν είναι κρυφό, μπορείτε να ανακτήσετε το σχήμα αργότερα με `doc.GetChildNodes(NodeType.Shape, true)` και να φιλτράρετε με αυτό το κείμενο.

## Πλήρης κώδικας πηγής

Παρακάτω βρίσκεται το πλήρες πρόγραμμα που μπορείτε να αντιγράψετε, επικολλήσετε και εκτελέσετε.

```csharp
using System;
using Aspose.Words;
using Aspose.Words.Drawing;

namespace HiddenShapeDemo
{
    class Program
    {
        static void Main()
        {
            // Create a new blank document and a builder
            Document doc = new Document();
            DocumentBuilder builder = new DocumentBuilder(doc);

            // Insert an ellipse shape (100 pt × 50 pt)
            Shape ellipse = builder.InsertShape(ShapeType.Ellipse, 100, 50);

            // Position the shape on the page
            ellipse.Left = 150;
            ellipse.Top  = 100;

            // Hide the shape so it is invisible in the UI and on print
            ellipse.Hidden = true;

            // Optional: add a description for later retrieval
            ellipse.AlternativeText = "Hidden marker for internal processing";

            // Save the document
            string outputPath = @"C:\Temp\HiddenEllipse.docx";
            doc.Save(outputPath);

            Console.WriteLine($"Document saved to {outputPath}");
        }
    }
}
```

**Αναμενόμενο αποτέλεσμα:** Η κονσόλα εκτυπώνει τη διαδρομή αποθήκευσης, και το αρχείο `HiddenEllipse.docx` ανοίγει ως κενή σελίδα χωρίς ορατά γραφικά, εκτός εάν εμφανιστούν τα κρυφά αντικείμενα.
