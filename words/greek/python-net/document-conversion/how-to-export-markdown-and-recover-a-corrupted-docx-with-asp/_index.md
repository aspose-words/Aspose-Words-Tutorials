# Πώς να εξάγετε markdown και να ανακτήσετε ένα κατεστραμμένο DOCX με Aspose.Words

Αν χρειάζεστε **πώς να εξάγετε markdown** από ένα αρχείο Word που μπορεί να είναι κατεστραμμένο, αυτός ο οδηγός σας δείχνει τα ακριβή βήματα. Καλύπτει επίσης **πώς να ανακτήσετε το έγγραφο**, **εξαγωγή docx σε txt**, και **αποθήκευση word ως pdf** χρησιμοποιώντας το Aspose.Words for Python API.

Θα περάσετε από τη φόρτωση ενός πιθανώς κατεστραμμένου DOCX σε λειτουργία ανάκτησης, τη μετατροπή του σε Markdown διατηρώντας τις εξισώσεις, την αποθήκευση του ίδιου περιεχομένου ως απλό κείμενο, τη δημιουργία ενός προσβάσιμου PDF, και ακόμη την προσαρμογή της σκιάς ενός σχήματος πριν την τελική εξαγωγή. Δεν απαιτούνται εξωτερικά εργαλεία—μόνο το Aspose.Words και μερικές γραμμές Python.

## Προαπαιτούμενα

Πριν ξεκινήσετε, βεβαιωθείτε ότι έχετε:

* Python 3.8 ή νεότερο
* Πακέτο `aspose-words` (`pip install aspose-words`)
* Ένα αρχείο DOCX που μπορεί να είναι κατεστραμμένο (ή οποιοδήποτε κανονικό DOCX για δοκιμές)
* Βασική εξοικείωση με συναρτήσεις και κλάσεις Python

> **Συμβουλή:** Κρατήστε αντίγραφο ασφαλείας του αρχικού DOCX· η λειτουργία ανάκτησης τροποποιεί την αναπαράσταση στη μνήμη αλλά δεν γράφει ξανά στο αρχικό αρχείο.

## Βήμα 1: Πώς να ανακτήσετε κατεστραμμένο DOCX

Το πρώτο εμπόδιο είναι η ασφαλής φόρτωση του αρχείου. Το Aspose.Words παρέχει τη σημαία `RecoveryMode.RECOVER_CORRUPTED` που προσπαθεί να ξαναχτίσει μια σπασμένη δομή εγγράφου.

```python
import aspose.words as aw

# Load the file in recovery mode
load_opts = aw.LoadOptions()
load_opts.recovery_mode = aw.RecoveryMode.RECOVER_CORRUPTED
doc = aw.Document("YOUR_DIRECTORY/input.docx", load_opts)
```

**Γιατί είναι σημαντικό:**  
Όταν ένα DOCX είναι μερικώς κατεστραμμένο—λείπουν μέρη, σπασμένο XML ή εσφαλμένες σχέσεις—η κανονική φόρτωση ρίχνει εξαίρεση. Η λειτουργία ανάκτησης αναλύει ό,τι μπορεί, απορρίπτοντας τα μη αναγνώσιμα τμήματα ενώ διατηρεί το υπόλοιπο, κάτι που είναι απαραίτητο για οποιαδήποτε επακόλουθη **εξαγωγή docx σε txt** ή **αποθήκευση word ως pdf**.

### Συνηθισμένη ακραία περίπτωση
Αν το έγγραφο είναι πέρα από την επισκευή, το `doc` θα δημιουργηθεί όμως με ένα προειδοποιητικό μήνυμα. Μπορείτε να ελέγξετε το `doc.is_dirty` για να δείτε αν κάποιο περιεχόμενο τροποποιήθηκε κατά την ανάκτηση.

## Βήμα 2: Πώς να εξάγετε markdown με Aspose.Words

Το Markdown είναι μια ελαφριά γλώσσα σήμανσης που αγαπούν πολλοί δημιουργοί στατικών ιστοτόπων και εργαλεία τεκμηρίωσης. Το Aspose.Words μπορεί να παράγει Markdown διατηρώντας τις εξισώσεις ως LaTeX, κάτι ιδανικό για τεχνική τεκμηρίωση.

```python
# Configure Markdown export options
md_opts = aw.MarkdownSaveOptions()
md_opts.office_math_export_mode = aw.OfficeMathExportMode.LATEX

# Save as Markdown
doc.save("YOUR_DIRECTORY/output.md", md_opts)
```

**Τι λαμβάνετε:**  
* Απλό κείμενο με επικεφαλίδες, λίστες και πίνακες μετατρεπόμενα σε σύνταξη Markdown.  
* Κάθε εξίσωση Word αποδίδεται ως μπλοκ LaTeX (`$$ … $$`), διασφαλίζοντας ότι τα μαθηματικά παραμένουν επεξεργάσιμα σε επόμενα εργαλεία.

### Επαλήθευση του αποτελέσματος
Ανοίξτε το `output.md` σε οποιονδήποτε επεξεργαστή. Θα πρέπει να δείτε κάτι σαν:

```markdown
# Title of the Document

This is a paragraph with **bold** text.

$$
\int_{0}^{\infty} e^{-x} dx = 1
$$
```

Αν χρειάζεστε διαφορετική μορφή εξίσωσης (π.χ. MathML), αλλάξτε το `office_math_export_mode` ανάλογα.

## Βήμα 3: Εξαγωγή docx σε txt διατηρώντας τις εξισώσεις

Τα αρχεία απλού κειμένου είναι χρήσιμα για γρήγορες αναζητήσεις ή για τροφοδότηση σε pipelines φυσικής γλώσσας. Η ίδια ρύθμιση `OfficeMathExportMode.LATEX` λειτουργεί και για εξαγωγή σε `.txt`, δίνοντάς σας LaTeX ενσωματωμένο.

```python
txt_opts = aw.TxtSaveOptions()
txt_opts.office_math_export_mode = aw.OfficeMathExportMode.LATEX

doc.save("YOUR_DIRECTORY/output.txt", txt_opts)
```

**Γιατί να το χρησιμοποιήσετε αντί για αντιγραφή‑επικόλληση;**  
Η χειροκίνητη αντιγραφή‑επικόλληση συχνά αφαιρεί κρυφούς χαρακτήρες και χάνει την ακρίβεια των εξισώσεων. Αυτή η **εξαγωγή docx σε txt** εγγυάται ότι κάθε εξίσωση εμφανίζεται ως απόσπασμα LaTeX, έτοιμο για περαιτέρω επεξεργασία.

## Βήμα 4: Αποθήκευση word ως PDF με ενσωματωμένα σχήματα για καλύτερη προσβασιμότητα

Το PDF είναι το de‑facto φορμάτ για δημοσίευση. Όταν ένα έγγραφο Word περιέχει αιωρούμενες εικόνες ή διαγράμματα, ορισμένοι αναγνώστες μπορεί να μην τα ερμηνεύσουν σωστά. Η ρύθμιση `export_floating_shapes_as_inline_tag` μετατρέπει αυτά τα σχήματα σε ενσωματωμένα, βελτιώνοντας την προσβασιμότητα και τη συνοχή της διάταξης.

```python
pdf_opts = aw.PdfSaveOptions()
pdf_opts.export_floating_shapes_as_inline_tag = True

doc.save("YOUR_DIRECTORY/output.pdf", pdf_opts)
```

**Αποτέλεσμα:**  
Ένα PDF που αντικατοπτρίζει την αρχική διάταξη, αλλά όλα τα σχήματα είναι πλέον μέρος της ροής κειμένου. Αυτό είναι ιδιαίτερα χρήσιμο για αναγνώστες οθόνης, καθώς αντιμετωπίζουν τα ενσωματωμένα στοιχεία ως μέρος της σειράς ανάγνωσης.

### Συμβουλή για μεγάλα έγγραφα
Αν δημιουργείτε PDFs σε παρτίδες, επαναχρησιμοποιήστε το ίδιο αντικείμενο `PdfSaveOptions` για να αποφύγετε περιττές δημιουργίες αντικειμένων.

## Βήμα 5: Λεπτομερής ρύθμιση της σκιάς ενός σχήματος πριν το τελικό PDF

Μερικές φορές χρειάζεται να προσαρμόσετε οπτικές λεπτομέρειες—όπως τη σκιά ενός λογότυπου—πριν τη δημοσίευση. Το παρακάτω παράδειγμα παίρνει το πρώτο σχήμα, τροποποιεί τις ιδιότητες της σκιάς και αποθηκεύει ένα νέο PDF.

```python
# Retrieve the first shape in the document
shape = doc.get_child(aw.NodeType.SHAPE, 0, True).as_shape()

# Adjust shadow settings
shape.shadow.blur_radius = 5.0   # Soft blur
shape.shadow.distance = 2.0     # Distance from shape edge
shape.shadow.opacity = 0.6      # 60% opacity

# Save the shadow‑enhanced PDF
doc.save("YOUR_DIRECTORY/shadowed.pdf", pdf_opts)
```

**Τι κάνει:**  
* Το `blur_radius` ελέγχει πόσο θολή είναι η σκιά.  
* Η `distance` μετακινεί τη σκιά μακριά από το σχήμα, δημιουργώντας βάθος.  
* Η `opacity` κάνει τη σκιά ημιδιαφανή, κάτι που συχνά φαίνεται πιο επαγγελματικό.

Μπορείτε να επαναλάβετε αυτό το μπλοκ για οποιοδήποτε σχήμα αλλάζοντας το δείκτη στο `get_child`.

## Πλήρες script για γρήγορη αντιγραφή‑επικόλληση

Παρακάτω βρίσκεται το πλήρες, εκτελέσιμο script που συνδυάζει όλα τα βήματα. Αντικαταστήστε το `YOUR_DIRECTORY` με τη διαδρομή όπου βρίσκονται τα αρχεία σας.

```python
import aspose.words as aw

# -------------------------------------------------
# 1️⃣ Recover a possibly corrupted DOCX
# -------------------------------------------------
load_opts = aw.LoadOptions()
load_opts.recovery_mode = aw.RecoveryMode.RECOVER_CORRUPTED
doc = aw.Document("YOUR_DIRECTORY/input.docx", load_opts)

# -------------------------------------------------
# 2️⃣ Export to Markdown (how to export markdown)
# -------------------------------------------------
md_opts = aw.MarkdownSaveOptions()
md_opts.office_math_export_mode = aw.OfficeMathExportMode.LATEX
doc.save("YOUR_DIRECTORY/output.md", md_opts)

# -------------------------------------------------
# 3️⃣ Export to plain text (export docx to txt)
# -------------------------------------------------
txt_opts = aw.TxtSaveOptions()
txt_opts.office_math_export_mode = aw.OfficeMathExportMode.LATEX
doc.save("YOUR_DIRECTORY/output.txt", txt_opts)

# -------------------------------------------------
# 4️⃣ Save as PDF (save word as pdf)
# -------------------------------------------------
pdf_opts = aw.PdfSaveOptions()
pdf_opts.export_floating_shapes_as_inline_tag = True
doc.save("YOUR_DIRECTORY/output.pdf", pdf_opts)

# -------------------------------------------------
# 5️⃣ Adjust first shape's shadow and re‑save PDF
# -------------------------------------------------
shape = doc.get_child(aw.NodeType.SHAPE, 0, True).as_shape()
shape.shadow.blur_radius = 5.0
shape.shadow.distance = 2.0
shape.shadow.opacity = 0.6
doc.save("YOUR_DIRECTORY/shadowed.pdf", pdf_opts)
```

Η εκτέλεση του script παράγει:

| Αρχείο | Σκοπός |
|--------|--------|
| `output.md` | Markdown με εξισώσεις LaTeX (**πώς να εξάγετε markdown**) |
| `output.txt` | Έκδοση απλού κειμένου (**εξαγωγή docx σε txt**) |
| `output.pdf` | Προσβάσιμο PDF (**αποθήκευση word ως pdf**) |
| `shadowed.pdf` | PDF με σχήμα προσαρμοσμένης σκιάς |

**Ε: Τι γίνεται αν θέλω να κρατήσω τα αιωρούμενα σχήματα ως αιωρούμενα;**  
Α: Παραλείψτε το `export_floating_shapes_as_inline_tag` ή ορίστε το σε `False`.

**Ε: Είναι η εξαγωγή LaTeX συμβατή με MathJax;**  
Α: Απόλυτα. Το MathJax αποδίδει τα μπλοκ `$$ … $$` που δημιουργούν οι εξαγωγείς Markdown και Txt.
