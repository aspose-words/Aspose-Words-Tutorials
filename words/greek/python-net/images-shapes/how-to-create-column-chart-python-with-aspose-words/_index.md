# Πώς να δημιουργήσετε γράφημα στήλης Python με Aspose.Words

Εάν χρειάζεστε να δημιουργήσετε γράφημα στήλης Python, αυτός ο οδηγός δείχνει τον ακριβή κώδικα και τη λογική που χρειάζεστε. Χρησιμοποιώντας το API γραφημάτων του Aspose.Words, μπορείτε να ορίσετε ακριβείς διαστάσεις, να εφαρμόσετε ένα ενσωματωμένο στυλ και να εξάγετε το αποτέλεσμα χωρίς να αφήσετε το Python.

Η δημιουργία γραφήματος στήλης είναι συχνή απαίτηση για αναφορές, πίνακες ελέγχου και αυτοματοποιημένη δημιουργία εγγράφων. Αυτό το tutorial καλύπτει κάθε βήμα—από την εισαγωγή της βιβλιοθήκης μέχρι την επαλήθευση της αποθηκευμένης εικόνας—ώστε να μπορείτε να ενσωματώσετε τη δημιουργία γραφημάτων σε οποιοδήποτε έργο Python.

## Προαπαιτήσεις

Πριν ξεκινήσετε, βεβαιωθείτε ότι έχετε:

* Python 3.8 ή νεότερη έκδοση εγκατεστημένη.
* Ένα έγκυρο άδεια Aspose.Words για Python (ή ένα δωρεάν κλειδί αξιολόγησης).
* Βασική εξοικείωση με τα modules Python και τον αντικειμενοστραφή κώδικα.

Η μηχανή γραφημάτων του Aspose.Words λειτουργεί σε Windows, macOS και Linux, και δεν απαιτεί πρόσθετες γραφικές βιβλιοθήκες επειδή η απόδοση γίνεται στην πλευρά του διακομιστή.

## Βήμα 1: Εισαγωγή της βιβλιοθήκης Aspose.Words

Το πρώτο βήμα είναι η εισαγωγή του πακέτου `aspose.words` και η ανάθεση ενός σύντομου ψευδώνυμου. Η εισαγωγή στην αρχή του αρχείου διατηρεί το namespace καθαρό και κάνει τον κώδικα πιο ευανάγνωστο.

```python
# Step 1: Import the Aspose.Words library
import aspose.words as aw
```

`aw` τώρα αναφέρεται στο πλήρες API του Aspose.Words, συμπεριλαμβανομένης της κλάσης `Chart` που θα χρησιμοποιήσετε για να δημιουργήσετε το γράφημα στήλης.

## Βήμα 2: Δημιουργία γραφήματος στήλης με τις επιθυμητές διαστάσεις

Ένα γράφημα στήλης χρειάζεται ρητές τιμές πλάτους και ύψους ώστε η αποδοθείσα εικόνα να ταιριάζει στη διάταξη του εγγράφου σας. Ο κατασκευαστής `Chart` δέχεται τρία ορίσματα: τον τύπο γραφήματος, το πλάτος (σε points) και το ύψος (σε points). Η χρήση του `aw.ChartType.COLUMN` λέει στη μηχανή να δημιουργήσει ένα κατακόρυφο γράφημα ράβδων.

```python
# Step 2: Create a column chart with the desired dimensions
chart = aw.Chart(aw.ChartType.COLUMN, 400, 300)   # width=400pt, height=300pt
```

*Γιατί να ορίσετε διαστάσεις;*  
Όταν ενσωματώνετε το γράφημα σε έγγραφο Word ή το εξάγετε ως εικόνα, το περιβάλλον περιεχομένου σέβεται το ακριβές μέγεθος που παρέχετε. Αυτό αποτρέπει ανεπιθύμητη κλιμάκωση ή αποκοπή.

### Συμβουλή: Χρησιμοποιήστε `chart.dimensions` για δυναμική αλλαγή μεγέθους

Εάν το σύνολο δεδομένων σας διαφέρει, μπορείτε να υπολογίσετε το μέγεθος με βάση τον αριθμό των σειρών:

```python
series_count = 5
base_width = 80
chart.width = base_width * series_count
chart.height = 300
```

## Βήμα 3: Εφαρμογή ενσωματωμένου στυλ στο γράφημα στήλης

Το Aspose.Words παρέχει αρκετά προκαθορισμένα οπτικά θέματα. Η επιλογή ενός στυλ αφαιρεί την ανάγκη διαμόρφωσης χρωμάτων, γραμματοσειρών και πλέγματος με το χέρι. Το `aw.ChartStyle.STYLE_5` είναι μια καθαρή, επαγγελματική εμφάνιση κατάλληλη για τις περισσότερες επιχειρηματικές αναφορές.

```python
# Step 3: Apply a built‑in style to the chart
chart.style = aw.ChartStyle.STYLE_5
```

Αν προτιμάτε διαφορετική εμφάνιση, αντικαταστήστε το `STYLE_5` με οποιαδήποτε από τις άλλες σταθερές (`STYLE_1` … `STYLE_8`). Κάθε στυλ ακολουθεί την ίδια ονομαστική σύμβαση, καθιστώντας εύκολο το πειραματισμό.

### Ακραία περίπτωση: Μη έγκυρη σταθερά στυλ

Η προσπάθεια ανάθεσης ενός μη υπάρχοντος στυλ προκαλεί `AttributeError`. Προστατέψτε τον κώδικα ελέγχοντας τη σταθερά έναντι της απαρίθμησης:

```python
if hasattr(aw.ChartStyle, "STYLE_5"):
    chart.style = aw.ChartStyle.STYLE_5
else:
    raise ValueError("Requested chart style does not exist.")
```

## Βήμα 4: Προσθήκη σειρών δεδομένων στο γράφημα στήλης

Ένα γράφημα χωρίς δεδομένα είναι άσκοπο. Μπορείτε να προσθέσετε ένα ή περισσότερα αντικείμενα `ChartSeries`, το καθένα αντιπροσωπεύει μια ομάδα στηλών. Το παρακάτω παράδειγμα προσθέτει μία σειρά με τρία σημεία δεδομένων.

```python
# Step 4: Add data series to the column chart
series = chart.series.add()
series.name = "Quarterly Sales"
series.data = [12000, 15000, 18000]   # Values for Q1, Q2, Q3
```

Μπορείτε να επαναλάβετε την κλήση `chart.series.add()` για να συμπεριλάβετε επιπλέον σειρές (π.χ., “Προβλεπόμενες Πωλήσεις”). Το API κατανέμει αυτόματα τις στήλες δίπλα-δίπλα.

## Βήμα 5: Απόδοση του γραφήματος και αποθήκευση ως εικόνα

Αφού διαμορφώσετε το γράφημα, το αποδίδετε σε bitmap ή αρχείο εικόνας. Η μέθοδος `save` δέχεται διαδρομή αρχείου και προαιρετική μορφή. Το PNG είναι χωρίς απώλειες και ευρέως υποστηριζόμενο.

```python
# Step 5: Render and save the chart as a PNG image
output_path = "column_chart.png"
chart.save(output_path, aw.SaveFormat.PNG)
print(f"Chart saved to {output_path}")
```

Η απαρίθμηση `SaveFormat` περιλαμβάνει PNG, JPEG, BMP και άλλα. Επιλέξτε τη μορφή που ταιριάζει στη συνέχεια της ροής εργασίας σας.

Ανοίξτε το `column_chart.png` με οποιονδήποτε προβολέα εικόνων. Θα πρέπει να δείτε ένα γράφημα τριών στηλών με στυλ το επιλεγμένο ενσωματωμένο θέμα, με μέγεθος ακριβώς 400 × 300 points.

Εάν η εικόνα εμφανίζεται κενή ή παραμορφωμένη, ελέγξτε ξανά τα εξής:

1. Το αντικείμενο `aw.Chart` δημιουργήθηκε πριν την προσθήκη σειρών.
2. Η σταθερά `chart.style` ταιάζει με μια υπάρχουσα τιμή enum.
3. Η κλήση `save` χρησιμοποιεί ένα υποστηριζόμενο `SaveFormat`.

## Συνηθισμένες παραλλαγές και πρόσθετες συμβουλές

| Κατάσταση | Συνιστώμενη αλλαγή |
|-----------|--------------------|
| **Πολλαπλές σειρές δεδομένων** | Προσθέστε επιπλέον μπλοκ `chart.series.add()` και ορίστε `series.name` και `series.data` για κάθε μία. |
| **Προσαρμοσμένα χρώματα** | Μετά την εφαρμογή ενσωματωμένου στυλ, παρακάμψτε τα χρώματα των επιμέρους στηλών μέσω `series.points[i].fill.fore_color`. |
| **Ενσωμάτωση σε έγγραφο Word** | Αντί για `chart.save()`, χρησιμοποιήστε `doc = aw.Document(); doc.sections[0].body.append_child(chart); doc.save("report.docx")`. |
| **Δυναμικό μέγεθος** | Υπολογίστε το πλάτος με βάση τον αριθμό των σειρών (`width = 80 * len(chart.series)`). |

Αυτές οι παραλλαγές δείχνουν πώς ο ίδιος βασικός κώδικας προσαρμόζεται σε διαφορετικά σενάρια αναφοράς.
