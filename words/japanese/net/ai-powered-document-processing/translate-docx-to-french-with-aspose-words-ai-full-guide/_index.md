# Aspose.Words.AI を使用した docx のフランス語への翻訳 – 完全ガイド

IDEを離れずに **docx をフランス語に翻訳** したことがありますか？ あなただけではありません。多くの開発者が契約書、マニュアル、マーケティングパンフレットなどをその場でローカライズする必要があり、手作業で行うのは誰もが感じる痛みです。

このチュートリアルでは、DOCX からテキストを抽出し、Aspose.Words.AI に送信し、フランス語版をディスクに書き戻す、完全に実行可能なソリューションをご紹介します。余計なサービスは不要、コピー＆ペーストも不要、仕事を完遂する純粋な C# コードだけです。

## このガイドでカバーする内容

プログラムで **word ドキュメントの言語を変換** するために必要な手順をすべて解説します：

1. Aspose.Words for .NET ライブラリのセットアップ（ライセンスに関する注意点を含む）。  
2. DOCX ファイルを読み込み、**docx からテキストを抽出** する。  
3. 組み込みの AI 翻訳機能を呼び出して **AI で docx を翻訳** する。  
4. 翻訳されたコンテンツを新しい Word ファイルとして保存し、実質的に **word ドキュメントの言語を変換** するエンドツーエンドの流れを実装する。  

最後まで実行すれば、Word、LibreOffice、またはフォーマットをサポートする任意のビューアで開けるフランス語版 DOCX が手に入ります。

---

## 前提条件 – 作業開始前に必要なもの

- **.NET 6.0 以降** – コードは .NET 6 を対象としていますが、.NET 5 でも動作します。  
- **Aspose.Words for .NET**（v24.9 以上） – `Aspose.Words.AI` 名前空間が含まれています。  
- 有効な **Aspose ライセンス**（または一時的な評価キー） – これがないと 20 ページの制限に達します。  
- `input.docx` という名前の入力 Word ファイルを、参照可能なフォルダーに配置しておくこと。  

まだ NuGet パッケージをインストールしていない場合は、次のコマンドを実行してください：

```bash
dotnet add package Aspose.Words
```

> **Pro tip:** パッケージを追加すると Visual Studio が自動的に `Aspose.Words.AI` アセンブリを取得するため、追加の参照設定は不要です。

---

## Step 1: Load the Source Document

最初に行うのは、元のファイルを指す `Document` オブジェクトを作成することです。これは本を読む前に最初のページを開くイメージです。

```csharp
using Aspose.Words;
using Aspose.Words.AI;

// Adjust the path to where your DOCX lives
string sourcePath = @"C:\MyDocs\input.docx";

// Load the document – this also loads styles, images, etc.
Document sourceDoc = new Document(sourcePath);
```

> **Why this matters:** ドキュメントをロードすることで、テキスト、テーブル、ヘッダーなどすべてのパーツにアクセスできるようになります。プレーンテキストだけが必要な場合は次のステップをスキップできますが、翻訳後に書式を保持したいのであればフル構造が必要です。

---

## Step 2: Extract Text from docx (and Preserve Layout)

`sourceDoc.GetText()` を呼び出すだけだと、レイアウト情報のない生の文字列が返ります。多くの翻訳 API では問題ありませんが、Aspose.Words.AI はドキュメントのテキストを直接扱い、元のレイアウトを保持したまま処理できます。

```csharp
// Extract the raw text – this is what we’ll feed to the translator
string originalText = sourceDoc.GetText();
Console.WriteLine("Original text length: " + originalText.Length);
```

*「本当にテキストを抽出する必要がありますか？ ファイル全体を翻訳できないのですか？」*  
答えは **はい**、ファイル全体を翻訳することは可能ですが、先にテキストを抽出しておくことで **前処理**（機密部分の除去、カスタム用語集の適用など）を AI に渡す前に行う余地が生まれます。

---

## Step 3: Translate docx with AI – French Edition

さあ、楽しいパートです。Aspose.Words.AI には重い処理を抽象化した `Translator` クラスが用意されています。ソーステキストとターゲット言語の enum を渡すだけです。

```csharp
// Translate the extracted text to French
string frenchText = Translator.Translate(
    originalText,
    Language.French); // Language enum lives in Aspose.Words.AI
Console.WriteLine("Translation completed. French characters: " + frenchText.Length);
```

> **How it works:** 背後では Aspose がクラウドベースのニューラルモデル（OpenAI の GPT に似たもの）を呼び出し、文書翻訳に特化したファインチューニングが施されています。API がトークナイズ、コンテキスト保持、基本的な書式復元まで処理します。

### 考慮すべきエッジケース

| 状況 | 対応策 |
|-----------|------------|
| 非常に大きなドキュメント（>10 MB） | テキストを 5 000 文字ごとのチャンクに分割し、各チャンクに `Translator.Translate` を呼び出して結果を結合する。 |
| 機密データ | ライセンスに `Translator.TranslateSecure` が含まれている場合はそれを使用し、ネットワークに送信する前にペイロードを暗号化する。 |
| 混在言語のソース | まず `LanguageDetector.Detect` で言語を検出し、フランス語以外の部分だけを翻訳する。 |

## Step 4: Convert Word Document Language – Write Back the French Content

ここまででフランス語テキストの文字列が手に入りました。元のスタイリングを保持するために、ドキュメントの本文を新しい `Section` に置き換えて、翻訳済みテキストを挿入します。

```csharp
// Clear existing sections (optional – keep if you want to preserve headers/footers)
sourceDoc.Sections.Clear();

// Create a new section for the French content
Section frenchSection = new Section(sourceDoc);
sourceDoc.Sections.Add(frenchSection);

// Add a paragraph with the translated text
Paragraph para = new Paragraph(sourceDoc);
para.ParagraphFormat.StyleIdentifier = StyleIdentifier.Normal;
para.AppendChild(new Run(sourceDoc, frenchText));
frenchSection.Body.AppendChild(para);
```

元のレイアウト（テーブル、画像など）をそのまま残したい場合は、各 `Run` ノードのテキストを個別に置き換える方法もあります。やや高度ですが、基本的な考え方は同じです。

---

## Step 5: Save the Translated Document – Your New French DOCX

最後に、更新した `Document` オブジェクトをディスクに書き出します。ファイル名にターゲット言語を明示しておくと、後続プロセスで扱いやすくなります。

```csharp
// Destination path – note the _fr suffix
string destPath = @"C:\MyDocs\translated_fr.docx";

// Save the document in DOCX format
sourceDoc.Save(destPath, SaveFormat.Docx);
Console.WriteLine("French document saved to: " + destPath);
```

`translated_fr.docx` を Microsoft Word で開くと、同じレイアウトが保たれたままフランス語の文章が表示されます。

### 期待される出力

```
Original text length: 1245
Translation completed. French characters: 1320
French document saved to: C:\MyDocs\translated_fr.docx
```

ファイルを開くと、最初の段落は次のようになるでしょう：

> « Bonjour, ceci est un exemple de texte traduit en français à l'aide d'Aspose.Words.AI. »

## Pro Tips & Common Pitfalls

- **ライセンスの重要性:** 正規のライセンスがないと、ライブラリは最初のページに透かしを挿入します。まずはトライアルライセンスでテストし、問題なければ本番キーに切り替えてください。  
- **エンコーディングの問題:** `�` 文字が表示されたら、元の DOCX が UTF‑8 で保存されているか確認してください。Aspose はほとんどの場合自動で処理しますが、古い Word ファイルは `LoadOptions` の `Encoding = Encoding.UTF8` を指定する必要があります。  
- **パフォーマンス:** 50 ページ程度のレポートは、一般的なブロードバンド環境で約 12 秒で翻訳できます。バッチ処理の場合は、認証ハンドシェイクを繰り返さないように単一の `Translator` インスタンスを再利用すると効果的です。  
- **テーブルの保持:** 上記のシンプルな置換はテーブルを失います。テーブルを残したい場合は `NodeType.Table` ノードを走査し、各セルのテキストを個別に翻訳してください。
