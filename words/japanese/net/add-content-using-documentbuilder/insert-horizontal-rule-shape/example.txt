//ExSummary: このチュートリアルでは、Document と DocumentBuilder を使用して Word ドキュメントを作成し、テキストの段落を追加し、水平ルール シェイプを挿入する方法を示します。
//ExStepSummary:0: Document クラスのインスタンスを作成して、新しい空の Word ドキュメントを作成します。
//ExStepSummary:1: ドキュメントにリンクされた DocumentBuilder を作成し、編集操作を可能にします。
//ExStepSummary:2: テキストの段落を書き込み、次に DocumentBuilder を使用してカーソル位置に水平ルール シェイプを挿入します。
//ExStepSummary:3: 出力フォルダーのパスを定義し、ドキュメントを .docx ファイルとして保存します。
//ExStepImage:2:images/1.png
//ExStep:0-
Document doc = new Document();

//ExStep:1-
DocumentBuilder builder = new DocumentBuilder(doc);

//ExStep:2-
builder.Writeln("Insert a horizontal rule shape into the document.");
builder.InsertHorizontalRule();

//ExStep:3-
string dataDir = "YOUR DOCUMENT DIRECTORY";
doc.Save(dataDir + "AddContentUsingDocumentBuilder.InsertHorizontalRule.docx");
