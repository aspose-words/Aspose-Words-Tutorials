# Aspose.Words C# でチャートにパーセンテージを表示する方法

**チャートにパーセンテージを表示する方法**で、複雑な Office Interop に悩まされたことはありませんか？ 同じ壁にぶつかる開発者は多いです。すぐにプログラムで円グラフやドーナツグラフにラベルを付けたいときに便利です。朗報です！ Aspose.Words for .NET を使えば、数行のコードでデータラベルを有効にできます。

このチュートリアルでは **円グラフにデータラベルを追加する** 方法と **チャート データ ラベルを有効にする** 方法もカバーします。最後には、各スライスの外側にパーセンテージがきれいに配置された完成品の Word 文書（`.docx`）が手に入ります。

## 前提条件

作業を始める前に以下を用意してください。

- **Aspose.Words for .NET**（最新バージョン、例: 24.9）を NuGet でインストール  
- 円グラフまたはドーナツグラフが含まれた **ChartTemplate.docx** ファイル  
  *(まだ持っていない場合は、簡単な Word 文書を作成し、円グラフを挿入して `ChartTemplate.docx` として保存してください)*  
- .NET 6.0 以降とお好みの IDE（Visual Studio、Rider、VS Code など）

追加の依存関係は不要です。Aspose.Words がすべて内部で処理します。

## チャートにパーセンテージを表示する手順 – ステップバイステップ

以下の 6 つのステップに分けて解説します。各ステップにはそのままコピーできる C# コード（{{CODE_BLOCK_X}}）と、**なぜ**その操作が必要かの簡単な説明が含まれています。

### ステップ 1: ソース ドキュメントをロード

```csharp
using Aspose.Words;
using Aspose.Words.Drawing.Charts;

// Load the .docx that already holds a chart.
Document sourceDoc = new Document("YOUR_DIRECTORY/ChartTemplate.docx");
```

*なぜ？*  
`Document` は Word 操作のエントリーポイントです。テンプレートをロードすることで、図形、テーブル、テキスト、そして編集対象のチャートにアクセスできます。

### ステップ 2: 最初のチャート シェイプを取得

```csharp
// The chart lives inside a Shape node; retrieve it.
Chart chart = (Chart)sourceDoc.GetChild(NodeType.Shape, 0, true);
```

*なぜ？*  
Aspose はチャートを `Shape` オブジェクトとして保持します。`GetChild` でドキュメントツリーを走査し、最初に見つかったシェイプ（今回編集したい円グラフ）を取得します。

### ステップ 3: チャートの種類を確認

```csharp
if (chart.ChartType == ChartType.Pie || chart.ChartType == ChartType.Doughnut)
{
    // Inside this block we’ll enable the data labels.
}
else
{
    throw new InvalidOperationException("The chart is not a Pie or Doughnut type.");
}
```

*なぜ？*  
パーセンテージ ラベルは円形のチャートでのみ意味があります。このチェックにより、棒グラフなど `ShowPercentage` が無視されるタイプに誤って設定を適用するのを防げます。

### ステップ 4: データ ラベルを有効化し、パーセンテージを表示

```csharp
// Turn on data labels for the chart.
chart.HasDataLabel = true;

// Show the percentage value for each slice.
chart.DataLabel.ShowPercentage = true;
```

*なぜ？*  
`HasDataLabel` を true にすると、各データ ポイントにラベルが描画されます。`ShowPercentage` を設定すると、ラベルの内容が全体に対する割合として計算され、**円グラフにデータラベルを追加する** 要件を満たします。

### ステップ 5: ラベルをスライスの外側に配置

```csharp
// Place the labels outside the pie slices for better readability.
chart.DataLabel.Position = ChartDataLabelPosition.OutSideEnd;
```

*なぜ？*  
スライス内部にラベルを入れると、特に小さなスライスで窮屈になります。`OutSideEnd` は Word UI のデフォルト「外側」スタイルを模倣し、チャートをすっきり見せます。

### ステップ 6: 更新したドキュメントを保存

```csharp
sourceDoc.Save("YOUR_DIRECTORY/FormattedPieChart.docx");
```

*なぜ？*  
`Save` により変更が新しいファイルに書き込まれます。`FormattedPieChart.docx` を Word で開くと、各スライスの横にパーセンテージが表示されます。

#### 期待される結果

`FormattedPieChart.docx` を開くと、円グラフは以下のようになります（イメージ画像）:

```
[ Pie chart with three slices ]
- Slice A – 45%
- Slice B – 30%
- Slice C – 25%
```

すべてのパーセンテージは基になるデータ系列から自動計算され、ラベルは各スライスのすぐ外側に配置されます。

## よくあるバリエーションとエッジケース

| 状況 | 調整すべき点 |
|-----------|----------------|
| 同一文書内に **複数のチャート** がある場合 | `sourceDoc.GetChildNodes(NodeType.Shape, true)` をループし、各シェイプを `Chart` にキャストして同じロジックを適用 |
| **棒グラフや折れ線グラフ** でラベルが必要な場合 | `chart.DataLabel.ShowValue = true;`（または `ShowSeriesName`）を使用し、`ShowPercentage` の代わりに設定 |
| **カスタム数値書式**（例: “45 %”） | 保存前に `chart.DataLabel.NumberFormat = "0%";` を設定 |
| **データ数が多くラベルが重なる** 場合 | `chart.DataLabel.ShowLeaderLines = true;` を有効にし、コネクタ線を描画 |

> **プロのコツ:** バッチで多数の文書を生成する場合、アプリケーション起動時に `Aspose.Words.License` オブジェクトを 1 回だけインスタンス化しておくと、ライセンス読み込みのパフォーマンスオーバーヘッドを回避できます。

## 完全動作サンプル

以下が全体のプログラムです。すぐに実行可能です。

```csharp
using System;
using Aspose.Words;
using Aspose.Words.Drawing.Charts;

class Program
{
    static void Main()
    {
        // 1️⃣ Load the template document.
        Document sourceDoc = new Document("YOUR_DIRECTORY/ChartTemplate.docx");

        // 2️⃣ Retrieve the first chart shape.
        Chart chart = (Chart)sourceDoc.GetChild(NodeType.Shape, 0, true);

        // 3️⃣ Ensure we’re dealing with a Pie or Doughnut chart.
        if (chart.ChartType != ChartType.Pie && chart.ChartType != ChartType.Doughnut)
        {
            Console.WriteLine("The selected shape is not a Pie/Doughnut chart.");
            return;
        }

        // 4️⃣ Enable data labels and show percentages.
        chart.HasDataLabel = true;
        chart.DataLabel.ShowPercentage = true;

        // 5️⃣ Position the labels outside the slices.
        chart.DataLabel.Position = ChartDataLabelPosition.OutSideEnd;

        // 6️⃣ Save the modified document.
        sourceDoc.Save("YOUR_DIRECTORY/FormattedPieChart.docx");

        Console.WriteLine("Chart updated successfully – percentages now visible!");
    }
}
```

コードをコピーし、`YOUR_DIRECTORY` を実際のパスに置き換えて実行してください。数秒で、完全にラベル付けされた円グラフを含む Word ファイルが生成されます。

## まとめ

Aspose.Words for C# を使って **チャートにパーセンテージを表示する方法** を解説しました。手順は次の通りです。

1. テンプレートをロード  
2. チャート シェイプを取得  
3. 円/ドーナツか確認  
4. **円グラフにデータラベルを追加** し、パーセンテージを有効化  
5. ラベルを外側に配置  
6. 結果を保存  

この知識があれば、パーセンテージベースの可視化が必要なレポート作成を自動化できます。
