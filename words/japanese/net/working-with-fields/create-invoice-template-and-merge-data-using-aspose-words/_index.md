# Aspose.Words を使用して請求書テンプレートを作成しデータをマージする

請求書テンプレートを **迅速に作成** したい場合、本ガイドが具体的な手順を示します。最初の2文を読めば、空の Word ファイルを完全に埋め込まれた請求書に変換するワークフロー全体が把握でき、Aspose.Words のローコード メールマージ API を利用した実装が理解できます。

請求書の生成は、請求システム、ERP 連携、そして自動レポート作成において一般的な要件です。このチュートリアルでは **メールマージの方法**、**Word テンプレートへのデータ注入**、**Word へのデータマージ**、そして最終的に **マージされたドキュメントの保存** を、数行の C# コードで実現する方法を学びます。

## 達成できること

* 再利用可能な Word テンプレート（`InvoiceTemplate.docx`）で、顧客、日付、明細項目、合計のマージフィールドを保持。  
* テンプレートを読み込み、強く型付けされたデータオブジェクトを注入し、結果を `Invoice_001.docx` に書き出す C# プログラム。  
* 空コレクション、カスタムデータ型、ファイルパス処理などのエッジケースに関する知見。

### 前提条件

| 要件 | 重要な理由 |
|------|------------|
| .NET 6 以降 | Aspose.Words for .NET は .NET 6+ をサポートし、本ガイドで使用するローコード API を提供します。 |
| Aspose.Words for .NET NuGet パッケージ（`Aspose.Words`） | `Document`、`MailMerger` などの型を提供します。 |
| 基本的な C# の知識 | 匿名オブジェクトや LINQ を理解するために必要です。 |
| Visual Studio 2022（または任意の IDE） | 編集とデバッグが容易になります。 |

> **プロのコツ:** パッケージマネージャコンソールから NuGet パッケージをインストールします。  
> `Install-Package Aspose.Words`

## ローコード メールマージで請求書テンプレートを作成する手順

最初のステップは、後で渡すデータオブジェクトのプロパティに対応するマージフィールドを含む Word ファイルを作成することです。ファイルは `InvoiceTemplate.docx` として、任意のフォルダー（例: `C:\Invoices\Template`）に保存します。

| マージフィールド | Word 内のプレースホルダー例 |
|------------------|----------------------------|
| CustomerName | «CustomerName» |
| InvoiceDate | «InvoiceDate» |
| Items（繰り返し） | «Items.Description», «Items.Qty», «Items.Price» |
| Total | «Total» |

> **なぜ重要か:** ローコード API はデータソースのプロパティ名をマージフィールドに自動的にマッピングします。名前を一致させるだけで手動のフィールド‑プロパティマッピングが不要になり、実行時エラーが減少します。

## 手順 1: 請求書テンプレートを読み込む

```csharp
using Aspose.Words;
using Aspose.Words.LowCode;   // Low‑code mail‑merge API

// Load the Word file that contains the merge fields.
Document template = new Document(@"C:\Invoices\Template\InvoiceTemplate.docx");
```

*`Document` クラスは Word ファイル全体を表します。一度読み込めば、同じテンプレートを多数の請求書で再利用できます。*

## 手順 2: データソースを準備する

マージフィールドと同構造の匿名オブジェクトを作成します。ローコード API は配列や入れ子コレクションを含む任意の .NET オブジェクトを扱えます。

```csharp
var invoiceData = new
{
    CustomerName = "Acme Corp",
    InvoiceDate = DateTime.Today,
    Items = new[]
    {
        new { Description = "Widget A", Qty = 10, Price = 9.99M },
        new { Description = "Widget B", Qty = 5,  Price = 19.95M }
    },
    Total = 199.85M
};
```

**この方法が機能する理由:**  
* プロパティ名（`CustomerName`、`InvoiceDate`、`Items`、`Total`）がテンプレートのマージフィールドと一致しています。  
* `Items` はオブジェクトの配列なので、メールマージは各要素に対してテーブル行を自動的に繰り返します。  
* 金額には `decimal`（`M` サフィックス）を使用することで、浮動小数点の丸め誤差を回避します。

### 空コレクションの取り扱い

請求書に明細項目がない場合は、空の配列を渡します。

```csharp
Items = new object[0]
```

ローコードエンジンは繰り返しセクションを単に省略し、テーブルヘッダーはそのまま残ります。

## 手順 3: ローコード メールマージを初期化する

```csharp
MailMerger merger = new MailMerger(template);
```

`MailMerger` は Aspose.Words で **メールマージを実行する** エントリーポイントです。テンプレートを読み込み、データをバインドし、最終ドキュメントを一括で準備します。

## 手順 4: マージを実行 – 1 行で Word テンプレートにデータを注入

```csharp
Document mergedDocument = merger.Execute(invoiceData);
```

* この行は **Word テンプレートにデータを注入** し、新しい `Document` インスタンス（`mergedDocument`）を生成します。  
* すべてのマージフィールドが置換され、繰り返しセクションが展開され、結果のドキュメントはメモリ上に完全に保持されます。

### エッジケース: カスタム書式設定

特定の日付書式が必要な場合は、マージ前にカスタムフォーマッタを追加します。

```csharp
merger.Options.DateFormat = "MMMM dd, yyyy"; // e.g., "October 07, 2026"
```

## 手順 5: マージされたドキュメントを保存する

```csharp
mergedDocument.Save(@"C:\Invoices\Output\Invoice_001.docx");
```

**save merged document** 呼び出しは、完全に埋め込まれた請求書をディスクに書き出します。生成されたファイルは Microsoft Word で開くことも、メール添付として送信することも、PDF に変換することも可能です。

### 出力結果の確認

`Invoice_001.docx` を開くと、以下が確認できるはずです。

* **CustomerName** が *Acme Corp* に置換  
* **InvoiceDate** が選択した形式で本日の日付を表示  
* *Widget A*（10 × 9.99）と *Widget B*（5 × 19.95）のテーブル行が表示  
* **Total** が *199.85* を示す  

もしフィールドがそのまま（例: «CustomerName»）残っている場合は、プロパティ名がテンプレートのマージフィールド名と完全に一致しているか再確認してください。

## 完全な実行可能サンプル

以下は新規コンソールプロジェクトにコピペできる、全コードです。

```csharp
using System;
using Aspose.Words;
using Aspose.Words.LowCode;   // Low‑code mail‑merge API

namespace InvoiceGenerator
{
    class Program
    {
        static void Main()
        {
            // 1️⃣ Load the template
            Document template = new Document(@"C:\Invoices\Template\InvoiceTemplate.docx");

            // 2️⃣ Build the data source
            var invoiceData = new
            {
                CustomerName = "Acme Corp",
                InvoiceDate = DateTime.Today,
                Items = new[]
                {
                    new { Description = "Widget A", Qty = 10, Price = 9.99M },
                    new { Description = "Widget B", Qty = 5,  Price = 19.95M }
                },
                Total = 199.85M
            };

            // 3️⃣ Initialise the mail merger
            MailMerger merger = new MailMerger(template);

            // Optional: customise date format
            merger.Options.DateFormat = "MMMM dd, yyyy";

            // 4️⃣ Perform the merge (populate word template)
            Document mergedDocument = merger.Execute(invoiceData);

            // 5️⃣ Save the resulting file (save merged document)
            mergedDocument.Save(@"C:\Invoices\Output\Invoice_001.docx");

            Console.WriteLine("Invoice generated successfully.");
        }
    }
}
```

プログラムを実行（`dotnet run`）すると、コンソールに *Invoice generated successfully.* と表示され、`C:\Invoices\Output` にファイルが生成されます。

## よくある質問とトラブルシューティング

| 質問 | 回答 |
|------|------|
| **テンプレートで別のフィールド区切り文字を使用している場合はどうすればよいですか？** | Aspose.Words のデフォルトは « » 区切りです。`MailMerger.Options.FieldStartDelimiter` と `FieldEndDelimiter` を使用して変更できます。 |
| **マージ後に余分な空白が残ります。対処法は？** | マージフィールドの前後に不要なスペースや改行がないか確認し、必要に応じて `Trim` した文字列をデータ側で提供してください。 |
| **大きなデータセットでパフォーマンスが低下します。** | `MailMerger` のストリーミング機能や `Document` の `Clone` メソッドを活用し、メモリ使用量を最適化できます。 |
