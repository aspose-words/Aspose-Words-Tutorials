# 空白のWord文書を作成し、C#で楕円形を非表示にする

空白のWord文書を**作成**し、グラフィック要素を非表示にしたい場合、このガイドではC#での具体的な手順を示します。楕円を挿入し、位置を設定し、非表示としてマークし、ファイルを保存する完全な実行可能サンプルが数行のコードで確認できます。

このチュートリアルはプロジェクトのセットアップから最終的な検証手順までを網羅しています。最後まで実施すれば、画面上でも印刷時でも楕円が表示されないWordファイルを生成でき、メタデータやブックマーク、任意の不可視マーカーの保存に役立ちます。

## 前提条件

開始する前に、以下が揃っていることを確認してください。

* .NET 6.0 SDK 以降がインストールされていること  
* C# 開発環境（Visual Studio 2022、Rider、または VS Code）  
* **Aspose.Words for .NET** NuGet パッケージ (`Install-Package Aspose.Words`)  

これらのツールはコードサンプルで使用する `Document` と `DocumentBuilder` クラスを提供します。

## 手順 1: 空白のWord文書を作成する

最初の操作で空の `Document` オブジェクトと、コンテンツ追加を可能にする `DocumentBuilder` を作成します。

```csharp
using Aspose.Words;
using Aspose.Words.Drawing;

// Step 1: Initialize an empty document and a builder
Document doc = new Document();
DocumentBuilder builder = new DocumentBuilder(doc);
```

`Document` は `.docx` パッケージ全体を表し、`DocumentBuilder` はテキスト、図形、その他のオブジェクトを挿入するためのフルエント API を提供します。空白の文書から開始することで、追加するすべての要素を完全にコントロールできます。

## 手順 2: 楕円を挿入する方法

楕円はマーカーとして使用できるベクター図形です。`InsertShape` メソッドは図形の種類と幅・高さ（ポイント単位）を指定する必要があります。

```csharp
// Step 2: Insert an ellipse shape of the desired size (100 pt × 50 pt)
Shape ellipse = builder.InsertShape(ShapeType.Ellipse, 100, 50);
```

楕円はカーソル位置の現在のページに配置されます。数値引数を調整することでサイズを変更できます。

## 手順 3: 図形の位置を設定する方法

挿入後、`Left` と `Top` プロパティを設定することでページ上の任意の位置に図形を移動できます。これらのプロパティはページ余白を基準としたポイント単位です。

```csharp
// Step 3: Position the shape on the page
ellipse.Left = 150; // distance from the left margin
ellipse.Top  = 100; // distance from the top margin
```

これらの座標は標準的な A4 用紙の上部中央付近に楕円を配置します。レイアウト要件に合わせて値を調整してください。

## 手順 4: 図形を非表示にする方法

非表示オブジェクトは文書が開かれたときや印刷されたときに表示されません。`Hidden` フラグを設定することで、図形を **hidden object word** としてマークします。

```csharp
// Step 4: Hide the shape so it never appears
ellipse.Hidden = true;
```

Word は画面表示と印刷出力の両方で hidden フラグを尊重します。図形は文書構造の一部として残り、後からコードで検索・変更することが可能です。

## 手順 5: 文書を保存する

最後に文書をディスクに書き込みます。書き込み権限のあるフォルダーを選択してください。

```csharp
// Step 5: Save the document to a .docx file
doc.Save(@"C:\Temp\HiddenEllipse.docx");
```

`HiddenEllipse.docx` ファイルには、非表示の楕円形が配置された空白ページが含まれます。

## 非表示楕円の検証

生成されたファイルを Microsoft Word で開き、**表示** → **オプション** → **表示** の **非表示文字の表示** を有効にします。楕円の薄い輪郭が見えるはずです。このオプションをオフにすると図形は完全に消え、`ellipse.Hidden = true` が期待通りに機能していることが確認できます。

## よくあるバリエーションとエッジケース

| 状況 | 推奨される調整 |
|-----------|------------------------|
| **異なる形状** | `ShapeType.Ellipse` を `ShapeType.Rectangle`、`ShapeType.Arrow` などに置き換えます。 |
| **複数の非表示オブジェクト** | 各図形に対して手順 2‑4 を繰り返します。各図形は独自の `Hidden` フラグを持てます。 |
| **異なるページサイズ** | 図形を挿入する前に `doc.FirstSection.PageSetup.PageWidth` と `PageHeight` を設定します。 |
| **条件付き表示** | 実行時にコードで切り替えるために `Hidden` と組み合わせて `Shape.Visible` を使用します。 |

**プロのコツ:** 図形の `AlternativeText` プロパティに識別データを保存します。非表示でも `doc.GetChildNodes(NodeType.Shape, true)` で図形を取得し、そのテキストでフィルタリングできます。

## 完全なソースコード

以下にコピー＆ペーストして実行できる完全なプログラムを示します。

```csharp
using System;
using Aspose.Words;
using Aspose.Words.Drawing;

namespace HiddenShapeDemo
{
    class Program
    {
        static void Main()
        {
            // Create a new blank document and a builder
            Document doc = new Document();
            DocumentBuilder builder = new DocumentBuilder(doc);

            // Insert an ellipse shape (100 pt × 50 pt)
            Shape ellipse = builder.InsertShape(ShapeType.Ellipse, 100, 50);

            // Position the shape on the page
            ellipse.Left = 150;
            ellipse.Top  = 100;

            // Hide the shape so it is invisible in the UI and on print
            ellipse.Hidden = true;

            // Optional: add a description for later retrieval
            ellipse.AlternativeText = "Hidden marker for internal processing";

            // Save the document
            string outputPath = @"C:\Temp\HiddenEllipse.docx";
            doc.Save(outputPath);

            Console.WriteLine($"Document saved to {outputPath}");
        }
    }
}
```

**期待される出力:** コンソールに保存パスが表示され、`HiddenEllipse.docx` を開くと非表示オブジェクトが表示設定されていない限り何も見えない空白ページが表示されます。
