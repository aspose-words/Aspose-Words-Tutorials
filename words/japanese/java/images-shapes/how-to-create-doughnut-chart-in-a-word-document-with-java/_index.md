# JavaでWord文書にドーナツチャートを作成する方法

Wordファイル内に **ドーナツチャートを作成** したい場合、このチュートリアルでは完全に実行可能なソリューションを示します。**円グラフを挿入**し、ドーナツに変換し、**円グラフを回転**してバランスを調整し、**円グラフをフォーマット**してブランドに合わせる方法が分かります。最後には、レポートやダッシュボード、あるいは自動メール添付として使用できるプロフェッショナルなWord文書が完成します。

プログラムでチャートを作成すれば、手動のコピーペースト作業が不要になり、数十件の生成文書でもスタイルを一貫させることができます。例では Aspose.Words for Java ライブラリを使用します。Java 8+ に対応し、Microsoft Office のインストールは不要です。標準的な JDK とお好みの IDE さえあれば、他に必要なものはありません。

## 前提条件

- Java Development Kit (JDK) 8 以上  
- 依存関係管理のための Maven または Gradle（本チュートリアルは Maven を使用）  
- Aspose.Words for Java ライブラリ（テスト用には無料トライアルライセンスで十分）  

`pom.xml` に Aspose.Words の依存関係を追加します:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-words</artifactId>
    <version>24.9</version> <!-- Use the latest stable version -->
</dependency>
```

> **プロのコツ:** ドキュメントを作成する前に `License license = new License(); license.setLicense("Aspose.Words.lic");` でライセンスを登録し、評価版の透かしを除去しましょう。

## Word文書にドーナツチャートを作成する

コアワークフローは5つの論理ステップで構成されます。各ステップはメソッドに分割して、コードをすっきり保ち再利用しやすくしています。

```java
import com.aspose.words.*;
import com.aspose.words.drawing.*;

public class DoughnutChartDemo {

    public static void main(String[] args) throws Exception {
        // Step 1: create blank Word document
        Document doc = createBlankWordDocument();

        // Step 2: insert a pie chart (base for the doughnut)
        Chart chart = insertPieChart(doc, 400, 300);

        // Step 3: convert the pie chart into a doughnut and rotate it
        customizeChartAppearance(chart);

        // Step 4: apply additional formatting to the chart
        formatPieChart(chart);

        // Step 5: save the final document
        doc.save("output/DoughnutChartFormatted.docx");
        System.out.println("Document saved successfully.");
    }

    /** Step 1 – create blank Word document */
    private static Document createBlankWordDocument() {
        // Aspose.Words creates an empty document by default
        return new Document();
    }

    /** Step 2 – insert pie chart with given dimensions */
    private static Chart insertPieChart(Document doc, int width, int height) throws Exception {
        DocumentBuilder builder = new DocumentBuilder(doc);
        // ChartType.PIE creates a standard pie chart that we will later turn into a doughnut
        Chart chart = builder.insertChart(ChartType.PIE, width, height);
        // Populate the chart with sample data
        chart.getSeries().clear(); // Remove default series
        ChartSeries series = chart.getSeries().add("Sales", new String[]{"Q1", "Q2", "Q3", "Q4"},
                new double[]{15000, 23000, 18000, 27000});
        return chart;
    }

    /** Step 3 – rotate pie chart and make it a doughnut */
    private static void customizeChartAppearance(Chart chart) {
        // Explode the first slice for emphasis
        chart.getSeries().get(0).setExplode(20);
        // Convert the pie into a doughnut by setting a hole size (percentage of radius)
        chart.setHoleSize(30); // 30% hole creates a classic doughnut look
        // Rotate the chart so the largest slice starts at 45°
        chart.setRotationAngle(45);
    }

    /** Step 4 – additional formatting of the pie chart */
    private static void formatPieChart(Chart chart) {
        // Example: change the first slice color to a brand color
        chart.getSeries().get(0).getPoints().get(0).getFormat().setFillForegroundColor(Color.fromArgb(0xFF, 0x4A, 0x90));
        // Add a legend and position it at the bottom
        chart.setHasLegend(true);
        chart.getLegend().setPosition(LegendPosition.BOTTOM);
        // Set a title for the chart
        chart.setTitle("Quarterly Sales Distribution");
    }
}
```

### コードの概要

| Step | Action | Reason |
|------|--------|--------|
| **Create blank Word document** | `new Document()` | クリーンなファイルから開始し、すべての要素を自分でコントロールできます。 |
| **Insert pie chart** | `builder.insertChart(ChartType.PIE, …)` | 円グラフがベース形状です。Aspose は穴のサイズを調整することでドーナツを提供します。 |
| **Rotate pie chart** | `chart.setRotationAngle(45)` | 回転させることで最大のスライスを読みやすい位置に配置します。 |
| **Format pie chart** | `setExplode`, `setHoleSize`, color, legend | ビジュアル階層を改善し、企業のスタイルガイドラインに合わせます。 |
| **Save document** | `doc.save("…/DoughnutChartFormatted.docx")` | 完成した .docx ファイルをディスクに書き出し、配布準備が整います。 |

## ドーナツに変換する前に円グラフを挿入する

Aspose.Words には直接「ドーナツチャートを挿入」するメソッドはありません。代わりに **円グラフを挿入**し、そのプロパティを変更します。この 2 ステップ方式により、データ系列、スライスの爆発、穴のサイズを完全にコントロールできます。純粋な円グラフが必要な場合は、`setHoleSize` の呼び出しを省略してください。

## ビジュアルバランスのために円グラフを回転する

デフォルトでは最初のスライスが 12 時の位置から開始します。多くのビジネスレポートでは、最も重要なスライスを 45 度などの自然な角度から開始させた方が見やすくなります。`setRotationAngle(double angle)` メソッドは度数を受け取り、データ値に影響を与えずにチャート全体を回転させます。

## 円グラフのフォーマットと外観のカスタマイズ

ドーナツに変換するだけでなく、**円グラフをフォーマット**することもよくあります:

- **Explode**: 最初のスライスを `setExplode` で強調表示。  
- **Color**: `getPoints().get(i).getFormat().setFillForegroundColor` で各スライスに色を付与。  
- **Legend**: `setHasLegend`, `setPosition` で凡例の位置を調整し、カテゴリの解釈を支援。  
- **Title**: `setTitle` で一目で内容が分かるタイトルを設定。  

これらの設定はすべて任意です。ブランドの配色や企業テンプレートに合わせて調整してください。

## 空の Word 文書を作成し結果を保存する

`createBlankWordDocument` メソッドは **空の Word 文書を作成** するステップをカプセル化しています。このロジックを分離しておくことで、バッチ処理で複数のレポートを生成する際に簡単に再利用できます。すべてのカスタマイズが完了したら、`doc.save` が標準の Office Open XML 形式（`.docx`）でファイルを書き出し、Microsoft Word、LibreOffice、Google Docs で忠実に開くことができます。

### 期待される出力

`main` メソッドを実行すると、コンソールに次が表示されます:

```
Document saved successfully.
```

そして `output/DoughnutChartFormatted.docx` には、*Quarterly Sales Distribution* というタイトルのドーナツチャートが1ページ分だけ含まれます。チャートは4つのスライスを持ち、最初のスライスが爆発表示され、ブランドカラーで塗られ、45 度回転しています。

## よくあるバリエーションとエッジケース

| Situation | Adjustment |
|-----------|------------|
| **More than one data series** | `chart.getSeries()` に追加の `ChartSeries` オブジェクトを加える。 |
| **Different chart size** | `insertPieChart` の `width` と `height` 引数を変更する。 |
| **No hole (pure pie)** | `chart.setHoleSize(…)` を省くか `0` に設定する。 |
| **Large documents** | `DocumentBuilder` を使用して特定のセクションやブックマークにチャートを挿入する。 |
| **License not set** | ライセンス未設定の場合は評価モードで動作し、1ページ目に透かしが入ります。透かしを除去するにはライセンスを登録してください。 |

## 結論

これで **Java を使って Word 文書にドーナツチャートを作成** する方法が分かりました。**空の Word 文書を作成** し、**円グラフを挿入**、**円グラフを回転**、そして **円グラフをフォーマット** して、仕上がりの良い最終製品を作る一連の手順をマスターしました。完全な実行可能サンプルは、Aspose.Words を既に使用している任意の Java プロジェクトにそのまま組み込めます。
