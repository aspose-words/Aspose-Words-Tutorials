# Jak stworzyć wykres kolumnowy w Pythonie przy użyciu Aspose.Words

Jeśli potrzebujesz stworzyć wykres kolumnowy w Pythonie, ten przewodnik pokazuje dokładny kod i uzasadnienie, które są potrzebne. Korzystając z API wykresów Aspose.Words, możesz określić precyzyjne wymiary, zastosować wbudowany styl i wyeksportować wynik bez opuszczania Pythona.

Tworzenie wykresu kolumnowego jest częstym wymogiem w raportach, dashboardach i automatycznym generowaniu dokumentów. Ten tutorial obejmuje każdy krok — od importu biblioteki po weryfikację zapisanego obrazu — abyś mógł zintegrować generowanie wykresów w dowolnym projekcie Python.

## Wymagania wstępne

Zanim rozpoczniesz, upewnij się, że masz:

* Python 3.8 lub nowszy zainstalowany.
* Ważną licencję Aspose.Words for Python (lub darmowy klucz ewaluacyjny).
* Podstawową znajomość modułów Pythona i programowania obiektowego.

Silnik wykresów Aspose.Words działa na Windows, macOS i Linux, i nie wymaga dodatkowych bibliotek graficznych, ponieważ renderowanie odbywa się po stronie serwera.

## Krok 1: Import biblioteki Aspose.Words

Pierwszym krokiem jest zaimportowanie pakietu `aspose.words` i nadanie mu krótkiego aliasu. Import na początku pliku utrzymuje porządek w przestrzeni nazw i ułatwia czytanie kodu.

```python
# Step 1: Import the Aspose.Words library
import aspose.words as aw
```

`aw` od teraz odwołuje się do pełnego API Aspose.Words, w tym klasy `Chart`, której użyjesz do zbudowania wykresu kolumnowego.

## Krok 2: Utwórz wykres kolumnowy o żądanych wymiarach

Wykres kolumnowy wymaga wyraźnych wartości szerokości i wysokości, aby renderowany obraz pasował do układu dokumentu. Konstruktor `Chart` przyjmuje trzy argumenty: typ wykresu, szerokość (w punktach) i wysokość (w punktach). Użycie `aw.ChartType.COLUMN` informuje silnik, że ma wygenerować wykres słupkowy pionowy.

```python
# Step 2: Create a column chart with the desired dimensions
chart = aw.Chart(aw.ChartType.COLUMN, 400, 300)   # width=400pt, height=300pt
```

*Dlaczego ustawia się wymiary?*  
Gdy osadzasz wykres w dokumencie Word lub eksportujesz go jako obraz, otaczająca treść respektuje dokładny rozmiar, który podasz. Zapobiega to niepożądanemu skalowaniu lub przycinaniu.

### Porada: użyj `chart.dimensions` do dynamicznego skalowania

Jeśli Twój zestaw danych się zmienia, możesz obliczyć rozmiar na podstawie liczby serii:

```python
series_count = 5
base_width = 80
chart.width = base_width * series_count
chart.height = 300
```

## Krok 3: Zastosuj wbudowany styl do wykresu kolumnowego

Aspose.Words dostarcza kilka predefiniowanych motywów wizualnych. Wybranie stylu eliminuje potrzebę ręcznego konfigurowania kolorów, czcionek i linii siatki. `aw.ChartStyle.STYLE_5` to czysty, profesjonalny wygląd odpowiedni dla większości raportów biznesowych.

```python
# Step 3: Apply a built‑in style to the chart
chart.style = aw.ChartStyle.STYLE_5
```

Jeśli wolisz inny wygląd, zamień `STYLE_5` na dowolną inną stałą (`STYLE_1` … `STYLE_8`). Każdy styl ma taką samą konwencję nazewnictwa, co ułatwia eksperymentowanie.

### Przypadek brzegowy: nieprawidłowa stała stylu

Próba przypisania nieistniejącego stylu podnosi `AttributeError`. Zabezpiecz się, sprawdzając stałą względem wyliczenia:

```python
if hasattr(aw.ChartStyle, "STYLE_5"):
    chart.style = aw.ChartStyle.STYLE_5
else:
    raise ValueError("Requested chart style does not exist.")
```

## Krok 4: Dodaj serie danych do wykresu kolumnowego

Wykres bez danych jest bezwartościowy. Możesz dodać jedną lub więcej obiektów `ChartSeries`, z których każdy reprezentuje grupę kolumn. Poniższy przykład dodaje jedną serię z trzema punktami danych.

```python
# Step 4: Add data series to the column chart
series = chart.series.add()
series.name = "Quarterly Sales"
series.data = [12000, 15000, 18000]   # Values for Q1, Q2, Q3
```

Możesz powtórzyć wywołanie `chart.series.add()`, aby dodać kolejne serie (np. „Prognozowana sprzedaż”). API automatycznie rozmieszcza kolumny obok siebie.

## Krok 5: Renderuj wykres i zapisz go jako obraz

Po skonfigurowaniu wykresu renderujesz go do bitmapy lub pliku graficznego. Metoda `save` przyjmuje ścieżkę pliku oraz opcjonalny format. PNG jest bezstratny i szeroko wspierany.

```python
# Step 5: Render and save the chart as a PNG image
output_path = "column_chart.png"
chart.save(output_path, aw.SaveFormat.PNG)
print(f"Chart saved to {output_path}")
```

Wyliczenie `SaveFormat` zawiera PNG, JPEG, BMP i inne. Wybierz format, który pasuje do Twojego dalszego przepływu pracy.

3. Wywołanie `save` używa obsługiwanego `SaveFormat`.

## Typowe warianty i dodatkowe wskazówki

| Sytuacja | Zalecana zmiana |
|-----------|--------------------|
| **Wiele serii danych** | Dodaj dodatkowe bloki `chart.series.add()` i ustaw `series.name` oraz `series.data` dla każdej z nich. |
| **Niestandardowe kolory** | Po zastosowaniu wbudowanego stylu, nadpisz kolory poszczególnych kolumn za pomocą `series.points[i].fill.fore_color`. |
| **Osadzanie w dokumencie Word** | Zamiast `chart.save()`, użyj `doc = aw.Document(); doc.sections[0].body.append_child(chart); doc.save("report.docx")`. |
| **Dynamiczne skalowanie** | Oblicz szerokość na podstawie liczby serii (`width = 80 * len(chart.series)`). |

Te warianty pokazują, jak ten sam podstawowy kod można dostosować do różnych scenariuszy raportowych.

Kompletny przepływ pracy — import, tworzenie, stylizacja, wypełnianie i renderowanie — obejmuje najczęstsze przypadki użycia w automatycznym raportowaniu.
