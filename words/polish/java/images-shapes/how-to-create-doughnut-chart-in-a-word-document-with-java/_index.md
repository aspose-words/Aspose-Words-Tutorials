# Jak stworzyć wykres pierścieniowy w dokumencie Word przy użyciu Javy

Jeśli potrzebujesz **create doughnut chart** wewnątrz pliku Word, ten samouczek pokaże Ci kompletną, gotową do uruchomienia rozwiązanie. Zobaczysz, jak **insert pie chart**, przekształcić go w wykres pierścieniowy, **rotate pie chart** dla lepszego zbalansowania oraz **format pie chart**, aby dopasować go do Twojej marki. Po zakończeniu będziesz mieć profesjonalny dokument Word, który można używać w raportach, pulpitach nawigacyjnych lub jako automatyczne załączniki e‑mail.

Tworzenie wykresu programowo eliminuje ręczne kroki kopiuj‑wklej i zapewnia spójny styl w dziesiątkach generowanych dokumentów. Przykład używa biblioteki Aspose.Words for Java, która działa z Java 8+ i nie wymaga instalacji Microsoft Office. Nie są potrzebne żadne inne wymagania poza standardowym JDK i Twoim ulubionym IDE.

## Wymagania wstępne

- Java Development Kit (JDK) 8 lub nowszy  
- Maven lub Gradle do zarządzania zależnościami (samouczek używa Maven)  
- Biblioteka Aspose.Words for Java (bezpłatna licencja próbna wystarczy do testów)  

Dodaj zależność Aspose.Words do swojego `pom.xml`:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-words</artifactId>
    <version>24.9</version> <!-- Use the latest stable version -->
</dependency>
```

> **Pro tip:** Zarejestruj swoją licencję za pomocą `License license = new License(); license.setLicense("Aspose.Words.lic");` przed tworzeniem jakiegokolwiek dokumentu, aby usunąć znaki wodne wersji ewaluacyjnej.

## Utwórz wykres pierścieniowy w dokumencie Word

Główny przepływ pracy składa się z pięciu logicznych kroków. Każdy krok jest zawarty w osobnej metodzie, aby kod był czysty i wielokrotnego użytku.

```java
import com.aspose.words.*;
import com.aspose.words.drawing.*;

public class DoughnutChartDemo {

    public static void main(String[] args) throws Exception {
        // Step 1: create blank Word document
        Document doc = createBlankWordDocument();

        // Step 2: insert a pie chart (base for the doughnut)
        Chart chart = insertPieChart(doc, 400, 300);

        // Step 3: convert the pie chart into a doughnut and rotate it
        customizeChartAppearance(chart);

        // Step 4: apply additional formatting to the chart
        formatPieChart(chart);

        // Step 5: save the final document
        doc.save("output/DoughnutChartFormatted.docx");
        System.out.println("Document saved successfully.");
    }

    /** Step 1 – create blank Word document */
    private static Document createBlankWordDocument() {
        // Aspose.Words creates an empty document by default
        return new Document();
    }

    /** Step 2 – insert pie chart with given dimensions */
    private static Chart insertPieChart(Document doc, int width, int height) throws Exception {
        DocumentBuilder builder = new DocumentBuilder(doc);
        // ChartType.PIE creates a standard pie chart that we will later turn into a doughnut
        Chart chart = builder.insertChart(ChartType.PIE, width, height);
        // Populate the chart with sample data
        chart.getSeries().clear(); // Remove default series
        ChartSeries series = chart.getSeries().add("Sales", new String[]{"Q1", "Q2", "Q3", "Q4"},
                new double[]{15000, 23000, 18000, 27000});
        return chart;
    }

    /** Step 3 – rotate pie chart and make it a doughnut */
    private static void customizeChartAppearance(Chart chart) {
        // Explode the first slice for emphasis
        chart.getSeries().get(0).setExplode(20);
        // Convert the pie into a doughnut by setting a hole size (percentage of radius)
        chart.setHoleSize(30); // 30% hole creates a classic doughnut look
        // Rotate the chart so the largest slice starts at 45°
        chart.setRotationAngle(45);
    }

    /** Step 4 – additional formatting of the pie chart */
    private static void formatPieChart(Chart chart) {
        // Example: change the first slice color to a brand color
        chart.getSeries().get(0).getPoints().get(0).getFormat().setFillForegroundColor(Color.fromArgb(0xFF, 0x4A, 0x90));
        // Add a legend and position it at the bottom
        chart.setHasLegend(true);
        chart.getLegend().setPosition(LegendPosition.BOTTOM);
        // Set a title for the chart
        chart.setTitle("Quarterly Sales Distribution");
    }
}
```

### Co robi kod

| Krok | Działanie | Powód |
|------|-----------|-------|
| **Create blank Word document** | `new Document()` | Zaczyna od czystego pliku, abyś miał kontrolę nad każdym elementem. |
| **Insert pie chart** | `builder.insertChart(ChartType.PIE, …)` | Wykres kołowy jest podstawowym kształtem; Aspose udostępnia wykres pierścieniowy jedynie poprzez dostosowanie rozmiaru otworu. |
| **Rotate pie chart** | `chart.setRotationAngle(45)` | Obrót ustawia największy segment w bardziej czytelną pozycję. |
| **Format pie chart** | `setExplode`, `setHoleSize`, color, legend | Poprawia hierarchię wizualną i dopasowuje się do wytycznych stylu korporacyjnego. |
| **Save document** | `doc.save("…/DoughnutChartFormatted.docx")` | Zapisuje finalny plik .docx na dysku, gotowy do dystrybucji. |

## Wstaw wykres kołowy przed konwersją na wykres pierścieniowy

Aspose.Words nie udostępnia bezpośredniej metody „insert doughnut chart”. Zamiast tego **insert pie chart** i następnie modyfikujesz jego właściwości. To dwustopniowe podejście daje pełną kontrolę nad seriami danych, eksplozją segmentów i rozmiarem otworu. Jeśli potrzebujesz czystego wykresu kołowego w innym miejscu, po prostu pomiń wywołanie `setHoleSize`.

## Obróć wykres kołowy dla równowagi wizualnej

Domyślna orientacja rozpoczyna pierwszy segment na pozycji 12 godziny. W wielu raportach biznesowych najważniejszy segment powinien zaczynać się pod bardziej naturalnym kątem, np. 45 stopni. Metoda `setRotationAngle(double angle)` przyjmuje stopnie i obraca cały wykres bez wpływu na wartości danych.

## Formatuj wykres kołowy i dostosuj wygląd

Poza konwersją na wykres pierścieniowy, często chcesz **format pie chart** elementy:

- **Explode** pierwszy segment (`setExplode`), aby przyciągnąć uwagę.  
- **Color** każdy segment przy użyciu `getPoints().get(i).getFormat().setFillForegroundColor`.  
- **Legend** pozycjonowanie (`setHasLegend`, `setPosition`) pomaga czytelnikom interpretować kategorie.  
- **Title** (`setTitle`) zapewnia kontekst na pierwszy rzut oka.  

Wszystkie te ustawienia są opcjonalne; możesz je dostosować, aby pasowały do palety Twojej marki lub szablonów korporacyjnych.

## Utwórz pusty dokument Word i zapisz wynik

Metoda `createBlankWordDocument` kapsułkuje krok **create blank word document**. Utrzymanie tej logiki w izolacji ułatwia ponowne użycie metody przy generowaniu wielu raportów w procesie wsadowym. Po wszystkich dostosowaniach, `doc.save` zapisuje plik w standardowym formacie Office Open XML (`.docx`), który można otworzyć w Microsoft Word, LibreOffice lub Google Docs bez utraty jakości.

### Oczekiwany wynik

Gdy uruchomisz metodę `main`, konsola wypisze:

```
Document saved successfully.
```

A plik `output/DoughnutChartFormatted.docx` zawiera jedną stronę z wykresem pierścieniowym zatytułowanym *Quarterly Sales Distribution*. Wykres pokazuje cztery segmenty, pierwszy segment eksplodowany, pokolorowany w odcieniu marki i obrócony o 45 stopni.

## Typowe warianty i przypadki brzegowe

| Sytuacja | Dostosowanie |
|----------|--------------|
| **More than one data series** | Dodaj dodatkowe obiekty `ChartSeries` do `chart.getSeries()`. |
| **Different chart size** | Zmień argumenty `width` i `height` w `insertPieChart`. |
| **No hole (pure pie)** | Pomiń `chart.setHoleSize(…)` lub ustaw na `0`. |
| **Large documents** | Użyj `DocumentBuilder`, aby wstawić wykres do określonej sekcji lub zakładki. |
| **License not set** | Biblioteka działa w trybie ewaluacyjnym, dodając znak wodny na pierwszej stronie. Zarejestruj licencję, aby go usunąć. |
