# Jak utworzyć dokument Word z polami zastępczymi i listami

Jeśli potrzebujesz **utworzyć dokument Word** programowo, ten przewodnik pokaże Ci dokładnie, jak to zrobić. Przejdziemy przez **ustawić tekst zastępczy**, **dodać elementy listy**, oraz **jak używać SDT** (Structured Document Tag) controls z Aspose.Words for .NET.

Programiści często pytają o sposób wstawiania kontrolek treści — takich jak pola zastępcze w formacie plain‑text lub listy rozwijane — bezpośrednio do pliku .docx bez otwierania Worda. Ten tutorial dostarcza kompletny, gotowy do uruchomienia przykład, wyjaśnia, dlaczego każdy krok ma znaczenie, i omawia typowe warianty, takie jak dodawanie kontrolek do istniejącego dokumentu lub dostosowywanie wartości listy.

## Prerequisites

Before you start, make sure you have:

- .NET 6.0 SDK lub nowszy, zainstalowany  
- Visual Studio 2022 (lub dowolne IDE C#)  
- Aktywna licencja Aspose.Words for .NET (bezpłatna wersja próbna wystarczy do rozwoju)  
- Podstawowa znajomość składni C#  

The code targets **Aspose.Words 23.9** (the latest stable version at the time of writing). Adjust the NuGet package version if you use a newer release.

Creating a fresh `Document` ensures you start with a clean file structure, avoiding hidden formatting that can appear when you open a template. `DocumentBuilder` abstracts the low‑level OPC (Open Packaging Convention) handling, letting you focus on content.

## Wstaw plain‑text Structured Document Tag (ustaw tekst zastępczy)

A plain‑text SDT behaves like a content control that the user can fill in. Setting its `Title` and `PlaceholderName` provides a friendly hint inside Word.

```csharp
            // Step 2: Insert a plain‑text SDT and set its placeholder text
            StructuredDocumentTag plainTextTag = builder.InsertStructuredDocumentTag(
                StructuredDocumentTagType.PlainText, true);
            plainTextTag.Title = "CustomerName";
            plainTextTag.PlaceholderName = "Enter name";
```

**Explanation:**  
- `InsertStructuredDocumentTag` tworzy kontrolkę w bieżącej pozycji kursora buildera.  
- `StructuredDocumentTagType.PlainText` instruuje Word, aby wyświetlił prostą ramkę tekstową.  
- `Title` jest wewnętrzną nazwą używaną w XML Worda; przydaje się przy późniejszym wiązaniu danych.  
- `PlaceholderName` to szara wskazówka wyświetlana, dopóki użytkownik nic nie wpisze.

> **Pro tip:** Jeśli potrzebujesz, aby placeholder pojawił się w panelu *Properties* dokumentu, ustaw także `plainTextTag.Tag = "CustomerName"`.

## Wstaw listę rozwijaną SDT (jak używać sdt)

A drop‑down list lets you present a predefined set of choices. This is the core of **how to use sdt** for enumerated data.

```csharp
            // Step 3: Insert a drop‑down list SDT and define its title
            StructuredDocumentTag dropdownTag = builder.InsertStructuredDocumentTag(
                StructuredDocumentTagType.DropDownList, true);
            dropdownTag.Title = "Country";
```

**Why a drop‑down?**  
Drop‑down lists improve data consistency and reduce typing errors. The `Title` property again serves as an identifier for downstream processing (e.g., when extracting form data).

## Dodaj elementy listy do listy rozwijanej (add list items)

Now we populate the control with selectable values. Each `ListItem` takes a display text and an optional value that can be stored in the document’s XML.

```csharp
            // Step 4: Populate the drop‑down with selectable items
            dropdownTag.ListItems.Add(new ListItem("USA", "US"));
            dropdownTag.ListItems.Add(new ListItem("Canada", "CA"));
            dropdownTag.ListItems.Add(new ListItem("Mexico", "MX"));
```

**Key points:**  

- Pierwszy argument (`"USA"`) to to, co widzi użytkownik.  
- Drugi argument (`"US"`) to wartość podstawowa, którą możesz odczytać programowo.  
- Możesz dodać dowolną liczbę elementów; lista jest przechowywana w elementach `<w:listItem>` XML pliku .docx.

### Przypadki brzegowe i warianty

| Sytuacja | Zalecana korekta |
|-----------|------------------------|
| **Dodawanie kontrolek do istniejącego pliku** | Załaduj plik przy użyciu `new Document("Existing.docx")` zamiast tworzyć nowy `Document`. |
| **Wymaganie wypełnienia pola zastępczego** | Ustaw `plainTextTag.IsShowingPlaceholderWhenEmpty = false` oraz `plainTextTag.IsShowingPlaceholderWhenEmpty = true` w zależności od logiki walidacji. |
| **Powiązanie elementów listy ze źródłem danych** | Przejdź przez kolekcję (`foreach (var country in countries)`) i wywołaj `dropdownTag.ListItems.Add(new ListItem(country.Name, country.Code))`. |
| **Stylowanie kontrolki** | Użyj właściwości `builder.Font` przed wstawieniem SDT, aby wpłynąć na domyślny styl tekstu zastępczego. |
| **Usuwanie kontrolki później** | Znajdź ją za pomocą `doc.GetChildNodes(NodeType.StructuredDocumentTag, true)` i wywołaj `tag.Remove();`. |

## Jak tworzyć kontrolki programowo – najlepsze praktyki

1. **Utwórz najpierw dokument – wczesna inicjalizacja `DocumentBuilder` zapobiega niespodziewanym pozycjom kursora.**  
2. **Ustaw tytuły i tagi – służą jako stabilne identyfikatory przy późniejszym wyciąganiu danych.**  
3. **Dodaj tekst zastępczy – poprawia doświadczenie użytkownika, szczególnie w przypadku tagów plain‑text.**  
4. **Od razu wypełnij elementy listy – Word renderuje listę rozwijaną poprawnie dopiero po dołączeniu elementów.**  
5. **Zapisz raz – wielokrotne wywołania `Save` w pętli znacząco zwiększają obciążenie I/O.**  

By following these steps, you ensure that the Word file is both *machine‑readable* (for back‑end processing) and *user‑friendly* (for front‑end editing).
