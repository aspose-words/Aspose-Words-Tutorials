# Jak podsumować dokument Word przy użyciu dostawców AI w C#

Jeśli potrzebujesz szybko **podsumować dokument Word**, ten przewodnik pokaże Ci dokładnie, jak to zrobić. Zobaczysz kompletny, gotowy do uruchomienia przykład, który pozwala **wybrać dostawcę AI** (OpenAI lub Google) i obsłużyć scenariusz **podsumowania dużego dokumentu** bez opuszczania IDE.

Podsumowywanie dokumentu Word jest powszechnym zadaniem przy budowaniu botów baz wiedzy, streszczeń raportów lub automatycznych podsumowań e‑mail. W kolejnych sekcjach dowiesz się, który pakiet NuGet zainstalować, jak wczytać plik `.docx`, skonfigurować podsumowywacz i wyświetlić wynik — wszystko w czystym C#.

## Czego będziesz potrzebować

| Requirement | Reason |
|-------------|--------|
| .NET 6 SDK or later | Zapewnia środowisko uruchomieniowe dla przykładu w C# |
| Visual Studio 2022 (or any IDE) | Umożliwia łatwe dodawanie pakietów NuGet i uruchamianie aplikacji konsolowej |
| `GroupDocs.Summarization` NuGet package | Dostarcza API `DocumentSummarizer` używane w kodzie |
| An internet connection | Wymagane dla dostawcy AI (OpenAI lub Google) do przetworzenia tekstu |

> **Porada:** Jeśli planujesz **podsumować duży dokument** (powyżej 100 KB), włącz tryb strumieniowania w opcjach, aby uniknąć ładowania całego pliku do pamięci.

## Jak podsumować dokument Word krok po kroku

### Krok 1: Zainstaluj bibliotekę podsumowującą

Otwórz konsolę Package Manager i uruchom:

```powershell
Install-Package GroupDocs.Summarization
```

Biblioteka `GroupDocs.Summarization` abstrahuje wywołania AI, dzięki czemu możesz zmienić dostawcę bez modyfikacji logiki biznesowej.

### Krok 2: Wczytaj dokument Word

```csharp
using GroupDocs.Summarization;
using GroupDocs.Summarization.Options;

// Step 2: Load the source document
Document doc = new Document("YOUR_DIRECTORY/Report.docx");
```

Klasa `Document` odczytuje plik `.docx` i przygotowuje go do podsumowania. Jeśli plik jest duży, biblioteka automatycznie używa parsera oszczędzającego pamięć.

### Krok 3: Skonfiguruj opcje podsumowywacza i **wybierz dostawcę AI**

```csharp
// Step 3: Set up summarization options (choose the AI provider)
SummarizerOptions options = new SummarizerOptions
{
    Provider = SummarizerProvider.OpenAI   // or SummarizerProvider.Google
};
```

- `Provider = SummarizerProvider.OpenAI` wybiera model GPT‑4 od OpenAI.  
- `Provider = SummarizerProvider.Google` wybiera model Gemini od Google, co jest idealne, gdy **podsumowujesz przy użyciu Google** dla lepszej obsługi wielu języków.

Możesz **wybrać dostawcę AI** w zależności od kosztów, opóźnień lub wymagań językowych. Ten sam obiekt `options` działa dla obu dostawców, utrzymując kod schludnym.

### Krok 4: Wygeneruj podsumowanie – wsparcie **podsumowania dużego dokumentu**

```csharp
// Step 4: Generate the summary using the selected provider
string summary = DocumentSummarizer.Summarize(doc, options);
```

Gdy **podsumowujesz duży dokument**, biblioteka strumieniuje zawartość do usługi AI, zapobiegając błędom braku pamięci. Metoda `Summarize` zwraca ciąg tekstowy zawierający najważniejsze zdania.

### Krok 5: Wyświetl wynik

```csharp
// Step 5: Output the generated summary
Console.WriteLine("Summary:\n" + summary);
```

Uruchomienie programu wyświetla zwięzły akapit, który oddaje istotę oryginalnego pliku Word.

## Pełny, gotowy do uruchomienia przykład

```csharp
using System;
using GroupDocs.Summarization;
using GroupDocs.Summarization.Options;

namespace WordSummarizerDemo
{
    class Program
    {
        static void Main(string[] args)
        {
            // Load the source Word document
            Document doc = new Document("YOUR_DIRECTORY/Report.docx");

            // Choose the AI provider (OpenAI or Google)
            SummarizerOptions options = new SummarizerOptions
            {
                Provider = SummarizerProvider.Google   // Change to OpenAI if you prefer
            };

            // Generate the summary – works for both small and large documents
            string summary = DocumentSummarizer.Summarize(doc, options);

            // Display the summary in the console
            Console.WriteLine("Summary:\n" + summary);
        }
    }
}
```

**Oczekiwany wynik**

```
Summary:
The quarterly sales increased by 12% driven by the new product line, while operational costs fell 3% due to efficiency gains. The report also highlights upcoming market expansion in APAC and recommends allocating additional budget to R&D.
```

Dokładne sformułowanie będzie się różnić w zależności od modelu AI, którego **wybierzesz jako dostawcę**, ale struktura pozostanie taka sama.

## Obsługa scenariusza **podsumowania dużego dokumentu**

Gdy źródłowy plik `.docx` przekracza 5 MB, rozważ następujące zmiany:

1. **Włącz podział na fragmenty** – biblioteka dzieli dokument na bloki po 5 KB przed wysłaniem ich do usługi AI.  
2. **Zwiększ `MaxSentences`** w `SummarizerOptions`, jeśli potrzebujesz dłuższego podsumowania.  
3. **Ustaw `Timeout`** na wyższą wartość, aby uwzględnić dłuższy czas przetwarzania.

```csharp
options.MaxSentences = 8;          // Return up to 8 sentences
options.EnableChunking = true;    // Essential for very large files
options.Timeout = TimeSpan.FromMinutes(2);
```

Te drobne zmiany zapewniają, że operacja **podsumowania dużego dokumentu** pozostaje szybka i niezawodna.

## Jak **podsumować przy użyciu Google** efektywnie

Model Gemini od Google wyróżnia się w obsłudze treści wielojęzycznych i zwięzłych sformułowań. Aby uzyskać najlepsze wyniki:

- **Określ język** (opcjonalnie), jeśli dokument zawiera tekst nie‑angielski:
  ```csharp
  options.Language = "es"; // Spanish
  ```
- **Dostosuj temperaturę** aby kontrolować kreatywność:
  ```csharp
  options.Temperature = 0.3; // More deterministic output
  ```

Gdy **podsumowujesz przy użyciu Google**, usługa może zwrócić nieco krótsze, ale bardzo skoncentrowane podsumowanie w porównaniu do OpenAI. Przetestuj obu dostawców na przykładowym dokumencie, aby zdecydować, który lepiej pasuje do Twojego produktu.

## Typowe pułapki i jak ich unikać

| Objaw | Przyczyna | Rozwiązanie |
|-------|-----------|-------------|
| Pusty podsumowanie | Brak klucza dostawcy lub zablokowana sieć | Zweryfikuj klucze API w zmiennych środowiskowych i upewnij się, że połączenia HTTPS wychodzące są dozwolone |
| Obcięty tekst | Dokument przekracza limit tokenów dostawcy | Włącz `EnableChunking` lub zwiększ `MaxTokens`, jeśli biblioteka to obsługuje |
| Nieoczekiwany język | Nieprawidłowa opcja `Language` | Usuń opcję lub ustaw ją na rzeczywisty język dokumentu |

Rozwiązywanie tych problemów na wczesnym etapie oszczędza czas debugowania, szczególnie gdy **wybierasz dostawcę AI** dla produkcyjnych obciążeń.

## Podsumowanie

Teraz wiesz, jak **podsumować dokument Word** w C# przy użyciu elastycznej warstwy AI. Konfigurując `SummarizerOptions`, możesz **wybrać dostawcę AI**, obsłużyć obciążenie **podsumowania dużego dokumentu**, a nawet **podsumować przy użyciu Google** dla potrzeb wielojęzycznych. Eksperymentuj z `MaxSentences`, `Temperature` i ustawieniami podziału na fragmenty, aby dopasować wynik do swojego konkretnego scenariusza.

### Kolejne kroki

- Zbadaj zaawansowane funkcje `DocumentSummarizer`, takie jak ekstrakcja słów kluczowych.  
- Połącz podsumowywanie z **tłumaczeniem dokumentu**, aby tworzyć wielojęzyczne streszczenia.  
- Zintegruj podsumowanie z API webowym, aby inne usługi mogły żądać podsumowań na żądanie.

Miłego kodowania i ciesz się mocą podsumowywania dokumentów napędzanym przez AI!
