# Utwórz pusty dokument Word i ukryj kształt elipsy w C#

Jeśli potrzebujesz **utworzyć pusty dokument Word** i następnie ukryć element graficzny, ten przewodnik pokazuje dokładnie, jak to zrobić w C#. Zobaczysz kompletny, gotowy do uruchomienia przykład, który wstawia elipsę, pozycjonuje ją, oznacza jako ukrytą i zapisuje plik — wszystko w kilku linijkach kodu.

Samouczek obejmuje wszystko, od konfiguracji projektu po końcowy krok weryfikacji. Po jego zakończeniu będziesz mógł wygenerować plik Word, w którym elipsa nigdy nie pojawia się na ekranie ani w druku, co jest przydatne do przechowywania metadanych, zakładek lub dowolnego niewidzialnego znacznika.

## Wymagania wstępne

* .NET 6.0 SDK lub nowszy zainstalowany  
* Środowisko programistyczne C# (Visual Studio 2022, Rider lub VS Code)  
* Pakiet NuGet **Aspose.Words for .NET** (`Install-Package Aspose.Words`)  

Te narzędzia dostarczają klasy `Document` i `DocumentBuilder` używane w przykładzie kodu.

## Krok 1: Utwórz pusty dokument Word

Pierwsza operacja tworzy pusty obiekt `Document` oraz `DocumentBuilder`, który umożliwia dodawanie treści.

```csharp
using Aspose.Words;
using Aspose.Words.Drawing;

// Step 1: Initialize an empty document and a builder
Document doc = new Document();
DocumentBuilder builder = new DocumentBuilder(doc);
```

`Document` reprezentuje cały pakiet `.docx`, natomiast `DocumentBuilder` oferuje płynne API do wstawiania tekstu, kształtów i innych obiektów. Rozpoczęcie od pustego dokumentu daje pełną kontrolę nad każdym dodawanym elementem.

## Krok 2: Jak wstawić elipsę

Elipsa jest kształtem wektorowym, który może służyć jako znacznik. Metoda `InsertShape` wymaga typu kształtu oraz jego szerokości/wysokości w punktach.

```csharp
// Step 2: Insert an ellipse shape of the desired size (100 pt × 50 pt)
Shape ellipse = builder.InsertShape(ShapeType.Ellipse, 100, 50);
```

Elipsa znajduje się na bieżącej stronie w miejscu kursora. Możesz zmienić jej wymiary, modyfikując argumenty liczbowe.

## Krok 3: Jak pozycjonować kształt

Po wstawieniu możesz przenieść kształt w dowolne miejsce na stronie, ustawiając właściwości `Left` i `Top`, które używają punktów względem marginesu strony.

```csharp
// Step 3: Position the shape on the page
ellipse.Left = 150; // distance from the left margin
ellipse.Top  = 100; // distance from the top margin
```

Te współrzędne umieszczają elipsę mniej więcej w górnej‑środkowej części standardowej strony A4. Dostosuj wartości, aby spełnić wymagania układu.

## Krok 4: Jak ukryć kształt

Ukryty obiekt nie jest wyświetlany, gdy dokument jest otwierany lub drukowany. Ustawienie flagi `Hidden` oznacza kształt jako **ukryty obiekt w Word**.

```csharp
// Step 4: Hide the shape so it never appears
ellipse.Hidden = true;
```

Word respektuje flagę ukrycia zarówno przy renderowaniu na ekranie, jak i przy wydruku. Kształt pozostaje częścią struktury dokumentu, co pozwala na późniejsze odpytywanie lub modyfikowanie go za pomocą kodu.

## Krok 5: Zapisz dokument

Na koniec zapisz dokument na dysku. Wybierz folder, do którego masz prawo zapisu.

```csharp
// Step 5: Save the document to a .docx file
doc.Save(@"C:\Temp\HiddenEllipse.docx");
```

Plik `HiddenEllipse.docx` zawiera teraz pustą stronę z ukrytym kształtem elipsy.

## Weryfikacja ukrytej elipsy

Otwórz wygenerowany plik w Microsoft Word i włącz opcję **Pokaż ukryty tekst** (Plik → Opcje → Wyświetlanie). Zobaczysz słaby zarys elipsy. Jeśli wyłączysz tę opcję, kształt zniknie całkowicie, potwierdzając, że `ellipse.Hidden = true` działa zgodnie z oczekiwaniami.

## Typowe warianty i przypadki brzegowe

| Situation | Recommended adjustment |
|-----------|------------------------|
| **Inny kształt** | Zastąp `ShapeType.Ellipse` przez `ShapeType.Rectangle`, `ShapeType.Arrow` itp. |
| **Wiele ukrytych obiektów** | Powtórz kroki 2‑4 dla każdego kształtu; każdy może mieć własną flagę `Hidden`. |
| **Inny rozmiar strony** | Ustaw `doc.FirstSection.PageSetup.PageWidth` i `PageHeight` przed wstawieniem kształtu. |
| **Warunkowa widoczność** | Użyj `Shape.Visible` w połączeniu z `Hidden`, aby przełączać w czasie wykonywania za pomocą kodu. |

**Wskazówka:** Przechowuj dane identyfikacyjne w właściwości `AlternativeText` kształtu. Nawet gdy jest ukryty, możesz później pobrać kształt przy pomocy `doc.GetChildNodes(NodeType.Shape, true)` i przefiltrować go według tego tekstu.

## Pełny kod źródłowy

Poniżej znajduje się kompletny program, który możesz skopiować, wkleić i uruchomić.

```csharp
using System;
using Aspose.Words;
using Aspose.Words.Drawing;

namespace HiddenShapeDemo
{
    class Program
    {
        static void Main()
        {
            // Create a new blank document and a builder
            Document doc = new Document();
            DocumentBuilder builder = new DocumentBuilder(doc);

            // Insert an ellipse shape (100 pt × 50 pt)
            Shape ellipse = builder.InsertShape(ShapeType.Ellipse, 100, 50);

            // Position the shape on the page
            ellipse.Left = 150;
            ellipse.Top  = 100;

            // Hide the shape so it is invisible in the UI and on print
            ellipse.Hidden = true;

            // Optional: add a description for later retrieval
            ellipse.AlternativeText = "Hidden marker for internal processing";

            // Save the document
            string outputPath = @"C:\Temp\HiddenEllipse.docx";
            doc.Save(outputPath);

            Console.WriteLine($"Document saved to {outputPath}");
        }
    }
}
```

**Oczekiwany wynik:** Konsola wypisuje ścieżkę zapisu, a plik `HiddenEllipse.docx` otwiera się jako pusta strona bez widocznych grafik, chyba że ukryte obiekty są wyświetlane.

## Zakończenie

Teraz wiesz, jak programowo **utworzyć pusty dokument Word**, **wstawić elipsę**, **pozycjonować kształt** oraz **ukryć kształt**, aby zachowywał się jako **ukryty obiekt w Word**. Ta technika jest idealna do osadzania niewidzialnych znaczników, własnych metadanych lub placeholderów, które procesy downstream mogą odczytać bez wpływu na wizualny układ dokumentu.

### Kolejne kroki

* Zbadaj inne typy kształtów (`ShapeType.Arrow`, `ShapeType.TextBox`), aby osadzać różne znaczniki.  
* Połącz ukryte kształty z własnymi częściami XML, aby uzyskać bogatsze przechowywanie metadanych.  
* Zintegruj ten kod z większym potokiem automatyzacji, który generuje raporty lub umowy.

Śmiało eksperymentuj z współrzędnymi, wymiarami i flagą ukrycia, aby dopasować je do swojego konkretnego scenariusza. Szczęśliwego kodowania!
