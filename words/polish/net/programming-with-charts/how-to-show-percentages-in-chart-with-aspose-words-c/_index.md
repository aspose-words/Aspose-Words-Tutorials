# Jak wyświetlić procenty na wykresie w Aspose.Words C#

Zastanawiałeś się kiedyś **jak wyświetlić procenty na wykresie** bez walki z złożonym interopem Office? Nie jesteś sam — wielu programistów napotyka ten problem, gdy potrzebują szybkiego, programistycznego sposobu na oznaczenie wykresu kołowego lub pierścieniowego. Dobra wiadomość? Dzięki Aspose.Words dla .NET możesz włączyć te etykiety danych w zaledwie kilku linijkach kodu.

W tym samouczku omówimy także **dodawanie etykiet danych do wykresu kołowego** oraz **jak włączyć etykiety danych wykresu**, aby Twoje wizualizacje od razu stały się bardziej pouczające. Po zakończeniu będziesz mieć gotowy do użycia dokument Word (`.docx`) wyświetlający dopracowany wykres kołowy z procentami ładnie umieszczonymi na zewnątrz każdego kawałka.

## Wymagania wstępne

Zanim zaczniemy, upewnij się, że masz:

- **Aspose.Words for .NET** (najnowsza wersja, np. 24.9) zainstalowaną przez NuGet.
- Plik **ChartTemplate.docx**, który już zawiera wykres kołowy lub pierścieniowy.  
  *(Jeśli go nie masz, utwórz prosty dokument Word, wstaw wykres kołowy i zapisz go jako `ChartTemplate.docx`.)*
- .NET 6.0 lub nowszy oraz dowolne IDE, którego używasz (Visual Studio, Rider, VS Code).

Nie są wymagane dodatkowe zależności — Aspose.Words obsługuje wszystko wewnętrznie.

## Jak wyświetlić procenty na wykresie – krok po kroku

Poniżej dzielimy proces na sześć przejrzystych kroków. Każdy krok zawiera dokładny kod C#, który możesz skopiować‑wkleić, oraz krótkie wyjaśnienie **dlaczego** to robimy.

### Krok 1: Załaduj dokument źródłowy

```csharp
using Aspose.Words;
using Aspose.Words.Drawing.Charts;

// Load the .docx that already holds a chart.
Document sourceDoc = new Document("YOUR_DIRECTORY/ChartTemplate.docx");
```

*Dlaczego?*  
`Document` jest punktem wejścia do wszelkich manipulacji Wordem. Ładując szablon, uzyskujemy dostęp do każdego węzła — kształtów, tabel, tekstu i oczywiście wykresu, który zamierzamy zmodyfikować.

### Krok 2: Pobierz pierwszy kształt wykresu

```csharp
// The chart lives inside a Shape node; retrieve it.
Chart chart = (Chart)sourceDoc.GetChild(NodeType.Shape, 0, true);
```

*Dlaczego?*  
Aspose przechowuje wykresy jako obiekty `Shape`. `GetChild` przeszukuje drzewo dokumentu i zwraca pierwszy napotkany kształt, którym w naszym przypadku jest wykres kołowy, który chcemy edytować.

### Krok 3: Potwierdź typ wykresu

```csharp
if (chart.ChartType == ChartType.Pie || chart.ChartType == ChartType.Doughnut)
{
    // Inside this block we’ll enable the data labels.
}
else
{
    throw new InvalidOperationException("The chart is not a Pie or Doughnut type.");
}
```

*Dlaczego?*  
Etykiety procentowe mają sens tylko dla wykresów okrągłych. Ten warunek zapobiega przypadkowemu zastosowaniu ustawień do, powiedzmy, wykresu słupkowego, gdzie `ShowPercentage` byłoby ignorowane.

### Krok 4: Włącz etykiety danych i pokaż procenty

```csharp
// Turn on data labels for the chart.
chart.HasDataLabel = true;

// Show the percentage value for each slice.
chart.DataLabel.ShowPercentage = true;
```

*Dlaczego?*  
`HasDataLabel` mówi Aspose, aby renderował etykietę dla każdego punktu danych. Ustawienie `ShowPercentage` zapewnia, że treść etykiety to obliczony udział w całości — dokładnie to, o co prosi wymaganie **dodawanie etykiet danych do wykresu kołowego**.

### Krok 5: Umieść etykiety na zewnątrz kawałków

```csharp
// Place the labels outside the pie slices for better readability.
chart.DataLabel.Position = ChartDataLabelPosition.OutSideEnd;
```

*Dlaczego?*  
Etykiety wewnątrz kawałków mogą stać się ciasne, zwłaszcza gdy kawałki są małe. `OutSideEnd` naśladuje domyślny styl „na zewnątrz”, który widzisz w interfejsie Worda, utrzymując wykres w czystości.

### Krok 6: Zapisz zaktualizowany dokument

```csharp
sourceDoc.Save("YOUR_DIRECTORY/FormattedPieChart.docx");
```

*Dlaczego?*  
Zapis zapisuje wszystkie zmiany do nowego pliku. Otwórz `FormattedPieChart.docx` w Wordzie, a zobaczysz procenty wyświetlane obok każdego kawałka.

#### Oczekiwany rezultat

Po otwarciu `FormattedPieChart.docx` wykres kołowy powinien wyglądać podobnie do tego (wyimaginowany zrzut ekranu):

```
[ Pie chart with three slices ]
- Slice A – 45%
- Slice B – 30%
- Slice C – 25%
```

Wszystkie procenty są obliczane automatycznie na podstawie podstawowej serii danych, a etykiety znajdują się tuż poza każdym kawałkiem.

## Typowe warianty i przypadki brzegowe

| Sytuacja | Co należy dostosować |
|-----------|----------------------|
| **Wiele wykresów** w tym samym dokumencie | Przejdź pętlą przez `sourceDoc.GetChildNodes(NodeType.Shape, true)` i rzutuj każdy na `Chart` przed zastosowaniem tej samej logiki. |
| **Wykres słupkowy lub liniowy**, w którym nadal chcesz etykiety | Użyj `chart.DataLabel.ShowValue = true;` (lub `ShowSeriesName`) zamiast `ShowPercentage`. |
| **Niestandardowy format liczby** (np. „45 %”) | Ustaw `chart.DataLabel.NumberFormat = "0%";` przed zapisem. |
| **Duże zestawy danych** powodujące nakładanie się etykiet | Rozważ `chart.DataLabel.ShowLeaderLines = true;`, aby narysować linie łączące. |

> **Pro tip:** Jeśli generujesz wiele dokumentów w partii, zainicjalizuj pojedynczy obiekt `Aspose.Words.License` przy starcie aplikacji, aby uniknąć spadku wydajności związanego z wielokrotnym ładowaniem licencji.

## Pełny działający przykład

Oto cały program złożony razem, gotowy do uruchomienia:

```csharp
using System;
using Aspose.Words;
using Aspose.Words.Drawing.Charts;

class Program
{
    static void Main()
    {
        // 1️⃣ Load the template document.
        Document sourceDoc = new Document("YOUR_DIRECTORY/ChartTemplate.docx");

        // 2️⃣ Retrieve the first chart shape.
        Chart chart = (Chart)sourceDoc.GetChild(NodeType.Shape, 0, true);

        // 3️⃣ Ensure we’re dealing with a Pie or Doughnut chart.
        if (chart.ChartType != ChartType.Pie && chart.ChartType != ChartType.Doughnut)
        {
            Console.WriteLine("The selected shape is not a Pie/Doughnut chart.");
            return;
        }

        // 4️⃣ Enable data labels and show percentages.
        chart.HasDataLabel = true;
        chart.DataLabel.ShowPercentage = true;

        // 5️⃣ Position the labels outside the slices.
        chart.DataLabel.Position = ChartDataLabelPosition.OutSideEnd;

        // 6️⃣ Save the modified document.
        sourceDoc.Save("YOUR_DIRECTORY/FormattedPieChart.docx");

        Console.WriteLine("Chart updated successfully – percentages now visible!");
    }
}
```

Skopiuj kod, zamień `YOUR_DIRECTORY` na rzeczywistą ścieżkę na swoim komputerze i uruchom go. W kilka sekund będziesz mieć plik Word z w pełni oznaczonym wykresem kołowym.

## Podsumowanie

Odpowiedzieliśmy na pytanie **jak wyświetlić procenty na wykresie** używając Aspose.Words dla C#. Omówione kroki:

1. Załaduj szablon.
2. Pobierz kształt wykresu.
3. Zweryfikuj, że jest to wykres kołowy/pierścieniowy.
4. **Dodaj etykiety danych do wykresu kołowego** i włącz procenty.
5. Umieść te etykiety na zewnątrz.
6. Zapisz wynik.

Dzięki tej wiedzy możesz teraz automatyzować dowolny scenariusz raportowy, który wymaga przejrzystych wizualizacji opartych na procentach.

## Co dalej?

- **Stylizuj etykiety** – zmień czcionkę, kolor lub dodaj tło przy użyciu `chart.DataLabel.Font`.  
- **Twórz wykresy od podstaw** – poznaj `Chart chart = (Chart)sourceDoc.FirstSection.Body.AppendChild(new Shape(sourceDoc, ShapeType.Chart));`, aby generować wykresy programowo.  
- **Łącz wiele wykresów** w jednym dokumencie, tworząc pulpity nawigacyjne, a następnie eksportuj do PDF przy pomocy `sourceDoc.Save("Dashboard.pdf", SaveFormat.Pdf);`.

Śmiało eksperymentuj, a jeśli napotkasz problemy, zostaw komentarz. Powodzenia w tworzeniu wykresów!
