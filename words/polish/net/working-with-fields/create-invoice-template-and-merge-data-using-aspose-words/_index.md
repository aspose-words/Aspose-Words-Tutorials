# Utwórz szablon faktury i scal dane przy użyciu Aspose.Words

Jeśli potrzebujesz **szybko utworzyć szablon faktury**, ten przewodnik pokaże Ci dokładnie, jak to zrobić. Po przeczytaniu pierwszych dwóch zdań będziesz znać kompletny przepływ pracy, który zamienia pusty plik Word w w pełni wypełnioną fakturę, przy użyciu niskokodowego API scalania korespondencji Aspose.Words.

Generowanie faktur jest powszechnym wymogiem dla systemów rozliczeniowych, integracji ERP i automatycznych raportów. W tym samouczku nauczysz się **jak scalanie korespondencji**, **wypełniania szablonu Word**, **scalania danych w Word**, oraz w końcu **zapisywania scalonego dokumentu** — wszystko przy użyciu kilku linii C#.

## Co osiągniesz

* Ponownie używalny szablon Word (`InvoiceTemplate.docx`) zawierający pola scalania dla klienta, daty, pozycji oraz sumy.  
* Program w C#, który ładuje szablon, wstrzykuje silnie typowany obiekt danych i zapisuje wynik do `Invoice_001.docx`.  
* Wgląd w przypadki brzegowe, takie jak puste kolekcje, niestandardowe typy danych i obsługa ścieżek plików.

### Wymagania wstępne

| Wymaganie | Dlaczego jest ważne |
|-------------|----------------|
| .NET 6 or later | Aspose.Words for .NET obsługuje .NET 6+ i udostępnia niskokodowe API użyte w tym przewodniku. |
| Aspose.Words for .NET NuGet package (`Aspose.Words`) | Dostarcza `Document`, `MailMerger` oraz powiązane typy. |
| Basic C# knowledge | Podstawowa znajomość C# – wymagana do zrozumienia obiektów anonimowych i LINQ. |
| Visual Studio 2022 (or any IDE) | Visual Studio 2022 (lub dowolne IDE) – ułatwia edycję i debugowanie. |

> **Pro tip:** Zainstaluj pakiet NuGet za pomocą Package Manager Console:  
> `Install-Package Aspose.Words`

## Jak utworzyć szablon faktury przy użyciu niskokodowego scalania korespondencji

Pierwszym krokiem jest stworzenie pliku Word, który zawiera pola scalania odpowiadające właściwościom obiektu danych, który przekażesz później. Zapisz plik jako `InvoiceTemplate.docx` w folderze, którym zarządzasz (np. `C:\Invoices\Template`).

| Pole scalania | Przykładowy placeholder w Word |
|-------------|-----------------------------|
| CustomerName | «CustomerName» |
| InvoiceDate | «InvoiceDate» |
| Items (repeating) | «Items.Description», «Items.Qty», «Items.Price» |
| Total | «Total» |

> **Why this matters:** The low‑code API automatically maps the property names of the data source to the merge fields. Keeping names identical eliminates manual field‑to‑property mapping and reduces runtime errors.

## Krok 1: Załaduj szablon faktury

```csharp
using Aspose.Words;
using Aspose.Words.LowCode;   // Low‑code mail‑merge API

// Load the Word file that contains the merge fields.
Document template = new Document(@"C:\Invoices\Template\InvoiceTemplate.docx");
```

*Klasa `Document` reprezentuje cały plik Word. Załadowanie go raz pozwala ponownie używać tego samego szablonu dla wielu faktur.*

## Krok 2: Przygotuj źródło danych

Utwórz anonimowy obiekt, który odzwierciedla pola scalania. Niskokodowe API może pracować z dowolnym obiektem .NET, w tym z tablicami i zagnieżdżonymi kolekcjami.

```csharp
var invoiceData = new
{
    CustomerName = "Acme Corp",
    InvoiceDate = DateTime.Today,
    Items = new[]
    {
        new { Description = "Widget A", Qty = 10, Price = 9.99M },
        new { Description = "Widget B", Qty = 5,  Price = 19.95M }
    },
    Total = 199.85M
};
```

**Why this works:**  
* Nazwy właściwości (`CustomerName`, `InvoiceDate`, `Items`, `Total`) odpowiadają polom scalania w szablonie.  
* `Items` jest tablicą obiektów, więc mail merger automatycznie powtórzy wiersz tabeli dla każdego elementu.  
* Użycie typu `decimal` (`M` suffix) dla wartości pieniężnych eliminuje problemy z zaokrąglaniem zmiennoprzecinkowym.

### Obsługa pustych kolekcji

Jeśli faktura nie ma pozycji, przekaż pustą tablicę:

```csharp
Items = new object[0]
```

Silnik niskokodowy po prostu pominie sekcję powtarzalną, pozostawiając nagłówek tabeli nienaruszony.

## Krok 3: Zainicjalizuj niskokodowy mail merger

```csharp
MailMerger merger = new MailMerger(template);
```

`MailMerger` jest punktem wejścia dla **how to mail merge** z Aspose.Words. Odczytuje szablon, wiąże dane i przygotowuje finalny dokument w jednym wywołaniu.

## Krok 4: Wykonaj scalanie – wypełnij szablon Word w jednej linii

```csharp
Document mergedDocument = merger.Execute(invoiceData);
```

* Ta linia **populates the word template** i tworzy nową instancję `Document` (`mergedDocument`).  
* Wszystkie pola scalania zostają zastąpione, sekcje powtarzalne zostają rozwinięte, a wynikowy dokument znajduje się w całości w pamięci.

### Przypadek brzegowy: Niestandardowe formatowanie

Jeśli potrzebujesz konkretnego formatu daty, dodaj własny format przed scaleniem:

```csharp
merger.Options.DateFormat = "MMMM dd, yyyy"; // e.g., "October 07, 2026"
```

## Krok 5: Zapisz scalony dokument

```csharp
mergedDocument.Save(@"C:\Invoices\Output\Invoice_001.docx");
```

Wywołanie **save merged document** zapisuje w pełni wypełnioną fakturę na dysku. Plik może teraz zostać otwarty w Microsoft Word, wysłany jako załącznik e‑mail lub przekonwertowany na PDF.

### Weryfikacja wyniku

Otwórz `Invoice_001.docx`. Powinieneś zobaczyć:

* **CustomerName** zastąpione przez *Acme Corp*  
* **InvoiceDate** wyświetlające dzisiejszą datę w wybranym formacie  
* Wiersz tabeli dla *Widget A* (10 × 9.99) i *Widget B* (5 × 19.95)  
* **Total** wyświetlające *199.85*  

Jeśli któreś pole pozostanie niezmienione (np. nadal pokazuje «CustomerName»), sprawdź, czy nazwy właściwości dokładnie odpowiadają nazwom pól scalania w szablonie.

## Pełny działający przykład

Poniżej znajduje się kompletny program, który możesz skopiować i wkleić do nowego projektu konsolowego.

```csharp
using System;
using Aspose.Words;
using Aspose.Words.LowCode;   // Low‑code mail‑merge API

namespace InvoiceGenerator
{
    class Program
    {
        static void Main()
        {
            // 1️⃣ Load the template
            Document template = new Document(@"C:\Invoices\Template\InvoiceTemplate.docx");

            // 2️⃣ Build the data source
            var invoiceData = new
            {
                CustomerName = "Acme Corp",
                InvoiceDate = DateTime.Today,
                Items = new[]
                {
                    new { Description = "Widget A", Qty = 10, Price = 9.99M },
                    new { Description = "Widget B", Qty = 5,  Price = 19.95M }
                },
                Total = 199.85M
            };

            // 3️⃣ Initialise the mail merger
            MailMerger merger = new MailMerger(template);

            // Optional: customise date format
            merger.Options.DateFormat = "MMMM dd, yyyy";

            // 4️⃣ Perform the merge (populate word template)
            Document mergedDocument = merger.Execute(invoiceData);

            // 5️⃣ Save the resulting file (save merged document)
            mergedDocument.Save(@"C:\Invoices\Output\Invoice_001.docx");

            Console.WriteLine("Invoice generated successfully.");
        }
    }
}
```

Uruchom program (`dotnet run`). Konsola wypisze *Invoice generated successfully.* i plik pojawi się w `C:\Invoices\Output`.
