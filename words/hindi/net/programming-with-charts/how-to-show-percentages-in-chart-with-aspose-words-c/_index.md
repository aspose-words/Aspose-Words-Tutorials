# चार्ट में प्रतिशत कैसे दिखाएँ Aspose.Words C# के साथ

क्या आपने कभी **चार्ट में प्रतिशत कैसे दिखाएँ** के बारे में सोचा है बिना जटिल Office interop से जूझे? आप अकेले नहीं हैं—कई डेवलपर्स को यह समस्या आती है जब उन्हें पाई या डोनट चार्ट को जल्दी से प्रोग्रामेटिक तरीके से लेबल करने की जरूरत होती है। अच्छी खबर? Aspose.Words for .NET के साथ आप केवल कुछ लाइनों में डेटा लेबल सक्षम कर सकते हैं।

इस ट्यूटोरियल में हम **पाई चार्ट में डेटा लेबल जोड़ें** और **चार्ट डेटा लेबल कैसे सक्षम करें** को भी कवर करेंगे ताकि आपके विज़ुअलाइज़ेशन तुरंत अधिक सूचनात्मक बन जाएँ। अंत तक आपके पास एक तैयार‑उपयोग Word दस्तावेज़ (`.docx`) होगा जिसमें एक परिष्कृत पाई चार्ट प्रतिशतों के साथ प्रत्येक स्लाइस के बाहर साफ़‑सुथरे ढंग से दिखाया गया होगा।

## आवश्यकताएँ

- **Aspose.Words for .NET** (नवीनतम संस्करण, उदाहरण के लिए 24.9) NuGet के माध्यम से स्थापित।
- एक **ChartTemplate.docx** फ़ाइल जिसमें पहले से ही पाई या डोनट चार्ट हो।  
  *(यदि आपके पास नहीं है, तो एक साधारण Word दस्तावेज़ बनाएँ, पाई चार्ट डालें, और इसे `ChartTemplate.docx` के रूप में सहेजें।)*
- .NET 6.0 या बाद का संस्करण और कोई भी IDE जो आप पसंद करते हैं (Visual Studio, Rider, VS Code)।

कोई अतिरिक्त निर्भरताएँ आवश्यक नहीं हैं—Aspose.Words सब कुछ आंतरिक रूप से संभालता है।

## चार्ट में प्रतिशत दिखाने के चरण‑दर‑चरण

नीचे हम प्रक्रिया को छह स्पष्ट चरणों में विभाजित करते हैं। प्रत्येक चरण में वह सटीक C# कोड शामिल है जिसे आप कॉपी‑पेस्ट कर सकते हैं, साथ ही **क्यों** हम यह करते हैं, इसका संक्षिप्त स्पष्टीकरण भी।

### चरण 1: स्रोत दस्तावेज़ लोड करें

```csharp
using Aspose.Words;
using Aspose.Words.Drawing.Charts;

// Load the .docx that already holds a chart.
Document sourceDoc = new Document("YOUR_DIRECTORY/ChartTemplate.docx");
```

*क्यों?*  
`Document` किसी भी Word हेरफेर का प्रवेश बिंदु है। टेम्पलेट लोड करके हमें प्रत्येक नोड—शेप्स, टेबल्स, टेक्स्ट, और बेशक वह चार्ट जिसे हम संशोधित करेंगे—तक पहुँच मिलती है।

### चरण 2: पहला चार्ट शेप प्राप्त करें

```csharp
// The chart lives inside a Shape node; retrieve it.
Chart chart = (Chart)sourceDoc.GetChild(NodeType.Shape, 0, true);
```

*क्यों?*  
Aspose charts को `Shape` ऑब्जेक्ट्स के रूप में संग्रहीत करता है। `GetChild` दस्तावेज़ ट्री को चलाता है और पहला शैप लौटाता है, जो हमारे मामले में वह पाई चार्ट है जिसे हम संपादित करना चाहते हैं।

### चरण 3: चार्ट प्रकार की पुष्टि करें

```csharp
if (chart.ChartType == ChartType.Pie || chart.ChartType == ChartType.Doughnut)
{
    // Inside this block we’ll enable the data labels.
}
else
{
    throw new InvalidOperationException("The chart is not a Pie or Doughnut type.");
}
```

*क्यों?*  
प्रतिशत लेबल केवल गोलाकार चार्ट के लिए अर्थपूर्ण होते हैं। यह गार्ड सुनिश्चित करता है कि हम गलती से सेटिंग्स बार चार्ट जैसे किसी अन्य प्रकार पर लागू न करें जहाँ `ShowPercentage` को नजरअंदाज किया जाएगा।

### चरण 4: डेटा लेबल सक्षम करें और प्रतिशत दिखाएँ

```csharp
// Turn on data labels for the chart.
chart.HasDataLabel = true;

// Show the percentage value for each slice.
chart.DataLabel.ShowPercentage = true;
```

*क्यों?*  
`HasDataLabel` Aspose को प्रत्येक डेटा पॉइंट के लिए लेबल रेंडर करने को बताता है। `ShowPercentage` सेट करने से लेबल सामग्री पूरे का गणना किया गया हिस्सा बन जाता है—बिल्कुल वही जो **पाई चार्ट में डेटा लेबल जोड़ें** की आवश्यकता है।

### चरण 5: लेबल को स्लाइस के बाहर स्थित करें

```csharp
// Place the labels outside the pie slices for better readability.
chart.DataLabel.Position = ChartDataLabelPosition.OutSideEnd;
```

*क्यों?*  
स्लाइस के अंदर के लेबल छोटे स्लाइस होने पर भीड़भाड़ कर सकते हैं। `OutSideEnd` वह डिफ़ॉल्ट “बाहर” शैली की नकल करता है जो आप Word UI में देखते हैं, जिससे चार्ट साफ़ रहता है।

### चरण 6: अपडेटेड दस्तावेज़ सहेजें

```csharp
sourceDoc.Save("YOUR_DIRECTORY/FormattedPieChart.docx");
```

*क्यों?*  
सेव करने से सभी बदलाव नई फ़ाइल में लिखे जाते हैं। `FormattedPieChart.docx` को Word में खोलें और आप देखेंगे कि प्रत्येक स्लाइस के बगल में प्रतिशत दिखाए गए हैं।

#### अपेक्षित परिणाम

`FormattedPieChart.docx` खोलने पर, पाई चार्ट इस (काल्पनिक स्क्रीनशॉट) जैसा दिखना चाहिए:

```
[ Pie chart with three slices ]
- Slice A – 45%
- Slice B – 30%
- Slice C – 25%
```

सभी प्रतिशत स्वचालित रूप से अंतर्निहित डेटा सीरीज़ से गणना किए जाते हैं, और लेबल प्रत्येक स्लाइस के ठीक बाहर स्थित होते हैं।

## सामान्य विविधताएँ और किनारी मामलों

| स्थिति | क्या समायोजित करें |
|-----------|----------------|
| **एक ही दस्तावेज़ में कई चार्ट** | `sourceDoc.GetChildNodes(NodeType.Shape, true)` पर लूप करें और प्रत्येक को `Chart` में कास्ट करें, फिर समान लॉजिक लागू करें। |
| **बार या लाइन चार्ट** जहाँ आप अभी भी लेबल चाहते हैं | `ShowPercentage` के बजाय `chart.DataLabel.ShowValue = true;` (या `ShowSeriesName`) का उपयोग करें। |
| **कस्टम नंबर फॉर्मेट** (उदा., “45 %”) | सहेजने से पहले `chart.DataLabel.NumberFormat = "0%";` सेट करें। |
| **बड़े डेटा सेट** जिससे लेबल ओवरलैप हो | कनेक्टर लाइनों को ड्रॉ करने के लिए `chart.DataLabel.ShowLeaderLines = true;` पर विचार करें। |

> **प्रो टिप:** यदि आप बैच में कई दस्तावेज़ बना रहे हैं, तो एप्लिकेशन शुरू में एक ही `Aspose.Words.License` ऑब्जेक्ट बनाएं ताकि लाइसेंस को बार‑बार लोड करने के प्रदर्शन प्रभाव से बचा जा सके।

## पूर्ण कार्यशील उदाहरण

यहाँ पूरा प्रोग्राम एक साथ दिया गया है, चलाने के लिए तैयार:

```csharp
using System;
using Aspose.Words;
using Aspose.Words.Drawing.Charts;

class Program
{
    static void Main()
    {
        // 1️⃣ Load the template document.
        Document sourceDoc = new Document("YOUR_DIRECTORY/ChartTemplate.docx");

        // 2️⃣ Retrieve the first chart shape.
        Chart chart = (Chart)sourceDoc.GetChild(NodeType.Shape, 0, true);

        // 3️⃣ Ensure we’re dealing with a Pie or Doughnut chart.
        if (chart.ChartType != ChartType.Pie && chart.ChartType != ChartType.Doughnut)
        {
            Console.WriteLine("The selected shape is not a Pie/Doughnut chart.");
            return;
        }

        // 4️⃣ Enable data labels and show percentages.
        chart.HasDataLabel = true;
        chart.DataLabel.ShowPercentage = true;

        // 5️⃣ Position the labels outside the slices.
        chart.DataLabel.Position = ChartDataLabelPosition.OutSideEnd;

        // 6️⃣ Save the modified document.
        sourceDoc.Save("YOUR_DIRECTORY/FormattedPieChart.docx");

        Console.WriteLine("Chart updated successfully – percentages now visible!");
    }
}
```

कोड कॉपी करें, `YOUR_DIRECTORY` को अपने मशीन पर वास्तविक पथ से बदलें, और इसे चलाएँ। कुछ ही सेकंड में आपके पास एक Word फ़ाइल होगी जिसमें पूरी तरह लेबल किया हुआ पाई चार्ट होगा।

## सारांश

हमने **चार्ट में प्रतिशत कैसे दिखाएँ** का उत्तर Aspose.Words for C# का उपयोग करके दिया है। कवर किए गए चरण:

1. टेम्पलेट लोड करें।  
2. चार्ट शेप प्राप्त करें।  
3. पुष्टि करें कि यह पाई/डोनट है।  
4. **पाई चार्ट में डेटा लेबल जोड़ें** और प्रतिशत सक्षम करें।  
5. लेबल को बाहर स्थित करें।  
6. परिणाम सहेजें।

इस ज्ञान के साथ आप अब किसी भी रिपोर्टिंग परिदृश्य को स्वचालित कर सकते हैं जिसमें स्पष्ट, प्रतिशत‑आधारित विज़ुअलाइज़ेशन की आवश्यकता होती है।

## आगे क्या?

- **लेबल की शैली बदलें** – फ़ॉन्ट, रंग बदलें, या `chart.DataLabel.Font` का उपयोग करके पृष्ठभूमि जोड़ें।  
- **शुरू से चार्ट बनाएं** – प्रोग्रामेटिक रूप से चार्ट उत्पन्न करने के लिए `Chart chart = (Chart)sourceDoc.FirstSection.Body.AppendChild(new Shape(sourceDoc, ShapeType.Chart));` देखें।  
- **एक ही दस्तावेज़ में कई चार्ट मिलाएँ** डैशबोर्ड के लिए, फिर `sourceDoc.Save("Dashboard.pdf", SaveFormat.Pdf);` के साथ PDF में निर्यात करें।

बिना संकोच प्रयोग करें, और यदि आपको कोई अजीब समस्या मिले तो टिप्पणी करें। चार्टिंग का आनंद लें!
