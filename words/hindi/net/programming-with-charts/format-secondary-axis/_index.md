# Aspose.Words for .NET का उपयोग करके Word चार्ट में द्वितीयक Y‑अक्ष को मुद्रा के रूप में फ़ॉर्मेट करें
इस ट्यूटोरियल में आप देखेंगे कि Aspose.Words for .NET का उपयोग करके Word दस्तावेज़ कैसे बनाया जाए, लाइन चार्ट कैसे डाला जाए, द्वितीयक Y‑अक्ष कैसे जोड़ा जाए, उस अक्ष को दो दशमलव स्थानों के साथ मुद्रा के रूप में फ़ॉर्मेट किया जाए, और उससे द्वितीयक डेटा सीरीज़ को बाइंड किया जाए। द्वितीयक अक्ष को मुद्रा के रूप में फ़ॉर्मेट करने से आप वित्तीय डेटा को प्राइमरी सीरीज़ के साथ स्पष्ट रूप से प्रस्तुत कर सकते हैं। चरण‑दर‑चरण कोड का पालन करें ताकि चार्ट सीधे उत्पन्न दस्तावेज़ में रेंडर हो।

1. Download Aspose.Words for .NET:
   Get the latest version from the [Aspose Downloads page](https://releases.aspose.com/words/net/).

2. Install via NuGet:
   - Open your Visual Studio project.
   - Navigate to the NuGet Package Manager (Tools > NuGet Package Manager > Manage NuGet Packages for Solution).
   - Search for "Aspose.Words" and click Install.

3. Add Namespace References:

## Frequently asked questions

**Q: यदि मैं `lineChart.Series.Clear()` कॉल को छोड़ दूँ तो क्या होगा?**  
A: चार्ट Aspose.Words द्वारा डाली गई डिफ़ॉल्ट प्लेसहोल्डर सीरीज़ को रखेगा, इसलिए आपकी कस्टम "Main Series" अनचाहे डेटा पॉइंट्स के साथ दिखाई देगी।

**Q: मैं द्वितीयक X‑अक्ष को छिपाने के बजाय कैसे दिखा सकता हूँ?**  
A: `secondarySeriesGroup.AxisX.Hidden = false;` सेट करें (या बस वह लाइन हटाएँ जो इसे `true` सेट करती है)।

**Q: क्या मैं द्वितीयक Y‑अक्ष के लिए अलग मुद्रा प्रतीक या फ़ॉर्मेट उपयोग कर सकता हूँ?**  
A: हाँ – फ़ॉर्मेट स्ट्रिंग बदलें, उदाहरण के लिए यूरो के लिए `secondarySeriesGroup.AxisY.NumberFormat.FormatCode = "\"€\"#,##0.00";` या अपने लोकेल के अनुसार पैटर्न समायोजित करें।

**Q: कस्टम नंबर फ़ॉर्मेट लागू करते समय `IsLinkedToSource = false` सेट करने की आवश्यकता क्यों है?**  
A: जब `IsLinkedToSource` true होता है तो अक्ष आधार डेटा स्रोत से नंबर फ़ॉर्मेट विरासत में लेता है, जिससे कोई भी कस्टम `FormatCode` ओवरराइड हो जाता है; इसे false सेट करने से चार्ट को आप द्वारा निर्दिष्ट फ़ॉर्मेट उपयोग करने के लिए मजबूर किया जाता है।

**Q: क्या द्वितीयक Y‑अक्ष को चार्ट के बाएँ पक्ष पर ले जाना संभव है?**  
A: हाँ, `secondarySeriesGroup.AxisY.Position = AxisPosition.Left;` असाइन करें (या डिफ़ॉल्ट के लिए `Right`) ताकि आप तय कर सकें कि अक्ष किस पक्ष पर खींचा जाए।
