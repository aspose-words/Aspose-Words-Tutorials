# ब्लैंक Word दस्तावेज़ बनाएं और C# में एक एलिप्स आकार को छुपाएँ

यदि आपको **ब्लैंक Word दस्तावेज़** बनाना है और फिर एक ग्राफ़िकल एलिमेंट को छुपाना है, तो यह गाइड आपको C# के साथ ठीक‑ठीक बताता है कि कैसे करना है। आप एक पूर्ण, चलाने योग्य उदाहरण देखेंगे जो एक एलिप्स डालता है, उसकी स्थिति सेट करता है, उसे छुपा देता है, और फ़ाइल को सहेजता है—सभी कुछ पंक्तियों के कोड में।

यह ट्यूटोरियल प्रोजेक्ट सेटअप से लेकर अंतिम सत्यापन चरण तक सब कुछ कवर करता है। अंत तक, आप एक ऐसा Word फ़ाइल बना सकते हैं जहाँ एलिप्स स्क्रीन या प्रिंट में कभी नहीं दिखता, जो मेटाडेटा, बुकमार्क या किसी भी अदृश्य मार्कर को संग्रहीत करने के लिए उपयोगी है।

## आवश्यकताएँ

शुरू करने से पहले सुनिश्चित करें कि आपके पास है:

* .NET 6.0 SDK या बाद का संस्करण स्थापित हो  
* एक C# विकास वातावरण (Visual Studio 2022, Rider, या VS Code)  
* **Aspose.Words for .NET** NuGet पैकेज (`Install-Package Aspose.Words`)  

ये टूल्स कोड नमूने में उपयोग किए गए `Document` और `DocumentBuilder` क्लासेज़ प्रदान करते हैं।

## चरण १: एक ब्लैंक Word दस्तावेज़ बनाएं

पहला ऑपरेशन एक खाली `Document` ऑब्जेक्ट और एक `DocumentBuilder` बनाता है जो आपको कंटेंट जोड़ने की अनुमति देता है।

```csharp
using Aspose.Words;
using Aspose.Words.Drawing;

// Step 1: Initialize an empty document and a builder
Document doc = new Document();
DocumentBuilder builder = new DocumentBuilder(doc);
```

`Document` पूरे `.docx` पैकेज का प्रतिनिधित्व करता है, जबकि `DocumentBuilder` टेक्स्ट, शैप्स और अन्य ऑब्जेक्ट्स डालने के लिए एक फ्लुएंट API प्रदान करता है। ब्लैंक दस्तावेज़ से शुरू करने से आप जोड़ने वाले हर एलिमेंट पर पूरी नियंत्रण प्राप्त करते हैं।

## चरण २: एलिप्स कैसे डालें

एक एलिप्स एक वेक्टर शैप है जिसे मार्कर के रूप में उपयोग किया जा सकता है। `InsertShape` मेथड को शैप टाइप और उसकी चौड़ाई/ऊँचाई पॉइंट्स में चाहिए होती है।

```csharp
// Step 2: Insert an ellipse shape of the desired size (100 pt × 50 pt)
Shape ellipse = builder.InsertShape(ShapeType.Ellipse, 100, 50);
```

एलिप्स वर्तमान पेज पर कर्सर लोकेशन पर रहता है। आप संख्यात्मक आर्ग्यूमेंट्स को समायोजित करके उसके आयाम बदल सकते हैं।

## चरण ३: आकार को कैसे स्थित करें

डालने के बाद, आप `Left` और `Top` प्रॉपर्टीज़ सेट करके शैप को पेज पर कहीं भी ले जा सकते हैं, जो पेज मार्जिन के सापेक्ष पॉइंट्स में होते हैं।

```csharp
// Step 3: Position the shape on the page
ellipse.Left = 150; // distance from the left margin
ellipse.Top  = 100; // distance from the top margin
```

ये कॉर्डिनेट्स एलिप्स को एक सामान्य A4 पेज के ऊपर‑मध्य में रखती हैं। अपने लेआउट की आवश्यकताओं के अनुसार मानों को समायोजित करें।

## चरण ४: आकार को कैसे छुपाएँ

एक छुपा हुआ ऑब्जेक्ट दस्तावेज़ खुलने या प्रिंट होने पर प्रदर्शित नहीं होता। `Hidden` फ़्लैग सेट करने से शैप **छुपा हुआ ऑब्जेक्ट शब्द** बन जाता है।

```csharp
// Step 4: Hide the shape so it never appears
ellipse.Hidden = true;
```

Word स्क्रीन रेंडरिंग और प्रिंट आउटपुट दोनों के लिए छुपे हुए फ़्लैग का सम्मान करता है। शैप दस्तावेज़ संरचना का हिस्सा बना रहता है, जिससे आप बाद में कोड के माध्यम से उसे क्वेरी या मॉडिफ़ाई कर सकते हैं।

## चरण ५: दस्तावेज़ को सहेजें

अंत में, दस्तावेज़ को डिस्क पर लिखें। ऐसी फ़ोल्डर चुनें जहाँ आपके पास लिखने की अनुमति हो।

```csharp
// Step 5: Save the document to a .docx file
doc.Save(@"C:\Temp\HiddenEllipse.docx");
```

फ़ाइल `HiddenEllipse.docx` अब एक ब्लैंक पेज के साथ छुपा हुआ एलिप्स शैप रखती है।

## छुपे हुए एलिप्स की जाँच

जनरेट की गई फ़ाइल को Microsoft Word में खोलें और **Show hidden text** विकल्प सक्षम करें (File → Options → Display)। आपको एलिप्स की हल्की रूपरेखा दिखाई देगी। यदि आप विकल्प बंद कर देते हैं, तो शैप पूरी तरह गायब हो जाता है, जिससे पुष्टि होती है कि `ellipse.Hidden = true` अपेक्षित रूप से काम करता है।

## सामान्य विविधताएँ और किनारी मामलों

| स्थिति | सिफारिशित समायोजन |
|-----------|------------------------|
| **विभिन्न आकार** | `ShapeType.Ellipse` को `ShapeType.Rectangle`, `ShapeType.Arrow` आदि से बदलें। |
| **एकाधिक छुपे हुए ऑब्जेक्ट्स** | प्रत्येक आकार के लिए चरण 2‑4 दोहराएँ; प्रत्येक का अपना `Hidden` फ़्लैग हो सकता है। |
| **विभिन्न पेज आकार** | आकार डालने से पहले `doc.FirstSection.PageSetup.PageWidth` और `PageHeight` सेट करें। |
| **शर्तीय दृश्यता** | रनटाइम में कोड के माध्यम से टॉगल करने के लिए `Hidden` के साथ `Shape.Visible` का उपयोग करें। |

**Pro tip:** शैप के `AlternativeText` प्रॉपर्टी में पहचान डेटा स्टोर करें। छुपा हुआ होने पर भी आप बाद में `doc.GetChildNodes(NodeType.Shape, true)` के साथ शैप को प्राप्त कर सकते हैं और उस टेक्स्ट के आधार पर फ़िल्टर कर सकते हैं।

## पूर्ण स्रोत कोड

नीचे वह पूरा प्रोग्राम है जिसे आप कॉपी, पेस्ट और रन कर सकते हैं।

```csharp
using System;
using Aspose.Words;
using Aspose.Words.Drawing;

namespace HiddenShapeDemo
{
    class Program
    {
        static void Main()
        {
            // Create a new blank document and a builder
            Document doc = new Document();
            DocumentBuilder builder = new DocumentBuilder(doc);

            // Insert an ellipse shape (100 pt × 50 pt)
            Shape ellipse = builder.InsertShape(ShapeType.Ellipse, 100, 50);

            // Position the shape on the page
            ellipse.Left = 150;
            ellipse.Top  = 100;

            // Hide the shape so it is invisible in the UI and on print
            ellipse.Hidden = true;

            // Optional: add a description for later retrieval
            ellipse.AlternativeText = "Hidden marker for internal processing";

            // Save the document
            string outputPath = @"C:\Temp\HiddenEllipse.docx";
            doc.Save(outputPath);

            Console.WriteLine($"Document saved to {outputPath}");
        }
    }
}
```

**Expected output:** कंसोल सहेजने का पाथ प्रिंट करता है, और फ़ाइल `HiddenEllipse.docx` एक ब्लैंक पेज के रूप में खुलती है जिसमें कोई दृश्यमान ग्राफ़िक नहीं होता जब तक कि छुपे हुए ऑब्जेक्ट्स दिखाए न जाएँ।

## निष्कर्ष

आप अब प्रोग्रामेटिक रूप से **ब्लैंक Word दस्तावेज़** कैसे बनाते हैं, **एलिप्स कैसे डालते हैं**, **शैप को कैसे स्थित करते हैं**, और **शैप को कैसे छुपाते हैं** ताकि वह **छुपा हुआ ऑब्जेक्ट शब्द** बन जाए, यह जानते हैं। यह तकनीक अदृश्य मार्कर, कस्टम मेटाडेटा, या प्लेसहोल्डर एम्बेड करने के लिए आदर्श है, जिन्हें डाउनस्ट्रीम प्रोसेस बिना दस्तावेज़ के दृश्य लेआउट को प्रभावित किए पढ़ सकते हैं।

### अगले कदम

* विभिन्न आकार प्रकारों (`ShapeType.Arrow`, `ShapeType.TextBox`) का अन्वेषण करें ताकि विभिन्न मार्कर एम्बेड कर सकें।  
* अधिक समृद्ध मेटाडेटा स्टोरेज के लिए छुपे शैप्स को कस्टम XML पार्ट्स के साथ मिलाएँ।  
* इस कोड को बड़े ऑटोमेशन पाइपलाइन में इंटीग्रेट करें जो रिपोर्ट या कॉन्ट्रैक्ट जनरेट करता है।

निर्दिष्ट परिदृश्य के अनुसार कॉर्डिनेट्स, आयाम और छुपा फ़्लैग के साथ प्रयोग करने में संकोच न करें। Happy coding!
