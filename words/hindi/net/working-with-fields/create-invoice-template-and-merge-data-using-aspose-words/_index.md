# Aspose.Words का उपयोग करके इनवॉइस टेम्पलेट बनाएं और डेटा मर्ज करें

यदि आपको **इनवॉइस टेम्पलेट** जल्दी बनाना है, तो यह गाइड आपको ठीक‑ठीक दिखाएगा। पहले दो वाक्यों के अंत तक आप यह समझ जाएंगे कि एक खाली Word फ़ाइल को पूरी तरह से भरे हुए इनवॉइस में बदलने की पूरी वर्कफ़्लो क्या है, Aspose.Words के लो‑कोड मेल‑मर्ज API का उपयोग करके।

इनवॉइस जनरेट करना बिलिंग सिस्टम, ERP इंटीग्रेशन और ऑटोमेटेड रिपोर्टिंग के लिए एक सामान्य आवश्यकता है। इस ट्यूटोरियल में आप सीखेंगे **कैसे मेल मर्ज करें**, **Word टेम्पलेट को पॉपुलेट करें**, **डेटा को Word में मर्ज करें**, और अंत में **मर्ज किए गए डॉक्यूमेंट को सेव करें**—सिर्फ कुछ C# लाइनों के साथ।

## आप क्या हासिल करेंगे

* एक पुन: उपयोग योग्य Word टेम्पलेट (`InvoiceTemplate.docx`) जिसमें ग्राहक, तिथि, लाइन आइटम और टोटल के लिए मर्ज फ़ील्ड हों।  
* एक C# प्रोग्राम जो टेम्पलेट को लोड करता है, एक स्ट्रॉन्ग‑टाइप्ड डेटा ऑब्जेक्ट इन्जेक्ट करता है, और परिणाम को `Invoice_001.docx` में लिखता है।  
* खाली कलेक्शन, कस्टम डेटा टाइप और फ़ाइल‑पाथ हैंडलिंग जैसे एज केस की समझ।

| Aspose.Words for .NET NuGet package (`Aspose.Words`) | `Document`, `MailMerger` और संबंधित टाइप्स उपलब्ध कराता है। |

## लो‑कोड मेल मर्ज के साथ इनवॉइस टेम्पलेट कैसे बनाएं

पहला कदम एक Word फ़ाइल बनाना है जिसमें मर्ज फ़ील्ड हों जो बाद में आप पास करने वाले डेटा ऑब्जेक्ट की प्रॉपर्टीज़ से मेल खाते हों। फ़ाइल को `InvoiceTemplate.docx` के रूप में उस फ़ोल्डर में सेव करें जिसे आप नियंत्रित करते हैं (जैसे, `C:\Invoices\Template`)।

| Merge field | Example placeholder in Word |
|-------------|-----------------------------|
| CustomerName | «CustomerName» |
| InvoiceDate | «InvoiceDate» |
| Items (repeating) | «Items.Description», «Items.Qty», «Items.Price» |
| Total | «Total» |

> **Why this matters:** लो‑कोड API डेटा स्रोत की प्रॉपर्टी नामों को मर्ज फ़ील्ड से स्वचालित रूप से मैप करता है। नामों को समान रखने से मैन्युअल फ़ील्ड‑टू‑प्रॉपर्टी मैपिंग नहीं करनी पड़ती और रन‑टाइम एरर कम होते हैं।

## Step 1: इनवॉइस टेम्पलेट लोड करें

```csharp
using Aspose.Words;
using Aspose.Words.LowCode;   // Low‑code mail‑merge API

// Load the Word file that contains the merge fields.
Document template = new Document(@"C:\Invoices\Template\InvoiceTemplate.docx");
```

*`Document` क्लास पूरे Word फ़ाइल का प्रतिनिधित्व करता है। इसे एक बार लोड करने से आप कई इनवॉइस के लिए एक ही टेम्पलेट को पुन: उपयोग कर सकते हैं।*

## Step 2: डेटा स्रोत तैयार करें

एक अनॉनिमस ऑब्जेक्ट बनाएं जो मर्ज फ़ील्ड के साथ मेल खाता हो। लो‑कोड API किसी भी .NET ऑब्जेक्ट के साथ काम कर सकता है, जिसमें एरे और नेस्टेड कलेक्शन शामिल हैं।

```csharp
var invoiceData = new
{
    CustomerName = "Acme Corp",
    InvoiceDate = DateTime.Today,
    Items = new[]
    {
        new { Description = "Widget A", Qty = 10, Price = 9.99M },
        new { Description = "Widget B", Qty = 5,  Price = 19.95M }
    },
    Total = 199.85M
};
```

**Why this works:**  
* प्रॉपर्टी नाम (`CustomerName`, `InvoiceDate`, `Items`, `Total`) टेम्पलेट में मर्ज फ़ील्ड से मेल खाते हैं।  
* `Items` ऑब्जेक्ट्स का एरे है, इसलिए मेल मर्जर प्रत्येक एलिमेंट के लिए टेबल रो को स्वचालित रूप से दोहराएगा।  
* मौद्रिक मानों के लिए `decimal` (`M` suffix) का उपयोग करने से फ़्लोटिंग‑पॉइंट राउंडिंग समस्याओं से बचा जा सकता है।

### खाली कलेक्शन को हैंडल करना

यदि किसी इनवॉइस में कोई लाइन आइटम नहीं है, तो एक खाली एरे पास करें:

```csharp
Items = new object[0]
```

लो‑कोड इंजन बस रिपीटिंग सेक्शन को छोड़ देगा, जबकि टेबल हेडर वैसा ही रहेगा।

## Step 3: लो‑कोड मेल मर्जर इनिशियलाइज़ करें

```csharp
MailMerger merger = new MailMerger(template);
```

`MailMerger` Aspose.Words के साथ **कैसे मेल मर्ज करें** का एंट्री पॉइंट है। यह टेम्पलेट को पढ़ता है, डेटा बाइंड करता है, और एक ही कॉल में अंतिम डॉक्यूमेंट तैयार करता है।

## Step 4: मर्ज निष्पादित करें – एक लाइन में Word टेम्पलेट पॉपुलेट करें

```csharp
Document mergedDocument = merger.Execute(invoiceData);
```

* यह लाइन **Word टेम्पलेट को पॉपुलेट** करती है और एक नया `Document` इंस्टेंस (`mergedDocument`) बनाती है।  
* सभी मर्ज फ़ील्ड बदल दिए जाते हैं, रिपीटिंग सेक्शन विस्तारित होते हैं, और परिणामी डॉक्यूमेंट पूरी तरह मेमोरी में रहता है।

### एज केस: कस्टम फ़ॉर्मेटिंग

यदि आपको विशेष तिथि फ़ॉर्मेट चाहिए, तो मर्ज से पहले एक कस्टम फ़ॉर्मैटर जोड़ें:

```csharp
merger.Options.DateFormat = "MMMM dd, yyyy"; // e.g., "October 07, 2026"
```

## Step 5: मर्ज किए गए डॉक्यूमेंट को सेव करें

```csharp
mergedDocument.Save(@"C:\Invoices\Output\Invoice_001.docx");
```

यह कॉल **save merged document** पूरी तरह पॉपुलेटेड इनवॉइस को डिस्क पर लिखती है। फ़ाइल अब Microsoft Word में खोली जा सकती है, ईमेल अटैचमेंट के रूप में भेजी जा सकती है, या PDF में कनवर्ट की जा सकती है।

### आउटपुट की वैरिफिकेशन

`Invoice_001.docx` खोलें। आपको दिखना चाहिए:

* **CustomerName** को *Acme Corp* से बदल दिया गया है  
* **InvoiceDate** चुने हुए फ़ॉर्मेट में आज की तिथि दिखा रहा है  
* *Widget A* (10 × 9.99) और *Widget B* (5 × 19.95) के लिए एक टेबल रो  
* **Total** में *199.85* दिख रहा है  

यदि कोई फ़ील्ड अपरिवर्तित रहता है (जैसे अभी भी «CustomerName» दिख रहा है), तो सुनिश्चित करें कि प्रॉपर्टी नाम टेम्पलेट में मर्ज फ़ील्ड नामों से बिल्कुल मेल खाते हों।

## पूर्ण चलाने योग्य उदाहरण

नीचे पूरा प्रोग्राम दिया गया है जिसे आप एक नए कंसोल प्रोजेक्ट में कॉपी‑पेस्ट कर सकते हैं।

```csharp
using System;
using Aspose.Words;
using Aspose.Words.LowCode;   // Low‑code mail‑merge API

namespace InvoiceGenerator
{
    class Program
    {
        static void Main()
        {
            // 1️⃣ Load the template
            Document template = new Document(@"C:\Invoices\Template\InvoiceTemplate.docx");

            // 2️⃣ Build the data source
            var invoiceData = new
            {
                CustomerName = "Acme Corp",
                InvoiceDate = DateTime.Today,
                Items = new[]
                {
                    new { Description = "Widget A", Qty = 10, Price = 9.99M },
                    new { Description = "Widget B", Qty = 5,  Price = 19.95M }
                },
                Total = 199.85M
            };

            // 3️⃣ Initialise the mail merger
            MailMerger merger = new MailMerger(template);

            // Optional: customise date format
            merger.Options.DateFormat = "MMMM dd, yyyy";

            // 4️⃣ Perform the merge (populate word template)
            Document mergedDocument = merger.Execute(invoiceData);

            // 5️⃣ Save the resulting file (save merged document)
            mergedDocument.Save(@"C:\Invoices\Output\Invoice_001.docx");

            Console.WriteLine("Invoice generated successfully.");
        }
    }
}
```

प्रोग्राम चलाएँ (`dotnet run`)। कंसोल पर *Invoice generated successfully.* प्रिंट होगा और फ़ाइल `C:\Invoices\Output` में दिखाई देगी।
