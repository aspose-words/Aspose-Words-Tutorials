# Word दस्तावेज़ में Java के साथ डोनट चार्ट कैसे बनाएं

यदि आपको Word फ़ाइल के अंदर **डोनट चार्ट बनाना** है, तो यह ट्यूटोरियल आपको एक पूर्ण, तैयार‑चलाने योग्य समाधान दिखाता है। आप देखेंगे कि कैसे **पाई चार्ट डालें**, उसे डोनट में बदलें, बेहतर संतुलन के लिए **पाई चार्ट घुमाएँ**, और **पाई चार्ट को फ़ॉर्मेट करें** ताकि वह आपके ब्रांडिंग से मेल खाए। अंत तक आपके पास एक पेशेवर Word दस्तावेज़ होगा जिसे रिपोर्ट, डैशबोर्ड, या स्वचालित ईमेल अटैचमेंट में उपयोग किया जा सकता है।

चार्ट को प्रोग्रामेटिकली बनाना मैन्युअल कॉपी‑पेस्ट चरणों को समाप्त करता है और सैकड़ों उत्पन्न दस्तावेज़ों में स्थिर शैली की गारंटी देता है। उदाहरण Aspose.Words for Java लाइब्रेरी का उपयोग करता है, जो Java 8+ के साथ काम करती है और Microsoft Office की स्थापना की आवश्यकता नहीं रखती। मानक JDK और आपके पसंदीदा IDE के अलावा कोई अन्य पूर्वापेक्षाएँ आवश्यक नहीं हैं।

## आवश्यकताएँ

- Java Development Kit (JDK) 8 या नया  
- Maven या Gradle निर्भरता प्रबंधन के लिए (ट्यूटोरियल Maven का उपयोग करता है)  
- Aspose.Words for Java लाइब्रेरी (टेस्टिंग के लिए मुफ्त ट्रायल लाइसेंस पर्याप्त है)  

Add the Aspose.Words dependency to your `pom.xml`:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-words</artifactId>
    <version>24.9</version> <!-- Use the latest stable version -->
</dependency>
```

> **प्रो टिप:** किसी भी दस्तावेज़ को बनाने से पहले `License license = new License(); license.setLicense("Aspose.Words.lic");` के साथ अपना लाइसेंस रजिस्टर करें ताकि मूल्यांकन वॉटरमार्क हट जाएँ।

## Word दस्तावेज़ में डोनट चार्ट बनाएं

मुख्य कार्यप्रवाह पाँच तार्किक चरणों से बना है। प्रत्येक चरण को अपने स्वयं के मेथड में लपेटा गया है ताकि कोड साफ़ और पुन: उपयोग योग्य रहे।

```java
import com.aspose.words.*;
import com.aspose.words.drawing.*;

public class DoughnutChartDemo {

    public static void main(String[] args) throws Exception {
        // Step 1: create blank Word document
        Document doc = createBlankWordDocument();

        // Step 2: insert a pie chart (base for the doughnut)
        Chart chart = insertPieChart(doc, 400, 300);

        // Step 3: convert the pie chart into a doughnut and rotate it
        customizeChartAppearance(chart);

        // Step 4: apply additional formatting to the chart
        formatPieChart(chart);

        // Step 5: save the final document
        doc.save("output/DoughnutChartFormatted.docx");
        System.out.println("Document saved successfully.");
    }

    /** Step 1 – create blank Word document */
    private static Document createBlankWordDocument() {
        // Aspose.Words creates an empty document by default
        return new Document();
    }

    /** Step 2 – insert pie chart with given dimensions */
    private static Chart insertPieChart(Document doc, int width, int height) throws Exception {
        DocumentBuilder builder = new DocumentBuilder(doc);
        // ChartType.PIE creates a standard pie chart that we will later turn into a doughnut
        Chart chart = builder.insertChart(ChartType.PIE, width, height);
        // Populate the chart with sample data
        chart.getSeries().clear(); // Remove default series
        ChartSeries series = chart.getSeries().add("Sales", new String[]{"Q1", "Q2", "Q3", "Q4"},
                new double[]{15000, 23000, 18000, 27000});
        return chart;
    }

    /** Step 3 – rotate pie chart and make it a doughnut */
    private static void customizeChartAppearance(Chart chart) {
        // Explode the first slice for emphasis
        chart.getSeries().get(0).setExplode(20);
        // Convert the pie into a doughnut by setting a hole size (percentage of radius)
        chart.setHoleSize(30); // 30% hole creates a classic doughnut look
        // Rotate the chart so the largest slice starts at 45°
        chart.setRotationAngle(45);
    }

    /** Step 4 – additional formatting of the pie chart */
    private static void formatPieChart(Chart chart) {
        // Example: change the first slice color to a brand color
        chart.getSeries().get(0).getPoints().get(0).getFormat().setFillForegroundColor(Color.fromArgb(0xFF, 0x4A, 0x90));
        // Add a legend and position it at the bottom
        chart.setHasLegend(true);
        chart.getLegend().setPosition(LegendPosition.BOTTOM);
        // Set a title for the chart
        chart.setTitle("Quarterly Sales Distribution");
    }
}
```

### कोड क्या करता है

| चरण | क्रिया | कारण |
|------|--------|--------|
| **खाली Word दस्तावेज़ बनाएं** | `new Document()` | एक साफ़ फ़ाइल से शुरू होता है ताकि आप हर तत्व को नियंत्रित कर सकें। |
| **पाई चार्ट डालें** | `builder.insertChart(ChartType.PIE, …)` | पाई चार्ट मूल आकार है; Aspose केवल होल साइज समायोजित करके डोनट प्रदान करता है। |
| **पाई चार्ट घुमाएँ** | `chart.setRotationAngle(45)` | घुमाने से सबसे बड़ा स्लाइस अधिक पढ़ने योग्य स्थिति में संरेखित होता है। |
| **पाई चार्ट को फ़ॉर्मेट करें** | `setExplode`, `setHoleSize`, color, legend | दृश्य पदानुक्रम को सुधारता है और कॉरपोरेट शैली दिशानिर्देशों से मेल खाता है। |
| **दस्तावेज़ सहेजें** | `doc.save("…/DoughnutChartFormatted.docx")` | अंतिम .docx फ़ाइल को डिस्क पर लिखता है, वितरण के लिए तैयार। |

## डोनट में बदलने से पहले पाई चार्ट डालें

Aspose.Words सीधे “डोनट चार्ट डालें” मेथड प्रदान नहीं करता। इसके बजाय, आप **पाई चार्ट डालें** और फिर उसकी प्रॉपर्टीज़ को संशोधित करें। यह दो‑चरणीय दृष्टिकोण आपको डेटा सीरीज़, स्लाइस एक्सप्लोजन, और होल साइज पर पूर्ण नियंत्रण देता है। यदि आपको कहीं और शुद्ध पाई चार्ट चाहिए, तो बस `setHoleSize` कॉल को छोड़ दें।

## दृश्य संतुलन के लिए पाई चार्ट घुमाएँ

डिफ़ॉल्ट अभिविन्यास पहले स्लाइस को 12 घंटे की स्थिति से शुरू करता है। कई व्यावसायिक रिपोर्टों में सबसे महत्वपूर्ण स्लाइस को अधिक प्राकृतिक कोण, जैसे 45 डिग्री पर शुरू होना चाहिए। `setRotationAngle(double angle)` मेथड डिग्री स्वीकार करता है और पूरे चार्ट को घुमाता है बिना डेटा मानों को प्रभावित किए।

## पाई चार्ट को फ़ॉर्मेट करें और रूप को अनुकूलित करें

डोनट में बदलने के अलावा, आप अक्सर **पाई चार्ट को फ़ॉर्मेट** करना चाहते हैं:

- **पहले स्लाइस को एक्सप्लोड** करें (`setExplode`) ताकि ध्यान आकर्षित हो।  
- **प्रत्येक स्लाइस को रंगें** `getPoints().get(i).getFormat().setFillForegroundColor` का उपयोग करके।  
- **लेजेंड** की स्थिति (`setHasLegend`, `setPosition`) पाठकों को श्रेणियों को समझने में मदद करती है।  
- **टाइटल** (`setTitle`) एक नज़र में संदर्भ प्रदान करता है।  

इन सभी सेटिंग्स वैकल्पिक हैं; आप इन्हें अपने ब्रांड पैलेट या कॉरपोरेट टेम्प्लेट के अनुसार अनुकूलित कर सकते हैं।

## खाली Word दस्तावेज़ बनाएं और परिणाम सहेजें

`createBlankWordDocument` मेथड **खाली Word दस्तावेज़ बनाएं** चरण को संलग्न करता है। इस लॉजिक को अलग रखने से बैच प्रक्रिया में कई रिपोर्ट उत्पन्न करते समय मेथड को पुन: उपयोग करना आसान हो जाता है। सभी कस्टमाइज़ेशन के बाद, `doc.save` फ़ाइल को मानक Office Open XML फ़ॉर्मेट (`.docx`) में लिखता है, जिसे Microsoft Word, LibreOffice, या Google Docs में बिना गुणवत्ता हानि के खोला जा सकता है।

### अपेक्षित आउटपुट

`main` मेथड चलाने पर, कंसोल प्रिंट करता है:

```
Document saved successfully.
```

और फ़ाइल `output/DoughnutChartFormatted.docx` में एक पृष्ठ होता है जिसमें *Quarterly Sales Distribution* शीर्षक वाला डोनट चार्ट होता है। चार्ट में चार स्लाइस दिखते हैं, पहला स्लाइस एक्सप्लोड किया गया है, ब्रांड रंग में रंगा हुआ है, और 45 डिग्री घुमाया गया है।

## सामान्य विविधताएँ और किनारे के मामले

| स्थिति | समायोजन |
|-----------|------------|
| **एक से अधिक डेटा सीरीज़** | `chart.getSeries()` में अतिरिक्त `ChartSeries` ऑब्जेक्ट जोड़ें। |
| **विभिन्न चार्ट आकार** | `insertPieChart` में `width` और `height` तर्क बदलें। |
| **कोई होल नहीं (शुद्ध पाई)** | `chart.setHoleSize(…)` को छोड़ दें या इसे `0` सेट करें। |
| **बड़े दस्तावेज़** | विशिष्ट सेक्शन या बुकमार्क में चार्ट डालने के लिए `DocumentBuilder` का उपयोग करें। |
| **लाइसेंस सेट नहीं है** | लाइब्रेरी मूल्यांकन मोड में चलती है, पहले पृष्ठ पर वॉटरमार्क जोड़ती है। इसे हटाने के लिए लाइसेंस रजिस्टर करें। |

## निष्कर्ष

अब आप जानते हैं कि Java का उपयोग करके Word दस्तावेज़ में **डोनट चार्ट कैसे बनाएं**, **खाली Word दस्तावेज़ बनाएं** से लेकर **पाई चार्ट डालें**, **पाई चार्ट घुमाएँ**, और **पाई चार्ट को फ़ॉर्मेट करें** तक, ताकि एक परिष्कृत अंतिम उत्पाद मिल सके। पूर्ण, चलाने योग्य उदाहरण को किसी भी Java प्रोजेक्ट में डाला जा सकता है जो पहले से Aspose.Words का उपयोग करता है।

अगला, आप खोज सकते हैं:

- डेटा लेबल जोड़ना (`chart.getSeries().get(0).setDataLabelType(DataLabelType.CATEGORY_AND_PERCENT);`)  
- चार्ट को इमेज के रूप में एक्सपोर्ट करना (`chart.toImage`) ताकि HTML ईमेल में उपयोग हो सके  
- लूप में कई दस्तावेज़ों की उत्पत्ति को स्वचालित करना बैच रिपोर्टिंग के लिए  

रंगों, स्लाइस एक्सप्लोजन, और लेजेंड के साथ प्रयोग करने में संकोच न करें ताकि आपके संगठन की दृश्य भाषा से मेल खाए। चार्टिंग का आनंद लें!
