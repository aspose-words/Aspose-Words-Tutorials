# Python में Aspose.Words के साथ कॉलम चार्ट कैसे बनाएं

यदि आपको Python में कॉलम चार्ट बनाना है, तो यह गाइड आपको आवश्यक सटीक कोड और तर्क प्रदान करता है। Aspose.Words चार्ट API का उपयोग करके, आप सटीक आयाम निर्धारित कर सकते हैं, एक बिल्ट‑इन स्टाइल लागू कर सकते हैं, और परिणाम को Python से बाहर निकले बिना एक्सपोर्ट कर सकते हैं।

रिपोर्ट, डैशबोर्ड और स्वचालित दस्तावेज़ निर्माण के लिए कॉलम चार्ट बनाना एक सामान्य आवश्यकता है। यह ट्यूटोरियल प्रत्येक चरण को कवर करता है—लाइब्रेरी को इम्पोर्ट करने से लेकर सेव्ड इमेज की पुष्टि तक—ताकि आप किसी भी Python प्रोजेक्ट में चार्ट जेनरेशन को एकीकृत कर सकें।

## Prerequisites

शुरू करने से पहले सुनिश्चित करें कि आपके पास है:

* Python 3.8 या उससे नया संस्करण स्थापित हो।
* एक वैध Aspose.Words for Python लाइसेंस (या एक फ्री इवैल्यूएशन की)।
* Python मॉड्यूल और ऑब्जेक्ट‑ओरिएंटेड कोड की बुनियादी समझ।

Aspose.Words चार्ट इंजन Windows, macOS और Linux पर काम करता है, और अतिरिक्त ग्राफिकल लाइब्रेरी की आवश्यकता नहीं होती क्योंकि रेंडरिंग सर्वर साइड पर होती है।

## Step 1: Import the Aspose.Words library

पहला चरण `aspose.words` पैकेज को इम्पोर्ट करना और उसे एक छोटा उपनाम देना है। फ़ाइल के शीर्ष पर इम्पोर्ट करने से नेमस्पेस साफ़ रहता है और कोड पढ़ने में आसान होता है।

```python
# Step 1: Import the Aspose.Words library
import aspose.words as aw
```

`aw` अब पूरे Aspose.Words API को रेफ़र करता है, जिसमें वह `Chart` क्लास भी शामिल है जिसका उपयोग आप कॉलम चार्ट बनाने के लिए करेंगे।

## Step 2: Create a column chart with the desired dimensions

कॉलम चार्ट को स्पष्ट चौड़ाई और ऊँचाई मानों की आवश्यकता होती है ताकि रेंडर की गई इमेज आपके दस्तावेज़ लेआउट में फिट हो सके। `Chart` कन्स्ट्रक्टर तीन आर्गुमेंट लेता है: चार्ट प्रकार, चौड़ाई (पॉइंट्स में), और ऊँचाई (पॉइंट्स में)। `aw.ChartType.COLUMN` का उपयोग करने से इंजन एक वर्टिकल बार चार्ट जेनरेट करता है।

```python
# Step 2: Create a column chart with the desired dimensions
chart = aw.Chart(aw.ChartType.COLUMN, 400, 300)   # width=400pt, height=300pt
```

*आयाम क्यों सेट करें?*  
जब आप चार्ट को Word दस्तावेज़ में एम्बेड करते हैं या इमेज के रूप में एक्सपोर्ट करते हैं, तो आसपास की सामग्री ठीक उसी आकार का सम्मान करती है जो आप प्रदान करते हैं। इससे अनचाहा स्केलिंग या क्लिपिंग नहीं होता।

### Pro tip: Use `chart.dimensions` for dynamic resizing

यदि आपका डेटा सेट बदलता रहता है, तो आप सीरीज़ की संख्या के आधार पर आकार की गणना कर सकते हैं:

```python
series_count = 5
base_width = 80
chart.width = base_width * series_count
chart.height = 300
```

## Step 3: Apply a built‑in style to the column chart

Aspose.Words कई प्री‑डिफाइंड विज़ुअल थीम्स के साथ आता है। एक स्टाइल चुनने से रंग, फ़ॉन्ट और ग्रिडलाइन को मैन्युअली कॉन्फ़िगर करने की ज़रूरत नहीं रहती। `aw.ChartStyle.STYLE_5` एक साफ़, प्रोफेशनल लुक देता है जो अधिकांश बिज़नेस रिपोर्ट्स के लिए उपयुक्त है।

```python
# Step 3: Apply a built‑in style to the chart
chart.style = aw.ChartStyle.STYLE_5
```

यदि आप कोई अलग लुक चाहते हैं, तो `STYLE_5` को किसी भी अन्य कॉन्स्टेंट (`STYLE_1` … `STYLE_8`) से बदल दें। प्रत्येक स्टाइल समान नामकरण नियम का पालन करता है, जिससे प्रयोग करना आसान हो जाता है।

### Edge case: Invalid style constant

एक गैर‑मौजूद स्टाइल असाइन करने पर `AttributeError` उठता है। इसे रोकने के लिए कॉन्स्टेंट को एनेमरेशन के खिलाफ चेक करें:

```python
if hasattr(aw.ChartStyle, "STYLE_5"):
    chart.style = aw.ChartStyle.STYLE_5
else:
    raise ValueError("Requested chart style does not exist.")
```

## Step 4: Add data series to the column chart

डेटा के बिना चार्ट बेकार है। आप एक या अधिक `ChartSeries` ऑब्जेक्ट्स जोड़ सकते हैं, जिनमें से प्रत्येक एक कॉलम ग्रुप को दर्शाता है। नीचे दिया गया उदाहरण तीन डेटा पॉइंट्स वाले एक सिंगल सीरीज़ को जोड़ता है।

```python
# Step 4: Add data series to the column chart
series = chart.series.add()
series.name = "Quarterly Sales"
series.data = [12000, 15000, 18000]   # Values for Q1, Q2, Q3
```

आप `chart.series.add()` कॉल को दोहराकर अतिरिक्त सीरीज़ (जैसे “Projected Sales”) जोड़ सकते हैं। API स्वचालित रूप से कॉलम्स को साइड‑बाय‑साइड वितरित करता है।

## Step 5: Render the chart and save it as an image

चार्ट को कॉन्फ़िगर करने के बाद, आप इसे बिटमैप या इमेज फ़ाइल में रेंडर करते हैं। `save` मेथड फ़ाइल पाथ और वैकल्पिक फ़ॉर्मेट दोनों को स्वीकार करता है। PNG लॉसलेस है और व्यापक रूप से सपोर्टेड है।

```python
# Step 5: Render and save the chart as a PNG image
output_path = "column_chart.png"
chart.save(output_path, aw.SaveFormat.PNG)
print(f"Chart saved to {output_path}")
```

`SaveFormat` एनेमरेशन में PNG, JPEG, BMP और अन्य फ़ॉर्मेट शामिल हैं। अपने डाउनस्ट्रीम वर्कफ़्लो के अनुसार उपयुक्त फ़ॉर्मेट चुनें।

## Verify the output

`column_chart.png` को किसी भी इमेज व्यूअर में खोलें। आपको एक तीन‑कॉलम बार चार्ट दिखना चाहिए जो चुनी गई बिल्ट‑इन थीम से स्टाइल किया गया है, और बिल्कुल 400 × 300 पॉइंट्स का आकार है।

![Column chart generated by Aspose.Words in Python](column_chart.png){: .center alt="Aspose.Words द्वारा Python में जेनरेट किया गया कॉलम चार्ट का स्क्रीनशॉट"}

यदि इमेज ब्लैंक या डिस्टॉर्टेड दिखे, तो निम्नलिखित बिंदुओं की दोबारा जाँच करें:

1. `aw.Chart` ऑब्जेक्ट को सीरीज़ जोड़ने से पहले इंस्टैंशिएट किया गया था।
2. `chart.style` कॉन्स्टेंट मौजूदा एनेम वैल्यू से मेल खाता है।
3. `save` कॉल एक सपोर्टेड `SaveFormat` का उपयोग कर रहा है।

## Common variations and additional tips

| Situation | Recommended change |
|-----------|--------------------|
| **Multiple data series** | अतिरिक्त `chart.series.add()` ब्लॉक्स जोड़ें और प्रत्येक के लिए `series.name` तथा `series.data` सेट करें। |
| **Custom colors** | बिल्ट‑इन स्टाइल लागू करने के बाद, व्यक्तिगत कॉलम रंगों को `series.points[i].fill.fore_color` के माध्यम से ओवरराइड करें। |
| **Embedding in a Word document** | `chart.save()` के बजाय, `doc = aw.Document(); doc.sections[0].body.append_child(chart); doc.save("report.docx")` उपयोग करें। |
| **Dynamic sizing** | सीरीज़ की संख्या के आधार पर चौड़ाई की गणना करें (`width = 80 * len(chart.series)`)। |

इन विविधताओं से आप देख सकते हैं कि समान कोर कोड विभिन्न रिपोर्टिंग परिदृश्यों के अनुसार कैसे अनुकूलित किया जा सकता है।
