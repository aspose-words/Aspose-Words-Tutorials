# Aspose.Words के साथ Markdown निर्यात करना और भ्रष्ट DOCX को पुनर्प्राप्त करना

यदि आपको किसी संभावित क्षतिग्रस्त Word फ़ाइल से **how to export markdown** निकालना है, तो यह गाइड आपको सटीक चरण दिखाता है। यह **how to recover document** समस्याओं, **export docx to txt**, और **save word as pdf** को Aspose.Words for Python API का उपयोग करके कवर करता है।

आप सीखेंगे कि कैसे संभावित भ्रष्ट DOCX को रिकवरी मोड में लोड किया जाए, उसे Markdown में परिवर्तित किया जाए जबकि समीकरणों को संरक्षित रखा जाए, उसी सामग्री को plain‑text के रूप में सहेजा जाए, एक सुलभ PDF जेनरेट किया जाए, और अंतिम निर्यात से पहले किसी आकार (shape) की छाया को समायोजित किया जाए। कोई बाहरी टूल आवश्यक नहीं—सिर्फ Aspose.Words और कुछ पंक्तियों का Python कोड।

## आवश्यकताएँ

* Python 3.8 या नया
* `aspose-words` पैकेज (`pip install aspose-words`)
* एक DOCX फ़ाइल जो भ्रष्ट हो सकती है (या परीक्षण के लिए कोई सामान्य DOCX)
* Python फ़ंक्शन्स और क्लासेज़ की बुनियादी जानकारी

> **Pro tip:** मूल DOCX की एक बैकअप रखें; रिकवरी मोड मेमोरी में प्रतिनिधित्व को संशोधित करता है लेकिन स्रोत फ़ाइल पर कभी लिखता नहीं है।

## चरण 1: भ्रष्ट DOCX को पुनर्प्राप्त कैसे करें

पहला बाधा फ़ाइल को सुरक्षित रूप से लोड करना है। Aspose.Words एक `RecoveryMode.RECOVER_CORRUPTED` फ़्लैग प्रदान करता है जो टूटे हुए दस्तावेज़ संरचना को पुनर्निर्माण करने का प्रयास करता है।

```python
import aspose.words as aw

# Load the file in recovery mode
load_opts = aw.LoadOptions()
load_opts.recovery_mode = aw.RecoveryMode.RECOVER_CORRUPTED
doc = aw.Document("YOUR_DIRECTORY/input.docx", load_opts)
```

**यह क्यों महत्वपूर्ण है:**  
जब कोई DOCX आंशिक रूप से क्षतिग्रस्त हो—जैसे भाग गायब हों, XML टूटे हों, या संबंध (relationships) विकृत हों—तो सामान्य लोडिंग एक अपवाद (exception) फेंकती है। रिकवरी मोड वह पढ़ सकता है उसे पार्स करता है, अपठनीय भागों को त्याग देता है जबकि शेष को संरक्षित रखता है, जो किसी भी बाद के **export docx to txt** या **save word as pdf** ऑपरेशन के लिए आवश्यक है।

### सामान्य किनारी मामला
यदि दस्तावेज़ मरम्मत से बाहर है, तो भी `doc` बनाया जाएगा लेकिन एक चेतावनी लॉग के साथ। आप `doc.is_dirty` की जाँच कर सकते हैं यह देखने के लिए कि क्या रिकवरी के दौरान कोई सामग्री बदली गई है।

## चरण 2: Aspose.Words के साथ Markdown निर्यात कैसे करें

Markdown एक हल्की मार्कअप भाषा है जिसे कई static‑site जेनरेटर और दस्तावेज़ीकरण टूल पसंद करते हैं। Aspose.Words Markdown उत्पन्न कर सकता है जबकि समीकरणों को LaTeX के रूप में रखता है, जो तकनीकी दस्तावेज़ीकरण के लिए आदर्श है।

```python
# Configure Markdown export options
md_opts = aw.MarkdownSaveOptions()
md_opts.office_math_export_mode = aw.OfficeMathExportMode.LATEX

# Save as Markdown
doc.save("YOUR_DIRECTORY/output.md", md_opts)
```

**आपको क्या मिलेगा:**  
* हेडिंग्स, सूचियों और तालिकाओं को Markdown सिंटैक्स में परिवर्तित किया गया साधारण टेक्स्ट।  
* प्रत्येक Word समीकरण को LaTeX ब्लॉक (`$$ … $$`) के रूप में रेंडर किया गया, जिससे गणित downstream टूल्स में संपादन योग्य बना रहे।

### आउटपुट की जाँच करें
`output.md` को किसी भी एडिटर में खोलें। आपको कुछ इस तरह दिखना चाहिए:

```markdown
# Title of the Document

This is a paragraph with **bold** text.

$$
\int_{0}^{\infty} e^{-x} dx = 1
$$
```

यदि आपको कोई अलग समीकरण फ़ॉर्मेट चाहिए (जैसे, MathML), तो `office_math_export_mode` को उसी अनुसार बदलें।

## चरण 3: समीकरणों को संरक्षित रखते हुए docx को txt में निर्यात करें

Plain‑text फ़ाइलें त्वरित खोज या natural‑language पाइपलाइन में फीड करने के लिए उपयोगी होती हैं। वही `OfficeMathExportMode.LATEX` `.txt` निर्यात के लिए काम करता है, जिससे आपको पढ़ने योग्य LaTeX इनलाइन मिलता है।

```python
txt_opts = aw.TxtSaveOptions()
txt_opts.office_math_export_mode = aw.OfficeMathExportMode.LATEX

doc.save("YOUR_DIRECTORY/output.txt", txt_opts)
```

**क्यों कॉपी‑पेस्ट के बजाय इसका उपयोग करें?**  
मैनुअल कॉपी‑पेस्ट अक्सर छिपे हुए कैरेक्टर्स को हटा देता है और समीकरण की सटीकता खो देता है। यह **export docx to txt** तरीका यह सुनिश्चित करता है कि प्रत्येक समीकरण एक LaTeX स्निपेट के रूप में दिखाई दे, आगे की प्रोसेसिंग के लिए तैयार।

## चरण 4: बेहतर एक्सेसिबिलिटी के लिए इनलाइन शैप्स के साथ Word को PDF में सहेजें

PDF प्रकाशन के लिए de‑facto फ़ॉर्मेट है। जब Word दस्तावेज़ में floating इमेजेज़ या डायग्राम होते हैं, तो कुछ रीडर्स उन्हें सही ढंग से व्याख्या नहीं कर पाते। `export_floating_shapes_as_inline_tag` सेट करने से ये शैप्स इनलाइन बन जाते हैं, जिससे एक्सेसिबिलिटी और लेआउट स्थिरता बेहतर होती है।

```python
pdf_opts = aw.PdfSaveOptions()
pdf_opts.export_floating_shapes_as_inline_tag = True

doc.save("YOUR_DIRECTORY/output.pdf", pdf_opts)
```

**परिणाम:**  
एक PDF जो मूल लेआउट को प्रतिबिंबित करता है, लेकिन सभी शैप्स अब टेक्स्ट फ्लो का हिस्सा हैं। यह स्क्रीन रीडर्स के लिए विशेष रूप से उपयोगी है, क्योंकि वे इनलाइन तत्वों को पढ़ने के क्रम का हिस्सा मानते हैं।

### बड़े दस्तावेज़ों के लिए टिप
यदि आप बैच में PDFs जेनरेट करते हैं, तो अनावश्यक ऑब्जेक्ट निर्माण से बचने के लिए वही `PdfSaveOptions` इंस्टेंस पुन: उपयोग करें।

## चरण 5: अंतिम PDF से पहले शैप की छाया को फाइन‑ट्यून करें

कभी-कभी आपको प्रकाशन से पहले दृश्य विवरण—जैसे लोगो की छाया—समायोजित करनी पड़ती है। नीचे दिया गया उदाहरण पहला शैप प्राप्त करता है, उसकी छाया गुणों को बदलता है, और एक नया PDF सहेजता है।

```python
# Retrieve the first shape in the document
shape = doc.get_child(aw.NodeType.SHAPE, 0, True).as_shape()

# Adjust shadow settings
shape.shadow.blur_radius = 5.0   # Soft blur
shape.shadow.distance = 2.0     # Distance from shape edge
shape.shadow.opacity = 0.6      # 60% opacity

# Save the shadow‑enhanced PDF
doc.save("YOUR_DIRECTORY/shadowed.pdf", pdf_opts)
```

**यह क्या करता है:**  
* `blur_radius` छाया की धुंधलापन नियंत्रित करता है।  
* `distance` छाया को शैप से दूर ले जाता है, जिससे गहराई बनती है।  
* `opacity` छाया को अर्ध‑पारदर्शी बनाता है, जो अक्सर अधिक प्रोफेशनल दिखता है।

आप `get_child` में इंडेक्स बदलकर इस ब्लॉक को किसी भी शैप के लिए दोहरा सकते हैं।

## तेज़ कॉपी‑पेस्ट के लिए पूर्ण स्क्रिप्ट

नीचे वह पूर्ण, चलाने योग्य स्क्रिप्ट है जो सभी चरणों को मिलाती है। `YOUR_DIRECTORY` को उस पथ से बदलें जहाँ आपकी फ़ाइलें स्थित हैं।

```python
import aspose.words as aw

# -------------------------------------------------
# 1️⃣ Recover a possibly corrupted DOCX
# -------------------------------------------------
load_opts = aw.LoadOptions()
load_opts.recovery_mode = aw.RecoveryMode.RECOVER_CORRUPTED
doc = aw.Document("YOUR_DIRECTORY/input.docx", load_opts)

# -------------------------------------------------
# 2️⃣ Export to Markdown (how to export markdown)
# -------------------------------------------------
md_opts = aw.MarkdownSaveOptions()
md_opts.office_math_export_mode = aw.OfficeMathExportMode.LATEX
doc.save("YOUR_DIRECTORY/output.md", md_opts)

# -------------------------------------------------
# 3️⃣ Export to plain text (export docx to txt)
# -------------------------------------------------
txt_opts = aw.TxtSaveOptions()
txt_opts.office_math_export_mode = aw.OfficeMathExportMode.LATEX
doc.save("YOUR_DIRECTORY/output.txt", txt_opts)

# -------------------------------------------------
# 4️⃣ Save as PDF (save word as pdf)
# -------------------------------------------------
pdf_opts = aw.PdfSaveOptions()
pdf_opts.export_floating_shapes_as_inline_tag = True
doc.save("YOUR_DIRECTORY/output.pdf", pdf_opts)

# -------------------------------------------------
# 5️⃣ Adjust first shape's shadow and re‑save PDF
# -------------------------------------------------
shape = doc.get_child(aw.NodeType.SHAPE, 0, True).as_shape()
shape.shadow.blur_radius = 5.0
shape.shadow.distance = 2.0
shape.shadow.opacity = 0.6
doc.save("YOUR_DIRECTORY/shadowed.pdf", pdf_opts)
```

स्क्रिप्ट चलाने पर प्राप्त होता है:

| फ़ाइल | उद्देश्य |
|------|---------|
| `output.md` | LaTeX समीकरणों के साथ Markdown (**how to export markdown**) |
| `output.txt` | Plain‑text संस्करण (**export docx to txt**) |
| `output.pdf` | एक्सेसिबल PDF (**save word as pdf**) |
| `shadowed.pdf` | कस्टम‑स्टाइल्ड शैप वाला PDF |

## अक्सर पूछे जाने वाले प्रश्न

**Q: क्या रिकवरी मोड गायब इमेजेज़ को ठीक करता है?**  
A: यह दस्तावेज़ संरचना को पुनर्स्थापित करता है लेकिन खोए हुए बाइनरी इमेज डेटा को पुनः नहीं बना सकता। यदि कोई इमेज पार्ट गायब है, तो शैप खाली रहेगा।

**Q: क्या मैं Markdown के बजाय HTML में निर्यात कर सकता हूँ?**  
A: हाँ—`aw.HtmlSaveOptions()` का उपयोग करें और आवश्यकतानुसार `office_math_export_mode` सेट करें।

**Q: यदि मुझे फ्लोटिंग शैप्स को फ्लोटिंग ही रखना है तो क्या करें?**  
A: `export_floating_shapes_as_inline_tag` को छोड़ दें या इसे `False` सेट करें।

**Q: क्या LaTeX निर्यात MathJax के साथ संगत है?**  
A: बिल्कुल। MathJax उन `$$ … $$` ब्लॉक्स को रेंडर करता है जो Markdown और Txt निर्यातकों द्वारा उत्पन्न होते हैं।

## निष्कर्ष

अब आप जानते हैं कि संभावित भ्रष्ट DOCX से **how to export markdown** कैसे किया जाए, **export docx to txt** कैसे किया जाए, **save word as pdf** कैसे किया जाए, और Aspose.Words for Python का उपयोग करके **how to recover document** के सटीक चरण क्या हैं। पूर्ण स्क्रिप्ट एक भरोसेमंद वर्कफ़्लो दर्शाती है जो स्वस्थ और क्षतिग्रस्त दोनों Word फ़ाइलों के लिए काम करता है, समीकरणों, शैप्स और दृश्य सटीकता को संरक्षित रखते हुए।

### अगले कदम

* वेब‑केंद्रित पाइपलाइन के लिए `MathML` जैसे अन्य `OfficeMathExportMode` विकल्पों का अन्वेषण करें।  
* इस वर्कफ़्लो को बैच प्रोसेसिंग के साथ मिलाकर पूरे DOCX फ़ोल्डर्स को कनवर्ट करें।  
* यदि आपको अभिलेखीय‑ग्रेड PDFs चाहिए तो `aw.PdfCompliance.PDF_A_1B` को देखें।  

विभिन्न छाया सेटिंग्स, पेज मार्जिन, या यहाँ तक कि Markdown आउटपुट के लिए कस्टम CSS के साथ प्रयोग करने में संकोच न करें। कोडिंग का आनंद लें!

## अगला आप क्या सीखें?
