# Aspose.Words를 사용하여 마크다운 내보내기 및 손상된 DOCX 복구 방법

손상될 수 있는 Word 파일에서 **how to export markdown**이 필요하다면, 이 가이드는 정확한 단계들을 보여줍니다. 또한 **how to recover document** 문제, **export docx to txt**, 그리고 Aspose.Words for Python API를 사용한 **save word as pdf**에 대해서도 다룹니다.

복구 모드에서 손상될 가능성이 있는 DOCX를 로드하고, 수식을 보존하면서 Markdown으로 변환하고, 동일한 내용을 일반 텍스트로 저장하고, 접근성 PDF를 생성하며, 최종 내보내기 전에 도형의 그림자를 조정하는 과정을 단계별로 진행합니다. 외부 도구는 필요 없으며, Aspose.Words와 몇 줄의 Python 코드만 있으면 됩니다.

## 사전 요구 사항

* Python 3.8 이상
* `aspose-words` 패키지 (`pip install aspose-words`)
* 손상될 수 있는 DOCX 파일 (또는 테스트용 일반 DOCX)
* Python 함수와 클래스에 대한 기본 지식

> **Pro tip:** 원본 DOCX의 백업을 보관하세요; 복구 모드는 메모리상의 표현을 수정하지만 원본 파일에 다시 쓰지는 않습니다.

## 단계 1: 손상된 DOCX 복구 방법

첫 번째 난관은 파일을 안전하게 로드하는 것입니다. Aspose.Words는 손상된 문서 구조를 복구하려는 `RecoveryMode.RECOVER_CORRUPTED` 플래그를 제공합니다.

```python
import aspose.words as aw

# Load the file in recovery mode
load_opts = aw.LoadOptions()
load_opts.recovery_mode = aw.RecoveryMode.RECOVER_CORRUPTED
doc = aw.Document("YOUR_DIRECTORY/input.docx", load_opts)
```

**왜 이것이 중요한가:**  
DOCX가 부분적으로 손상되면—예를 들어 일부가 누락되었거나, XML이 깨졌거나, 관계가 잘못된 경우—표준 로딩은 예외를 발생시킵니다. 복구 모드는 가능한 부분을 파싱하고 읽을 수 없는 조각을 버리면서 나머지를 보존합니다. 이는 이후의 **export docx to txt** 또는 **save word as pdf** 작업에 필수적입니다.

### 일반적인 예외 상황
문서가 복구 불가능할 정도로 손상된 경우에도 `doc`은 경고 로그와 함께 생성됩니다. 복구 중에 내용이 변경되었는지 확인하려면 `doc.is_dirty`를 검사할 수 있습니다.

## 단계 2: Aspose.Words를 사용하여 마크다운 내보내기

Markdown은 많은 정적 사이트 생성기와 문서 도구가 선호하는 가벼운 마크업 언어입니다. Aspose.Words는 수식을 LaTeX 형태로 유지하면서 Markdown을 출력할 수 있어 기술 문서에 최적입니다.

```python
# Configure Markdown export options
md_opts = aw.MarkdownSaveOptions()
md_opts.office_math_export_mode = aw.OfficeMathExportMode.LATEX

# Save as Markdown
doc.save("YOUR_DIRECTORY/output.md", md_opts)
```

**얻는 결과:**  
* 헤딩, 리스트, 테이블이 Markdown 구문으로 변환된 일반 텍스트.  
* 모든 Word 수식이 LaTeX 블록(`$$ … $$`)으로 렌더링되어, 이후 도구에서도 수식을 편집 가능하게 유지합니다.

### 출력 확인
`output.md`를 편집기에서 열어보세요. 다음과 같은 내용이 표시될 것입니다:

```markdown
# Title of the Document

This is a paragraph with **bold** text.

$$
\int_{0}^{\infty} e^{-x} dx = 1
$$
```

다른 수식 형식(예: MathML)이 필요하면 `office_math_export_mode`를 적절히 변경하세요.

## 단계 3: 수식을 보존하면서 docx를 txt로 내보내기

일반 텍스트 파일은 빠른 검색이나 자연어 파이프라인에 입력하기에 유용합니다. 동일한 `OfficeMathExportMode.LATEX`를 사용하면 `.txt` 내보내기에서도 읽기 쉬운 LaTeX 인라인을 얻을 수 있습니다.

```python
txt_opts = aw.TxtSaveOptions()
txt_opts.office_math_export_mode = aw.OfficeMathExportMode.LATEX

doc.save("YOUR_DIRECTORY/output.txt", txt_opts)
```

**복사‑붙여넣기 대신 이 방법을 사용하는 이유:**  
수동 복사‑붙여넣기는 종종 숨겨진 문자들을 제거하고 수식의 정확성을 잃게 됩니다. 이 **export docx to txt** 접근 방식은 모든 수식이 LaTeX 스니펫으로 나타나도록 보장하여 추가 처리에 바로 사용할 수 있게 합니다.

## 단계 4: 접근성을 높이기 위해 인라인 도형을 포함하여 Word를 PDF로 저장

PDF는 출판을 위한 사실상의 표준 형식입니다. Word 문서에 떠 있는 이미지나 다이어그램이 포함된 경우, 일부 리더가 이를 올바르게 해석하지 못할 수 있습니다. `export_floating_shapes_as_inline_tag`를 설정하면 이러한 도형을 인라인으로 강제 전환하여 접근성과 레이아웃 일관성을 향상시킵니다.

```python
pdf_opts = aw.PdfSaveOptions()
pdf_opts.export_floating_shapes_as_inline_tag = True

doc.save("YOUR_DIRECTORY/output.pdf", pdf_opts)
```

**결과:**  
원본 레이아웃을 그대로 유지하지만, 모든 도형이 이제 텍스트 흐름의 일부가 된 PDF입니다. 이는 스크린 리더가 인라인 요소를 읽기 순서의 일부로 처리하기 때문에 특히 유용합니다.

### 대용량 문서 팁
배치로 PDF를 생성할 경우, 불필요한 객체 생성을 방지하기 위해 동일한 `PdfSaveOptions` 인스턴스를 재사용하세요.

## 단계 5: 최종 PDF 전에 도형 그림자 미세 조정

출판 전에 로고 그림자와 같은 시각적 세부 사항을 조정해야 할 때가 있습니다. 아래 예제는 첫 번째 도형을 가져와 그림자 속성을 수정하고 새 PDF로 저장합니다.

```python
# Retrieve the first shape in the document
shape = doc.get_child(aw.NodeType.SHAPE, 0, True).as_shape()

# Adjust shadow settings
shape.shadow.blur_radius = 5.0   # Soft blur
shape.shadow.distance = 2.0     # Distance from shape edge
shape.shadow.opacity = 0.6      # 60% opacity

# Save the shadow‑enhanced PDF
doc.save("YOUR_DIRECTORY/shadowed.pdf", pdf_opts)
```

**이 코드가 하는 일:**  
* `blur_radius`는 그림자의 흐림 정도를 제어합니다.  
* `distance`는 그림자를 도형에서 떨어뜨려 깊이를 만듭니다.  
* `opacity`는 그림자를 반투명하게 만들어 보다 전문적인 느낌을 줍니다.

`get_child`의 인덱스를 변경하면 이 블록을 다른 도형에도 반복 적용할 수 있습니다.

## 전체 스크립트 (빠른 복사‑붙여넣기용)

아래는 모든 단계를 결합한 완전한 실행 가능한 스크립트입니다. `YOUR_DIRECTORY`를 파일이 위치한 경로로 교체하세요.

```python
import aspose.words as aw

# -------------------------------------------------
# 1️⃣ Recover a possibly corrupted DOCX
# -------------------------------------------------
load_opts = aw.LoadOptions()
load_opts.recovery_mode = aw.RecoveryMode.RECOVER_CORRUPTED
doc = aw.Document("YOUR_DIRECTORY/input.docx", load_opts)

# -------------------------------------------------
# 2️⃣ Export to Markdown (how to export markdown)
# -------------------------------------------------
md_opts = aw.MarkdownSaveOptions()
md_opts.office_math_export_mode = aw.OfficeMathExportMode.LATEX
doc.save("YOUR_DIRECTORY/output.md", md_opts)

# -------------------------------------------------
# 3️⃣ Export to plain text (export docx to txt)
# -------------------------------------------------
txt_opts = aw.TxtSaveOptions()
txt_opts.office_math_export_mode = aw.OfficeMathExportMode.LATEX
doc.save("YOUR_DIRECTORY/output.txt", txt_opts)

# -------------------------------------------------
# 4️⃣ Save as PDF (save word as pdf)
# -------------------------------------------------
pdf_opts = aw.PdfSaveOptions()
pdf_opts.export_floating_shapes_as_inline_tag = True
doc.save("YOUR_DIRECTORY/output.pdf", pdf_opts)

# -------------------------------------------------
# 5️⃣ Adjust first shape's shadow and re‑save PDF
# -------------------------------------------------
shape = doc.get_child(aw.NodeType.SHAPE, 0, True).as_shape()
shape.shadow.blur_radius = 5.0
shape.shadow.distance = 2.0
shape.shadow.opacity = 0.6
doc.save("YOUR_DIRECTORY/shadowed.pdf", pdf_opts)
```

스크립트를 실행하면 다음과 같은 파일이 생성됩니다:

| 파일 | 목적 |
|------|---------|
| `output.md` | LaTeX 수식이 포함된 Markdown (**how to export markdown**) |
| `output.txt` | 일반 텍스트 버전 (**export docx to txt**) |
| `output.pdf` | 접근성 PDF (**save word as pdf**) |
| `shadowed.pdf` | 맞춤 스타일 도형이 포함된 PDF |

## 자주 묻는 질문

**Q: 복구 모드가 누락된 이미지를 복구합니까?**  
A: 문서 구조는 복원하지만 손실된 바이너리 이미지 데이터는 재생성할 수 없습니다. 이미지 파트가 없으면 도형은 비어 있게 됩니다.

**Q: Markdown 대신 HTML로 내보낼 수 있나요?**  
A: 예—`aw.HtmlSaveOptions()`를 사용하고 필요에 따라 `office_math_export_mode`를 설정하면 됩니다.

**Q: 떠 있는 도형을 그대로 유지하려면 어떻게 해야 하나요?**  
A: `export_floating_shapes_as_inline_tag`를 생략하거나 `False`로 설정하면 됩니다.

**Q: LaTeX 내보내기가 MathJax와 호환되나요?**  
A: 전혀 문제 없습니다. MathJax는 Markdown 및 Txt 내보내기에서 생성된 `$$ … $$` 블록을 렌더링합니다.
