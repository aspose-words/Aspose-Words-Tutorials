# Create invoice template and merge data using Aspose.Words

청구서 템플릿을 **빠르게 만들고 싶다면**, 이 가이드는 정확한 방법을 보여줍니다. 처음 두 문장을 읽고 나면 Aspose.Words의 로우‑코드 메일‑머지 API를 사용해 빈 Word 파일을 완전한 청구서로 변환하는 전체 워크플로우를 알 수 있습니다.

청구서 생성은 청구 시스템, ERP 연동, 자동 보고서 등에서 흔히 요구되는 기능입니다. 이 튜토리얼에서는 **메일 머지 방법**, **워드 템플릿 채우기**, **워드에 데이터 병합**, 그리고 최종 **병합된 문서 저장**을 C# 몇 줄만으로 수행하는 방법을 배웁니다.

## What you’ll achieve

* 재사용 가능한 Word 템플릿(`InvoiceTemplate.docx`) – 고객, 날짜, 항목, 총액을 위한 병합 필드 포함  
* 템플릿을 로드하고 강타입 데이터 객체를 주입한 뒤 `Invoice_001.docx` 로 저장하는 C# 프로그램  
* 빈 컬렉션, 사용자 정의 데이터 타입, 파일 경로 처리와 같은 엣지 케이스에 대한 인사이트

### Prerequisites

| Requirement | Why it matters |
|-------------|----------------|
| .NET 6 or later | Aspose.Words for .NET은 .NET 6+를 지원하며 이 가이드에서 사용하는 로우‑코드 API를 제공합니다. |
| Aspose.Words for .NET NuGet package (`Aspose.Words`) | `Document`, `MailMerger` 및 관련 타입을 제공합니다. |
| Basic C# knowledge | 익명 객체와 LINQ를 이해하는 데 필요합니다. |
| Visual Studio 2022 (or any IDE) | 편집 및 디버깅을 간편하게 해줍니다. |

> **Pro tip:** 패키지 매니저 콘솔을 통해 NuGet 패키지를 설치하세요:  
> `Install-Package Aspose.Words`

## How to create invoice template with low‑code mail merge

첫 번째 단계는 나중에 전달할 데이터 객체의 속성과 일치하는 병합 필드를 포함한 Word 파일을 만드는 것입니다. 파일을 `InvoiceTemplate.docx` 라는 이름으로, 예: `C:\Invoices\Template` 와 같은 직접 관리하는 폴더에 저장합니다.

| Merge field | Example placeholder in Word |
|-------------|-----------------------------|
| CustomerName | «CustomerName» |
| InvoiceDate | «InvoiceDate» |
| Items (repeating) | «Items.Description», «Items.Qty», «Items.Price» |
| Total | «Total» |

> **Why this matters:** 로우‑코드 API는 데이터 소스의 속성 이름을 병합 필드에 자동으로 매핑합니다. 이름을 동일하게 유지하면 수동 매핑이 필요 없으며 런타임 오류를 줄일 수 있습니다.

## Step 1: Load the invoice template

```csharp
using Aspose.Words;
using Aspose.Words.LowCode;   // Low‑code mail‑merge API

// Load the Word file that contains the merge fields.
Document template = new Document(@"C:\Invoices\Template\InvoiceTemplate.docx");
```

*`Document` 클래스는 전체 Word 파일을 나타냅니다. 한 번 로드하면 여러 청구서에 동일한 템플릿을 재사용할 수 있습니다.*

## Step 2: Prepare the data source

병합 필드와 구조가 동일한 익명 객체를 생성합니다. 로우‑코드 API는 배열 및 중첩 컬렉션을 포함한 모든 .NET 객체와 함께 사용할 수 있습니다.

```csharp
var invoiceData = new
{
    CustomerName = "Acme Corp",
    InvoiceDate = DateTime.Today,
    Items = new[]
    {
        new { Description = "Widget A", Qty = 10, Price = 9.99M },
        new { Description = "Widget B", Qty = 5,  Price = 19.95M }
    },
    Total = 199.85M
};
```

**Why this works:**  
* 속성 이름(`CustomerName`, `InvoiceDate`, `Items`, `Total`)이 템플릿의 병합 필드와 일치합니다.  
* `Items`는 객체 배열이므로 메일 머지는 각 요소마다 테이블 행을 자동으로 반복합니다.  
* 금액에 `decimal`(`M` 접미사) 사용은 부동소수점 반올림 문제를 방지합니다.

### Handling empty collections

청구서에 라인 아이템이 없을 경우 빈 배열을 전달합니다:

```csharp
Items = new object[0]
```

로우‑코드 엔진은 반복 섹션을 생략하고 테이블 헤더만 남깁니다.

## Step 3: Initialise the low‑code mail merger

```csharp
MailMerger merger = new MailMerger(template);
```

`MailMerger`는 Aspose.Words와 **메일 머지**를 수행하는 진입점입니다. 템플릿을 읽고 데이터를 바인딩하며 최종 문서를 한 번에 준비합니다.

## Step 4: Execute the merge – populate word template in one line

```csharp
Document mergedDocument = merger.Execute(invoiceData);
```

* 이 한 줄은 **워드 템플릿을 채우고** 새로운 `Document` 인스턴스(`mergedDocument`)를 생성합니다.  
* 모든 병합 필드가 교체되고, 반복 섹션이 확장되며, 결과 문서는 메모리 상에 완전히 존재합니다.

### Edge case: Custom formatting

특정 날짜 형식이 필요하면 병합 전에 사용자 정의 포맷터를 추가합니다:

```csharp
merger.Options.DateFormat = "MMMM dd, yyyy"; // e.g., "October 07, 2026"
```

## Step 5: Save merged document

```csharp
mergedDocument.Save(@"C:\Invoices\Output\Invoice_001.docx");
```

**save merged document** 호출은 완전히 채워진 청구서를 디스크에 기록합니다. 이제 파일을 Microsoft Word에서 열거나 이메일 첨부 파일로 보내거나 PDF로 변환할 수 있습니다.

### Verifying the output

`Invoice_001.docx` 를 열어 다음과 같이 표시되는지 확인합니다:

* **CustomerName** 이 *Acme Corp* 로 교체됨  
* **InvoiceDate** 가 선택한 형식의 오늘 날짜 표시  
* *Widget A* (10 × 9.99)와 *Widget B* (5 × 19.95) 행이 포함된 테이블  
* **Total** 이 *199.85* 로 표시  

필드가 그대로 남아 있다면(예: «CustomerName» 표시) 속성 이름이 템플릿의 병합 필드 이름과 정확히 일치하는지 다시 확인하세요.

## Full runnable example

아래는 새 콘솔 프로젝트에 복사‑붙여넣기 할 수 있는 전체 프로그램입니다.

```csharp
using System;
using Aspose.Words;
using Aspose.Words.LowCode;   // Low‑code mail‑merge API

namespace InvoiceGenerator
{
    class Program
    {
        static void Main()
        {
            // 1️⃣ Load the template
            Document template = new Document(@"C:\Invoices\Template\InvoiceTemplate.docx");

            // 2️⃣ Build the data source
            var invoiceData = new
            {
                CustomerName = "Acme Corp",
                InvoiceDate = DateTime.Today,
                Items = new[]
                {
                    new { Description = "Widget A", Qty = 10, Price = 9.99M },
                    new { Description = "Widget B", Qty = 5,  Price = 19.95M }
                },
                Total = 199.85M
            };

            // 3️⃣ Initialise the mail merger
            MailMerger merger = new MailMerger(template);

            // Optional: customise date format
            merger.Options.DateFormat = "MMMM dd, yyyy";

            // 4️⃣ Perform the merge (populate word template)
            Document mergedDocument = merger.Execute(invoiceData);

            // 5️⃣ Save the resulting file (save merged document)
            mergedDocument.Save(@"C:\Invoices\Output\Invoice_001.docx");

            Console.WriteLine("Invoice generated successfully.");
        }
    }
}
```

프로그램을 실행(`dotnet run`)하면 콘솔에 *Invoice generated successfully.* 가 출력되고 파일이 `C:\Invoices\Output` 에 생성됩니다.

## Common questions and troubleshooting

| Question | Answer |
|----------|--------|
| **What if my template uses different field delimiters?** | Aspose.Words는 기본적으로 « » 구분자를 사용합니다. `MailMerger.Options.FieldStartDelimiter` 및 `FieldEndDelimiter` 를 통해 변경할 수 있습니다. |
| **How do I merge a large collection efficiently?** | 데이터 컬렉션을 청크 단위로 나누어 순차적으로 머지하거나, `MailMerge.ExecuteWithRegions` 를 사용해 메모리 사용량을 최소화하세요. |
| **Can I merge images or binary data?** | 예, `MailMerger.ExecuteImageField` 를 사용해 이미지 필드를 병합하거나, `DocumentBuilder` 로 바이너리 데이터를 삽입할 수 있습니다. |
| **What happens if a merge field is missing in the data source?** | 해당 필드는 원본 템플릿에 남아 있게 되며, `MailMerge.CleanupOptions` 로 비어 있는 필드를 자동 제거하도록 설정할 수 있습니다. |
