# Aspose.Words C# 로 차트에 백분율 표시하기

복잡한 Office Interop 없이 **차트에 백분율을 표시하는 방법**을 궁금해 본 적 있나요? 혼자가 아닙니다—많은 개발자들이 파이 차트나 도넛 차트에 빠르게 프로그래밍 방식으로 레이블을 붙여야 할 때 이 문제에 부딪히곤 합니다. 좋은 소식은? Aspose.Words for .NET을 사용하면 몇 줄의 코드만으로 데이터 레이블을 활성화할 수 있습니다.

이 튜토리얼에서는 **파이 차트에 데이터 레이블 추가**와 **차트 데이터 레이블 활성화** 방법도 다루어 시각화가 즉시 더 통찰력 있게 됩니다. 마지막에는 백분율이 각 조각 외부에 깔끔하게 배치된 완성된 Word 문서(`.docx`)를 얻게 됩니다.

## 전제 조건

시작하기 전에 다음이 준비되어 있는지 확인하세요:

- **Aspose.Words for .NET**(최신 버전, 예: 24.9)를 NuGet을 통해 설치.
- 파이 차트 또는 도넛 차트가 이미 포함된 **ChartTemplate.docx** 파일.  
  *(없다면 간단한 Word 문서를 만들고 파이 차트를 삽입한 뒤 `ChartTemplate.docx`로 저장하세요.)*
- .NET 6.0 이상 및 선호하는 IDE(Visual Studio, Rider, VS Code 등).

추가 종속성은 필요하지 않습니다—Aspose.Words가 내부적으로 모든 작업을 처리합니다.

## 차트에 백분율 표시하기 – 단계별 가이드

아래에서는 전체 과정을 6개의 명확한 단계로 나눕니다. 각 단계마다 복사‑붙여넣기 가능한 정확한 C# 코드와 **왜** 해당 작업을 수행하는지에 대한 짧은 설명을 제공합니다.

### Step 1: Load the Source Document

```csharp
using Aspose.Words;
using Aspose.Words.Drawing.Charts;

// Load the .docx that already holds a chart.
Document sourceDoc = new Document("YOUR_DIRECTORY/ChartTemplate.docx");
```

*Why?*  
`Document`는 Word 조작의 진입점입니다. 템플릿을 로드하면 모든 노드(도형, 표, 텍스트, 그리고 수정할 차트)에 접근할 수 있습니다.

### Step 2: Grab the First Chart Shape

```csharp
// The chart lives inside a Shape node; retrieve it.
Chart chart = (Chart)sourceDoc.GetChild(NodeType.Shape, 0, true);
```

*Why?*  
Aspose는 차트를 `Shape` 객체로 저장합니다. `GetChild`는 문서 트리를 순회하며 첫 번째 도형을 반환하는데, 여기서는 편집하려는 파이 차트가 됩니다.

### Step 3: Confirm the Chart Type

```csharp
if (chart.ChartType == ChartType.Pie || chart.ChartType == ChartType.Doughnut)
{
    // Inside this block we’ll enable the data labels.
}
else
{
    throw new InvalidOperationException("The chart is not a Pie or Doughnut type.");
}
```

*Why?*  
백분율 레이블은 원형 차트에서만 의미가 있습니다. 이 검사는 바 차트와 같이 `ShowPercentage`가 무시되는 경우에 설정이 적용되는 것을 방지합니다.

### Step 4: Enable Data Labels and Show Percentages

```csharp
// Turn on data labels for the chart.
chart.HasDataLabel = true;

// Show the percentage value for each slice.
chart.DataLabel.ShowPercentage = true;
```

*Why?*  
`HasDataLabel`은 각 데이터 포인트에 레이블을 렌더링하도록 Aspose에 지시합니다. `ShowPercentage`를 설정하면 레이블 내용이 전체 대비 계산된 비율이 되며, 이는 **파이 차트에 데이터 레이블 추가** 요구사항을 정확히 만족합니다.

### Step 5: Position Labels Outside the Slices

```csharp
// Place the labels outside the pie slices for better readability.
chart.DataLabel.Position = ChartDataLabelPosition.OutSideEnd;
```

*Why?*  
조각 내부에 레이블을 배치하면 특히 작은 조각일 때 공간이 부족해집니다. `OutSideEnd`는 Word UI에서 보는 기본 “외부” 스타일을 모방해 차트를 깔끔하게 유지합니다.

### Step 6: Save the Updated Document

```csharp
sourceDoc.Save("YOUR_DIRECTORY/FormattedPieChart.docx");
```

*Why?*  
저장은 모든 변경 사항을 새 파일에 기록합니다. `FormattedPieChart.docx`를 Word에서 열면 각 조각 옆에 백분율이 표시된 것을 확인할 수 있습니다.

#### Expected Result

`FormattedPieChart.docx`를 열면 파이 차트가 다음과 유사하게 표시됩니다(가상의 스크린샷):

```
[ Pie chart with three slices ]
- Slice A – 45%
- Slice B – 30%
- Slice C – 25%
```

모든 백분율은 기본 데이터 시리즈에서 자동으로 계산되며, 레이블은 각 조각 바로 외부에 배치됩니다.

## 일반적인 변형 및 예외 상황

| 상황 | 조정 방법 |
|-----------|----------------|
| **여러 차트**가 동일 문서에 존재하는 경우 | `sourceDoc.GetChildNodes(NodeType.Shape, true)`를 순회하면서 각 `Shape`을 `Chart`로 캐스팅한 뒤 동일 로직을 적용합니다. |
| **막대형 또는 꺾은선형 차트**에서 레이블이 필요한 경우 | `ShowPercentage` 대신 `chart.DataLabel.ShowValue = true;`(또는 `ShowSeriesName`)를 사용합니다. |
| **사용자 정의 숫자 형식**(예: “45 %”) | 저장하기 전에 `chart.DataLabel.NumberFormat = "0%";`를 설정합니다. |
| **대용량 데이터 세트**로 레이블이 겹치는 경우 | `chart.DataLabel.ShowLeaderLines = true;`를 사용해 연결선을 그립니다. |

> **Pro tip:** 배치로 많은 문서를 생성한다면 애플리케이션 시작 시 `Aspose.Words.License` 객체를 한 번만 인스턴스화하여 라이선스를 반복 로드하는 성능 저하를 방지하세요.

## 전체 작업 예제

전체 프로그램을 한 번에 모아 실행 가능한 형태로 정리했습니다:

```csharp
using System;
using Aspose.Words;
using Aspose.Words.Drawing.Charts;

class Program
{
    static void Main()
    {
        // 1️⃣ Load the template document.
        Document sourceDoc = new Document("YOUR_DIRECTORY/ChartTemplate.docx");

        // 2️⃣ Retrieve the first chart shape.
        Chart chart = (Chart)sourceDoc.GetChild(NodeType.Shape, 0, true);

        // 3️⃣ Ensure we’re dealing with a Pie or Doughnut chart.
        if (chart.ChartType != ChartType.Pie && chart.ChartType != ChartType.Doughnut)
        {
            Console.WriteLine("The selected shape is not a Pie/Doughnut chart.");
            return;
        }

        // 4️⃣ Enable data labels and show percentages.
        chart.HasDataLabel = true;
        chart.DataLabel.ShowPercentage = true;

        // 5️⃣ Position the labels outside the slices.
        chart.DataLabel.Position = ChartDataLabelPosition.OutSideEnd;

        // 6️⃣ Save the modified document.
        sourceDoc.Save("YOUR_DIRECTORY/FormattedPieChart.docx");

        Console.WriteLine("Chart updated successfully – percentages now visible!");
    }
}
```

코드를 복사하고 `YOUR_DIRECTORY`를 실제 경로로 바꾼 뒤 실행하세요. 몇 초 만에 완전 레이블이 붙은 파이 차트가 포함된 Word 파일을 얻을 수 있습니다.

3. 파이/도넛 차트인지 확인
4. **파이 차트에 데이터 레이블 추가** 및 백분율 활성화
5. 레이블을 조각 외부에 배치
6. 결과 저장

이 지식을 통해 명확한 백분율 기반 시각화가 필요한 모든 보고 시나리오를 자동화할 수 있습니다.
