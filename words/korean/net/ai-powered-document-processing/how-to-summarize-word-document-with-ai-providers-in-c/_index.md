# C#에서 AI 제공자를 사용해 Word 문서 요약하기

Word 문서를 **빠르게 요약**해야 할 때, 이 가이드는 정확히 어떻게 하는지 보여줍니다. **AI 제공자**(OpenAI 또는 Google)를 **선택**하고 IDE를 떠나지 않고 **대용량 문서 요약** 시나리오를 처리하는 완전한 실행 예제를 확인할 수 있습니다.

Word 문서 요약은 지식‑베이스 봇, 보고서 요약, 자동 이메일 브리핑 등을 구축할 때 흔히 필요한 작업입니다. 아래 섹션에서는 어떤 NuGet 패키지를 설치하고, `.docx` 파일을 로드하며, 요약기를 구성하고, 결과를 출력하는 방법을 모두 순수 C#으로 배웁니다.

## 준비 사항

| 요구 사항 | 이유 |
|-------------|--------|
| .NET 6 SDK 이상 | C# 예제 실행을 위한 런타임 제공 |
| Visual Studio 2022(또는 기타 IDE) | NuGet 패키지를 쉽게 추가하고 콘솔 앱을 실행할 수 있음 |
| `GroupDocs.Summarization` NuGet 패키지 | 코드에서 사용하는 `DocumentSummarizer` API 제공 |
| 인터넷 연결 | AI 제공자(OpenAI 또는 Google)가 텍스트를 처리하는 데 필요 |

> **프로 팁:** **대용량 문서 요약** 파일(100 KB 이상)을 처리할 경우, 옵션에서 스트리밍 모드를 활성화하면 전체 파일을 메모리에 로드하지 않아도 됩니다.

## Word 문서 요약 단계별 가이드

### 단계 1: 요약 라이브러리 설치

패키지 관리자 콘솔을 열고 다음을 실행합니다:

```powershell
Install-Package GroupDocs.Summarization
```

`GroupDocs.Summarization` 라이브러리는 기본 AI 호출을 추상화하므로 비즈니스 로직을 변경하지 않고도 제공자를 전환할 수 있습니다.

### 단계 2: Word 문서 로드

```csharp
using GroupDocs.Summarization;
using GroupDocs.Summarization.Options;

// Step 2: Load the source document
Document doc = new Document("YOUR_DIRECTORY/Report.docx");
```

`Document` 클래스가 `.docx` 파일을 읽어 요약 준비를 합니다. 파일이 크면 라이브러리가 자동으로 메모리 효율적인 파서를 사용합니다.

### 단계 3: 요약 옵션 구성 및 **AI 제공자 선택**

```csharp
// Step 3: Set up summarization options (choose the AI provider)
SummarizerOptions options = new SummarizerOptions
{
    Provider = SummarizerProvider.OpenAI   // or SummarizerProvider.Google
};
```

- `Provider = SummarizerProvider.OpenAI`는 OpenAI의 GPT‑4 모델을 선택합니다.  
- `Provider = SummarizerProvider.Google`는 Google의 Gemini 모델을 선택하는데, 이는 **Google로 요약**할 때 다국어 지원이 뛰어나기 때문입니다.

비용, 지연 시간, 언어 요구 사항에 따라 **AI 제공자를 선택**합니다. 동일한 `options` 객체가 두 제공자 모두에서 작동하므로 코드가 깔끔합니다.

### 단계 4: 요약 생성 – **대용량 문서 요약** 지원

```csharp
// Step 4: Generate the summary using the selected provider
string summary = DocumentSummarizer.Summarize(doc, options);
```

**대용량 문서 요약** 파일을 처리할 때 라이브러리는 콘텐츠를 AI 서비스에 스트리밍하여 메모리 초과 오류를 방지합니다. `Summarize` 메서드는 가장 관련성 높은 문장을 포함한 일반 텍스트 문자열을 반환합니다.

### 단계 5: 결과 출력

```csharp
// Step 5: Output the generated summary
Console.WriteLine("Summary:\n" + summary);
```

프로그램을 실행하면 원본 Word 파일의 핵심을 포착한 간결한 단락이 출력됩니다.

## 전체 실행 예제

```csharp
using System;
using GroupDocs.Summarization;
using GroupDocs.Summarization.Options;

namespace WordSummarizerDemo
{
    class Program
    {
        static void Main(string[] args)
        {
            // Load the source Word document
            Document doc = new Document("YOUR_DIRECTORY/Report.docx");

            // Choose the AI provider (OpenAI or Google)
            SummarizerOptions options = new SummarizerOptions
            {
                Provider = SummarizerProvider.Google   // Change to OpenAI if you prefer
            };

            // Generate the summary – works for both small and large documents
            string summary = DocumentSummarizer.Summarize(doc, options);

            // Display the summary in the console
            Console.WriteLine("Summary:\n" + summary);
        }
    }
}
```

**예상 출력**

```
Summary:
The quarterly sales increased by 12% driven by the new product line, while operational costs fell 3% due to efficiency gains. The report also highlights upcoming market expansion in APAC and recommends allocating additional budget to R&D.
```

정확한 문구는 **AI 제공자를 선택**한 모델에 따라 달라지지만 구조는 동일합니다.

## **대용량 문서 요약** 시나리오 처리

소스 `.docx` 파일이 5 MB를 초과할 경우 다음과 같은 조정을 고려하세요:

1. **청크 활성화** – 라이브러리가 문서를 5 KB 블록으로 나눈 뒤 AI 서비스에 전송합니다.  
2. 요약이 더 길어야 하면 `SummarizerOptions`의 `MaxSentences`를 늘립니다.  
3. 처리 시간이 길어질 수 있으니 `Timeout`을 더 높은 값으로 설정합니다.

```csharp
options.MaxSentences = 8;          // Return up to 8 sentences
options.EnableChunking = true;    // Essential for very large files
options.Timeout = TimeSpan.FromMinutes(2);
```

이러한 조정으로 **대용량 문서 요약** 작업이 빠르고 안정적으로 유지됩니다.

## **Google로 요약**을 효과적으로 수행하는 방법

Google의 Gemini 모델은 다국어 콘텐츠와 간결한 표현에 강점이 있습니다. 최적의 결과를 얻으려면:

- 문서에 비영어 텍스트가 포함된 경우 **언어 지정**(선택 사항):
  ```csharp
  options.Language = "es"; // Spanish
  ```
- 창의성을 제어하려면 **temperature**를 조정:
  ```csharp
  options.Temperature = 0.3; // More deterministic output
  ```

**Google로 요약**하면 OpenAI에 비해 약간 짧지만 매우 집중된 요약을 반환할 수 있습니다. 샘플 문서로 두 제공자를 테스트해 어느 쪽이 제품에 적합한지 판단하세요.

## 흔히 발생하는 문제와 해결 방법

| 증상 | 원인 | 해결책 |
|---------|-------|-----|
| 요약이 비어 있음 | 제공자 키 누락 또는 네트워크 차단 | 환경 변수에 API 키를 확인하고 외부 HTTPS가 허용되는지 확인 |
| 텍스트가 잘림 | 문서가 제공자 토큰 제한 초과 | `EnableChunking`을 활성화하거나 라이브러리가 지원한다면 `MaxTokens`를 늘림 |
| 예상치 못한 언어 | 잘못된 `Language` 옵션 | 옵션을 제거하거나 문서 실제 언어로 설정 |

초기에 이러한 문제를 해결하면 **AI 제공자를 선택**하여 프로덕션 워크로드를 운영할 때 디버깅 시간을 크게 절감할 수 있습니다.

## 결론

이제 C#에서 유연한 AI 레이어를 활용해 **Word 문서 요약**하는 방법을 알게 되었습니다. `SummarizerOptions`를 구성하면 **AI 제공자를 선택**하고, **대용량 문서 요약** 작업을 처리하며, 필요에 따라 **Google로 요약**해 다국어 요구도 충족할 수 있습니다. `MaxSentences`, `Temperature`, 청크 설정을 실험해 특정 시나리오에 맞게 출력을 미세 조정해 보세요.
