# C#에서 빈 Word 문서를 만들고 타원 모양을 숨기기

빈 Word 문서를 **빈 Word 문서를 만들기**하고 그래픽 요소를 숨겨야 한다면, 이 가이드는 C#으로 정확히 수행하는 방법을 보여줍니다. 타원을 삽입하고, 위치를 지정하고, 숨김으로 표시한 뒤 파일을 저장하는 완전한 실행 가능한 예제를 몇 줄의 코드로 확인할 수 있습니다.

이 튜토리얼은 프로젝트 설정부터 최종 검증 단계까지 모든 과정을 다룹니다. 끝까지 따라오면 화면이나 인쇄물에 타원이 전혀 나타나지 않는 Word 파일을 생성할 수 있으며, 이는 메타데이터, 북마크 또는 보이지 않는 마커를 저장하는 데 유용합니다.

## Prerequisites

시작하기 전에 다음이 설치되어 있는지 확인하세요:

* .NET 6.0 SDK 또는 그 이후 버전 설치  
* C# 개발 환경 (Visual Studio 2022, Rider, 또는 VS Code)  
* **Aspose.Words for .NET** NuGet 패키지 (`Install-Package Aspose.Words`)  

이 도구들은 코드 샘플에서 사용되는 `Document`와 `DocumentBuilder` 클래스를 제공합니다.

## 1단계: 빈 Word 문서 만들기

첫 번째 작업은 빈 `Document` 객체와 콘텐츠를 추가할 수 있는 `DocumentBuilder`를 생성합니다.

```csharp
using Aspose.Words;
using Aspose.Words.Drawing;

// Step 1: Initialize an empty document and a builder
Document doc = new Document();
DocumentBuilder builder = new DocumentBuilder(doc);
```

`Document`는 전체 `.docx` 패키지를 나타내고, `DocumentBuilder`는 텍스트, 도형 및 기타 객체를 삽입하기 위한 fluent API를 제공합니다. 빈 문서에서 시작하면 추가하는 모든 요소를 완전히 제어할 수 있습니다.

## 2단계: 타원 삽입 방법

타원은 마커로 사용할 수 있는 벡터 도형입니다. `InsertShape` 메서드는 도형 유형과 너비/높이를 포인트 단위로 지정해야 합니다.

```csharp
// Step 2: Insert an ellipse shape of the desired size (100 pt × 50 pt)
Shape ellipse = builder.InsertShape(ShapeType.Ellipse, 100, 50);
```

타원은 커서 위치에 현재 페이지에 배치됩니다. 숫자 인수를 조정하여 크기를 변경할 수 있습니다.

## 3단계: 도형 위치 지정 방법

삽입 후 `Left`와 `Top` 속성을 설정하여 페이지 여백을 기준으로 포인트 단위의 좌표로 도형을 원하는 위치로 이동할 수 있습니다.

```csharp
// Step 3: Position the shape on the page
ellipse.Left = 150; // distance from the left margin
ellipse.Top  = 100; // distance from the top margin
```

이 좌표는 표준 A4 페이지의 상단‑중간에 타원을 대략 배치합니다. 레이아웃 요구에 맞게 값을 조정하세요.

## 4단계: 도형 숨기기 방법

숨김 객체는 문서를 열거나 인쇄할 때 표시되지 않습니다. `Hidden` 플래그를 설정하면 도형이 **hidden object word**로 표시됩니다.

```csharp
// Step 4: Hide the shape so it never appears
ellipse.Hidden = true;
```

Word는 화면 렌더링과 인쇄 출력 모두에서 숨김 플래그를 존중합니다. 도형은 문서 구조의 일부로 남아 있어 이후 코드로 조회하거나 수정할 수 있습니다.

## 5단계: 문서 저장

마지막으로 문서를 디스크에 기록합니다. 쓰기 권한이 있는 폴더를 선택하세요.

```csharp
// Step 5: Save the document to a .docx file
doc.Save(@"C:\Temp\HiddenEllipse.docx");
```

`HiddenEllipse.docx` 파일에는 숨겨진 타원 도형이 포함된 빈 페이지가 들어 있습니다.

## 숨겨진 타원 확인하기

생성된 파일을 Microsoft Word에서 열고 **Show hidden text** 옵션을 활성화합니다 (File → Options → Display). 타원의 흐릿한 윤곽을 볼 수 있습니다. 옵션을 끄면 도형이 완전히 사라져 `ellipse.Hidden = true`가 정상적으로 작동함을 확인할 수 있습니다.

## 일반적인 변형 및 엣지 케이스

| 상황 | 권장 조정 |
|-----------|------------------------|
| **Different shape** | `ShapeType.Ellipse`를 `ShapeType.Rectangle`, `ShapeType.Arrow` 등으로 교체합니다. |
| **Multiple hidden objects** | 각 도형마다 2‑4단계를 반복합니다; 각각 고유한 `Hidden` 플래그를 가질 수 있습니다. |
| **Different page size** | 도형을 삽입하기 전에 `doc.FirstSection.PageSetup.PageWidth`와 `PageHeight`를 설정합니다. |
| **Conditional visibility** | 런타임에 토글하려면 `Hidden`과 함께 `Shape.Visible`을 사용합니다. |

**Pro tip:** 도형의 `AlternativeText` 속성에 식별 데이터를 저장하세요. 숨겨져 있어도 `doc.GetChildNodes(NodeType.Shape, true)`를 사용해 나중에 도형을 검색하고 해당 텍스트로 필터링할 수 있습니다.

## 전체 소스 코드

아래는 복사·붙여넣기 후 실행할 수 있는 완전한 프로그램입니다.

```csharp
using System;
using Aspose.Words;
using Aspose.Words.Drawing;

namespace HiddenShapeDemo
{
    class Program
    {
        static void Main()
        {
            // Create a new blank document and a builder
            Document doc = new Document();
            DocumentBuilder builder = new DocumentBuilder(doc);

            // Insert an ellipse shape (100 pt × 50 pt)
            Shape ellipse = builder.InsertShape(ShapeType.Ellipse, 100, 50);

            // Position the shape on the page
            ellipse.Left = 150;
            ellipse.Top  = 100;

            // Hide the shape so it is invisible in the UI and on print
            ellipse.Hidden = true;

            // Optional: add a description for later retrieval
            ellipse.AlternativeText = "Hidden marker for internal processing";

            // Save the document
            string outputPath = @"C:\Temp\HiddenEllipse.docx";
            doc.Save(outputPath);

            Console.WriteLine($"Document saved to {outputPath}");
        }
    }
}
```

**Expected output:** 콘솔에 저장 경로가 출력되고, `HiddenEllipse.docx` 파일을 열면 숨겨진 객체가 표시되지 않는 빈 페이지가 나타납니다(숨김 객체를 표시하도록 설정하지 않은 경우).

## 결론

이제 **빈 Word 문서를 만들기** 프로그램matically, **타원 삽입 방법**, **도형 위치 지정 방법**, 그리고 **도형 숨기기**를 통해 **hidden object word**처럼 동작하도록 할 수 있습니다. 이 기술은 보이지 않는 마커, 사용자 정의 메타데이터 또는 하위 프로세스가 문서 레이아웃에 영향을 주지 않고 읽을 수 있는 자리표시자를 삽입하는 데 이상적입니다.
