# Java를 사용하여 Word 문서에 도넛 차트 만들기

Word 파일 안에 **create doughnut chart**가 필요하다면, 이 튜토리얼은 완전하고 바로 실행할 수 있는 솔루션을 보여줍니다. **insert pie chart**, 이를 도넛으로 변환, **rotate pie chart**로 균형을 맞추고, **format pie chart**을 브랜드에 맞게 조정하는 방법을 확인할 수 있습니다. 끝까지 진행하면 보고서, 대시보드 또는 자동 이메일 첨부 파일에 사용할 수 있는 전문적인 Word 문서를 얻게 됩니다.

프로그램matically 차트를 생성하면 수동 복사‑붙여넣기 단계를 없애고 수십 개의 생성된 문서 전반에 걸쳐 일관된 스타일을 보장합니다. 예제는 Aspose.Words for Java 라이브러리를 사용하며, Java 8+에서 작동하고 Microsoft Office 설치가 필요하지 않습니다. 표준 JDK와 선호하는 IDE만 있으면 다른 전제 조건은 필요하지 않습니다.

## 전제 조건

- Java Development Kit (JDK) 8 이상  
- Maven 또는 Gradle(의존성 관리용, 이 튜토리얼은 Maven 사용)  
- Aspose.Words for Java 라이브러리(무료 체험 라이선스로 테스트 가능)  

`pom.xml`에 Aspose.Words 의존성을 추가합니다:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-words</artifactId>
    <version>24.9</version> <!-- Use the latest stable version -->
</dependency>
```

> **Pro tip:** 문서를 생성하기 전에 `License license = new License(); license.setLicense("Aspose.Words.lic");` 로 라이선스를 등록하면 평가 워터마크를 제거할 수 있습니다.

## Word 문서에 도넛 차트 만들기

핵심 워크플로는 다섯 가지 논리적 단계로 구성됩니다. 각 단계는 별도의 메서드로 감싸서 코드를 깔끔하고 재사용 가능하게 유지합니다.

```java
import com.aspose.words.*;
import com.aspose.words.drawing.*;

public class DoughnutChartDemo {

    public static void main(String[] args) throws Exception {
        // Step 1: create blank Word document
        Document doc = createBlankWordDocument();

        // Step 2: insert a pie chart (base for the doughnut)
        Chart chart = insertPieChart(doc, 400, 300);

        // Step 3: convert the pie chart into a doughnut and rotate it
        customizeChartAppearance(chart);

        // Step 4: apply additional formatting to the chart
        formatPieChart(chart);

        // Step 5: save the final document
        doc.save("output/DoughnutChartFormatted.docx");
        System.out.println("Document saved successfully.");
    }

    /** Step 1 – create blank Word document */
    private static Document createBlankWordDocument() {
        // Aspose.Words creates an empty document by default
        return new Document();
    }

    /** Step 2 – insert pie chart with given dimensions */
    private static Chart insertPieChart(Document doc, int width, int height) throws Exception {
        DocumentBuilder builder = new DocumentBuilder(doc);
        // ChartType.PIE creates a standard pie chart that we will later turn into a doughnut
        Chart chart = builder.insertChart(ChartType.PIE, width, height);
        // Populate the chart with sample data
        chart.getSeries().clear(); // Remove default series
        ChartSeries series = chart.getSeries().add("Sales", new String[]{"Q1", "Q2", "Q3", "Q4"},
                new double[]{15000, 23000, 18000, 27000});
        return chart;
    }

    /** Step 3 – rotate pie chart and make it a doughnut */
    private static void customizeChartAppearance(Chart chart) {
        // Explode the first slice for emphasis
        chart.getSeries().get(0).setExplode(20);
        // Convert the pie into a doughnut by setting a hole size (percentage of radius)
        chart.setHoleSize(30); // 30% hole creates a classic doughnut look
        // Rotate the chart so the largest slice starts at 45°
        chart.setRotationAngle(45);
    }

    /** Step 4 – additional formatting of the pie chart */
    private static void formatPieChart(Chart chart) {
        // Example: change the first slice color to a brand color
        chart.getSeries().get(0).getPoints().get(0).getFormat().setFillForegroundColor(Color.fromArgb(0xFF, 0x4A, 0x90));
        // Add a legend and position it at the bottom
        chart.setHasLegend(true);
        chart.getLegend().setPosition(LegendPosition.BOTTOM);
        // Set a title for the chart
        chart.setTitle("Quarterly Sales Distribution");
    }
}
```

### 코드가 수행하는 작업

| 단계 | 작업 | 이유 |
|------|--------|--------|
| **Create blank Word document** | `new Document()` | 모든 요소를 제어할 수 있도록 깨끗한 파일로 시작합니다. |
| **Insert pie chart** | `builder.insertChart(ChartType.PIE, …)` | 파이 차트가 기본 형태이며, Aspose는 구멍 크기를 조정하여 도넛을 제공합니다. |
| **Rotate pie chart** | `chart.setRotationAngle(45)` | 회전으로 가장 큰 조각을 더 읽기 쉬운 위치에 맞춥니다. |
| **Format pie chart** | `setExplode`, `setHoleSize`, color, legend | 시각적 계층 구조를 개선하고 기업 스타일 가이드라인에 맞춥니다. |
| **Save document** | `doc.save("…/DoughnutChartFormatted.docx")` | 배포 준비가 된 최종 .docx 파일을 디스크에 기록합니다. |

## 도넛으로 변환하기 전에 파이 차트 삽입

Aspose.Words는 직접적인 “도넛 차트 삽입” 메서드를 제공하지 않습니다. 대신 **insert pie chart** 후 속성을 수정합니다. 이 두 단계 접근 방식은 데이터 시리즈, 조각 폭발, 구멍 크기에 대한 완전한 제어를 제공합니다. 다른 곳에서 순수 파이 차트가 필요하면 `setHoleSize` 호출을 생략하면 됩니다.

## 시각적 균형을 위한 파이 차트 회전

기본 방향은 첫 번째 조각을 12시 위치에서 시작합니다. 많은 비즈니스 보고서에서 가장 중요한 조각은 45도와 같은 보다 자연스러운 각도에서 시작하는 것이 좋습니다. `setRotationAngle(double angle)` 메서드는 각도를 받아 차트 전체를 회전시키며 데이터 값에는 영향을 주지 않습니다.

## 파이 차트 포맷 및 외관 맞춤

도넛으로 변환하는 것 외에도, 종종 **format pie chart** 요소를 조정하고 싶습니다:

- **Explode** 첫 번째 조각을 (`setExplode`) 시켜 주목을 끕니다.  
- `getPoints().get(i).getFormat().setFillForegroundColor`를 사용해 각 조각에 **Color**를 지정합니다.  
- **Legend** 위치(`setHasLegend`, `setPosition`)는 독자가 카테고리를 해석하는 데 도움이 됩니다.  
- **Title**(`setTitle`)은 한눈에 컨텍스트를 제공합니다.  

이 모든 설정은 선택 사항이며, 브랜드 팔레트나 기업 템플릿에 맞게 조정할 수 있습니다.

## 빈 Word 문서 만들기 및 결과 저장

`createBlankWordDocument` 메서드는 **create blank word document** 단계를 캡슐화합니다. 이 로직을 분리하면 배치 프로세스에서 여러 보고서를 생성할 때 메서드를 쉽게 재사용할 수 있습니다. 모든 커스터마이징이 끝난 후 `doc.save`는 표준 Office Open XML 형식(`.docx`)으로 파일을 기록하며, Microsoft Word, LibreOffice, Google Docs에서 손실 없이 열 수 있습니다.

### 예상 출력

`main` 메서드를 실행하면 콘솔에 다음이 출력됩니다:

```
Document saved successfully.
```

그리고 파일 `output/DoughnutChartFormatted.docx`에는 *Quarterly Sales Distribution*이라는 제목의 도넛 차트가 포함된 단일 페이지가 있습니다. 차트는 네 개의 조각을 표시하며, 첫 번째 조각이 폭발되고 브랜드 색상으로 색칠되며 45도 회전되었습니다.

## 일반적인 변형 및 예외 상황

| 상황 | 조정 |
|-----------|------------|
| **More than one data series** | `chart.getSeries()`에 추가 `ChartSeries` 객체를 추가합니다. |
| **Different chart size** | `insertPieChart`의 `width`와 `height` 인수를 변경합니다. |
| **No hole (pure pie)** | `chart.setHoleSize(…)` 호출을 생략하거나 `0`으로 설정합니다. |
| **Large documents** | 특정 섹션이나 북마크에 차트를 삽입하려면 `DocumentBuilder`를 사용합니다. |
| **License not set** | 라이브러리가 평가 모드로 실행되어 첫 페이지에 워터마크가 추가됩니다. 라이선스를 등록하면 제거됩니다. |
