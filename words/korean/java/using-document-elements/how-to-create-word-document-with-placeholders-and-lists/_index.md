# 자리 표시자와 목록이 포함된 Word 문서 만들기

프로그램matically **Word 문서 만들기**가 필요하다면, 이 가이드가 정확히 어떻게 하는지 보여줍니다. **자리 표시자 텍스트 설정**, **목록 항목 추가**, 그리고 **SDT 사용 방법**(Structured Document Tag) 컨트롤을 Aspose.Words for .NET으로 사용하는 방법을 단계별로 안내합니다.

개발자들은 종종 Word를 열지 않고도 .docx 파일에 콘텐츠 컨트롤(예: 일반 텍스트 자리 표시자 또는 드롭다운 목록)을 직접 삽입할 방법을 요청합니다. 이 튜토리얼은 완전한 실행 가능한 예제를 제공하고, 각 단계가 왜 중요한지 설명하며, 기존 문서에 컨트롤을 추가하거나 목록 값을 사용자 지정하는 등 일반적인 변형도 다룹니다.

## 사전 요구 사항

시작하기 전에 다음이 설치되어 있는지 확인하십시오:

- .NET 6.0 SDK 이상이 설치되어 있음  
- Visual Studio 2022(또는 기타 C# IDE)  
- 활성화된 Aspose.Words for .NET 라이선스(무료 체험판도 개발에 사용할 수 있음)  
- C# 구문에 대한 기본적인 이해  

코드는 **Aspose.Words 23.9**(작성 시 최신 안정 버전)를 대상으로 합니다. 최신 릴리스를 사용하는 경우 NuGet 패키지 버전을 조정하십시오.

## 일반 텍스트 Structured Document Tag 삽입 (자리 표시자 텍스트 설정)

일반 텍스트 SDT는 사용자가 입력할 수 있는 콘텐츠 컨트롤처럼 동작합니다. `Title`과 `PlaceholderName`을 설정하면 Word 내부에 친절한 힌트를 제공할 수 있습니다.

```csharp
            // Step 2: Insert a plain‑text SDT and set its placeholder text
            StructuredDocumentTag plainTextTag = builder.InsertStructuredDocumentTag(
                StructuredDocumentTagType.PlainText, true);
            plainTextTag.Title = "CustomerName";
            plainTextTag.PlaceholderName = "Enter name";
```

**설명:**  
- `InsertStructuredDocumentTag`는 빌더의 현재 커서 위치에 컨트롤을 생성합니다.  
- `StructuredDocumentTagType.PlainText`는 Word에 단순 텍스트 상자를 렌더링하도록 지시합니다.  
- `Title`은 Word XML에서 사용되는 내부 이름이며, 이후 데이터 바인딩에 편리합니다.  
- `PlaceholderName`은 사용자가 입력하기 전까지 회색 힌트로 표시됩니다.

> **Pro tip:** 자리 표시자를 문서의 *Properties* 창에도 표시하려면 `plainTextTag.Tag = "CustomerName"`도 설정하십시오.

## 드롭다운 목록 SDT 삽입 (how to use sdt)

드롭다운 목록을 사용하면 미리 정의된 선택지를 제공할 수 있습니다. 이는 **how to use sdt**를 활용한 열거형 데이터 입력의 핵심입니다.

```csharp
            // Step 3: Insert a drop‑down list SDT and define its title
            StructuredDocumentTag dropdownTag = builder.InsertStructuredDocumentTag(
                StructuredDocumentTagType.DropDownList, true);
            dropdownTag.Title = "Country";
```

**드롭다운이 필요한 이유:**  
드롭다운 목록은 데이터 일관성을 높이고 입력 오류를 줄여줍니다. `Title` 속성은 다운스트림 처리(예: 양식 데이터 추출) 시 식별자로 다시 사용됩니다.

## 드롭다운에 목록 항목 추가 (add list items)

이제 컨트롤에 선택 가능한 값을 채워 넣습니다. 각 `ListItem`은 표시 텍스트와 선택적으로 문서 XML에 저장될 값을 가집니다.

```csharp
            // Step 4: Populate the drop‑down with selectable items
            dropdownTag.ListItems.Add(new ListItem("USA", "US"));
            dropdownTag.ListItems.Add(new ListItem("Canada", "CA"));
            dropdownTag.ListItems.Add(new ListItem("Mexico", "MX"));
```

**핵심 포인트:**  

- 첫 번째 인수(`"USA"`)는 사용자가 보는 텍스트입니다.  
- 두 번째 인수(`"US"`)는 프로그래밍적으로 읽을 수 있는 기본값입니다.  
- 필요한 만큼 항목을 추가할 수 있으며, 목록은 .docx XML의 `<w:listItem>` 요소에 저장됩니다.

### Edge cases and variations

| 상황 | 권장 조정 |
|-----------|------------------------|
| **기존 파일에 컨트롤 추가** | 새 `Document`를 만들 대신 `new Document("Existing.docx")`로 파일을 로드합니다. |
| **자리 표시자를 필수로 만들기** | `plainTextTag.IsShowingPlaceholderWhenEmpty = false`와 `plainTextTag.IsShowingPlaceholderWhenEmpty = true`를 검증 로직에 따라 설정합니다. |
| **목록 항목을 데이터 소스에 바인딩** | 컬렉션을 순회(`foreach (var country in countries)`)하면서 `dropdownTag.ListItems.Add(new ListItem(country.Name, country.Code))`를 호출합니다. |
| **컨트롤 스타일 지정** | SDT를 삽입하기 전에 `builder.Font` 속성을 사용해 자리 표시자 텍스트의 기본 스타일을 지정합니다. |
| **나중에 컨트롤 제거** | `doc.GetChildNodes(NodeType.StructuredDocumentTag, true)`로 찾아 `tag.Remove();`를 호출합니다. |

## 프로그램matically 컨트롤 생성 – 모범 사례

1. **먼저 문서를 생성** – `DocumentBuilder`를 일찍 초기화하면 커서 위치 관련 예기치 않은 상황을 방지합니다.  
2. **제목과 태그 설정** – 이후 데이터 추출 시 안정적인 식별자로 작동합니다.  
3. **자리 표시자 텍스트 추가** – 특히 일반 텍스트 태그에서 사용자 경험을 향상시킵니다.  
4. **목록 항목을 즉시 채우기** – Word는 목록이 연결된 후에야 드롭다운을 올바르게 렌더링합니다.  
5. **한 번만 저장** – 루프 내에서 반복 `Save` 호출은 I/O 오버헤드를 크게 증가시킵니다.

이 단계들을 따르면 Word 파일이 *머신‑리더블*(백엔드 처리용)과 *유저‑프렌들리*(프론트엔드 편집용) 모두를 만족하게 됩니다.
